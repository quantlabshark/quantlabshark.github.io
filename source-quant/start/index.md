## 你的第一条学习路径

1. 打开[系统课程](/courses/)，从「研究问题与证据」开始，认识假设、基准与验证。
2. 用 GitHub 登录[个人中心](/account/)，阅读课程正文并保存学习进度。
3. 在[交互实验](/labs/)调整均线和成本，观察合成样本上的差异。
4. 从[资料中心](/resources/)下载相同的数据和 Python 代码，在本机复现。
5. 完成[第一份作业](/assignments/)，在[讨论中心](/community/)交流结果。

## 研究约定

本站案例用于学习方法。实验采用明确标注的合成数据，结果不代表真实市场表现。先记录数据可用时间，再讨论信号收益；先固定验证方案，再看测试集结果。

## 学习时可以做什么

读完一课后标记已学；选中文字添加私人笔记；在课程下提问；把研究过程整理为文章，在作者工作台提交。GitHub 登录用于识别账号，私人笔记仅本人可见，公开讨论对访客可见。
