行情数据接入

使用自己的行情账号，在本机获取并检查数据。

获取一个最小样本

下载行情获取示例。示例使用 Python 标准库，通过 HTTPS 调用 Tushare 日线接口。先在本机环境变量中设置自己的 TUSHARE_TOKEN，再运行脚本；脚本中不含任何人的令牌。

修改脚本里的 ts_code、start_date 和 end_date 可以改变样本范围。默认代码仅用于演示接口，不代表推荐。请求权限和频次由自己的账号决定；程序会明确显示接口错误，不会把失败结果当成行情。

拿到价格后先检查什么

  1. 核对日期范围、排序、重复记录、缺失值与停牌情况。
  2. daily 返回未复权行情。除权除息会影响价格连续性，不能直接用收盘价变化当作含分红总收益。
  3. 记录数据来源、下载时间、字段含义和处理过程；保留原始文件，另存清洗结果。
  4. 研究用复权数据需要检查复权因子、公司行动和当时可获得的信息。展示价格与回测收益应采用明确一致的口径。

原始数据留在自己的本机，网站不会接收你的令牌。学习成交与成本时，可先使用合成数据实验核对代码。

参考：Tushare HTTP 接口、日线行情说明。
