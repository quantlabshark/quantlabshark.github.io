Python 数据结构与算法分析

从 Python 对象和算法成本出发，学习线性结构、递归、排序、树、图与进阶算法。

数据结构决定信息怎样保存，算法决定怎样完成操作。从小规模输入逐步跟踪程序状态，再分析时间与空间成本，并检查边界情形。各节示例可下载运行，章节练习用于独立推演与编程。
