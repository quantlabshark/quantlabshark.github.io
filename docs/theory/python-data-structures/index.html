Python 数据结构与算法分析

    从名称绑定解释共享引用，按操作认识数值和容器，区分切片、浅复制与嵌套对象。

  3. 1.3 输入输出、控制流程与函数

    由数据读取到函数返回组织程序，说明异常处理，并逐步计算牛顿法求平方根。

  4. 1.4 类、分数对象与运算符

    以约分分数建立对象不变式，推导运算规则，解释特殊方法和相等比较。

  5. 1.5 继承、组合与逻辑门模型

    从真值表构造逻辑门接口，说明继承、方法重写、连接器和递归求值。

第 3 章 · 基本数据结构6 节
  1. 3.1 栈与括号匹配

  3. 3.3 队列、双端队列与循环处理

    明确队列与双端队列的操作约定，通过轮转和回文算例分析时间、空间成本。

  4. 3.4 打印任务的离散时间模拟

  5. 3.5 链表、引用更新与有序插入

    用引用图解释链表插入删除，补齐列表操作接口，比较无序与有序链表的定位成本。

  4. 4.4 迷宫搜索、回溯与访问标记

    把网格写成搜索状态，追踪访问集合与当前路线，说明回溯、终止和最短路径的区别。

  5. 4.5 重复子问题、记忆化与动态规划

    由找零的最后一枚硬币推导转移，填写状态表并还原方案，比较记忆化与动态规划。

    逐轮比较冒泡、选择和插入排序，用带标签重复键解释稳定性与逆序对成本。

  4. 5.4 希尔排序与间隔序列

    逐轮展示间隔 4、2、1 的希尔排序，解释分组插入、最终有序性与间隔相关的复杂度。

  5. 5.5 归并排序与分治

    逐项合并有序子列，展开归并排序递推，说明稳定性、缓冲区和自底向上实现。

  6. 5.6 快速排序、划分与枢轴选择

  5. 6.5 二叉搜索树的查找、插入与删除

    维护搜索树的全子树顺序，逐步处理三类删除，补充映射、后继和有序迭代。

  6. 6.6 AVL 平衡树与旋转

    推导 AVL 高度界，按有序区间解释单双旋转，逐步维护缓存高度并说明删除传播。
