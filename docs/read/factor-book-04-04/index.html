4.4 因子模型的复杂度与样本外表现

分别计算因子构造次数和独立输入数量，理解简约指数及复杂模型为何需要独立验证。

两个三因子模型可以有完全不同的工作量

模型A用市场收益、市值和BM，构造三个因子。模型B先计算50项指标，再把它们压成两个综合得分，与市场因子共同使用。二者都叫三因子模型，但B需要更多数据、缺失处理、排序和组合规则。只数最终因子个数，会漏掉大部分复杂度。

复杂度带来的第一个问题是选择空间。假设研究者尝试了多种窗口、断点和权重，再保留历史表现最好的方案，最终结果也包含“挑选”这一步获得的好处。未来没有机会提前知道哪种方案最好，因此需要把选择后的模型放到没有参与选择的数据上检验。

两种简约指数分别数什么

第一种指数逐个因子统计构造变量数，再加总取负：

P1=−∑k=1Knk.P_1=-\sum_{k=1}^{K}n_k.P1​=−k=1∑K​nk​.

KKK 是最终因子数，nkn_knk​ 是构造第 kkk 个因子所用变量数。同一个变量出现在两个因子中，需要计算两次。按这一约定，直接使用市场组合的市场因子记0项额外构造变量。

第二种指数统计最终因子数与不同输入变量的种类数：

P2=−(K+Nunique).P_2=-(K+N_{unique}).P2​=−(K+Nunique​).

这里同一个变量只算一次。两个指数都取负，越接近0表示规则越简单。它们是对构造方式的计数，没有百分比单位。

Fama–French三因子的规模与价值均用市值和BM，因此 P1=−(0+2+2)=−4P_1=-(0+2+2)=-4P1​=−(0+2+2)=−4；最终3个因子、2类输入，所以 P2=−(3+2)=−5P_2=-(3+2)=-5P2​=−(3+2)=−5。

Stambaugh–Yuan四因子的管理使用市值与6项异象，表现使用市值与5项异象，规模使用市值与全部11项异象。因此 P1=−(0+7+6+12)=−25P_1=-(0+7+6+12)=-25P1​=−(0+7+6+12)=−25。4个最终因子、12类输入，P2=−16P_2=-16P2​=−16。只多一个最终因子，数据和构造工作却显著增加。

一个可以自己复算的例子

有市场因子以及两个风格因子：风格一用A、B、C，风格二用B、D。B在第一种计数中出现两次，在第二种计数中只出现一次。

Python6 行
factors = [set(), {'A', 'B', 'C'}, {'B', 'D'}]
p1 = -sum(len(items) for items in factors)
unique = set().union(*factors)
p2 = -(len(factors) + len(unique))
assert (p1, p2) == (-5, -7)
print('简约指数I：', p1, '简约指数II：', p2)

再增加一个只使用A、B的因子，P1P_1P1​变为−7，P2P_2P2​变为−8。没有新数据种类，并不代表没有增加模型结构。

鲨鱼说

把很多指标压成一个综合分，不会自动消除复杂度。需要统计的还包括压缩之前用了什么信息、权重怎样确定，以及这些规则是否根据历史收益反复调整。

拟合改善为何不能代替预测检验

对同一个最小二乘目标增加解释变量，模型至少可以把新系数设为0，继续取得旧模型的拟合效果，所以样本内残差平方和不会增加。这一性质解释了为什么复杂模型容易“看起来更好”。但平均截距、截距显著性和未来预测误差不具有同样的单调保证。

以34项异象为测试对象的历史比较发现，构造更复杂的模型通常留下更少在5%水平显著的异象。这是样本中的经验关系。新增变量也可能带来真实信息，关键是它是否改善了未参与构造的资产或时期。

图中 20 条收益路径均为模拟数据，深色线按验证期表现选出；训练、验证与测试三个区间依次分开。测试期表现显示，历史选出的最佳路径未必继续领先。

图中训练数据用来估计，验证数据用来选择，测试数据留到方案冻结后评价。若每次看到测试结果都重新改规则，这段数据便已经参与了选择，不能继续充当独立证据。

如何决定是否保留新增因子

先写清楚新增变量解释什么经济问题，再与固定基准比较：它是否降低样本外定价误差，是否在不同市场阶段保持方向，是否需要难以取得的数据，是否造成很高换手率。高度相关的因子还会放大估计误差，使系数随样本变化剧烈摆动。

简约指数没有计入样本长度、参数不确定性和交易成本，因此不能把 P1P_1P1​相差5理解为应多赚5%。当两套模型对研究目标的满足程度接近时，输入较少、定义明确的模型通常更易维护。当新增机制改善了某个重要风险场景，就应把这一增益单独量化。

练习

一个模型加入10项指标后，训练期误差下降20%，独立测试期误差上升5%。这说明哪些工作应该优先做？

查看解答

先检查新增指标是否只吸收训练期偶然变化，比较简化模型、收缩估计和删除高度相关变量后的结果。保留同一测试口径，追踪每次尝试，重新选择参数时使用训练或验证区间。测试误差上升提供了具体的过拟合迹象，不能仅凭训练改善保留全部指标。
