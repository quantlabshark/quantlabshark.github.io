1. 三条随机弦分区

题目

每条弦通过在圆周上独立均匀取两个端点生成，三条弦相互独立。它们将圆盘分成 NNN 个区域，求 E(N)E(N)E(N)。

考点：相交事件；区域增量；期望线性性。

查看分析与解答

必要知识

一条新弦没有交点时把一个区域分成两个，增加一区；有 k 个不同内部交点时被切成 k+1 段，增加 k+1 区。随机连续端点下三弦共点或端点重合是零概率情形。

分析思路

把区域数分为起始一区、每条弦固定贡献与各对弦的交点贡献。只需求单对相交概率，不需要列三条弦全部配置。

解答步骤

两弦四个端点按圆周次序记一、二、三、四。三种无序配对为 (12,34)、(13,24)、(14,23)，只有 (13,24) 端点交错、内部相交。由独立均匀端点的标签对称，三种配对等可能。

逐条加入弦：如果新弦与已有弦有 kkk 个不同内部交点，它被切成 k+1k+1k+1 段，每段把一个旧区域分成两个，所以区域数增加 k+1k+1k+1。连续随机抽样下共点、重合概率为零，因此总区域数为 1+3+1+3+1+3+两两交点数。

任意两弦的四个端点绕圆周排列后，只有两弦端点交错才相交。四点分成两对共有三种配对，恰有一种交错，故相交概率 1/3。三对弦的交点指示变量期望相加，得到 E(N)=4+3/3=5E(N)=4+3/3=5E(N)=4+3/3=5。

三条弦共有 C(3,2)=3 对，因此 E[N]=1+3+3×1/3=5。各相交事件可能有关联，但期望仍可逐对相加。推广到 m 条同机制弦得 1+m+C(m,2)/3。

同类问题

几何数量期望可研究逐个加入对象时增加多少，把复杂整体转成局部相交指标。使用交点公式前检查重合、共点是否会改变分段数。

2. 短于半径的随机弦

题目

半径 RRR 的圆中分别按以下方式生成弦：两个端点在圆周独立均匀；弦中点在圆盘面积上均匀，再取垂直半径方向的弦；弦方向均匀且圆心到弦的距离在 [0,R][0,R][0,R] 均匀。分别求弦长小于 RRR 的概率。

考点：随机测度；弦长关系；面积与半径。

查看分析与解答

必要知识

“随机弦”本身不指定唯一分布。端点均匀、中点面积均匀和圆心距离均匀会给不同位置更多权重，即使它们使用同一个几何长度公式。

分析思路

先统一事件阈值，再在每种生成机制下计算该阈值的概率。不要把不同模型中的半径或角度都默认为均匀。

解答步骤

弦中点到圆心距离 d 与半弦长满足 (ℓ/2)²+d²=R²。ℓ<R 等价于 d²>3R²/4。端点模型的较小圆心角均匀于零至 π，ℓ=2Rsin(θ/2)<R 等价于 θ<π/3，故概率一比三。

统一几何关系：若弦到圆心距离为 ddd，半弦与半径组成直角三角形，弦长为 2R2−d22\sqrt{R^2-d^2}2R2−d2​。短于 RRR 等价于 d>3R/2d>\sqrt3R/2d>3​R/2。区别只在 ddd 的分布。

端点模型也可用较小圆心角 θ∈[0,π]\theta\in[0,\pi]θ∈[0,π]，它均匀分布，弦长为 2Rsin⁡(θ/2)2R\sin(\theta/2)2Rsin(θ/2)。中点面积均匀时，半径不均匀，P(d≤r)=r2/R2P(d\le r)=r^2/R^2P(d≤r)=r2/R2；距离均匀模型才有 P(d≤r)=r/RP(d\le r)=r/RP(d≤r)=r/R。分别代入阈值便得到不同概率。

三种概率依次为 1/31/31/3、1−(3/2)2=1/41-(\sqrt3/2)^2=1/41−(3​/2)2=1/4、1−3/21-\sqrt3/21−3​/2。随机生成规则决定测度，因此相同几何阈值可以对应不同答案。

面积均匀时外环 d>√3R/2 的面积比为 [πR²−π(3R²/4)]/(πR²)=1/4；距离均匀时只比较区间长度，概率 (R−√3R/2)/R=1−√3/2。圆心附近同样厚度的环带面积更小，所以均匀面积不等于均匀距离。

3. 停止前未出现五

题目

独立投掷公平六面骰，第一次出现 6 时停止，投掷数为 NNN。已知停止前没有出现过 5，求条件期望 E[N∣停止前无 5]E[N\mid\text{停止前无 5}]E[N∣停止前无 5]。

考点：路径条件；竞争事件；几何分布。

查看分析与解答

必要知识

条件“停止前无五”筛选整段直到六出现的路径，长路径更容易被剔除。它不同于每一步预先把五从骰子上删掉，后者会给另一种长度分布。

分析思路

先写 N=n 与条件事件同时发生的概率，再求条件事件总概率并归一化。也可把五和六看作竞争终点理解均值。

解答步骤

前 n−1 次每次只能一至四，概率四比六，末次为六概率一比六，联合为 (2/3)^(n−1)/6。总和 (1/6)/(1−2/3)=1/2，条件后首项变为三分之一。

不能把条件理解成“每次直接掷一个没有 5 的五面骰”，因为它同时筛选了序列长度。长序列有更多机会出现 5，条件筛选会偏向更短序列。

若长度为 nnn 且无 5，前 n−1n-1n−1 次只能为 1 至 4，最后为 6，联合概率为 (2/3)n−1/6(2/3)^{n-1}/6(2/3)n−1/6。把所有 n≥1n\ge1n≥1 相加得无 5 事件概率为 1/2。除以 1/2 后，条件长度分布变为参数 1/3 的几何分布，均值为 3。

条件分布明确写为 P(N=n∣无五)=(1/3)(2/3)n−1P(N=n\mid\text{无五})=(1/3)(2/3)^{n-1}P(N=n∣无五)=(1/3)(2/3)n−1，n≥1n\ge1n≥1。

忽略一至四，第一次出现五或六的种类等可能；等待五或六的时间每步成功概率二比六，均值三。条件这次终点是六不改变该等待时长分布，因每个可能等待长度下五、六仍对称。

同类问题

对停止路径附加条件，先用联合概率除事件概率，别直接修改每一步样本空间。若能找到对称竞争终点，可进一步简化条件等待分布。

4. 两个有序数组中位数

题目

给定两个已经非降序排列的有限实数数组，长度为 m,nm,nm,n，可为空但不能同时为空。求合并后的中位数，要求时间为 O(log⁡(min⁡(m,n)+2))O(\log(\min(m,n)+2))O(log(min(m,n)+2))、额外空间 O(1)O(1)O(1)，不实际合并数组。

考点：中位分割；单调移动；边界哨兵。

查看分析与解答

必要知识

中位数左边应容纳总数一半，奇数时左侧多一个。两个数组内部已排序，只要交叉边界也有序，就能保证所有左元素不大于所有右元素，无需实际合并。

分析思路

只在较短数组二分切点 i，另一切点 j 由左侧总数量固定。根据哪个交叉边界违反次序决定移动方向，再从边界读取中位数。

解答步骤

例 a=[1,3]、b=[2] 会先交换使 a=[2]、b=[1,3]。左侧需二个，取 i=0、j=2 时 b 左边三大于 a 右边二，说明 a 左侧取少，应增 i；i=1、j=1 时左最大二、右最小三，奇数总数中位为二。

中位数把有序总序列切成左右两半，左侧含 (m+n+1)//2(m+n+1)//2(m+n+1)//2 个元素。假设从较短数组取前 iii 个进入左侧，则另一数组必须取 j=(m+n+1)//2−ij=(m+n+1)//2-ij=(m+n+1)//2−i 个，切分只剩一个自由变量。

正确切分需要第一数组左边界不大于第二数组右边界，且第二数组左边界不大于第一数组右边界。若前者过大，应减少 iii。若后者过大，应增加 iii，因此可二分。奇数总长取左侧最大值，偶数取左最大与右最小的均值。空边界用无穷值表示，可统一处理单数组为空。

在较短数组上二分，时间为 O(log⁡(min⁡(m,n)+2))O(\log(\min(m,n)+2))O(log(min(m,n)+2))、额外空间 O(1)O(1)O(1)。两数组同时为空时中位数无定义。

def median_sorted(a, b):
    if len(a) > len(b):
        a, b = b, a
    if not a and not b:
        raise ValueError('两个数组均为空')
    m, n = len(a), len(b)
    lo, hi = 0, m
    while lo <= hi:
        i = (lo + hi)//2
        j = (m+n+1)//2-i
        al = a[i-1] if i else -float('inf')
        ar = a[i] if i < m else float('inf')
        bl = b[j-1] if j else -float('inf')
        br = b[j] if j < n else float('inf')
        if al > br:
            hi = i-1
        elif bl > ar:
            lo = i+1
        else:
            left = max(al, bl)
            return left if (m+n)%2 else (left+min(ar, br))/2
    raise ValueError('输入须已排序')

assert median_sorted([], [1,2]) == 1.5

若 a 左边界大于 b 右边界，增 i 只会让 a 左值更大、j 更小使 b 右值更小，因此只能减 i；另一种违序反之。较短数组二分还保证 j 不越界。无元素一侧用正负无穷作哨兵，但输入本身应具有一致有效排序，含 NaN 的数据需事先规定处理。

5. 多边形照明

题目

一个房间平面为无洞简单 NNN 边形，光沿直线传播，允许在顶点放点光源。证明至多 ⌊N/3⌋\lfloor N/3\rfloor⌊N/3⌋ 盏灯足以照亮全部房间。

考点：可见性；三角剖分；颜色覆盖。

查看分析与解答

必要知识

房间无洞且边界不自交，允许用内部对角线剖成三角形。三角形内任意两点连线仍在其中，所以一个顶点的灯能照亮该三角形，问题转为选顶点覆盖全部三角形。

分析思路

先构造每个三角形三顶点不同色的着色，再选人数最少的一色放灯。三色的作用是让每个小三角形必含所选颜色。

解答步骤

三角剖分中有 N−2 个三角形、N−3 条内部对角线，按共享对角线连出的邻接图连通且边数比点数少一，因此是树。取叶子对应耳三角形，移去耳顶点可递归着色；恢复时其两个邻点已异色，给耳顶点第三色即可。

先用互不相交的内部对角线把多边形分成三角形。其三角形邻接图是一棵树；从叶三角形逐步剥离，可等价地归纳构造顶点的三种颜色，使每个三角形的三个顶点异色。

具体归纳时，去掉一个只有一个邻居的耳三角形，剩余多边形已着色；恢复耳顶点时，给它与其两个邻点不同的第三种颜色即可。三种颜色顶点数之和为 NNN，最少的一类不超过 ⌊N/3⌋\lfloor N/3\rfloor⌊N/3⌋。

在这类所有顶点放灯，每个三角形都有一盏。三角形是凸的，该顶点能直视其内部所有点，因而所有三角形都被覆盖。

三类顶点总数 N，最少类至多 floor(N/3)。它在每个三角形恰出现一个顶点，因而这些灯照亮三角形并集，也就是全部房间。结论给通用上界，并不说每个 N 边形都至少需要这么多灯，凸房间一盏就够。

7. 另类数据预测想法

题目

考点：代理变量；混杂因素；预测增量。

查看分析与解答

必要知识

等待时间同时受顾客需求与服务供给影响，不可直接等同金融从业者忙碌程度。即使反映关注度，它也可能预测波动而非收益方向，研究目标需先明确。

分析思路

先固定采样地点、时刻与对照店，再剔除常见供需因素，形成异常等待信号。用后续样本检验它在常规市场变量之外的增量，而不是先赋予涨跌方向。

解答步骤

例如办公区店等待十五分钟、训练模型按时段天气预期十分钟，异常为五；若当天所有普通商圈店也普遍多等五分钟，可能是配送或促销共同变化，而非金融活动。可用办公区残差减匹配商圈残差作对照信号。

先固定门店与采样时刻，记录等待时间、营业状态、促销、天气、节假日及配送供给。门店集合不能事后挑选表现最好的地点，历史数据也要保留实际可获得时延。

可先提出较窄假设：办公区相对于普通商圈的异常等待时间，是否反映市场关注度，并预测随后波动率。用训练期模型去除固定门店效应、午休和天气等因素，剩余值作为异常活动信号；信号方向由训练验证决定。

按时间留出后续样本，与仅含历史波动、成交量等常规变量的模型比较误差。若改为收益策略，还要指定可交易资产、成交时点与成本。等待变长可能来自客流增加，也可能来自人员不足，控制普通商圈和供给因素可减少这类混杂。

预测目标可预先定为发布后下一小时实现波动率，输入只使用采样已完成的数据。基准含历史波动、成交量与日内时段，再比较加入等待信号后的时间外误差。门店停业、系统改版或排队估计算法变化需记录，否则信号跳变可能纯由测量口径产生。
