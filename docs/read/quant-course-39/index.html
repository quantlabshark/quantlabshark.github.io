39 · 收缩估计与Black–Litterman配置

用先验与样本的加权关系解释收缩，推导均值更新、相对收益观点及Black–Litterman后验。

收缩估计结合样本信息与较稳定的参考值，减轻小样本估计波动。Black–Litterman 方法进一步把市场隐含收益与带有不确定性的投资观点结合起来。

六个月上涨，能否推断长期均值

某资产六个月平均月收益为2%，而较长期经验给出的均值为0.5%。若两部分信息具有相同精度，一个折中估计为1.25%。样本提供了新证据，但只有六个月时，不必把旧信息完全丢弃。

收缩估计将不稳定的样本结果向结构化目标拉近。它通常引入一些偏差，换取更低的估计方差。是否值得取决于目标是否合理、样本有多少、结果用于何种决策。

协方差为何特别容易估不准

mmm项资产需要估计m(m+1)/2m(m+1)/2m(m+1)/2个独立协方差元素。100项资产对应5050个参数；若只有60期数据，样本协方差的秩至多为59，无法直接获得唯一逆矩阵。

常见收缩形式为

Σ^δ=(1−δ)S+δF,0≤δ≤1.\hat\Sigma_\delta=(1-\delta)S+\delta F,\qquad0\le\delta\le1.Σ^δ​=(1−δ)S+δF,0≤δ≤1.

SSS是样本协方差，FFF是目标矩阵，δ\deltaδ控制收缩程度。对角目标假设资产间不相关。常相关目标保留各自波动、压缩相关性差异。因子目标用少量共同风险描述联动。目标不同，保留的信息也不同。Ledoit–Wolf等方法按估计误差选择强度，不要求先把它解释为贝叶斯先验。

正态均值的贝叶斯更新

设每期收益的方差σ2\sigma^2σ2已知，未知均值μ\muμ的先验为N(m0,v0)N(m_0,v_0)N(m0​,v0​)。观察nnn个独立收益，样本均值为rˉ\bar rrˉ。后验为正态分布，其参数为

vn=(1v0+nσ2)−1,mn=vn(m0v0+nrˉσ2).v_n=\left(\frac1{v_0}+\frac n{\sigma^2}\right)^{-1},\qquad m_n=v_n\left(\frac{m_0}{v_0}+\frac{n\bar r}{\sigma^2}\right).vn​=(v0​1​+σ2n​)−1,mn​=vn​(v0​m0​​+σ2nrˉ​).

方差的倒数称为精度。后验精度等于先验精度加样本精度；后验均值是按精度加权的平均。若先验相当于6期观测，已有6期样本，两个权重各一半，得到前面的1.25%。观察更多数据后，样本权重增加。

下一期收益本身还会波动，因此预测方差是σ2+vn\sigma^2+v_nσ2+vn​。只用σ2\sigma^2σ2忽略了对均值的未知。均值和协方差同时未知时，可以使用正态–逆Wishart先验：μ∣Σ∼N(ν,Σ/κ)\mu\mid\Sigma\sim N(\nu,\Sigma/\kappa)μ∣Σ∼N(ν,Σ/κ)、Σ∼IW(Ψ,n0)\Sigma\sim\mathrm{IW}(\Psi,n_0)Σ∼IW(Ψ,n0​)。其中κ\kappaκ控制均值先验精度，n0n_0n0​控制协方差信息。

在n0>m+1n_0>m+1n0​>m+1时，E(Σ)=Ψ/(n0−m−1)E(\Sigma)=\Psi/(n_0-m-1)E(Σ)=Ψ/(n0​−m−1)。这些参数应与收益周期和矩阵维度一致。

从市场权重反推收益先验

Black–Litterman方法先给出一个基准收益向量，再表达研究者的观点。若均值方差目标为w⊤π−δw⊤Σw/2w^\top\pi-\delta w^\top\Sigma w/2w⊤π−δw⊤Σw/2，在适当的超额收益与融资设定下，市场均衡权重weqw_{\mathrm{eq}}weq​对应

π=δΣweq.\pi=\delta\Sigma w_{\mathrm{eq}}.π=δΣweq​.

这里δ\deltaδ是风险厌恶强度。若目标函数的方差前没有1/21/21/2，一阶条件的系数会相应改变；实现时必须保持同一约定。反推收益提供的是与给定风险、权重和偏好一致的起点。

设未知均值先验为μ∼N(π,V)\mu\sim N(\pi,V)μ∼N(π,V)，其中V=τΣV=\tau\SigmaV=τΣ。参数τ\tauτ描述对均值先验的不确定性，不是直接把资产收益波动缩放成预测波动。

相对观点如何进入矩阵

“A的预期收益比B高1个百分点”可写成Pμ=q+ϵP\mu=q+\epsilonPμ=q+ϵ，其中P=(1,−1)P=(1,-1)P=(1,−1)、q=0.01q=0.01q=0.01，观点误差ϵ∼N(0,Ω)\epsilon\sim N(0,\Omega)ϵ∼N(0,Ω)。一行PPP表达一个观点；Ω\OmegaΩ越大，该观点越不精确。

在先验与观点误差独立的正态模型下，后验均值为

m=π+VP⊤(PVP⊤+Ω)−1(q−Pπ).m=\pi+VP^\top(PVP^\top+\Omega)^{-1}(q-P\pi).m=π+VP⊤(PVP⊤+Ω)−1(q−Pπ).

q−Pπq-P\piq−Pπ是观点与原先预测的差异；中间的矩阵决定根据不确定性应调整多少。后验协方差为

U=V−VP⊤(PVP⊤+Ω)−1PV.U=V-VP^\top(PVP^\top+\Omega)^{-1}PV.U=V−VP⊤(PVP⊤+Ω)−1PV.

若下一期收益噪声协方差Σ\SigmaΣ已知且与均值误差独立，预测协方差为Σ+U\Sigma+UΣ+U，不能只拿UUU当资产风险。

Python13 行
import numpy as np
cov = np.array([[0.04, 0.01], [0.01, 0.09]])
tau = 0.05
prior = np.array([0.04, 0.06])
p = np.array([[1.0, -1.0]])
view = np.array([0.01])
omega = np.array([[0.0025]])
v = tau * cov
adjustment = v @ p.T @ np.linalg.solve(p @ v @ p.T + omega, view - p @ prior)
posterior = prior + adjustment
print(posterior)
print('prior spread:', float((p @ prior)[0]))
print('posterior spread:', float((p @ posterior)[0]))

代码依赖NumPy，先验收益为A4%、B6%，观点为A比B高1%，τ=0.05\tau=0.05τ=0.05、观点方差0.0025。更新后A为4.5625%、B为4.5%，收益差为0.0625%。观点没有被照单全收，因为先验本来认为A低于B2个百分点，且观点自身仍有不确定性。

图中的横轴是A减B的预期收益差，纵轴为概率密度。后验中心在两者之间，分布比先验窄。它表示关于未知均值的认识变化，不是下一期实际收益一定落入的狭窄区间。

鲨鱼说

“观点强”应落实为经过校准的误差大小。随意把观点方差设得极小，会使更新几乎完全服从观点，随后产生集中仓位；这只是输入假设的结果。

练习

若只将观点方差Ω\OmegaΩ扩大很多，后验趋向哪里？若先验均值已经满足Pπ=qP\pi=qPπ=q，还会调整均值吗？

查看解答

观点方差趋于很大时，更新增益趋于0，后验均值回到π\piπ。若Pπ=qP\pi=qPπ=q，差异项为0，均值不调整；但一致的新信息仍可降低后验不确定性，所以UUU一般小于VVV。
