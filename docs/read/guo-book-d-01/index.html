弱收敛、流体极限与扩散极限

区分单个时点的中心极限定理与整条路径的弱收敛，用反射映射建立队列的流体和扩散近似。

1. 一个终点与一条路径

独立同分布变量 XiX_iXi​ 的均值为 μ\muμ、方差为 σ2<∞\sigma^2<\inftyσ2<∞。中心极限定理描述某个固定样本量下的标准化总和：

∑i=1nXi−nμn⇒N(0,σ2).\frac{\sum_{i=1}^nX_i-n\mu}{\sqrt n}\Rightarrow N(0,\sigma^2).n​∑i=1n​Xi​−nμ​⇒N(0,σ2).

订单簿研究还关心期间是否清空、何时达到阈值、累计积压有多大。这些问题依赖整条路径，不能仅由终点分布回答。

定义随时间变化的部分和过程

Sn(t)=1n∑i=1⌊nt⌋(Xi−μ).S_n(t)=\frac1{\sqrt n}\sum_{i=1}^{\lfloor nt\rfloor}(X_i-\mu).Sn​(t)=n​1​i=1∑⌊nt⌋​(Xi​−μ).

Donsker 不变性原理给出函数中心极限定理：

Sn(⋅)⇒σW(⋅).S_n(\cdot)\Rightarrow \sigma W(\cdot).Sn​(⋅)⇒σW(⋅).

一条由离散小增量组成的路径，经过时间加快和幅度缩小后，其分布趋近布朗运动的路径分布。这并不要求每一条模拟路径越来越接近某一条固定布朗路径。

为什么时间乘以 n、幅度除以根号 n

先令增量均值为零、方差为 1。到时点 ttt 已累计约 ntntnt 个独立增量，总和方差约为 ntntnt。除以 n\sqrt nn​ 后，方差变为 ttt，正好与标准布朗运动一致。若除以 nnn，方差会缩到 t/n→0t/n\to0t/n→0，得到的是保留平均趋势的大数定律尺度。

对 s<ts<ts<t，两个时点共享前 ⌊ns⌋\lfloor ns\rfloor⌊ns⌋ 个增量，因此

Cov⁡(Sn(s),Sn(t))=⌊ns⌋n→s=min⁡(s,t).\operatorname{Cov}(S_n(s),S_n(t))=\frac{\lfloor ns\rfloor}{n}\to s=\min(s,t).Cov(Sn​(s),Sn​(t))=n⌊ns⌋​→s=min(s,t).

这解释了布朗运动的协方差结构。证明整条路径收敛还需要控制短时间内的波动，排除越来越窄却很高的尖峰；这种控制称为紧性。只验证几个终点的正态分布，还没有验证最大积压或越界时间的近似。

协方差，即两个变量偏离各自均值时，共同变化程度的度量。

2. 怎样比较有跳跃的两条路径

若 XiX_iXi​ 是平稳、存在足够快衰减依赖的序列，极限仍可能是布朗运动，但方差需要计入各期协方差：

6. 撤单怎样进入近似模型

订单簿中的订单可以主动撤销。若每个等待订单具有近似恒定的撤销强度 θ\thetaθ，队列越长，总撤销速度越高。净漂移会出现类似 −θq-\theta q−θq 的恢复项，扩散近似因而具有 Ornstein–Uhlenbeck 型结构。

如果状态仍表示非负队列长度，就需要处理零边界；若在一个较大的均衡队列附近作中心化，边界在所研究尺度下可能不再起主要作用。订单规模、优先级和撤单行为都会影响具体极限，模型推导应从这些队列规则出发。
