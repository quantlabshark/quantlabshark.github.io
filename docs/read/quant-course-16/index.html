16 · 回归直线怎样解释收益与残差

逐步求斜率和截距，解释R²、预测时序及残差中的非线性和异方差信息。

线性回归用截距和斜率描述变量之间的平均关系。实际观测与拟合值之差称为残差，分析残差可以了解模型尚未解释的变化。

每个符号对应一组观测

市场上涨 1 个百分点时，一只股票通常上涨多少？线性回归用一条直线概括这种共同变化，并把每次偏离直线的部分保留下来。直线提供平均关系，残差则显示还有哪些现象没有解释。

设 xtx_txt​ 为市场收益，yty_tyt​ 为股票收益。模型写成 yt=a+bxt+ety_t=a+bx_t+e_tyt​=a+bxt​+et​，aaa 是截距，bbb 是斜率，ete_tet​ 是误差。若都以百分点表示，b=1.2b=1.2b=1.2 意味着市场收益增加 1 个百分点时，拟合的股票收益增加 1.2 个百分点。

普通最小二乘选择 a,ba,ba,b，使残差平方和 ∑t(yt−a−bxt)2\sum_t(y_t-a-bx_t)^2∑t​(yt​−a−bxt​)2 最小。有截距时，解为

b^=∑t(xt−xˉ)(yt−yˉ)∑t(xt−xˉ)2,a^=yˉ−b^xˉ.\hat b=\frac{\sum_t(x_t-\bar x)(y_t-\bar y)}{\sum_t(x_t-\bar x)^2}, \qquad \hat a=\bar y-\hat b\bar x.b^=∑t​(xt​−xˉ)2∑t​(xt​−xˉ)(yt​−yˉ​)​,a^=yˉ​−b^xˉ.

分子衡量共同变化，分母衡量解释变量本身有多少变化。若所有 xxx 都相同，分母为零，数据无法识别斜率。

最小二乘回归的计算示例

自拟市场收益为 −2、−1、0、1、2 个百分点，股票收益为 −1.5、−1、1、2、2 个百分点。市场均值为 0，股票均值为 0.5。分子为 10，分母也是 10，因此斜率为 1、截距为 0.5 个百分点。

拟合值为 −1.5、−0.5、0.5、1.5、2.5，残差为 0、−0.5、0.5、0.5、−0.5。残差正负相加为零，是含截距 OLS 的拟合性质；不能据此认定真实预测没有偏差。

竖线连接每个实际点与同一横坐标下的拟合值，因此表示股票收益方向上的误差。线的斜率描述共同变化，点散开的幅度描述剩余风险。

R² 比较解释前后的平方偏离

股票围绕自身均值的总平方偏离为 11，回归后的残差平方和为 1，因此 R2=1−1/11≈90.91%R^2=1-1/11\approx90.91\%R2=1−1/11≈90.91%。它衡量样本内线性拟合解释了多少变动，不是预测正确的概率，也不是账户收益率。

增加解释变量通常不会降低样本内 R²，却可能让模型学习噪声。评价预测时，应在未用于估计参数的数据上计算误差。对时间序列，训练段还必须在测试段之前。

Python12 行
import numpy as np
x = np.array([-2,-1,0,1,2],dtype=float)
y = np.array([-1.5,-1,1,2,2],dtype=float)
slope = ((x-x.mean())*(y-y.mean())).sum()/((x-x.mean())**2).sum()
intercept = y.mean()-slope*x.mean()
fitted = intercept+slope*x
residual = y-fitted
r2 = 1-(residual**2).sum()/((y-y.mean())**2).sum()
print(f"截距 {intercept:.2f} 个百分点，斜率 {slope:.2f}，R² {r2:.2%}")
print("残差:",residual)
assert np.isclose(residual.sum(),0)
assert np.isclose(np.dot(x,residual),0)

输出为截距 0.50、斜率 1.00、R² 90.91%。第二个断言检查残差与解释变量正交，也是 OLS 的计算性质。

同期解释与事前预测必须区分

用当月市场收益解释当月股票收益，可以估计市场暴露，却不能在月初知道整月市场收益。若要预测下一期，可以用此前已知的 xt−1x_{t-1}xt−1​，模型改为 yt=a+bxt−1+ety_t=a+bx_{t-1}+e_tyt​=a+bxt−1​+et​。两个模型的输入时间与经济问题不同，不能把同期高 R² 直接称作预测能力。

金融回归还常把股票与市场收益都减去同频率无风险收益。此时截距可解释为相对于该因子模型的平均剩余收益；直接使用总收益得到的截距，含义则不同。加入规模、价值等多个因子后，系数描述控制其他因子后的线性关系。

残差图帮助发现什么

残差若随预测值形成弯曲，线性关系可能遗漏非线性。残差幅度随成交量或波动状态扩大，说明误差方差可能变化。相邻残差持续同号，说明时间依赖尚未处理。正态 QQ 图比较残差分位数与正态分位数，尾端偏离可提示厚尾。

收益波动与成交量的关系还可能适合对数变换。例如研究平方价格变化随成交量的变化时，先明确量纲，再考虑对数尺度。零价格变化不能直接取对数，删除零值也会改变样本，需要在数据处理里保留规则。

鲨鱼说

厚尾，即相对于所比较的较轻尾分布，极端取值更容易出现的分布特征。

新变量的系数为什么会改变旧系数

假设股票收益既随市场变化，也随行业变化，而行业收益与市场高度相关。只放市场变量时，市场系数会吸收部分行业影响。加入行业变量后，市场系数描述在行业变量固定时的增量关系，因此可能改变。这种变化不必意味着程序错误，而是比较条件不同。

若两个解释变量完全相同，数据无法分别判断哪一个产生影响；若只是非常接近，仍可估计，但系数可能对少量数据变化敏感。预测值可能比较稳定，各单独系数却大幅正负变动，这就是多重共线性的一种表现。

回归也不自动建立因果关系。交易量和价格波动可能同时受到新闻影响，把波动对成交量回归得到正系数，不能据此推断人为增加成交量一定导致同样波动。解释变量的时间、共同驱动和选择机制都影响推断。

计算预测误差时，最简单基准可以是训练段均值。若一个新模型在训练段拟合很好，却在后续样本的均方误差高于这个固定均值基准，复杂结构并未改善这项预测任务。基准需要在与模型相同的信息范围内建立。

鲨鱼说

拟合完成后先画残差，而不是只看系数表。残差中连续的形状通常比再多一位小数更能说明模型缺了什么。

练习

模型拟合值为 2%，实际收益为 −1%，残差是多少？这一个负残差能否说明长期 alpha 为负？

查看解答

残差为 −3 个百分点。一个观测只能说明该期低于拟合值；长期 alpha 是整个模型的截距，需要多期估计及标准误，不能从一次残差判断。
