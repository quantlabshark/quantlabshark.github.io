杠杆与随机排列

十倍杠杆、随机分组

1. 十倍杠杆

题目

设策略每期超额收益为 RRR，夏普比率 E[R]/sd⁡(R)=10E[R]/\operatorname{sd}(R)=10E[R]/sd(R)=10。用固定 10 倍杠杆持有该策略，融资利率等于计算超额收益的无风险利率，忽略费用和强制平仓。求波动与夏普的变化，并讨论融资差和复合收益。

考点：超额收益；缩放；融资与复合增长。

查看分析与解答

必要知识

夏普比率用超额收益均值除以标准差。正的固定倍数同时缩放分子分母，因此理想单期夏普不变。财富增长是每期 1+收益率的连乘，不能把单期均值的倍数当作多期财富倍数。

分析思路

先严格按题设写 R_L=10R 并计算均值、方差，再逐项放宽融资、费用和强平假设，说明何时比例关系被破坏。

解答步骤

Var(10R)=100Var(R)，所以标准差乘十而非乘一百。夏普为 10E[R]/[10sd(R)]，与原值相同；负杠杆则会反转均值符号，需要另行处理。

按给定条件，加杠杆后的超额收益为 RL=10RR_L=10RRL​=10R。所以 E[RL]=10E[R]E[R_L]=10E[R]E[RL​]=10E[R]，sd⁡(RL)=10sd⁡(R)\operatorname{sd}(R_L)=10\operatorname{sd}(R)sd(RL​)=10sd(R)，二者相除仍为 10。

例如原策略年化超额收益 20%、波动 2%，理想缩放后对应 200% 与 20%，夏普不变。这里缩放的是单期超额收益的均值与标准差。复合增长由各期财富倍数连乘得到，还受到收益路径影响。

若融资利率比无风险利率高 sss，则借入部分产生额外费用，超额均值约减少 (L−1)s(L-1)s(L−1)s，夏普随之下降。动态限仓、交易成本和保证金强平还会使收益不再等于固定倍数。

若各期无风险收益设为零，财富按 ∏t(1+RL,t)\prod_t(1+R_{L,t})∏t​(1+RL,t​) 演化，杠杆提高波动损耗并放大回撤；单期亏损接近本金时，还可能无法继续持仓。因此，夏普保持不变时，回撤和本金损失风险仍可能随杠杆增加。

例如无杠杆两期先 +10%、再 −10%，财富变为 1.1×0.9=0.99；十倍敞口对应 +100%、−100%，第二期会把财富归零，不能根据夏普缩放判断路径安全。若融资利差 s=1%、L=10，借入的九倍本金每期额外成本约 9%，先从超额均值扣除，再算夏普。

同类问题

比率指标对正比例缩放不敏感，但风险承受能力与财富路径敏感。杠杆分析应同时列出均值、波动、融资和破产边界，而不只比较夏普。

2. 随机分组

题目

20 人各自不放回抽一张姓名标签，共 20 张，每个姓名恰出现一次。将“某人抽到谁”看作一个排列，沿指向关系形成闭合循环，每个循环算一组。求组数期望。

考点：排列循环；均匀插入；期望递推。

查看分析与解答

必要知识

每个人恰好指向一人、也恰好被一人指向，有限有向图因此由不相交循环组成。自己指向自己是长度一的循环。组数是循环数量，而不是互相直接抽到对方的人对数。

分析思路

从 n−1 人的均匀排列构造 n 人排列，寻找哪些插入操作会增加循环。证明这 n 种插入等可能且覆盖所有新排列后，才能写期望递推。

解答步骤

新元素可单独形成循环，也可插在任一旧元素之后。例如旧循环 a→b→a，在 a 后插入新元素 x 就变成 a→x→b→a，循环数不变。给定新排列，删去 x 并接回其前后元素可唯一恢复旧排列及插入位置，所以构造是双射。

例如，A 抽到 B、B 抽到 A，两人的指向闭合，构成长度为 2 的循环。自己抽到自己则构成长度为 1 的循环。所有人恰被指向一次，因此每个人都属于且只属于一个循环。

设 CnC_nCn​ 为 nnn 人随机排列的循环数。从 n−1n-1n−1 人的排列构造 nnn 人排列，有 nnn 种等可能插入方式：让新元素独立成为一个循环，或把它插到原来某个元素之后，共 n−1n-1n−1 个位置。只有第一种增加循环数，所以 E[Cn]=E[Cn−1]+1n.E[C_n]=E[C_{n-1}]+\frac1n.E[Cn​]=E[Cn−1​]+n1​. 由 E[C1]=1E[C_1]=1E[C1​]=1，得到 E[Cn]=∑j=1n1/jE[C_n]=\sum_{j=1}^n1/jE[Cn​]=∑j=1n​1/j。因此 E[C20]=H20≈3.597739657.E[C_{20}]=H_{20}\approx3.597739657.E[C20​]=H20​≈3.597739657. 期望可以不是整数，因为它是不同排列组数的加权平均。若允许标签重复抽取，指向关系可能形成分支，便不再是此处的排列模型。

旧排列有 (n−1)! 种、每种有 n 个插入位置，共 n! 种新排列，均匀选择便保持均匀分布。只有独立成环这一个位置增加组数，增量期望 1/n。求和得 H₂₀≈3.59774。n=2 时两个排列分别有两组和一组，平均 1.5，符合 1+1/2。

同类问题

随机组合对象的期望可用逐个插入构造求解。关键不只是找到一个递推，还要证明构造保留目标的均匀分布。
