二进制与概率编码

2的幂、移位乘法、指定概率模拟和1000个候选的一轮二进制定位。

二进制用二的幂表示整数和小数，位运算则直接处理各位状态。概率编码利用这些表示构造随机结果，需同时检查取值概率与程序停止条件。

二进制表示

二进制整数以 2k2^k2k 为权重，每一位只取 0 或 1。位运算可直接表达集合选择、状态编码和某些算术恒等式。对小数，二进制展开为 p=∑k≥1pk2−kp=\sum_{k\ge1}p_k2^{-k}p=∑k≥1​pk​2−k，这也将公平硬币与均匀随机变量联系起来。

判断 2 的幂

题目

如何判断整数 xxx 是否为 2 的非负整数次幂？

考点：二进制表示；位运算；边界值。

查看分析与解答

必要知识

二进制位权依次为 1、2、4、8。正整数是二的整数次幂，当且仅当其二进制恰有一个 1。按位与只保留两个操作数中同时为 1 的位置。

分析思路

研究 x 减一如何改变最低位的 1：该位变零，更低的零变一，其余高位不变。再与原数相与，恰好清掉最低位的 1。

解答步骤

x=8 时二进制为 1000，x−1=0111，两者相与为 0000。x=12 时为 1100，减一为 1011，相与为 1000，仍非零，说明原数不止一个 1。

正整数 x=2kx=2^kx=2k 的二进制中只有一位为 1，而 x−1x-1x−1 把该位以下全部变为 1，两者按位与为零。反过来，任何含多个 1 的正整数，执行 x&(x−1)x\mathbin{\&}(x-1)x&(x−1) 只会清除最低位的 1，不会使结果全部归零。因此条件为

x>0且x&(x−1)=0.x>0\quad\text{且}\quad x\mathbin{\&}(x-1)=0.x>0且x&(x−1)=0.

x=1=20x=1=2^0x=1=20 符合条件；零必须排除。

Python2 行
def is_power_of_two(x):
    return x > 0 and (x & (x - 1)) == 0

零也会使 x&(x−1) 等于零，因此必须先检查 x>0。一为 2⁰，应该接受。负数的位表示与语言整数模型相关，正数条件同时将其排除。固定宽度机器整数下该判断为常数时间；任意精度整数的位运算成本随位数增长。

同类问题

操作 x&(x−1) 每次删除最低的一个置位，可用于计算置位个数。位技巧应先用二进制变化解释，再列出零、负数与表示宽度的边界。

不用乘法计算七倍

题目

不使用乘法运算符，如何计算整数 xxx 的 7 倍？

考点：移位；常数乘法分解；数值表示。

查看分析与解答

必要知识

左移 k 位在数学整数模型下等于乘 2ᵏ。把常数写成少数二的幂之和或差，可以用移位与加减代替乘法。七接近八，因此 7x=8x−x 只需一次移位与一次减法。

分析思路

先做代数分解，再映射为语言操作。用正、负样例检查实现，并说明固定宽度下中间结果是否可能比最终值更大。

解答步骤

x=5 时，5<<3=40，再减 5 得 35；x=−3 时，Python 中 −3<<3=−24，再减 −3 得 −21。结果分别等于 7×5 与 7×(−3)。

由 7x=8x−x7x=8x-x7x=8x−x，将 xxx 左移三位后减去原数即可：

Python2 行
def multiply_by_seven(x):
    return (x << 3) - x

Python 整数可扩展，正负整数均满足该等式。固定宽度语言中应检查移位和减法的表示范围，并按该语言对有符号移位的定义实现。

若机器整数有固定范围，中间的 8x 可能溢出，即使 7x 仍可表示。不同语言对有符号负值移位与溢出的规定也不同，因此本示例明确采用 Python 任意精度整数。编译器通常能自行优化常数乘法，手写移位不保证更快。

同类问题

常数乘法可按二进制或带符号幂分解，但算法正确性包括中间表示范围。实现选择应结合语言规则，不要把数学恒等式直接等同于所有机器操作。

用公平硬币产生指定获胜概率

题目

只允许使用公平硬币，设计获胜概率为任意给定 0<p<10<p<10<p<1 的游戏。

考点：随机位；逆概率构造；几乎必然停止。

查看分析与解答

必要知识

公平硬币给独立的零一位。把这些位作为二进制小数，可构造 [0,1] 上的均匀变量 U；U<p 的概率就是 p。比较两个二进制小数，只需找到第一位不同的位置。

分析思路

不必先生成无限位 U，而是边投边比较。一旦某一位确定大小关系，后面的位都不可能改变结论，立即停止。

解答步骤

以 p=1/3=0.010101…₂ 为例，第一随机位为 1 时立即失败；第一位为 0 则继续比较第二位，第二位为 0 时立即成功；若为 1 则继续。这与逐位比较 U 和 p 完全一致。

把 ppp 写成二进制 0.p1p2…0.p_1p_2\ldots0.p1​p2​…。每次硬币结果作为随机位 bib_ibi​：正面记 1，反面记 0。依次比较 bib_ibi​ 与 pip_ipi​；第一次出现 bi<pib_i<p_ibi​<pi​ 时获胜，第一次出现 bi>pib_i>p_ibi​>pi​ 时失败，相同则继续。若采用有限展开且全部位相同，则判失败。

无限硬币位产生 U=∑i≥1bi2−i∼U(0,1)U=\sum_{i\ge1}b_i2^{-i}\sim U(0,1)U=∑i≥1​bi​2−i∼U(0,1)，上述规则正是在判定 U<pU<pU<p，故获胜概率为 ppp。前 kkk 位仍完全相等的概率为 2−k2^{-k}2−k，所以无限等待概率为零，投掷次数期望不超过 ∑k≥02−k=2\sum_{k\ge0}2^{-k}=2∑k≥0​2−k=2。

例如 p=1/4=0.012p=1/4=0.01_2p=1/4=0.012​，两次结果中只有 00 获胜；p=1/3p=1/3p=1/3 的二进制无限循环，但算法仍以概率 1 在有限步停止。下列实现用有理数维持精确二进制展开，避免有限浮点舍入改变目标概率。

Python19 行
from fractions import Fraction
import random

def bernoulli_from_fair_coin(p, rng=None):
    p = Fraction(p)
    if not 0 <= p <= 1:
        raise ValueError('p must lie in [0, 1]')
    if p == 0 or p == 1:
        return p == 1
    rng = random if rng is None else rng
    while True:
        p *= 2
        target_bit = int(p)
        p -= target_bit
        coin_bit = rng.randrange(2)
        if coin_bit < target_bit:
            return True
        if coin_bit > target_bit or p == 0:
            return False

投到第 k 次之前仍未确定，要求前 k−1 位全部匹配，其概率为 2⁻⁽ᵏ⁻¹⁾，所以平均投掷次数不超过 1+1/2+1/4+…=2。代码用 Fraction 表示有理目标；如需精确的十进制 0.1，应传 Fraction(1,10) 或字符串 '0.1'，直接传二进制浮点 0.1 会表示该浮点近似值对应的有理数。任意实数目标则需要能逐位提供其二进制展开的接口。

以 p=1/3=0.010101…2p=1/3=0.010101\ldots_2p=1/3=0.010101…2​ 为例。随机二进制小数 U=0.B1B2…U=0.B_1B_2\ldotsU=0.B1​B2​… 的各位来自独立公平硬币；从左向右，遇到第一处不同即可比较 U<pU<pU<p。输出 1 的互斥情形是随机位以 00、0100、010100 等开头，其概率依次为 1/4,1/16,1/64,…1/4,1/16,1/64,\ldots1/4,1/16,1/64,…，总和为 (1/4)/(1−1/4)=1/3(1/4)/(1-1/4)=1/3(1/4)/(1−1/4)=1/3。前 kkk 位一直相同的概率为 2−k2^{-k}2−k，因此平均读取位数为 ∑k=0∞2−k=2\sum_{k=0}^{\infty}2^{-k}=2∑k=0∞​2−k=2；有限二进制展开还可提前结束。

同类问题

无限对象并不意味着算法必须无限运行。若有限前缀已足以确定事件，可逐步生成并几乎必然停止；同时要区分理论实数输入与程序可精确表示的输入。

千瓶酒的二进制编码

题目

为宴会准备的 1000 瓶酒中恰有一瓶被下毒。宴会前 20 小时得知消息，有 10 只实验小鼠可用于检测。即使少量毒酒也会使小鼠恰好在 18 小时后死亡，此前没有其他症状。只允许同一时刻进行一轮并行检测，最后仅记录各检测的二元结果，不能借助不同开始时间编码。如何在宴会前确定有毒酒瓶？

考点：信息量；二进制编码；并行分组检测。

查看分析与解答

必要知识

一个理想二元检测结果只能区分两类情况，m 个并行结果最多给出 2ᵐ 种模式。1000 个候选需要至少 ceil(log₂1000)=10 位信息。时间不足以等待多轮反馈，因此需要一次非自适应编码。

分析思路

给每个候选一个不同的十位编码，让第 k 个检测对应编码第 k 位是否为一。结果向量直接恢复唯一异常候选的编号；先说明容量下界，再给达到下界的构造。

解答步骤

九个检测最多区分 512 种情况，不足以保证定位 1000 个候选；十个提供 1024 种模式，数量上足够。编号选 1 至 1000，零模式不对应任何候选，剩余编码也可作为模型异常信号。

将小鼠死亡记作阳性、存活记作阴性。10 个二元结果可区分 210=10242^{10}=1024210=1024 种状态，足以编码 1000 个候选。把酒瓶编号为 1 至 1000，用 10 位二进制表示。第 kkk 个检测对象对应权重 2k−12^{k-1}2k−1，它只接收编号中该位为 1 的酒瓶样本。

同时进行一次检测。18 小时后，把第 kkk 个对象阳性记为 bk=1b_k=1bk​=1、阴性记为 0，则问题酒瓶编号为

j=∑k=110bk2k−1.j=\sum_{k=1}^{10}b_k2^{k-1}.j=k=1∑10​bk​2k−1.

例如 1000 的编码为 111110100021111101000_211111010002​。若第 6、7、9 个对象为阳性，其余阴性，则编号为 25+26+28=3522^5+2^6+2^8=35225+26+28=352，对应 010110000020101100000_201011000002​。每瓶具有唯一编码，因此一次并行结果可唯一定位；等待检测结果后再逐轮二分则会超过给定时间。

这里的数学模型要求恰有一个异常来源、混合检测结果等于所含样本是否包含该来源，并且检测没有误差。它本质上是单异常对象的非自适应分组检测。

例如编号 13 的编码为 0000001101₂，对应权重 1、4、8 三位为阳性，其他位阴性，解码为 1+4+8=13。唯一异常使结果向量恰好等于其编码；多个异常时结果是多个编码的逐位或，可能与另一编号混淆，因此此构造针对单异常模型。

同类问题

分组检测可先用结果模式数量给信息下界，再设计唯一编码。若存在检测噪声或多个异常，需要冗余编码或不同的检测矩阵，普通二进制编号不再足够。
