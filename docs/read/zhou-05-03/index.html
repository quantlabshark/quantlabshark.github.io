动态规划

Bellman方程、三次骰子、系列赛复制、归零骰子与红黑牌的最优停止。

动态规划将多阶段选择写成状态与价值的递推。每一步比较立即行动的结果和继续等待的价值，再由终点向前计算决策。

设问题有阶段 k=0,…,Nk=0,\ldots,Nk=0,…,N，状态为 xkx_kxk​，决策为 uku_kuk​，随机扰动为 wkw_kwk​，满足

阶段成本为 gk(xk,uk,wk)g_k(x_k,u_k,w_k)gk​(xk​,uk​,wk​)，末期成本为 gN(xN)g_N(x_N)gN​(xN​)。最小期望总成本的价值函数满足 Bellman 方程

JN(x)=gN(x),Jk(x)=min⁡u∈Uk(x)E[gk(x,u,wk)+Jk+1(fk(x,u,wk))].J_N(x)=g_N(x),\qquad J_k(x)=\min_{u\in U_k(x)}E\left[g_k(x,u,w_k)+J_{k+1}(f_k(x,u,w_k))\right].JN​(x)=gN​(x),Jk​(x)=u∈Uk​(x)min​E[gk​(x,u,wk​)+Jk+1​(fk​(x,u,wk​))].

三次投掷内的骰子停止问题

题目

最多独立投掷公平六面骰三次，目标是使最终金额的期望最大。前两次掷出 xxx 后，可以选择获得 xxx 美元并结束，也可以放弃本次点数继续掷。第三次必须接受该点数。求最优策略与游戏价值。

考点：逆向归纳；继续价值；最优停止。

查看分析与解答

必要知识

价值 V_k 指尚有 k 次投掷机会、还未看到当前点数时的最优期望。看到点数 x 后，要比较立即获得 x 与放弃它后的继续价值 V_(k−1)。风险中性意味着以期望金额为准。

分析思路

从最后一次向前推。最后一次没有选择，均值为 3.5；倒数第二次据此确定阈值，算出新的继续价值，再决定第一次的阈值。

解答步骤

继续会放弃本次点数，因此每个分支的价值是 max(x,V_(k−1))，而不是 x+V_(k−1)。统一递推为 Vk=(1/6)∑x=16max⁡(x,Vk−1)V_k=(1/6)\sum_{x=1}^6\max(x,V_{k-1})Vk​=(1/6)∑x=16​max(x,Vk−1​)，k≥2。

剩余一次投掷时，价值 V1=7/2=3.5V_1=7/2=3.5V1​=7/2=3.5。剩余两次时，首掷为 4、5、6 就停止，为 1、2、3 则继续，因此

V2=3V1+4+5+66=4.25.V_2=\frac{3V_1+4+5+6}{6}=4.25.V2​=63V1​+4+5+6​=4.25.

最初剩余三次，首次掷出 5、6 则停止，1 至 4 则继续。故

V3=4V2+5+66=143≈4.6667.V_3=\frac{4V_2+5+6}{6}=\frac{14}{3}\approx4.6667.V3​=64V2​+5+6​=314​≈4.6667.

这里每次继续都放弃此前点数，不能将三次最大值的期望作为游戏价值。

实际执行规则为：第一次 5 或 6 接受，其余再投；第二次 4、5、6 接受，其余再投；第三次无论结果都接受。三次都投完再取最大值使用了当时不可得的未来信息，不是可执行的停止策略。

同类问题

有限期限停止问题通常从终点回推，每一层比较立即收益与继续的条件期望。机会越多，继续价值通常越高，接受当前结果的门槛也随之提高。

题目

考点：动态复制；二叉状态；自融资。

查看分析与解答

必要知识

分析思路

累计金额归零的骰子游戏

题目

可持续独立投掷公平六面骰。掷出 1 至 5 时，累计获得相应美元金额，并可选择停止；掷出 6 时，此前收益全部归零，游戏结束。风险中性的参与者最多愿意支付多少入场费？

考点：无限期停止；Bellman 方程；阈值验证。

查看分析与解答

必要知识

状态 n 是当前累计金额。停止得到 n；继续时，点数 6 会归零，1 至 5 则转到 n+k。最优价值必须比较当前确定金额与未来最优期望，而非仅比较下一次点数均值。

红黑牌的最优停止

题目

一副 52 张扑克牌含 26 张红牌、26 张黑牌，均匀洗牌后依次翻开，不放回。每张红牌收入 1 美元，每张黑牌损失 1 美元，可以随时停止。求最大期望收益及最优停止规则。

考点：无放回状态；动态规划；停止边界。

查看分析与解答

必要知识

剩余黑牌 b、红牌 r 完全决定未来牌色概率。由于最初各有 26 张，当前收益等于已翻红减已翻黑，即 (26−r)−(26−b)=b−r。定义价值时要说明是最终总收益，还是未来额外收益。

分析思路

这里采用最终总收益 V(b,r)，所以立即停止值为 b−r。继续分支直接使用下一状态的最终价值，不再额外加减一美元，避免重复计算当前收益。

    if b == 0:
        return 0.0
    if r == 0:
        return float(b)
    continuation = (b * value(b - 1, r) + r * value(b, r - 1)) / (b + r)
    return max(b - r, continuation)

def should_stop(b, r):
    if r == 0:
        return True
    if b == 0:
        return r == 0
    continuation = (b * value(b - 1, r) + r * value(b, r - 1)) / (b + r)
    return b - r >= continuation

print(value(26, 26))
for r in range(27):
    print([round(value(b, r), 2) for b in range(27)])

此类问题与美式期权的行权判断具有相同结构：在每个状态比较立即取得的收益与继续持有的价值。

例如 V(1,1)=max(0,[V(0,1)+V(1,0)]/2)=1/2。再看 V(2,1)：停止得 1，继续期望为 [2V(1,1)+V(2,0)]/3=1，两者相同。大牌堆同样逐状态比较，初始价值约 2.62448。程序的决策不是固定“赚到某个数就停”，而取决于剩余牌的组成。

**从小牌堆逐格算，而不是只运行程序。**当剩两黑两红时，当前收益为 0。已有边界 V(1,0)=1,V(2,0)=2,V(0,1)=V(0,2)=0V(1,0)=1,V(2,0)=2,V(0,1)=V(0,2)=0V(1,0)=1,V(2,0)=2,V(0,1)=V(0,2)=0。

  1. 一黑一红：V(1,1)=max⁡(0,(0+1)/2)=1/2V(1,1)=\max(0,(0+1)/2)=1/2V(1,1)=max(0,(0+1)/2)=1/2。
  2. 一黑两红：停止得 −1-1−1；继续得 [V(0,2)+2V(1,1)]/3=1/3[V(0,2)+2V(1,1)]/3=1/3[V(0,2)+2V(1,1)]/3=1/3，故 V(1,2)=1/3V(1,2)=1/3V(1,2)=1/3。
  3. 两黑一红：停止得 1；继续得 [2V(1,1)+V(2,0)]/3=1[2V(1,1)+V(2,0)]/3=1[2V(1,1)+V(2,0)]/3=1，故 V(2,1)=1V(2,1)=1V(2,1)=1。
  4. 两黑两红：V(2,2)=max⁡(0,[2V(1,2)+2V(2,1)]/4)=2/3V(2,2)=\max(0,[2V(1,2)+2V(2,1)]/4)=2/3V(2,2)=max(0,[2V(1,2)+2V(2,1)]/4)=2/3。

这里先算总牌数较小的格子，再用它们计算较大的格子，就是程序缓存递归的计算顺序。26 比 26 只扩大了状态表，所用方程完全相同。
