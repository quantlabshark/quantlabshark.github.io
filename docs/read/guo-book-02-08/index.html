非参数信号、变点与配对交易

把形态识别转化为可检验的统计规则，比较趋势、变点和均值回复信号。

图形需要对应一个统计对象

价格图上的趋势、拐点和偏离，只有写成规则后才能复现。设过去可用变量为 xtx_txt​，目标为下一期收益 rt+1r_{t+1}rt+1​。非参数回归直接估计 m(x)=E(rt+1∣xt=x)m(x)=E(r_{t+1}\mid x_t=x)m(x)=E(rt+1​∣xt​=x)，不预先限定线性关系。

核回归把与当前状态接近的历史样本赋予较大权重：

m^(x)=∑iK((xi−x)/h)ri+1∑iK((xi−x)/h).\widehat m(x)=\frac{\sum_iK((x_i-x)/h)r_{i+1}}{\sum_iK((x_i-x)/h)}.m(x)=∑i​K((xi​−x)/h)∑i​K((xi​−x)/h)ri+1​​.

带宽 hhh 小，曲线更灵活但方差更大；带宽大，结果更平滑但可能掩盖局部变化。边界区域和样本稀少区域的预测尤其不稳定。带宽需要按时间验证，不能为匹配一张历史价格图而选择。

CUSUM 累积小幅变化

若标准化观测在变化前服从 N(0,1)N(0,1)N(0,1)，变化后均值升至已知 δ>0\delta>0δ>0，单次对数似然比为 δxt−δ2/2\delta x_t-\delta^2/2δxt​−δ2/2。未知变化时点时，可递推

Gt=max⁡{0,Gt−1+δxt−δ2/2}.G_t=\max\{0,G_{t-1}+\delta x_t-\delta^2/2\}.Gt​=max{0,Gt−1​+δxt​−δ2/2}.

当 Gt>hG_t>hGt​>h 时报警。减去 δ2/2\delta^2/2δ2/2 使正常时期的增量均值为负，避免单纯累积噪声。阈值越高，误报通常越少，但检测延迟越长。

如果变化发生的起点已知，可以累积似然比并使用序贯概率比检验的上下边界。CUSUM 则不断允许从新的时点重新开始。若变化幅度也未知，有限窗口广义似然比可对起点和幅度同时最大化。例如在单位方差正态模型中，长度为 ℓ\ellℓ 的窗口贡献与 ℓxˉ2/2\ell\bar x^2/2ℓxˉ2/2 有关。只检测向上变化时用正部均值。

移动平均规则也在积累一段窗口的信息，但固定窗口会稀释短促变化。多窗口检测提高对不同持续时间的敏感度，同时增加多重比较，需要重新校准总体报警率。

对数似然，即对似然取自然对数，便于把独立观测的乘积转为求和。

累积检测的一次手算

取待检测均值变化 δ=1\delta=1δ=1、阈值 h=2h=2h=2，依次观察 x=(0.2,−0.4,1.5,1.8)x=(0.2,-0.4,1.5,1.8)x=(0.2,−0.4,1.5,1.8)。每次加入 xt−0.5x_t-0.5xt​−0.5，并将负结果重置为零，统计量依次为 0,0,1.0,2.30,0,1.0,2.30,0,1.0,2.3，第四次越过阈值。前两次不支持均值升高，因此没有持续拖累后面的新证据。

这也说明 CUSUM 与从第一条数据不断累加不同。递推中的零等价于允许变化刚刚开始。从所有可能起点比较累计证据，才适合不知道何时发生改变的场景。阈值 hhh 需要用正常状态下的误报频率和目标变化下的延迟共同校准，数值 2 在这里只用于展示运算。

核回归也可用小例子理解。当前状态附近三条历史观测的核权重为 (1,2,1)(1,2,1)(1,2,1)，次期收益为 (−1%,2%,1%)(-1\%,2\%,1\%)(−1%,2%,1%)，预测均值为 (−0.01+2×0.02+0.01)/4=1%(-0.01+2\times0.02+0.01)/4=1\%(−0.01+2×0.02+0.01)/4=1%。它是相近状态的加权平均；远处样本权重小，不是被证明毫无价值。

半衰期描述条件平均偏离如何减小，不是保证在那个时刻平仓获利。随机冲击会不断加入，价差也可能先扩大再回归。

趋势与配对交易的假设不同

时间序列动量按某个资产自身过去的累计收益决定方向；截面动量按同一期不同资产的表现排序。前者回答“它是否延续上涨”，后者回答“它是否继续强于其他资产”。两者可以在同一市场环境中给出不同持仓。

配对交易寻找两种价格之间较稳定的关系。若 p1,tp_{1,t}p1,t​、p2,tp_{2,t}p2,t​ 为对数价格，可估计价差 st=p1,t−a−bp2,ts_t=p_{1,t}-a-bp_{2,t}st​=p1,t​−a−bp2,t​。只有当价差具有均值回复性质，偏离才有回归的统计依据；高相关不等于价差平稳。

若 st+1=ϕst+ϵt+1s_{t+1}=\phi s_t+\epsilon_{t+1}st+1​=ϕst​+ϵt+1​ 且 0<ϕ<10<\phi<10<ϕ<1，当前价差偏离的条件期望在 hhh 期后为 ϕhst\phi^hs_tϕhst​。半衰期为 log⁡(1/2)/log⁡ϕ\log(1/2)/\log\philog(1/2)/logϕ。建仓阈值还应覆盖双腿手续费、价差、融资和对冲误差。估计对冲比率时只使用训练期，结构变化后需要重新检验关系。

从上涨概率到交易动作

方向分类的准确率不直接决定收益。设上涨赚 uuu，下跌亏 ddd，单次成本为 ccc，预测上涨概率为 ppp。做多的预期净收益为 pu−(1−p)d−cpu-(1-p)d-cpu−(1−p)d−c，因此需满足 p>(d+c)/(u+d)p>(d+c)/(u+d)p>(d+c)/(u+d)。上涨和下跌幅度不同，会改变交易门槛。

鲨鱼说

检测到“过去的分布变了”，不等于知道“接下来一定往哪走”。变点检测可以用于暂停模型或重新估计，交易方向仍需要单独的预测依据。
