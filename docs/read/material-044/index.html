1. 对象拷贝

题目

给定 cfg = {"windows": [5, 20], "cost": 0.001}，执行 shallow = cfg.copy()，随后执行 shallow["windows"][0] = 10 和 shallow["cost"] = 0.002。写出此时两个字典的内容，解释原因，并说明如何得到可独立修改的嵌套副本。

考点：可变对象；引用关系；浅拷贝与深拷贝。

查看分析与解答

必要知识

Python 字典保存键到对象的引用。列表可在原位置修改，浮点数则不可变；给字典键重新赋值，是改变该键所指向的对象，并不是修改旧浮点数本身。

分析思路

分别画外层字典和内层列表，判断哪次操作改变对象内容，哪次操作改变引用。不要只按“已经 copy 过”判断是否独立。

解答步骤

执行 copy 后，cfg is shallow 为假，而 cfg["windows"] is shallow["windows"] 为真。第一条语句找到共享列表后修改其第零个元素；第二条语句只改 shallow 字典内部的 cost 引用。

先画出引用关系：两个外层字典是不同对象，但其 windows 都指向同一个列表，cost 初始指向同一个浮点数对象。

第一条修改通过共享引用改变列表元素，所以两个字典里的列表都成为 [10,20]。第二条修改给 shallow 的键绑定了新浮点数，没有改变 cfg 中的绑定。最终 cfg 为 {"windows":[10,20],"cost":0.001}，shallow 为 {"windows":[10,20],"cost":0.002}。

对这类由字典、列表和普通数值组成的配置，可用 deepcopy 复制嵌套对象。之后修改副本列表不会影响原列表。若只需要独立修改 windows，也可以单独复制该列表。浅拷贝耗时通常与外层键数成正比，深拷贝还需遍历可达的嵌套对象。

Python11 行
from copy import deepcopy

cfg = {"windows": [5, 20], "cost": 0.001}
shallow = cfg.copy()
shallow["windows"][0] = 10
shallow["cost"] = 0.002
assert cfg == {"windows": [10, 20], "cost": 0.001}

independent = deepcopy(cfg)
independent["windows"][0] = 3
assert cfg["windows"][0] == 10

若只需独立列表，可用 independent={**cfg,"windows":cfg["windows"].copy()}，数值仍可共享，因为本身不可变。deepcopy 会递归复制嵌套结构，并用已复制对象记录处理共享和循环引用；它不是简单地对每个引用无限递归。配置中含文件、连接等资源时，需另行定义复制语义。

同类问题

遇到修改一处却影响另一处的问题，逐层检查对象身份。只有会被修改的共享可变对象才是本题的关键，没必要机械地把所有对象都深拷贝。

2. 平方数列表

题目

用一行 Python 代码生成升序列表，包含区间 [1,1000][1,1000][1,1000] 中所有除以 5 余 1 的完全平方数。条件作用于平方后的整数，而不是它的平方根。

考点：列表推导；平方根边界；模运算。

查看分析与解答

必要知识

完全平方数是某个整数的平方。与其遍历全部1至1000再判断是否平方，不如直接枚举可能的整数根。range 的右端点不包含在枚举中。

分析思路

先由上界确定最大整数根，再对平方后的值筛选余数。最后用首尾值和模五的可能余数检查结果。

解答步骤

range(1,32) 产生1到31。表达式 nn 是输出项，if 后的条件也是对 nn 判断；若误写 n%5==1，就会漏掉根余数为4的情况，例如4²=16。

设平方数为 n2n^2n2。由 312=961≤1000<1024=32231^2=961\le1000<1024=32^2312=961≤1000<1024=322，只需枚举正整数根 n=1,…,31n=1,\ldots,31n=1,…,31。逐个检查平方数对 5 的余数即可：

[n*n for n in range(1, 32) if (n*n) % 5 == 1]

根从小到大枚举，平方也递增，不需要再排序。模 5 的平方余数只有 0、1、4，满足条件的根余数为 1 或 4。例如列表开头为 1、16、36、81，末尾为 961。将上界换成 MMM 时，需要 O(M)O(\sqrt M)O(M​) 次检查。

根对五的余数依次为0、1、2、3、4时，平方余数为0、1、4、4、1。因此也可把条件写成 n%5 in (1,4)。当上界很大时，可用 math.isqrt(M) 精确取得整数平方根，避免浮点开方在边界上取错。

同类问题

构造式枚举通常比遍历全部候选再识别更直接。处理整数边界时，用最大合法值及下一个非法值同时验证。

3. 可变参数

题目

解释函数定义和函数调用中 *args、**kwargs 的作用。用 def f(a, *args, **kwargs) 和调用 f(1, 2, 3, scale=4) 说明各参数得到什么值；再说明如何把已有列表、字典传入函数。

考点：参数绑定；打包与解包；关键字冲突。

查看分析与解答

必要知识

位置参数按顺序绑定，关键字参数按名称绑定。星号放在函数定义和调用中有相反方向：定义时收集，调用时展开。元组和字典只是承载这些参数的容器。

分析思路

先逐个模拟参数绑定，再把直接调用改写成容器解包调用，最后检查重复赋值和键类型。

解答步骤

f(1,2,3,scale=4) 首先把1交给a；剩余2和3没有普通位置形参可接收，进入args；scale没有对应的命名形参，进入kwargs。函数内可分别访问 args[0] 与 kwargs["scale"]。

在函数定义里，a 接收第一个位置参数，args 收集其余位置参数并组成元组，kwargs 收集未被其他命名形参接收的关键字参数并组成字典。上述调用中，a=1、args=(2,3)、kwargs={'scale':4}。args 和 kwargs 是惯用名称，起作用的是星号。

在调用里作用相反：f(*[1,2,3], **{'scale':4}) 先将列表拆成三个位置参数，再将字典拆成关键字参数，得到相同结果。映射的键必须是字符串；同一参数不能重复赋值，例如 f(1, a=2) 会报错。

这些符号处理的是函数入参。return x, y 返回的是一个元组，与是否使用可变参数无关。

例如 def f(a,*args,kwargs): return a,args,kwargs，调用后返回(1,(2,3),{"scale":4})。若写 f(*[1,2],{"a":3})，a 已由第一个位置参数赋值，再遇关键字a便冲突。给两个 ** 映射提供同名关键字也会报错，不能把调用规则误认为字典后值覆盖前值。

同类问题

阅读带星号函数时，按“展开实参—绑定普通形参—收集剩余参数”追踪。接口设计中，明确的命名参数更便于校验，只有需要转发或可变长度时才使用收集参数。

4. Lasso 与 Ridge

题目

对中心化后的数据 X∈Rn×pX\in\mathbb R^{n\times p}X∈Rn×p、y∈Rny\in\mathbb R^ny∈Rn，比较目标函数 ∥y−Xβ∥22+λ∥β∥22\|y-X\beta\|_2^2+\lambda\|\beta\|_2^2∥y−Xβ∥22​+λ∥β∥22​ 与 ∥y−Xβ∥22+λ∥β∥1\|y-X\beta\|_2^2+\lambda\|\beta\|_1∥y−Xβ∥22​+λ∥β∥1​。说明它们的解、稀疏性、共线性表现，以及标准化和惩罚参数的选择。

考点：二次惩罚；软阈值；训练内标准化。

查看分析与解答

必要知识

β 是特征系数向量，残差平方和衡量拟合误差，λ控制系数惩罚强度。中心化使截距可单独处理。共线性意味着不同系数组合可能给出相近预测，导致系数对数据扰动敏感。

鲨鱼说

Lasso 的零点像一个可接住多种斜率的范围。当平方损失在零处的推动力没有超过惩罚阈值，系数就停在零；Ridge 的惩罚则随系数平滑变化，通常只把它缩小。

分析思路

先在单个单位长度特征上看两种惩罚如何改变解，再推广到矩阵形式。Lasso 在零点需用次梯度，不能把绝对值当作处处可微。

解答步骤

单变量平方损失去掉常数后是 β²−2zβ。Ridge 加 λβ²，导数2(1+λ)β−2z，故解为z/(1+λ)。Lasso 在β>0时导数2β−2z+λ，在β<0时为2β−2z−λ；零点的绝对值次梯度范围[−1,1]，当|2z|≤λ时零即可满足最优条件。

记 (z)+=max⁡(z,0)(z)_+=\max(z,0)(z)+​=max(z,0)，sign⁡(z)\operatorname{sign}(z)sign(z) 表示 z 的正负号（零的符号取 0），λ≥0\lambda\ge0λ≥0 为惩罚强度。两种方法都在拟合误差之外惩罚较大的系数。增大 λ\lambdaλ 通常会增加训练误差，同时限制系数对样本扰动的敏感程度。

在单一标准正交特征的例子中，令 XTX=1X^TX=1XTX=1、z=XTyz=X^Tyz=XTy。Ridge 的解为 z/(1+λ)z/(1+\lambda)z/(1+λ)；本题未在平方损失前乘 1/21/21/2，所以 Lasso 的解为 sign⁡(z)(∣z∣−λ/2)+\operatorname{sign}(z)(|z|-\lambda/2)_+sign(z)(∣z∣−λ/2)+​。这展示了连续缩小与直接归零的区别，也说明推导时必须固定损失函数系数。

采用未除以样本数的记号，岭回归最小化 ∥y−Xβ∥22+λ∥β∥22,λ>0.\|y-X\beta\|_2^2+\lambda\|\beta\|_2^2,\quad\lambda>0.∥y−Xβ∥22​+λ∥β∥22​,λ>0. 梯度为 2X⊤(Xβ−y)+2λβ2X^\top(X\beta-y)+2\lambda\beta2X⊤(Xβ−y)+2λβ，令其为零可得 β^ridge=(X⊤X+λI)−1X⊤y.\hat\beta_{\rm ridge}=(X^\top X+\lambda I)^{-1}X^\top y.β^​ridge​=(X⊤X+λI)−1X⊤y. 实际实现应解线性方程，不必显式求逆。λ>0\lambda>0λ>0 使矩阵正定，即便 X 列相关也能获得唯一解。系数被平滑缩小，但一般不会恰好为零。

Lasso 将惩罚替换为 λ∥β∥1\lambda\|\beta\|_1λ∥β∥1​。绝对值在零处不可微，最优性条件允许一段梯度由零系数满足，因此能产生稀疏解。一般用坐标下降等算法。高度相关的因子中，它可能只保留某一个，所选成员对样本变化较敏感。岭回归更倾向于分摊权重。

惩罚直接作用于系数，特征单位会改变相同经济暴露所需的系数大小，所以标准化必须只用训练段拟合。截距一般不惩罚。λ\lambdaλ 用时间顺序验证选择，标准化、缺失值处理和特征筛选均在各训练折内重新拟合。Lasso 的稀疏性不等于发现因果关系，也不保证投资组合换手更低。

例如 z=0.3、λ=1，Ridge 给0.15，Lasso给零；z=2时两者分别为1和1.5。两种数值不表示相同λ对应相同正则强度。若一列特征乘100，其等效系数缩为百分之一，惩罚随之改变，所以要统一尺度并在训练数据上确定变换。

同类问题

比较正则化模型时，先统一损失系数、特征尺度和验证方式。稀疏系数只是统计模型的一种结构，若关心交易换手，应直接对仓位变化及成本建模。

5. Dropout 训练与推理

题目

采用 inverted dropout，保留概率为 q∈(0,1]q\in(0,1]q∈(0,1]。给定某神经元的激活值 aaa，训练时输出 ma/qma/qma/q，其中 m∼Bernoulli⁡(q)m\sim\operatorname{Bernoulli}(q)m∼Bernoulli(q)。计算条件均值和方差，并说明推理时如何处理、为什么要切换评估模式。

考点：伯努利随机变量；条件矩；模型状态。

12. 翻牌与环

题目

有 nnn 张牌，编号为 0,…,n−10,\ldots,n-10,…,n−1，第 iii 张正面写着编号 pip_ipi​，其中 ppp 是这 nnn 个编号的一个排列。所有牌正面朝上时，从 iii 向 pip_ipi​ 连一条有向边。翻到背面后删去该牌对应的出边，其他边不变。至少翻几张牌，才能使图中没有有向环？给出方案和算法。

考点：置换环；结构分解；下界与构造。

查看分析与解答

必要知识

排列保证每个编号出现一次，所以每个顶点恰有一条出边和一条入边。有限图沿出边走最终重复，而入度一又排除了环外树枝，故全部顶点恰好分成不交的环。

分析思路

先按环分解，证明每个环至少需要一次删除，再给每环恰删一条边的方案，使上下界相等。

解答步骤

若存在自环 p_i=i，它也是一个环，必须翻该牌。若有两个不同环，删掉其中一环的边不影响另一环，所以不能用一次翻牌同时解决两环。

因为 ppp 是排列，每个顶点的入度、出度都是 1，图恰好分解成若干互不相交的有向环。若有 ccc 个环，至少要从每个环翻一张牌；否则该环的所有边都保留，仍然存在环。这给出下界 ccc。

反过来，每个环任选一张牌翻到背面，删去一条边后，该环变成一条有向路径，不会影响其他环。翻 ccc 张就足够，所以最少数恰为环数。

用 visited 数组，从每个未访问的编号出发沿 pip_ipi​ 移动，直到遇到访问过的编号。每开始一次新遍历就发现一个环，并记录起点作为要翻的牌。例如 p=[1,0,3,4,2]p=[1,0,3,4,2]p=[1,0,3,4,2] 有环 0→1→00\to1\to00→1→0 和 2→3→4→22\to3\to4\to22→3→4→2，最少翻 2 张，可翻编号 0 和 2。每个顶点只访问一次，时间和空间都是 O(n)O(n)O(n)。

样例从0遍历得到0、1，标记已访问；下一个未访问的2得到2、3、4。各记一个起点就是删除方案。由于每次沿边前都检查visited，每个顶点只展开一次，即使单个环长达n，总时间仍为O(n)。

13. 回文链表

题目

给定单链表头结点，判断结点值从前向后是否与从后向前相同。要求时间复杂度为 O(n)、额外空间为 O(1)，返回前恢复链表原有连接；空链表和单结点链表视为回文。

考点：快慢指针；链表反转；恢复不变量。

查看分析与解答

必要知识

单链表只能沿 next 向前走，不能直接从尾向前比较。原地反转后半段，相当于把后向访问转换为前向遍历；恢复要求意味着返回前必须把临时修改撤销。

分析思路

让慢指针停在前半段末尾，反转 slow.next，比较长度较短的后半段，记录是否匹配，再反转一次并接回。

解答步骤

可采用 while fast.next and fast.next.next 的中点循环。长度四时 slow停在第二个结点，后半段含第三、四个；长度五时停在第三个，中心结点被留在前半段而不参与比较。统一从 slow.next 开始即可处理奇偶。

先让快指针每次走两步、慢指针每次走一步，快指针到末尾时慢指针位于中点附近。若长度为奇数，中心结点不用参加比较，后半段从其下一结点开始；长度为偶数则直接从后半段第一结点开始。

保存连接前后半段的结点，把后半段原地反转。此时从头结点和反转后半段的头同时向前比较，每次检查两个值，直到后半段结束。例如 1→2→3→2→1 的后半段反转后为 1→2，依次与前两个值比较即可。

即使中途发现不等，也先记录结果，再将后半段反转回去、恢复连接，最后返回真假。找中点、反转、比较和恢复均为线性遍历，总时间 O(n)O(n)O(n)。只维护若干指针，额外空间 O(1)O(1)O(1)。若选择把所有值存入列表再双向比较，时间同样线性，但空间为 O(n)O(n)O(n)，不满足本题的空间要求。

反转循环每次保存 nxt=current.next，再令 current.next=previous，最后同步推进 previous、current，防止丢失剩余链。比较发现不等时只设置结果为假，不能在恢复之前直接返回。空链表和单结点先返回真，避免访问不存在的 next。

同类问题

题目允许临时修改输入但要求恢复时，显式安排“保存连接—修改—计算—恢复”四步，并检查提前退出路径。复杂度应累计遍历次数，常数次线性遍历仍是O(n)。

题目

def largest_white_region(white, edges):
    n = len(white)
    if not n:
        return 0
    parent, size = list(range(n)), [1]*n
    neighbors = [[] for _ in range(n)]
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    def union(a,b):
        a,b = find(a),find(b)
        if a==b: return
        if size[a]<size[b]: a,b=b,a
        parent[b]=a
        size[a]+=size[b]
    for a,b in edges:
        neighbors[a].append(b); neighbors[b].append(a)
        if white[a] and white[b]: union(a,b)
    best = max((size[find(i)] for i in range(n) if white[i]),default=0)
    for i in range(n):
        if not white[i]:
            components={find(j) for j in neighbors[i] if white[j]}
            best=max(best,1+sum(size[j] for j in components))
    return best
