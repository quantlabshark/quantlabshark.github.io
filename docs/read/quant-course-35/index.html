35 · 神经网络、卷积与LSTM

逐步计算一次神经网络更新、局部卷积和记忆状态递推，理解文本序列的形状、嵌入、填充与训练控制。

神经网络由线性变换和非线性激活组成。卷积处理局部结构，循环网络与 LSTM 处理序列状态，不同结构对应不同的数据关系。

两层线性运算为什么还不够

若第一层是xW1\mathbf xW_1xW1​，第二层再乘W2W_2W2​，整体仍为x(W1W2)\mathbf x(W_1W_2)x(W1​W2​)，只是一层线性变换。网络需要激活函数才能表达更丰富关系。ReLU为max⁡(0,z)\max(0,z)max(0,z)，把负值置零；sigmoid为1/(1+e−z)1/(1+e^{-z})1/(1+e−z)，将输出压到0与1之间。

给定x=(1,−1)\mathbf x=(1,-1)x=(1,−1)、W=(10.5−0.51)W=\begin{pmatrix}1&0.5\\-0.5&1\end{pmatrix}W=(1−0.5​0.51​)，先得到z=xW=(1.5,−0.5)\mathbf z=\mathbf xW=(1.5,-0.5)z=xW=(1.5,−0.5)，经ReLU变为h=(1.5,0)\mathbf h=(1.5,0)h=(1.5,0)。再以输出权重(1,−1)(1,-1)(1,−1)计算得到1.5，sigmoid概率约0.8176。

这就是一个很小的多层感知机MLP：全连接层形成组合，激活函数改变表达方式，输出层连接具体目标。

一次参数更新怎样降低损失

二分类交叉熵为L=−[ylog⁡p+(1−y)log⁡(1−p)]L=-[y\log p+(1-y)\log(1-p)]L=−[ylogp+(1−y)log(1−p)]。若标签为1，初始损失为−log⁡(0.8176)≈0.2014-\log(0.8176)\approx0.2014−log(0.8176)≈0.2014。输出分数的梯度为p−y≈−0.1824p-y\approx-0.1824p−y≈−0.1824，说明应提高这个正类样本的分数。

利用链式法则，可以将梯度传回输出权重和第一层权重，再按θnew=θold−η∇L\theta_{new}=\theta_{old}-\eta\nabla Lθnew​=θold​−η∇L更新。学习率η\etaη控制一步走多远；太大可能越过较好区域，太小则进展慢。下面先验证这个具体计算，再计算CNN与LSTM的小例。

Python35 行
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

x = np.array([1.0, -1.0])
W = np.array([[1.0, 0.5], [-0.5, 1.0]])
v = np.array([1.0, -1.0])
z = x @ W
hidden = np.maximum(z, 0)
prob = sigmoid(hidden @ v)
loss_before = -np.log(prob)  # label y=1
error = prob - 1.0
grad_v = hidden * error
grad_W = np.outer(x, (v * error) * (z > 0))
v -= 0.1 * grad_v
W -= 0.1 * grad_W
prob_after = sigmoid(np.maximum(x @ W, 0) @ v)
print("MLP:", prob, prob_after)
assert -np.log(prob_after) < loss_before

sequence = np.array([1.0, 2.0, 0.0, 3.0])
kernel = np.array([1.0, -1.0])
conv = np.array([sequence[i:i+2] @ kernel for i in range(3)])
activated = np.maximum(conv, 0)
print("CNN local values:", conv, "max pooling:", activated.max())
assert np.allclose(conv, [-1.0, 2.0, -3.0])

h, cell = 0.0, 0.0
for value in [1.0, -1.0]:
    forget = input_gate = output_gate = sigmoid(0.0)
    candidate = np.tanh(value + h)
    cell = forget*cell + input_gate*candidate
    h = output_gate*np.tanh(cell)
    print("LSTM state:", cell, h)

第一部分更新后正类概率提高、损失降低，验证梯度方向。这里仅有一个样本，不能用它判断泛化。实际训练按批次重复前向、损失、反向传播和更新，并用未参与更新的验证数据观察是否开始过拟合。

词编号与嵌入不是同一种数值

词编号只是查表索引，编号100不代表编号10的十倍语义。嵌入矩阵为每个词存一个可训练稠密向量。例如词表有5000项、向量维度16，参数矩阵有5000×165000\times165000×16项；一句20词文本会变成20×1620\times1620×16的矩阵。

普通静态嵌入中，同一词始终查得同一向量，语境差异由后续网络处理。可以从当前任务训练嵌入，也可加载预训练向量；后者的领域与词表若不同，仍需检查匹配。

一批文本的形状通常是“样本数×序列长度×嵌入维度”。填充到64个位置，指每句话保留64个位置，不是词表只保留64个词。截断方向影响句首或句尾信息，填充位置需要掩码或正确长度规则。

卷积提取相邻位置的变化

对序列[1,2,0,3][1,2,0,3][1,2,0,3]，使用核[1,−1][1,-1][1,−1]、步长1、不补边界，局部乘加依次为1−2=−11-2=-11−2=−1、2−0=22-0=22−0=2、0−3=−30-3=-30−3=−3。ReLU后为[0,2,0][0,2,0][0,2,0]，全局最大池化取2。

左图显示各滑动位置的原始响应与ReLU结果，负响应被置零；右图显示下文两步LSTM的细胞状态和隐藏状态。图中的每个值都来自程序，而不是抽象的网络装饰。

深度学习中常用不翻转核的互相关计算，仍称卷积层。多个核可以学习不同局部模式，步长决定采样间隔，填充决定边界输出。池化减少位置数，也丢失精确位置信息。沿文本词序列做卷积，需要保留顺序，不能先打乱成词袋再假定顺序仍在。

LSTM怎样保留和更新记忆

普通循环网络把上一状态与当前输入合成新状态，长时间反向传播可能遇到梯度消失。LSTM引入细胞状态ctc_tct​及三个连续门：遗忘ftf_tft​、输入iti_tit​、输出oto_tot​，门由sigmoid给出0到1之间的比例。候选信息gtg_tgt​常由tanh产生。

ct=ft⊙ct−1+it⊙gt,ht=ot⊙tanh⁡(ct).c_t=f_t\odot c_{t-1}+i_t\odot g_t,\qquad h_t=o_t\odot\tanh(c_t).ct​=ft​⊙ct−1​+it​⊙gt​,ht​=ot​⊙tanh(ct​).

⊙\odot⊙表示逐元素相乘，不是向量点积。第一项保留旧信息，第二项加入新信息，输出门决定对外暴露多少状态。门值不是只能取0或1。

代码将三个门固定为0.5以展示计算，初始状态为0。第一输入1产生g1=tanh⁡1g_1=\tanh1g1​=tanh1，c1≈0.3808c_1\approx0.3808c1​≈0.3808、h1≈0.1817h_1\approx0.1817h1​≈0.1817。第二输入−1时，新候选还受h1h_1h1​影响，旧记忆也保留一半。训练 LSTM 时，需要学习各门的权重，沿时间展开反向传播。

鲨鱼说

细胞状态、隐藏状态和输入是三个不同对象。先按一个时间步写清维度与数值，再把同一个更新式沿时间重复，比直接记复杂结构图更容易理解。

Dropout、早停与模型比较

Dropout在训练时随机屏蔽部分激活，并按实现约定缩放；预测时关闭这种随机屏蔽。它降低对少数内部路径的依赖，但不保证消除过拟合。参数惩罚、较小网络和早停也可控制复杂度。

早停依据验证损失选训练轮数，最终测试只评价固定模型。比较MLP、CNN与LSTM时，应统一语料、拆分、词表、序列长度与目标；若CNN只保留16词、MLP保留64词，差异还包括输入信息量。

保存模型时同时保存词表、填充方向、掩码、标签编码和训练日期。仅保存网络权重不能确保之后得到相同输入。文本情绪分类仍需另行验证与未来收益的关系。

练习

卷积结果[−1,2,−3][-1,2,-3][−1,2,−3]经过ReLU与最大池化后是什么？LSTM若遗忘门为1、输入门为0，细胞状态怎样变化？

查看解答

ReLU得到[0,2,0][0,2,0][0,2,0]，最大池化为2。LSTM此时ct=ct−1c_t=c_{t-1}ct​=ct−1​，保留旧细胞状态而不加入新候选；隐藏状态仍受输出门及tanh影响，不必与细胞状态相同。
