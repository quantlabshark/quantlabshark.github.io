1. 四开关识别

题目

房间内有一盏灯，外面有四个开关。只有一个开关每次翻转时会切换灯的亮灭，其余无影响。每轮可同时翻转任意一组开关，并能观察灯相对上一轮是否改变。最少几轮可确定有效开关？

考点：二进制编码；信息下界；观测设计。

查看分析与解答

必要知识

一轮的有效观测只有灯变了或没变两个结果，因此 k 轮最多形成 2ᵏ 条不同记录。给开关编码，就是预先规定它在哪几轮被翻转；有效开关的编码将直接成为观测记录。

分析思路

先数要区分的候选数，得到轮数下界，再给每个候选安排唯一编码。零编码也能使用，因为“两轮都不变”本身是可辨认的结果。

解答步骤

四个候选至少需要四条不同记录，一轮只有两条，故不够。两轮恰有 00、01、10、11 四条记录，只要让每个开关对应一条，就能达到下界。

每轮只观察“改变”或“不改变”，最多提供一个二进制结果。一次只能区分两种候选，四个候选至少需要 ⌈log⁡24⌉=2\lceil\log_2 4\rceil=2⌈log2​4⌉=2 轮。

给开关 A、B、C、D 编码 00、01、10、11。第一轮翻转 C、D，第二轮翻转 B、D。每轮记录灯是否改变，改变记 1、不改变记 0。

两轮结果为 00 则 A 有效，为 01 则 B 有效，为 10 则 C 有效，为 11 则 D 有效。例如 D 有效时，两轮都被翻转，灯每轮都改变，编码为 11，即使最终亮灭状态与初始相同也不影响判断。

方案达到两轮信息下界，因此最少为 2 轮。记录的是每轮相对前一轮的变化，不能只看最后一次灯的状态。

以初始灯亮为例，若有效开关是 D，两轮后依次为灭、亮，记录的是变、变即 11；若只比较末态与初态，会把 D 和完全未翻转的 A 混淆。记录每一步变化是编码成立的条件。

同类问题

多个候选、每次有限种观测的识别题，先用结果数量求下界，再设计编码。若一次可观察三种结果，上界数量变为 3ᵏ，但还需确认每种编码都能通过合法操作实现。

2. 递增抽样停止

题目

独立地从 U[0,1] 抽数。至少抽两次，第一次出现新数小于紧前一个数时停止；总次数 N 包含这次导致停止的抽样。求 E[N]。

考点：排列对称；生存概率；尾和公式。

查看分析与解答

必要知识

整数停止时间 N 可以写成指示变量之和 N=∑k≥01{N>k}N=\sum_{k\ge0}1_{\{N>k\}}N=∑k≥0​1{N>k}​：若 N=3，只有 k=0、1、2 三项为一。逐项取期望便得到尾和公式，避免先求每个停止概率再乘次数。

分析思路

“第 k 次之后还没停止”比“恰好第 k 次停止”简单。它只要求前 k 个数递增，因此可用样本顺序的对称性计算。

解答步骤

例如 N>2 表示第二个数大于第一个，概率为 1/2；N>3 表示前三个顺序递增，六种相对次序只有一种满足，概率为 1/6。N>1 的概率为一，因为题目至少抽两次。

对 k≥1k\ge1k≥1，事件 N>kN>kN>k 表示前 k 个数严格递增，否则已经在前 k 次停止。连续独立同分布样本的 k!k!k! 种相对顺序等可能，只有一种递增，因此 P(N>k)=1/k!P(N>k)=1/k!P(N>k)=1/k!；另外 P(N>0)=1P(N>0)=1P(N>0)=1。

非负整数随机变量的尾和公式给出 E[N]=∑k=0∞P(N>k)=1+∑k=1∞1k!=e.E[N]=\sum_{k=0}^\infty P(N>k)=1+\sum_{k=1}^\infty\frac1{k!}=e.E[N]=k=0∑∞​P(N>k)=1+k=1∑∞​k!1​=e. 也可写出 P(N=n)=1/(n−1)!−1/n!=(n−1)/n!P(N=n)=1/(n-1)!-1/n!=(n-1)/n!P(N=n)=1/(n−1)!−1/n!=(n−1)/n!，其中 n≥2n\ge2n≥2，作为核对。若不把最后一次下降计入次数，结果会少 1，所以题目必须说明计数范围。

对任意连续独立同分布的抽样，样本没有相等值，所有相对次序仍等可能，结果 E[N]=e 都成立，不必局限于均匀分布。若分布含离散原子，相等情况不能忽略，递增与不下降对应不同事件。

同类问题

停止时间求均值时优先检查尾事件是否好算。把 N>k、N≥k 和是否包含触发停止的最后一次区分清楚，能避免常见的一次偏差。

3. 已知红黑数量下注

题目

牌堆含 x 张红牌、y 张黑牌，均匀洗牌后依次翻开并弃掉。初始资金 W₀，每轮可将不超过现有资金的金额押一种颜色。猜中返还两倍下注额（含本金），猜错失去下注额，其余资金保留。求最大期望终值，并构造终值无波动的最优策略。演示 x=2、y=1。

考点：条件概率；资金递推；期望上界。

查看分析与解答

必要知识

若押红的资金比例为 f，翻红后财富为 W(1+f)，翻黑后为 W(1−f)。可用有符号 f 表示押色，f<0 等于押黑。已知剩余 r 红 b 黑，红的条件概率是 r/(r+b)，随翻牌更新。

分析思路

先寻找能使每条合法牌序得到相同终值的资金比例，再另外证明没有策略能提高平均终值。保证收益的构造与期望最优的证明是两步，不能相互替代。

解答步骤

令 f=(r−b)/(r+b)，则 1+f=2r/(r+b)、1−f=2b/(r+b)。这解释了比例公式来自何处：每步财富乘数等于该颜色条件概率的两倍。相乘后，合法牌序的概率都为 1/C(x+y,x)，因此财富也都相同。

剩余 r 红、b 黑时，押多数颜色，下注比例为 ∣r−b∣/(r+b)|r-b|/(r+b)∣r−b∣/(r+b)；数量相同时不下注。无论哪种颜色占多数，下一张红牌使资金变成 W 2r/(r+b)W\,2r/(r+b)W2r/(r+b)，黑牌使资金变成 W 2b/(r+b)W\,2b/(r+b)W2b/(r+b)。

沿任意合法牌序相乘，红牌分子依次包含 x,x−1,…,1x,x-1,\ldots,1x,x−1,…,1，黑牌包含 y,y−1,…,1y,y-1,\ldots,1y,y−1,…,1，分母为 (x+y)!(x+y)!(x+y)!，所以最终资金恒为 WT=W02x+yx!y!(x+y)!=W02x+y(x+yx).W_T=W_0\frac{2^{x+y}x!y!}{(x+y)!}=W_0\frac{2^{x+y}}{\binom{x+y}{x}}.WT​=W0​(x+y)!2x+yx!y!​=W0​(xx+y​)2x+y​. 每条牌序的终值相同，终值方差为零。x=2、y=1、W₀=1 时先押红三分之一；若先红，资金为 4/3，下一轮红黑相等不押，最后已知颜色全押，得 8/3；若先黑，资金为 2/3，剩余两张必红，连续加倍也得 8/3。

证明期望最优时，将策略放在所有 2x+y2^{x+y}2x+y 条独立公平红黑序列上考察，并在不可能符合剩余组成的路径上定义为不再下注。公平赔率下，非负自融资策略的无条件期望终值为 W₀。合法牌序有 (x+yx)\binom{x+y}{x}(xx+y​) 条，因此这些路径上的条件平均不能超过上述终值。该策略达到上界，也达到最大保证终值。

一直全押某一合法牌序也可达到相同期望，但大多数路径资金归零；比例策略在终值风险方面更优，中途资金仍随牌序变化。

以三张牌为例，合法序列 RRB、RBR、BRR 各概率三分之一，终值均 8/3。若反而假设三个颜色独立公平，共有八条等可能序列。任何不借款的公平下注策略在八条路径的平均终值为一；合法三条路径的非负财富总和至多八，所以其平均不超过 8/3。这一论证推广到任意 x、y，给出期望上界。

同类问题

牌堆组成已知时，应使用随剩余数量更新的条件概率。构造确定终值可尝试让路径乘积消去顺序；证明最优则寻找适用所有策略的守恒量或期望上界。

4. 十五分钟来车

题目

车辆到达服从齐次泊松过程，各不相交时间段的到达数独立。一小时至少来一辆车的概率为 0.8，求任意十五分钟内至少一辆的概率。

考点：泊松参数；补事件；时间单位。

查看分析与解答

必要知识

速率 λ 的单位是每小时车辆数，长 t 小时的计数均值为 λt。泊松计数为零的概率 e^(−λt) 随时长呈指数变化，至少一辆的概率是它的补集。

分析思路

先将“一小时至少一辆”变成零辆概率，再缩放时间参数。也可把一小时分成四个独立同分布的十五分钟区间，利用零辆事件相乘。

解答步骤

设十五分钟无车概率为 q，四段都无车才等于一小时无车，因此 q⁴=0.2，q=0.2^(1/4)。这种方法不必先算出 λ，也直接体现了独立平稳增量。

设每小时速率为 λ\lambdaλ，一小时没有车辆的概率为 e−λ=1−0.8=0.2e^{-\lambda}=1-0.8=0.2e−λ=1−0.8=0.2，所以 λ=−log⁡0.2\lambda=-\log0.2λ=−log0.2。

十五分钟是四分之一小时，车辆数参数为 λ/4\lambda/4λ/4，无车概率为 e−λ/4=0.21/4e^{-\lambda/4}=0.2^{1/4}e−λ/4=0.21/4。故至少一辆的概率为 1−0.21/4≈0.331260.1-0.2^{1/4}\approx0.331260.1−0.21/4≈0.331260. 不能直接将 0.8 除以 4，因为“至少一辆”概率不是期望到达数。四个十五分钟均无车的概率才相乘为 0.20.20.2，与计算结果一致。

由 λ=−log0.2≈1.60944，可算十五分钟平均车辆数约 0.40236，但至少一辆概率约 0.33126。二者不同，因为出现两辆、三辆等情况会增加均值，却在“至少一辆”事件里都只算一次。

同类问题

到达问题先区分期望计数与事件概率。时间分段可直接相加的是期望计数，相互独立的零事件概率则相乘。

5. 第一张A

题目

52 张牌中有 4 张 A，均匀洗牌后不放回逐张翻开。设 N 包含第一次翻到 A 的那一张，求 E[N]。

考点：随机间隙；不放回抽样；位置期望。

查看分析与解答

必要知识

把目标牌看成分隔符，第一次目标出现的位置等于它前面的非目标牌数加一。间隙可为零，例如第一张就是 A。对称性允许在不求完整分布的情况下计算每个间隙的均值。

分析思路

将四张 A 形成的五段非 A 牌数记为 G₀ 至 G₄。先说明这些间隙分布对称，再利用总数恒为四十八求均值。

解答步骤

每一种非负整数间隙组合 G₀+…+G₄=48 唯一对应四个 A 的位置，而四个位置组合在均匀洗牌下等可能。交换任意两个间隙仍得到等可能组合，因此五个 G 的期望相同。

把 4 张 A 暂时固定为分隔符，其他 48 张牌分布在第一张 A 前、相邻 A 之间和最后一张 A 后，共 5 个间隙。均匀洗牌下，这 5 个间隙在期望上对称，非 A 总数又为 48，因此每个间隙期望为 48/548/548/5。

第一次 A 前平均有 48/548/548/5 张非 A，再加上 A 自身，得到 E[N]=485+1=535=10.6.E[N]=\frac{48}{5}+1=\frac{53}{5}=10.6.E[N]=548​+1=553​=10.6. 不能按每次成功概率固定为 4/524/524/52 使用几何分布：不放回抽到非 A 后，剩余牌中 A 的比例上升。一般 n 张牌含 m 张目标牌时，同理得到第一目标位置期望 (n+1)/(m+1)(n+1)/(m+1)(n+1)/(m+1)。

极端情形可检查一般公式：若全部牌都是目标，(n+1)/(n+1)=1；若只有一个目标，其位置在 1 至 n 均匀，期望为 (n+1)/2。两者都与间隙公式一致。

同类问题

随机排列中求第几个目标的位置，间隙对称常比逐步计算失败概率简单。第 k 个目标前包含 k 个间隙和 k 张目标，其期望位置为 k(n+1)/(m+1)。

6. 双向回归

题目

同一组样本中 X、Y 的方差均非零。分别作含截距最小二乘回归 y=ax+by=ax+by=ax+b、x=cy+dx=cy+dx=cy+d，求乘积 acacac 的范围，并解释负相关和完全相关时的结果。

考点：中心化回归；斜率单位；相关平方。

查看分析与解答

必要知识

含截距回归会使拟合直线经过样本均值。令 x_i−均值和 y_i−均值分别中心化，最小二乘斜率就是交叉和除以自变量平方和。正向斜率的单位是 Y/X，反向为 X/Y，因此乘积无量纲。

分析思路

分别从两次回归的正规方程写斜率，再相乘。分子是同一交叉和的平方，分母恰好组成相关系数的归一化项。

解答步骤

正向最小化 Σ(y_i−均值_y−a(x_i−均值_x))²，对 a 求导并令零，得到 aS_xx=S_xy。反向只需交换 x、y，得到 cS_yy=S_xy。无需把正向方程强行反解。

令中心化平方和为 Sxx,SyyS_{xx},S_{yy}Sxx​,Syy​、交叉和为 SxyS_{xy}Sxy​。含截距 OLS 的斜率分别为 a=Sxy/Sxxa=S_{xy}/S_{xx}a=Sxy​/Sxx​、c=Sxy/Syyc=S_{xy}/S_{yy}c=Sxy​/Syy​，所以 ac=Sxy2SxxSyy=rXY2.ac=\frac{S_{xy}^2}{S_{xx}S_{yy}}=r_{XY}^2.ac=Sxx​Syy​Sxy2​​=rXY2​. 相关系数在 [−1,1][-1,1][−1,1] 内，因此 ac∈[0,1]ac\in[0,1]ac∈[0,1]。若负相关，两斜率都为负，乘积仍非负；若不相关，则两斜率都为零。

完全正或负线性关系下 ∣r∣=1|r|=1∣r∣=1，两个方向都无残差，斜率互为倒数，所以乘积为 1。一般有残差时，回归 y 对 x 与回归 x 对 y 最小化的垂直误差方向不同，不能把一个斜率简单取倒数当成另一个。

例如 r=−0.6、样本标准差 s_x=2、s_y=5，则 a=rs_y/s_x=−1.5，c=rs_x/s_y=−0.24，乘积 0.36=r²，而 1/a≈−0.667 并不是反向回归斜率。

同类问题

涉及回归与相关的关系时，先确认是否含截距、样本是否相同及变量是否非退化。交换因变量会改变最小化的误差方向，一般不能用代数倒数替代重新拟合。

7. 相关系数边界

题目

三个非退化随机变量 X、Y、Z：先求两两相关都为 r 时的范围；再给定 Corr⁡(X,Y)=a\operatorname{Corr}(X,Y)=aCorr(X,Y)=a、Corr⁡(Y,Z)=b\operatorname{Corr}(Y,Z)=bCorr(Y,Z)=b，求 c=Corr⁡(X,Z)c=\operatorname{Corr}(X,Z)c=Corr(X,Z) 的范围并说明边界可达。

考点：共同因子；残差方差；相关可行域。

查看分析与解答

必要知识

标准化变量方差为一。将 X 中与 Y 线性相关的部分写成 aY，余下残差 X−aY 与 Y 不相关，方差为 1−a²。同样，Z 的残差方差为 1−b²。

分析思路

把 X、Z 的协方差分为共同 Y 带来的 ab 和两个残差的协方差，再用柯西不等式限制后一项。这样可以理解边界，而不只是展开行列式。

解答步骤

先将 X、Y、Z 分别减均值并除以自身标准差，后文沿用同一字母。记 ε=X−aY、η=Z−bY，则 c=Cov(X,Z)=ab+Cov(ε,η)。由于 |Cov(ε,η)|≤√[Var(ε)Var(η)]，立即得到 c 的上下界。边界对应两个残差完全同向或反向。

等相关矩阵的特征值为 1+2r1+2r1+2r 与两个 1−r1-r1−r，非负条件给出 −1/2≤r≤1-1/2\le r\le1−1/2≤r≤1。

一般情况下，将三变量标准化，相关矩阵行列式为 1+2abc−a2−b2−c21+2abc-a^2-b^2-c^21+2abc−a2−b2−c2。要求非负，整理得 (c−ab)2≤(1−a2)(1−b2), (c-ab)^2\le(1-a^2)(1-b^2),(c−ab)2≤(1−a2)(1−b2), 所以 ab−(1−a2)(1−b2)≤c≤ab+(1−a2)(1−b2).ab-\sqrt{(1-a^2)(1-b^2)}\le c\le ab+\sqrt{(1-a^2)(1-b^2)}.ab−(1−a2)(1−b2)​≤c≤ab+(1−a2)(1−b2)​.

为说明范围可达，取相互独立的标准变量 Y、U、V，令 X=aY+1−a2UX=aY+\sqrt{1-a^2}UX=aY+1−a2​U，Z=bY+1−b2(ρU+1−ρ2V)Z=bY+\sqrt{1-b^2}(\rho U+\sqrt{1-\rho^2}V)Z=bY+1−b2​(ρU+1−ρ2​V)。于是 c=ab+ρ(1−a2)(1−b2)c=ab+\rho\sqrt{(1-a^2)(1-b^2)}c=ab+ρ(1−a2)(1−b2)​。让 ρ\rhoρ 在 [−1,1][-1,1][−1,1] 变化即可覆盖上述区间；两端对应残差同向或反向。

例如 a=b=0.8 时 c 在 [0.28,1] 内，而不是可以任意取 [-1,1]。

当 a=b=0.8，共同部分贡献 0.64，两个残差标准差均 0.6，残差协方差最少 −0.36，故总相关最低 0.28。若 a=1，X 与 Y 标准化后相同，残差为零，范围收缩成单点 c=b，公式也自动涵盖这种退化边界。

同类问题

多个相关约束可以通过“共同部分加残差”理解。求出的区间还需给出合法变量构造，才能确认是全部可取范围，而非仅一个必要条件。

8. 证券代码正则

题目

从字符串列表 600036.SH、522663.SH、159996.SZ、500001.SZ、300005.SZ、51205.HK、510559.SZ、151665.SZ 中，筛选数字部分恰为六位、以 51 开头、后缀为 .SZ 的字符串。写出正则表达式。只校验格式，不判断证券是否实际存在。

考点：格式匹配；字符类；全串约束。

查看分析与解答

必要知识

正则中的点号默认匹配任意普通字符，若要匹配证券代码里的小数点形状字符，必须转义。字符类 [0-9] 限定 ASCII 数字，数量标记 {4} 只作用于它紧前面的字符类。

分析思路

把要求拆成固定前缀、剩余位数和固定后缀三个部分，再加全串匹配约束，逐个排除相似但不合格的字符串。

解答步骤

六位数字已经由前缀 51 占两位，所以后面补四位，而不是六位。若写成 51[0-9]{6}，会错误要求八位数字；若漏掉点号转义，510559XSZ 也可能通过。

表达式为 ^51[0-9]{4}\.SZ$。其中 51 固定前两位，[0-9]{4} 再匹配四位数字，合计六位；\. 匹配字面点号，SZ 固定后缀，首尾锚点限制整个字符串。

给定列表中只有 510559.SZ 匹配。51205.HK 的数字长度与后缀均不符；151665.SZ 虽是六位且后缀正确，但没有以 51 开头。

Python 中也可使用 re.fullmatch(r"51[0-9]{4}\.SZ", value)，由 fullmatch 保证全串匹配。格式筛选与代码在交易所是否存在属于不同检查，后者需要证券主表。

Python 的 $ 可匹配结尾换行之前，因此对要求严格全串的输入，优先使用给出的 re.fullmatch。若原始数据允许行尾换行，应先按数据规范清理，再匹配，不能让模糊边界掩盖数据质量问题。

同类问题

写筛选规则时分别测试正确样本、错误前缀、位数不足、错误后缀和多余字符。正则只负责语法，代码是否上市、是否退市需另查业务数据。

9. 有限次交换的最大拼接数

题目

给定 1 至 n 的一个排列，最多允许 k 次交换任意两个元素，将元素十进制表示依次拼接，求最大结果。演示 [1,3,2,4]、k=1，并说明 n≤9 与 n≥10 时的区别。给出适用于小 n、小 k 的精确算法。

考点：交换预算；字典序；精确搜索。

查看分析与解答

必要知识

拼接结果各候选总位数相同，所以可以按字符串字典序比较。但元素本身可能有不同位数：数值更大不代表放在前面更有利。最多 k 次还允许零次、一次等提前停止。

分析思路

先区分单数字元素的贪心情形与变长元素情形。对后者以排列和剩余预算为状态，枚举每一种下一次交换，把“不再交换”的当前结果也纳入候选。

解答步骤

n≤9 时，最左边第一个不同数字决定大小。若当前位置不是剩余最大数字，最优结果必须花一次交换把唯一最大数字移来，再处理后缀。n≥10 时，9 与 10 的例子说明按元素数值降序已失效，需要比较拼接影响。

例子交换首尾得到 [4,3,2,1]，拼接为 4321。n≤9 时每个元素一位，首个不同位置决定大小；从左到右把剩余最大值交换到当前位置，每个错位消耗一次预算，即可贪心求解。

n≥10 时不能按数字大小降序：9 在 10 前得到 910，大于反过来的 109。无限交换时可按 ab 与 ba 的大小排序，但在有限交换预算下，不能直接把这个排序目标逐位强行换入。

小规模精确解搜索所有不超过 k 次交换可达的排列，并对“排列、剩余次数”记忆化。所有候选的总数字长度相同，因此拼接字符串的字典序与整数大小一致。

Python19 行
from functools import lru_cache

def largest_join(values, k):
    @lru_cache(None)
    def solve(state, budget):
        best = ''.join(map(str, state))  # 允许少于 k 次
        if budget == 0:
            return best
        for i in range(len(state)):
            for j in range(i+1, len(state)):
                nxt = list(state)
                nxt[i], nxt[j] = nxt[j], nxt[i]
                best = max(best, solve(tuple(nxt), budget-1))
        return best
    return solve(tuple(values), k)

assert largest_join([1, 3, 2, 4], 1) == '4321'
assert largest_join([10, 9], 1) == '910'
assert largest_join([1, 2, 3], 0) == '123'

忽略记忆化收益，搜索分支数约为 O((n2)k)O((n^2)^k)O((n2)k)；每次复制与拼接需 O(D)O(D)O(D)，D 为总数字长度，因此仅适合小规模。记忆化避免反复搜索同一状态，但不会将一般情况变为线性算法。

搜索的完整性可按预算归纳：预算零只有原状态；预算正时，任何合法方案要么直接停止，要么先交换某一对，再执行预算少一的合法方案。代码枚举了所有这两类，故不会遗漏最优解。缓存键还要包含预算，因为同一排列允许多一次交换可能得到更优结果。

同类问题

贪心需要证明局部选择不会妨碍后续最优结果。规模较小时，可先建立枚举或记忆化精确解，用它检验贪心猜想并寻找反例。

10. 最长公共子序列

题目

允许从字符串删除任意字符但不改变剩余字符顺序，求两个字符串的最长公共子序列长度。以 ABCDE 和 FBDAN 为例，说明递推、边界、复杂度及如何恢复一个序列。

考点：子序列；前缀状态；动态规划回溯。

查看分析与解答

必要知识

子串必须连续，子序列只保留相对顺序。动态规划把原问题缩小为两个前缀间的同类问题，D_i,j 的两个下标分别表示已允许使用的字符数量，不是字符本身的下标。

分析思路

观察两个前缀的最后字符。相同则可共同接上；不同则不可能同时作为同一公共序列的末字符，至少舍弃一边。由较短前缀推向较长前缀。

解答步骤

例中 A 前缀为 AB、B 前缀为 FB 时，末字符均 B，较短前缀 A、F 的值为零，因此 D₂,₂=1。到 ABCD 与 FBD 时，末字符 D 相同，前缀 ABC、FB 已有 B，因此值变为二，对应 BD。

子序列不要求连续，故 BD 是两个字符串的公共子序列。设 Di,jD_{i,j}Di,j​ 为 A 前 i 个字符与 B 前 j 个字符的最长公共子序列长度，空串边界为 D0,j=Di,0=0D_{0,j}=D_{i,0}=0D0,j​=Di,0​=0。

若末字符相同，可把该字符接在两个较短前缀的公共子序列后，得到 Di,j=Di−1,j−1+1D_{i,j}=D_{i-1,j-1}+1Di,j​=Di−1,j−1​+1；否则至少舍弃一个末字符，取 max⁡(Di−1,j,Di,j−1)\max(D_{i-1,j},D_{i,j-1})max(Di−1,j​,Di,j−1​)。

Python15 行
def lcs_length(a, b):
    if len(a) < len(b):
        a, b = b, a
    previous = [0] * (len(b)+1)
    for ca in a:
        current = [0]
        for j, cb in enumerate(b, 1):
            current.append(previous[j-1]+1 if ca == cb
                           else max(previous[j], current[j-1]))
        previous = current
    return previous[-1]

assert lcs_length('ABCDE', 'FBDAN') == 2
assert lcs_length('', 'ABC') == 0
assert lcs_length('AAAA', 'AA') == 2

时间为 O(mn)O(mn)O(mn)；代码只保留相邻两行，空间为 O(min⁡(m,n))O(\min(m,n))O(min(m,n))。若需要恢复序列，可保存整张表，从右下角回溯：相同字符进入答案并向左上走，否则向值较大的上方或左方走，最后逆序；例中可恢复 BD。

相同末字符 c 时，设一个最优公共子序列为 S。若 S 不以 c 结尾，则两边用于 S 的位置都早于末位，可在其后再接 c，与最优性矛盾；所以 S 以 c 结尾。把 S 最后那个 c 的匹配位置改到两边末位，仍不影响此前顺序。删除这个末尾字符，剩余长度不能超过 D[i−1,j−1]，与可追加 c 的下界合起来就证明了递推。不同末字符时两条分支分别覆盖舍弃 A 末字符、舍弃 B 末字符的可能。压缩两行后值仍能求出，但丢失回溯路径，因此恢复序列需要整表或专门的分治回溯算法。

同类问题

序列动态规划先定义前缀状态，再用末元素分类。边界空串、重复字符和完全无共同字符应手算核验，长度计算与方案恢复是两个不同输出要求。
