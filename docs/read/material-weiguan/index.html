贪心算法、矩阵赋值与条件分布

1. 双方估值不同的取石子游戏

题目

有 nnn 枚石子，Alice 和 Bob 对第 iii 枚的价值分别为非负数 ai,bia_i,b_iai​,bi​。Alice 先手，双方轮流取一枚，直到取完，各自按自己的估值累计总分。双方以最大化自己的最终分差为目标。求最优策略下 Alice 胜、平、负的判断方法。

考点：价值合并；零和转化；贪心归纳。

查看分析与解答

必要知识

取一枚石子既增加自己的分数，也使对手不能再取它。最终每枚都被一方取走，因此Alice的分差可写成Σ_{Alice}(a_i+b_i)−Σ全部b_i，第二项固定，真正争夺的是合并价值c_i=a_i+b_i。

鲨鱼说

拿走一枚石子有两项效果：自己得到分数，对手失去得到它的机会。因此优先级看双方估值之和，最终胜负仍按各自实际得分计算。

分析思路

先把不同估值转成双方共同争夺c_i的零和取数游戏，再证明总取当前最大c是最优，最后回到各自实际得分计算胜负。

解答步骤

设当前玩家在共同价值游戏中的最优分差为G(S)，则G(S)=max_{j∈S}[c_j−G(S\{j})]。按归纳假设，剩余降序c的最优分差是交替和。对降序c₁≥c₂≥…，选择第j项而非第一项会使当前可得分差减少2Σ_{l=1}^{⌊j/2⌋}(c_{2l−1}−c_{2l})，每项非负，所以取第一项最优。

取走石子 i 对 Alice 相对 Bob 的分差有双重影响：她得到 aia_iai​，同时阻止 Bob 得到 bib_ibi​，因此比较量为 ai+bia_i+b_iai​+bi​。将石子按这个和降序排序，双方依次取当前最大者。

看相邻的两步：如果 Alice 先取 i、Bob 后取 j，这两步对 Alice 的分差贡献为 ai−bja_i-b_jai​−bj​。交换为 Alice 取 j、Bob 取 i，则为 aj−bia_j-b_iaj​−bi​。两者之差为 (ai+bi)−(aj+bj)(a_i+b_i)-(a_j+b_j)(ai​+bi​)−(aj​+bj​)。所以总估值较大者放在先手位置，不会降低先手的分差。

对 Bob 的回合同理。由交换与逆向归纳，可支持双方按该优先级取子。

排序后偶数下标（从零开始）贡献 aia_iai​，奇数下标贡献 −bi-b_i−bi​，求和的正、零、负分别表示 Alice 胜、平、负。例如 a=[1,3],b=[2,1]a=[1,3],b=[2,1]a=[1,3],b=[2,1]，总估值为 3、4，Alice 取第二枚得 3，Bob 取第一枚得 2，Alice 胜。排序 O(nlog⁡n)O(n\log n)O(nlogn)，扫描 O(n)O(n)O(n)。

Python6 行
def stone_game(a,b):
    if len(a)!=len(b): raise ValueError('长度不一致')
    order=sorted(range(len(a)),key=lambda i:a[i]+b[i],reverse=True)
    diff=sum(a[i] if t%2==0 else -b[i] for t,i in enumerate(order))
    return (diff>0)-(diff<0)
assert stone_game([1,3],[2,1])==1

这补齐了只交换相邻两步未覆盖全部后续策略的问题。合并价值并列时，上述损失为零，任一并列顺序可用。最后仍按Alice取到的a加分、Bob取到的b减分，不能把共同价值交替和直接当原分差。

同类问题

交替选物且双方估值不同，可尝试把最终差改写成选中物品的共同价值加常数。贪心证明需覆盖完整剩余博弈，而不仅比较两步局部收益。

2. 行列覆盖后的矩阵元素之和

题目

初始 n×nn\times nn×n 矩阵全为零，依次接收操作 [type,index,value]：type=0 将一整行赋为 value，type=1 将一整列赋为 value，索引从 0 开始。后来的赋值覆盖以前的值。求最终矩阵所有元素之和，要求避免构造整个矩阵。

考点：最后写入；逆序扫描；互斥计数。

查看分析与解答

必要知识

一个格子先后会被所在行和所在列操作覆盖，最终只认时间最晚的一次。逆序处理让第一次遇到的有效赋值就是最终值，不必模拟每一次覆盖。

分析思路

保存逆序已经确定的行列集合。新行只计算未被更晚列覆盖的格子，新列对称；重复行或列整条跳过。

解答步骤

2×2例子最终矩阵为[[3,5],[0,5]]。逆序列1先决定两个5，行0随后只决定列0的3，剩余格没有操作保持零。每个格只在决定最终值的那次操作中计入，故没有重计。

每个格子最终值由作用于它的最后一次行或列赋值决定。逆序扫描操作，已见过的行、列代表更晚操作已经确定的位置。

第一次逆序遇到行 r 时，其中被已见列覆盖的位置不能再计入，剩下 n−∣C∣n-|C|n−∣C∣ 个格子均由当前行赋值决定，贡献为 v(n−∣C∣)v(n-|C|)v(n−∣C∣)，再将 r 加入已见行集合。再次遇到同一行则跳过。列操作对称，贡献为 v(n−∣R∣)v(n-|R|)v(n−∣R∣)。

例如 n=2n=2n=2，先给第 0 行赋 3，再给第 1 列赋 5。逆序先计入整列 5×2=105\times2=105×2=10，再给第 0 行尚未确定的一个位置计入 3，总和 13。无操作的格子保持零，无需单独处理。

共有 q 个操作时，每个操作只做集合查询和常数次运算，平均时间 O(q)O(q)O(q)、空间 O(min⁡(q,n))O(\min(q,n))O(min(q,n))，不需要 O(n2)O(n^2)O(n2) 的矩阵。

Python11 行
def matrix_sum(n,queries):
    rows,cols=set(),set(); total=0
    for typ,idx,value in reversed(queries):
        if not 0<=idx<n: raise ValueError('索引越界')
        if typ==0 and idx not in rows:
            total+=value*(n-len(cols)); rows.add(idx)
        elif typ==1 and idx not in cols:
            total+=value*(n-len(rows)); cols.add(idx)
        elif typ not in (0,1): raise ValueError('未知操作')
    return total
assert matrix_sum(2,[(0,0,3),(1,1,5)])==13

即使赋值为零或负数也必须把行列加入已见集合，因为覆盖与数值大小无关。若同一行前后赋3与7，逆序先看到7，后续3全部失效。集合最多各n个标识，空间不随矩阵格数n²增长。

同类问题

覆盖型操作可考虑倒序，把“撤销旧效果”改成“只登记尚未确定部分”。证明每个元素恰被最后一次操作计入，是这种方法的核心。

4. 均匀分布的贝叶斯更新

题目

未知参数 aaa 的先验为 U(10,20)U(10,20)U(10,20)，给定 a 时观测 X∣a∼U(a−0.5,a+0.5)X\mid a\sim U(a-0.5,a+0.5)X∣a∼U(a−0.5,a+0.5)。观察到 X=12X=12X=12，求 a 的后验密度、均值和方差。进一步说明观测值接近先验端点时如何处理。

考点：密度条件化；支持交集；截断归一。

查看分析与解答

必要知识

连续观测恰等于12的概率为零，但可以使用条件密度作贝叶斯更新。给定参数a，长度一的均匀观测区间内密度恒一，所以数据只负责排除不能产生该观测的参数值。

分析思路

由|x−a|≤0.5求似然支持，再与先验[10,20]相交。在交集上密度仍为常数，按其长度重新归一化。

解答步骤

5. 研究经历追问

题目

选取自己实际参与的一项量化或数据研究，说明研究问题、数据和标签、基准方法、主要结果及本人工作。面试官若追问信息泄漏、失败实验和结果稳定性，应怎样组织回答？

考点：研究叙述；时序证据；个人贡献。

查看分析与解答

必要知识

研究经历回答需要让听者复原研究对象、方法与结论。指标改善只有在数据可得时间、对照方法和评价样本明确时才有可解释性。本人贡献则应对应可核验的具体工作。

分析思路

按问题、数据标签、基准、改动、结果、局限与下一步组织。追问时回到对应实验或数据处理决策，用实际记录说明，而不是补一个未做过的成功故事。

解答步骤

可先画时间线：t日收盘后形成特征，t+1按约定价格成交，持有到标签结束。随后解释训练、验证、测试日期，以及为何边界处要删除跨段标签。若没有交易回测，就报告预测误差或相关结果，不把它改称策略收益。

先用一句话说明输入、预测对象和使用场景，例如“用日终可得的成交特征预测下一交易日横截面收益”。随后给出数据区间、资产范围、标签计算、训练验证测试切分，并画出特征产生、预测、成交、标签结束的时间顺序。

结果先与明确基准比较：可用零预测、持久性预测、简单线性模型或同风险预算组合。报告样本数、评价指标和时间分段结果，再解释加入某特征后改变了多少。若研究涉及交易，说明成本与成交价格，使预测指标和策略损益可对应。

对失败实验选择一个具体例子，说明最初假设、观察到的现象、排查方式与后续处理。例如随机划分优于时间划分，可能提示同一事件或相邻标签跨越了集合边界。应展示调整切分后的结果。个人贡献则说明自己负责的数据、代码或分析环节，避免把团队结果全部归到本人。

失败实验可以讲“增加某类变量后训练误差下降，但验证误差上升”，继而展示按时间分段、剔除异常或检查泄漏后的实际结果。本人工作可具体到字段对齐、特征实现、评价设计或复现实验，并说明与团队其他环节怎样连接。没有留存的数字可说明未记录，不能编造补齐。
