54 · 波动率预测与状态变化

区分事前方差预测与事后测度，解释Realized GARCH反馈、评分及状态过滤。

波动率预测使用过去收益及日内变化估计后续风险。状态模型和已实现指标提供不同信息，建模时需要区分当期观测与此前形成的预测。

已发生的波动与未来风险

一天上午涨2%、下午回到开盘附近，收盘收益约零，盘中却并不平静。日收益平方只保留终点差，高频收益平方和可以补充日内变化信息。预测时需要同时记住两种时间：hth_tht​ 是第 ttt 天开始前的方差预测，xtx_txt​ 是第 ttt 天结束后计算的已实现测度。

若今天开盘决定仓位，就只能用昨天及更早的 xxx。今天收盘才知道的 xtx_txt​ 可更新明天的 ht+1h_{t+1}ht+1​。这条时序比模型名字更直接地决定回测是否用了未来信息。

从GARCH到测量方程

GARCH(1,1)把收益写成 rt=htztr_t=\sqrt{h_t}z_trt​=ht​​zt​，其中标准化冲击 ztz_tzt​ 均值0、方差1；再令 ht=ω+αrt−12+βht−1h_t=\omega+\alpha r_{t-1}^2+\beta h_{t-1}ht​=ω+αrt−12​+βht−1​。新增项 γxt−1\gamma x_{t-1}γxt−1​ 可形成GARCH-X，让过去高频测度参与预测。

Realized GARCH进一步解释测度自身如何产生：

log⁡ht=ω+βlog⁡ht−1+γlog⁡xt−1,\log h_t=\omega+\beta\log h_{t-1}+\gamma\log x_{t-1},loght​=ω+βloght−1​+γlogxt−1​, log⁡xt=ξ+ϕlog⁡ht+τ1zt+τ2(zt2−1)+ut.\log x_t=\xi+\phi\log h_t+\tau_1z_t+\tau_2(z_t^2-1)+u_t.logxt​=ξ+ϕloght​+τ1​zt​+τ2​(zt2​−1)+ut​.

第一行是预测更新，第二行是测量关系。utu_tut​ 代表已实现测度相对潜在方差的测量误差。τ1\tau_1τ1​ 区分正负冲击，τ2\tau_2τ2​ 反映冲击大小。标准化后两项期望均为零。对数形式让指数化后的方差为正，但零值或负的去偏测度不能直接取对数，需要事先选定适用的正测度与处理办法。

持续性为何不只等于beta

将昨天的测量方程代入今天预测，可得 log⁡ht\log h_tloght​ 的滞后系数为 β+γϕ\beta+\gamma\phiβ+γϕ。因为昨天方差会影响昨天测度，后者又反馈到今天，这条间接路径也延续了冲击。

当 β=0.7,γ=0.2,ϕ=1\beta=0.7,\gamma=0.2,\phi=1β=0.7,γ=0.2,ϕ=1，持续性为0.9；若冲击均值为零且绝对系数小于1，长期平均对数方差为

E(log⁡h)=ω+γξ1−β−γϕ.E(\log h)=\frac{\omega+\gamma\xi}{1-\beta-\gamma\phi}.E(logh)=1−β−γϕω+γξ​.

指数化这个平均得到几何尺度，不一般等于 E(h)E(h)E(h)。例如 hhh 一半为1、一半为9，算术均值5，而指数化平均对数得到3。不能在波动预测中忽略这种非线性差别。

逐日检查信息进入模型的时点

自拟测度依次为0.0001、0.00012、0.00015、0.0009、0.0007、0.0003。初始预测0.0001，对应日标准差1%。下面固定参数，只计算预测递推。

Python13 行
import numpy as np
x = np.array([0.0001, 0.00012, 0.00015, 0.0009, 0.0007, 0.0003])
beta, gamma = 0.7, 0.2
long_run = 0.0001
omega = (1-beta-gamma)*np.log(long_run)
h = np.empty(len(x)+1)
h[0] = long_run
for t in range(len(x)):
    h[t+1] = np.exp(omega + beta*np.log(h[t]) + gamma*np.log(x[t]))
for t in range(len(x)):
    print('日',t+1,'当日事前预测',round(h[t],7),'收盘测度',x[t],
          '下一日预测',round(h[t+1],7))
assert h[4] > h[3]

第4天开始前预测约0.0001113，收盘才观察到0.0009。第5天预测因此提高到0.0001672，而不是第4天提前变高。第5天测度仍高，使第6天预测进一步升至0.0002115。图中预测相对测度的滞后是信息约束的结果，不是应当通过向前移动曲线修正的绘图误差。

把第5天方差预测开平方，得到日波动约1.293%。若用波动倒数配置风险，原来1%时的仓位为1，新的比例约 1/1.293=0.7731/1.293=0.7731/1.293=0.773。模型给方差，仓位公式若使用波动，需要先开平方。

评价的目标应是同一种风险

均方误差比较 (xt−ht)2(x_t-h_t)^2(xt​−ht​)2；QLIKE可写为 log⁡ht+xt/ht\log h_t+x_t/h_tloght​+xt​/ht​。给定过去，对其条件期望求导得 1/h−E(x)/h2=01/h-E(x)/h^2=01/h−E(x)/h2=0，最优预测为 h=E(x∣过去信息)h=E(x\mid\text{过去信息})h=E(x∣过去信息)。因此它奖励条件平均方差测度，不是条件平均标准差。

不同模型使用同一测试期、同一目标测度才可比较。盘中连续方差、含跳跃二次变差、含隔夜的全天风险是不同目标。若每分钟更新全日风险，应拆为“已发生的累计变差＋剩余时段的预测”，避免把已发生部分重复预测。

鲨鱼说

条件期望，即给定已有信息后，对可能结果按条件概率求平均。

隐藏状态的实时过滤

另一种模型假设市场有低波动L与高波动H，但看不到状态本身。转移矩阵 Pij=P(St=j∣St−1=i)P_{ij}=P(S_t=j\mid S_{t-1}=i)Pij​=P(St​=j∣St−1​=i) 表达状态持续性。若昨日过滤概率为列向量 pt−1p_{t-1}pt−1​，今日事前概率 pt−=P⊤pt−1p_t^-=P^\top p_{t-1}pt−​=P⊤pt−1​；看到今日收益后，按两种状态的收益密度加权并归一化。

例如事前L、H各0.5，同一收益在L下密度2、H下密度6，未归一化权重为1与3，后验H概率0.75。密度可大于1，概率则必须归一化到总和1。

过滤只使用截至当前的数据；平滑利用未来数据重新判断过去状态。平滑可以帮助事后解释历史，但实时交易应使用预测或过滤概率。状态数、滚动估计窗口和参数更新速度，应在时间顺序正确的验证中选择。

其他模型怎样放在一起比较

HEAVY用高频测度驱动方差动态，乘法误差模型直接为正测度建立条件均值。它们与Realized GARCH的区别在于方程、分布及反馈方式。学习时先写清每个状态变量何时可知、单位是什么，再比较预测误差怎样传入组合仓位或执行库存风险。

一步状态预测的计算

设昨日过滤概率为低波动0.8、高波动0.2。低状态下一天仍低的概率0.95，高状态转低的概率0.15，则今日事前低概率为 0.8×0.95+0.2×0.15=0.790.8\times0.95+0.2\times0.15=0.790.8×0.95+0.2×0.15=0.79，高概率0.21。先预测状态，再观察今天收益，这两个步骤不能颠倒。

若同一今日收益在低、高状态下密度为2、6，后验高概率为 0.21×6/(0.79×2+0.21×6)≈0.443660.21\times6/(0.79\times2+0.21\times6)\approx0.443660.21×6/(0.79×2+0.21×6)≈0.44366。观察令高波动概率由21%增到44.37%，但没有把状态确定为高。若两状态的收益均值均零、标准差分别1%和3%，今日事前混合方差为 0.79×0.012+0.21×0.032=0.0002680.79\times0.01^2+0.21\times0.03^2=0.0002680.79×0.012+0.21×0.032=0.000268，标准差约1.637%。

如果状态收益均值不同，混合方差还要加上状态均值相对总均值的离散程度。只平均两个状态的方差会漏掉状态间均值风险。这与组合风险中的全方差分解是同一个原理。

误差怎样传入风险仓位

设目标日波动1%，模型预测0.5%，按波动倒数会给2倍仓位。真实日波动若是2%，实际风险就可能达到4%。此时问题既来自低估风险，也来自仓位放大。给预测增加下限、给仓位增加上限，改变的是决策规则，评价时应连同预测模型一起记录。

方差测度也有测量误差。比较两个模型时，用噪声很强的单日收益平方作为唯一目标可能掩盖预测差异。用高频测度则需确保去噪、交易窗口和隔夜口径一致。测量方程的作用正是承认“今天算出的风险指标”并不等于没有误差的潜在方差。

练习

1. β=0.6,γ=0.3,ϕ=1.1\beta=0.6,\gamma=0.3,\phi=1.1β=0.6,γ=0.3,ϕ=1.1，持续性是多少？

查看解答

0.6+0.3×1.1=0.930.6+0.3\times1.1=0.930.6+0.3×1.1=0.93。只看0.6会遗漏测量反馈路径。相应均值存在仍需冲击和模型条件。

2. 实时模型用全样本平滑概率标记低波动日，再回测这些日子的高仓位，会出现什么问题？

查看解答

过去的状态标签已经利用未来收益，仓位使用了当时未知的信息。应在每个时点递推预测/过滤概率，并只用此前样本估计参数。
