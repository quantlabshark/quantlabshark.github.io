1. OLS 与复制样本

题目

线性模型 y=Xβ+εy=X\beta+\varepsilony=Xβ+ε 有 n>pn>pn>p 个观测、p 个参数（含截距），X∈Rn×pX\in\mathbb R^{n\times p}X∈Rn×p 满列秩，误差独立服从 N(0,σ2)N(0,\sigma^2)N(0,σ2)，σ2>0\sigma^2>0σ2>0 且未知。推导 OLS。把每行原样复制一次后，系数、R2R^2R2 以及按独立观测公式计算的 t 值怎样变化？

考点：最小二乘推导；自由度；重复样本的依赖。

查看分析与解答

必要知识

X 的每行是一个观测、每列是一个待估参数对应的解释变量，p 包含截距。满列秩保证 XᵀX 可逆。估计 p 个参数后，残差方差的分母为 n−p；标准误描述系数的抽样不确定性，不等于残差标准差。

分析思路

依次追踪复制对损失函数、交叉乘积、残差平方和和自由度的影响。把软件按独立行计算的形式结果与真正增加的信息分开。

解答步骤

展开损失为 yᵀy−2βᵀXᵀy+βᵀXᵀXβ，对 β 求导得到正规方程。复制后损失只是原损失乘二，最小值位置当然不变。说明系数不变不需要重新逐元素求逆。

复制后的统计信息

同一观测的两个副本误差完全相关，独立误差假设已被破坏，信息量没有增加。应去重、保留原样本，或按真实独立抽样单位构造推断。不要把简单复制后的常规标准误作为研究结果。

系数协方差估计是 s²(XᵀX)⁻¹。复制使前一因子变为原来的 2(n−p)/(2n−p)，后一因子减半，相乘得到 (n−p)/(2n−p)；再开平方才是标准误比。检验同一假设 β_j=β₀ 时分子不变，t 值按标准误反比变化。副本与原行相关为一，所以这个缩放并不意味着实际信息增加。

同类问题

数据扩增、重复采样或同一主体多条记录都可能使行数大于独立信息量。应先确认独立抽样单位，再选择标准误；拟合效果不变而显著性增强时尤其要检查重复数据。

2. 二维密度

题目

联合密度为 f(x,y)=ke−(2x+3y)f(x,y)=ke^{-(2x+3y)}f(x,y)=ke−(2x+3y)（x>0、y>0），其他位置为零。求常数 k、联合分布函数、P(X<Y)P(X<Y)P(X<Y)，并判断 X、Y 是否独立。

考点：联合密度；边缘分布；积分区域。

查看分析与解答

必要知识

二维密度需在整个支持域积分为一。联合分布函数 F(x,y) 是 X≤x 且 Y≤y 的概率；边缘密度通过把另一个变量在全部支持域上积分得到。密度数值本身不是某一点的概率。

先归一化，再求边缘并检查乘积分解。计算 X<Y 时可以对一个变量固定值后积分，或直接在 y>x 的区域做二重积分。

3. 相关和的最小值

题目

三个变量均有正的有限方差。求它们三对 Pearson 相关系数之和的最小值，并构造达到下界的例子。

考点：标准化；协方差展开；达到下界。

查看分析与解答

必要知识

Pearson 相关是标准化变量的协方差。将所有变量统一到均值零、方差一后，相关和可以直接出现在某个线性组合的方差中。求最小值仍须构造达到界的分布。

分析思路

选择 X+Y+Z，使三个交叉项以相同系数出现。由方差非负得到下界，再使这个和恒为零以达到等号。

解答步骤

先将三个变量标准化为均值零、方差一，再展开平方 E[(X+Y+Z)²]，三个自身平方期望各一，另外三对交叉项各出现两次，因此是 3+2Σr。由此可以看出 −3/2 来自整体方差约束，而不是把三个相关各取 −1。

标准化不会改变相关系数，故可设 X、Y、Z 的均值为零、方差为 1。由方差非负， 0≤Var⁡(X+Y+Z)=3+2(rXY+rXZ+rYZ),0\le\operatorname{Var}(X+Y+Z)=3+2(r_{XY}+r_{XZ}+r_{YZ}),0≤Var(X+Y+Z)=3+2(rXY​+rXZ​+rYZ​), 所以三对相关之和至少为 −3/2-3/2−3/2。

取独立标准变量 U、V，令 X=UX=UX=U、Y=−U/2+3V/2Y=-U/2+\sqrt3V/2Y=−U/2+3​V/2、Z=−U/2−3V/2Z=-U/2-\sqrt3V/2Z=−U/2−3​V/2。三者方差都为 1，每对协方差均为 -1/2，相关和为 -3/2，达到下界。

此构造中 X+Y+Z=0X+Y+Z=0X+Y+Z=0，正好使第一式中的方差为零。三对相关不可能同时为 -1，因为若 Y、Z 都完全反向于 X，它们彼此反而同向。

在给出的构造中，Y+Z=−U=−X，所以总和严格为零；Var(Y)=1/4+3/4=1，Cov(Y,Z)=1/4−3/4=−1/2。逐项验证确保每个变量仍非退化，相关系数都有定义。

同类问题

优化若干协方差或相关之和时，可以尝试把目标放进某个方差表达式。非负性给下界，方差为零则提示达到界所需的线性约束。

4. 偏币生成公平结果

题目

一枚硬币每次独立出现正面的概率为 1/3、反面为 2/3。只使用这枚硬币，生成双方各以 1/2 概率获胜的结果，并求平均抛掷次数。

考点：对称事件；偏币去偏；重启期望。

查看分析与解答

必要知识

公平结果不要求原硬币公平，只需要挑出两个等概率且可区分的结果。独立、固定偏置使 HT 与 TH 都有概率 p(1−p)，即使 p 未知也相等。

分析思路

把两次投掷当作一轮，仅保留不同面两种情况，丢掉其余结果。再分别计算接受后的条件概率和等待轮数。

解答步骤

若将 H 直接判甲赢、T 判乙赢，偏置不会消失；若接受 HH 与 TT，它们概率分别为 1/9 与 4/9，也不对称。只有把正反顺序交换成对的 HT、TH，才能利用乘法交换性抵消偏置。

每轮抛两次。HT 概率为 (1/3)(2/3)=2/9(1/3)(2/3)=2/9(1/3)(2/3)=2/9，TH 概率同样为 2/9。将 HT 分给甲、TH 分给乙，HH 或 TT 则丢弃这一轮并重来。

每轮被接受的概率为 4/9；在接受条件下，甲的概率为 (2/9)/(4/9)=1/2(2/9)/(4/9)=1/2(2/9)/(4/9)=1/2，乙同理。独立重复不会改变接受后的比例。

轮数服从成功率 4/9 的几何分布，均值 9/4，每轮两次，所以平均抛掷数为 2×9/4=9/22\times9/4=9/22×9/4=9/2。该方法也适用于任意固定 0<p<10<p<10<p<1 的未知偏币，因为 HT 和 TH 始终同概率；若各次偏置随时间变化或相互依赖，则需重新检查此对称性。

总体甲胜概率 q 满足 q=2/9+(5/9)q，因此 q=1/2。平均投掷次数 E 满足 E=2+(5/9)E，得到 9/2。一般偏置 p 的平均次数为 1/[p(1−p)]，接近零或一时拒绝很多，效率下降。

同类问题

未知偏置随机源可通过等概率对称事件提取公平性。验证条件是两次独立且偏置相同；仅知道长期正面比例并不能保证方法有效。

5. 公平币生成5/13

题目

只用独立公平硬币生成一次游戏结果，使甲胜率恰为 5/13、乙胜率为 8/13。给出几乎必然终止的方法，并求平均投掷次数。

考点：二进制编码；精确概率；拒绝次数。

查看分析与解答

必要知识

四个公平独立比特形成十六个等可能整数。有限固定次投掷能直接给出的概率分母是二的幂，5/13 不具备这一形式，因此可通过允许重启得到精确概率。

分析思路

先构造十三个等可能结果，再按五比八分配胜者。拒绝的三种编码不算任何一方输赢，而是完整重启。

解答步骤

例如 HHTT 编成 1100₂=12，属于乙；HHHT 编成 1110₂=14，丢弃。每轮甲直接胜概率 5/16、乙直接胜 8/16、重启 3/16，因此最终甲胜概率 q 满足 q=5/16+3q/16。

把正反面编码为 1、0，每四次组成四位二进制整数 Z，因此 Z 在 0 至 15 上均匀。若 Z 为 13、14、15，则丢弃并重新抛四次；否则接受。

接受后 0 至 12 共 13 个值等可能。把 0 至 4 五个值分给甲，5 至 12 八个值分给乙，即得到 5/13 与 8/13。

每轮接受率为 13/16，平均轮数为 16/13，平均投掷次数为 4×16/13=64/13≈4.9234\times16/13=64/13\approx4.9234×16/13=64/13≈4.923。连续拒绝 k 轮概率为 (3/16)k(3/16)^k(3/16)k，趋于零。不能直接把 16 个等可能结果按近似比例分配，因为 5/13 不是分母为 16 的分数。

解得 q=5/13。平均次数同样由 E=4+3E/16 得 64/13。这个数是当前四比特整轮拒绝方案的耗时，并未证明它在所有可能的随机位算法中最省，题目只要求一个准确且能终止的方案。

同类问题

构造有理概率 a/b 时，可选 2ᵏ≥b，接受前 b 个均匀编码，再划 a 个为成功。若需要优化效率，可进一步考虑利用被拒绝编码保留的信息。

6. 首次正面

题目

独立公平硬币直到首次正面才停止，奖金等于抛掷次数 N 元。假设零利率、不计时间成本、奖金确定支付，求风险中性公平入场价，并给出两种求期望的方法。

考点：首次成功；尾概率；期望支付。

查看分析与解答

必要知识

首次正面在第 n 次出现，意味着前 n−1 次都反面、最后一次正面，概率为 (1/2)ⁿ。风险中性表示只按货币支付的数学期望评价，而非根据输赢频率或个人风险偏好定价。

分析思路

先求停止次数均值，再利用奖金恰为次数换算支付。首步分析最短，尾和公式则能独立核对，二者都利用抛出反面后状态重启。

解答步骤

奖金一元的概率一半、二元四分之一、三元八分之一，后续依此下降。虽然可能等待任意长时间，概率呈指数下降，线性奖金的期望仍有限。

首次正面在第 n 次的概率为 2−n2^{-n}2−n，因此 E[N]=∑n≥1n2−n=2E[N]=\sum_{n\ge1}n2^{-n}=2E[N]=∑n≥1​n2−n=2。也可使用尾和公式：抽到第 n 次意味着前 n−1 次均反面，故 E[N]=∑n≥12−(n−1)=2E[N]=\sum_{n\ge1}2^{-(n-1)}=2E[N]=∑n≥1​2−(n−1)=2。

首步分析更简洁。记剩余次数期望为 E，先抛一次必花 1 次；若反面（概率 1/2），又回到相同状态，因此 E=1+E/2E=1+E/2E=1+E/2，解得 E=2。

风险中性且没有折现或支付风险时，公平入场价等于期望奖金，即 2 元。奖金按次数线性增长，与按 2N−12^{N-1}2N−1 支付的重尾赌局不同。

尾和的第一项 P(N≥1)=1，第二项 P(N≥2)=1/2，形成等比级数 1+1/2+1/4+…=2。首步方程中的常数一表示无论正反都已经发生一次投掷，不能只在反面分支加一。

同类问题

首次成功等待可用几何分布或自重启方程。若奖金是 g(N)，应求 E[g(N)]；除非 g 为线性函数，不能直接把 E[N] 代入 g。

7. 连续三正面

题目

独立公平硬币首次出现连续三个正面时结束，奖金等于总投掷次数。求期望次数和风险中性公平入场价；零利率且不计时间成本。

考点：连续模式；状态重置；期望方程。

查看分析与解答

必要知识

已经积累两个连续正面比没有连续正面更接近结束，剩余期望不同。一次反面会破坏全部连续正面，所以状态需记录当前结尾连续 H 的长度，而非历史正面总数。

分析思路

为零、一、二个连续正面各设一个未知剩余期望。对下一次结果分类，每个方程都先加上必然消耗的一次投掷。

解答步骤

在状态二，再正面就结束、剩余次数零；反面回状态零，因此 E₂=1+E₀/2。在状态一，再正面进入状态二；反面回零。把 E₂ 代入 E₁，再与 E₀ 方程联立即可。

设 EjE_jEj​ 为当前末尾已有 j 个连续正面时，还需投掷的期望次数，j=0、1、2、3。完成状态 E3=0E_3=0E3​=0。每次出现反面会把连续正面数重置为 0，因此 E0=1+12E1+12E0,E_0=1+\tfrac12E_1+\tfrac12E_0,E0​=1+21​E1​+21​E0​, E1=1+12E2+12E0,E2=1+12E0.E_1=1+\tfrac12E_2+\tfrac12E_0,\qquad E_2=1+\tfrac12E_0.E1​=1+21​E2​+21​E0​,E2​=1+21​E0​. 最后两式代入得 E1=3/2+3E0/4E_1=3/2+3E_0/4E1​=3/2+3E0​/4；第一式又给出 E0=2+E1E_0=2+E_1E0​=2+E1​。整理得 E0=14E_0=14E0​=14，因此公平价为 14 元。

不能用“某组三次全正面概率 1/8，所以平均 8 次”计算，因为连续窗口互相重叠，且一次反面会打断已积累的前缀。状态变量记录末尾连续正面的数量，正是递推需要的信息。

解得 E₀=14、E₁=12、E₂=8。即使已有两个正面，平均还需八次，因为下一次有一半概率失去全部前缀、重新等待。按不重叠三次一组检查会得到平均二十四次，但它漏掉跨组边界出现的 HHH，解决的是另一个停止规则。

同类问题

连续成功题用当前连续长度作为状态；更一般模式要保留仍可能匹配目标的后缀。先写转移，再求均值，能避免把重叠窗口当独立试验。

8. 任意终止模式

题目

给定长度 m 的 H/T 模式，独立公平硬币不断抛掷，首次在序列末尾出现该模式时停止。如何计算期望次数？以 HHH 和 HHHHTTTT 为例，并说明模式自重叠的作用。

考点：前缀自动机；重叠；线性方程。

查看分析与解答

必要知识

状态保存的是已经出现的序列末尾仍可用于未来完成目标的部分。失败后不一定归零，例如目标 HTH，看到 HH 时末尾那个 H 仍可作为新匹配的开始。δ(i,c) 表示状态 i 再看到字符 c 后的新匹配长度。

分析思路

逐个列出匹配状态，计算 H、T 两条转移，再为每个未完成状态写剩余期望方程。先用短模式手算核对转移，最后扩展到八字符例子。

解答步骤

目标 HTH 的转移为：状态零经 H 到一、T 留零；状态一经 H 留一、T 到二；状态二经 H 结束、T 到零。因此 E₀=1+(E₁+E₀)/2，E₁=1+(E₁+E₂)/2，E₂=1+E₀/2。解得 E₀=10，说明长度同为三的 HTH 与 HHH 等待时间不同。

用状态 i 表示“当前序列后缀与目标前缀匹配的最长长度”，i 从 0 到 m。状态 m 已完成，Em=0E_m=0Em​=0。其余状态各抛一次后转移到最长可保留前缀，故 Ei=1+12Eδ(i,H)+12Eδ(i,T).E_i=1+\frac12E_{\delta(i,H)}+\frac12E_{\delta(i,T)}.Ei​=1+21​Eδ(i,H)​+21​Eδ(i,T)​. 例如目标 HTH，状态 2 代表末尾为 HT；再来 T 时后缀没有匹配前缀，回到 0；再来 H 则到达 3。状态转移可用字符串前缀函数构造，而不是失败后总是把历史清空。

建立 m 个线性方程后求解即可。通常的稠密线性求解为 O(m3)O(m^3)O(m3) 时间；模式较长时可以利用转移的稀疏结构。由于有限模式在独立公平投掷中以正概率出现，等待期望有限。

公平硬币还有一个便于核对的结果：列出模式所有非空“前缀等于后缀”的长度 l，包括整个模式，期望为这些 2l2^l2l 之和。HHH 的匹配长度为 1、2、3，所以期望为 2+4+8=142+4+8=142+4+8=14。HHHHTTTT 没有真前后缀相同，只有长度 8，期望为 28=2562^8=25628=256。

自重叠使一次模式出现前后共享的局部结构增多，等待次数不能只由长度决定。用状态方程能够直接计算，也可避免记错特殊公式。

对 HHHHTTTT，各未完成状态的 (遇 H,遇 T) 转移依次为 (1,0)、(2,0)、(3,0)、(4,0)、(4,5)、(1,6)、(1,7)、(1,8)。状态四再遇 H 仍保留末尾四个 H；状态五至七遇 H 则留下一个新 H，不能清零。代入方程所得 E₀ 至 E₇ 为 256、254、250、242、226、224、192、128，E₈=0。逐行代入即可核对，例如 E₇=1+E₁/2=128。

同类问题

模式等待问题的难点通常在失败转移，而非解方程。把每次新序列的所有后缀与目标前缀比较，选最长匹配，能系统处理自重叠和部分保留。
