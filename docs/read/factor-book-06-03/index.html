6.3 行为偏差如何影响价格与交易

结合套利限制、预期偏差、累积前景理论和注意力，解释动量、反转、公告漂移及彩票型股票。

估值100元的股票跌到80元，为何仍可能亏损

投资者估计一家公司价值100元，以80元买入，之后价格却跌至60元。可能是估值遗漏了经营恶化，也可能是市场抛售暂时扩大。即使长期价格最终恢复，投资者也可能因为资金赎回而提前卖出。价格有偏差与能够从偏差中获利之间，存在一段实际交易过程。

行为金融学把问题分成两部分：预期、偏好和信息处理上的偏差怎样形成价格偏离；套利者又为何无法立即纠正它们。这里的套利通常是押注价格修正的风险交易，不是严格意义上锁定无风险利润。

三种套利限制

基本面风险来自价值本身的不确定性。买入看似便宜的公司后，业务可能真的恶化，也很难找到经营现金流完全相同的证券来对冲。

噪声交易者风险来自价格在修正前继续偏离。基金投资者依据近期净值赎回，管理人可能被迫在低价卖出，长期判断与短期资金约束因此冲突。

实施成本包括手续费、价差、冲击、借券，以及调查公司真实价值所花费的信息成本。即便预期修正幅度为3%，若研究与交易成本加上风险补偿已达3%，也没有剩余的无风险利润。

七类预期偏差及其可观察后果

偏差 含义 可以观察的研究问题
过度自信 高估判断精度与自身能力 预测区间是否过窄，交易是否过多
乐观主义 高估有利结果，受控制幻觉和自身利益强化 盈利预测是否长期偏高，是否忽视失败情景
代表性启发法 按表面相似判断，忽略基准概率和样本量 是否把少数季度增长外推为长期趋势
保守主义 既有观点更新过慢 新公告后是否持续同方向修正预测
确认偏误 只搜集支持已有结论的信息 是否系统遗漏反向证据
锚定 过度依赖初始价格或目标值 预测是否围绕历史高点或买入价僵化
可得性启发法 容易想起的新闻与经历获得过高权重 近期报道和极端成交是否吸引过多买入

例如某行业只有10%的公司能维持高增长，连续两个季度增长并不自动把长期成功概率提高到90%。需要比较这类数据在持续增长公司和普通公司中分别出现的概率，再结合基准比例。只依据“很像成长股”判断，便遗漏了先验。

沉没成本也会强化保守更新：过去已经花费的研究时间无法收回，决策应比较从现在开始继续持有和换仓的未来收益，而非为了证明旧判断正确继续追加投入。检验“所有元音卡背面都是偶数”应翻A和7，而不是A和4。7背面若是元音可以推翻结论。

这种主动寻找反证的思路同样适用于因子研究。

历史52周高点、历史最高点与近期新闻可以成为价格锚或注意力焦点。要把心理机制转成定量研究，需要事先规定锚的定义、信息时间与预测方向，避免价格上涨后才解释为过度自信、下跌后才解释为悲观。

盈亏参照点与损失厌恶

一个人从1000元变成1100元，通常感受的是赚100元；从1000元变成900元，感受的是亏100元。前景理论围绕参照点的盈亏建模，而非只看最终财富。常用价值函数为

v(x)={xc,x≥0,−κ(−x)c,x<0,0<c<1, κ>1.v(x)=\begin{cases}x^c,&x\ge0,\\-\kappa(-x)^c,&x<0,\end{cases} \qquad 0<c<1,\ \kappa>1.v(x)={xc,−κ(−x)c,​x≥0,x<0,​0<c<1, κ>1.

ccc 控制敏感度递减：从赚100到200的变化，可能比从赚1000到1100更明显。κ\kappaκ 控制损失厌恶：相同金额的损失具有更大的主观影响。盈利侧函数凹、亏损侧函数凸，对应人们可能在盈利时偏向确定收益、亏损时愿意冒险回本。

实际选择还取决于概率权重与参照点。

取 c=0.5,κ=2c=0.5,\kappa=2c=0.5,κ=2，赚100的价值为10，亏100为−20。各50%概率时，使用客观概率加权的价值为−5，虽然期望金额为0。这说明损失厌恶如何改变对公平赌局的评价。

鲨鱼说

价值函数，即给定当前状态，按照指定目标评价未来累计结果的函数。

累积概率怎样形成决策权重

累积前景理论允许多个盈亏结果。一个常用权重函数为

w(p)=pγ[pγ+(1−p)γ]1/γ.w(p)=\frac{p^\gamma}{[p^\gamma+(1-p)^\gamma]^{1/\gamma}}.w(p)=[pγ+(1−p)γ]1/γpγ​.

下面取γ=0.65\gamma=0.65γ=0.65，并要求累积权重函数单调递增、满足w(0)=0,w(1)=1w(0)=0,w(1)=1w(0)=0,w(1)=1。不能把任意0<γ<10<\gamma<10<γ<1都当成有效参数；单调性保证相邻尾部累积权重之差非负。

盈利与亏损可用不同的 w+w^+w+、w−w^-w−。对于从小到大排列的正收益 x1<⋯<xnx_1<\cdots<x_nx1​<⋯<xn​，第 iii 项权重为

πi+=w+(∑j=inpj)−w+(∑j=i+1npj).\pi_i^+=w^+\left(\sum_{j=i}^{n}p_j\right)-w^+\left(\sum_{j=i+1}^{n}p_j\right).πi+​=w+(j=i∑n​pj​)−w+(j=i+1∑n​pj​).

即“不差于它”的累积权重减“严格好于它”的累积权重。负收益从最差向0排序时，使用左尾累积概率之差。最后计算 ∑iπiv(xi)\sum_i\pi_i v(x_i)∑i​πi​v(xi​)。

自拟三个盈利结果10、30、100元，概率0.5、0.4、0.1，取 γ=0.65\gamma=0.65γ=0.65：

Python9 行
def w(p, gamma=0.65):
    return p**gamma / (p**gamma + (1-p)**gamma)**(1/gamma)
prob = [0.5, 0.4, 0.1]
payoff = [10, 30, 100]
weights = [w(sum(prob[i:])) - w(sum(prob[i+1:])) for i in range(3)]
subjective = sum(weight * x**0.5 for weight, x in zip(weights, payoff))
assert abs(sum(weights) - 1) < 1e-12
print('决策权重：', [round(x, 4) for x in weights])
print('主观价值：', round(subjective, 4))

最大的100元结果只有10%客观概率，却获得较高决策权重。三个结果都为盈利时，权重可望远镜式相消并加总为1。同时包含盈利和亏损时，两侧分别加权，总和不必为1。它们是决策权重，不能再当作客观概率使用。早期实验常用 c=0.88,κ=2.25c=0.88,\kappa=2.25c=0.88,κ=2.25、盈利参数0.61、亏损参数0.69，这些参数来自特定实验而非适用于所有投资者。

鲨鱼说

累积权重不是把每个概率分别“放大一点”。中间结果的权重要由两个累积值相减得到，极端结果才直接对应尾部权重。这样才能保留结果之间的排序关系。

风险已知与概率未知

罐子A有100个红蓝球，但各多少未知。罐子B明确有红蓝各50个。抽到红球获奖时，许多人选B。换成抽到蓝球获奖时，他们仍选B。如果用同一套主观概率解释，就相当于同时认为A中红球少于50、蓝球也少于50，产生矛盾。

这体现模糊厌恶：已知概率的风险与不知道概率分布的模糊性，会引起不同偏好。投资者可能因此偏好熟悉的本地公司或行业。熟悉有助于获取信息，也可能造成集中持仓；两者需要通过信息质量与分散风险分别衡量。

注意力有限与分类思维

信息公开不等于所有人已经处理。大量公司同日发布财报、临近周末公告，都会增加信息吸收的压力。旧消息在醒目媒体重新报道后引发交易，说明可见度和经济新信息也有区别。

投资者还会把股票分成价值、成长、小盘等类别，以降低处理成本。当资金按类别买卖，同类股票可能在基本面没有同步变化时仍共同涨跌。历史研究发现，股票入选某指数后，与其他成分股的相关性可能上升。这种分类交易提供了除经营联系之外的共同运动来源。

从机制推到具体异象

盈余公告后漂移PEAD可由好坏消息未一次吸收解释。保守更新先造成反应不足，随后连续好消息引起过度外推，又可能形成较长周期的反转与价值效应。基本面交易者与趋势交易者之间的信息扩散，也能产生先延续、后过度反应的过程。

尾部权重则能解释对“彩票型”股票的偏好：少数大涨结果获得较高主观权重，需求推高当前价格，使未来平均收益下降。处置效应表现为过早兑现盈利、过久持有亏损。未实现盈利CGO可以与公告信息交叉：浮盈加好消息可能受到获利卖出抑制，浮亏加坏消息可能受到不愿卖出抑制，二者都延迟充分反应。

持仓盈亏状态也会改变对高波动、正偏度股票的需求。历史研究在浮亏股票中观察到更强的彩票偏好与低波动关系。进一步的模型把过去60个月收益分布代入前景价值，或加入心理账户中的狭隘框架，把每只股票分开评价。

这些模型对动量、IVOL、盈利和PEAD提供了解释，对规模、价值、反转、应计与投资等现象则存在解释边界。

价格偏离价值，市场仍可能难以战胜

“价格等于价值”与“扣除风险、费用后难以持续战胜市场”是两个命题。套利限制允许价格偏离价值，同时让利用偏差的成本很高。这种行为有效市场视角解释了为何观察到心理偏差，并不能直接得到易于执行的盈利规则。

练习

某投资者认为亏损股票一定要等到回本再卖，并只阅读支持公司前景的报道。这里可能涉及哪些机制？怎样把判断改成可检验的决策？

查看解答

买入价可能成为参照点和锚，亏损区域的风险偏好可能强化持有，选择报道涉及确认偏误。可以重新估计未来现金流与不同情景，列出能推翻判断的证据，比较从当前价格开始的收益风险以及替代持仓。过去成本保留为绩效记录，不直接决定未来价格。
