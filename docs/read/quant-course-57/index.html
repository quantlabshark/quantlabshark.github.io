57 · 多资产执行与最优配置

用联立矩阵方程安排多资产减仓，并按成交概率比较主动与被动订单成本。

多资产执行同时改变各资产库存和组合的共同风险。分别减少某项持仓，可能破坏已有对冲，因此交易速度应结合协方差和总成本安排。

鲨鱼说

协方差，即两个变量偏离各自均值时，共同变化程度的度量。

减少股数不一定减少组合风险

持有A多头1单位、B空头1单位，两者价格标准差均1，相关系数0.8。库存 q=(1,−1)⊤q=(1,-1)^\topq=(1,−1)⊤ 的方差为 q⊤Σq=1+1−2×0.8=0.4q^\top\Sigma q=1+1-2\times0.8=0.4q⊤Σq=1+1−2×0.8=0.4。若先完全卖掉A，只剩B空头，方差变为1，反而增加。

原因是原来两项价格变化大部分相互抵消，单边平仓暂时拆开了对冲。多资产执行需要控制整个剩余库存的风险路径。每个资产单独追求最快完成，不一定让组合整体最稳。

冲击矩阵与协方差矩阵

本期减仓向量记为 uuu，剩余为 q−uq-uq−u。二次冲击 u⊤Λuu^\top\Lambda uu⊤Λu 用 Λ\LambdaΛ 描述交易成本，剩余风险 (q−u)⊤Σ(q−u)(q-u)^\top\Sigma(q-u)(q−u)⊤Σ(q−u) 用 Σ\SigmaΣ 描述随机价格共动。前者是成交量/速度到货币成本的关系，后者是价格变化的二阶矩，不能用相关系数直接代替交叉冲击。

例如 Λ\LambdaΛ 的对角为1和4，表示同规模B交易的自冲击更大。非对角项则使同时交易两个资产产生额外相互影响。二次型只使用矩阵的对称部分，凸成本要求相关矩阵具有适当半正定性。不同交易时段的间隔和单位也要一致。

两期任务的联立解

第一期交易 uuu，第二期完成 q−uq-uq−u；中间持仓承担风险惩罚 λ\lambdaλ。目标为

J(u)=u⊤Λu+(q−u)⊤Λ(q−u)+λ(q−u)⊤Σ(q−u).J(u)=u^\top\Lambda u+(q-u)^\top\Lambda(q-u)+\lambda(q-u)^\top\Sigma(q-u).J(u)=u⊤Λu+(q−u)⊤Λ(q−u)+λ(q−u)⊤Σ(q−u).

对每个分量求导并整理：

(2Λ+λΣ)u∗=(Λ+λΣ)q.(2\Lambda+\lambda\Sigma)u^*=(\Lambda+\lambda\Sigma)q.(2Λ+λΣ)u∗=(Λ+λΣ)q.

这是线性方程组。若风险惩罚为0，两期相同成本下每期一半；若风险为正，第一期通常完成更多，但各资产速度受对冲关系和流动性共同影响。

Python12 行
import numpy as np
q = np.array([1.,-1.])
impact = np.diag([1.,4.])
cov = np.array([[1.,0.8],[0.8,1.]])
lam = 2.0
u = np.linalg.solve(2*impact+lam*cov, (impact+lam*cov)@q)
def objective(first):
    remaining = q-first
    return first@impact@first + remaining@impact@remaining + lam*(remaining@cov@remaining)
print('首期交易、剩余库存',u,q-u)
print('最优目标、各半目标',objective(u),objective(q/2))
assert objective(u) <= objective(q/2)

本例首期交易约 (0.56197,−0.52991)(0.56197,-0.52991)(0.56197,−0.52991)，剩余约 (0.43803,−0.47009)(0.43803,-0.47009)(0.43803,−0.47009)。负交易量表示回补原空头，不是继续增加空头。目标约2.68162，低于各做一半的2.7。数学解允许有符号交易。若只允许沿原方向减仓或受参与率限制，应把这些约束加入优化。

图比较同一库存结构下的风险：保留配对风险0.4，单独平掉一腿风险1，两腿同步缩减一半则风险0.1。所有数值以本例单位计算。

数量决定后，还要选择怎样成交

资产配置决定“持有什么”，订单配置决定“这一笔放在什么位置、用什么方式”。假设买一99.99、卖一100.01，主动买入另付0.001，成本为100.011。被动买一成交返还0.001，净成本99.989。

若没成交，到截止时补买的条件期望含费成本100.041。

设被动成交概率 ppp，限价方案期望成本为 p×99.989+(1−p)×100.041p\times99.989+(1-p)\times100.041p×99.989+(1−p)×100.041。p=0.6p=0.6p=0.6时为100.0098，略低于主动；p=0.2p=0.2p=0.2时为100.0306，主动更低。求等成本阈值得

p>100.041−100.011100.041−99.989≈0.576923.p>\frac{100.041-100.011}{100.041-99.989}\approx0.576923.p>100.041−99.989100.041−100.011​≈0.576923.

这里100.041必须是“未成交条件下”的补买成本。如果价格上涨恰好导致自己的买单不成交，用无条件未来均价代替它，会低估等待成本。

吸收边界给出成交概率

用有限状态描述前方队列、价差、剩余期限。将“全部成交”设为概率1的边界，“退出且未成交”设为0。其他状态满足 p(s)=∑s′Pss′p(s′)p(s)=\sum_{s'}P_{ss'}p(s')p(s)=∑s′​Pss′​p(s′)。例如从当前状态有0.4概率立即成交，0.3概率进入一个成交概率0.5的状态，0.3概率退出，则总概率为0.55。

如果状态转换按事件次数定义，还要建模等待时间，才能求未来一秒内成交概率。连续时间链可由生成元或矩阵指数计算指定期限的吸收概率。下一次事件内完成与截止时完成并非同一个目标。

等待、改价和主动成交的价值比较

动态策略在每个新状态比较三项：继续排队的期望成本、撤销改价后新状态的成本、立刻主动完成的成本。改价可能失去原队列位置，撤销也存在确认延迟；因此不能在回测中免费保留旧位置。

多资产状态还包括其他腿剩余库存。流动性差的一腿可能决定整体速度，另一腿需要保留适量对冲。加入价格预测时，还要把预期等待收益与预测误差共同放进目标：看涨信号能推动买入提前，但不应覆盖无界冲击或突破风险约束。

把协方差计算展开到每一项

两资产价格标准差分别2和3、相关0.5，协方差为 0.5×2×3=30.5\times2\times3=30.5×2×3=3，矩阵为 (4339)\begin{pmatrix}4&3\\3&9\end{pmatrix}(43​39​)。持仓 (10,−5)(10,-5)(10,−5) 时，方差为 102×4+(−5)2×9+2×10×(−5)×3=32510^2\times4+(-5)^2\times9+2\times10\times(-5)\times3=325102×4+(−5)2×9+2×10×(−5)×3=325，标准差约18.03。

如果把相关0.5直接填在协方差位置，会得到575，忽略了价格波动的单位换算。若持仓单位是合约，价格损益还要乘合约乘数；同样的矩阵公式只有在输入单位相容时才具有正确含义。

冲击矩阵也需要独立估计。价格高度相关的两资产，可能在不同场所具有完全不同深度；同一共同信息会使它们一起变价，却不意味着买A必定机械抬高B的报价。收益相关与交易交叉影响是不同的条件关系。

成交概率的不确定性会影响微小成本优势

限价例中 p=0.6p=0.6p=0.6 比主动便宜0.0012元/股。若成交概率仅由25次独立相似尝试中15次成交估计，标准误约 0.6×0.4/25=0.098\sqrt{0.6\times0.4/25}=0.0980.6×0.4/25​=0.098。期望成本对 ppp 的斜率为 99.989−100.041=−0.05299.989-100.041=-0.05299.989−100.041=−0.052，这层概率误差对应约0.0051元/股的成本标准误，明显大于0.0012的表面优势。

因此要同时评估成交概率和条件补单成本的不确定性，并在新样本比较实际结果。若样本是连续重叠窗口，独立标准误还会偏小。可按时间区块估计。这个例子说明精确到小数点后很多位的成本计算，并不意味着输入概率同样精确。

练习

1. 同样的一多一空，相关系数由0.8变为−0.8，方差是多少？

查看解答

1+1−2×(−0.8)=3.61+1-2\times(-0.8)=3.61+1−2×(−0.8)=3.6。两资产本来反向变化，再用相反持仓，会让两项损益同向变化。
