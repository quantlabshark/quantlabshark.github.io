60 · 暗池、删失数据与流动性分配

识别满额成交的右删失，用风险集估计容量尾概率并分配有限订单。

隐藏流动性的成交记录常受到订单数量限制。全额成交只说明可用容量至少达到下单量，估计容量分布时需要保留这种下界信息。

满额成交只提供一个下界

向一个不展示完整深度的场所发100股，成交60股，在固定窗口与简化撮合模型下，可观察可供自己成交的容量为60。若成交100股，只知道容量至少100。实际可能恰好100，也可能有500股，订单把更远的信息截住了。

令下单量 nnn、潜在容量 UUU、实际成交 R=min⁡(n,U)R=\min(n,U)R=min(n,U)。R<nR<nR<n 是准确容量观测，R=nR=nR=n 是右删失。这里容量包含该窗口、订单方向与价格条件，不是场所永恒不变的总流动性。若一律把满额样本当作 U=nU=nU=n，会低估尾部容量。

图中的实心点表示已看到容量终点，箭头表示只知道容量向右至少延伸到下单量。看不到终点不能当作终点就在此处。

鲨鱼说

删失，即只能观察到数值达到某个边界，而无法得知边界之外具体取值的情况。

尾概率决定下一股的价值

对整数容量，记 Ti(k)=P(Ui≥k)T_i(k)=P(U_i\ge k)Ti​(k)=P(Ui​≥k)。因为 min⁡(n,U)=∑k=1n1{U≥k}\min(n,U)=\sum_{k=1}^n1\{U\ge k\}min(n,U)=∑k=1n​1{U≥k}，取期望得到

E[min⁡(ni,Ui)]=∑k=1niTi(k).E[\min(n_i,U_i)]=\sum_{k=1}^{n_i}T_i(k).E[min(ni​,Ui​)]=k=1∑ni​​Ti​(k).

第 ni+1n_i+1ni​+1 股的边际期望成交就是 Ti(ni+1)T_i(n_i+1)Ti​(ni​+1)，且随数量递减。已知尾概率时，可每次把下一股分给边际值最大的场所。A前三项为0.9、0.5、0.2，B为0.8、0.7、0.1，总分4股，选择顺序A第1、B第1、B第2、A第2，最后各2股，期望成交2.9股。

这个贪心规则依赖每场所的边际收益递减，优化的是期望成交量。不同费用、逆向选择或相关的总量风险会改变目标，不能只比较成交概率。

风险集表示谁有机会揭示终点

在容量层级 jjj，只有下单超过 jjj 且已经至少成交 jjj 的样本，才有机会告诉我们容量是否恰好在 jjj 结束。定义

Nj=∑s1{ns>j,Rs≥j},Mj=∑s1{ns>j,Rs=j}.N_j=\sum_s1\{n_s>j,R_s\ge j\},\qquad M_j=\sum_s1\{n_s>j,R_s=j\}.Nj​=s∑​1{ns​>j,Rs​≥j},Mj​=s∑​1{ns​>j,Rs​=j}.

NjN_jNj​ 为风险集，MjM_jMj​ 为观察到的终止次数，条件终止概率 h^j=Mj/Nj\hat h_j=M_j/N_jh^j​=Mj​/Nj​。离散Kaplan–Meier尾概率为 T^(k)=∏j=0k−1(1−h^j)\widehat T(k)=\prod_{j=0}^{k-1}(1-\hat h_j)T(k)=∏j=0k−1​(1−h^j​)。

若只下2股且满额成交2，样本不能判断是否在2结束，所以不在 j=2j=2j=2 的风险集；若下3股只成交2，才确知容量2。风险集为空意味着这一层未识别，不能解释成容量无限或尾概率确定为1。

五条记录逐层计算

自拟订单量为2、4、3、4、5，成交为2、1、3、4、2。前两条满2和只成1分别是删失与完整观测，第三、四条也满额，最后一条完整观察到容量2。

Python22 行
import numpy as np
orders = np.array([2,4,3,4,5])
fills = np.array([2,1,3,4,2])
survival = 1.0
for j in range(5):
    at_risk = (orders>j)&(fills>=j)
    count = int(at_risk.sum())
    failures = int(((orders>j)&(fills==j)).sum())
    if count == 0:
        print('从数量',j+1,'开始尾概率未识别')
        break
    survival *= 1-failures/count
    print('T(',j+1,')=',round(survival,6),'风险集',count)
tails = [[0.9,0.5,0.2,0.0],[0.8,0.7,0.1,0.0]]
allocation = [0,0]
for _ in range(4):
    marginal = [tails[i][allocation[i]] for i in range(2)]
    chosen = int(np.argmax(marginal))
    allocation[chosen] += 1
expected = sum(sum(tails[i][:allocation[i]]) for i in range(2))
print('最优整数分配',allocation,'期望成交',expected)
assert allocation == [2,2] and np.isclose(expected,2.9)

为什么学习需要适量探索

如果一直只发10股，即使每次全成，也无法区分容量11与1000。必须偶尔选择更大规模，才会对更远尾部获得信息。可靠的数量上界可由风险集样本量和估计误差决定，未知区域可作乐观处理以引导探索。

探索也占用实际执行机会，因而要与目标完成和补单代价共同安排。下单量依赖过去资料通常可被适应性学习框架处理，但不能暗中利用当前尚未观察到的容量；若当前状态同时影响下单量与容量，应在条件模型中控制。

从似然看，未满额样本贡献 P(U=R)P(U=R)P(U=R)，满额样本贡献 P(U≥n)P(U\ge n)P(U≥n)。两者携带的信息不同，是删失估计而非普通容量平均值的原因。

连续比例分配与相等边际收益

若总量 VVV 可连续分配，比例 ri≥0,∑ri=1r_i\ge0,\sum r_i=1ri​≥0,∑ri​=1，每单位成交吸引力 ρi\rho_iρi​，目标为 G(r)=∑iρiE[min⁡(riV,Ui)]G(r)=\sum_i\rho_iE[\min(r_iV,U_i)]G(r)=∑i​ρi​E[min(ri​V,Ui​)]。在阈值无原子等可微条件下，边际为

∂G∂ri=ρiE[V1{riV<Ui}].\frac{\partial G}{\partial r_i}=\rho_iE[V1\{r_iV<U_i\}].∂ri​∂G​=ρi​E[V1{ri​V<Ui​}].

最优内点各边际相等。零分配场所的边际不能高于共同值，否则挪去一点数量就能改善目标。用是否满额成交形成样本梯度，再把更新投影到比例单纯形，可以逐步学习分配。若容量离散且在阈值有质量，应使用适当次梯度而非假装处处可微。

两个容量模型可以给出完全相同的反馈

模型A有一半概率容量0、一半20。模型B有一半0、一半200。如果每次只发10股，两模型都以一半概率成交0、一半成交10，任何次数的相同下单都无法区分它们。但真实平均容量分别10与100，后续大任务的分配会很不同。

偶尔发30股时，模型A的满流动性状态成交20，模型B则成交30且仍删失，这才产生区分信息。探索需要选择能够区分候选容量分布的动作，同时承担该动作的执行成本。

贪心分配为何能够逐股进行

A、B尾概率各自递减，所以选中某场所第3股之前，必然已选中它边际不低的第1、2股。将所有边际值从高到低取前4个，会自然满足每场所数量连续性的限制。本例前4个为0.9、0.8、0.7、0.5，来自A1、B1、B2、A2，总和2.9。

若向某场所第2股的单位收益反而高于第1股，例如达到最小成交量才获得一笔固定优惠，边际不再递减。此时简单逐股贪心可能错过组合优惠，需要动态规划或其他离散优化。算法正确性来自目标结构，不只来自它在一个例子上给出合理分配。

条件容量还随时段、方向和报价变化。将早盘大单与午间小单混合估计一个无条件尾概率，可能把状态差异误当成容量分布。可以先按可观察状态分层，但每层风险集会变小。应同时显示估计值和支持它的样本数，尤其关注远尾部。
