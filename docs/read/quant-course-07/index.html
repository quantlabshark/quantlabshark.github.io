07 · 运行 Python 与保存结果

识别解释器、环境和工作目录，运行脚本与Notebook，并保存数据、结果和依赖。

Python 程序由解释器执行，第三方库提供数据处理和绘图功能。建立项目环境时，需要明确解释器位置、输入路径、依赖版本和输出目录。

编辑器与解释器是两件事

同一段程序在一个窗口能运行，在另一个窗口却提示找不到 pandas，通常意味着两个窗口使用了不同的 Python 环境。开始研究前，先弄清是谁执行程序、从哪里读取文件、把结果写到哪里。

编辑器负责输入和保存代码。Python 解释器执行代码。第三方库提供额外功能。Jupyter Notebook 把代码和文字放在一个文件里，背后的内核仍然调用某个 Python 解释器。浏览器页面本身并不负责计算。

终端输入 python --version 可以查看当前命令对应的版本。在编辑器中运行 import sys; print(sys.executable) 可以查看实际解释器路径。两处路径若不同，安装的库和读取的环境变量也可能不同。不要用“电脑已经装过 pandas”代替对具体解释器的检查。

已有能够运行 Python 的环境时，可以直接完成下面的实验。需要为新项目隔离依赖时，Python 自带的 venv 可创建环境；安装库时使用目标解释器的 -m pip，可以把安装动作与运行环境对应起来。Python 环境文档

在 Windows 项目目录中，可按顺序运行以下终端命令；它们不是 Python 单元格代码：

powershell3 行
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install numpy pandas matplotlib jupyterlab
.\.venv\Scripts\python.exe -m jupyter lab

这里直接使用环境里的解释器路径，避免命令窗口仍指向其他环境。已有 Conda 环境也可以使用，核心要求是编辑器、Notebook 内核和安装工具指向同一环境。

用五行计算认识变量和输出

设买入价格 100 元、期末价格 105 元，持有 20 股。价格收益为 105/100−1=5%105/100-1=5\%105/100−1=5%，价格变动产生的盈亏为 (105−100)×20=100(105-100)\times20=100(105−100)×20=100 元。程序里 = 把右侧结果保存到左侧名称，print 显示值。

图中每个箭头表示计算依赖。修改期末价会同时改变收益和盈亏；修改股数只改变盈亏，不改变每股收益率。可以用这种方式检查程序是否把数量和收益率混在一起。

下面的例子使用标准库，不需要行情账号或网络连接。将它保存为 first_experiment.py 后运行，或整体放进一个 Notebook 单元格。

Python17 行
from pathlib import Path
import csv
import sys

buy_price, end_price, shares = 100.0, 105.0, 20
return_rate = end_price/buy_price-1
pnl = (end_price-buy_price)*shares
print("解释器:", sys.executable)
print("工作目录:", Path.cwd())
print(f"价格收益 {return_rate:.2%}，盈亏 {pnl:.2f} 元")
target = Path("first_experiment_result.csv")
with target.open("w", newline="", encoding="utf-8-sig") as stream:
    writer = csv.writer(stream)
    writer.writerow(["buy_price","end_price","shares","return","pnl"])
    writer.writerow([buy_price,end_price,shares,return_rate,pnl])
print("已保存:",target.resolve())
assert abs(return_rate-0.05) < 1e-12 and pnl == 100

输出应包含 5.00% 和 100.00 元。生成的 CSV 保留原始输入和结果，打开后能追溯百分数的分母。路径输出说明文件实际写到了哪里；它不一定与编辑器当前打开的文件夹相同。

Notebook 的执行顺序会影响结果

Notebook 会记住此前运行过的变量。若先运行 end_price = 105，后来修改代码为 110 却没有重新执行这个单元格，下方计算仍可能使用旧值 105。页面从上到下的视觉顺序并不保证实际执行顺序相同。

完成实验后，重新启动内核并从头运行全部单元格。若结果能够重现，说明没有依赖隐藏在内存中的旧变量。脚本则从第一行依次执行，每次新进程运行较容易暴露未定义变量。

根据错误信息定位步骤

NameError 常表示变量尚未定义或名称拼写不同；ModuleNotFoundError 表示当前解释器找不到所导入模块；FileNotFoundError 表示给定路径下没有目标文件。读取报错时，先找到自己的文件和行号，再看错误类型与对应语句。

中文说明可以写在注释里，但代码中的括号、逗号和引号需要使用程序能识别的字符。缩进也是 Python 语法的一部分，循环、条件和函数内部的语句要保持相同缩进。

实验文件可以分为原始输入、处理代码和输出结果三个位置。原始数据保留下载时的版本，处理后的结果另存；记录 Python 与依赖版本，能够减少日后库升级带来的差异。不要把账户密钥写入可公开下载的脚本。

读取输入与保存结果

工作目录是相对路径的起点。例如程序写 prices.csv，会在当前工作目录寻找文件，不一定在脚本所在目录寻找。把原始数据放在 data 子目录时，路径应明确写成 data/prices.csv，并在第一次运行时显示解析后的绝对位置。

读取失败时，先检查文件是否确实存在、扩展名是否被隐藏、中文路径是否正确，再检查读取函数。数字文件有时使用逗号分隔，有时使用制表符。字符编码也可能不同。乱码与“找不到文件”是不同问题，不能通过反复更改模型代码解决。

一个最小实验说明可以记录五项：入口脚本、输入文件及单位、需要的库、运行后产生的文件、预期出现的关键数值。随机示例还记录随机种子。这样别人获得同一文件夹后，可以知道该运行哪一步，也能区分程序执行成功与计算结果正确。

程序输出过多时，可先显示行数、日期范围和头尾少数记录，再显示收益、持仓等核心结果。数据表另存为文件。把关键检查放在清晰位置，有助于发现下载为空、日期范围错误或数值被读成文字等问题。

鲨鱼说

关闭并重新打开程序，再按顺序运行代码，检查能否生成相同结果。如果结果变化，应检查随机种子、文件路径和未重新执行的变量。

练习

将期末价改成 97 元，股数改成 50。收益率和盈亏应分别是多少？修改后只有盈亏更新而收益率未变，应先检查什么？

查看解答

收益率为 −3%，盈亏为 −150 元。先检查两个结果是否都依赖同一个 end_price、是否重新执行了相关单元格，以及是否有旧变量覆盖新值。重新启动后按顺序运行所有单元格，可以排查旧变量的影响。
