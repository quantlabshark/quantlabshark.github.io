56 · 价格冲击与订单簿恢复

沿订单簿积分计算成交成本，比较恢复机制、分批交易和乘数冲击。

价格冲击描述订单对成交价格和后续报价的影响。订单簿恢复描述冲击随时间减弱的过程，两者共同影响分拆交易的数量与间隔。

沿着卖盘成交会支付一串价格

设未受影响卖价为 A0A_0A0​，其上每1元价格区间均匀有10000股可卖。买1000股需向上走0.1元，但不是每股都在最高价买入。额外支出等于数量—价格曲线下面积：1000×0.1/2=501000\times0.1/2=501000×0.1/2=50 元。平均每股额外0.05元，最后一股额外0.1元。

这说明“末笔价格冲击”“平均执行冲击”和“总成本”是三个不同量。若先买500股，影响衰减一半后再买500股，第一笔额外12.5元；第二笔从残余抬价0.025元起步，成本 500×0.025+12.5=25500\times0.025+12.5=25500×0.025+12.5=25 元，合计37.5元。

图中的面积就是额外支出；第二笔起点抬高形成矩形，再加该笔继续消耗深度形成的三角形。

永久、暂时和瞬态冲击

永久冲击改变后续参考价格，暂时冲击只进入当前成交价格，瞬态冲击保留一段时间再衰减。模型中区分它们，是为了确定每一笔交易会怎样影响下一笔成本。

实际成交后的涨跌还可能包含新信息和其他交易者行为。若自己的买入本来就由利好预测触发，随后上涨不能全解释为机械冲击。估计冲击时应以方向、规模、参与率、波动与状态为条件，明确参考价格和观察窗口。

import numpy as np
Q, depth, a = 1000.0, 10000.0, 0.5
def cost(trades):
    u = np.asarray(trades,dtype=float)
    index = np.arange(len(u))
    kernel = a**np.abs(index[:,None]-index[None,:])
    return u@kernel@u/(2*depth)
print('一次、两次、三次最优', cost([Q]), cost([Q/2,Q/2]), cost([400,200,400]))
print('三次等量', cost([Q/3]*3))
assert np.isclose(cost([Q]),50)
assert np.isclose(cost([Q/2,Q/2]),37.5)
assert np.isclose(cost([400,200,400]),30)

结果依次为50、37.5、30元。三笔等量约30.5556元。三笔最优400、200、400：首笔争取恢复时间，中间维持，终点完成残量。这个形状来自本例无价格风险、常数深度和固定交易时刻，加入等待风险后应重新优化。

若 a→0a\to0a→0，前后几乎不互相影响，成本取决于各笔平方和，固定笔数下等量最优；若 a→1a\to1a→1，总成本趋 Q2/(2q)Q^2/(2q)Q2/(2q)，单纯拆分不再降成本。这两个极限可检查程序中的衰减符号和交叉项。

每一笔现金流只记一次

同时保存未受影响参考价、已有偏移和本笔新增影响。若残余偏移已包含在当前报价，再作为额外冲击加一次就会重复收费。用买入后等量卖出的往返序列检查库存归零、现金守恒及成本符号，可发现冲击模型的内部错误。有些参数设定还会产生不合理的机械交易套利，应在使用前排查。

取自拟卖盘深度 f(z)=200zf(z)=200zf(z)=200z 股/元，zzz 为高于参考卖价的元数。累计深度 F(D)=100D2F(D)=100D^2F(D)=100D2。买900股需达到 D=3D=3D=3 元，额外成本为 ∫03200z2dz=1800\int_0^3 200z^2dz=1800∫03​200z2dz=1800 元；平均每股额外2元，最后成交价格偏移3元。

再买700股时，累计消耗达到1600股，偏移升为4元。本笔额外成本 ∫34200z2dz=(200/3)(64−27)≈2466.67\int_3^4 200z^2dz=(200/3)(64-27)\approx2466.67∫34​200z2dz=(200/3)(64−27)≈2466.67 元，平均每股额外约3.5238元。用最终偏移4元乘全部700股会高估，用起点3元乘全部数量又会低估。

这组深度在远端变厚，因此累计数量与价格偏移是平方关系。若数量恢复一半，DDD 变为原来的 1/21/\sqrt21/2​；若价格偏移减半，已消耗数量只剩四分之一。选择恢复变量实际上选择了流动性如何回补，不能在同一模拟中随手换用。

等待能省冲击，也会承受价格变化

前面的两笔500股例相对一次买1000股节约12.5元。若等待期间未受影响价格上涨0.04元，第二笔500股额外多付20元，合计成本反而比立即全部买入多7.5元。机械恢复收益与市场价格变化来自不同状态变量，应分别记账。

这也是执行模型需要价格预测和风险项的原因。平均恢复较快只能说明拆分有潜在流动性好处，不能保证每条实际路径都更省。比较策略时应同时看总成交数量、完成时间和各笔现金流，将等待造成的价格变动归入明确的基准成本。

1. 深度从10000变为20000股/元，固定交易序列成本怎样变化？

查看解答

在块状模型中成本与 1/q1/q1/q 成正比，因此减半。一次买1000股的末端偏移从0.1降至0.05元，总额外成本从50降至25元。
