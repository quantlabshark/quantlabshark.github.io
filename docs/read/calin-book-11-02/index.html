衰变计数与连续测量模型

区分随机存活数量、纯死亡过程和叠加测量波动的连续状态。

数量、浓度与仪器读数

衰变问题至少有三个不同变量：还存活的粒子个数、按体积归一化的浓度、仪器报告的读数。个数是非负整数且只能下降。浓度在粒子很多时可近似为连续量。仪器读数还会受到测量误差影响。先明确变量，才能判断噪声应加在真实状态还是观测方程中。

下文用 NtN_tNt​ 表示真实存活数，XtX_tXt​ 表示连续状态。参数 λ\lambdaλ 是单个粒子每单位时间的衰变率。初始有一百个粒子，并不表示整个系统每单位时间只衰变 λ\lambdaλ 个；系统的总速率还要乘当前存活数。

从独立寿命得到衰变规律

设初始有 N0N_0N0​ 个彼此独立的粒子，每个寿命为参数 λ\lambdaλ 的指数变量。一个粒子在时间 ttt 后仍存活的概率为 p=e−λtp=e^{-\lambda t}p=e−λt。因此存活总数

纯死亡链可逐事件模拟：剩余 nnn 时生成均值 1/(λn)1/(\lambda n)1/(λn) 的等待时间，再把数量减一。若只需固定时刻的分布，直接生成二项变量更高效。连续加性模型则可使用 OU 的精确转移。选择哪一种模拟取决于要复现数量、事件时刻还是测量信号。

大样本极限和末期行为

存活比例的方差为 p(1−p)/N0p(1-p)/N_0p(1−p)/N0​，所以初始数量很大时，比例曲线接近确定指数衰减；这来自独立粒子的平均作用。接近全部衰尽时，剩余数量很小，离散事件和最后几次等待就会变得突出。

因此同一个系统在不同阶段可能适合不同精度的模型。前期只关心比例趋势时确定近似较好；若研究最后一次衰变的时间，则必须保留离散等待结构。模型选择由目标统计量决定，而不只由初始数量大小决定。

初始数量一百、单粒子衰变率 0.2。阶梯线是各次试验，深色线是理论均值，阴影为均值上下 1.96 倍标准差；计数分布的精确分位数需按二项分布计算。

鲨鱼说

半衰期可能指平均曲线降到一半，也可能指某次实验首次降到一半。随机模型里必须先确定统计对象，才能选择指数曲线、等待时间求和或边界值方程。
