高频数据分析

50 · 噪声修正、双尺度与已实现核

比较双尺度、已实现核、预平均和QMLE的去噪机制，并核对同路径估计结果。

高频噪声修正利用不同采样尺度或相邻收益关系，区分有效价格波动与观测误差。双尺度、已实现核和预平均采用不同加权方式，但都需要恢复信号尺度并处理剩余偏差。

噪声偏差的分解与修正

上一课得到 E(RV)≈IV+2nη2E(RV)\approx IV+2n\eta^2E(RV)≈IV+2nη2。nnn 是收益个数，η2\eta^2η2 是每个对数价格误差的方差，IVIVIV 是整个窗口的有效积分方差。本课的不同方法都试图从含噪数据恢复这个总量；只有最后才把方差开平方，或按明确时间口径年化。

只每隔20个点取样，会丢掉其余起点的信息。可分别从第0、1、…、19个价格开始，每隔20点形成一个子网格，再平均这些网格的RV。这样使用全部价格，但仍有残留噪声，平均本身并不消除偏差。

双尺度：用细网格估噪声

设共有 KKK 个稀疏子网格，平均RV为 RVavgRV_{avg}RVavg​、平均收益数为 nˉ\bar nnˉ。细网格为 RVallRV_{all}RVall​、收益数为 nnn。由于细网格噪声约为 2nη22n\eta^22nη2，RVall/(2n)RV_{all}/(2n)RVall​/(2n) 可作为噪声方差的高频估计，于是

IV^raw=RVavg−nˉnRVall.\widehat{IV}_{raw}=RV_{avg}-\frac{\bar n}{n}RV_{all}.IVraw​=RVavg​−nnˉ​RVall​.

减去的细网格项也包含一点有效价格方差，有限样本常再除以 1−nˉ/n1-\bar n/n1−nˉ/n。例如 RVavg=0.0012,RVall=0.01,nˉ/n=0.05RV_{avg}=0.0012,RV_{all}=0.01,\bar n/n=0.05RVavg​=0.0012,RVall​=0.01,nˉ/n=0.05，先得0.0007，修正后约0.00073684。应使用实际每个子网格的收益数，不能无条件拿 1/K1/K1/K 代替比率。首尾覆盖不齐仍会产生边界误差。

已实现核利用负自协方差

定义未归一化的滞后乘积和 γh=∑i=h+1nriri−h\gamma_h=\sum_{i=h+1}^nr_ir_{i-h}γh​=∑i=h+1n​ri​ri−h​。其中 γ0\gamma_0γ0​ 就是RV。核估计写成

RK=γ0+2∑h=1Hkhγh.RK=\gamma_0+2\sum_{h=1}^{H}k_h\gamma_h.RK=γ0​+2h=1∑H​kh​γh​.

价格误差独立时，γ1\gamma_1γ1​ 的期望为负，加入它可以抵消RV的一部分正偏差。系数2来自正、负两个滞后方向。这里 γh\gamma_hγh​ 没有除以样本数，不能直接用软件默认的“样本自协方差”替换后仍保留同一公式。

核权重让远距离项逐渐减弱，带宽 HHH 决定利用多少滞后。合适的核、带宽和端点处理共同决定一致性与非负性；简单无限加大带宽会纳入很多噪声乘积。多资产情形还需保住整个矩阵的半正定结构。

鲨鱼说

协方差，即两个变量偏离各自均值时，共同变化程度的度量。

局部加权与噪声平滑

取两端为零的权重函数 ggg，对连续 KKK 个附近收益加权：rˉi=∑j=1K−1g(j/K)ri+j\bar r_i=\sum_{j=1}^{K-1}g(j/K)r_{i+j}rˉi​=∑j=1K−1​g(j/K)ri+j​。相邻价格误差会部分抵消，形成较平滑的局部增量。之后对 rˉi2\bar r_i^2rˉi2​ 求和，按 ψ2=∫01g2(u)du\psi_2=\int_0^1g^2(u)duψ2​=∫01​g2(u)du 归一化，再减去与 ψ1=∫01[g′(u)]2du\psi_1=\int_0^1[g'(u)]^2duψ1​=∫01​[g′(u)]2du 有关的噪声项。

例如三角权重 g(u)=min⁡(u,1−u)g(u)=\min(u,1-u)g(u)=min(u,1−u)，有 ψ1=1,ψ2=1/12\psi_1=1,\psi_2=1/12ψ1​=1,ψ2​=1/12。ggg 较大的位置提高有效信号权重，而变化较快的权重会把更多相邻噪声差带入估计。先平滑价格再直接套原RV公式，会把信号也缩小，却没有进行对应尺度恢复。

QMLE把差分噪声写进矩阵

假设有效方差率为常数 vvv，间隔 Δ\DeltaΔ，观测收益的协方差矩阵 Ω\OmegaΩ 主对角为 vΔ+2η2v\Delta+2\eta^2vΔ+2η2，相邻对角为 −η2-\eta^2−η2，其余为0。对三个收益就是

Ω=(vΔ+2η2−η20−η2vΔ+2η2−η20−η2vΔ+2η2).\Omega=\begin{pmatrix}v\Delta+2\eta^2&-\eta^2&0\\-\eta^2&v\Delta+2\eta^2&-\eta^2\\0&-\eta^2&v\Delta+2\eta^2\end{pmatrix}.Ω=​vΔ+2η2−η20​−η2vΔ+2η2−η2​0−η2vΔ+2η2​​.

高斯负对数似然去掉常数后为 L=12[log⁡det⁡Ω+r⊤Ω−1r]L=\frac12[\log\det\Omega+r^\top\Omega^{-1}r]L=21​[logdetΩ+r⊤Ω−1r]。第一项反映模型给出的总体分散程度，第二项衡量观测收益相对该协方差有多大。同时选择 v,η2v,\eta^2v,η2 使 LLL 最小，便可区分有效波动与价格噪声。

在合适的矩条件与模型设定下，即使噪声不严格正态，也可使用准似然估计；有效波动随时间变化时，常数方差率参数对应窗口平均 IV/TIV/TIV/T。这一解释依赖具体渐近条件，不能推广到任意相关或内生噪声。

在同一路径上比较结果

以下自拟模拟设 T=1,v=0.04,η2=0.0001,n=400T=1,v=0.04,\eta^2=0.0001,n=400T=1,v=0.04,η2=0.0001,n=400。先生成有效价格，再加噪声；双尺度取 K=20K=20K=20，QMLE用明确的二维网格搜索。

Python25 行
import numpy as np
rng = np.random.default_rng(50)
n, T, true_v, noise_var = 400, 1.0, 0.04, 0.0001
x = np.r_[0., np.cumsum(rng.normal(0, np.sqrt(true_v/n), n))]
y = x + rng.normal(0, np.sqrt(noise_var), n+1)
r = np.diff(y)
K = 20
rv = np.array([np.sum(np.diff(y[j::K])**2) for j in range(K)])
nbar = np.mean([len(y[j::K])-1 for j in range(K)])
all_rv = r@r
ts = (rv.mean() - nbar/n*all_rv)/(1-nbar/n)
# 三对角噪声矩阵的特征值、正交正弦基
j = np.arange(1, n+1)
U = np.sqrt(2/(n+1))*np.sin(np.pi*np.outer(j,j)/(n+1))
eigen_noise = 2-2*np.cos(np.pi*j/(n+1))
z2 = (U.T@r)**2
best = (np.inf, None, None)
for v in np.linspace(0.01, 0.08, 71):
    for eta2 in np.linspace(0.00002, 0.0002, 73):
        eig = v*T/n + eta2*eigen_noise
        loss = 0.5*np.sum(np.log(eig)+z2/eig)
        if loss < best[0]:
            best = (loss, v, eta2)
print('真实 IV、原始 RV、双尺度', true_v*T, all_rv, ts)
print('QMLE 方差率、噪声方差', best[1:])

结果为原始RV约0.11855、双尺度约0.03462、QMLE积分方差约0.043，真实IV为0.04。QMLE噪声方差约0.000095。两个修正都明显减小这次样本的正偏，但单条路径不足以评价哪一个方法长期误差最小。

代码将三对角噪声矩阵用正交正弦基对角化。其特征值为 2−2cos⁡[πj/(n+1)]2-2\cos[\pi j/(n+1)]2−2cos[πj/(n+1)]，因此行列式变成特征值乘积，取对数后变成求和。二次型也变成变换后收益平方除以各特征值的和。这样避免直接构造逆矩阵。最优点若落在搜索边界，应扩大范围并检查目标曲面。

用相同实验评价估计方法

重复生成许多路径，分别计算偏差 E(IV^)−IVE(\hat{IV})-IVE(IV^)−IV 与均方误差 E[(IV^−IV)2]E[(\hat{IV}-IV)^2]E[(IV^−IV)2]；前者只看系统方向，后者还计入估计波动。真实数据没有可观察的IV，应再看不同采样频率的稳定程度，以及它对未来风险的预测表现。

去偏后偶尔得到负值可能是有限样本波动。展示波动率前可另行说明如何处理，但应保留未截断估计用于诊断。直接把所有负值改成零，会改变偏差和分布，不能再用原估计的误差结论。

一个带权窗口的实际计算

取四个收益 0.001,−0.002,0.003,00.001,-0.002,0.003,00.001,−0.002,0.003,0，使用三角权重在 K=4K=4K=4 时的值0.25、0.5、0.25，对前三个收益预平均，得到 0.25×0.001+0.5×(−0.002)+0.25×0.003=00.25\times0.001+0.5\times(-0.002)+0.25\times0.003=00.25×0.001+0.5×(−0.002)+0.25×0.003=0。相邻波动在加权后抵消，所以预平均平方为0，不代表这段有效方差就是0。

如果这三个有效增量独立、方差都为 vΔv\DeltavΔ，加权和的方差为 (0.252+0.52+0.252)vΔ=0.375vΔ(0.25^2+0.5^2+0.25^2)v\Delta=0.375v\Delta(0.252+0.52+0.252)vΔ=0.375vΔ。把它直接与三个普通增量平方和的期望 3vΔ3v\Delta3vΔ 比较，会差一个尺度。预平均估计中的归一化就是为恢复这种被权重改变的信号量，重叠窗口还会带来窗口间相关。

噪声参数如何由相邻收益约束

设样本平均收益平方为0.00024，相邻收益乘积平均为−0.00010。在常方差独立噪声模型下，后一项提示 η2≈0.00010\eta^2\approx0.00010η2≈0.00010。前一项扣除两倍噪声后，vΔ≈0.00004v\Delta\approx0.00004vΔ≈0.00004。若间隔 Δ=0.001\Delta=0.001Δ=0.001，便得 v≈0.04v\approx0.04v≈0.04。这是矩方法的直观计算，QMLE则同时利用整组收益的联合结构。

若反推 vΔv\DeltavΔ 为负，可能只是小样本误差，也可能提示噪声结构不对。此时应比较数据定义和残差，而不是随意调整一个数使结果变正。做模拟评价时也可把所有估计保留，分别报告负值比例与调整后的风险用途。

带宽会同时改变偏差与方差。用同一条路径尝试很多带宽并选择最接近未知真值的一个在真实数据中不可行；模拟可以知道真值，真实使用则应预先固定规则，或在独立窗口按预测目标选择。

2. 平均多个稀疏网格后，为什么还要减去细网格项？

查看解答

平均降低抽样波动，却保留每个稀疏收益的价格噪声方差。其期望仍约含 2nˉη22\bar n\eta^22nˉη2。细网格提供噪声尺度，按 nˉ/n\bar n/nnˉ/n 缩放后才能扣除这项偏差。
