普通时间积分为何保留路径信息

但某些被积函数的组合可以有意消去路径项。例如 Wt2−tW_t^2-tWt2​−t 中的确定项贡献 ∫tdW\int tdW∫tdW，它与立方公式中的时间积分相抵。选择这种组合的过程，与构造无漂移多项式鞅具有相同代数结构。

横轴为时间加权的随机积分，纵轴为布朗路径的普通时间积分，观察时长为二。它们方差相同、相关系数为二分之一，散点并不落在一条直线上。
