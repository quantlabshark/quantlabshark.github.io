23.3 指数基金、ETF、期货与期权

比较不同指数工具的交易方式、资金占用和风险结构，并理解整篮子成交。

风险转移目标与对冲工具

同一个指数可以对应多种产品，但这些产品的持有方式不同。买基金份额取得组合资产的经济敞口；期货通过合约约定承担价格变动，使用保证金；期权则赋予在约定条件下买卖或取得现金结算的权利，收益是非线性的。

“跟踪同一个指数”并不意味着相同本金可以买到相同风险。保证金只是履约担保，不是期货合约全部风险的价值。比较产品时，应先换算成指数名义敞口，再比较费用、资金需求、期限和极端损失。

开放式指数基金与ETF

传统开放式指数基金主要按规定的净值进行申购和赎回。基金管理人要处理投资者进出带来的现金，需要时买卖底层证券；现金缓冲和交易费用会影响跟踪效果。投资者不能把它当成随时按屏幕报价成交的股票。

ETF份额可以在二级市场像股票一样交易，成交价由买卖订单形成。同时，具备相应资格和规模的参与者可以按产品机制用一篮子证券或约定资产申购份额，或赎回对应资产。二级市场价格明显高于底层组合价值时，创建份额并卖出的交易可能形成约束。明显低于时，买入并赎回可能形成约束。

这一约束需要申赎、融资和底层资产交易可以实施。价格与净值估计的差异不一定是立即可实现的利润：底层资产休市、报价陈旧、成本较高或交付受限时，差异可能扩大。对初学者而言，应分别识别基金净值、盘中参考价值和实际成交价。

期货的期限与保证金

指数期货通常提供较便捷的多空风险敞口，但持仓会受到每日结算和保证金要求影响。长期保持敞口需要在合约到期前后处理展期，展期时还涉及价差、交易费用和流动性。期货价格与现货价格的差异与融资、分红和期限有关，不能单纯把较高的期货价格解释为预测指数上涨。

自拟算例：指数为4000点，合约乘数为每点50元，一张合约名义价值20万元。指数下跌2%，一张多头合约价格损失约4000元，尚未计入基差变化和费用。如果初始只交2万元保证金，这笔损失相当于保证金的20%，并不是风险只下跌2%就很小。

鲨鱼说

基差，即按约定顺序计算的现货与期货价格之差，具体符号取决于所用定义。

期权与整体组合交易

指数看跌期权可在下跌时获得保护，保护需要支付权利金。它与动态卖出期货模拟保护不同：期权将部分交易和尾部风险通过合约交给卖方，动态复制则要求未来能够按需要持续交易。两者都需要付出成本，只是成本表现形式不同。

整篮子买卖则是执行方式。客户向组合交易商提供组合的规模、行业、贝塔、平均成交量、波动等描述，交易商据此估计处理成本并报价。组合名称披露过早可能泄露交易意图，披露过少又会使交易商难以评估风险。报价流程就在这两者之间安排。

选择指数工具时，可依次明确持有期限、是否需要盘中成交、是否使用杠杆、能否管理保证金、是否需要非线性保护以及允许多大的跟踪偏离。税费、准入和合约细则，应以对应产品在研究时点的有效条款为准。
