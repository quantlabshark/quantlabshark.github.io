Black–Scholes 与其他模型

1. Black–Scholes 与其他模型

题目

无分红股票当前价 S0S_0S0​，欧式期权执行价 KKK、到期时间 TTT，无风险连续复利率 rrr、常数波动率 σ\sigmaσ。说明 Black–Scholes 定价的假设和主要推导，写出看涨价格与看跌平价，并比较二叉树、蒙特卡洛和有限差分方法。

考点：无套利；定价方程；数值方法选择。

查看分析与解答

必要知识

欧式看涨在到期支付 (S_T−K)⁺。Black–Scholes 用连续股价模型与动态交易复制这一支付；真实漂移 μ 描述现实平均变化，定价中的 r 来自无风险组合收益要求。数值方法是求同一个定价问题的不同计算途径。

分析思路

先推导风险抵消为何消去 μ，再给公式与平价。选择数值方法时，依据支付是否路径依赖、维度多高、能否提前行权，而不是按算法名称泛泛比较。
