22.2 用统计检验区分能力与运气

解释标准误、显著性与检验功效，并计算识别微弱超额收益所需的时间。

过去表现好需要满足什么条件

过去盈利要对未来有预测价值，至少要满足三个条件：过去的好成绩确实包含能力。这种能力在新的市场环境下仍然有用。产生能力的团队、资源和流程仍然存在。某类交易机会消失，或核心人员离开，都会使同一条历史净值曲线失去原来的含义。

统计检验主要处理第一个条件。它考察：如果管理人没有超额能力，仅靠随机波动，出现当前结果是否罕见。它不能单独回答策略今后是否失效，也不能证明团队会保持原有水平。

平均收益的误差有多大

设每期风险调整收益为xtx_txt​，共nnn期，样本均值为xˉ\bar xxˉ，样本标准差为sxs_xsx​。若观测近似独立且分布稳定，均值标准误约为sx/ns_x/\sqrt nsx​/n​，t统计量为

t=xˉsx/n.t=\frac{\bar x}{s_x/\sqrt n}.t=sx​/n​xˉ​.

分子是估计出的平均超额收益，分母是这个均值本身的不确定程度。标准差描述单期收益多变，标准误描述对长期平均值估计得多不准。二者不是同一个量。

显著性水平5%的单侧检验，在“没有正超额能力”的假设成立时，允许大约5%的误报概率。这不等于“通过检验者有95%的概率具备能力”。后一个概率还依赖真正有能力者所占比例和检验识别能力。

检验功效指确实存在某个给定水平的能力时，检验能将其识别出来的概率。把阈值调得很高，误报减少，但真正有能力者也更容易被漏掉。能力弱、随机波动大、观察时间短，都会降低功效。

为什么多取日频数据不能替代十年历史

在独立、稳定的近似下，设年均超额收益为μ\muμ，年化残差波动率为σ\sigmaσ，观察TTT年，则信号强度约为μT/σ\mu\sqrt T/\sigmaμT​/σ。若μ=2%\mu=2\%μ=2%、σ=7%\sigma=7\%σ=7%，五年的信号强度只有约0.64，仍远低于常用的单侧正态临界值1.645。

在大样本正态近似下，达到5%显著性水平、75%检验功效所需的年数为

T≈[(z0.95+z0.75)σμ]2.T\approx\left[\frac{(z_{0.95}+z_{0.75})\sigma}{\mu}\right]^2.T≈[μ(z0.95​+z0.75​)σ​]2.

这组自拟参数得到约66年。将五年的月收益改成日收益，并没有将五年变成几十年。更高频数据可改善部分波动估计，但收益信号积累所经历的经济时间没有增加，而且还可能引入更强的序列相关。

Python12 行
# 正态近似演示，参数为教学设定，不是某基金的实测业绩
from statistics import NormalDist
from math import sqrt
normal = NormalDist()
mu, sigma = 0.02, 0.07
critical = normal.inv_cdf(0.95)
for years in [1, 5, 10, 20]:
    power = 1 - normal.cdf(critical - mu * sqrt(years) / sigma)
    print(years, '年，功效', round(power, 4))
required = ((critical + normal.inv_cdf(0.75)) * sigma / mu) ** 2
print('达到 75% 功效所需年数:', round(required, 1))
assert 65 < required < 67

图中年超额收益设为 2%，年残差波动为 7%，使用单侧 5% 显著性水平。达到 75% 功效需要约 66 年；增加同一年内的采样频率，不能替代新增的独立年度信息。

降低噪声与决定是否采用策略

合适的基准和因子模型能解释一部分共同波动，提高检验精度；但把管理人主动获取的某类因子收益全部控制掉后，检验回答的是“控制这些暴露后是否仍有增值”。因此必须先说明评价对象。

统计显著也不等于经济上值得采用。净收益还要扣除管理费、交易费和选择管理人的成本。误选高成本管理人的损失、错过真正优秀策略的损失以及低成本替代方案的收益，都影响决策阈值。低信噪比会提高筛选成本，因此比较主动管理与指数化时，应同时计入净收益、识别能力所需的时间和选择成本。

如果收益存在序列相关，简单的标准误公式还需调整。重复观测相近的风险状态，并不产生同样多的独立证据，报告样本长度时应说明时间频率和依赖结构。

练习

在其他条件不变时，将年均超额收益从2%提高到4%，达到同样检验目标所需时间如何变化？

查看解答

所需时间与1/μ21/\mu^21/μ2成正比，能力加倍，时间降为原来的四分之一。这个结果建立在波动、独立性和能力持续性不变的模型假设上。
