Bootstrap、参数不确定性与 NPEB

把估计误差纳入组合风险，理解重抽样组合、预测二阶矩与非参数经验贝叶斯方法。

权重也是一个估计结果

给定两只股票，组合权重写成 w=(w1,w2)⊤w=(w_1,w_2)^\topw=(w1​,w2​)⊤。通常先估计收益均值和协方差，再把估计值放入优化器。这个过程容易忽略一项风险：换一段历史样本，估计出的均值会变，持仓也会变。

设历史数据为 DDD，下一期资产收益为 rrr，组合收益为 W=w(D)⊤rW=w(D)^\top rW=w(D)⊤r。这里的随机性有两个来源：下一期市场变化，以及用于决定持仓的样本变化。假如某次抽样把资产一的均值高估了，优化器可能集中买入它。这种集中本身就是估计误差的后果。

条件均值和协方差记作 μD=E(r∣D)\mu_D=E(r\mid D)μD​=E(r∣D)、ΣD=Cov⁡(r∣D)\Sigma_D=\operatorname{Cov}(r\mid D)ΣD​=Cov(r∣D)。全方差公式给出

Var⁡(W)=E{w(D)⊤ΣDw(D)}+Var⁡{w(D)⊤μD}.\operatorname{Var}(W)=E\{w(D)^\top\Sigma_Dw(D)\}+\operatorname{Var}\{w(D)^\top\mu_D\}.Var(W)=E{w(D)⊤ΣD​w(D)}+Var{w(D)⊤μD​}.

第一项是给定持仓后的市场风险，第二项是不同样本产生不同预期组合收益的风险。直接对一组估计值求最优权重，没有自动计入第二项。

鲨鱼说

协方差，即两个变量偏离各自均值时，共同变化程度的度量。

重抽样需要重新估计权重

Bootstrap 的操作是从已有样本中有放回地抽取一份同样大小的数据。对每一份重抽样数据，重新估计均值、协方差和最优权重，重复 BBB 次。若只对一组固定权重的收益重抽样，测量的是该组合的收益波动，不能反映选权重的过程。

把这 BBB 个权重取平均，可以得到重抽样平均组合。它通过平均减少极端持仓，但平均权重一般不等于某个均值方差问题的精确最优解。若收益存在时间依赖，应按连续时间块抽样，不能把相邻交易日的关系随意打乱。

用预测二阶矩重写目标

考虑目标 max⁡E(W)−λVar⁡(W)\max E(W)-\lambda\operatorname{Var}(W)maxE(W)−λVar(W)，其中 λ>0\lambda>0λ>0 表示风险厌恶。设

VD=E(rr⊤∣D)=ΣD+μDμD⊤.V_D=E(rr^\top\mid D)=\Sigma_D+\mu_D\mu_D^\top.VD​=E(rr⊤∣D)=ΣD​+μD​μD⊤​.

注意 VDV_DVD​ 是二阶矩，不能直接替换为协方差。原目标包含 [E(W)]2[E(W)]^2[E(W)]2，使各数据情形下的决策相互关联。可以引入标量 η\etaη，先求一族条件二次优化问题

min⁡w: 1⊤w=1 λw⊤VDw−ηw⊤μD,\min_{w:\,\mathbf1^\top w=1}\ \lambda w^\top V_Dw-\eta w^\top\mu_D,w:1⊤w=1min​ λw⊤VD​w−ηw⊤μD​,

再比较这一族决策在原目标下的表现。对内部最优解，η=1+2λE(W)\eta=1+2\lambda E(W)η=1+2λE(W)；实际计算可在一组候选 η\etaη 上搜索。

当 VDV_DVD​ 正定且没有卖空限制时，记 A=1⊤VD−1μDA=\mathbf1^\top V_D^{-1}\mu_DA=1⊤VD−1​μD​、C=1⊤VD−11C=\mathbf1^\top V_D^{-1}\mathbf1C=1⊤VD−1​1，拉格朗日一阶条件得到

w(η)=VD−11C+η2λVD−1(μD−AC1).w(\eta)=\frac{V_D^{-1}\mathbf1}{C}+\frac{\eta}{2\lambda}V_D^{-1}\left(\mu_D-\frac AC\mathbf1\right).w(η)=CVD−1​1​+2λη​VD−1​(μD​−CA​1).

第一项满足预算约束，第二项的权重和为零，用于调整收益暴露。有非负持仓或单资产上限时，应直接解带约束的二次规划。

条件风险与重复抽样风险要分清

在已经看到当前数据 DDD 后，交易者实际采用的权重是一个确定向量。此时不确定性仍可来自未知参数。例如未知均值为 μ\muμ，若给定参数的收益协方差为 Σ\SigmaΣ，则

Cov⁡(r∣D)=E(Σ∣D)+Cov⁡(μ∣D).\operatorname{Cov}(r\mid D)=E(\Sigma\mid D)+\operatorname{Cov}(\mu\mid D).Cov(r∣D)=E(Σ∣D)+Cov(μ∣D).

第一项是市场自身的波动，第二项是参数估计的不确定性。假设一项资产的市场方差为 0.00040.00040.0004，均值后验方差为 0.00010.00010.0001，预测方差就是 0.00050.00050.0005。不能把后验均值当成已知常数而仅留下 0.00040.00040.0004。

前面的全方差分解则站在重复取得训练样本的角度，评价整条决策规则 w(D)w(D)w(D)。两种条件化层次不同：一项讨论当前持仓面对的预测分布，另一项讨论换一份训练数据后方法会怎样变化。实际计算应先说明采用哪一层，避免把同一项参数风险加两次。

两种参数情形怎样合成预测风险

设当前信息下有两个等权的参数情形。情形 A 中组合下一期收益 WWW 的条件均值为 0，情形 B 中为 4%；两个情形的条件方差均为 0.00010.00010.0001。整体均值为 μˉ=(0+0.04)/2=0.02\bar\mu=(0+0.04)/2=0.02μˉ​=(0+0.04)/2=0.02。

平均的条件方差为 0.0001；条件均值自身的方差为

12(0−0.02)2+12(0.04−0.02)2=0.0004.\frac12(0-0.02)^2+\frac12(0.04-0.02)^2=0.0004.21​(0−0.02)2+21​(0.04−0.02)2=0.0004.

故预测总方差为 0.0001+0.0004=0.00050.0001+0.0004=0.00050.0001+0.0004=0.0005，标准差约 2.2361%。如果只把条件均值 2% 与条件方差 0.0001 放进优化器，报告的标准差就只有 1%，遗漏了参数情形之间的差异。

二阶矩也能得到同一答案：E[W2]=(0.0001+02)/2+(0.0001+0.042)/2=0.0009E[W^2]=(0.0001+0^2)/2+(0.0001+0.04^2)/2=0.0009E[W2]=(0.0001+02)/2+(0.0001+0.042)/2=0.0009，减去整体均值平方 0.0220.02^20.022，得到 0.0005。这里 E[W2]E[W^2]E[W2] 与 Var⁡(W)\operatorname{Var}(W)Var(W) 的差别就是均值平方。

为什么引入标量参数

将目标展开为 E(W)−λE(W2)+λ[E(W)]2E(W)-\lambda E(W^2)+\lambda[E(W)]^2E(W)−λE(W2)+λ[E(W)]2。若规则发生微小变化 W↦W+ϵHW\mapsto W+\epsilon HW↦W+ϵH，在 ϵ=0\epsilon=0ϵ=0 处的导数为 E[(1+2λE(W)−2λW)H]E[(1+2\lambda E(W)-2\lambda W)H]E[(1+2λE(W)−2λW)H]。因此最优规则可在 η=1+2λE(W)\eta=1+2\lambda E(W)η=1+2λE(W) 对应的二次问题族中寻找。

每个固定 η\etaη 的条件问题容易求解，但 η\etaη 又依赖整条规则的期望收益，所以要回到原目标比较候选值。它是连接条件决策与总体目标的辅助参数，不是新增的经济信号。

鲨鱼说

预测均值为 1% 时，还需要描述该估计随样本变化的幅度。经验贝叶斯和重抽样的作用，是把这种不确定性带进选择仓位的过程。

非参数经验贝叶斯的计算含义

非参数经验贝叶斯方法用经验分布描述未知收益分布，以样本信息构造预测矩，再把估计不确定性带入决策。它与只平均重抽样权重的方法不同：评价对象是“看到一份数据后怎样持仓”这一决策规则。

下面的数值实验采用两只资产、有限的 η\etaη 网格和经验分布重抽样。每次抽样重新求权重，再从同一经验分布抽取下一期收益，估计各规则的 E(W)E(W)E(W) 和 Var⁡(W)\operatorname{Var}(W)Var(W)。这说明计算结构。另留一段时间数据，才能评价规则在新时期的表现。

鲨鱼说

“样本中的最优组合”和“用样本选组合的好方法”是两个问题。前者固定一份样本求权重，后者还要考虑换一份样本后会选成什么样。

练习

设两种训练样本出现概率各为 1/21/21/2。对应组合的条件均值为 000 和 0.020.020.02，条件方差均为 0.00040.00040.0004。求总体方差，并说明只平均条件方差会漏掉什么。

查看解答

总体均值为 0.010.010.01。条件均值的方差为 [(0−0.01)2+(0.02−0.01)2]/2=0.0001[(0-0.01)^2+(0.02-0.01)^2]/2=0.0001[(0−0.01)2+(0.02−0.01)2]/2=0.0001，因此总体方差为 0.0004+0.0001=0.00050.0004+0.0001=0.00050.0004+0.0001=0.0005。忽略训练样本变化会少算 20%20\%20% 的总体方差。这里新增的风险来自不同样本导致的不同预期收益，而不是同一组合内部的价格波动。
