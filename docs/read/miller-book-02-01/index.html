操作次数与渐近复杂度

建立操作次数模型，推导线性、平方和对数增长，区分最坏、平均与摊还成本。

对同一程序增加输入规模，执行时间往往随之增长。算法分析先选定规模 n，再数主要操作执行多少次，从而说明增长来自哪里。

操作次数模型

逐项累加 n 个数，循环执行 n 次。若每轮成本为 a，初始化和返回成本为 b，则 T(n)=an+bT(n)=an+bT(n)=an+b。这里暂按固定精度数值的加法为常数成本；若整数位数也随问题增长，应另计位运算成本。

大 O 表示渐近上界：存在常数 c>0、n0n_0n0​，使 n≥n0n\ge n_0n≥n0​ 时 T(n)≤cg(n)T(n)\le cg(n)T(n)≤cg(n)，记为 T(n)=O(g(n))T(n)=O(g(n))T(n)=O(g(n))。大 Ω 表示下界，同时满足上下界则记为 Θ。线性函数也是 O(n²)，但 Θ(n) 更准确地描述其增长阶。

循环总次数要相加

若外层 i 从 0 到 n−1，内层 j 从 0 到 i−1，内层共执行

∑i=0n−1i=n(n−1)2.\sum_{i=0}^{n-1}i=\frac{n(n-1)}2.i=0∑n−1​i=2n(n−1)​.

可将正序和倒序两行相加，每列都是 n−1，共 n 列，除以 2 得此式。因此该程序为 Θ(n²)。两个先后执行、各 n 次的循环则总共 2n 次，为 Θ(n)。是否嵌套以及每层边界，才决定总工作量。

对数来自反复折半

k 次折半后剩余规模约为 n/2kn/2^kn/2k。缩至 1 需 2k≥n2^k\ge n2k≥n，所以 k 约为 log⁡2n\log_2 nlog2​n。当 n=1024，只需约 10 次；n 扩大到约一百万，约需 20 次。

常见增长顺序为 1,log⁡n,n,nlog⁡n,n2,2n,n!1,\log n,n,n\log n,n^2,2^n,n!1,logn,n,nlogn,n2,2n,n!。n 翻倍时，线性项翻倍，平方项变为四倍，对数项只增加常数。不同机器会改变运行常数，通常不改变这些增长关系。

最好、最坏和平均需要不同的条件

顺序查找在第一项命中时只比较一次；未找到时比较 n 次；若每个位置等可能且保证找到，平均比较次数为

1+2+⋯+nn=n+12.\frac{1+2+\cdots+n}{n}=\frac{n+1}{2}.n1+2+⋯+n​=2n+1​.

平均分析使用了明确的概率模型。摊还分析则对一串操作的总成本取平均，不要求随机输入。动态数组的某次扩容可能复制 n 个元素，但多次追加的摊还成本仍可为常数。

空间也随实现变化

累计求和只需一个累计值，额外空间 O(1)。递归求和可能保留 n 层调用帧，占 O(n)；每层再切片，会增加复制成本。分析中应说明是否包含输入存储，以及是否把调用栈计入。

鲨鱼说 先数步骤，再去掉低阶项。仅凭代码里出现两个 for 或调用一次函数，无法判断复杂度；函数内部做了多少工作也要计算。
