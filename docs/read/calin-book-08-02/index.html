分布计算的两条路线

有显式状态表达式时，可以从已知正态变量的函数出发求分布；只有积分表达式时，可以先求矩或特征函数。两种路线的适用条件不同。平方布朗终点可用卡方分布，而一般路径积分不能只把被积过程替换成终点状态。

如果随机系数依赖另一个与驱动噪声独立的过程，给定该系数路径后，积分有时是条件正态；取消条件后则成为正态混合，方差本身随机。这种分布通常比固定方差正态更厚尾，因此“条件正态”也不能直接缩写为“正态”。
