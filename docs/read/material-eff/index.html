订单簿特征与波动率预测

艾方：订单簿特征与波动率预测，按原资料主题整理。

数据与任务

使用订单簿数据 order_book.parquet 和目标表 y_label.csv，预测下一段 10 分钟的已实现波动率。订单簿字段为股票 stock_id、时间段 time_id、段内秒数 seconds_in_bucket，以及两档买卖价 bid1,bid2,ask1,ask2 和对应数量 bsize1,bsize2,asize1,asize2。段内秒数范围为 0—599，记录间隔约 3 秒但不规则。time_id 本身不保证按时间排序。

以下先计算单档指标，再构造分组特征并比较预测模型；样例程序使用人工小数据检查计算。

1. 相对买卖价差

题目

订单簿每行含股票 stock_id、时间段 time_id、段内秒数 seconds_in_bucket、一档买卖价 bid1,ask1 与数量 bsize1,asize1。每段为 600 秒，报价间隔不规则。按 s=ask1/bid1−1s=\mathrm{ask1}/\mathrm{bid1}-1s=ask1/bid1−1 计算相对价差，比较各股票的价差分布，以及段内前、后五分钟的差异。

考点：基点；持续时间权重；配对比较。

查看分析与解答

必要知识

相对价差把价差除以买价，便于比较不同价格水平的股票。一个基点为0.0001，即0.01%。报价更新频率不均时，逐条平均与随机时刻面对的平均盘口不是同一统计量。

分析思路

先做报价合法性与时间排序，分别形成股票、时间段及半段统计。前后半段使用同段配对差，再比较记录权重和持续时间权重口径。

解答步骤

价差2基点持续9秒、10基点持续1秒，记录均值为6基点，时间均值却为(2×9+10×1)/10=2.8基点。若某报价从290秒持续到310秒，应在300处切开，前后各计10秒，不能把整段持续时间归到一边。

先检查买价为正、卖价不低于买价，股票与时间段内按秒排序。相对价差为 (ask1−bid1)/bid1(\mathrm{ask1}-\mathrm{bid1})/\mathrm{bid1}(ask1−bid1)/bid1；买价 100、卖价 100.02 时为 0.0002，即 2 个基点。

将前五分钟定义为 [0,300)[0,300)[0,300)、后五分钟为 [300,600)[300,600)[300,600)，按股票和时间段分别统计中位数、均值、上下分位数及样本数，再对同一段的前后值作配对比较。这样可以减少不同股票长期流动性差异对比较的干扰。

记录均值给每条报价相同权重，频繁更新的状态权重更大。若研究一个随机时刻会面对怎样的价差，应使用保持前值的持续时间作为权重：sˉ=∑siΔti/∑Δti\bar s=\sum s_i\Delta t_i/\sum\Delta t_isˉ=∑si​Δti​/∑Δti​。分段边界处需切开持续时间，缺少前置报价的开头区间不应未经说明就前填。

输出可用各股箱线图或经验分布，以及每段后半减前半的差值图；图外标明使用记录权重还是时间权重。

可为每个股票时间段输出前半均值、后半均值、后减前、有效覆盖秒数和记录数。再对配对差画分布并按股票汇总，避免高频更新股票因记录更多而自动获得更大权重。缺开头报价时只统计已知覆盖区间，并保留覆盖率。

同类问题

高频描述统计先确定抽样单位是事件还是时间。比较两组时优先配对相同股票和时段，明确剩余差异与权重。

2. 盘口量差

题目

一档卖量为 a≥0a\ge0a≥0、买量为 b≥0b\ge0b≥0，定义盘口量差 I=(a−b)/[0.5(a+b)]I=(a-b)/[0.5(a+b)]I=(a−b)/[0.5(a+b)]。求取值范围、解释符号，给出 a=300,b=100a=300,b=100a=300,b=100 的值，并说明 a+b=0a+b=0a+b=0 时的处理。

考点：差额归一化；范围；空盘口。

查看分析与解答

必要知识

分母是一半总展示量，因此本题指标等于普通差额比例的两倍。符号用卖减买，与不少买减卖定义相反，建模前必须固定约定。

分析思路

把式子化成2(a−b)/(a+b)，用非负数量证明范围，再检查单侧为空、双侧相等及双侧全空三个边界。

解答步骤

因为−(a+b)≤a−b≤a+b，总量正时可除分母得−2≤I≤2。a=300、b=100，差额200、平均量200，所以I=1；不是说卖量仅比买量高一倍，而是这一特定归一化尺度的数值。

总量为正时，I=2(a−b)/(a+b)I=2(a-b)/(a+b)I=2(a−b)/(a+b)。因 ∣a−b∣≤a+b|a-b|\le a+b∣a−b∣≤a+b，范围为 [−2,2][-2,2][−2,2]。只有卖量为零时为 -2，只有买量为零时为 2，买卖量相等时为零。

本定义用卖减买，所以正值表示卖侧展示量更多。a=300,b=100a=300,b=100a=300,b=100 时，I=200/200=1I=200/200=1I=200/200=1。若采用常见的 (b−a)/(a+b)(b-a)/(a+b)(b−a)/(a+b)，同一盘口会得到 -0.5；两种指标符号相反、尺度差两倍，混用会使模型解释反向。

当总量为零时，盘口并没有提供可比较的展示量，比例未定义，应记缺失并另保留“空盘口”标记。直接填零会把空盘口误写成双侧平衡。挂单量还可能撤销，因此量差描述的是观测时刻的展示深度，不等同于未来成交方向。

a=0、b>0给−2；a>0、b=0给2；a=b>0给零。a=b=0时0/0未定义，应与真正买卖均衡区分。若换成J=(b−a)/(a+b)，关系为J=−I/2，可明确转换已有特征。

同类问题

比例指标先检查方向、缩放与零分母。把缺失填零可能把“没有信息”误成“中性信息”，宜另保留状态标记。

3. 价差与量差的动态

题目

在同一股票、同一 10 分钟时间段内，研究相对价差和盘口量差的变化及二者关系。说明差分、滞后、采样间隔、跨段处理和汇总权重，并给出一项可执行的统计分析。

考点：水平与变化；滞后定义；事件时钟。

查看分析与解答

必要知识

价差水平大并不表示正在扩大，量差水平高也不表示刚增加。差分描述相邻变化；滞后关系还需说明相邻是一条事件还是固定秒数。

分析思路

在股票与时间段内部排序差分，先描述变化分布，再把当前量差变化配到未来价差变化。固定秒网格结果与事件序号结果分开报告。

解答步骤

若在10秒与30秒记录价差，差分覆盖20秒；另一次相邻记录只间隔1秒，两者不能直接称为相同“一秒变化”。固定秒网格可保持前一已知报价，但无前置报价的开头仍缺失。段间先后未知时，每段第一差分应清空。

先按股票、时间段、秒数排序，计算 Δsi=si−si−1\Delta s_i=s_i-s_{i-1}Δsi​=si​−si−1​、ΔIi=Ii−Ii−1\Delta I_i=I_i-I_{i-1}ΔIi​=Ii​−Ii−1​。每段首条记录没有段内前值，差分置缺失。未知时间段先后关系时不能直接把上一段末条作为下一段前值。

先分别查看两种差分的分布、零值比例和绝对变化分位数，再在相同有效记录上计算 Corr⁡(Δsi,ΔIi)\operatorname{Corr}(\Delta s_i,\Delta I_i)Corr(Δsi​,ΔIi​)。进一步研究先后关系时，可比较量差变化与下一次价差变化，但必须将因变量向后移，避免把同一时刻关系说成预测关系。

不规则采样下“一条记录之后”可能是 1 秒也可能是 20 秒。可先以事件序号报告，再在固定秒网格上按前值持有重采样，比较不同滞后秒数的相关。汇总到股票时先分别计算每股指标，再说明是否等权。直接池化会使记录多的股票占更大权重。

一个可执行输出是：每股差分统计表、量差变化分箱后的下一秒价差变化均值及样本数，再按时间段留出检验该形状是否持续。

可把ΔI按训练段分位切为五组，统计每组下一秒Δs的均值、标准差及样本数，再在留出时段用相同切点复算。若只报告同期Corr(ΔI,Δs)，应称共同变化，不能称量差预测了价差。

同类问题

动态研究先明确时钟、滞后和跨段规则。分箱图应同时显示样本量，避免少量极端事件制造貌似清晰的预测形状。

4. WAP 与已实现波动率

题目

按对侧挂单量加权计算 WAP=(bid1 asize1+ask1 bsize1)/(asize1+bsize1)\mathrm{WAP}=(\mathrm{bid1}\,\mathrm{asize1}+\mathrm{ask1}\,\mathrm{bsize1})/(\mathrm{asize1}+\mathrm{bsize1})WAP=(bid1asize1+ask1bsize1)/(asize1+bsize1)。在每个股票、时间段内，用相邻 WAP 的对数收益平方和平方根计算 RV。实现分组特征程序，并说明单条记录、空盘口和前后半段的归属方式。

考点：对侧深度加权；对数收益；平方可加。

查看分析与解答

必要知识

WAP用对侧量给报价加权：买盘厚时卖价权重大，价格更靠近卖方。RV不是收益标准差，而是一个观察区间内对数收益平方和的平方根，不先减平均收益。

分析思路

先检查报价和数量，计算WAP，再在同股票同段中差分对数。收益按结束时刻归属半段，最后分别聚合平方和及有效收益数。

解答步骤

两段分别100→101与110→111，各只有一个收益。若全表不分组直接diff，会额外出现101→110的大跳变，污染第二段。存在空盘口时WAP为缺失，代码相邻差分也会缺失，不跨空缺记录自动桥接。

对侧加权使较厚买盘把 WAP 拉向卖价。比如买价 100、卖价 102、买量 3、卖量 1，WAP=(100×1+102×3)/4=101.5\mathrm{WAP}=(100\times1+102\times3)/4=101.5WAP=(100×1+102×3)/4=101.5，比中间价 101 更靠近卖价。

同一股票和时间段排序后，计算 ri=log⁡(WAPi/WAPi−1)r_i=\log(\mathrm{WAP}_i/\mathrm{WAP}_{i-1})ri​=log(WAPi​/WAPi−1​)，然后 RV=∑ri2\mathrm{RV}=\sqrt{\sum r_i^2}RV=∑ri2​​。若有效价格依次为 100、101，则只有一个收益，RV 为 ∣log⁡(101/100)∣|\log(101/100)|∣log(101/100)∣。不能跨段差分，否则两个并不相邻的价格会产生虚假的大跳变。

两侧总量为零时 WAP 缺失。只有一个有效价格时没有可用收益，RV 也记缺失。下方程序把相邻收益归到后一个报价所在的半段，例如 299 秒到 302 秒的收益计入后半段。因此两个半段的平方 RV 相加与整段平方 RV 对应。

若改成每半段独立起算，应明确舍弃跨 300 秒边界的这一项。

排序复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)，组内差分和聚合为 O(n)O(n)O(n)。代码以两个时间段验证未发生跨段收益连接。

def order_features(frame):
    x=frame.copy().sort_values(['stock_id','time_id','seconds_in_bucket'])
    keys=['stock_id','time_id']
    if x.duplicated(keys+['seconds_in_bucket']).any():
        raise ValueError('同股票同时间段存在重复时点，需要先核查')
    values=x[['bid1','ask1','bsize1','asize1','seconds_in_bucket']].to_numpy(dtype=float)
    if not np.isfinite(values).all() or not x.seconds_in_bucket.between(0,600,inclusive='left').all():
        raise ValueError('报价须有限，段内秒数须在[0,600)')
    valid=(x.bid1>0)&(x.ask1>=x.bid1)&(x.bsize1>=0)&(x.asize1>=0)
    if not valid.all(): raise ValueError('发现无效报价或数量')
    den=x.asize1+x.bsize1
    x['spread']=x.ask1/x.bid1-1
    x['imbalance']=(x.asize1-x.bsize1)/(0.5*den.replace(0,np.nan))
    x['wap']=(x.bid1*x.asize1+x.ask1*x.bsize1)/den.replace(0,np.nan)
    x['log_wap']=np.log(x.wap)
    x['log_return']=x.groupby(keys).log_wap.diff()
    x['spread_change']=x.groupby(keys).spread.diff()
    x['imbalance_change']=x.groupby(keys).imbalance.diff()
    x['half']=np.where(x.seconds_in_bucket<300,'first','last')
    def rv(v):
        z=v.dropna().to_numpy()
        return np.sqrt(z@z) if len(z) else np.nan
    features=x.groupby(keys).agg(
        rv=('log_return',rv), spread_mean=('spread','mean'),
        spread_std=('spread','std'), imbalance_mean=('imbalance','mean'),
        imbalance_std=('imbalance','std'), observations=('wap','count'))
    halves=x.groupby(keys+['half']).log_return.agg(rv).unstack('half').add_prefix('rv_')
    features=features.join(halves)
    return x,features.reset_index()

5. 预测实验

题目

使用当前 10 分钟订单簿特征预测下一段 10 分钟的已实现波动率。标签表以 (stock_id,time_id) 标识当前特征对应的未来目标。建立持久性基准、Ridge 和树模型，说明连接、分组验证、预处理、调参与误差指标。假设 time_id 只是组标识，不代表可排序的真实日期。

考点：标签键；组隔离；相同样本比较。

查看分析与解答

必要知识

标签表的键对应当前特征，数值却描述未来一段波动，不能仅凭键相同就把目标误当同期RV。同段各股票共享市场环境，随机按行拆分会让这种共同信息跨越训练与测试。

分析思路

校验键并连接，整段留出，建立当前RV持久性基准。所有预处理只用训练组拟合，模型在相同有效样本上比较；调参另需训练组内部验证。

解答步骤

Ridge的中位数填补和尺度变换放入Pipeline，fit仅看训练行；树模型无需标准化，但同样不能从测试估填充值。time_id没有真实日期含义，所以GroupShuffleSplit评估的是新组泛化，不能称为严格时间外滚动检验。

**数据连接。**先分别检查特征表与标签表键唯一，再进行一对一连接，记录未匹配比例。标签虽然表示下一段波动，其键必须与当前段特征对应；不能仅按表行号拼接。

**建立基准。**使用当前段 RV 预测下一段 RV，得到持久性基准。线性模型和树模型使用相同特征、同一批训练测试样本，才能比较新增预测价值。特征可包含整段 RV、两半段 RV、价差、量差、深度和记录数。

**划分与调参。**同一时间段各股票共享市场状态，因此按 time_id 整组分配，避免同组进入两侧。仅有组标识时，这是分组留出评价。若后来取得真实日期，应改用前训后测的滚动划分。中位数填补、标准化和筛选全部在训练段拟合。超参数比较也仅在训练组内部完成。

**评价。**测试集上计算 RMSE、MAE 和正目标上的 RMSPE，并报告评价样本数。RMSE 放大大误差，MAE 直接对应平均绝对误差，RMSPE 衡量相对误差但会受接近零的目标影响。模型输出若负值，事先规定截为零。下面代码实现固定参数的基准比较，调参时另在训练组中加一层交叉验证。

import numpy as np
import pandas as pd
from sklearn.model_selection import GroupShuffleSplit
from sklearn.pipeline import make_pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import Ridge
from sklearn.ensemble import HistGradientBoostingRegressor
from sklearn.metrics import mean_squared_error,mean_absolute_error

def evaluate_features(features,labels):
    keys=['stock_id','time_id']
    d=features.merge(labels[keys+['target']],on=keys,validate='one_to_one')
    d=d[d.target.notna() & (d.target>=0)].reset_index(drop=True)
    cols=[c for c in features if c not in keys]
    splitter=GroupShuffleSplit(n_splits=1,test_size=.2,random_state=17)
    train,test=next(splitter.split(d,groups=d.time_id))
    X,y=d[cols],d.target
    models={
        'ridge':make_pipeline(SimpleImputer(strategy='median'),StandardScaler(),Ridge(alpha=1)),
        'tree':make_pipeline(SimpleImputer(strategy='median'),HistGradientBoostingRegressor(
            max_iter=100,max_leaf_nodes=7,l2_regularization=1,random_state=17,early_stopping=False))}
    predictions={'persistence':d.rv.to_numpy()}
    for name,model in models.items():
        model.fit(X.iloc[train],y.iloc[train])
        predictions[name]=np.maximum(model.predict(X),0)
    common=np.logical_and.reduce([np.isfinite(v) for v in predictions.values()])
    rows=[]
    for name,pred in predictions.items():
        for split,ix in [('train',train),('test',test)]:
            ok=common[ix]; a=y.iloc[ix].to_numpy()[ok];b=pred[ix][ok]
            if not len(a):
                raise ValueError('该分组没有所有模型共同可评价的样本')
            positive=a>0
            rows.append({'model':name,'split':split,'count':len(a),'split_count':len(ix),'positive_count':int(positive.sum()),
                'rmse':np.sqrt(mean_squared_error(a,b)), 'mae':mean_absolute_error(a,b),
                'rmspe_positive':np.sqrt(np.mean(((a[positive]-b[positive])/a[positive])**2))
                    if positive.any() else np.nan})
    return pd.DataFrame(rows)

6. 第二档及更多档位是否有帮助

题目

已有一档订单簿特征模型，准备加入第二档及更深档位。请列出有意义的新特征，设计对照实验，判断新增档位是否改善下一段波动率预测。

考点：新增信息；消融对照；成对误差。

查看分析与解答

必要知识

更深档位可能提供订单簿形状，也可能引入更多缺失、撤单噪声和计算成本。训练误差改善不证明新增信息有用，必须固定其他条件比较留出误差。

分析思路

先定义有经济含义且时点一致的新特征，再用相同组划分和调参预算训练两套模型。逐样本算误差差并按时间组汇总，观察改善是否稳定。

解答步骤

例如买侧一二档价差b₁−b₂刻画报价阶梯，累计买量bsize₁+bsize₂与累计卖量可形成深度差；除以价格间距时若间距零，需明确缺失或合并档位规则，不能产生无穷值。

新特征可包括二档价差、累计买卖深度、两档量差、第一档到第二档的价格间距，以及每单位价格距离的挂单深度。先检查档位顺序：第二档买价不高于第一档，第二档卖价不低于第一档；缺档应有明确标记。

固定同一训练、验证、测试分组和调参预算，比较只用一档与加入二档的模型。不要在不同随机切分上比较两个分数，否则差异可能来自测试难度变化。用相同测试样本逐条计算误差差值，再按时间组汇总，可查看收益是否仅由少数极端时段贡献。

进一步按股票、波动水平和流动性分层检查。若总体改善来自极少数股票，可考虑分层模型。若新增特征提高训练拟合却不改善验证，应检查撤单噪声、缺失和维度。除误差外还记录计算耗时、数据缺失率和存储量，确定新增信息是否值得获取。

令d_i=(y_i−预测一档_i)²−(y_i−预测多档_i)²，d_i>0表示多档改善。对同组求平均再比较各组，可发现总改善是否来自少数大波动时段。若需区间估计，应按组重采样保留组内相关，而非把所有股票行当独立样本。

同类问题

增量特征实验只改变待检验的信息集合，其余流程保持可比。同步记录缺失率、延迟与资源开销，才能判断改善是否具有实际价值。

7. 其他波动指标

题目

除 RV=∑ri2\mathrm{RV}=\sqrt{\sum r_i^2}RV=∑ri2​​ 外，给出已实现方差、平均绝对收益、双幂变差和基于最高最低价的波动估计，说明单位、计算和主要适用条件。

考点：方差与波动；跳跃敏感性；采样尺度。

查看分析与解答

必要知识

收益平方和与双幂变差估计方差量，开平方后才与收益率同单位。平均绝对收益则平均每个采样间隔的变化，采样越细其尺度会变化，不能直接与整段RV并列当同一量。

分析思路

逐一写指标、单位与依赖的价格模型，再用短收益序列核算。解释双幂系数与高低价范围常数的来源，最后讨论频率和噪声。

解答步骤

若相邻小区间收益近似独立N(0,σ²Δ)，则E|r|=σ√Δ√(2/π)，相邻绝对收益乘积期望为(2/π)σ²Δ，所以乘π/2可匹配方差尺度。孤立大跳跃只影响少数相邻乘积，高频极限下其邻项变小，使双幂量与平方和对跳跃的反应不同。

已实现方差为 ∑ri2\sum r_i^2∑ri2​，单位是收益率的平方；RV 是其平方根，与收益率同单位。平均绝对收益为 n−1∑∣ri∣n^{-1}\sum|r_i|n−1∑∣ri​∣，不会像平方项一样放大极端收益，但它与固定区间 RV 的尺度不同，比较时必须固定采样频率和观察长度。

双幂变差常写为 BV=(π/2)∑i=2n∣ri∣∣ri−1∣\mathrm{BV}=(\pi/2)\sum_{i=2}^n|r_i||r_{i-1}|BV=(π/2)∑i=2n​∣ri​∣∣ri−1​∣，也可附有限样本修正。在连续半鞅和适当高频条件下，它估计连续部分的积分方差，对有限个孤立跳跃较稳健；RV 方差与 BV 的差可用于研究跳跃贡献，正式检验还需估计相应误差尺度。

若一个观察区间的最高价、最低价为 H、L，Parkinson 方差估计为 [log⁡(H/L)]2/(4log⁡2)[\log(H/L)]^2/(4\log2)[log(H/L)]2/(4log2)。它利用区间范围，在连续、无漂移的对数价格扩散等条件下有良好性质；隔夜跳空、明显漂移或极值记录错误会影响它。

所有比较先统一价格定义和区间。高频成交价的买卖价反弹可能抬高平方收益和，采样越密不一定越准确，可比较较稀网格、报价中间价或噪声稳健估计。

对收益[0.01,−0.02,0.01]，平方和0.0006、RV约0.024495，平均绝对收益约0.013333；未作有限样本修正的BV=(π/2)(0.0002+0.0002)≈0.000628。小样本BV可大于平方和，不能把差的正负直接当作确定的跳跃结论。Parkinson公式的4log2来自无漂移布朗对数价格区间范围平方的期望，使用不同模型时需重新检查。

同类问题

先统一采样频率、观察区间和价格口径，再比较指标。平方收益放大极端值，范围估计依赖可靠极值，双幂量需足够细且质量合格的数据，各自解决不同问题。
