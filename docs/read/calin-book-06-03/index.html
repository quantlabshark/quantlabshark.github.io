为什么协方差矩阵比噪声分解更直接

同一个正半定矩阵可能有不同的平方根，因此可以用不同独立噪声组合产生相同的短时协方差。伊藤公式的漂移修正只依赖 A=σσTA=\sigma\sigma^TA=σσT，不会因为更换噪声坐标而改变。状态方程中的随机积分表达式会变，但对应扩散的局部分布结构保持一致。

计算机实现时，可以先写出每个坐标的噪声系数行，再对每两行做内积。同行内积给方差，异行内积给协方差。这样能避免忘记同一噪声影响多个变量，也能检查结果矩阵是否对称以及对角线是否非负。
