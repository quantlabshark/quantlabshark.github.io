1. 圆周三点成锐角

题目

在圆周上独立均匀取三个点，求它们组成锐角三角形的概率；共点或直角等零概率情形可忽略。

考点：圆周间隔；半圆覆盖；唯一计数。

查看分析与解答

必要知识

圆周三个点按顺序分出三段弧，每个三角形内角等于对面那段不含该顶点弧的一半。三角形锐角要求三个这样的弧都小于半圆，等价于不存在能包含全部三点的半圆。

分析思路

先求非锐角的补事件，用三个已选点分别作顺时针半圆起点。关键是说明这些事件不会重复计数，而不只是直接乘三。

解答步骤

固定点 A 后，另两点独立落在 A 开始的半圆概率各一半，所以同时落入为四分之一。若存在包含三点的半圆，则圆周上有一段超过半圈的空弧，且这样的空弧最多一段；其终点是唯一可用的已选起点。

三角形为锐角等价于圆心位于三角形内部，也等价于三个点不被某个半圆同时包含。对固定候选起点 A，从它沿顺时针半圆看，另外两个点都落在其中的概率为 (1/2)2(1/2)^2(1/2)2。

若三点同处一个半圆且没有边界重合，恰有一个已选点能作为这种顺时针半圆的起点；可以将三点按圆周顺序排列，唯一大于半周的空隙后面的点就是该起点。因此三个起点事件可以相加，补事件概率为 3/4。

因此锐角三角形的概率为 1−3/4=1/41-3/4=1/41−3/4=1/4。

因此三个起点事件除零概率边界外互斥，合计四分之三，锐角补集为四分之一。用弧长再核对：若某段空弧超过半圈，它对应的对顶角超过九十度，形成钝角，正与补事件一致。

同类问题

圆周随机点问题常可借旋转对称固定一点，再把几何性质转为间隔或半圆事件。乘候选数前必须检查每个配置被计数几次。

2. 百年内连续一百个正面

题目

每秒独立投掷一次公平硬币，持续 100 年，以一年 365.25 天计。证明期间至少出现一次连续 100 个正面的概率小于 10−510^{-5}10−5。

考点：窗口事件；并集上界；稀有概率。

查看分析与解答

必要知识

长度一百的连续正面可以从许多起点开始，至少出现一次是所有起点事件的并集。并集上界 P(∪A_i)≤ΣP(A_i) 不要求事件独立，因此适合处理高度重叠窗口。

分析思路

先数总投掷次数和合法窗口数，再用每个窗口 2⁻¹⁰⁰ 的概率作上界。题目只要求小于给定阈值，不必求精确等待分布。

解答步骤

第一个窗口占一至一百次，最后一个起点 T−99，因此窗口数 T−99。相邻窗口共享九十九次结果，不能把“都没出现”的概率写成独立乘积，但将各窗口概率直接相加始终给合法上界。

总投掷数取 T=100×365.25×24×3600=3,155,760,000T=100\times365.25\times24\times3600=3,155,760,000T=100×365.25×24×3600=3,155,760,000。从第 1 到第 T−99T-99T−99 次都可作为一个长度为 100 的窗口起点。记窗口全正面事件为 AiA_iAi​，则每个 P(Ai)=2−100P(A_i)=2^{-100}P(Ai​)=2−100。

同类问题

证明罕见事件很小时，先尝试并集界或期望计数界。相关性会影响精确概率，却不妨碍许多简单且足够有力的上界。

3. 四面体随机游走

题目

在正四面体四个顶点间随机游走，从某个顶点出发，每一步等概率走到其余三个顶点之一。起点算已访问，求访问全部四个顶点所需步数的期望。

考点：覆盖时间；已访问数量；分阶段等待。

查看分析与解答

必要知识

四面体每个顶点都与另外三个相连，因此下一步必离开当前点。已访问 k 个时，当前点本身已访问，三个可去点中只有 k−1 个旧点，另 4−k 个是新点。

分析思路

把访问全部顶点拆成从一到二、二到三、三到四个不同顶点三个阶段，分别求发现新点的等待均值后相加。

解答步骤

第一步三个候选都新，必发现第二点，耗时一；已有两点时，候选中两个新点、一个旧点，成功率三分之二，平均一点五步；已有三点时只剩一个新点，成功率三分之一，平均三步。

按已经访问过的不同顶点数分阶段。当已访问 kkk 个点时，当前点属于其中之一，下一步的三个候选中有 4−k4-k4−k 个未访问点，所以发现新点的概率恒为 (4−k)/3(4-k)/3(4−k)/3。

在发现新点前，即使在旧点间移动，已访问数仍是 kkk，成功概率不变，因此等待时间服从参数 (4−k)/3(4-k)/3(4−k)/3 的几何分布，均值为其倒数。依次从 1 个已访问点增长到 4 个，期望相加为 3/3+3/2+3/1=11/23/3+3/2+3/1=11/23/3+3/2+3/1=11/2。

每阶段失败后虽当前位置改变，但仍处于已访问集合，未访问点数量不变，且完全图结构使成功率保持相同。因此可以用几何均值；对一般不规则图，只有已访问数量未必足以决定成功率。

同类问题

覆盖问题若具有高度对称，可按已收集种类数分阶段。先确认失败后成功概率是否不变，再使用几何等待；一般图可能需记录具体访问集合和位置。

4. 飞机最后两人

题目

100 位乘客按 1 至 100 顺序登机，每人有同编号座位。第 1 人在全部座位中均匀随机选座；以后的人若本座空着就坐本座，否则在空座中均匀随机选择。求第 99、100 人均坐到自己座位的概率。

考点：错位链；关键集合；条件对称。

查看分析与解答

必要知识

正常乘客坐本座不会制造新随机性，只有本座已被占者接续随机选座。因此整个错位过程可以沿一条链追踪，不必枚举全部一百人的安排。

分析思路

关注会终结或破坏目标的三个座位：一号结束错位，九十九或一百号一旦提前被占就使最后两人无法都坐对。其余选择只延续链。

解答步骤

首次碰到关键集合之前，三个座位始终同时空着。无论当前还剩多少其他空座，随机选择到这三个中任一个的单座概率相同，所以条件于这次进入关键集合，三者各一比三。此前经过多少次非关键选择不会打破这种对称。

只有被抢座的人会继续随机选择，这形成一条错位链。链若选中 1 号座位，就结束；若在结束前选中 99 或 100 号座位，目标事件已经失败。选中其他编号则只是把随机选择权传给后面的某个人。

在首次命中关键集合 {1,99,100}\{1,99,100\}{1,99,100} 之前，这三个位子都空着，每次随机选择对它们完全对称。因此最先命中三者中的哪一个各有 1/3 概率。只有 1 号先被命中会保护最后两人的座位，答案为 1/3。推广到最后 kkk 人都坐对，概率为 1/(k+1)1/(k+1)1/(k+1)。

若一号先被选，之后所有尚未登机乘客都可坐本位，最后两人成功；若九十九号或一百号先被占，该位不会再次空出，目标失败。推广最后 k 人时关键集合有一号加最后 k 个，共 k+1 个，同理成功率 1/(k+1)。

同类问题

随机错位过程可先找少数决定成败的吸收事件，忽略只延迟结局的中间状态。对关键位置的条件对称往往比全路径递推更简洁。

5. 六十面与五十面骰

题目

A 掷 1 至 60 的公平骰，B 掷 1 至 50 的公平骰，两者独立。点数较大者获胜，平局算 B 赢；输家支付赢家所掷点数对应的金额。求 A 的净收益期望。

考点：离散收益；赢家支付；平局规则。

查看分析与解答

必要知识

A 赢时收自己的点数，输时付 B 的点数，因此收益不是固定正负一。平局算 B 赢，会带来额外负项。两骰独立均匀使每个点数组合概率一比三千。

按赢家点数分组，将五十以内双方可出现的对称部分抵消，再加上 A 独有的五十一至六十区间。

解答步骤

z≤50 时，A=z 且赢要求 B 从一到 z−1，共 z−1 种；B=z 且赢允许 A 从一到 z，共 z 种，多出来的正是平局。两者净贡献 z(z−1)−z²=−z。

当赢家点数为 z≤50z\le50z≤50 时，A 赢有 z−1z-1z−1 个对手点数，正贡献 z(z−1)z(z-1)z(z−1)。B 赢有 zzz 个 A 点数（含平局），负贡献 −z2-z^2−z2，净为 −z-z−z。当 A 点数为 51 至 60 时，无论 B 掷什么 A 都赢，每个点数贡献 50z50z50z。最后把贡献总和除以 3000。

得到 [50∑z=5160z−∑z=150z]/3000=353/40=8.825[50\sum_{z=51}^{60}z-\sum_{z=1}^{50}z]/3000=353/40=8.825[50∑z=5160​z−∑z=150​z]/3000=353/40=8.825。

Σ₅₁⁶⁰z=(51+60)×10/2=555，Σ₁⁵⁰z=1275，总净贡献 50×555−1275=26475，除三千得 8.825。平局规则若改为不支付，会去掉负的 1275 部分，答案便不同。

同类问题

非固定赔率的比较游戏，应先逐状态写出实际支付，而不是只求胜率。按赢家、最大值或对称结果分组，可以把双重求和化为简单和式。

6. 含卖出费用的最优交易

题目

给定按日期排列的正价格，可以多次买卖但最多持有 1 单位，禁止做空，初始和最终均空仓，每次卖出支付固定非负手续费 KKK。求这条已知价格路径上可实现的最大利润，给出 O(n)O(n)O(n) 算法。

考点：持仓状态；手续费；事后路径最优。

查看分析与解答

必要知识

cash 是空仓时累计现金收益，hold 是持有一单位时支付买价后的现金余额，后者不含当前股票市值。两状态区分未来允许的动作，最终空仓要求答案只能取 cash。

分析思路

每天分别比较继续保持与买卖转移，全部读取前一天状态以保留时间顺序。卖出时一次性扣费，避免买卖两边重复扣或遗漏。

解答步骤

示例费二：第一天一元买后 hold=−1；到八元可卖得 −1+8−2=5；四元再买后 hold 可为 5−4=1；九元卖得 1+9−2=8。两笔交易分别净赚五和三，总八。

使用两个状态：cash 表示截至当前日空仓时能获得的最大累计现金收益；hold 表示持有一单位时的最大现金余额。初始 cash=0，hold=−∞。观察价格 p 后： cash′=max⁡(cash,hold+p−fee),hold′=max⁡(hold,cash−p). cash'=\max(cash,hold+p-fee),\qquad hold'=\max(hold,cash-p). cash′=max(cash,hold+p−fee),hold′=max(hold,cash−p). 两个右侧都使用更新前的状态，以保持状态含义一致。最终返回 cash。

from math import isfinite

def max_profit_with_fee(prices, fee):
    if not isfinite(fee) or fee < 0:
        raise ValueError("fee must be finite and nonnegative")
    cash, hold = 0.0, float("-inf")
    for p in prices:
        if not isfinite(p) or p <= 0:
            raise ValueError("prices must be finite and positive")
        old_cash, old_hold = cash, hold
        cash = max(old_cash, old_hold + p - fee)
        hold = max(old_hold, old_cash - p)
    return cash

assert max_profit_with_fee([9, 7, 4], 1) == 0
assert max_profit_with_fee([], 1) == 0
assert max_profit_with_fee([4], 0) == 0

算法在已知历史路径上选择最优交易序列，是事后最优上界。要决定今天究竟买还是不买，通常需要知道哪条状态路径在未来胜出，所以不能把恢复出的最优买卖点直接当成实时预测模型。真实研究必须另有仅依赖当时信息的决策规则。

题目

考点：GCD 多重集；对角项；贪心扣除。

查看分析与解答

必要知识

GCD(a,b) 不大于任一输入，自身对角项 GCD(a,a)=a。完整有序对矩阵对称，两个不同位置的交叉 GCD 会出现两份，即使两个原元素数值相等也不能少算。

分析思路

按从大到小恢复原元素，每次取仍有正计数的最大值，扣除它的对角项和与已恢复元素的双份交叉项。用剩余计数维持尚未解释的矩阵条目。

解答步骤

原序列最大元素一定出现在矩阵对角线，任何 GCD 不会更大，因此首先取最大正确。恢复若干元素后，它们内部与后续逐步配对的相关条目按规则扣除，剩余最大值仍必须对应下一个未恢复对角元素。

当前最大剩余值一定是一个未恢复元素：其自身的对角项等于它，而任何与更小数的 GCD 都不可能超过那个较小数。取出它后，先消耗一份对角项，再与每个此前恢复的元素 yyy 计算 GCD，并消耗两份，分别代表矩阵的 (i,j)(i,j)(i,j) 与 (j,i)(j,i)(j,i)。

示例先取 9，再取 6 时删除两份 3；再取 4 时删除两份 1 和两份 2，最后所有计数恰为零。重复元素同样适用：两条相同值之间仍有两个非对角条目，不能因数值相同而只删一份。

示例恢复为 4、6、9。对 n2n^2n2 个条目排序并维护计数，排序成本约 O(n2log⁡n)O(n^2\log n)O(n2logn)，另需 O(n2)O(n^2)O(n2) 次 GCD 运算。

from collections import Counter
from math import gcd, isqrt

def recover(values):
    n = isqrt(len(values))
    if n*n != len(values):
        raise ValueError('条目数必须为平方数')
    counts = Counter(values)
    answer = []
    for x in sorted(values, reverse=True):
        if counts[x] <= 0:
            continue
        counts[x] -= 1
        for y in answer:
            counts[gcd(x, y)] -= 2
        answer.append(x)
        if len(answer) == n:
            break
    if len(answer) != n or any(v != 0 for v in counts.values()):
        raise ValueError('输入不是有效的完整 GCD 矩阵')
    return sorted(answer)

assert recover([1,4,2,6,3,3,9,2,1]) == [4,6,9]
assert recover([2,2,2,2]) == [2,2]

import numpy as np

def fish_value(n=80):
    x = (np.arange(n) + 0.5) / n
    i, j, k = np.ogrid[:n, :n, :n]
    hi = np.maximum(np.maximum(i, j), k)
    lo = np.minimum(np.minimum(i, j), k)
    mid = i + j + k - hi - lo
    total = x[i] + x[j] + x[k]
    value = total.copy()
    for _ in range(7):
        continuation = value.mean(axis=2)
        value = np.maximum(total, continuation[mid, hi])
    return float(value.mean())
