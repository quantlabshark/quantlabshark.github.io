随机拉格朗日优化与收敛

以连续订单比例推导边际收益条件，用成交反馈进行投影随机逼近，并区分收敛与跟踪。

对固定样本，min⁡(riν,Ui)\min(r_i\nu,U_i)min(ri​ν,Ui​) 是先增长后变平的凹函数，取期望后仍凹。假定 Eν<∞E\nu<\inftyEν<∞，且分配边界处没有容量概率质量，边际收益为

只有当前订单能够全部成交，增加一点订单量才可能带来收益。总量随机时，较大的订单对梯度贡献也更大，不能只用不加权的全部成交比例。

拉格朗日条件的含义

引入总比例约束的乘子 λ\lambdaλ。在最优解中，所有正分配市场满足 Fi′(ri)=λF_i'(r_i)=\lambdaFi′​(ri​)=λ；分配为零的市场满足 Fi′(0)≤λF_i'(0)\le\lambdaFi′​(0)≤λ。否则可从边际收益较低处移出一小部分，转给较高处继续提高目标。

实际容量未必可见，但连续容量模型中，全部成交事件可由 Ri=riνR_i=r_i\nuRi​=ri​ν 判断。在概率为零的等号例外之外，样本梯度为 gi=ρiν1{Ri=riν}g_i=\rho_i\nu\mathbf1_{\{R_i=r_i\nu\}}gi​=ρi​ν1{Ri​=ri​ν}​。若容量是整数且阈值处有原子，则应采用相应的单侧导数或次梯度，不把等号当作严格超过。

rt+1=ΠΔ(rt+γtgt),Δ={r≥0:∑iri=1}.r_{t+1}=\Pi_\Delta(r_t+\gamma_tg_t),\qquad \Delta=\{r\ge0:\sum_ir_i=1\}.rt+1​=ΠΔ​(rt​+γt​gt​),Δ={r≥0:i∑​ri​=1}.

投影先找一个阈值 τ\tauτ，再令新比例为 max⁡(vi−τ,0)\max(v_i-\tau,0)max(vi​−τ,0)，使其和为一。只减去梯度平均值虽然保持分量和，却可能产生负比例；单纯归一化也不等同于欧氏投影。

比例投影怎样手工计算

假设梯度更新后得到 v=(−0.2,0.8,0.9)v=(-0.2,0.8,0.9)v=(−0.2,0.8,0.9)，它含负数且总和为 1.5。投影问题是最小化 ∑i(ri−vi)2/2\sum_i(r_i-v_i)^2/2∑i​(ri​−vi​)2/2，同时满足 ri≥0,∑iri=1r_i\ge0,\sum_ir_i=1ri​≥0,∑i​ri​=1。对正分量的一阶条件给出 ri=vi−τr_i=v_i-\tauri​=vi​−τ，非负约束将小于零的项截成零。

随机梯度使用的严格尾事件也与边界有关。对固定样本，函数 min⁡(rν,U)\min(r\nu,U)min(rν,U) 的右导数为 ν1{U>rν}\nu\mathbf1_{\{U>r\nu\}}ν1{U>rν}​，左导数为 ν1{U≥rν}\nu\mathbf1_{\{U\ge r\nu\}}ν1{U≥rν}​。容量在阈值有正概率质量时，两者不同；连续分布且 r>0r>0r>0 时通常一致。导数绝对值不超过 ν\nuν，因此 Eν<∞E\nu<\inftyEν<∞ 为交换期望与单侧求导提供了控制条件。

若给某市场的比例恰为零，观察到零成交不能判断它是否有可用容量。为了继续学习，可以安排少量正分配的探索轮次，再由这些观察估计边际收益。把“零订单全部成交”机械地作为成功事件，会把没有观察到的容量当作已知信息。

鲨鱼说

投影负责让订单比例合法，探索负责取得尚未知的信息，步长负责权衡旧观察与新观察。这三项解决不同问题，不能用一次归一化同时代替。

步长与噪声

Robbins–Monro 型迭代寻找平均更新方向为零的位置。在固定环境下，常用条件为 ∑tγt=∞\sum_t\gamma_t=\infty∑t​γt​=∞、∑tγt2<∞\sum_t\gamma_t^2<\infty∑t​γt2​<∞：前者保证仍有足够调整幅度，后者使累计随机波动受到控制。γt=c/ta\gamma_t=c/t^aγt​=c/ta，1/2<a≤11/2<a\le11/2<a≤1 满足两者；1/t1/\sqrt t1/t​ 不满足平方可和条件。

结论还依赖目标凹性、迭代稳定，以及样本噪声具有合适的条件均值和矩界。时间相关订单流需要相应的遍历或混合条件，不能仅凭步长形式断言收敛。

对后期迭代取平均可减少波动。固定步长则持续响应新状态，通常保留稳态噪声，适合讨论跟踪误差。若只能观察目标值，可用 Kiefer–Wolfowitz 差分近似梯度。差分间隔太小会放大观测噪声，太大又会增加近似偏差，需要与步长共同选择。

鲨鱼说

跟踪误差，即策略收益与基准收益之差的波动率。
