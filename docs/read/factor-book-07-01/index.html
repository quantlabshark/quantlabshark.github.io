7.1 从选股指标到预期收益

学习选股指标的检验、数据处理与收益标定，理解排名信号如何转为组合可使用的预测值。

账面市值比怎样成为选股信号

两家公司账面净资产都是100亿元，股票市值分别为200亿元和500亿元，账面市值比BM便是0.50和0.20。第一家公司相对于账面净资产更便宜，但这个比值还没有告诉我们两家公司下个月分别会涨多少。选股研究必须依次回答：便宜是否与未来收益有关。

这种关系能否超出行业、规模等已有信息。信号强弱怎样换算为预期收益。

实践中常把BM、盈利能力、分析师预期等预测变量称为“阿尔法因子”。这里的因子首先是每只股票的一个数值，与学术模型中多空组合的收益序列不同。组合相对指数的收益差，也不同于控制多个风险因子后回归所得的截距α。明确研究对象，才能正确比较结果。

新指标可以来自已有异象、对已有指标的修正，也可以来自新的数据。例如研发费用化可能低估知识密集企业的账面资产，因而可研究研发资本化后的价值指标。员工评价、专利关联和环境治理信息则提供新的经营观察。每个方向都需要解释数据如何产生、何时公开，以及它为什么可能影响尚未被价格反映的现金流或风险。

信息系数衡量什么

在某个月末，设股票iii的标准化信号为zi,tz_{i,t}zi,t​，下一月收益为ri,t+1r_{i,t+1}ri,t+1​。信息系数IC是同一个月内、不同股票之间的相关系数：

ICt=Corr⁡i(zi,t,ri,t+1).IC_t=\operatorname{Corr}_i(z_{i,t},r_{i,t+1}).ICt​=Corri​(zi,t​,ri,t+1​).

IC为正，意味着当月高分股票随后总体上收益较高；它不是组合收益率。Rank IC先将两组数转为名次再计算相关，关注排序是否一致，降低极端值的影响。一个关系可以排序稳定而幅度不线性，所以两者都值得观察。

将各月IC排列成时间序列，可计算均值、标准差及ICIR=IC‾/s(IC)ICIR=\overline{IC}/s(IC)ICIR=IC/s(IC)。这个比值衡量IC的稳定程度，不等于持仓组合的信息比率。IC序列有自相关时，均值的标准误需要相应修正。不能机械使用s(IC)/Ts(IC)/\sqrt Ts(IC)/T​。历史实践中的“IC超过某个百分比”只是特定股票池和频率下的经验尺度，不能作为通用录用标准。

判断一个指标，还要检查六方面：经济机制是否明确，关系是否持续，是否有独立贡献，换市场或参数后是否稳健，是否能够交易，以及是否在足够广的股票中成立。平均IC可能被少数小股票或单次行情驱动，分行业、分规模和分时期检验有助于识别这种集中。

鲨鱼说

自相关，即同一序列与其滞后值之间的相关关系。

相关指标怎样检验独立贡献

假设新指标主要选中小市值公司。即使它的IC为正，也可能只是在重复规模信息。可以在各规模组内重新排序，再比较新指标的高低组收益。也可以逐期进行截面回归，同时加入规模、行业和其他已有指标，观察新指标的系数。

另一种方法是正交化：用已有指标解释新指标，只保留残差。例如

xi=a+blog⁡(MEi)+∑hchDih+ui,x_i=a+b\log(ME_i)+\sum_hc_hD_{ih}+u_i,xi​=a+blog(MEi​)+h∑​ch​Dih​+ui​,

其中MEMEME是市值，DihD_{ih}Dih​是行业标记，残差uiu_iui​表示同等规模、同行业内额外的信号。残差在这一次回归采用的样本和权重下与解释变量正交；它不意味着未来收益独立，也不保证没有其他风险暴露。

信号还会衰减。分别计算今天的信号与未来第1、第2、第3个月收益的IC，可观察有效期限。半衰期指效果降至初始水平一半所需时间。很快消失的信号要求更频繁交易，也更容易受到成交延迟、成本和容量限制。

鲨鱼说

“排名正确”和“值得交易”之间还有收益幅度、费用和风险三道计算。一个IC稳定但很快衰减的指标，可能来不及以足够低的成本交易。

异常值与股票池改变了什么

研究股票池应先明确上市状态、流动性、可交易性与产品限制，并使用每个历史时点实际存在的股票。是否局限于指数成分股，取决于产品约束。指数增强并不在数学上必然只能持有成分股。根据预测收益过滤股票，也应与原始股票池效果分开报告。

截面处理常包括缺失值处理、缩尾和标准化。缩尾将极端值压到边界，保留股票；截尾直接删除极端股票，两者会得到不同样本。均值加减三倍标准差的边界容易被极端值自身拉宽。另一种尺度是中位数绝对偏差：

MAD=median⁡i∣xi−median⁡(x)∣.MAD=\operatorname{median}_i|x_i-\operatorname{median}(x)|.MAD=mediani​∣xi​−median(x)∣.

正态分布下可用1.4826MAD1.4826MAD1.4826MAD近似标准差，再设定倍数边界。MAD等于零时，应另设处理规则，不能除以零。处理后的zi=(xi−xˉ)/sxz_i=(x_i-\bar x)/s_xzi​=(xi​−xˉ)/sx​把不同量纲转成可比较的截面坐标。

条件选股与排名选股

考虑下面四只虚构股票。

股票 BM ROE BM排名分 ROE排名分
A 0.60 8% 4 1
B 0.45 14% 3 3
C 0.30 18% 2 4
D 0.20 11% 1 2

条件选股要求BM大于1/31/31/3且ROE大于10%，只有B入选。排名选股把两个排名分相加，选前两名，则C与B入选。前一种表达明确的估值与盈利门槛，股票数量随市场变化。后一种稳定持仓数量，但不保留数值间距。

例如18%与14%的ROE，在排名中只差一分，与14%和11%的差距相同。

多个相近指标先在同一风格内部合成，再合成不同风格，可避免“拥有十个价值指标”的价值风格在总分中天然占据十倍权重。合成后再次标准化，有助于控制最终信号的尺度。阈值、指标方向和权重都应在验证期之前确定。

把标准分换成收益率

组合优化需要收益幅度。每个月用历史数据估计

ri,t+1=at+btzi,t+ei,t+1,r_{i,t+1}=a_t+b_tz_{i,t}+e_{i,t+1},ri,t+1​=at​+bt​zi,t​+ei,t+1​,

再使用过去若干期系数的平均值预测下一期，是一种参数化方法。滚动面板回归则将多期股票观测放在一起估计共同关系，可加入时间效应；股票间及时间上的相关误差仍需处理。窗口长度影响适应速度与估计误差。

在单变量、同一截面权重口径且zzz方差为1时，回归斜率满足

b=IC σr.b=IC\,\sigma_r.b=ICσr​.

因此，若预测IC为0.05，下一期股票收益的截面标准差为4%，标准分为1的股票相对截面均值的预测优势为0.05×4%=0.20%0.05\times4\%=0.20\%0.05×4%=0.20%。标准分为−1则为−0.20%。这里的σr\sigma_rσr​是同一时点不同股票收益的离散程度，不是某只股票的历史波动率。

Python8 行
# 自拟截面：预测的是相对股票池均值的收益偏离。
from statistics import mean, pstdev
raw = [-1.0, 0.0, 1.0]
z = [(x-mean(raw))/pstdev(raw) for x in raw]
ic, cross_section_vol = 0.05, 0.04
forecast = [ic*cross_section_vol*x for x in z]
print([round(x*100, 4) for x in forecast])
assert abs(sum(forecast)) < 1e-12

输出约为−0.2449、0、0.2449个百分点。原始分数经过标准化后，端点为正负1.2247，因此预测幅度大于0.20个百分点。若基准是市值加权指数，截面等权平均预测为零并不意味着相对基准的截距为零。还需减去基准持仓的预测收益。

图中信号只提供收益预测。风险、成本和约束仍会改变最终持仓：预测高的股票，也可能因行业已过度集中而只获得较小权重。

练习

某标准化信号的预测IC为0.04，收益截面标准差为5%，股票得分为1.5。相对截面均值的预测收益是多少？这是否就是它下个月的绝对收益？

查看解答

预测偏离为0.04×0.05×1.5=0.0030.04\times0.05\times1.5=0.0030.04×0.05×1.5=0.003，即0.30个百分点。绝对收益还包含截面平均收益和预测误差。若市场整体下跌5%，该股票即使比均值高0.30个百分点，也仍可能亏损。
