17 · 价格趋势、收益平稳性与波动聚集

比较随机游走与均值回复，计算自相关，并区分预测收益方向和预测风险。

金融时间序列需要区分价格水平、收益方向和波动大小。差分与收益变换用于处理水平变化，相关结构和条件方差模型则分别研究方向依赖与风险变化。

鲨鱼说

条件方差，即给定当前信息后，随机变量围绕条件均值的平方偏差期望。

时间顺序是数据的一部分

一条价格曲线长期上升，不意味着相邻涨跌容易预测；一串收益涨跌方向近乎随机，也不意味着风险始终不变。金融时间序列需要分别研究水平、方向依赖和波动大小。

时间序列是按时间排列的观测。打乱顺序后，均值和总体直方图可能不变，但连续亏损、趋势和波动聚集都会消失。相关结构描述的正是顺序中保留的信息。

弱平稳要求均值不随时间改变、方差有限且不随时间改变、两个时点的协方差只取决于它们相隔多少期。这个定义不要求每期数值相同，而是要求产生数值的主要统计规律在时间平移后保持一致。

随机游走为何适合先做差分

设 pt=pt−1+utp_t=p_{t-1}+u_tpt​=pt−1​+ut​，其中 utu_tut​ 独立、均值零、方差 σu2\sigma_u^2σu2​。从固定初值开始，ptp_tpt​ 的方差为 tσu2t\sigma_u^2tσu2​，随时间扩大，所以价格水平不满足上述平稳条件。差分 pt−pt−1=utp_t-p_{t-1}=u_tpt​−pt−1​=ut​ 则具有恒定方差。

若 pt=ln⁡Ptp_t=\ln P_tpt​=lnPt​ 为对数价格，差分就是对数收益。ARIMA 中的差分用于处理这类水平变化，但差分次数需要由数据性质判断，不能把所有序列都反复差分。

AR(1) 描述偏离如何延续

一阶自回归写为 xt=μ+ϕ(xt−1−μ)+utx_t=\mu+\phi(x_{t-1}-\mu)+u_txt​=μ+ϕ(xt−1​−μ)+ut​。μ\muμ 是长期中心，ϕ\phiϕ 决定上一期偏离保留多少。若 ϕ=0.5\phi=0.5ϕ=0.5、当前高于中心 8，在未来冲击均值为零的预测下，后续偏离依次为 4、2、1。

在 ∣ϕ∣<1|\phi|<1∣ϕ∣<1 且冲击条件合适时，过程可有稳定分布，方差为 σu2/(1−ϕ2)\sigma_u^2/(1-\phi^2)σu2​/(1−ϕ2)。若 ϕ=1\phi=1ϕ=1，偏离不会衰减，就回到随机游走。phiphiphi 为负时偏离会交替反号；正且接近 1 时，偏离消退较慢。

合成曲线使用同一组冲击。随机游走把冲击永久累积，AR 序列逐步衰减旧影响；下方自相关图比较不同滞后距离上的联系。

自相关是一个变量与自身过去的相关

滞后 kkk 的总体自相关为 ρk=Cov⁡(xt,xt−k)/Var⁡(xt)\rho_k=\operatorname{Cov}(x_t,x_{t-k})/\operatorname{Var}(x_t)ρk​=Cov(xt​,xt−k​)/Var(xt​)。一种常见样本估计把去均值后的对应乘积相加，再除以全部观测的去均值平方和。

Python14 行
import numpy as np
rng = np.random.default_rng(2026)
shock = rng.normal(0,1,600)
walk = np.cumsum(shock)
ar = np.zeros(len(shock))
for t in range(1,len(ar)):
    ar[t] = 0.6*ar[t-1]+shock[t]
def acf(values,lag):
    centered = values-values.mean()
    return np.dot(centered[lag:],centered[:-lag])/np.dot(centered,centered)
sample = ar[100:]
print("AR样本一阶自相关:",round(acf(sample,1),3))
print("冲击一阶自相关:",round(acf(shock[100:],1),3))
print("未来无新增冲击时的偏离:",[8*0.5**k for k in range(4)])

AR 的样本自相关应围绕设定的 0.6 波动，独立冲击的样本自相关围绕零波动。有限样本结果不必精确等于理论值；舍弃前一百期减少了固定初值对示例的影响。

收益不相关，平方收益仍可相关

把收益写成 rt=σtztr_t=\sigma_tz_trt​=σt​zt​，其中 ztz_tzt​ 条件均值为零、方差为 1，而 σt\sigma_tσt​ 随历史变化。即使无法预测正负方向，仍可能预测波动幅度。GARCH 类型模型用过去冲击平方和过去条件方差更新下一期方差，例如

σt2=ω+αrt−12+βσt−12.\sigma_t^2=\omega+\alpha r_{t-1}^2+\beta\sigma_{t-1}^2.σt2​=ω+αrt−12​+βσt−12​.

ω\omegaω 提供基础方差，α\alphaα 反映新冲击影响，β\betaβ 反映波动持续。非负参数保证方差非负，常用平稳设定还要求 α+β<1\alpha+\beta<1α+β<1。负向冲击与正向冲击可能影响不同，进一步模型会加入不对称项。

条件均值为零的误差可以称为鞅差分：已知过去信息后，误差的平均仍为零。它不要求每期方差相同，也不自动保证相互独立。因此“不预测方向”和“不预测风险”是不同命题。

检查图形与模型残差

先画价格和收益，再画滚动均值、滚动波动、收益与平方收益的自相关。明显的制度变化、极端事件或趋势，可能使一个固定参数模型不能概括整段时期。白噪声检验通常针对若干阶线性相关，未拒绝零自相关并不能证明完全独立。

AR、MA 和移动平均线不是同一概念

AR 模型把过去观测作为解释变量；时间序列中的 MA 模型把当前及过去随机冲击组合起来，例如 xt=ut+θut−1x_t=u_t+\theta u_{t-1}xt​=ut​+θut−1​。这里的“移动平均”指冲击结构，不是交易技术指标中对最近几个价格求均值。

ARMA 把过去观测和过去冲击合在一起。冲击通常不能直接观察，需要通过拟合得到残差或递推估计。即使模型形式简短，拟合后仍要检查残差是否保留相关和波动变化。

季节性会在固定间隔出现联系。例如每隔五个交易日的成交量规律，可能来自星期结构；日内每个时段的成交活跃度不同，则需要按时段比较。把这些可重复模式与长期趋势分开，才能判断差分或模型中应该保留哪些项。

自相关图只是诊断工具。许多滞后同时检查时，个别样本相关偏离零可能偶然出现。模型阶数还要结合解释、样本长度和样本外预测比较，不应根据某个孤立柱子是否超过参考线就断言存在可交易规律。

鲨鱼说

看见价格图有趋势时，先转到收益再观察；看见收益方向难预测时，再看绝对收益或平方收益。方向与幅度常常保留不同的信息。

练习

AR(1) 的中心为 10，当前值为 18，ϕ=0.5\phi=0.5ϕ=0.5。下一期和两期后的条件期望是多少？

查看解答

当前偏离中心 8，下一期预期偏离 4，水平为 14；再下一期预期偏离 2，水平为 12。模型衰减的是相对中心的偏离，不能把水平 18 直接乘 0.5。
