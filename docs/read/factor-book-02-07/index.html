用平均关系估计价格模型：广义矩估计

从两种状态下的一元钱开始，建立随机折现、矩条件、参数估计和过度识别检验。

两项资产未来平均都支付 100 元，为什么今天价格可能不同？如果一项资产恰在收入很低、现金紧张时支付，另一项却在经济繁荣时支付，投资者对它们的评价可能不同。资产定价需要给不同状态中的现金流不同权重，再利用实际数据估计这些权重。

状态中的现金流怎样折算到今天

设未来状态为 sss，概率为 psp_sps​，资产在该状态支付 XsX_sXs​。随机折现因子 msm_sms​ 表示该状态下一元钱折算到今天的价值权重。资产价格为

P=E[mX]=∑spsmsXs.P=E[mX]=\sum_s p_sm_sX_s.P=E[mX]=s∑​ps​ms​Xs​.

教学例子中，好、坏两种状态各占一半，折现因子分别为 0.8、1.1。资产甲只在坏状态支付 100 元，价格为 0.5×1.1×100=550.5\times1.1\times100=550.5×1.1×100=55 元。资产乙只在好状态支付 100 元，价格为 40 元。它们未来平均支付都是 50 元，价格差来自支付状态。

状态价格是 psmsp_sm_sps​ms​，不是单独的概率。图中两项资产在景气、困难状态下的支付方向相反。计算价格时，分别把各状态支付乘以对应状态价格，再相加；坏状态中的保护性支付因此可以更贵。

消费型模型常设 mt+1=δ(Ct+1/Ct)−γm_{t+1}=\delta(C_{t+1}/C_t)^{-\gamma}mt+1​=δ(Ct+1​/Ct​)−γ。Ct+1/CtC_{t+1}/C_tCt+1​/Ct​ 是消费增长倍数，δ\deltaδ 是时间偏好参数，γ\gammaγ 控制边际效用对消费变化的敏感程度。消费下降时，一元钱更稀缺，mmm 变大。这给出了“坏状态更值钱”的具体参数模型。

把定价关系写成误差均值为零

若投入 1 元、下一期获得含本金的毛收益 GGG，条件为 E[mG−1]=0E[mG-1]=0E[mG−1]=0。净收益 5% 对应 G=1.05G=1.05G=1.05。对于等金额多空组合的零成本收益 rer^ere，条件为 E[mre]=0E[mr^e]=0E[mre]=0。

每项资产都提供一个条件。消费模型只有 δ,γ\delta,\gammaδ,γ 两个参数，却可以面对无风险资产、市场超额收益、规模和价值四项资产：

E[mGf−1mrMemfSMBmfHML]=0.E\begin{bmatrix} mG_f-1\\m r_M^e\\m f_{SMB}\\m f_{HML} \end{bmatrix}=\boldsymbol0.E​mGf​−1mrMe​mfSMB​mfHML​​​=0.

这四项都是“定价误差长期平均应为零”。矩条件中的“矩”，指随机变量某个函数的期望，不只是均值和方差两个名称。

样本均值本身也有误差

设观测函数为 ht(b)h_t(b)ht​(b)，bbb 是参数向量。真实参数 b0b_0b0​ 满足 E[ht(b0)]=0E[h_t(b_0)]=0E[ht​(b0​)]=0。手里只有 TTT 期数据，能够计算的是

gT(b)=1T∑t=1Tht(b).g_T(b)=\frac1T\sum_{t=1}^{T}h_t(b).gT​(b)=T1​t=1∑T​ht​(b).

即使模型正确，有限样本的 gT(b0)g_T(b_0)gT​(b0​) 也不一定恰好为零。独立数据下，单个均值方差为原变量方差除以 TTT。若各期相关，设 γj=Cov⁡(ut,ut−j)\gamma_j=\operatorname{Cov}(u_t,u_{t-j})γj​=Cov(ut​,ut−j​)，则平稳序列的均值方差为

Var⁡(uˉ)=1T[γ0+2∑j=1T−1(1−jT)γj].\operatorname{Var}(\bar u)=\frac1T\left[\gamma_0+ 2\sum_{j=1}^{T-1}\left(1-\frac jT\right)\gamma_j\right].Var(uˉ)=T1​[γ0​+2j=1∑T−1​(1−Tj​)γj​].

这可以直接从 Var⁡(T−1∑tut)\operatorname{Var}(T^{-1}\sum_tu_t)Var(T−1∑t​ut​) 展开得到：每期自身方差之外，还要加上每一对观测的协方差。若一个消息影响连续几个月，就不能把每个月视为完全独立的证据。

向量矩条件的长期协方差记为 S=∑j=−∞∞Cov⁡(ht,ht−j)S=\sum_{j=-\infty}^{\infty}\operatorname{Cov}(h_t,h_{t-j})S=∑j=−∞∞​Cov(ht​,ht−j​)。在适当平稳、弱依赖和有限矩条件下，大样本中 Var⁡(gT(b0))≈S/T\operatorname{Var}(g_T(b_0))\approx S/TVar(gT​(b0​))≈S/T。后面的参数标准误和模型检验都由这份均值不确定性传递而来。

鲨鱼说

协方差，即两个变量偏离各自均值时，共同变化程度的度量。

条件多于参数时怎样折中

假设有 nnn 个矩条件、ppp 个参数。若 n=pn=pn=p 且条件足以识别参数，可以求解 gT(b^)=0g_T(\hat b)=0gT​(b^)=0。若 n>pn>pn>p，通常没有足够的参数让所有样本误差同时归零，这叫过度识别。

GMM 选择使加权误差最小的参数：

b^=arg⁡min⁡bgT(b)TWgT(b).\hat b=\arg\min_b g_T(b)^{\mathsf T}Wg_T(b).b^=argbmin​gT​(b)TWgT​(b).

WWW 是衡量误差的权重矩阵。若不同条件误差相关，非对角元素也有作用；它不只是逐项赋予几个百分比。另一种表述是选择 ppp 个矩条件的线性组合，使 agT(b^)=0ag_T(\hat b)=0agT​(b^)=0，其中 aaa 为 p×np\times np×n 矩阵。

例如两个独立样本都估计同一稳定收益均值，得到 0.6% 与 1.0%，标准误分别为 0.2% 与 0.6%。两个条件要求同一均值同时接近这两个读数。按精度加权时，权重与方差倒数成正比，较精确的第一组获得 90% 权重，合并估计为 0.64%。

这是用于理解矩条件权重的自拟数据。

Python10 行
means = [0.006, 0.010]
standard_errors = [0.002, 0.006]
precision = [1 / se**2 for se in standard_errors]
weights = [p / sum(precision) for p in precision]
estimate = sum(w * mean for w, mean in zip(weights, means))
combined_se = (1 / sum(precision)) ** 0.5
print("权重：", weights)
print(f"共同均值估计：{estimate:.3%}；标准误：{combined_se:.3%}")
assert abs(estimate - 0.0064) < 1e-12
assert abs(weights[0] - 0.9) < 1e-12

这里使用已知均值标准误演示加权。实际 GMM 中，SSS 通常未知，要由各期矩序列估计；条件相关时也不能直接按单项方差倒数处理。

参数误差怎样由矩误差传递

设 D=E[∂ht(b0)/∂bT]D=E[\partial h_t(b_0)/\partial b^{\mathsf T}]D=E[∂ht​(b0​)/∂bT]，它有 nnn 行、ppp 列。第 jjj 列表示第 jjj 个参数略微变化时，各个矩怎样变化。它相当于把“参数移动”和“误差移动”连接起来的局部换算表。

在真实参数附近作线性近似：gT(b^)≈gT(b0)+D(b^−b0)g_T(\hat b)\approx g_T(b_0)+D(\hat b-b_0)gT​(b^)≈gT​(b0​)+D(b^−b0​)。代入 agT(b^)=0ag_T(\hat b)=0agT​(b^)=0，得到

b^−b0≈−(aD)−1a gT(b0).\hat b-b_0\approx-(aD)^{-1}a\,g_T(b_0).b^−b0​≈−(aD)−1agT​(b0​).

右侧是有噪声的样本均值经过一次线性换算。因此

Var⁡(b^)≈1T(aD)−1aSaT(aD)−T.\operatorname{Var}(\hat b)\approx\frac1T (aD)^{-1}aSa^{\mathsf T}(aD)^{-\mathsf T}.Var(b^)≈T1​(aD)−1aSaT(aD)−T.

如果 aDaDaD 不可逆，说明这些条件不足以分别识别所有参数。即使可逆但接近退化，参数估计也可能很不稳定。

进阶推导：估计后的剩余矩与一般权重检验

把参数误差公式代回样本矩，令 M=I−D(aD)−1aM=I-D(aD)^{-1}aM=I−D(aD)−1a，得到

gT(b^)≈MgT(b0),Var⁡(gT(b^))≈1TMSMT.g_T(\hat b)\approx M g_T(b_0),\qquad \operatorname{Var}(g_T(\hat b))\approx\frac1T MSM^{\mathsf T}.gT​(b^)≈MgT​(b0​),Var(gT​(b^))≈T1​MSMT.

估计参数已经用掉 ppp 个误差方向，剩余只有 n−pn-pn−p 个独立方向。因此协方差通常不满秩，联合检验使用广义逆：

Ja=TgT(b^)T(MSMT)+gT(b^)∼aχn−p2.J_a=Tg_T(\hat b)^{\mathsf T} (MSM^{\mathsf T})^{+}g_T(\hat b) \overset{a}{\sim}\chi^2_{n-p}.Ja​=TgT​(b^)T(MSMT)+gT​(b^)∼aχn−p2​.

上标 aaa 表示渐近关系，不能当作任意小样本的精确分布。这个写法适用于所给 aaa 的一般推断；把任意权重下的目标函数直接当作标准 JJJ 统计量，会遗漏权重带来的尺度变化。

有效权重与两阶段估计

在给定正确矩条件下，W=S−1W=S^{-1}W=S−1 可得到渐近有效估计，对应 a=DTS−1a=D^{\mathsf T}S^{-1}a=DTS−1。它利用各项误差的大小与相关性，在这些信息中尽量准确地估计参数。这时

Var⁡(b^)≈1T(DTS−1D)−1,\operatorname{Var}(\hat b)\approx\frac1T(D^{\mathsf T}S^{-1}D)^{-1},Var(b^)≈T1​(DTS−1D)−1, J=TgT(b^)TS^−1gT(b^)∼aχn−p2.J=Tg_T(\hat b)^{\mathsf T}\hat S^{-1}g_T(\hat b) \overset{a}{\sim}\chi^2_{n-p}.J=TgT​(b^)TS^−1gT​(b^)∼aχn−p2​.

实际操作通常先令 W=IW=IW=I 获得初步参数。用它计算逐期矩和长期协方差 S^\hat SS^。再令 W=S^−1W=\hat S^{-1}W=S^−1 重新估计。矩序列有自相关时，长期协方差可用 Newey–West 估计。最优是针对给定矩条件的估计方差，不保证每一次样本中的估计都最接近真值。

四项资产怎样留下两个检验方向

回到消费模型，可以让无风险资产和市场超额收益的两个样本矩精确为零，据此估计 δ\deltaδ 与 γ\gammaγ；再查看规模和价值组合的剩余矩。如果剩余误差相对于其标准误过大，说明该消费模型与四项资产不能同时匹配。

这种选择回答的是具体经济问题：一个能解释无风险收益和市场风险补偿的消费模型，能否进一步解释规模与价值？也可以用四项矩共同估计两参数，但那是在不同条件之间折中，应使用相应权重下的标准误。四矩两参数保留两个过度识别自由度。只有两矩两参数时，没有额外限制用于此类检验。

鲨鱼说

矩条件表达模型要求成立的平均关系。明确这层经济含义后，再根据各条件的误差和相关性选择权重。例如，无风险毛收益与随机折现因子的乘积，其期望应为 1。将变量单位与支付口径代入这一关系，可以检查数据定义是否一致。

练习

某模型有两个参数，用两个资产的矩条件求得精确解，软件目标函数等于零。能否据此宣布模型通过严格检验？

查看解答

不能。两项可识别条件恰好用来估计两个参数，目标为零可以只是求解的结果。应加入具有独立经济含义的其他资产条件，或使用新的样本检验预测，才有未用于拟合的限制可供比较。
