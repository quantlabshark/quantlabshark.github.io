怎样从问题找到文献

文献检索围绕研究问题展开。价值因子研究需要联系指标定义、组合构造和基准模型；交易实施研究则需要联系换手、成本与持仓约束。记录这些环节，可以比较结论差异来自数据、方法还是市场条件。

阅读时记录研究问题、市场与时期、变量定义、组合权重、基准模型和核心结果。遇到新的统计方法，先读它在当前问题中的作用，再沿引用查其推导。复现论文时，优先选一张能够由数据和代码完整重建的主表。

鲨鱼说

两篇论文都研究“价值因子”，仍可能使用不同的账面权益口径、股票池或形成日期。将账面权益、股票池与形成日期并列比较，可以定位结论差异的具体来源。
