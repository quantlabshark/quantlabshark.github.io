泊松跳跃的链式法则

通过一次跳跃的函数变化量推导公式，区分跳前值和跳后值。

事件计数与条件均值

强度 λ\lambdaλ 的泊松过程在长度 hhh 的区间内新增事件数服从 Poisson⁡(λh)\operatorname{Poisson}(\lambda h)Poisson(λh)，均值和方差均为 λh\lambda hλh。不同不重叠区间的计数独立。给定时刻 sss 的记录，E[Nt∣Fs]=Ns+λ(t−s)E[N_t\mid\mathcal F_s]=N_s+\lambda(t-s)E[Nt​∣Fs​]=Ns​+λ(t−s)，所以 NtN_tNt​ 本身有正向平均增长。

减去这项可预测增长，令 Mt=Nt−λtM_t=N_t-\lambda tMt​=Nt​−λt，便有 E[Mt∣Fs]=Ns−λs=MsE[M_t\mid\mathcal F_s]=N_s-\lambda s=M_sE[Mt​∣Fs​]=Ns​−λs=Ms​。这就是补偿过程成为鞅的原因。λt\lambda tλt 可以不是整数；补偿过程既记录整数跳跃，也包含跳跃间连续下降。

补偿过程，即从事件计数或累计支付中减去其条件平均累积后得到的过程。
