交易间隔、ACD 与 Hawkes 强度

从交易间隔走向事件强度，推导 ACD 的长期均值与 Hawkes 的分支比率。

交易时间本身就是数据

相同价格变化，在一秒内连续出现和在半小时内缓慢出现，可能对应不同的市场状态。设第 iii 笔交易时间为 tit_iti​，间隔为 di=ti−ti−1>0d_i=t_i-t_{i-1}>0di​=ti​−ti−1​>0。开盘、午间和收盘的活跃度通常不同，应先区分日内季节性与短期聚集。

一种处理是估计正的时间尺度函数 s(t)s(t)s(t)，用 di/s(ti)d_i/s(t_i)di​/s(ti​) 去除规律性变化。对数间隔回归的指数变换对应几何尺度，若需要条件算术均值，还需考虑误差的指数矩。

ACD 预测下一次间隔

自回归条件间隔模型为

di=ψiϵi,ψi=ω+αdi−1+βψi−1,E(ϵi)=1.d_i=\psi_i\epsilon_i,\qquad\psi_i=\omega+\alpha d_{i-1}+\beta\psi_{i-1},\qquad E(\epsilon_i)=1.di​=ψi​ϵi​,ψi​=ω+αdi−1​+βψi−1​,E(ϵi​)=1.

正参数保证间隔均值非负。若 α+β<1\alpha+\beta<1α+β<1，平稳均值为 E(di)=ω/(1−α−β)E(d_i)=\omega/(1-\alpha-\beta)E(di​)=ω/(1−α−β)。取 ω=0.2\omega=0.2ω=0.2 秒、α=0.15\alpha=0.15α=0.15、β=0.75\beta=0.75β=0.75，长期平均间隔为两秒。

指数创新的条件密度为 ψi−1exp⁡(−di/ψi)\psi_i^{-1}\exp(-d_i/\psi_i)ψi−1​exp(−di​/ψi​)。Weibull 创新允许不同危险率形状，但必须缩放到均值一，才能把 ψi\psi_iψi​ 解释为条件均值。把 di−ψid_i-\psi_idi​−ψi​ 写成鞅差后，ACD 也可转化为 ARMA 型递推，类似于 GARCH 的平方误差结构。

Hawkes 直接预测事件到达率

计数过程 N(t)N(t)N(t) 的条件强度 λ(t)\lambda(t)λ(t) 满足：很短时间 dtdtdt 内，给定过去发生事件的概率约为 λ(t)dt\lambda(t)dtλ(t)dt。指数 Hawkes 模型为

λ(t)=μ+∑ti<tαe−β(t−ti).\lambda(t)=\mu+\sum_{t_i<t}\alpha e^{-\beta(t-t_i)}.λ(t)=μ+ti​<t∑​αe−β(t−ti​).

每次事件使强度增加 α\alphaα，随后按速率 β\betaβ 衰减到背景强度 μ\muμ。核积分 nb=α/βn_b=\alpha/\betanb​=α/β 是分支比率，表示一个事件平均直接激发多少后续事件。

当 nb<1n_b<1nb​<1 时，平稳平均强度为 λˉ=μ/(1−nb)\bar\lambda=\mu/(1-n_b)λˉ=μ/(1−nb​)。取 μ=0.4\mu=0.4μ=0.4、α=0.6\alpha=0.6α=0.6、β=1.2\beta=1.2β=1.2，得分支比率 0.50.50.5，平均强度 0.80.80.8 次每秒。平均簇大小为 1/(1−nb)=21/(1-n_b)=21/(1−nb​)=2。

从强度得到等待时间分布

若上一事件后强度沿给定路径变化，直到下一事件尚未发生时的等待生存概率为 P(D>d∣F)=exp⁡[−∫0dλ(ti+u)du]P(D>d\mid\mathcal F)=\exp[-\int_0^d\lambda(t_i+u)du]P(D>d∣F)=exp[−∫0d​λ(ti​+u)du]。常数强度 λ\lambdaλ 给出指数等待时间；时变或自激励强度则不再具有同一个固定平均间隔。

在指数 Hawkes 中，假设事件前恰为背景强度 μ=0.4\mu=0.4μ=0.4，新事件使强度增加 α=0.6\alpha=0.6α=0.6，衰减率为 β=1.2\beta=1.2β=1.2。随后一秒内没有新事件的概率为 exp⁡[−0.4−0.6(1−e−1.2)/1.2]≈0.4726\exp[-0.4-0.6(1-e^{-1.2})/1.2]\approx0.4726exp[−0.4−0.6(1−e−1.2)/1.2]≈0.4726。积分第二项表示这次事件留下的额外到达风险。

分支解释也能推导平均簇大小。一个背景事件平均产生 nbn_bnb​ 个直接后代，再产生 nb2n_b^2nb2​ 个第二代，如此相加为 1+nb+nb2+⋯=1/(1−nb)1+n_b+n_b^2+\cdots=1/(1-n_b)1+nb​+nb2​+⋯=1/(1−nb​)。因此平均强度等于背景强度乘以平均簇大小。这里“后代”是模型中的事件归因，不是已经识别出的经济因果。

鲨鱼说

强度的单位是每秒事件数，它乘一个很短时间才近似为概率。不能直接把大于一的强度当作概率，也不能在长时间窗口内一直使用线性近似。

取背景强度 μ=0.2\mu=0.2μ=0.2、事件冲击幅度 α=0.6\alpha=0.6α=0.6、衰减率 β=2\beta=2β=2，观察到事件时刻 t1=1,t2=2t_1=1,t_2=2t1​=1,t2​=2，截止时刻 T=3T=3T=3。μ,α\mu,\alphaμ,α 的单位为每单位时间，β\betaβ 决定冲击衰减的速度。

λ(2−)=0.2+0.6e−2≈0.2812.\lambda(2-)=0.2+0.6e^{-2}\approx0.2812.λ(2−)=0.2+0.6e−2≈0.2812.

鲨鱼说

ACD 从“下一笔要等多久”出发，Hawkes 从“此刻每秒可能来多少笔”出发。两者都描述交易时钟，但它们的状态和条件分布不同。
