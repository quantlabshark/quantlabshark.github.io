65 · 均线策略研究项目

按固定信号、执行时序和成本完成合成数据研究，计算指标并安排独立检验。

均线项目将数据处理、信号生成、下一日成交和账户核算连接起来。固定规则与基准采用相同资金和费用口径，再比较收益、回撤和换手。

定义均线策略与比较指标

项目比较固定20日、60日均线形成的多头/空仓规则与持续持有基准。快线高于慢线记信号1，否则0。信号产生后等待一个完整交易周期，在下一收盘时执行，随后才承担持有收益。目标是比较收益、波动、回撤和成本，参数在实验前固定。

数据用固定种子生成700个交易日的合成价格。合成数据使每个人能得到相同结果，也让我们明确知道收益生成过程。它没有提供真实资产的盈利证据。换用真实数据后，要重新处理复权、退市、可交易状态、费用及公开时间。

信号、成交与持仓时间表

记 sts_tst​ 为第 ttt 天收盘得到的信号，rt=Pt/Pt−1−1r_t=P_t/P_{t-1}-1rt​=Pt​/Pt−1​−1 为第 t−1t-1t−1 到 ttt 的收益。若 st−2s_{t-2}st−2​ 在 t−1t-1t−1 收盘执行，则承受 rtr_trt​ 的持仓是 wt=st−2w_t=s_{t-2}wt​=st−2​，因此代码使用 shift(2)。

时点 此时已知/发生的事 可以影响的最早收益
第60天收盘 首次有60日均线，产生信号 尚未持仓
第61天收盘 执行第60天信号 第61至62天
第62天收盘 记录第一段可能的持有收益 当日结果用于后续更新

这比笼统写“信号滞后一天”明确，因为不同软件的行标签可能代表区间起点或终点。代码最前61行持仓为0，是这一时序的直接结果。

逐期净收益与成本

单边成本率 c=0.0005c=0.0005c=0.0005，即5个基点。换手为 ∣wt−wt−1∣|w_t-w_{t-1}|∣wt​−wt−1​∣，0到1收一次，1到0再收一次。简化的净值比例模型用

1+Rtnet=(1−c∣wt−wt−1∣)(1+wtrt).1+R_t^{net}=(1-c|w_t-w_{t-1}|)(1+w_tr_t).1+Rtnet​=(1−c∣wt​−wt−1​∣)(1+wt​rt​).

从空仓变满仓，区间收益2%，则净收益 (1−0.0005)×1.02−1=1.949%(1-0.0005)\times1.02-1=1.949\%(1−0.0005)×1.02−1=1.949%；下期卖出变空仓且没有持有收益，成本使净值再乘0.9995。这一模型使用连续比例仓位，没有整股、税费、滑点和容量约束，后续可逐项替换为账户现金流模型。

一次生成全部逐期记录

程序保存价格、信号、持仓、换手、成本、策略与基准收益，以及双方净值。基准也收建仓和平仓成本。样本末尾按持仓增加一次平仓费用，采用同一净值比例近似。

import numpy as np
import pandas as pd

def experiment(seed=17,n=700,fee=.0005):
    rng=np.random.default_rng(seed)
    dates=pd.bdate_range('2020-01-01',periods=n)
    price=pd.Series(100*np.exp(np.cumsum(rng.normal(.0002,.012,n))),index=dates)
    ret=price.pct_change().fillna(0)
    fast=price.rolling(20,min_periods=20).mean()
    slow=price.rolling(60,min_periods=60).mean()
    signal=(fast>slow).astype(float).where(slow.notna(),0)
    # t-2收盘得到信号，t-1收盘执行，承担t-1至t的收益
    position=signal.shift(2).fillna(0)
    turnover=position.diff().abs().fillna(position.abs())
    cost=fee*turnover
    # 样本结束平仓，最后一期额外记一次卖出成本
    cost.iloc[-1]+=fee*position.iloc[-1]
    strategy=(1-cost)*(1+position*ret)-1
    baseline_cost=pd.Series(0.,index=dates)
    baseline_cost.iloc[1]=fee
    baseline_cost.iloc[-1]+=fee
    baseline=(1-baseline_cost)*(1+ret)-1
    out=pd.DataFrame({'price':price,'signal':signal,'position':position,
        'turnover':turnover,'cost':cost,'strategy_return':strategy,
        'baseline_return':baseline})
    out['equity']=(1+strategy).cumprod()
    out['baseline_equity']=(1+baseline).cumprod()
    return out

def describe(returns):
    equity=(1+returns).cumprod()
    # 起始净值1也纳入历史峰值
    peak=equity.cummax().clip(lower=1)
    return {'total_return':equity.iloc[-1]-1,
        'annualized_volatility':returns.std(ddof=1)*np.sqrt(252),
        'maximum_drawdown':(1-equity/peak).max()}

result=experiment()
assert len(result)==700 and result.iloc[:61].position.eq(0).all()
assert np.allclose(result.position.to_numpy()[2:],result.signal.to_numpy()[:-2])
for name in ['strategy_return','baseline_return']:
    print(name,describe(result[name]))

固定种子下，策略累计约−1.1587%、年化波动12.4982%、最大回撤20.9365%。基准约−18.3124%、18.4831%、36.0328%。策略亏得较少，同时持有风险也更少，应结合持仓时间解释。一个合成样本中优于基准，不代表规则能在其他路径维持优势。

图从净值1出发，同时画策略与基准，回撤由各自此前最高净值计算。初始1也必须进入峰值，否则一开始亏损时，程序会把首个低净值当作历史最高，漏掉这段回撤。

三个指标怎样从记录计算

累计收益为 ∏t(1+Rt)−1\prod_t(1+R_t)-1∏t​(1+Rt​)−1。年化波动采用日收益样本标准差乘 252\sqrt{252}252​，它依赖日频与年交易日近似。最大回撤为 max⁡t[1−Vt/max⁡(1,V1,…,Vt)]\max_t[1-V_t/\max(1,V_1,\ldots,V_t)]maxt​[1−Vt​/max(1,V1​,…,Vt​)]，反映从历史峰值向下走得最深的一段。

例如净值1、1.10、0.99、1.05，峰值依次1、1.10、1.10、1.10，回撤为0、0、10%、约4.545%，最大10%。累计最终仍赚5%，说明最终收益与期间损失是两种不同结果。回撤长度还描述恢复花了多久，可与深度共同报告。

训练、验证与最终检验

若将前60%即420天用于研究，后280天最终检验，应在使用数据前规定。若准备从多个窗口组合中选参数，需在前420天内部再划训练和验证。最终280天不参与窗口选择。指标形成可以读取测试前的历史价格作为回看窗口，但不能读取测试未来标签。

当前代码展示固定规则的整段结果，没有暗中做参数搜索。若另作分段评价，要明确测试段起点是继承已有持仓还是重新建仓，并正确收取转换成本。不能直接截取收益后宣称经历了不存在的建仓过程。

成本和延迟敏感性

先固定价格与信号，仅把单边费率设为0、5、10个基点，检查成本影响；再保持费率不变，调整信号产生至执行之间的等待周期，检查信号衰减。每项变化都有单一解释，便于识别收益下降来自成本还是时序。

进一步可限制每期成交量、不允许停牌成交、加入成交价偏移，并对未完成订单持续记账。应同时保存基线与压力结果，而不是仅保留表现最高的一列。多次试验本身就是研究过程的一部分，需要在最终报告列出尝试数量和选择依据。

保存代码、数据与研究记录

数据说明写清生成方式或来源、字段、时区与可用时点。参数文件固定窗口、成本、延迟和样本区间。逐期CSV保存所有中间量。报告给出策略/基准指标及敏感性。代码版本与依赖版本使别人能重算，失败结果则说明假设在哪里没有得到支持。

结论可以直接写“在该合成样本和指定时序下，策略亏损1.16%，最大回撤20.94%。持有基准亏损18.31%，最大回撤36.03%”。随后解释暴露与交易差异，再列真实数据研究尚需补充的机制，避免把流程演示夸成策略发现。

练习

1. 单边费率从5变10基点，做成本敏感性时是否重新选最优均线？

查看解答

不重新选。保持信号和窗口固定，才能隔离费用变化。重新选参数属于另一个研究，需要重新规定训练验证并保留独立测试。

2. 把 shift(2) 改成 shift(1)，改变的是哪段假设？

查看解答

使第 t−1t-1t−1 天收盘信号直接承担 t−1t-1t−1 到 ttt 的收益，相当于在产生信号的同一收盘完成执行。若信号只有收盘后才可计算，这就需要额外成交机制支持，不能仅视为代码优化。
