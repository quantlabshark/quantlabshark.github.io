例如终端值只记录是否超过阈值，当前条件期望就是未来超过阈值的概率，而不是现在位置是否超过阈值的零一判断。这一解释能把热方程的平滑作用与概率预测联系起来，也说明终端点的不光滑和内部时间的可微性可以同时存在。

剩余时间越长，高斯核越宽；接近终点时，质量向当前位置集中。三条曲线的面积均为一。

鲨鱼说

终端函数告诉我们最后要预测什么；高斯核告诉我们从现在的位置出发，未来可能落在哪里。把两者加权平均，就得到当前预测。剩余时间改变时，平滑范围也随之改变。
