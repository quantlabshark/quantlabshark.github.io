推导跨市场订单量的随机梯度，在给定市价量的例子中用成交样本求解最优分配。

下一股只有在前方队列和已提交数量都能成交后才有价值。指数尾概率使这种边际价值随分配数量下降，最优解把两处下降后的边际价值配到相同水平。

样本梯度与时间变化

本例每次产生两处订单流样本，并用 −w11{η1>Q1+l}+w21{η2>Q2+80−l}-w_1\mathbf1_{\{\eta_1>Q_1+l\}}+w_2\mathbf1_{\{\eta_2>Q_2+80-l\}}−w1​1{η1​>Q1​+l}​+w2​1{η2​>Q2​+80−l}​ 更新 lll。样本梯度很跳跃，但条件期望等于平滑目标的导数。

递减步长适合估计固定环境下的最优分配；持续变化的市场可能需要滚动重估或小的固定步长。评价应使用更新之后的后续窗口，并同时检查完成率、尾部成本和超额成交量。

鲨鱼说

条件期望，即给定已有信息后，对可能结果按条件概率求平均。

查看解答

对称情况下，边际条件给出 L1=L2=40L_1=L_2=40L1​=L2​=40。市场一队列增加后，给定数量下的成交尾概率下降，其边际节省减少，因此最优时应减少市场一的数量、增加市场二的数量，直到两边边际节省重新相等或到达边界。

鲨鱼说

“多分一股还有多大收益”比平均成交率更适合指导分配。平均成交率描述已有订单，边际概率描述下一股，两者不能互换。
