最大值变换：Lévy 与 Pitman 定理

从终点和历史最大值的联合密度，理解反射布朗运动与三维 Bessel 过程。

最大值和终点需要一起研究

令 Mt=max⁡s≤tWsM_t=\max_{s\le t}W_sMt​=maxs≤t​Ws​。仅知道最大值或终点的边缘分布，无法计算回撤 Mt−WtM_t-W_tMt​−Wt​。反射原理给出二者的联合密度：

pWt,Mt(x,m)=2(2m−x)2π t3/2exp⁡[−(2m−x)22t],p_{W_t,M_t}(x,m)=\frac{2(2m-x)}{\sqrt{2\pi}\,t^{3/2}} \exp\left[-\frac{(2m-x)^2}{2t}\right],pWt​,Mt​​(x,m)=2π​t3/22(2m−x)​exp[−2t(2m−x)2​],

定义域为 m≥max⁡(x,0)m\ge\max(x,0)m≥max(x,0)。这个约束很直观：历史最大值不能小于终点，也不能小于初值零。

推导可先对 x<mx<mx<m 写出被上边界 mmm 限制的终点密度 ϕt(x)−ϕt(2m−x)\phi_t(x)-\phi_t(2m-x)ϕt​(x)−ϕt​(2m−x)，其中 ϕt\phi_tϕt​ 是方差为 ttt 的正态密度，再对 mmm 求导。被减去的反射项恰好对应曾越过边界的路径。

鲨鱼说

反射原理，即通过反射首次到达某水平之后的路径，把越界事件与终点事件联系起来的方法。

对最大值上界求导

当 x<mx<mx<m 时，终点在 xxx 附近且此前没有超过 mmm 的密度为 ϕt(x)−ϕt(2m−x)\phi_t(x)-\phi_t(2m-x)ϕt​(x)−ϕt​(2m−x)。第一项是全部终点密度，第二项是反射后对应的越界路径。对 mmm 求导，第一项不变，第二项的导数为

−2ϕt′(2m−x)=2(2m−x)tϕt(2m−x).-2\phi_t'(2m-x)=\frac{2(2m-x)}{t}\phi_t(2m-x).−2ϕt′​(2m−x)=t2(2m−x)​ϕt​(2m−x).

写开 ϕt\phi_tϕt​ 就得到前面的联合密度。定义域的 m≥0m\ge0m≥0 来自初始点，x≤mx\le mx≤m 来自终点不超过历史最大值。密度只在这个区域积分，若忽略支持限制会导致概率不归一化。

从历史最大值回撤多少

定义 Rt=Mt−Wt≥0R_t=M_t-W_t\ge0Rt​=Mt​−Wt​≥0。变量变换 x=m−rx=m-rx=m−r 后，联合密度中的 2m−x2m-x2m−x 变为 m+rm+rm+r。对 m≥0m\ge0m≥0 积分：

pR(r)=∫0∞2(m+r)2πt3/2e−(m+r)2/(2t)dm=2πte−r2/(2t),r≥0.p_R(r)=\int_0^\infty\frac{2(m+r)}{\sqrt{2\pi}t^{3/2}}e^{-(m+r)^2/(2t)}dm =\sqrt{\frac2{\pi t}}e^{-r^2/(2t)},\quad r\ge0.pR​(r)=∫0∞​2π​t3/22(m+r)​e−(m+r)2/(2t)dm=πt2​​e−r2/(2t),r≥0.

因此每个固定时刻的 Mt−WtM_t-W_tMt​−Wt​ 与 ∣Wt∣|W_t|∣Wt​∣ 同分布。Lévy 定理给出更强的过程结论：回撤过程 (Mt−Wt)(M_t-W_t)(Mt​−Wt​) 与反射布朗过程 (∣Wt∣)(|W_t|)(∣Wt​∣) 具有相同的有限维分布。

这个过程结论不等于说两者由同一条 WWW 构造时逐点相等。证明整段过程的分布关系需要进一步处理转移结构；上面的单时刻密度计算只验证了边缘分布。

回撤过程的反射调节

把 Bt=−WtB_t=-W_tBt​=−Wt​ 看作另一个布朗运动，则 Mt−Wt=Bt+MtM_t-W_t=B_t+M_tMt​−Wt​=Bt​+Mt​。其中 Mt=max⁡s≤t(−Bs)M_t=\max_{s\le t}(-B_s)Mt​=maxs≤t​(−Bs​) 是使和保持非负所需的最小非减调节量；只有当反射过程处于零边界时，这个调节量才增加。这是半轴上的反射构造。

从正值 rrr 出发的反射布朗运动，在时间 hhh 后的转移密度为 ϕh(y−r)+ϕh(y+r)\phi_h(y-r)+\phi_h(y+r)ϕh​(y−r)+ϕh​(y+r)，y≥0y\ge0y≥0：第一项对应直接到达，第二项对应经零边界反射的路径。它与绝对值布朗运动的转移结构一致，这给出了 Lévy 回撤过程定理背后的机制，而不只是一张固定时刻直方图。

一个相关但不同的变换

Pitman 定理考虑 Yt=2Mt−WtY_t=2M_t-W_tYt​=2Mt​−Wt​。它非负，并且作为过程与从零出发的三维 Bessel 过程同分布。固定时刻的密度可从联合密度直接求出。

令 y=2m−xy=2m-xy=2m−x，则 x=2m−yx=2m-yx=2m−y。原定义域变为 0≤m≤y0\le m\le y0≤m≤y，变量变换的 Jacobian 为 1。因此

pY(y)=∫0y2y2πt3/2e−y2/(2t)dm=2πy2t3/2e−y2/(2t),y≥0.p_Y(y)=\int_0^y\frac{2y}{\sqrt{2\pi}t^{3/2}}e^{-y^2/(2t)}dm =\sqrt{\frac2\pi}\frac{y^2}{t^{3/2}}e^{-y^2/(2t)},\quad y\ge0.pY​(y)=∫0y​2π​t3/22y​e−y2/(2t)dm=π2​​t3/2y2​e−y2/(2t),y≥0.

Mt∣Yt=y∼U(0,y).M_t\mid Y_t=y\sim U(0,y).Mt​∣Yt​=y∼U(0,y).

这只是固定时刻的条件分布结论。Pitman 的过程定理还涉及随时间的转移结构，不能把上述条件均匀结论直接解释成“在观察整个变换历史后，隐含变量仍自动独立均匀”。过程定理在这里作为进一步的路径结果使用，边缘密度推导不冒充它的全部证明。

为什么不把最大值本身也当成反射布朗运动

MtM_tMt​、Mt−WtM_t-W_tMt​−Wt​ 和 ∣Wt∣|W_t|∣Wt​∣ 在固定时刻都具有半正态分布，但第一个过程单调不减，后两个可以下降。因此 MtM_tMt​ 与 ∣Wt∣|W_t|∣Wt​∣ 不具有相同过程分布。单时刻统计无法检测路径单调性。

相比之下，Lévy 与 Pitman 定理明确断言特定变换后的整个过程分布关系。这种结论可用于模拟替代与分布推导，但必须保留正确的变换形式，不能因为几个边缘分布相同就任意替换过程。

路径变换的直观作用

每次布朗路径刷新最高点，MtM_tMt​ 才增加。回撤 Mt−WtM_t-W_tMt​−Wt​ 在刷新最高点时回到零，在价格回落时上升。2Mt−Wt2M_t-W_t2Mt​−Wt​ 则把历史最大值再加回一次，形成与三维径向过程相同的分布结构。两种变换都由过去和当前值构造，所以适应原信息流，但其动力学不再是原来的布朗运动。

鲨鱼说 “同分布”应说明比较的是一个时刻的随机变量，还是多个时刻组成的过程。匹配均值、方差甚至每个时刻的直方图，都不足以保证路径关系正确。

还可以检查终点与最大值的交叉矩。由 Yt2=4Mt2−4MtWt+Wt2Y_t^2=4M_t^2-4M_tW_t+W_t^2Yt2​=4Mt2​−4Mt​Wt​+Wt2​，代入 E[Yt2]=3t\mathbb E[Y_t^2]=3tE[Yt2​]=3t、E[Mt2]=E[Wt2]=t\mathbb E[M_t^2]=\mathbb E[W_t^2]=tE[Mt2​]=E[Wt2​]=t，解得 E[MtWt]=t/2\mathbb E[M_tW_t]=t/2E[Mt​Wt​]=t/2。由于 E[Wt]=0\mathbb E[W_t]=0E[Wt​]=0，这也等于协方差。最大值与终点不是独立的，不能在计算回撤方差时直接忽略交叉项。
