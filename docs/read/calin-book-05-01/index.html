随机积分中的信息顺序与增量尺度

解释为何用左端点信息加权噪声，以及布朗增量的二阶、四阶矩如何决定积分规则。

适应与可预测

适应过程满足 HtH_tHt​ 在 ttt 时刻已知。构造一般随机积分时，常采用更精确的可预测性：权重由当前时刻之前可获得的信息决定。左连续适应过程和分段左端点权重都属于常用可预测过程。

对连续适应过程，通常不需要在“当前值”和“左极限”之间作区别；对跳跃过程却必须区分。NtN_tNt​ 在跳跃时已经包含本次跳跃，而 Nt−N_{t-}Nt−​ 只包含此前计数，后者才适合加权本次跳跃。

如果积分过程允许预先知道未来布朗增量，条件零均值性质会被破坏。独立增量说的是未来噪声与过去信息独立，不是允许把未来噪声本身加入过去信息后仍保持独立。

适应过程，即每个时点的取值都由当时的信息集确定的过程。

数值实现时的更新顺序

一个简单循环应先用当前状态计算权重，再生成新增量，累计 HiΔWiH_i\Delta W_iHi​ΔWi​，最后更新状态。如果先更新状态，再把新状态当作同一段的左端点权重，就会把伊藤和改成另一种和。代码中只交换两行，数学含义可能已经改变。

鲨鱼说 “步长很小”不能消除信息顺序错误。每段因使用未来端点而多出的偏差约为步长，段数约为步长的倒数，总偏差可以保持为常数。

若使用偷看未来符号的权重，长度 TTT 分为 nnn 段后，所谓“收益和”的均值是 n2(T/n)/π=2Tn/πn\sqrt{2(T/n)/\pi}=\sqrt{2Tn/\pi}n2(T/n)/π​=2Tn/π​，随着网格加密发散。这个结果不是布朗噪声中存在可事先获得的无风险收益，而是每段权重在看完结果后才确定。信息约束被破坏后，原有的零均值和等距性质不能继续使用。

对可预测权重，数值循环可以按“记录旧状态、计算权重、产生新增量、累计乘积、更新状态”的顺序实现。这样每一步对应一个明确的信息时间点，便于与数学定义逐项比较。
