1. 含缺失值的滚动方差

题目

输入实数序列 data 和正整数 window。返回等长列表：每个位置使用最近 window 个位置，忽略 NaN，以有效观测数减一为分母计算样本方差。前 window−1 个位置及有效值不足两个时返回 NaN。禁止调用 NumPy、Pandas 的方差函数，要求总时间为线性量级。

考点：中心矩；窗口增删；有效样本数。

查看分析与解答

必要知识

样本方差是离均差平方和除以有效样本数减一。窗口按位置移动，即使某位置为NaN也占一个位置；统计量则只考虑非缺失值，两种计数不能混用。

分析思路

保存有效数n、均值μ、中心平方和M₂以及退出窗口所需的队列。先推导加一个值的公式，删除公式可由总和关系反推，并单独处理有效值减到零或一。

解答步骤

新增x后均值μ′=(nμ+x)/(n+1)，所以位移d=μ′−μ=(x−μ)/(n+1)。旧观测偏差和为零，平移后其平方和增加nd²；再加入新项(x−μ′)²，合并得M₂′=M₂+(x−μ)(x−μ′)。删除时把等式反向使用，并由nμ−x=(n−1)μ′得到新均值。

维护当前窗口的有效计数 n、均值 μ 和离均差平方和 M2=∑(xi−μ)2M_2=\sum(x_i-\mu)^2M2​=∑(xi​−μ)2。新增 x 时使用 Welford 更新：令 δ=x−μ，更新 μ′=μ+δ/(n+1)\mu'=\mu+\delta/(n+1)μ′=μ+δ/(n+1)，再令 M2′=M2+δ(x−μ′)M_2'=M_2+\delta(x-\mu')M2′​=M2​+δ(x−μ′)。删除旧值 x 时，若 n>1，使用 μ′=μ−(x−μ)/(n−1)\mu'=\mu-(x-\mu)/(n-1)μ′=μ−(x−μ)/(n−1)、M2′=M2−(x−μ)(x−μ′)M_2'=M_2-(x-\mu)(x-\mu')M2′​=M2​−(x−μ)(x−μ′)。NaN 只占窗口位置，不参与统计。

from collections import deque
from math import isnan, isfinite, fsum

def rolling_var(data, window):
    if not isinstance(window, int) or window < 1:
        raise ValueError("window must be a positive integer")
    q, out = deque(), []
    n, mean, m2 = 0, 0.0, 0.0
    origin = None
    for i, raw in enumerate(data):
        x = float(raw)
        if not isnan(x) and not isfinite(x):
            raise ValueError("infinite observations are not supported")
        q.append(x)
        if not isnan(x):
            if origin is None:
                origin = x
            shifted = x - origin
            n += 1
            delta = shifted - mean
            mean += delta / n
            m2 += delta * (shifted - mean)
        if len(q) > window:
            old = q.popleft()
            if not isnan(old):
                old -= origin
                if n == 1:
                    n, mean, m2 = 0, 0.0, 0.0
                else:
                    new_mean = mean - (old - mean) / (n - 1)
                    m2 -= (old - mean) * (old - new_mean)
                    n -= 1
                    mean = new_mean
                    if n == 1:
                        m2 = 0.0
        if (i + 1) % window == 0:
            valid = [value for value in q if not isnan(value)]
            n = len(valid)
            if n:
                origin = valid[0]
                centered = [value - origin for value in valid]
                mean = fsum(centered) / n
                m2 = fsum((value - mean)**2 for value in centered)
            else:
                origin, mean, m2 = None, 0.0, 0.0
        if n >= 2 and m2 < 0:
            raise ArithmeticError("中心平方和为负，需提高计算精度或调整数值尺度")
        out.append(m2 / (n - 1)
                   if i >= window - 1 and n >= 2 else float("nan"))
    return out

a = rolling_var([1, float("nan"), 3, 5, 7], 3)
assert isnan(a[0]) and isnan(a[1])
assert a[2:] == [2.0, 2.0, 4.0]
assert all(isnan(v) for v in rolling_var([1, 2], 1))

以窗口 [1, NaN, 3] 为例，有效值为 1 和 3，均值为 2，平方偏差和为 2，样本方差为 2/(2−1)=2。窗口右移成 [NaN, 3, 5]，删除 1、加入 5 后仍得到方差 2。

代码先减去参考值 origin，再维护平移后的均值；方差不受常数平移影响。例如观测在 10¹² 附近、波动约 0.01 时，先减去一个窗口内观测值，后续运算处理的便是百分位附近的小数，而非反复相减的巨大均值。每隔 window 步，用当前窗口重新设置参考值，并以 fsum 重算中心矩，限制增删误差的累计。每次重算至多处理 window 项，在 n 项输入中进行至多 n/window 次，总时间仍为 O(n)，窗口空间 O(window)，输出空间另计。

窗口[1,NaN,3]虽有三位置，有效n=2，故分母是一。窗口为一时无论是否有效都不够计算样本方差。代码不会把负的中心平方和直接截成零；若出现这种数值异常，会明确报错。参考值平移与定期重算也不能恢复输入转为浮点数时已经丢失的精度。

同类问题

滑动统计先区分窗口长度和有效样本数，再寻找可增删的充分统计量。数值稳定性与渐近复杂度都要检查，尤其是大基数、小波动的数据。

2. 过去五日全股票标准化

题目

输入含 date、ticker、factor 三列的数据，每个日期与股票组合唯一，日期覆盖所需交易日历。每日使用此前五个交易日（不含当日）的全部有效因子观测，共同估计均值与总体标准差，再标准化当日因子。输出保留全部输入行。历史不足或标准差为零时返回缺失。

考点：历史窗口；加权合并；防止未来信息。

查看分析与解答

必要知识

题目要求把过去五日全部股票观测放在同一个样本池中，每条有效观测等权。它不同于每日截面标准化，也不同于先求五个日均值再平均。总体标准差的分母是有效总数而非总数减一。

鲨鱼说

每日先平均再平均，相当于每一天一票；把所有股票观测合起来平均，则是每条观测一票。股票数量不同时，这两种权重回答的是不同问题。

分析思路

按日汇总个数、和及平方和，先shift一天排除当日，再滚动五日合并。把得到的同一历史均值和尺度连接到当日每只股票。

解答步骤

一日只有0、另一日有九个10时，总和90、总数10，均值9。日均值等权却给(0+10)/2=5，过度放大了样本少的那一天。代码固定原点origin只是数值平移：E[(X−origin)²]−E[X−origin]²仍等于Var(X)。

设过去五日有效样本数为 ndn_dnd​，因子和为 sds_dsd​，平方和为 qdq_dqd​。合并后的均值是 μ=∑dsd/∑dnd\mu=\sum_ds_d/\sum_dn_dμ=∑d​sd​/∑d​nd​，总体方差是 ∑dqd/∑dnd−μ2\sum_dq_d/\sum_dn_d-\mu^2∑d​qd​/∑d​nd​−μ2。每日股票数不同时，先算日均值再等权平均会改变观测权重。例如两日分别只有值 0 和九个值 10，合并均值为 9，而日均值的平均只有 5。按日保存有效个数、中心化值的和及平方和，移位一日后滚动五日汇总，再恢复共同均值与总体方差。

下面把输入出现的日期视为完整交易日历。若有整日缺失，应先用交易日历补齐，明确缺失日口径。

import numpy as np
import pandas as pd

def rolling_all_normalize(df):
    x = df.copy()
    x['date'] = pd.to_datetime(x['date'])
    if x.duplicated(['date','ticker']).any():
        raise ValueError('日期与股票组合重复')
    x = x.sort_values(['date','ticker'])
    good = x['factor'].dropna()
    origin = float(good.iloc[0]) if len(good) else 0.0
    x['_z'] = x['factor']-origin
    x['_z2'] = x['_z']**2
    daily = x.groupby('date').agg(n=('_z','count'), s=('_z','sum'), q=('_z2','sum'))
    hist = daily.shift(1).rolling(5, min_periods=5).sum()
    mean_z = hist['s']/hist['n'].replace(0,np.nan)
    var = (hist['q']/hist['n'].replace(0,np.nan)-mean_z**2).clip(lower=0)
    stats = pd.DataFrame({'_mean':mean_z+origin,'_std':np.sqrt(var).replace(0,np.nan)})
    x = x.join(stats,on='date')
    x['normalized'] = (x['factor']-x['_mean'])/x['_std']
    return x.drop(columns=['_z','_z2','_mean','_std'])

test = pd.DataFrame({'date':pd.date_range('2020-01-01',periods=6),'ticker':['A']*6,'factor':range(1,7)})
out = rolling_all_normalize(test)
assert out['normalized'].iloc[:5].isna().all()
assert np.isclose(out['normalized'].iloc[5],3/np.sqrt(2))

固定原点中心化减少平方差消减，极端动态范围可进一步采用可合并的均值与二阶中心矩。零标准差返回缺失，不除以零。

样例第六天值6，历史五天为1至5，均值3、总体方差[(−2)²+(−1)²+0²+1²+2²]/5=2，所以标准化为3/√2。前五天历史不足均缺失。若整日没有任何行，须先补交易日索引，否则rolling(5)只数五个出现过的日期，可能跨过应计入的缺失交易日。

同类问题

滚动因子题先固定观察单位、日历和信息截止时点。检查shift发生在哪一步，并用当日极端值验证它没有进入自己的历史估计。

3. 稳健标准化、相关与残差

题目

给定因子 A、B 两张表，均含 date、ticker、factor，键唯一。完成三项任务：（1）每个因子每日用位于 1% 与 99% 分位数之间的样本估计均值和总体标准差，对全部样本标准化并截至 [−3,3]。（2）计算每日配对 Pearson 相关，再形成按年、月排列的日相关均值表。

（3）每日用标准化后的 B 对 A 作含截距 OLS，输出与 A 行数一致的残差 C。

考点：稳健尺度；配对样本；OLS正交残差。

查看分析与解答

必要知识

分位区间用于估计尺度，不是删除输出行。相关与回归必须使用两因子都存在的同一组股票，否则两边均值不属于相同样本。含截距回归等价于先对配对样本中心化再求斜率。

分析思路

分别标准化A、B，再按日期和股票一对一连接。日内计算共同有效样本的均值、平方和及交叉和，生成相关和残差；月表最后对日相关平均。

解答步骤

若核心因子为2、3、4，均值3、总体标准差√(2/3)。原始尾部值1和5仍按这个尺度转换，而不是消失。若转换结果超出±3才截断，这与先把原始值压到分位点的缩尾处理不同。

使用每日百分之一及九十九分位数作闭区间筛选。分位点并列可能使实际保留比例略异于百分之九十八。以下为总体标准差、含截距 OLS，先按日期与股票一对一配对。B 缺失的 A 行保留但残差为缺失。如果原始 B 的当日核心标准差为零，标准化 B 未定义，该日残差为缺失。如果 B 已能标准化，但在与 A 配对后的子样本内恰为常数，回归才退化为截距模型。

import numpy as np
import pandas as pd

def robust_standardize(df):
    x = df.copy()
    x['date'] = pd.to_datetime(x['date'])
    if x.duplicated(['date','ticker']).any():
        raise ValueError('日期与股票组合重复')
    g = x.groupby('date')['factor']
    lo = g.transform(lambda v:v.quantile(.01))
    hi = g.transform(lambda v:v.quantile(.99))
    core = x['factor'].where(x['factor'].between(lo,hi))
    cg = core.groupby(x['date'])
    mean = cg.transform('mean')
    std = cg.transform(lambda v:v.std(ddof=0)).replace(0,np.nan)
    x['z'] = ((x['factor']-mean)/std).clip(-3,3)
    return x

def factor_outputs(a,b):
    aa,bb = robust_standardize(a),robust_standardize(b)
    m = aa[['date','ticker','z']].rename(columns={'z':'A'}).merge(
        bb[['date','ticker','z']].rename(columns={'z':'B'}),on=['date','ticker'],how='left',validate='one_to_one')
    valid = m['A'].notna() & m['B'].notna()
    av,bv = m['A'].where(valid),m['B'].where(valid)
    da = av-av.groupby(m['date']).transform('mean')
    db = bv-bv.groupby(m['date']).transform('mean')
    cov = (da*db).groupby(m['date']).sum(min_count=1)
    va = (da*da).groupby(m['date']).sum(min_count=1)
    vb = (db*db).groupby(m['date']).sum(min_count=1)
    daily = cov/np.sqrt(va*vb).replace(0,np.nan)
    monthly = daily.groupby([daily.index.year,daily.index.month]).mean().unstack().reindex(columns=range(1,13))
    beta = (cov/vb.replace(0,np.nan)).where(vb!=0,0)
    m['C'] = da-db*m['date'].map(beta)
    return aa,bb,daily,monthly,m[['date','ticker','C']]

题目

各轮先独立等概率抽取赌注 Xi∈{1,2}X_i\in\{1,2\}Xi​∈{1,2}，再独立抛硬币，正面概率 p<1p<1p<1。正面赚取该轮赌注并继续，首次反面扣除该轮赌注并结束。求停止时累计净收益 YYY 的均值和方差。

考点：几何分布；随机和；全方差。

查看分析与解答

必要知识

N数的是首次反面之前的正面次数，因此可为零，均值p/q而非1/q。最终一轮的赌注仍随机，且符号为负。给定N后，独立赌注的均值可按符号相加，方差却都以正号相加。

分析思路

先条件在N=n上，把随机长度和变成固定长度和，再对N求全期望与全方差。方差分成赌注本身波动和停止次数波动两部分。

解答步骤

赌注1、2各半，均值1.5，平方均值2.5，故方差2.5−2.25=0.25。条件N=n时共有n+1笔赌注，最后一项乘−1不改变其方差，所以条件方差v(n+1)，条件均值却为μ(n−1)。

设首次反面前共有 NNN 次正面，q=1−pq=1-pq=1−p。则 P(N=n)=pnqP(N=n)=p^nqP(N=n)=pnq，E[N]=p/qE[N]=p/qE[N]=p/q，Var⁡(N)=p/q2\operatorname{Var}(N)=p/q^2Var(N)=p/q2。赌注均值为 μ=3/2\mu=3/2μ=3/2，方差为 v=1/4v=1/4v=1/4，并且赌注序列与硬币序列独立。

累计收益为 Y=∑i=1NXi−XN+1Y=\sum_{i=1}^NX_i-X_{N+1}Y=∑i=1N​Xi​−XN+1​。给定 N=nN=nN=n 后，前 nnn 项赚入、最后一项扣除，因此 E[Y∣N]=μ(N−1),Var⁡(Y∣N)=v(N+1).E[Y\mid N]=\mu(N-1),\qquad \operatorname{Var}(Y\mid N)=v(N+1).E[Y∣N]=μ(N−1),Var(Y∣N)=v(N+1). 取期望得到 E[Y]=32(pq−1)=3(2p−1)2q.E[Y]=\frac32\left(\frac pq-1\right)=\frac{3(2p-1)}{2q}.E[Y]=23​(qp​−1)=2q3(2p−1)​. 再应用全方差公式： Var⁡(Y)=E[Var⁡(Y∣N)]+Var⁡(E[Y∣N])\operatorname{Var}(Y)=E[\operatorname{Var}(Y\mid N)]+\operatorname{Var}(E[Y\mid N])Var(Y)=E[Var(Y∣N)]+Var(E[Y∣N]) =14(pq+1)+94pq2=1+8p4q2.=\frac14\left(\frac pq+1\right)+\frac94\frac p{q^2}=\frac{1+8p}{4q^2}.=41​(qp​+1)+49​q2p​=4q21+8p​. 公平币 p=1/2p=1/2p=1/2 时均值为 0、方差为 5；p=0p=0p=0 时只扣一次赌注，均值为 −3/2-3/2−3/2、方差为 1/41/41/4，与公式一致。p=1p=1p=1 时不会停止，因而不适用上述停止收益公式。

E[v(N+1)]=v/q代表固定轮数下赌注大小的波动；Var(μ(N−1))=μ²p/q²代表轮数变化。p=1/2时两部分为0.5和4.5，总方差5。均值为零并不意味着路径风险小，也不意味着每次最终收益接近零。

同类问题

随机次数之和可先对次数条件化；若停止规则还依赖赌注大小，次数与赌注不再独立，不能直接沿用本题的条件分布。
