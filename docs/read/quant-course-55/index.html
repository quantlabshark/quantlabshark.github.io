55 · TWAP、VWAP与最优执行

将完整任务成本、冲击与库存风险联系起来，推导并验证分段清算路径。

执行计划把总交易数量分配到多个时段。TWAP 按时间安排，VWAP 参考成交量分布，最优执行进一步权衡价格冲击与等待期间的持仓风险。

成交基准与下单计划

卖出一万股需要一小时。均分四个15分钟区间，每段2500股，是TWAP式计划。若预测四段市场成交量占比为10%、20%、40%、30%，按1000、2000、4000、3000股安排，是VWAP式计划。两种计划都需要把总任务转换成各时段数量。

TWAP、VWAP首先是价格基准。等长时间格上的TWAP是价格均值，市场VWAP为 ∑pivi/∑vi\sum p_iv_i/\sum v_i∑pi​vi​/∑vi​，其中 viv_ivi​ 是市场成交量。自己的成交均价用自己的成交量加权。自拟四段价格10、11、9、10，市场成交量1、2、4、3，TWAP为10，VWAP为9.8。市场较多成交发生在低价9，因此VWAP更低。

当天完整成交量曲线只能事后知道。执行时使用历史预测与实时更新，不能在回测开盘就读取当日真实全天曲线。POV则把下单量与已经观察到或估计的市场成交量按比例关联，低活跃时可能留下较多残单。

卖出损失的符号

以决策时中间价 S0S_0S0​ 为基准，卖出 QQQ 股的损失为 S0Q−∑piui+费用S_0Q-\sum p_iu_i+\text{费用}S0​Q−∑pi​ui​+费用；卖价越低，损失越大。买入任务则是实际支出减基准支出。基准时点可以是研究决策、订单到达或执行开始，但须固定，以便区分发送延迟和执行过程的成本。

例如基准10元，卖出1000股平均9.98元，另付5元费用，损失为 10000−9980+5=2510000-9980+5=2510000−9980+5=25 元，即每股0.025元；除以基准名义金额为0.25%，也就是25个基点。股数、元和基点之间要经过这两次明确换算。

等待为什么也是一种成本

令 x(t)x(t)x(t) 为剩余股数，v(t)=−x′(t)v(t)=-x'(t)v(t)=−x′(t) 为每单位时间卖出数量。卖得快会更强地消耗流动性；卖得慢则长时间暴露于价格变化。设每股暂时冲击为 ηv\eta vηv，单位时间成本为“每股冲击×成交速度”，即 ηv2\eta v^2ηv2。

未受影响价格为 dS=σdWdS=\sigma dWdS=σdW，持有库存 xxx 的随机价格损益为 xσdWx\sigma dWxσdW。对确定库存路径，累计损益方差为 σ2∫x(t)2dt\sigma^2\int x(t)^2dtσ2∫x(t)2dt。把平均冲击与风险惩罚相加：

数值计算与独立核对

将股数、时间归一为1，取 η=1,λσ2=4\eta=1,\lambda\sigma^2=4η=1,λσ2=4，故 κ=2\kappa=2κ=2。以下程序计算路径和目标，并与匀速比较。

Python13 行
import numpy as np
Q, T, eta, risk = 1.0, 1.0, 1.0, 4.0  # risk = lambda*sigma^2
kappa = np.sqrt(risk/eta)
t = np.linspace(0,T,2001)
x = Q*np.sinh(kappa*(T-t))/np.sinh(kappa*T)
speed = Q*kappa*np.cosh(kappa*(T-t))/np.sinh(kappa*T)
integrand = eta*speed**2 + risk*x**2
cost = np.sum((integrand[1:]+integrand[:-1])*np.diff(t)/2)
twap_cost = eta*Q**2/T + risk*Q**2*T/3
print('最优目标、TWAP目标', cost, twap_cost)
print('四段成交比例', -np.diff(Q*np.sinh(kappa*(T-np.linspace(0,T,5)))/np.sinh(kappa*T)))
assert np.isclose(x[0],Q) and np.isclose(x[-1],0)
assert cost < twap_cost

四段成交比例约41.29%、26.31%、18.04%、14.37%，合计100%。模型最优目标约2.07463，匀速目标2.33333。数值目标的单位是本例归一化成本，不是投资收益率。

J∗=ηκQ2coth⁡(κT).J^*=\eta\kappa Q^2\coth(\kappa T).J∗=ηκQ2coth(κT).

代入参数得到2.074629，与数值积分接近。解析值、端点条件、总成交量三项分别检查，可区分求积误差与路径实现错误。

永久冲击与动态执行

在线性永久冲击且总数量固定的简化模型中，永久冲击常化为只与 Q2Q^2Q2 有关的固定项，因此不改变上述时间安排。瞬态恢复、非线性冲击、价格预测或随机流动性加入后，目标会依赖更多状态，原确定路径就不一定最优。

离散动态规划可在每段选择交易量，把当前冲击成本与剩余任务价值相加。连续时间HJB则表达同一个“当前动作＋未来价值”的比较。参与率上限、最小单位和库存方向约束必须进入可行动作集合。将解析数量四舍五入后，要补齐残量并重新计算可行性和成本。

比较算法时保留未完成任务

只统计已成交部分的均价会偏爱慢策略，因为难成交的残单被排除。应共同报告整笔订单的实现缺口、完成率、尾部成本与截止库存。强制终点清仓与允许残单罚款是两种不同问题，应使用各自明确的终端条件。

鲨鱼说

终端条件，即在决策期限末端规定的价值或支付。

两期版本让最优安排可以手算

把任务归一为1，两期各自冲击系数为1。第一期卖 uuu，第二期卖 1−u1-u1−u；两期之间对剩余库存按系数2罚风险。目标为 J(u)=u2+(1−u)2+2(1−u)2J(u)=u^2+(1-u)^2+2(1-u)^2J(u)=u2+(1−u)2+2(1−u)2。展开求导 J′(u)=8u−6J'(u)=8u-6J′(u)=8u−6，得到第一期 u=0.75u=0.75u=0.75、第二期0.25。

匀速各半时目标为 0.25+0.25+0.5=10.25+0.25+0.5=10.25+0.25+0.5=1；最优安排目标为 0.5625+0.0625+0.125=0.750.5625+0.0625+0.125=0.750.5625+0.0625+0.125=0.75。提前卖出把冲击从0.5提高到0.625，却把风险从0.5降到0.125，合计改善。这一分解比仅报告“总成本下降”更能说明风险厌恶的作用。

若第一期参与率限制最多0.6，解析解0.75不可行。凸目标在允许区间内最小点变为0.6，第二期0.4，目标0.84。离散动态规划和带约束优化做的就是把类似比较扩展到更多时段和状态。

报价基准会改变相对成绩

同一买入任务均价10.01元，若到达中间价10.00，实现缺口为每股0.01元。若当日市场VWAP10.02，则相对VWAP便宜0.01元。两个判断同时成立，因为它们回答不同问题。前者包含等待期间价格变化，后者比较相对市场成交分布的位置。

若价格一整天上涨，缓慢执行可能贴近VWAP却相对到达价很差。若任务来自必须当日完成的组合调整，应按实际目标选择基准。不能事后从多个基准中只展示最好看的一个。所有比较都使用同一方向、数量、时间窗口和费用口径。

练习

1. 风险系数 λσ2\lambda\sigma^2λσ2 变成4倍，κ\kappaκ 和库存路径怎样变化？

查看解答

κ\kappaκ 变成2倍。相同终点下库存更早下降，前段成交增加；平均冲击成本可能提高，但库存风险下降。

2. 买入500股，基准20元、实际均价20.03元、费用2元，实现缺口多少元及基点？

查看解答

损失 500×0.03+2=17500\times0.03+2=17500×0.03+2=17 元。基准金额10000元，缺口为0.17%，即17个基点。
