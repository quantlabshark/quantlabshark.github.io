逆向、价值与宏观策略的收益机制

从现金流、风险暴露和投资者行为解释策略收益，明确估值误差与持有期限的影响。

便宜、下跌与低估不是同一件事

逆向策略常买入近期表现较差的资产，价值策略常买入价格相对基本面较低的资产。两者可能重合，但逻辑不同。一家公司股价下跌后，如果未来现金流下降得更多，估值反而可能更贵。

价值分析把未来现金流折现。若第 ttt 年预期现金流为 CtC_tCt​，折现率为 kkk，则有限期现值为 ∑t=1TCt/(1+k)t\sum_{t=1}^TC_t/(1+k)^t∑t=1T​Ct​/(1+k)t，还需计入期末价值。现金流、折现率和终值增长率中的微小误差，都会改变估值，尤其是长期增长部分。

设下一年现金流为 5，之后永久增长率为 g=2%g=2\%g=2%，折现率为 k=8%k=8\%k=8%，则增长永续模型给出 V=5/(0.08−0.02)=83.33V=5/(0.08-0.02)=83.33V=5/(0.08−0.02)=83.33。若折现率升至 9%9\%9%，价值降为 71.4371.4371.43。价格变化可能来自风险要求改变，不必对应投资者情绪错误。

行为机制如何进入可检验假设

过度反应意味着价格对信息的反应超过其长期影响，随后可能反转。反应不足意味着信息逐步进入价格，随后可能延续。两种机制对应不同时间尺度。设计研究时应明确观察窗口、持有窗口和事件类型，再检验条件收益是否符合假设。

价值与动量也可以在股票、债券、外汇和商品等不同资产上定义，但信号单位和融资条件不同。跨资产比较前，应按风险尺度标准化，分离共同市场风险、期限风险和流动性风险。横截面排序产生的收益并不自动证明某一种心理机制，多个经济机制可能给出相似结果。

前景理论怎样改变风险选择

前景理论以相对参考点的得失为对象。一个常用价值函数为

参考点变化会改变同一价格的心理含义：一只股票相对买入价亏损，却可能相对昨日上涨。实际建模必须明确参考点如何确定，不能事后随结果选择。

在累积前景表达中，先把结果排序，再由累计概率的权重差得到各结果的决策权重。这样处理多个结果时能够保留排序关系。若所有结果都非负，设 0≤x1<⋯<xn0\le x_1<\cdots<x_n0≤x1​<⋯<xn​，可写为

全球宏观策略的传导链

宏观策略研究利率、通胀、经济周期和资金流对资产价格的影响。一个判断需要写成传导链：变量如何变化，影响哪一类现金流或折现率，通过什么工具表达，何时可能被市场提前定价。

例如认为利率下降会推高债券价格，可以用久期近似 ΔP/P≈−DΔy\Delta P/P\approx-D\Delta yΔP/P≈−DΔy。久期为 5、收益率下降 0.5 个百分点，对应价格约上涨 2.5%2.5\%2.5%。但持有期间还受到曲线非平行变动、信用利差、融资成本和汇率的影响。这些变量可以直接纳入情景表。

鲨鱼说

一个故事能解释已经发生的收益，并不意味着它给出了事前可执行的信号。研究需要把“何时判断”和“何时交易”写在同一条时间线上。
