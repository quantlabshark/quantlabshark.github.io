20 · 移动平均怎样生成趋势持仓

手算短长均线，区分状态与交叉事件，用下一开盘成交检验趋势和反复交易。

移动平均平滑近期价格，快慢均线之差反映不同时间尺度的变化。将均线关系写成持仓规则后，还需确定成交时间和费用，才能计算策略收益。

移动窗口包含哪些价格

价格连续上涨时，三日均价通常比五日均价更快上移；价格转跌时，它也更快下移。双均线规则把这种速度差变成持仓条件，但反应速度同时影响交易频率和滞后。

收盘价为 PtP_tPt​，长度为 LLL 的简单移动平均定义为 MAL,t=(Pt+Pt−1+⋯+Pt−L+1)/LMA_{L,t}=(P_t+P_{t-1}+\cdots+P_{t-L+1})/LMAL,t​=(Pt​+Pt−1​+⋯+Pt−L+1​)/L。下一个交易日到来时，加入一个新价格、删除一个最旧价格，因此窗口向前移动。

自拟前五日收盘为 10、10、10、11、12。第五日三日均值为 (10+11+12)/3=11(10+11+12)/3=11(10+11+12)/3=11，五日均值为 53/5=10.653/5=10.653/5=10.6。短均线更高，是因为它给最近较高的价格分配了更大的总权重。

第六日收盘降到 11，三日均线仍为 (11+12+11)/3≈11.333(11+12+11)/3\approx11.333(11+12+11)/3≈11.333，五日均线为 10.8。价格当日下跌不代表均线状态立即转空。均线平滑了变化，也因此滞后于转折。

状态与交叉事件不要混用

一种状态规则是短均线高于长均线时目标持仓 10 股，否则为零。只要条件持续成立，目标保持 10 股。交叉事件则要求昨天短均线不高于长均线、今天变成高于，才产生一次买入事件。

状态可以直接计算目标持仓，交叉事件需要结合当前持仓更新。把“短均线高于长均线”的每一天都当作增加持仓，会无意间形成不断加仓的另一套策略。

开始几天不足五个观测时，五日均线尚未定义。此处要求完整窗口后才产生信号，前四日空仓。用已有一两天均价代替五日均价也可以构成另一规则，但其早期含义不同。

图中均线都包含当日收盘，持仓在下一开盘改变。短线先上穿后下穿，显示了趋势反应与迟滞；持仓阶梯没有在每个正信号日重复增加。

把均线规则放进现金账本

以下程序仅用标准库。价格为自拟，初始现金 1000 元，交易一次收取 1 元固定费用。短长窗口为 3 与 5，目标为 10 股或零。

Python14 行
closes = [10,10,10,11,12,11,10,9,10,11,12,11]
opens = [10,10,10,10.5,11.5,12,10.5,9.5,9.5,10.5,11.5,12]
def average_at(values,index,window):
    return sum(values[index-window+1:index+1])/window if index+1>=window else None
cash, shares, target = 1000.0,0,0
for i,(op,cl) in enumerate(zip(opens,closes)):
    order = target-shares
    cash -= order*op + (1 if order else 0)
    shares = target
    short,long = average_at(closes,i,3),average_at(closes,i,5)
    target = 10 if long is not None and short>long else 0
    print(i+1,"短线",short,"长线",long,"成交股数",order,"资产",round(cash+shares*cl,2))
print("最终资产:",cash+shares*closes[-1])
assert abs(cash+shares*closes[-1]-962) < 1e-10

第五日收盘形成多头状态，第六日开盘按 12 元买入 10 股。第八日收盘转为空仓状态，第九日按 9.5 元卖出，这一轮价差亏损 25 元、费用 2 元。第十一日再次转多，第十二日按 12 元买入，收盘 11 元，账户最终为 962 元，仍持有 10 股。

这个例子说明，趋势规则可以在反转时承受亏损，均线信号并不会把历史转折点提前告诉交易者。图上事后看起来明显的最低点，在当时还没有后面的价格来确认。

参数改变的是响应与交易成本

较短窗口对新信息反应快，也容易在震荡中频繁改变状态；较长窗口减少短期噪声，却更晚进入和退出。指数移动平均给近期更大权重，是另一种平滑方式，需要明确衰减参数。

可以设置均线差超过某个比例才开仓、回到另一阈值才平仓，以减少微小波动造成的反复切换，但这又增加了参数。窗口、阈值、持仓规模和费用必须在验证程序中一起考虑，不能看到回测结果后只调整最有利的一项。

趋势策略可能以较多小亏损换取少数持续趋势中的收益，因此胜率不是唯一指标。应比较交易次数、持仓时间、每笔盈亏分布、成本、最大回撤，以及相同时间范围的持有基准。

平滑减少噪声，也改变响应时间

考虑价格从连续五天的 100 突然跳到 110，并保持不变。三日均线第一次升到约 103.33，第三天才能完全达到 110。五日均线第一次只升到 102，第五天才完全达到 110。长窗口用更多旧价格平滑了跳变，也保留了更长时间的旧状态。

居中移动平均把某个时点前后两边的数据一起平均，图形通常更贴近趋势，但右侧数据在当时尚未出现，所以不能直接用它产生历史交易信号。研究图与可执行特征应明确区分。

除了价格均线，趋势还可以用一段期间的累计收益符号衡量。时间序列动量比较某资产自身过去的绝对表现。截面动量比较同一时点不同资产的相对表现。若所有资产都下跌，相对赢家仍可能为负收益，两种规则的持仓方向可以不同。

对趋势规则做交易分析时，可以按每次从建仓到清仓形成一笔完整记录，计算持有期、最大有利变化和最大不利变化。持续上涨中较晚退出与震荡中反复进出，可能得到相同总收益，却需要不同的改进方向。

鲨鱼说

先用五到十几个价格把每次交叉与成交写出来，再计算长历史。这样既能看见均线的滞后，也能确认程序没有把信号日的收盘价当成随后必然可得的成交价。

练习

某天短均线连续第三天高于长均线，账户已经持有目标 10 股。状态规则应新增多少股？若当天收盘突然下穿，应何时按本例成交？

查看解答

新增零股，目标没有变化。当天收盘下穿后把下一目标设为零，下一交易日开盘卖出；这段隔夜期间仍有持仓风险。
