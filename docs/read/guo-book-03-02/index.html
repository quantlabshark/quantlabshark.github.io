交易成本、约束与持仓数量优化

把买卖成本写在调仓量上，比较凸约束、持仓数量约束和离散搜索方法。

成本取决于交易量

设调仓前权重为 w−w^-w−，调仓后为 www，交易量为 Δw=w−w−\Delta w=w-w^-Δw=w−w−。买卖价差和按量收取的费用通常作用在 ∣Δwi∣|\Delta w_i|∣Δwi​∣ 上，而不是直接作用在最终持仓上。不交易时，持仓可以非零，但这一期交易成本应为零。

线性约束通常仍可有效求解

预算约束 1⊤w=1\mathbf1^\top w=11⊤w=1、持仓上下限、行业暴露范围都是线性条件。引入 zi≥Δwiz_i\ge\Delta w_izi​≥Δwi​、zi≥−Δwiz_i\ge-\Delta w_izi​≥−Δwi​，可以把绝对值成本写成线性项 cizic_i z_ici​zi​。若风险矩阵正半定，整个问题仍属于凸二次优化。

鲨鱼说

比例费用意味着每增加一单位交易，都要支付相应成本。当前调整带来的边际收益未超过这笔费用时，维持原持仓就是最优选择，因此结果中会出现零交易。

平滑与局部松弛解决什么问题

连续松弛先允许 0≤yi≤10\le y_i\le10≤yi​≤1，可提供较易计算的下界。加入 γ∑iyi(1−yi)\gamma\sum_i y_i(1-y_i)γ∑i​yi​(1−yi​) 会惩罚非整数值，再用对数障碍保持内部可行性，逐渐增加整数惩罚、减小障碍参数。这类连续化方法改善搜索路径，但惩罚项本身非凸，找到驻点不能直接证明全局最优。

局部松弛从一个可行资产集合出发，按因子载荷、风险和预期收益定义相似性，在相近资产中交换候选，再重新优化权重。可以先连续优化并删去小权重资产作为初值，但删掉某只资产后，其他资产的最优权重会变化，所以应重新求解。

精确枚举适合小例子，分支定界适合需要最优性界的离散问题，局部搜索适合大规模近似解。比较算法时应同时记录可行性、目标值、运行时间和最优性界。

鲨鱼说

“最多十只股票”限制的是选择，“每只股票不超过十分之一”限制的是权重。两类约束不能互相替代。

练习

两只资产调仓前权重为 (0.6,0.4)(0.6,0.4)(0.6,0.4)，调仓后为 (0.5,0.5)(0.5,0.5)(0.5,0.5)，两边单位交易费率均为 0.0010.0010.001。总成本占净值多少？

查看解答

卖出与买入量分别为 0.10.10.1，按双边成交额计费，总成本为 0.001(0.1+0.1)=0.00020.001(0.1+0.1)=0.00020.001(0.1+0.1)=0.0002，即 2 个基点。若换手率采用半边口径，它是 0.10.10.1；直接把这个数字乘双边费率会少算一半。因此需要同时说明换手定义和计费定义。
