41 · 多期配置、再平衡与交易成本

从价格变化后的权重漂移推导再平衡账务，理解无交易区间、多期决策、消费与参数学习。

价格变化会使实际权重偏离目标权重，再平衡通过交易恢复或调整配置。多期决策需要同时考虑当前收益、持有风险与后续调仓费用。

价格变化与组合权重漂移

初始资产10万元，A与B各5万元。随后A上涨10%、B不变，账户变为10.5万元，A占55000/105000=52.38%55000/105000=52.38\%55000/105000=52.38%。即使没有交易，价格变化也会改变权重。

若恢复50%配置且忽略费用，应卖出A2500元、买入B2500元。若买卖均收费0.1%，又不允许外部补入现金，不能仍机械地各交易2500元。设卖出金额sss、买入金额bbb，则现金守恒要求0.999s=1.001b0.999s=1.001b0.999s=1.001b，等权要求55000−s=50000+b55000-s=50000+b55000−s=50000+b，解得s=2502.5s=2502.5s=2502.5、b=2497.5b=2497.5b=2497.5。费用合计5元，账户终值104995元，每项资产52497.5元。

目标与当前权重相差不超过κ/a\kappa/aκ/a时不交易。超过边界后也只向目标移动一部分，因为最后一点调整的改善不足以覆盖费用。

Python8 行
def rebalance_with_cost(current, target, risk_curvature, fee):
    gap = target - current
    distance = max(abs(gap) - fee / risk_curvature, 0.0)
    return current + (distance if gap >= 0 else -distance)

for target in [0.51, 0.54, 0.65]:
    result = rebalance_with_cost(0.50, target, 2.0, 0.05)
    print(target, result)

图中目标经过0.475—0.525时，实际权重维持0.5；超出后才调整。若存在固定单笔费用，最优策略还可能越过一段距离后一次性调整，不能继续套用同一个软阈值公式。

多期决策为什么不等于重复单期优化

今天的交易改变明天的持仓、现金、费用基础和可选择动作。多期价值函数写为

Jt(s)=max⁡u∈A(s)E[gt(s,u)+Jt+1(s′)∣s,u],J_t(s)=\max_{u\in\mathcal A(s)}E[g_t(s,u)+J_{t+1}(s')\mid s,u],Jt​(s)=u∈A(s)max​E[gt​(s,u)+Jt+1​(s′)∣s,u],

sss是当前状态，uuu是动作，gtg_tgt​是当期收益或效用。单期方法只关心当前目标，多期方法还考虑后续持仓的价值。例如信号预计明天消失，今日建立昂贵仓位可能不划算；持续性强的信号则可能值得分批建立。

线性因子动态ft+1=Aft+ϵt+1f_{t+1}=Af_t+\epsilon_{t+1}ft+1​=Aft​+ϵt+1​配合二次风险与二次交易成本，可以形成线性二次控制问题。最优目标不仅取决于当前预测，也取决于预测衰减速度和未来成本。一项历史研究以1996—2009年的15种商品期货演示这种方法。样本与费用设定属于该实验，不能直接当成现行交易参数。

消费、偿付能力与Merton比例

若投资者还要持续消费，财富动态需扣除消费额。连续时间的简单模型为

dZt=[rfZt+(μ−rf)θtZt−Ct]dt+σθtZt dWt.dZ_t=[r_fZ_t+(\mu-r_f)\theta_tZ_t-C_t]dt+\sigma\theta_tZ_t\,dW_t.dZt​=[rf​Zt​+(μ−rf​)θt​Zt​−Ct​]dt+σθt​Zt​dWt​.

θt\theta_tθt​为风险资产比例，CtC_tCt​为消费率。目标可同时包括未来消费效用与终值效用。使用相对风险厌恶系数γ>0\gamma>0γ>0的CRRA效用U(z)=z1−γ/(1−γ)U(z)=z^{1-\gamma}/(1-\gamma)U(z)=z1−γ/(1−γ)时，在参数已知、无交易成本及适当融资条件下，风险资产最优比例为(μ−rf)/(γσ2)(\mu-r_f)/(\gamma\sigma^2)(μ−rf​)/(γσ2)。消费比例还取决于期限与折现。

存在买卖费用后，应按清算价值判断能否偿付。例如股票多头价值YYY、卖出费率κs\kappa_sκs​，清算财富为X+(1−κs)YX+(1-\kappa_s)YX+(1−κs​)Y。股票空头买回需支付买入费用，清算财富为X+(1+κb)YX+(1+\kappa_b)YX+(1+κb​)Y。此时通常出现持仓状态中的不交易区域，不能仅按股票价格高低机械划线。

参数学习也是状态的一部分

均值未知时，收到新收益后更新后验。正态漂移模型中，后验均值mtm_tmt​随“观测收益减原预测”的创新修正，后验方差随有效观测时间下降：

预测风险通常压低激进程度，但未来学习也会改变跨期对冲需求；因此不能把所有学习效应简化成固定折扣。状态应包括持仓、价格、预测及其不确定性。

鲨鱼说

提高再平衡频率同时改变跟踪偏差与费用。比较每日和每月调整时，要用同一价格路径逐笔记账，记录实际持仓漂移，才能判断净效果。

终值均值方差的时间一致性

终值方差包含(EZT)2(E Z_T)^2(EZT​)2，不能总像逐期效用那样直接拆成可加收益。在起点预先承诺的最优策略，走到中途重新优化后可能改变。需要明确采用预承诺、多期均衡或滚动近似方案。

状态维度增加后，动态规划网格迅速膨胀，称为维度灾难。近似动态规划用较简单函数表示未来价值；滚动规划每次只执行当前动作，再根据新状态重估。它们都应与可计算的小规模精确解比较，并检查约束与现金守恒。

查看解答
