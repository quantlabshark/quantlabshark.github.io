31 · 支持向量机与动态特征选择

推导分类间隔和软间隔目标，理解核函数、回归容忍区间及特征选择的时间边界。

支持向量机通过分类间隔和误差惩罚选择边界。特征选择则确定模型使用哪些信息，两者都应在训练与验证数据内完成，并保留独立测试区间。

为什么分类边界不能只求分对训练点

输入−2、−1属于负类，1、2属于正类。把边界放在−0.9或0.9都能分对四条记录，但它们分别紧贴某一类；放在0处则给两边留下相同空间。支持向量机在合适的误差约束下，寻找间隔较大的边界。

线性决策函数为f(x)=w′x+bf(\mathbf x)=\mathbf w'\mathbf x+bf(x)=w′x+b，按正负分类。若标签yiy_iyi​为−1或1，可分数据满足yif(xi)≥1y_i f(\mathbf x_i)\ge1yi​f(xi​)≥1。最小化∥w∥2/2\|\mathbf w\|^2/2∥w∥2/2，等价于扩大两侧间隔2/∥w∥2/\|\mathbf w\|2/∥w∥。

在本例中可取w=1,b=0w=1,b=0w=1,b=0，支持边界位于−1与1，间隔为2。位于两侧约束边缘的点影响边界位置，称为支持向量。离边界更远的点并非完全无关，但在保持其约束不活跃时，小幅移动通常不会改变这个解。

实线表示决策值为0的位置，虚线表示正负单位决策值。被圈出的样本位于间隔边缘；图中横向间隔与手算一致。

软间隔允许哪些错误

真实样本经常重叠。引入非负松弛量ξi\xi_iξi​后，目标变为

min⁡w,b,ξ12∥w∥2+C∑iξi,yif(xi)≥1−ξi.\min_{\mathbf w,b,\boldsymbol\xi}\frac12\|\mathbf w\|^2+C\sum_i\xi_i, \qquad y_i f(\mathbf x_i)\ge1-\xi_i.w,b,ξmin​21​∥w∥2+Ci∑​ξi​,yi​f(xi​)≥1−ξi​.

ξi=0\xi_i=0ξi​=0表示满足间隔，介于0与1表示在间隔内但分类仍正确，大于1则表示分错。较大C更重视训练违约，较小C允许更多违约以获得较平缓边界。C的含义受特征尺度和损失归一化影响，应与缩放一起验证。

核函数怎样表达弯曲边界

核函数通过样本间相似度构造非线性关系。RBF核为

K(x,z)=exp⁡(−γ∥x−z∥2).K(\mathbf x,\mathbf z)=\exp(-\gamma\|\mathbf x-\mathbf z\|^2).K(x,z)=exp(−γ∥x−z∥2).

距离1、γ=1\gamma=1γ=1时相似度约0.3679；γ=2\gamma=2γ=2时为0.1353。较大γ\gammaγ让单点影响更局部，可能形成许多小区域。最终预测还需要支持向量权重和截距，不是仅凭“附近是什么类”就完成判断。

输入单位改变会改变距离，所以通常先标准化。C与γ\gammaγ共同决定边界复杂度，应在内部时间验证中选择，不能分别看训练准确率后无限增大。

支持向量回归的容忍带

连续收益目标使用SVR。其ε\varepsilonε不敏感损失为max⁡(0,∣y−y^∣−ε)\max(0,|y-\hat y|-\varepsilon)max(0,∣y−y^​∣−ε)：误差落在容忍带内不再处罚，超过部分才进入损失。若预测0.8%、实际1.0%、容忍带0.3个百分点，损失为0。实际1.4%时超出0.3个百分点，损失为0.3个百分点。

SVC的决策值不直接等于概率，SVR的评分也不等于分类准确率。若需要概率，要使用单独的校准过程和允许的历史数据；如果预测市值，评价目标就是市值误差，而不是自动变成未来收益。

动态选因子是另一个学习步骤

每次更新先用训练样本的树重要性挑选特征，再缩放并拟合SVM，是一种动态选择流程。选择器本身已经读取标签，因此必须放在训练窗口内部。先用全部数据选择两列，再划分时间，会把后段标签提前传入模型。

Python23 行
import numpy as np
from sklearn.tree import DecisionTreeClassifier
from sklearn.feature_selection import SelectFromModel
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC
from sklearn.pipeline import Pipeline

rng = np.random.default_rng(31)
X = rng.normal(size=(120, 4))
y = (X[:, 0] - 0.7*X[:, 1] + 0.3*rng.normal(size=120) > 0).astype(int)
for cutoff in [60, 80]:
    model = Pipeline([
        ("select", SelectFromModel(
            DecisionTreeClassifier(max_depth=3, random_state=1),
            threshold=-np.inf, max_features=2)),
        ("scale", StandardScaler()),
        ("svm", SVC(kernel="rbf", C=1.0, gamma="scale"))
    ])
    model.fit(X[:cutoff], y[:cutoff])
    chosen = np.flatnonzero(model.named_steps["select"].get_support())
    print("cutoff:", cutoff, "selected:", chosen)
    print("next block:", model.predict(X[cutoff:cutoff+10]))
    assert len(chosen) == 2

代码在第60和80条记录更新，只使用各切点之前的数据，从四列选出两列，并预测随后十条。模拟标签被假定在切点前已经完成。真实多日收益标签应另外保存结束时间，只允许已经成熟的标签进入训练。

鲨鱼说

动态选因子会改变的不只是模型输入，还可能改变持仓与交易成本。先与固定特征、相同更新日期的基准比较，才能知道频繁更新是否增加了价值。

怎样解释因子名单变化

两个高度相关因子可能轮流入选，但它们表达的是相近信息。反过来，名单不变也不意味着预测稳定，参数更新仍可能造成大幅换仓。应同时记录特征集合、预测分布、交易次数和净收益。

每次模型更新还要检查至少存在两个类别，保存列名、列顺序、选择器、缩放统计量与分类器。只有单一类别时，普通二分类SVC不能正常拟合，应执行事先定义的常数预测或延迟更新规则。回放研究时使用当时保存的模型及预处理参数。

由yf(x)≥1−ξyf(x)\ge1-\xiyf(x)≥1−ξ，第一种需要ξ≥0.6\xi\ge0.6ξ≥0.6，分类正确但进入间隔；第二种需要ξ≥1.2\xi\ge1.2ξ≥1.2，已分错。全样本选择器使用了未来标签，使后续测试不再独立，应把选择器在每个训练窗口内重新拟合。
