1. 三角形内的回归

题目

在顶点 (1,0),(0,1),(1,1)(1,0),(0,1),(1,1)(1,0),(0,1),(1,1) 围成的三角形内，按面积均匀抽取随机点 (X,Y)(X,Y)(X,Y)。求总体含截距线性回归 Y=a+bX+εY=a+bX+\varepsilonY=a+bX+ε 的系数、相关系数和 R2R^2R2。

考点：二维密度；条件均值；总体最小二乘。

查看分析与解答

必要知识

按面积均匀意味着联合密度在三角形内为常数，常数乘总面积必须为一。总体回归系数最小化的是所有可能点上的平均平方误差，区别于一次有限抽样得到的估计。

分析思路

先确定区域与密度，再求均值、方差、协方差。也可以先观察给定 X=x 后 Y 的均匀区间，其条件均值恰好是一条直线，用来解释回归结果。

解答步骤

固定 x，竖直截面从 y=1−x 到 1，长度 x，故 X 的边际密度为 2x，而不是均匀密度一。给定 x 后 Y 在此区间均匀，条件均值为 [(1−x)+1]/2=1−x/2，已经提示回归斜率为 −1/2。

三角形区域为 0≤x≤10\le x\le10≤x≤1、1−x≤y≤11-x\le y\le11−x≤y≤1，面积为 1/21/21/2，故联合密度为 2。逐项积分： E[X]=∫012x⋅x dx=23,E[X2]=∫012x2⋅x dx=12.E[X]=\int_0^1 2x\cdot x\,dx=\frac23,\qquad E[X^2]=\int_0^1 2x^2\cdot x\,dx=\frac12.E[X]=∫01​2x⋅xdx=32​,E[X2]=∫01​2x2⋅xdx=21​. 由对称性 E[Y]=2/3E[Y]=2/3E[Y]=2/3、E[Y2]=1/2E[Y^2]=1/2E[Y2]=1/2。交叉矩为 E[XY]=2∫01x∫1−x1y dy dx=∫01(2x2−x3) dx=512.E[XY]=2\int_0^1x\int_{1-x}^1y\,dy\,dx=\int_0^1(2x^2-x^3)\,dx=\frac5{12}.E[XY]=2∫01​x∫1−x1​ydydx=∫01​(2x2−x3)dx=125​. 因此 Var⁡(X)=Var⁡(Y)=1/2−4/9=1/18\operatorname{Var}(X)=\operatorname{Var}(Y)=1/2-4/9=1/18Var(X)=Var(Y)=1/2−4/9=1/18，Cov⁡(X,Y)=5/12−4/9=−1/36\operatorname{Cov}(X,Y)=5/12-4/9=-1/36Cov(X,Y)=5/12−4/9=−1/36。

最小化 E[(Y−a−bX)2]E[(Y-a-bX)^2]E[(Y−a−bX)2] 的一阶条件给出 b=Cov⁡(X,Y)/Var⁡(X)=−1/2b=\operatorname{Cov}(X,Y)/\operatorname{Var}(X)=-1/2b=Cov(X,Y)/Var(X)=−1/2，a=E[Y]−bE[X]=1a=E[Y]-bE[X]=1a=E[Y]−bE[X]=1，回归线为 Y^=1−X/2\hat Y=1-X/2Y^=1−X/2。相关系数为 −1/2-1/2−1/2，含截距一元回归的 R2R^2R2 为相关系数平方，即 1/41/41/4。

直观上，XXX 越小，三角形限制要求 YYY 越接近 1；XXX 较大时，YYY 可取较低值，因此出现负相关。有限随机样本的估计会在这些总体数值附近波动。

OLS 一阶条件为 E[Y−a−bX]=0 与 E[X(Y−a−bX)]=0。第一式给 a=E[Y]−bE[X]，代入第二式得 bVar(X)=Cov(X,Y)。本题条件均值本身线性，因此这条线不仅是最佳线性预测，也是均方意义下的最佳预测。R²=1/4，仍有其余条件波动无法由 X 确定。

同类问题

几何抽样题先算截面长度，能识别边际分布是否均匀。总体回归可从矩或条件均值两条路线求解，相互核对还能揭示负相关的几何原因。

2. 计算器

题目

设计一个表达式计算器，输入由非负十进制整数、空格、加减乘除和圆括号组成，可在数字或括号前使用一元正负号。除法采用实数除法。说明解析规则、错误处理和复杂度，并演示计算 2+3×(4−1)。

考点：递归下降；优先级；词法与语法。

查看分析与解答

必要知识

词法分析把字符组合成整数与运算符 token；语法分析决定这些 token 如何结合。乘除优先于加减，括号可以改变顺序，一元负号只作用于一个因子，例如 −(2+3)。

分析思路

按优先级建立三层解析函数，每层消费自己负责的运算，并把更高优先级部分交给下一层。每个函数返回数值，同时推进唯一的 token 游标。

解答步骤

对 2+3*(4−1)，expression 先调用 term 得 2；遇加号后再调用 term，读到 3 与乘号，再调用 factor 处理括号，括号内 expression 得 3，因此第二个 term 为 9，最终为 11。这里先乘后加由函数调用结构保证，不需事后重新排序。

先将字符分成数字和运算符。连续数字必须合成一个数；空格只作分隔，其他字符报错。不要把表达式交给通用代码执行接口。

按优先级定义三层解析：

文本 / 日志3 行
expression := term { ('+' | '-') term }
term       := factor { ('*' | '/') factor }
factor     := number | '(' expression ')' | ('+' | '-') factor

factor 负责单个数、括号和一元符号；term 按出现顺序处理乘除；expression 按出现顺序处理加减。循环而不是从右边递归处理同级运算，可以保证减法和除法左结合，例如 8/4/2 得到 1。

计算 2+3*(4-1) 时，先读到首项 2；第二项内部先将括号算成 3，再与前面的 3 相乘为 9；最后相加为 11。若只有加减且没有括号，简化为扫描数字、记录当前符号并累加即可。

检查除数是否为零、括号是否匹配、运算符后是否有操作数，并确认解析结束后没有剩余 token。每个字符和 token 处理常数次，时间为 O(n)O(n)O(n)；嵌套括号或一元符号可使调用栈达到 O(n)O(n)O(n)。

一元负号可递归处理，例如 −−2 经两次符号取反为 2；8/4/2 在 term 的循环中先算 8/4 再除 2，得到 1。错误测试应包括空输入、1+、(2+3、2 3、1/0 和非法字符。输入 2 3 不能因忽略空格而拼成 23，词法阶段应先识别两个数字 token，语法结束时拒绝多余 token。

同类问题

解析器正确性来自语法与消费规则，不是依靠字符串替换。为每层写明接受的结构、返回结果与剩余输入，便能系统处理优先级、一元符号和错误位置。

3. Python 多线程

题目

在启用 GIL 的 CPython 中，说明多线程适合哪些任务、为何纯 Python 计算通常不能随线程数成比例加速，以及怎样避免共享数据竞态。

考点：并发与并行；GIL；共享状态竞态。

查看分析与解答

必要知识

并发指任务在时间上交错推进，并行指同时使用多个执行单元。启用 GIL 的 CPython 限制同一时刻执行 Python 字节码的线程数，但 I/O 等待和某些原生扩展可释放 GIL。它不是覆盖所有业务操作的锁。

分析思路

先判断时间花在 CPU 还是等待，再解释线程是否能重叠这部分工作。共享数据的正确性另行分析，不能由是否有 GIL 直接推断安全。

解答步骤

若下载十个文件主要在等网络，线程可以在一个请求等待时推进其他请求；若十个任务都是纯 Python 大循环，多线程通常仍争用同一字节码执行锁，无法按线程数成比例加速。

线程共享同一进程的地址空间，因此传递对象的成本较低；但共享状态也可能被多个线程交错修改。

在启用 GIL 的 CPython 中，同一时刻通常只有一个线程执行 Python 字节码。纯 Python 的长循环即使拆成多个线程，也常受此限制，并增加调度开销。I/O 任务的大量时间用于等待文件或网络，等待期间其他线程可以运行，因此线程池往往更合适。释放 GIL 的原生计算库和不启用 GIL 的构建需要单独评估。

例如两个线程都执行“读余额、计算新余额、写回”，若二者先读到同一旧值，后一次写入可能覆盖前一次更新。GIL 不保证这一整段业务操作不可分割。应在同一把锁内完成读取到写回，或让唯一工作线程通过队列串行处理更新。

CPU 密集任务可比较多进程、向量化和释放 GIL 的计算实现。选择时测量吞吐、延迟、内存和数据传输成本，线程数越多并不必然越快。

余额初值 100，线程 A、B 都读到 100，各自加 10 再写回，交错执行可能最终只得到 110。业务临界区应覆盖读、算、写整个过程，而非只保护最后赋值。可使用同一把锁，或由唯一消费者处理队列中的余额修改消息。使用多进程时还需计入对象序列化与进程间传输成本。

同类问题

性能与正确性分开回答：选择并发模型解决等待或计算瓶颈，用同步协议解决共享状态。题设明确启用 GIL 时使用该模型分析；其他解释器或无 GIL 构建需重新测量。

4. 项目讨论

题目

面试官要求介绍一个自己做过的量化或数据分析项目，并追问结果如何验证。应怎样组织陈述和准备依据？

考点：研究陈述；证据；个人贡献。

查看分析与解答

必要知识

项目介绍需要让面试官能够判断问题是否明确、方法是否合理、结果是否经受验证，以及哪些工作由本人完成。结果好坏与工作质量相关，但不能仅用最终收益高低代替过程证据。

分析思路

用问题、数据、方法、验证、结果五段组织，再选择一个关键决定展开。准备可以支持追问的中间结果，而非把全部实现细节一次讲完。

解答步骤

例如比较收益预测模型时，先交代样本单位是股票日、预测从何时到何时，再解释时间划分与基准。随后选择一个真实的问题，如财务公布日对齐或标签重叠，说明自己如何发现与修正。

先用一两句话说明项目要解决的问题和输出，例如“比较两个预测方法在后续月份的误差”。随后说明数据覆盖期、样本单位、标签和可见时点，使面试官知道评价对象是什么。

按实际职责讲方法：自己负责了哪些数据处理、模型或工程部分，哪些由团队其他成员完成。重点解释一个关键选择及备选方案，例如为什么按时间划分数据，或为什么采用较简单模型。

结果应包含基准、时间外指标和分段表现。若是回测，说明费用、成交时点及最不利时期；若模型未优于基准，也可解释定位了什么原因、做过哪些有效对照。这样能够区分工作量与结果。

准备一张流程图、少量关键表格和可运行入口即可。所有数字与经历应来自实际工作；没有实盘记录时，明确说明测试属于模拟或历史回测。

可准备三类材料：流程图显示输入到输出的依赖；对照表显示基准与目标方法在同样日期的结果；诊断表显示在哪些时期失效及检查结论。若自己只负责特征部分，应明确说明，不把团队部署或交易结果都归为个人贡献。没有优于基准也可以展示排除了哪些假说以及下一步依据。

同类问题
