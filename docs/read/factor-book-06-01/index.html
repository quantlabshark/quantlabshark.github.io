6.1 多重检验、发表偏差与先验证据

从100次无效检验的误报概率出发，计算FWER、FDR和贝叶斯后验，理解低p值为何需要结合研究过程。

一百个无效指标也容易出现显著结果

假设每个候选指标其实都不能预测收益，但每次统计检验都允许5%的误报概率。只检验一个指标时，这个风险为5%；独立检验100个时，至少误报一次的概率变成

1−(1−0.05)100≈99.41%.1-(1-0.05)^{100}\approx99.41\%.1−(1−0.05)100≈99.41%.

平均而言还会有 100×0.05=5100\times0.05=5100×0.05=5 个误报。若只展示其中最显著的一个，却不记录其余99次尝试，读者便会把“多次挑选的优胜者”当成“一开始就提出的假设”。因子动物园问题的核心正是这种选择过程。

p值的条件放在哪里

设 H0H_0H0​ 为“因子的真实平均超额收益为零”，样本统计量为 TTT。对称双侧检验可以写成

p=PH0(∣T∣≥∣Tobs∣).p=P_{H_0}(|T|\ge|T_{obs}|).p=PH0​​(∣T∣≥∣Tobs​∣).

它先假定零均值和统计模型成立，再计算得到当前这么极端、或更极端结果的概率。右侧检验只看上尾，左侧检验只看下尾，方向应在查看结果前确定。

若 p=0.01p=0.01p=0.01，含义是零假设下这种程度的偏离较少见。它不等于 P(H0∣D)=1%P(H_0\mid D)=1\%P(H0​∣D)=1%，也不等于未来盈利概率99%。样本足够长时，很小的均值也可能显著；若收益不足以覆盖费用，统计发现仍无法转化成净收益。

完整统计判断需要同时报告效应大小、不确定性、样本处理及全部尝试。只按是否低于0.05做决策，会把0.049与0.051夸大成两个截然不同的事实。

研究选择与发表偏差怎样累积

选20年还是30年，删除哪些异常点，按月还是按季调仓，采用什么断点，这些都会改变结果。金融实证中的可选环节较多，研究者容易在看到结果之后继续改规则，直到得到低p值，这称为p-hacking。

如果显著结果更容易发表，无效结果留在电脑里，公开论文的因子集合还会低估实际尝试次数。对1963—2012年间316个已发表因子的历史整理发现，大量结果集中于较高的 ttt 值区域。这个现象提示选择偏差，需要结合复现、未发表尝试和独立样本判断。有关“硬科学与软科学”的讨论，在这里对应的是研究者自由选择对实证结论的影响，并非用学科名称代替质量评估。

图中 20 条收益路径均为模拟数据，深色线按验证期表现选出；训练、验证与测试三个区间依次分开。测试期表现显示，历史选出的最佳路径未必继续领先。

图中候选规则经过训练和验证被挑选出来，测试阶段才评估冻结后的规则。更改规则意味着产生了新的尝试，之前的测试结果也成为已知信息。

三种控制目标不能混为一谈

设共检验 mmm 项，拒绝 RRR 项零假设，其中 VVV 项实际无效。

控制对象 定义 回答的问题
FWER P(V≥1)P(V\ge1)P(V≥1) 至少错报一项的概率多大
FDP V/max⁡(R,1)V/\max(R,1)V/max(R,1) 此次报告的发现中有多大比例错误
FDR E[FDP]E[FDP]E[FDP] 重复研究中错误比例平均多大

Bonferroni用 α/m\alpha/mα/m 作为每次检验阈值控制FWER，不需要假定检验独立。Holm按p值从小到大逐步比较，往往更有检验能力。自助现实检验和Romano–Wolf逐步方法则通过重抽样保留策略之间的依赖，估计择优带来的影响。

Benjamini–Hochberg方法以FDR为目标，把排序后的 p(j)p_{(j)}p(j)​ 与 jq/mjq/mjq/m 比较，取满足条件的最大序号。其控制性质依赖独立或特定正相关条件。任意依赖下可用更保守的Benjamini–Yekutieli调整。

另一种目标是 P(FDP>γ)≤αP(FDP>\gamma)\le\alphaP(FDP>γ)≤α，限制错误比例超出容忍线的概率，比只控制平均比例更关注尾部。

Python8 行
pvalues = [0.001, 0.012, 0.03, 0.04, 0.20]
q = 0.05
k = max([j for j, p in enumerate(pvalues, 1)
         if p <= j * q / len(pvalues)] + [0])
false_alarm = 1 - 0.95 ** 100
assert k == 4
print(f'100次独立检验至少一次误报：{false_alarm:.2%}')
print('BH拒绝前', k, '项')

前四项被拒绝，不代表四项都已证明真实。FDR描述重复实验的期望比例，也不会保证每次恰好只有5%的错误。

t值门槛为何随研究集合改变

关于已发表因子的研究曾提出约3的 ∣t∣|t|∣t∣ 门槛。考虑未发表尝试的模拟又得到时序与Fama–MacBeth检验约3.8和3.4的门槛。这些是特定研究集合、依赖结构和控制目标下的结果。候选因子更多、更相关或筛选过程不同，合适的调整也会变化。

正交化与自助法还可逐次寻找增量因子：先移除已入选因子的解释部分，再模拟剩余候选在无真实效应下能取得的最优表现。它检验的是新增信息，不能把同一效应换一个名字后反复计入。回测夏普比率的选择调整同样依赖尝试次数、样本长度和分布，不能统一乘一个固定折扣。

贝叶斯方法把机制与数据连接起来

先验概率描述看到本次样本前对假设的认识。具有企业投资机制的候选，与按股票代码末位选股的候选，可以具有不同先验。贝叶斯更新为

P(H1∣D)P(H0∣D)=P(D∣H1)P(D∣H0)P(H1)P(H0).\frac{P(H_1\mid D)}{P(H_0\mid D)} =\frac{P(D\mid H_1)}{P(D\mid H_0)}\frac{P(H_1)}{P(H_0)}.P(H0​∣D)P(H1​∣D)​=P(D∣H0​)P(D∣H1​)​P(H0​)P(H1​)​.

假设数据在有效假设下的似然是无效假设下的10倍。若先验有效概率为50%，后验有效概率为 10/(10+1)=90.9%10/(10+1)=90.9\%10/(10+1)=90.9%；若先验只有2%，后验为 10×0.02/(10×0.02+0.98)=16.9%10\times0.02/(10\times0.02+0.98)=16.9\%10×0.02/(10×0.02+0.98)=16.9%。相同数据证据，结合不同初始可信度，会得到不同后验。

鲨鱼说

p值与贝叶斯因子也不是同一个量。要从样本得到后验，需要明确两个假设如何生成数据以及先验；不能把p值直接代入“因子有效的概率”。

有关最小贝叶斯因子的讨论，可用 p<1/ep<1/ep<1/e 时的校准界 B01≥−epln⁡pB_{01}\ge-e p\ln pB01​≥−eplnp 理解：在相应备择分布条件下，数据对零假设的支持有一个下界。将贝叶斯因子与先验零假设概率 π0\pi_0π0​ 结合，有 P(H0∣D)=B01π0/[B01π0+1−π0]P(H_0\mid D)=B_{01}\pi_0/[B_{01}\pi_0+1-\pi_0]P(H0​∣D)=B01​π0​/[B01​π0​+1−π0​]。若只知道下界，得到的也只是后验下界，并非精确后验。正态点零假设的最大似然比较中还可出现 e−t2/2e^{-t^2/2}e−t2/2 形式，但它与前一个校准界的假设不同。

历史“易记股票代码”例子的原始p值约0.0079，低先验下的后验零假设评估却可升到约0.588。这里有用的信息是机制和先验如何改变证据解释，而不是把某个校准数当成所有因子的通用规则。
