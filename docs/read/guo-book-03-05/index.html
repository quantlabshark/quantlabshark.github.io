基础理论与原理

动态均值方差与参数不确定性

理解多期均值方差的时间不一致，利用信号衰减、交易成本和参数学习决定调仓速度。

每期重复单期优化会遗漏什么

今天买入一项资产，不仅影响明天收益，也改变明天的初始持仓和交易成本。若信号很快消失，大幅建仓可能尚未收回成本就需要平仓；若信号持续很久，适度分批进入可能更合适。

动态模型至少需要保存当前持仓、预测信号和剩余期限。目标可以是各期收益与风险惩罚之和，也可以是终值财富的均值方差。两种目标并不相同，选择时应先明确评价对象。

终值方差造成时间不一致

终值目标 E(WT)−λVar⁡(WT)E(W_T)-\lambda\operatorname{Var}(W_T)E(WT​)−λVar(WT​) 包含 [E(WT)]2[E(W_T)]^2[E(WT​)]2。在未来某个时点重新条件化后，目标中的均值和方差重新计算，原先承诺的策略未必仍是局部最优。

一种方法是在初始时点作预承诺，把问题嵌入带参数的二次终值目标 E[(WT−d)2]E[(W_T-d)^2]E[(WT​−d)2]，对候选 ddd 解动态规划，再恢复目标均值与方差关系。另一种方法寻找各时点都愿意继续执行的均衡策略。不能把普通可加收益的 Bellman 递推直接用于未处理的终值方差。

鲨鱼说

Bellman 递推，即将当前收益或成本与下一阶段价值连接起来的动态规划关系。

交易成本使持仓缓慢追随目标

考虑一维的当期近似问题：持仓 uuu、原持仓 u−u^-u−、预测单位收益 mmm、风险系数 γσ2\gamma\sigma^2γσ2，二次调仓成本系数为 λ\lambdaλ。最大化

mu−γσ22u2−λ2(u−u−)2.mu-\frac{\gamma\sigma^2}{2}u^2-\frac\lambda2(u-u^-)^2.mu−2γσ2​u2−2λ​(u−u−)2.

一阶条件得到

u∗=m+λu−γσ2+λ=θmγσ2+(1−θ)u−,θ=γσ2γσ2+λ.u^*=\frac{m+\lambda u^-}{\gamma\sigma^2+\lambda}=\theta\frac m{\gamma\sigma^2}+(1-\theta)u^-,\quad\theta=\frac{\gamma\sigma^2}{\gamma\sigma^2+\lambda}.u∗=γσ2+λm+λu−​=θγσ2m​+(1−θ)u−,θ=γσ2+λγσ2​.

持仓是无成本目标与原持仓的加权平均。成本越高，单次调整越少。这个公式属于单步近似；多期模型还需把未来信号和未来调仓成本纳入目标。

快信号与慢信号应有不同权重

设信号 ft+1=ρft+ϵt+1f_{t+1}=\rho f_t+\epsilon_{t+1}ft+1​=ρft​+ϵt+1​，预测收益为 bftbf_tbft​。ρ\rhoρ 越接近一，信号持续越久，未来多期收益对当前建仓更有价值。在线性信号、二次风险和二次交易成本下，价值函数可取状态与持仓的二次形式，利用 Riccati 递推求出最优线性交易规则。

实际结果通常表现为向一个考虑未来信号的目标持仓逐步靠近。多个信号有不同衰减速度时，不能只按它们对下一期收益的预测强度等比例合并。慢信号可能容许较慢建仓，快信号需要比较短期收益是否足以覆盖冲击。

一个两期例子：未来调仓成本改变今天的持仓

鲨鱼说

今天的持仓既产生今天的风险，也是明天调仓的起点。多期优化多考虑的，正是这个“起点会影响下一步费用”的关系。

预测风险与学习状态

若收益均值未知，新的收益会更新其后验分布。动态状态应包含后验均值和不确定性。只把后验均值代入已知参数的最优公式，忽略了未来学习对决策的影响。

在高斯漂移模型 dSt/St=μdt+σdBtdS_t/S_t=\mu dt+\sigma dB_tdSt​/St​=μdt+σdBt​ 中，若 μ∼N(m0,v0)\mu\sim N(m_0,v_0)μ∼N(m0​,v0​)，连续观测到时间 ttt 后的后验方差为 vt=(v0−1+t/σ2)−1v_t=(v_0^{-1}+t/\sigma^2)^{-1}vt​=(v0−1​+t/σ2)−1。时间越长，不确定性越小。若波动率也未知，通常需要扩展状态和非线性滤波，计算量随之增加。

滚动预测协方差、使用带成本的近似动态规划，以及按实际评价周期选择风险参数，可以把统计预测与多期决策连接起来。需要在未来数据上比较整个更新规则，而不是只比较一次求出的权重。

鲨鱼说

调仓速度也是策略参数。预测方向相同的两个模型，因为信号寿命不同，可能应该采用完全不同的下单节奏。
