07 · 分组与持仓：把因子排序转成交易记录

明确分组收益、权重漂移、换手口径、成本与成交容量，区分统计标签和可执行的资金路径。

分组收益与排序关系

将当日股票按分数从低到高分成五组，分别计算随后收益，可以观察收益是否随分数大致递增。若只有最高组与最低组差异较大，中间三组没有规律，则关系可能集中在两端；若中间组最高，线性排序假设可能不合适。

等权组的收益为

Rg,t=∑i∈gtwi,tyi,t,wi,t=1Ng,t. R_{g,t}=\sum_{i\in g_t}w_{i,t}y_{i,t},\qquad w_{i,t}=\frac1{N_{g,t}}. Rg,t​=i∈gt​∑​wi,t​yi,t​,wi,t​=Ng,t​1​.

其中 gtg_tgt​ 必须由形成时刻已知的分数确定。不能先删去未来收益缺失的股票，再重新分组，否则组合成员取决于未来信息。

并列分数需要预先约定处理方式。可以允许组规模略有不同，也可以按稳定、与未来收益无关的标识打破并列。缺失分数不参与排名，未投资资金如何处理则由组合规则规定。组内未来收益缺失时，应报告受影响权重，并在持仓系统中跟踪相应头寸，不能简单改为其余股票再归一化。

高减低组合的资本口径

设最高组收益为 3%、最低组为 1%。直接相减得到 2%，对应最高组权重 +1+1+1、最低组权重 −1-1−1，总绝对敞口为 2。若规定总绝对敞口为 1，则两边各占 50%，收益为

R=0.5R高−0.5R低=1%. R=0.5R_{\text{高}}-0.5R_{\text{低}}=1\%. R=0.5R高​−0.5R低​=1%.

对只做多的账户，低分组更适合作为比较对象，不能自动变成可卖空头寸。若使用空头，还须加入借券可得性、借券费用、保证金和不能卖出的情形。这些条件会影响实际仓位，与分组统计是不同层次的记录。

鲨鱼说

因子分数相同，资金规模不同，能实现的收益也可能不同。分数只决定希望买卖什么；订单占市场成交多少、能否成交、需要付出多少价格让步，决定这笔交易如何进入账户。

重叠持有期需要子账户或明确调仓规则

若每天形成一个五日信号，可以把资金分成五份，每天只更新其中一份，到第五个持有区间结束时退出。这样每份资金有自己的入场、退出和现金记录。另一种做法是每五日调仓一次，避免持有期重叠，但信号更新频率降低。

若选择每天根据最新分数重设全账户，持仓期已由调仓规则决定，不再等于研究标签中的五日。此时应从每日实际持仓逐日计算收益，而不能直接套用五日标签。

交易记录至少保留期初股数、目标股数、委托股数、成交股数、成交价、费用和期末现金。暂停交易的股票保留在持仓中；退市和公司行为按实际可得处置数据处理。不能用“下期没有价格”作为当初未持有的理由。
