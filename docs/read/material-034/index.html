最优停止、套利约束与吸收过程

红白球停止、世界杯赔率套利、反复等涨10%的策略、赌场与破产

1. 红白球停止

题目

袋中 3 红 4 白球，无放回均匀抽取，红球收益 +1 元、白球收益 −1 元。至少抽第一次，之后每次可选择停止并结算。求最优期望收益；袋中改为共 100 球时，至少多少红球能使最优期望严格为正？

考点：停止价值；强制首步；精确递推。

查看分析与解答

必要知识

V(r,w) 表示允许此刻退出时，未来最多可获得的期望增益，过去已经赢亏多少只是总收益的固定加项。立即退出值为零，所以 V 不会负；但强制第一次参加的期望可能为负。

分析思路

先按剩余总球数从少到多填 Bellman 表，再单独计算初始状态的继续值。第二问遍历红球数并找首个严格正值，不能用允许不参加时的零代替强制首步结果。

解答步骤

例如 V(1,1)=[(1+V(0,1))+(-1+V(1,0))]/2=1/2。V(1,2) 的继续值为 (1+0)/3+2(−1+1/2)/3=0；V(2,1)=[2(1+1/2)+(−1+2)]/3=4/3。继续逐层计算到 (3,4) 得 12/35≈0.342857。

只看“未来还能获得多少”，已实现的盈亏是固定项，不影响继续与停止的比较。剩余 rrr 红、www 白时，立即停止的未来收益为 0；继续的收益是第一球的 ±1 加上后续最优价值。两者取较大便得到递推。

例如只剩红球时应全部取出，V(r,0)=rV(r,0)=rV(r,0)=r；只剩白球时应立即停止，V(0,w)=0V(0,w)=0V(0,w)=0。从球数少的状态逐步计算到球数多的状态。首次必须抽取时，首步单独使用继续值，不与零取最大。

递推为 V(r,w)=max⁡{0,rr+w[1+V(r−1,w)]+wr+w[−1+V(r,w−1)]}.V(r,w)=\max\left\{0,\frac r{r+w}[1+V(r-1,w)]+\frac w{r+w}[-1+V(r,w-1)]\right\}.V(r,w)=max{0,r+wr​[1+V(r−1,w)]+r+ww​[−1+V(r,w−1)]}. 计算得 V(3,4)=12/35V(3,4)=12/35V(3,4)=12/35，首抽强制时也为此值。总共 100 球时，逐个枚举红球数量，首步继续值首次严格为正出现在 47 红，约为 0.404096142。46 红及以下允许不参加的价值可以是零。用有理数递推可以准确区分零与正值。

一百球的强制首步值，四十五红约 −0.1、四十六红约 −0.00779990、四十七红约 0.40409614。四十六红允许不玩时价值零，但强制玩仍负；这一区分决定“最少四十七”的答案。用 Fraction 保存分数，边界零不会被浮点舍入误判为很小正数。

Python17 行
from fractions import Fraction

value = {(0, 0): Fraction(0)}
forced = {}
for total in range(1, 101):
    for red in range(total + 1):
        white = total - red
        play = Fraction(0)
        if red:
            play += Fraction(red, total) * (1 + value[red-1, white])
        if white:
            play += Fraction(white, total) * (-1 + value[red, white-1])
        forced[red, white] = play
        value[red, white] = max(Fraction(0), play)

assert forced[3, 4] == Fraction(12, 35)
assert min(r for r in range(101) if forced[r, 100-r] > 0) == 47

同类问题

带自愿退出的游戏区分“现在可停”与“这一轮必须玩”。状态表存可停价值，强制开始则额外计算一次转移；最优规则是在后续状态继续值正时继续，否则停止。

分析思路

先列八种可能结果，构造净收益矩阵。将多空两边各限制不超过一，找到可行组合后逐场景验算；最后用一个代数加权向量限制所有可行组合，证明没有更优比例。

3. 反复等涨10%的策略

题目

价格初始为 a>0a>0a>0，每期独立以相同概率乘以 1.01 或 0.99。策略在价格 aaa 附近买入，等待达到或超过 1.1a1.1a1.1a 时卖出，再等回到买入阈值重复。分析“无限等待就一定盈利”是否成立。有限个零相关资产能否据此保证稳定收益？

考点：乘法波动；鞅；未平仓损益。

查看分析与解答

必要知识

每日涨跌百分比相同并不使长期对数增长为零。价格的算术条件均值与对数价格的平均增长是不同量；无限等待也不保证一定碰到某个更高阈值。

分析思路

分别看价格均值、长期对数漂移和上阈值命中概率，再检查回测是否把未结束交易遗漏。多资产部分则用联合路径说明零相关不足以保证无损失。

解答步骤

令 τ 为首次价格≥1.1a 的时刻。对有限 T，停止后的价格仍非负且 E[P_(τ∧T)]=a；在 τ≤T 的路径上至少值 1.1a，所以 a≥1.1aP(τ≤T)。令 T 增大得到最终触及概率≤10/11，至少有一部分路径始终无法兑现预期的止盈。

价格本身的条件期望满足 E(Pt+1∣Pt)=PtE(P_{t+1}\mid P_t)=P_tE(Pt+1​∣Pt​)=Pt​，但对数价格的期望变化并不为零。两天一涨一跌时，价格乘数为 1.01×0.99=0.9999<11.01\times0.99=0.9999<11.01×0.99=0.9999<1，这已经显示乘法中的波动损耗。

回测必须在统一截止日把未卖出头寸按市价计入资产，否则只统计已盈利的闭合交易会遗漏亏损。多资产组合要由联合收益分布、仓位和成本计算风险；零相关既不是独立，也不是每条路径都不会亏损。

同类问题

止盈策略应同时分析达到阈值的概率、等待时间和未完成持仓的价值。只规定盈利时退出、亏损时继续等待，不能把亏损从经济结果中消除。

4. 赌场与破产

题目

有固定有限 nnn 名赌客，各初始 mmm 元，每轮尚未破产者独立以 1/2 概率赢或输 1 元，资金为 0 时退出。赌场初始净收入为 0，可无限负债。求有限轮数 kkk 时赌场净收入的期望、赢钱概率的计算方法，以及长期结果。再比较“每轮恰有一半人赢”的规则。

考点：吸收游走；有限时刻均值；极限交换。

查看分析与解答

必要知识

资金归零后退出，使单人财富过程在零吸收。在正资金状态，一元输赢对称、条件期望不变；吸收后也保持零，因此有限时刻财富均值等于初值。多个赌客独立允许用卷积合成总资金分布。

分析思路

先分别求有限 k 的期望与分布，再处理长期几乎必然破产，最后解释为何长期结果与有限期望不同。替代规则需重新检查每轮现金流守恒。

解答步骤

以一名赌客、初资一元、两轮为例：第一轮输后停在零，概率一半；先赢后输回一，概率四分之一；连续赢到三，概率四分之一。赌场收入分别一、零、负二，赢钱概率一半，期望 1/2−2/4=0，展示均值与赢钱概率的不同。

单个赌客的资金 WtW_tWt​ 在 0 吸收，正资金时下一轮的条件均值仍是当前资金。因此每个有限 kkk 都有 E(Wk)=mE(W_k)=mE(Wk​)=m，赌场净收入 Ck=nm−∑iWkC_k=nm-\sum_iW_kCk​=nm−∑i​Wk​ 的期望为 0。均值为零并不自动使正负概率各半，因为分布可以偏斜。

先求单人资金分布，再对 nnn 人作离散卷积，即可得到 P(Ck>0)=P(∑iWk<nm)P(C_k>0)=P(\sum_iW_k<nm)P(Ck​>0)=P(∑i​Wk​<nm)。长期每个赌客几乎必然破产，但少数有限时点存活者可能极富，这正是极限与期望不能随意交换的原因。

单人分布的递推为 pt+1(0)=pt(0)+pt(1)/2p_{t+1}(0)=p_t(0)+p_t(1)/2pt+1​(0)=pt​(0)+pt​(1)/2，对 j≥1j\ge1j≥1 则有 pt+1(j)=[pt(j−1)1j>1+pt(j+1)]/2p_{t+1}(j)=[p_t(j-1)\mathbf1_{j>1}+p_t(j+1)]/2pt+1​(j)=[pt​(j−1)1j>1​+pt​(j+1)]/2，初态 p0(m)=1p_0(m)=1p0​(m)=1。状态零不再流出。对各赌客的分布作独立卷积后即可计算赌场赢钱概率。固定 kkk、人数增大且单人方差非零时，该概率可用中心极限定理近似，但并非精确为一半。

若另按题目比较的规则，每轮下注者人数为偶数且恰有一半赢、下注额相同，赌场该轮收支相抵，净收入恒为零。这与逐人独立胜负的机制不同。

对固定有限 n，每名赌客几乎必然在有限时间破产，所有破产时间的最大值也几乎必然有限，所以赌场收入最终为 nm，赢钱概率趋于一。但每个有限 k 的期望仍零，稀少且很富的存活赌客对应赌场巨额负收入，阻止期望随样本路径极限收敛。逐人独立与每轮严格一半胜负不同：后者下注额相同时每轮赌场收支恒零；剩余人数为奇数时还需补充配对或轮空规则才能继续定义游戏。

同类问题

随机过程题应区分固定时点期望、极限随机变量与极限事件概率。几乎必然收敛并不自动允许交换期望，吸收机制和尾部分布需要一起考察。
