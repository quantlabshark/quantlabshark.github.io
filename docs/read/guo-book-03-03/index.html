Merton 配置、消费与不交易区间

从财富变化推导 Merton 比例，解释消费选择和交易成本产生的不交易区间。

财富怎样随持仓变化

设无风险利率为 rrr，股票满足 dSt/St=μdt+σdBtdS_t/S_t=\mu dt+\sigma dB_tdSt​/St​=μdt+σdBt​。财富为 WtW_tWt​，股票比例为 πt\pi_tπt​，消费速度为 ctc_tct​。自融资关系给出

利息、股票超额收益和消费决定平均变化，布朗项表示市场随机波动。ctc_tct​ 的单位是每单位时间消费金额，不是财富比例；若消费比例为 ktk_tkt​，则 ct=ktWtc_t=k_tW_tct​=kt​Wt​。

消费的一阶条件是 U′(c)=VWU'(c)=V_WU′(c)=VW​：当前多消费一元获得的边际效用，等于留下这一元带来的未来价值。对幂效用，最优消费通常与财富成比例，但比例还依赖剩余期限、折现和终值效用，不能只由 Merton 股票比例确定。

将价值函数导数代回最优比例

风险厌恶系数的经济含义

幂效用的一阶、二阶导数为 U′(W)=W−γU'(W)=W^{-\gamma}U′(W)=W−γ、U′′(W)=−γW−γ−1U''(W)=-\gamma W^{-\gamma-1}U′′(W)=−γW−γ−1，所以 −WU′′/U′=γ-WU''/U'=\gamma−WU′′/U′=γ。财富放大一倍时，这个相对风险厌恶指标不变，因此无约束最优持仓通常按财富比例表示。

还可核算目标比例对长期对数增长的影响。若暂不消费、保持比例 π\piπ，财富对数的漂移为 r+π(μ−r)−π2σ2/2r+\pi(\mu-r)-\pi^2\sigma^2/2r+π(μ−r)−π2σ2/2。沿用 r=2%,μ=8%,σ=20%r=2\%,\mu=8\%,\sigma=20\%r=2%,μ=8%,σ=20%，π=0.5\pi=0.5π=0.5 的对数增长为 4.5%4.5\%4.5%。对数效用对应 γ=1\gamma=1γ=1，无约束比例为 1.5，对数增长为 6.5%6.5\%6.5%，但同时承担更高波动和借款暴露。

鲨鱼说

公式中的 1.5 表示股票市值是净财富的 150%，其中一部分由借款支持。它不是“最多投入全部本金”条件下可以直接执行的比例。

有交易费用后为何暂时不动

股票上涨会使其财富占比上升。无成本模型不断卖出一部分股票以保持目标比例；有比例成本时，小偏离的风险改善未必抵得过交易费用。

设现金为 xxx、股票市值为 yyy，买入一单位股票市值需支付 1+κb1+\kappa_b1+κb​ 单位现金，卖出只能收到 1−κs1-\kappa_s1−κs​。价值函数在不交易区内应满足边际条件

Vy−(1+κb)Vx≤0,(1−κs)Vx−Vy≤0.V_y-(1+\kappa_b)V_x\le0,\qquad(1-\kappa_s)V_x-V_y\le0.Vy​−(1+κb​)Vx​≤0,(1−κs​)Vx​−Vy​≤0.

第一式表示立即买入不能提高价值，第二式表示立即卖出不能提高价值。某个不等式达到等号时，相应交易开始有利，由此形成买入和卖出边界。

边界主要描述现金与风险资产的相对持仓状态，并不是一个固定的股票价格。相同股价下，持仓不同的投资者可以作出不同交易决策。比例成本下，典型最优控制把偏离推回边界。固定费用还可能使最优操作表现为一次较大的跳转。

图中仅演示一个预设区间的再平衡规则，区间边界不是根据 HJB 求出的最优值。计算最优区间需要同时满足价值方程、交易边界条件与偿付能力约束，通常采用数值方法。

鲨鱼说

不交易可以是一项经过计算的决策。关键是比较偏离目标造成的未来损失，与把持仓调回去所需支付的费用。

练习

财富 100，股票和现金各 50。股票上涨 10%10\%10%，现金不变。若忽略费用，要恢复一半股票比例，应卖出多少股票市值？

查看解答

总财富变为 105，股票市值为 55，占比约 52.38%52.38\%52.38%。目标股票市值为 52.5，应卖出 2.5。若区间规则允许股票比例在 45%45\%45% 至 55%55\%55% 之间，则本次无需交易。这是所给区间规则的结果，不等于该区间在所有参数下都最优。
