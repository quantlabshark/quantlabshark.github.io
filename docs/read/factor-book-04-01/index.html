4.1 多因子模型的经济含义与组合构造

从六组股票计算规模与价值收益，比较七类模型的经济解释、排序指标和调仓规则。

同样上涨，收益来源可以不同

甲组合一个月上涨3%，乙组合上涨2%。甲是否更有投资能力，要先看它承担了什么风险。如果甲主要持有小公司，乙主要持有大公司，而这个月恰好小公司普遍上涨，那么1个百分点的差距可能来自规模暴露。多因子模型把这些共同影响分别列出，再考察还剩多少收益没有得到解释。

令 ri=Ri−Rfr_i=R_i-R_fri​=Ri​−Rf​ 为股票超过无风险利率的收益，fkf_kfk​ 为第 kkk 个因子的收益。预期收益模型写成

E[ri]=∑k=1KβikE[fk].E[r_i]=\sum_{k=1}^{K}\beta_{ik}E[f_k].E[ri​]=k=1∑K​βik​E[fk​].

βik\beta_{ik}βik​ 是股票对该因子的敏感程度，E[fk]E[f_k]E[fk​] 是因子的预期收益。这里有两项不同的估计任务：测量股票承担了多少因子风险，估计这些风险平均对应多少收益。历史回归则写成 ri,t=αi+∑kβikfk,t+εi,tr_{i,t}=\alpha_i+\sum_k\beta_{ik}f_{k,t}+\varepsilon_{i,t}ri,t​=αi​+∑k​βik​fk,t​+εi,t​，用截距 αi\alpha_iαi​ 检查模型遗漏的平均收益，用残差 ε\varepsilonε 描述当期未解释的变化。

鲨鱼说

股票的市值是一个特征；按市值分组得到的“小盘减大盘”是一个组合；股票对该组合收益的敏感程度才是回归暴露。把这三层分开，模型名称和实际计算就容易对应起来。

从六个组合得到规模与价值因子

Fama–French三因子在市场超额收益之外加入规模SMB和价值HML。价值指标BM等于账面权益除以股票市值，数值越高，表示每一元市价对应的账面权益越多。

构造时，先分别按市值和BM划分股票。经典美国研究用纽约证券交易所股票的市值中位数划分小盘S、大盘B，用同一参考股票池BM的30%和70%分位数划分低L、中M、高H，再把断点用于NYSE、NASDAQ和AMEX的股票。两套划分取交集，得到S/H、S/M、S/L、B/H、B/M、B/L六组。

图中的关键顺序是先用形成日已知的特征分组，再计算随后持有期的收益。每组内部按市值加权；组成因子时，各组之间再等权平均。这是两层权重。

SMB=RS/H+RS/M+RS/L3−RB/H+RB/M+RB/L3,SMB=\frac{R_{S/H}+R_{S/M}+R_{S/L}}3-\frac{R_{B/H}+R_{B/M}+R_{B/L}}3,SMB=3RS/H​+RS/M​+RS/L​​−3RB/H​+RB/M​+RB/L​​,

HML=RS/H+RB/H2−RS/L+RB/L2.HML=\frac{R_{S/H}+R_{B/H}}2-\frac{R_{S/L}+R_{B/L}}2.HML=2RS/H​+RB/H​​−2RS/L​+RB/L​​.

SMB比较不同估值档中的小盘与大盘，HML比较不同规模档中的高BM与低BM。交叉分组减少其他特征的干扰，但无法使所有相关特征都完全相同。经典方案每年六月末更新财务分组，反映的是当时的研究规则。中国股票研究需要按实际披露日安排可用信息。

用自拟的六组月收益计算：

Python7 行
small = [0.03, 0.02, 0.01]  # 依次为高、中、低BM
big = [0.02, 0.01, 0.00]
smb = sum(small) / 3 - sum(big) / 3
hml = (small[0] + big[0] - small[2] - big[2]) / 2
assert abs(smb - 0.01) < 1e-12
assert abs(hml - 0.02) < 1e-12
print(f'SMB={smb:.2%}, HML={hml:.2%}')

结果为1%和2%。它们是当月已经实现的组合收益，估计长期溢价还需要许多期数据。SMB、HML曾被联系到财务困境和跨期投资机会变化，但名称本身没有确定唯一的风险机制。

动量与盈利带来的扩展

Carhart四因子保留市场、SMB、HML，再加入动量MOM。动量比较过去表现较强和较弱的股票。若用月末 ttt 的信息预测 t+1t+1t+1 月，可以累计 t−11t-11t−11 至 t−1t-1t−1 的11个月收益，跳过最近的 ttt 月，以减少短期反转的干扰。

这里每个整数月份都对应完整的一个月，避免“过去一年减一个月”在程序中少取或多取一期。所述原始构造每月将过去赢家与输家按30%两端分组，组内等权。后来同名动量数据可能采用不同权重。

Novy–Marx四因子采用市场、价值、动量和盈利PMU，不包含独立规模项。盈利用毛利润与总资产之比衡量。毛利润尚未扣除研发、广告等经营费用，因此与净利润相比，较少把当期投入直接当成经营能力下降。指标中的分母是总资产，不能误写成通常以营业收入为分母的销售毛利率。

该模型分别将价值、动量、盈利与市值做 2×32\times32×3 排序，组内市值加权。盈利因子为高盈利组减低盈利组。组合还以所属行业指数作相反方向的配对，降低行业涨跌的影响。动量每月更新，价值和盈利财务分组每年六月更新。相同的“动量”二字，并不意味着它与Carhart版本是同一条收益序列。

从股利贴现理解五因子

Fama–French五因子增加盈利RMW和投资CMA。理解其方向，可以从股东未来收到的钱出发。在净盈余关系成立时，利润 YYY 减去留在公司中的账面权益增加 ΔB\Delta BΔB，才是可分配给股东的现金。把未来现金按要求回报率 rrr 折现：

MtBt=∑τ=1∞Et[Yt+τ−ΔBt+τ]/Bt(1+r)τ.\frac{M_t}{B_t}=\sum_{\tau=1}^{\infty}\frac{E_t[Y_{t+\tau}-\Delta B_{t+\tau}]/B_t}{(1+r)^\tau}.Bt​Mt​​=τ=1∑∞​(1+r)τEt​[Yt+τ​−ΔBt+τ​]/Bt​​.

MtM_tMt​ 是当前市值，BtB_tBt​ 是当前账面权益。在其他条件固定时，价格更低需要更高的要求回报来解释。盈利更高而价格不变，也需要更高的要求回报。留存投资更大、可分配现金更少而价格不变，则对应更低的要求回报。

这些都是控制其他条件之后的关系。

实证构造分别用盈利、过去一年总资产增长率与规模交叉分组。RMW做多盈利强组、做空盈利弱组。CMA做多资产增长低的保守组、做空增长高的激进组。财务量是对未来盈利和投资的代理，未来账面权益变化与历史总资产变化并非同一个变量。具体复现应保留盈利指标的会计定义，不能把所有盈利指标统称为ROE。

五因子版SMB还要把价值、盈利、投资三套排序产生的小盘减大盘收益取平均；只复制三因子版SMB，会得到另一种组合。价值、盈利、投资和规模财务分组按年度更新。

从企业投资决策理解q因子

Hou–Xue–Zhang四因子包含市场、规模、投资与盈利。其出发点是企业是否应再投资一个项目。若多投入一元能够带来的未来收入现值大于一元，投资就有吸引力。持续投资后，边际成本会增加，直至边际收益现值与成本相等。

考虑两期公司：期初资产为 A0A_0A0​，新增投资为 I0I_0I0​，投资调整费用为 aI02/(2A0)aI_0^2/(2A_0)aI02​/(2A0​)；已有资产在下一期完全折旧，新投资产生利润率 Π1\Pi_1Π1​。投资目标中与 I0I_0I0​ 有关的部分是

−I0−a2I02A0+E0[M1Π1I0].-I_0-\frac a2\frac{I_0^2}{A_0}+E_0[M_1\Pi_1 I_0].−I0​−2a​A0​I02​​+E0​[M1​Π1​I0​].

M1M_1M1​ 是把不同未来状态的收入换成今天价值的随机折现因子。对投资额求导并令其为零，得到

1+aI0/A0=E0[M1Π1],E0[R1I]=E0[Π1]1+aI0/A0.1+aI_0/A_0=E_0[M_1\Pi_1],\qquad E_0[R^I_1]=\frac{E_0[\Pi_1]}{1+aI_0/A_0}.1+aI0​/A0​=E0​[M1​Π1​],E0​[R1I​]=1+aI0​/A0​E0​[Π1​]​.

R1IR^I_1R1I​ 是投资的总回报倍数，减去1才是净收益率。给定未来盈利，历史投资越多、边际成本越高，预期回报越低。给定投资，未来盈利越高，预期回报越高。在这一简化模型及相应融资条件下，企业投资回报可以联系到股票回报。

为了对应“给定另一变量”的条件关系，构造采用市值、季度ROE、资产增长的 2×3×32\times3\times32×3×3 独立排序，形成18组。规模因子平均9个小盘组减9个大盘组，盈利平均6个高盈利组减6个低盈利组，投资平均6个低投资组减6个高投资组。市值和投资排序变量每年更新，盈利变量每月更新，组合每月再平衡。

鲨鱼说

随机折现因子，即将不同未来状态的支付转换为当前价值的随机权重。

鲨鱼说

“投资低，未来收益高”不是说公司少建工厂就一定赚钱。模型讨论的是在盈利等条件相同时，投资规模与要求回报的联系。企业可能因为经营衰退而少投资，这与模型中的条件比较不同。

错误定价如何进入模型

Stambaugh–Yuan四因子包含市场、规模、管理MGMT、表现PERF。它把11项异象按共同变化分成两类：

管理类：6项 表现类：5项
股票净发行、复合股权发行、应计利润、净营业资产、资产增长、投资与总资产之比 财务困境、O-Score、动量、毛利润与总资产之比、资产回报率

每项先调整方向，使高综合分表示更可能高估，再平均组内排名。将两类综合分分别与市值交叉排序：市值用NYSE中位数，综合分用全体股票的20%、80%分位点。MGMT、PERF均做多潜在低估组、做空潜在高估组，组内按市值加权，组合按月更新。不同指标的排名转化必须统一，不能一部分“高分好”、另一部分“低分好”就直接平均。

它的SMB只使用两套排序的中间档：平均小盘中间组减大盘中间组。理由是高估股票难以卖空，小盘股又可能承受更强错误定价，简单平均所有估值档未必能抵消两端影响。多个指标能降低单项噪声，同时引入更多断点与合成选择，比较模型时要保留这些构造差异。

Daniel–Hirshleifer–Sun三因子包含市场、融资FIN和盈余公告后漂移PEAD。FIN针对较长时间的错误定价：管理层可能在估值高时发行股票、估值低时回购，而投资者没有充分反应。PEAD针对公告后的缓慢信息吸收，联系到注意力有限。

FIN使用过去五年复合股权发行和过去一年股票净发行。前者按NYSE的20%、80%分位点分三档。后者先区分净回购和净发行，在回购公司中按回购量中位数分组，在发行公司中按30%、70%分位点分组，分别取回购较多和发行较多的两端。两指标均在低档的股票进入FIN低组，均在高档的进入高组。

若只有一个指标可用，则按该指标的两端归组。其余归中组。再与市值做双重排序，低发行减高发行构成FIN，每年六月更新。

计算发行指标前要消除拆股的影响。令NtadjN_t^{adj}Ntadj​为按同一拆股基准调整后的股数，一年净发行可写为NSIt=log⁡(Ntadj/Nt−12adj)NSI_t=\log(N_t^{adj}/N_{t-12}^{adj})NSIt​=log(Ntadj​/Nt−12adj​)。拆成两股使原始股数翻倍，却没有融资。复权后的股数不会因此增加。自拟例中调整后股数由100增至110，净发行指标为log⁡1.1≈9.531%\log1.1\approx9.531\%log1.1≈9.531%。简单增长率为10%，两种口径单调对应但数值不同。

复合股权发行从市值变化中扣除已有股东的投资回报：CSIt=log⁡(MEt/MEt−60)−∑s=t−59tlog⁡(1+Rs)CSI_t=\log(ME_t/ME_{t-60})-\sum_{s=t-59}^{t}\log(1+R_s)CSIt​=log(MEt​/MEt−60​)−∑s=t−59t​log(1+Rs​)，其中MEMEME为权益市值，RsR_sRs​为相同月份口径的股票总回报。若五年市值从100增至180，而同期总回报乘数为1.5，CSI=log⁡(1.8/1.5)=log⁡1.2≈18.232%CSI=\log(1.8/1.5)=\log1.2\approx18.232\%CSI=log(1.8/1.5)=log1.2≈18.232%。市值增长中有一部分由价格上涨解释，剩余才进入复合指标。总回报包含现金分配时，指标还反映股东分配等融资变化，不能将它逐项等同于股数增长。

若研究纯发行股数，需另用拆股调整后的股份资料。

PEAD以最近财报披露日为0，累计第−2日至第1日的市场调整收益：CARi=∑d=−21(Ri,d−RM,d)CAR_i=\sum_{d=-2}^{1}(R_{i,d}-R_{M,d})CARi​=∑d=−21​(Ri,d​−RM,d​)。用CAR的20%、80%分位点与市值交叉分组，高CAR减低CAR，每月更新。公告窗口结束之后，完整CAR才可用于新交易。长周期融资与短周期公告反应分别捕捉不同的信息处理过程。

练习

某股票的市场、SMB、HML暴露为1.1、0.4、0.3，对应因子的预期月收益为0.5%、0.2%、0.3%。模型给出的预期超额收益是多少？若增加一个盈利因子，是否只需在原式最后加一项？

查看解答

预期超额收益为 1.1×0.5%+0.4×0.2%+0.3×0.3%=0.72%1.1\times0.5\%+0.4\times0.2\%+0.3\times0.3\%=0.72\%1.1×0.5%+0.4×0.2%+0.3×0.3%=0.72%。加入新因子后，应重新联合估计各项暴露；旧模型可能把盈利影响部分计入价值暴露。若采用五因子标准构造，SMB的定义也需要相应更新。
