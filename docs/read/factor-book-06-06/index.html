6.6 因子衰减、拥挤与成本后的收益

拆分信息曝光、同步持仓和交易成本，用经验贝叶斯收缩修正不稳定的高收益估计。

毛收益没变，净收益为何下降

一项策略回测月毛收益0.3%。初期资金较少，成本0.1%，净收益0.2%；规模扩大后，成交冲击使成本升至0.25%，净收益只剩0.05%。这次下降首先发生在执行层，而非一定意味着预测关系已经消失。

诊断样本外失效时，应同时保留信号收益、组合毛收益、实际成交和费用。因子本身可能是过拟合产物，真实机会也可能因信息曝光、拥挤或成本而减弱。

信息公开后，价格修正会更快

如果某指标捕捉错误定价，更多人知道后便可能提前交易，使修正更快完成。针对97个因子的历史研究区分了原样本结束到发表前、发表后两个阶段，平均收益相对样本内分别下降约26%和58%。两者差32个百分点被用于估计传播与知情交易的影响。

这是样本平均比较，不是每个策略都应统一打42折。

数据更新速度同样影响结果。业绩公告可能先给收入和利润，正式报表再提供完整财务项目。点时数据库逐项保存何时更新、当时是什么值，能避免把后来修订数字提前使用。相关美国研究发现，部分财务信号的收益集中在新信息公布后120天内，尤其最初30天，超过这一窗口后优势减弱。按年更新和按最新披露更新，检验的并非同一信息时效。

拥挤怎样从持仓传到价格

许多组合采用相似信号与调仓频率时，会共同买入某些股票。一旦受到冲击，它们又可能同时卖出，价格下跌与赎回相互强化。2007年8月美国量化基金的历史亏损，是研究相似持仓集中去杠杆的典型事件。

无法观察全部投资者持仓时，可使用以下代理：

代理 计算思路 与拥挤的联系
估值价差 比较多空两端BM等指标的中位数及其历史位置 多头价格被推高后，原有便宜程度可能收窄
配对相关性 剔除共同因子后，计算个股残差与组内其他股票平均残差的相关性，再汇总两端 同步资金流可能使残差共同变化
相对波动率 因子预测波动与市场预测波动之比 区分市场普遍波动与某因子异常活跃
长期累计收益 例如过去三年累计表现 表现追逐可能使资金集中并增加反转风险
空头持仓差 比较两端可取得的卖空数据 反映方向性持仓与借券拥挤

配对相关性不是简单平均原始股票相关性，先剔除系统部分是为了减少市场涨跌干扰。估值差的正负也取决于使用BM还是PB、做哪一端减哪一端，需要先固定定义。原先A股研究因制度和数据条件未采用空头持仓差，跨市场复现要检查可用数据。

成本应按实际成交金额计算

若每月买入和卖出各占净值50%，每成交一元的单边成本为0.2%，总成交额是净值的100%，因此总成本为0.2%，毛收益0.3%扣除后剩0.1%。若换手率定义为 12∑i∣Δwi∣\frac12\sum_i|\Delta w_i|21​∑i​∣Δwi​∣，就不能再把它当成全部成交额。

有效价差利用实际成交价相对交易前中间价计算，比只看挂牌买卖差更接近执行代价。还要加入佣金、冲击、融资与借券费用。降低成本的方法包括限制高成本股票、降低再平衡频率、设定买卖缓冲区，以及将成本纳入优化。调仓变慢又会损失部分新信息，需要比较净效果。

历史120因子研究中，纳入成本后平均样本内月收益从超过0.6%降到约0.3%，样本外更弱；改善交易方法后样本外平均月收益约0.13%。这些结果强调成本口径对研究结论的影响。

为什么高样本均值需要收缩

观察到的平均收益 μ^i\hat\mu_iμ^​i​ 包含真实均值 μi\mu_iμi​ 与估计噪声。设

μ^i∣μi∼N(μi,si2),μi∼N(μ0,τ2).\hat\mu_i\mid\mu_i\sim N(\mu_i,s_i^2),\qquad \mu_i\sim N(\mu_0,\tau^2).μ^​i​∣μi​∼N(μi​,si2​),μi​∼N(μ0​,τ2).

sis_isi​是该因子均值的标准误，τ2\tau^2τ2表示不同因子真实均值的离散程度。正态模型的后验均值为

μ~i=τ2τ2+si2μ^i+si2τ2+si2μ0.\tilde\mu_i=\frac{\tau^2}{\tau^2+s_i^2}\hat\mu_i +\frac{s_i^2}{\tau^2+s_i^2}\mu_0.μ~​i​=τ2+si2​τ2​μ^​i​+τ2+si2​si2​​μ0​.

估计越不精确，越向总体均值靠拢。矩估计可以用因子样本均值的截面平均估计 μ0\mu_0μ0​，用截面方差减平均 si2s_i^2si2​估计 τ2\tau^2τ2，并处理负估计值。这一步是在扣除观察到的离散中由测量误差造成的部分。

Python7 行
observed, group_mean = 0.01, 0.002
se, tau = 0.008, 0.004
weight = tau**2 / (tau**2 + se**2)
estimate = weight * observed + (1-weight) * group_mean
assert abs(weight - 0.2) < 1e-12
assert abs(estimate - 0.0036) < 1e-12
print(f'保留样本估计的权重：{weight:.0%}，收缩后均值：{estimate:.2%}')

观察均值1%被收缩为0.36%，因为其标准误0.8%大于组间真实均值标准差0.4%。历史成本研究进一步估计，发表后即便排名前5%的因子，收缩后的月收益约0.21%，市值加权版本约0.07%。

鲨鱼说

收缩估计根据证据精度调整样本结果与参考值的权重。同样1%的样本均值，长期稳定得到的证据应比短期偶然得到的证据占更大权重。

练习

因子公布后毛收益下降，但每次新财报公布后的前20天仍有明显收益，后续月份没有。应优先检验什么变化？

查看解答

检验信息进入价格的速度是否提高，比较按最新披露更新时间与固定年度更新的结果，并保留严格的实际披露时点。随后衡量更频繁更新带来的额外换手和冲击。若净收益没有改善，提高更新速度也不能直接成为实施理由。
