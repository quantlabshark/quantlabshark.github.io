常用随机积分与计算方法选择

按多项式、指数、三角函数和路径积分分类建立计算清单。

两种目标需要不同计算

“求积分”可能要求一个路径表达式，也可能只要求均值、方差或分布。对确定函数 h(t)h(t)h(t)，∫hdW\int h dW∫hdW 的分布由 ∫h2dt\int h^2dt∫h2dt 直接给出。为了求分布，不必先把它化成终点。对随机被积函数，仍可用等距求二阶矩，但正态性不能仅由积分符号判断。

若已有候选表达式，验证时应比较初值、漂移系数和扩散系数三项。初值相同且两个微分系数相同，才说明它们表示同一过程。只核对平均值会漏掉路径上的差异。

被积过程与积分条件

若 h(t)h(t)h(t) 是确定函数，∫0Th(t)dWt\int_0^T h(t)dW_t∫0T​h(t)dWt​ 是均值零、方差 ∫0Th(t)2dt\int_0^T h(t)^2dt∫0T​h(t)2dt 的正态变量。此时求分布通常比求端点表达式容易。若被积过程依赖 WtW_tWt​，伊藤积分仍可能均值为零，却一般不再正态。例如 ∫0TWtdWt=(WT2−T)/2\int_0^T W_tdW_t=(W_T^2-T)/2∫0T​Wt​dWt​=(WT2​−T)/2 是平移缩放后的卡方变量。
