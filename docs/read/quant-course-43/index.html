43 · 随机游走、布朗运动与鞅

从对称步长构造连续随机过程，理解条件期望、二次变差、随机积分以及厚尾和时间变化。

随机游走由离散增量累加而成，布朗运动描述连续时间下的一类随机变化，鞅则规定给定已有信息后的条件均值关系。三者从不同角度组织随机过程。

抛硬币的波动为何按平方根增长

每次独立掷一枚公平硬币，正面记+1、反面记−1，累计和为Sn=∑i=1nϵiS_n=\sum_{i=1}^n\epsilon_iSn​=∑i=1n​ϵi​。单步均值0、方差1，因此E(Sn)=0E(S_n)=0E(Sn​)=0、Var⁡(Sn)=n\operatorname{Var}(S_n)=nVar(Sn​)=n，标准差为n\sqrt nn​。

若将一年分成nnn步，每步乘以1/n1/\sqrt n1/n​，一年后的方差保持为1；若错用1/n1/n1/n，方差会缩到1/n1/n1/n并趋于0。布朗运动是这类缩放随机游走的连续极限。

布朗运动描述了什么

标准布朗运动WtW_tWt​从0出发，路径连续，不重叠时段的增量独立，且Wt+h−Wt∼N(0,h)W_{t+h}-W_t\sim N(0,h)Wt+h​−Wt​∼N(0,h)。时间长度扩大4倍，增量标准差扩大2倍。连续不意味着光滑，典型路径没有普通导数。

中心极限定理讨论某个终点的归一化和；函数中心极限定理讨论整条随机路径。对独立同分布、有限方差的步长，有n−1/2∑i≤nt(Xi−μ)n^{-1/2}\sum_{i\le nt}(X_i-\mu)n−1/2∑i≤nt​(Xi​−μ)弱收敛到σWt\sigma W_tσWt​。弱收敛表示路径分布逐渐接近，并非每条模拟路径逐点变成同一条曲线。

允许弱依赖时还需额外条件，极限方差一般变为长期方差γ0+2∑k≥1γk\gamma_0+2\sum_{k\ge1}\gamma_kγ0​+2∑k≥1​γk​，其中γk\gamma_kγk​是滞后kkk阶协方差。不能对任意相关序列直接套用独立步长的平方根缩放。

鲨鱼说

协方差，即两个变量偏离各自均值时，共同变化程度的度量。

信息、条件期望与鞅

用Ft\mathcal F_tFt​表示截至ttt时刻可获得的信息，随时间增加形成滤子。适应过程的当前值由当前信息确定。停时表示是否已经停止，可以用当时信息判断。例如“首次跌破阈值的时刻”是停时，“未来一年最低价发生的时刻”通常不是。

过程MtM_tMt​为鞅，要求可积、适应，并满足E(Mt+h∣Ft)=MtE(M_{t+h}\mid\mathcal F_t)=M_tE(Mt+h​∣Ft​)=Mt​。即基于现有信息，未来条件均值等于当前值。公平随机游走和布朗运动都是鞅；零条件均值的增量称为鞅差分。

若条件期望不小于当前值，称下鞅；不大于当前值，称上鞅。这些定义不要求增量独立，也不要求条件方差恒定。GARCH型波动可以随过去信息变化，而收益创新仍是鞅差分。

可选停止结论需要有界停时或一致可积等条件。“一直加倍下注直到赢一次”不能凭鞅性质推出有限本金下的必胜策略。一致可积控制的是尾部期望是否可统一忽略。局部鞅则通过一列越来越晚的停时，先在受控范围内满足鞅条件。局部性质不自动等于全局可积鞅。

二次变差为何不能忽略

把[0,t][0,t][0,t]分成许多小段，平方增量之和∑(ΔW)2\sum(\Delta W)^2∑(ΔW)2趋于ttt，称为二次变差。普通平滑路径的对应平方和趋于0，布朗路径却保留了有限随机波动尺度。

因此对XtX_tXt​满足dXt=μtdt+σtdWtdX_t=\mu_tdt+\sigma_tdW_tdXt​=μt​dt+σt​dWt​，Itô公式为

随机积分如何对应持仓收益

分段策略在时点tit_iti​确定仓位HiH_iHi​，随后收益为Hi(Wti+1−Wti)H_i(W_{t_{i+1}}-W_{t_i})Hi​(Wti+1​​−Wti​​)。仓位必须在增量出现前确定，这对应可预测性。允许事后看到涨跌再选仓位，就改变了积分和信息条件。

在平方可积条件下，Itô等距给出

E[(∫0tHs dWs)2]=E∫0tHs2ds.E\left[\left(\int_0^tH_s\,dW_s\right)^2\right]=E\int_0^tH_s^2ds.E[(∫0t​Hs​dWs​)2]=E∫0t​Hs2​ds.

一年中前半段仓位1、后半段2，积分方差为0.5×12+0.5×22=2.50.5\times1^2+0.5\times2^2=2.50.5×12+0.5×22=2.5，不是平均仓位1.5的平方2.25。风险按每段暴露平方累积。

从算术价格到几何价格

几何布朗运动dPt/Pt=μdt+σdWtdP_t/P_t=\mu dt+\sigma dW_tdPt​/Pt​=μdt+σdWt​保持价格为正。对数价格满足

log⁡(Pt/P0)=(μ−σ2/2)t+σWt.\log(P_t/P_0)=(\mu-\sigma^2/2)t+\sigma W_t.log(Pt​/P0​)=(μ−σ2/2)t+σWt​.

因此E(Pt)=P0eμtE(P_t)=P_0e^{\mu t}E(Pt​)=P0​eμt，而平均对数增长为μ−σ2/2\mu-\sigma^2/2μ−σ2/2。两者差异再次体现波动对复利的影响。

import numpy as np
rng = np.random.default_rng(43)
n, paths, T = 252, 20000, 1.0
dw = rng.normal(0.0, np.sqrt(T/n), (paths, n))
wT = dw.sum(axis=1)
qv = (dw*dw).sum(axis=1)
S0, mu, sigma = 100.0, 0.06, 0.20
ST = S0*np.exp((mu-0.5*sigma*sigma)*T + sigma*wT)
print('平均二次变差', round(qv.mean(), 4))
print('终值样本均值、理论均值', round(ST.mean(), 3), round(S0*np.exp(mu*T), 3))

代码依赖NumPy，模拟20000条、每年252步的路径，检查平均二次变差；同时模拟初价100、漂移6%、波动20%的价格。理论一年均价为100e0.06≈106.1837100e^{0.06}\approx106.1837100e0.06≈106.1837。模拟均值有抽样误差，不能要求每次精确相等。

厚尾不必依靠无限方差

早期金融模型用稳定分布描述厚尾。尾部概率近似cx−αcx^{-\alpha}cx−α时，α≤1\alpha\le1α≤1通常没有有限均值，1<α≤21<\alpha\le21<α≤2通常没有有限方差；对称稳定和的尺度按n1/αn^{1/\alpha}n1/α增长。正态是稳定族的特殊情形，柯西分布也属其中。无限方差模型不能照常使用样本方差与夏普比率的常规推断。

另一条解释来自随机时钟。若给定活动强度vtv_tvt​后，价格变化服从N(0,γ2vt)N(0,\gamma^2v_t)N(0,γ2vt​)，不同日期的方差混合可以产生厚尾。若vtv_tvt​均值为mmm、方差为s2s^2s2，无条件峰度为3(1+s2/m2)>33(1+s^2/m^2)>33(1+s2/m2)>3，同时仍有有限方差γ2m\gamma^2mγ2m。

成交量可作为活动强度的代理，历史示例用2005—2014年的Pfizer价格和成交量拟合对数平方变动与成交量关系，再检查标准化残差的QQ图。代理拟合并不自动恢复独立正态性。还应看残差时间依赖和零收益处理。方差Gamma等模型也通过随机时钟构造不同的尾部形态。

跳跃、补偿与风险分解

半鞅可以分为局部鞅部分与有限变差部分，容纳连续波动和跳跃。若价格发生跳跃，二次变差还包含跳幅平方之和：[M]t=⟨Mc⟩t+∑s≤t(ΔMs)2[M]_t=\langle M^c\rangle_t+\sum_{s\le t}(\Delta M_s)^2[M]t​=⟨Mc⟩t​+∑s≤t​(ΔMs​)2。跳跃下Itô公式需额外加上函数跳变减一阶近似的修正项。

Doob–Meyer分解把适当条件下的下鞅写成鞅加可预测累积项。对平方可积鞅，Mt2−⟨M⟩tM_t^2-\langle M\rangle_tMt2​−⟨M⟩t​为鞅，⟨M⟩\langle M\rangle⟨M⟩称为可预测二次变差。连续情形它与路径二次变差相同，跳跃情形需区分。两个鞅的协变差刻画共同波动，正交分解把可由一组风险解释的部分与剩余部分分开。

鲨鱼说

“收益条件均值为0”与“风险恒定”没有等价关系。即使方向无法预测，波动也可能成簇出现，仓位和风险估计仍需要随状态变化。
