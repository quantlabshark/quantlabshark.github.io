第 n 次到达与累计计数

利用 Gamma 分布和均匀次序统计量计算等待时间、累计工作量及其条件分布。

第 n 次事件的时间

Poisson 过程的相邻到达间隔独立且服从 Exp⁡(λ)\operatorname{Exp}(\lambda)Exp(λ)。第 nnn 次到达时间 Sn=T1+⋯+TnS_n=T_1+\cdots+T_nSn​=T1​+⋯+Tn​ 因而服从 Gamma 分布：

pSn(s)=λnsn−1e−λs(n−1)!,s>0.p_{S_n}(s)=\frac{\lambda^ns^{n-1}e^{-\lambda s}}{(n-1)!},\quad s>0.pSn​​(s)=(n−1)!λnsn−1e−λs​,s>0.

均值为 n/λn/\lambdan/λ，方差为 n/λ2n/\lambda^2n/λ2。也可以不求密度，直接利用 {Sn≤t}={Nt≥n}\{S_n\le t\}=\{N_t\ge n\}{Sn​≤t}={Nt​≥n}，得到

P(Sn≤t)=1−e−λt∑k=0n−1(λt)kk!.\mathbb P(S_n\le t)=1-e^{-\lambda t}\sum_{k=0}^{n-1}\frac{(\lambda t)^k}{k!}.P(Sn​≤t)=1−e−λtk=0∑n−1​k!(λt)k​.

由计数写出的分布函数还可以求导验证 Gamma 密度。对 e−λt∑k=0n−1(λt)k/k!e^{-\lambda t}\sum_{k=0}^{n-1}(\lambda t)^k/k!e−λt∑k=0n−1​(λt)k/k! 求导，指数项与多项式的前 n−1n-1n−1 项逐项抵消，只剩 −λntn−1e−λt/(n−1)!-\lambda^nt^{n-1}e^{-\lambda t}/(n-1)!−λntn−1e−λt/(n−1)!；再考虑分布函数前面的负号，就得到正的到达密度。

这提供了两条相互核对的路线：把 nnn 个独立指数间隔相加，或者把“到达时间不晚于 ttt”改写成“截至 ttt 至少有 nnn 次”。前者适合求矩，后者适合直接计算尾概率。

E[At∣Nt=n]=nt2,Var⁡(At∣Nt=n)=nt212.\mathbb E[A_t\mid N_t=n]=\frac{nt}{2},\qquad \operatorname{Var}(A_t\mid N_t=n)=\frac{nt^2}{12}.E[At​∣Nt​=n]=2nt​,Var(At​∣Nt​=n)=12nt2​.

在 0<s1<⋯<sn<t0<s_1<\cdots<s_n<t0<s1​<⋯<sn​<t 上，前 nnn 次到达出现在这些小区间、且截至 ttt 没有第 n+1n+1n+1 次事件的联合密度是 λne−λt\lambda^ne^{-\lambda t}λne−λt。除以 P(Nt=n)=e−λt(λt)n/n!\mathbb P(N_t=n)=e^{-\lambda t}(\lambda t)^n/n!P(Nt​=n)=e−λt(λt)n/n!，得到条件密度 n!/tnn!/t^nn!/tn。
