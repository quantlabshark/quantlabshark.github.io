2. 赠送筹码与累计下注门槛

题目

存入 1000 元可获得 2000 筹码。每次公平猜硬币，可押不超过余额的正整数筹码 X。猜中总返还 1.4X1.4X1.4X，猜错返还零。累计下注额严格超过 4000 后可提取全部余额。此前提现要扣除赠送的 1000，余额不足则最多提取零。下注计入流水，金额可选 1、2000 等。是否存在相对初始 1000 元存款的正期望净收益策略？

考点：筹码与现金；门槛终止；路径期望。

查看分析与解答

必要知识

筹码余额不等于随时可取的现金，未达流水门槛前要扣赠送部分。单次下注的负期望与含赠送规则的整体净现金流应分别计算。题中门槛是严格超过4000，恰4000仍不合格。

分析思路

构造明确的停止策略，列出各路径余额与累计下注。先算最终实际提现期望，再减最初现金存入额，不把赠送筹码当成额外现金支出。

解答步骤

第一注2000若输，概率一半，提现零；若赢，余额2800、流水2000。第二注2000赢后余额3600，输后余额800，两种都达到流水4000但未超过，所以各再押一筹码。

单次下注的净变化：赢时 +0.4X+0.4X+0.4X，输时 −X-X−X，期望为 −0.3X-0.3X−0.3X。单看下注是负期望，但赠送筹码和提现规则使整体现金流需要另算。

采取如下策略：首次押 2000，若输则余额为零，停止。若赢则余额为 2800，再押 2000。第二次之后累计下注恰为 4000，尚未满足“严格超过”。此时余额为 3600（第二次赢）或 800（第二次输），均可再押 1，然后提现。

在第一次赢的条件下，第二次之后的期望余额为 (3600+800)/2=2200(3600+800)/2=2200(3600+800)/2=2200，最后押 1 再减少期望 0.3，因此期望提现为 12×(2200−0.3)+12×0=1099.85.\frac12\times(2200-0.3)+\frac12\times0=1099.85.21​×(2200−0.3)+21​×0=1099.85. 扣除存入的 1000，期望净收益为 99.85。本问只要求证明存在正期望策略，这一构造已经达到目标，尚不需要证明它是最优策略。

第二注后的两种余额都足以承担最后一注。末注赢增加0.4、输减少1，期望变化−0.3，且无论输赢流水都变4001，余额可全取。故总体期望提现0.5×2199.7=1099.85，净值99.85；首轮失败仍可能损失全部存款，正期望不代表每条路径盈利。

同类问题

带赠送和提现条件的问题按真实现金流与规则分支计算。证明存在只需给一个有效构造，证明最优则还需比较所有允许的停止与下注策略。

3. Lasso 的软阈值与坐标下降

题目

给定 λ≥0\lambda\ge0λ≥0，求 min⁡θ{12(x−θ)2+λ∣θ∣}\min_\theta\{\tfrac12(x-\theta)^2+\lambda|\theta|\}minθ​{21​(x−θ)2+λ∣θ∣}。再对 12∥Y−X1β1−X2β2∥2+λ(∣β1∣+∣β2∣)\tfrac12\|Y-X_1\beta_1-X_2\beta_2\|^2+\lambda(|\beta_1|+|\beta_2|)21​∥Y−X1​β1​−X2​β2​∥2+λ(∣β1​∣+∣β2​∣) 推导坐标下降式，并编程从零系数开始依次更新两个坐标，共执行 10 轮。

考点：零点次梯度；坐标残差；软阈值。

查看分析与解答

必要知识

绝对值在零点的斜率不是单一数，而是次梯度区间[−1,1]。这个区间使一段输入都以零为最优，正是Lasso产生稀疏解的原因。

分析思路

标量问题分正、负、零三段求解。坐标更新把其他系数固定，提取当前列的二次曲率和线性项，套用同一个软阈值。

解答步骤

固定其他坐标后，损失中与β_j有关的部分为(1/2)||X_j||²β_j²−(X_jᵀr_j)β_j+λ|β_j|。在β_j非零时解导数，在零时检查|X_jᵀr_j|≤λ，统一得到S(X_jᵀr_j,λ)/||X_j||²。

当 θ>0\theta>0θ>0，导数为 θ−x+λ\theta-x+\lambdaθ−x+λ，驻点 θ=x−λ\theta=x-\lambdaθ=x−λ 只有在 x>λx>\lambdax>λ 时有效。当 θ<0\theta<0θ<0，导数为 θ−x−λ\theta-x-\lambdaθ−x−λ，驻点 x+λx+\lambdax+λ 只有在 x<−λx<-\lambdax<−λ 时有效。

在零点，绝对值的次梯度为 [−1,1][-1,1][−1,1]，最优条件是 0∈−x+λ[−1,1]0\in-x+\lambda[-1,1]0∈−x+λ[−1,1]，即 ∣x∣≤λ|x|\le\lambda∣x∣≤λ。三种情况合并为 S(x,λ)=sign⁡(x)max⁡(∣x∣−λ,0).S(x,\lambda)=\operatorname{sign}(x)\max(|x|-\lambda,0).S(x,λ)=sign(x)max(∣x∣−λ,0). 例如 x=3,λ=1x=3,\lambda=1x=3,λ=1 时结果为 2，x=0.6x=0.6x=0.6 时直接缩为零。

更新第 j 个回归系数时，先排除该变量贡献，得部分残差 rj=Y−∑k≠jXkβkr_j=Y-\sum_{k\ne j}X_k\beta_krj​=Y−∑k=j​Xk​βk​。关于 βj\beta_jβj​ 的二次项曲率为 XjTXjX_j^TX_jXjT​Xj​，所以 βj←S(XjTrj,λ)XjTXj.\beta_j\leftarrow\frac{S(X_j^Tr_j,\lambda)}{X_j^TX_j}.βj​←XjT​Xj​S(XjT​rj​,λ)​. 零列对拟合没有作用，取系数零。每轮按最新的另一个系数更新，10 轮表示两个坐标各更新 10 次。固定轮数完成后可再检查目标值和 KKT 残差；10 轮本身不保证任何数据都已收敛。

import numpy as np
def coordinate_lasso(X,y,lam,cycles=10):
    X=np.asarray(X,float); y=np.asarray(y,float)
    if lam<0: raise ValueError('lambda非负')
    beta=np.zeros(X.shape[1])
    for _ in range(cycles):
        for j in range(X.shape[1]):
            residual=y-X@beta+X[:,j]*beta[j]
            norm=X[:,j]@X[:,j]
            v=X[:,j]@residual
            beta[j]=np.sign(v)*max(abs(v)-lam,0)/norm if norm else 0
    return beta
assert np.allclose(coordinate_lasso(np.eye(2),[3,-1],1),[2,0])

单位矩阵例子中两个坐标不耦合，x为3和−1，阈值一，结果2与零，一轮即稳定。一般相关列中，更新第一坐标后第二坐标必须使用新残差。十轮只是题设迭代次数；检查非零坐标梯度与λ符号项抵消、零坐标梯度不超λ，才可评估最优性。

4. 两种交易规则的持仓与交易次数

题目

时点 i=0,…,Ni=0,\ldots,Ni=0,…,N 的价格为 SiS_iSi​，信号 Fi∈{−1,1}F_i\in\{-1,1\}Fi​∈{−1,1}。在前 N 个时点交易，最后在 N 平仓，不计费用。规则 A 每期按信号买或卖一单位，相反方向用先进先出平旧仓。规则 B 每期把总持仓调整为 FiF_iFi​。分别计算持仓、损益和平均持有期。

若信号均值为零、方差为一、相邻相关系数为 r，且间隔大于 1 的信号两两独立，求规则 B 的预期下单次数与单位成交数，并讨论长期平均持有期。

考点：交易量与持仓；FIFO；翻转频率。

查看分析与解答

必要知识

信号可以表示新增交易量，也可以表示目标持仓，这两种解释产生不同库存。下单次数只数非零指令，单位成交量则还要考虑从一单位多头翻到一单位空头需交易两单位。

分析思路

先分别写持仓，再由价格增量求损益；持有期按真实开平配对。随机信号部分先求相邻翻转概率，再线性累计期望次数，长期平均需额外平稳可遍历条件。

解答步骤

规则A信号[1,1,−1]在时点0、1开两单位多，时点2用FIFO平最早一单位，时点3平剩余一单位，持有期分别2和2，平均2。规则B则第一单位持有到2，翻空后持有到3，两个持有段长度2和1，平均1.5。

先用例子区别两种规则。若信号为 [1,1,-1]，规则 A 的期末持仓为 [1,2,1]；规则 B 为 [1,1,-1]。B 的最后一次调整需要卖出两单位，其中一单位平多、一单位开空。因此下单次数和单位成交数量不同。

from collections import deque
def fifo_duration(signals):
    opened=deque(); duration=closed=0
    for t,s in enumerate(signals):
        if s not in (-1,1): raise ValueError('信号须为±1')
        if opened and opened[0][1]!=s:
            old,_=opened.popleft(); duration+=t-old; closed+=1
        else: opened.append((t,s))
    for old,_ in opened:
        duration+=len(signals)-old; closed+=1
    return duration/closed if closed else 0
assert fifo_duration([1,1,-1])==2

必要知识

线性回归面对非线性响应时，估计的是最佳线性近似斜率，不是非线性函数本身。即使没有额外观测噪声，抽到哪些X仍随机，样本斜率因此有抽样波动。

分析思路

先用大数定律求分子分母极限，再把斜率误差精确写成均值零的随机和除以趋一的分母。计算方差时保留分子与分母的共同随机性。
