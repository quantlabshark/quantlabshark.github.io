6.8 机器学习的预测、降维与样本外检验

由线性预测进入树模型与神经网络，计算样本外误差，并解释PCA、IPCA与风险溢价PCA。

六个相近指标，为什么可能让预测更差

用规模、价值和动量预测收益后，又加入三个与它们高度相关的指标，训练误差通常会下降。但相关输入使系数可以在许多组合之间互相抵消，样本稍变，估计就可能大幅摆动。机器学习的作用之一，是在更多信息与更大估计误差之间作出有约束的选择。

把时点 ttt 已知特征记为 zi,t\mathbf z_{i,t}zi,t​，预测目标为下一期收益 ri,t+1r_{i,t+1}ri,t+1​。任务可以是预测具体收益、是否跑赢基准或股票排名。目标不同，损失函数和评价方式也不同。

线性模型中的三种改造

普通线性预测为 r^=a+z⊤b\hat r=a+\mathbf z^\top\mathbf br^=a+z⊤b。OLS最小化平方误差，极端误差的影响很大。Huber损失在小误差区使用平方，大误差区改为线性：

eee为预测误差，ξ\xiξ为切换阈值。加权回归则改变不同观察值的重要程度，例如按可靠程度或目标投资范围给权重；它解决的问题与Huber降低离群点影响并不完全相同。

惩罚回归在误差之外增加系数代价。岭回归加 λ∑jbj2\lambda\sum_jb_j^2λ∑j​bj2​，把不稳定系数压小；Lasso加 λ∑j∣bj∣\lambda\sum_j|b_j|λ∑j​∣bj​∣，可使部分系数恰好为0；弹性网络结合两者。惩罚强度 λ\lambdaλ用训练与验证区间选择，特征尺度也只能用训练数据估计。

降维方法把许多输入压成少数综合变量。PCR先用PCA寻找共同波动方向，再回归收益。PLS提取方向时已经考虑收益目标。前者可能保留解释输入波动最多、却与预测目标无关的方向，后者则需要更谨慎地隔离目标数据。

非线性可以从简单条件关系开始

“价值只在盈利为正的公司中有效”是一个交互关系。在线性参数模型中可增加价值乘盈利指标，也可以加入多项式与样条。它们对特征非线性，但对待估系数仍可线性。不能因为出现平方项就一概称为广义线性模型。逻辑回归则通过连接函数预测0/1事件概率，适合“下月是否跑赢基准”。

回归树把样本按阈值分区，使用各叶子中的训练收益平均值预测。例如先分大盘与小盘，再在小盘中分高BM与低BM，价值的作用就随规模状态改变。过深的树会把少量噪声单独分组，需要限制深度、最少样本数等。

用8个训练样本计算一棵两层树，规模单位任意，收益单位为百分比。先以规模50分两支，再在每支以BM=0.8划分：

Bagging对重抽样训练的多个模型求平均。随机森林进一步随机选择候选特征，降低树之间的相关性。Boosting按顺序修正已有预测，在平方误差下，下一棵树拟合当前残差。第一轮预测1.2%、实际3%，剩余1.8%便是待修正对象。使用小步长并提前停止，减少把噪声也全部拟合掉的风险。

支持向量方法用核函数表达高维非线性关系，分类时追求带约束的间隔，回归时可设置误差容忍区。神经网络则把线性组合与非线性激活层层连接，用梯度方法估计参数。层数、参数量、正则化和训练停止时间都需要验证。目标函数光滑并不保证神经网络训练达到全局最优。

正则化，即在拟合目标中加入约束或惩罚，以控制模型复杂度的方法。

PCA为何不直接等于收益预测

隐性因子模型 ri,t=βi⊤ft+εi,tr_{i,t}=\boldsymbol\beta_i^\top\mathbf f_t+\varepsilon_{i,t}ri,t​=βi⊤​ft​+εi,t​中，因子与暴露都未直接观察到。PCA从收益协方差中提取共同方向。若对因子作满秩线性变换、对暴露作相反变换，拟合收益可以不变，因此可识别的首先是因子空间，而非唯一的名称。

在因子足够强、样本足够的条件下，可以先用PCA估计隐性空间，再研究可观察因子在该空间的暴露与溢价。这帮助减少遗漏因子问题。稀疏PCA还通过限制载荷，使少数宏观变量构成较可解释的成分。历史研究用120项宏观数据提取10个稀疏方向，再分析其中名义利率、住宅与乐观情绪等溢价。

IPCA把公司特征用于随时间变化的暴露：βi,t=Γ⊤zi,t\boldsymbol\beta_{i,t}=\Gamma^\top\mathbf z_{i,t}βi,t​=Γ⊤zi,t​，联合估计映射 Γ\GammaΓ与隐性因子。这样公司规模、估值变化可以传到风险暴露，而不是给每只股票固定一个长期β。它并非简单地对特征做一次普通PCA。

风险溢价PCA在拟合共同波动之外加入均值定价误差，使目标同时关注一阶矩和二阶矩。普通PCA优先解释高方差方向，高方差却不必有高均值。历史IPCA与风险溢价PCA研究展示了更好的定价与样本外切线组合表现，但统计组合的多空、换手与估计精度还需要单独转成可投资约束。

二维例中设Σ=diag⁡(0.04,0.01)\Sigma=\operatorname{diag}(0.04,0.01)Σ=diag(0.04,0.01)、μ=(0,0.05)⊤\mu=(0,0.05)^\topμ=(0,0.05)⊤。普通PCA第一方向为(1,0)⊤(1,0)^\top(1,0)⊤，解释80%方差，却有0平均收益。第二方向只解释20%方差，但平均收益5%、波动10%。若为了展示均值项作用，将谱矩阵写成Σ+20μμ⊤=diag⁡(0.04,0.06)\Sigma+20\mu\mu^\top=\operatorname{diag}(0.04,0.06)Σ+20μμ⊤=diag(0.04,0.06)，领先方向转为第二维。

这里20是自拟目标权重，用来说明风险溢价PCA为何会保留低方差而有均值的信息，不是所有实现通用的参数。

IPCA的二维数例则从特征到暴露：设zi,t=(1,BMi,t)⊤z_{i,t}=(1,BM_{i,t})^\topzi,t​=(1,BMi,t​)⊤、Γ=(0.5,0.4)⊤\Gamma=(0.5,0.4)^\topΓ=(0.5,0.4)⊤，单因子暴露为βi,t=0.5+0.4BMi,t\beta_{i,t}=0.5+0.4BM_{i,t}βi,t​=0.5+0.4BMi,t​。BM从0.5变为1，暴露由0.7变为0.9。同一股票的暴露随特征变化，因子收益仍需与映射系数一起估计。这与上面按协方差寻找固定方向的PCA不同。

鲨鱼说

“解释最多波动”与“预测最高收益”是不同任务。一条因子可以每天大幅波动、长期均值接近零；它对风险模型很重要，却未必适合直接作为选股信号。

用训练前缀预测后60期

下面生成180期自拟数据，前120期训练岭回归，后60期测试；标准化也放在训练流水线中完成。

Python13 行
import numpy as np
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import Ridge
rng = np.random.default_rng(17)
X = rng.normal(size=(180, 6))
y = 0.01*X[:, 0] - 0.006*X[:, 1] + rng.normal(0, 0.01, 180)
model = make_pipeline(StandardScaler(), Ridge(alpha=10))
model.fit(X[:120], y[:120])
pred = model.predict(X[120:])
r2 = 1 - np.sum((y[120:]-pred)**2) / np.sum(y[120:]**2)
assert np.isfinite(r2)
print(f'相对零预测的样本外R²：{r2:.4f}')

这里知道模拟数据中前两个特征有信号，因此可以检查算法是否恢复部分关系；真实数据不提供这个答案。若要选择alpha，需在前120期内部再留验证区间。

解释模型与防止重复试验偏差

特征扰动、预测敏感度和分组表现可以帮助解释模型，但相关特征会共享重要性，重要性也不等于因果作用。金融数据只有有限历史路径，按时间滚动测试能避免直接用未来数据，却无法防止研究者反复根据整条回测曲线修改规则。

可保留最终独立测试期，对重叠收益标签设置隔离，使用多场景模拟检查稳定性，并对多次择优后的夏普作适当调整。模拟检验的是假定数据过程下的表现，不能替代真实新时期。自相关、异方差和厚尾也应进入验证设计。

练习

用所有月份计算标准化均值，再按时间切训练和测试；与先切分、只用训练均值标准化相比，为什么前一种仍有信息泄漏？

查看解答

全样本均值和标准差含有未来状态，改变了过去每个特征的坐标尺度。应只在训练集拟合变换，再原样应用于验证和测试；滚动更新时也仅使用更新日之前的数据。特征选择、PCA和缺失值填补同样遵守这一顺序。

资料来源：石川、刘洋溢、连祥斌，《因子投资：方法与实践》，2020年，PDF第281—290页。
