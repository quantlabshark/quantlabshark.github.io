01 · Alpha101 的输入、输出与研究问题

从一张日期与股票组成的数据表出发，区分信号分数、预测能力和交易收益。

因子分数与收益标签

设今天有 A、B、C 三只股票，我们希望比较它们随后一段时间的表现。一个量价公式读取已经发生的价格和成交量，为每只股票输出一个数。例如输出分别为 0.2、−0.1、0.7，表示 C 的分数最高、B 最低。

公式输出是用于股票比较的特征分数。C 的分数为 0.7，说明它在三只股票中排名最高；分数与后续收益的关系，需要使用历史样本另行估计。评价时，将当日排序与随后实际收益对应起来。

研究对象可以写成

xi,t=F(P≤t,V≤t),yi,t=Oi,t+2Oi,t+1−1.x_{i,t}=F(P_{\le t},V_{\le t}),\qquad y_{i,t}=\frac{O_{i,t+2}}{O_{i,t+1}}-1.xi,t​=F(P≤t​,V≤t​),yi,t​=Oi,t+1​Oi,t+2​​−1.

其中 iii 是股票，ttt 是交易日，PPP 表示价格，VVV 表示成交量，OOO 是开盘价。右侧收益标签从下一开盘开始，因为使用了今日收盘价的公式，要在收盘后才算得完整。标签仅在事后评价时使用，不进入今日分数计算。

鲨鱼说

因子分数负责排序，收益标签负责记录后续结果。例如高分组的后续平均收益高于低分组，才提供了排序方向与收益有关的证据。这个关系还需在不同时间区间比较。

日期与股票两个方向

把数据放在一个矩阵中，每一行是同一天的不同股票，每一列是一只股票的历史。今天 A、B、C 的价格是 10、20、15，截面排名依次为 1/3,1,2/31/3,1,2/31/3,1,2/3。对 A 的三天价格 9、11、10 排名，今天位于自身历史的 2/32/32/3。

前者回答“在其他股票中处于哪里”，后者回答“在自己最近历史中处于哪里”。Alpha101 经常把这两个方向嵌套：先做每天的股票排序，再分析这只股票的名次怎样变化。交换顺序会改变信号。

Alpha101 的计算示例

第 101 项为

a=C−OH−L+0.001.a=\frac{C-O}{H-L+0.001}.a=H−L+0.001C−O​.

若开盘 O=10O=10O=10、收盘 C=10.2C=10.2C=10.2、最高 H=10.4H=10.4H=10.4、最低 L=9.8L=9.8L=9.8，则 a=0.2/0.601≈0.3328a=0.2/0.601\approx0.3328a=0.2/0.601≈0.3328。分子表示开盘至收盘的价格变化，分母是当日振幅加一个小数值。即使两只股票都涨了 0.2 元，振幅不同也会得到不同的分数。

这也不是常见的收盘位置指标 (2C−H−L)/(H−L)(2C-H-L)/(H-L)(2C−H−L)/(H−L)。后者比较收盘价相对全天高低点的位置；本式保留了开盘价。因此开盘不同而最高、最低、收盘相同的两天，本式仍会不同。

加入 0.001 可以避免高低价相等时直接除零，但它有价格单位。数据从元改成分时，若常数不一起换单位，结果并不严格不变。实现细节会影响结果，不能只看公式外形。

本专题提供的实测范围

101 个公式均有实现和逐项解释。现有真实行情可评价其中 82 项；18 项需要历史行业分类，另 1 项需要历史市值。教学数据可演示全部输入类型，但构造的行业和市值不用于声称市场效果。

实测使用固定 60 股样本，报告 IC、年度变化和分组费用敏感性。它们帮助判断信号的稳定性与数据要求。公式分数要成为交易，还需确定仓位、成交、费用和约束，后文会逐步说明。

练习

两只股票的分数分别为 −3 和 −1。若采用“高分优先”的规则，哪只股票优先？能否仅凭负号判断应当做空两只股票？

查看解答

−1 大于 −3，因此第二只优先。负号本身不能决定仓位。只做多组合可以持有排名较高的一组；多空组合可以分别持有高低组；风险预算还会改变具体权重。分数方向、排序规则和仓位规则应分别写清。
