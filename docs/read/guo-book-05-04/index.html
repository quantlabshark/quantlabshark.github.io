买卖队列与扩散近似

把买卖队列视为生灭过程，说明先耗尽概率、扩散近似和时间缩放。

报价变化对应队列耗尽

简化订单簿只保留最优买侧数量 QbQ_bQb​ 与最优卖侧数量 QaQ_aQa​。限价单增加队列，市场单和撤单减少队列。卖侧先耗尽时价格向上移动，买侧先耗尽时向下移动；移动后按给定分布生成新的两侧深度。

这个模型把价差固定为一个报价单位，忽略更深档位和部分价差内改价，便于分析等待时间。若用于实际模拟，应检查这些简化能否再现目标资产的价差和深度分布。

生灭过程与耗尽时间

假设每次增减一单位，新增率为 λ\lambdaλ，市场消耗与撤销总率为 ν\nuν。单侧队列在正整数上作连续时间随机游走，零为吸收边界。若 ν>λ\nu>\lambdaν>λ，从 qqq 开始的平均耗尽时间为 q/(ν−λ)q/(\nu-\lambda)q/(ν−λ)。若两者相等，耗尽仍可能发生，但平均时间可以发散。

两侧独立时，第一次价格变化时间为 τ=min⁡(τb,τa)\tau=\min(\tau_b,\tau_a)τ=min(τb​,τa​)，因此

P(τ>t)=P(τb>t)P(τa>t).P(\tau>t)=P(\tau_b>t)P(\tau_a>t).P(τ>t)=P(τb​>t)P(τa​>t).

两边起点相同也仍然是生存概率的平方，不能把“两个队列都没耗尽”当成“一个队列没耗尽”。具体生灭模型可用递推或拉普拉斯变换求分布，数值模拟则直接比较两侧首达零时间。

鲨鱼说

拉普拉斯变换，即通过指数衰减加权，将函数或非负随机变量的分布转换为参数函数的方法。

设从队列量 qqq 出发的平均耗尽时间为 m(q)m(q)m(q)。下一事件的等待时间均值为 1/(λ+ν)1/(\lambda+\nu)1/(λ+ν)；之后以概率 λ/(λ+ν)\lambda/(\lambda+\nu)λ/(λ+ν) 增至 q+1q+1q+1，以概率 ν/(λ+ν)\nu/(\lambda+\nu)ν/(λ+ν) 降至 q−1q-1q−1。因此

二维扩散的上升概率可在极坐标下理解。令 θ=arctan⁡(y/x)\theta=\arctan(y/x)θ=arctan(y/x)，第一象限夹角为 π/2\pi/2π/2，调和函数 1−2θ/π1-2\theta/\pi1−2θ/π 在卖侧耗尽边界为一、买侧耗尽边界为零，于是得到 2arctan⁡(x/y)/π2\arctan(x/y)/\pi2arctan(x/y)/π。若两侧波动不同，应先按各自尺度变换。若相关或有漂移，边界问题也会改变，不能只代入原始队列比。

鲨鱼说

“最终大概率会发生”和“平均多久发生”是不同问题。少数特别长的等待可以使平均值不存在，即使很多模拟样本很快就到达边界。

扩散近似中的价格上升概率

在高事件率、近似平衡且两侧独立同方差时，把队列近似为第一象限中的二维无漂移布朗运动，遇到任一坐标轴停止。若初始买量为 xxx、卖量为 yyy，卖侧先耗尽的概率为

pup(x,y)=2πarctan⁡xy.p_{\rm up}(x,y)=\frac2\pi\arctan\frac xy.pup​(x,y)=π2​arctanyx​.

这个函数在卖量为零时等于一，在买量为零时等于零，内部满足 Laplace 方程。x=yx=yx=y 时为一半；x=2yx=2yx=2y 时约为 0.7050.7050.705。它属于扩散近似，离散小队列的精确概率应由相应随机游走计算。

流体与扩散的尺度不同

若观察时间放大 nnn 倍、队列量除以 nnn，大量事件的平均净流量形成确定性的流体极限。若先减去平均路径，再除以 n\sqrt nn​，则可能得到保留随机波动的扩散极限。多价位拍卖模型中，匹配和非负约束还会产生反射项。

在平衡的双队列模型中，价格变化等待时间尾部可能约为 c/tc/tc/t，平均等待时间无穷。此时累计 nnn 次变化的时间尺度可为 nlog⁡nn\log nnlogn，不能无条件使用普通有限均值更新过程的线性时间尺度。

1+2∑k=1∞(1/2)k=3.1+2\sum_{k=1}^{\infty}(1/2)^k=3.1+2k=1∑∞​(1/2)k=3.

因此按 n\sqrt nn​ 缩放的累计和趋向 3Bt\sqrt3B_t3​Bt​。独立假设会把方差少算三分之二。若再对该累计和建立乘积递推，弱收敛不能自动通过随机积分传递：离散二次项与极限布朗二次变差的差异可能留下额外漂移，需要检查联合极限条件。

鲨鱼说

流体模型回答平均队列怎样流入流出，扩散模型回答平均路径附近会怎样波动。选择哪一种，取决于你要预测等待时间的均值，还是风险区间。
