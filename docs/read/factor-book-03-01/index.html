财务数据怎样按真实时间进入因子计算

处理复权、停牌、财报修订、单季度与 TTM 数据，建立可复现的月度因子流程。

一家公司的 2018 年利润在 2019 年 3 月首次公布，2020 年又被更正。研究 2019 年 1 月的选股时，应该用哪个数？答案是两个数都不能用，因为当时 2018 年利润尚未公开。数据属于哪个报告期，与投资者何时能够知道它，是两条不同时间轴。

报告期说明数据描述哪段经营活动，披露日说明投资者何时首次知道，交易日决定策略何时可以使用。计算历史信号时应沿披露时间向后连接交易日期。

数据表至少保留三种时间

财务记录应区分报告期、首次披露时间和修订披露时间；行情记录应区分交易日期和可用于下单的时点。研究日只选择当时已公开的最新版本，这就是 point-in-time，也称时点一致的数据。

2020 年出版研究采用 Wind 的基本信息、行情、指数与宏观数据，财务数据来自 Tushare。平台名称不能代替字段核查：同名“利润”可能是累计值、单季度值、原始值或最新修订值，需要保存字段说明、版本与获取时间。

复权保证经济收益连贯

一只股票价格 100 元，发生一拆二后变成 50 元，原持有人同时拥有两股，财富没有因拆分减半。直接计算 50/100−150/100-150/100−1 会误报 −50% 收益。复权将分红、拆并股等权益事件纳入价格序列，使收益具有经济含义。

前复权通常保留当前价格并调整过去价格，便于显示走势，但之后的新事件会重新改变历史数值。后复权以历史基准向后调整，可用于构造长期持有收益序列。具体算法对现金分红再投资、配股等处理可能不同，计算前应确认数据含义。

若序列已经计入分红，就不要再加一次现金分红。

历史研究采用后复权价格。对存在长期停牌后复牌等异常跳跃的收益，还设置了按当时制度理解的 ±10% 压缩处理。这是该历史研究的样本处理选择，不等于所有真实收益都只能在这个区间，也不适合作为所有板块和时期的统一涨跌停规则。

停牌不等于没有风险

停牌日没有新成交。若只想知道某个历史日期最近可观察价格，可以沿用上一次成交价；若要估计日波动或市场暴露，把停牌日填成零收益就会人为降低变化程度。

自拟例子中，一周只有首尾两天交易，中间三天填零，五个“日收益”看上去很平稳。但最后一个交易日可能一次反映数日信息。这种记录结构不能与每天连续交易的股票直接等同。波动和回归计算应保留停牌标识及有效观测数。

该历史流程要求窗口至少有约三分之二有效观测。例如 21 日指标至少需要 14 个有效交易日；少于门槛则记为缺失。缺失不是零：零表示确实测得没有变化，缺失表示信息不足。

财报既有时点数，也有期间数

资产负债表描述某个日期的资产、负债和权益，是时点数据。利润表和现金流量表描述一段时间的经营流量，季度披露时往往从年初累计。所有者权益变动表解释权益变化，附注提供会计政策及细分项目。研究比率时，附注也可能决定两个公司的指标是否可比。

2018 年三季报的报告期可标记为 20180930，但不能据此认定 9 月 30 日已经知道全部内容。同比基准也不同：资产负债表常列上年年末余额，利润和现金流量表常列上年同期累计额。两列数字即使出现在同一份文件中，也不一定对应相同的比较期间。

调整、更正与历史版本

后续定期报告可能重新披露上一报告期比较数，并改变旧科目；公司也可能另行发公告更正。原始报表、最新报表、基准比较报表及其原始版本因此可能同时存在。

可以用下面的教学事件表理解选择规则：

信息公开日 2018 年利润最新可知值 当日新增信息
2019-03-20 100 首次披露
2019-08-10 90 更正公告
2020-03-25 95 后续报告调整比较数据

2019 年 6 月使用 100，2019 年 12 月使用 90，2020 年 4 月使用 95。始终用 100 会忽略后来已公开的信息；把最新 95 回填整个历史，则会提前使用未来信息。

数据供应商可能用四类记录区分初始/基准报表及原始/最新值。类型编号用于存储，历史查询则依据各版本的公开时间。若更正先于基准报告，可依次使用初始原始值、更正初始值、基准值。若更正后于基准报告，则历史中间区间要保留更正前的基准值。仅按报告期去重并保留最后一条，会丢失这些区间。

Python14 行
from datetime import date
events = [
    (date(2019, 3, 20), 100),
    (date(2019, 8, 10), 90),
    (date(2020, 3, 25), 95),
]
def value_known_on(day):
    available = [event for event in events if event[0] <= day]
    return max(available, key=lambda event: event[0])[1] if available else None
assert value_known_on(date(2019, 1, 31)) is None
assert value_known_on(date(2019, 6, 30)) == 100
assert value_known_on(date(2019, 12, 31)) == 90
print([value_known_on(date(y, m, d)) for y, m, d in
       [(2019, 1, 31), (2019, 6, 30), (2019, 12, 31), (2020, 4, 30)]])

日内还有披露与交易先后。如果公告在收盘后发布，只按日历日期相等就允许当日收盘成交，仍可能前视；实际流程需保存可用时点或至少明确次一交易日生效规则。

单季度和 TTM 怎样换算

假设同一会计口径下，一季累计利润为 20、半年累计为 55、前三季累计为 90、全年为 130。单季度利润依次为 20、35、35、40。除一季度外，均用本期累计减上期累计。若上期缺失，不能凭空计算差额。

TTM 指最近十二个月。若最新数据是三季累计，计算为

TTM利润=本年前三季+上年全年−上年前三季.\text{TTM利润}=\text{本年前三季}+\text{上年全年}-\text{上年前三季}.TTM利润=本年前三季+上年全年−上年前三季.

教学数字 90、120、80 给出 90+120−80=13090+120-80=13090+120−80=130。它把去年第四季度和今年前三季度拼在一起，降低季节性比较的影响。若缺少历史项，按季度累计乘 4、2 或 4/34/34/3 只能得到年化估计，应单独标记，不能称为真实 TTM。

资产负债表属于存量，不宜把四个季度余额相加。需要平均权益等分母时，可使用当前余额、四个季度均值或期初期末平均，但这些是不同口径。例如 TTM 营业利润除以最近四个季度平均股东权益，应明确两端是“期间利润”和“平均存量”。

鲨鱼说

计算增长率时，两期数字也要来自当时可得且口径一致的版本。只保证最新一期没有未来信息，却把上一期替换成多年后修订值，同样会改变历史上实际能够算出的增长率。

股票池与异常处理会改变研究对象

历史样本保留金融企业，剔除待退市、风险警示、最近报告期净资产为负及上市不足一年的股票；这些状态应按当时信息判断。今天已经退市的股票仍应出现在它当时符合条件的历史里，不能只拿当前存续股票回测。

极端比率先检查分子分母。例如净资产接近零时，ROE 可以非常大。它不一定是录入错误，却可能让少数公司主导回归。把数值压到 1% 和 99% 分位点叫缩尾。直接删除两端各 1% 观测叫截尾。该历史流程文字采用“缩尾”名称，但描述的是删除端点样本，复现时应明确记录采用哪一种操作。

月度因子计算的先后顺序

  1. 在月末冻结已公开数据，按当时状态形成股票池。
  2. 计算指标，保留缺失、修订版本和异常处理记录。
  3. 按预设方向排序，确定各组股票与形成日权重。
  4. 检查停牌、交易状态和可成交价格，记录无法完成的订单。
  5. 在持有期计算组合收益，再于下一次形成日更新。
  6. 同时保存各组特征、收益、多空价差、换手及成本。

“从可交易池排除”只约束新建仓，不会让账户中已经停牌或跌停的旧持仓自动消失。真实持仓回放必须继续记录这些仓位，直到能够成交。

历史实证结果对应的统一设定

后续因子表格讨论的是 2000 年 1 月至 2019 年 12 月的 A 股历史样本，覆盖当时沪深主板、中小板和创业板，不含科创板。单变量按十分位分十组。规模与目标变量独立排序时各分五组，形成 25 个组合。组内分别比较等权与总市值加权，每月末再平衡，报告未扣交易成本的研究收益。

数据覆盖度、异常处理和可交易筛选决定每月实际样本。规模因子本身按规模单变量研究；其他风格再用规模交叉分组。读到一个历史收益值时，至少同时确认方向、加权方式、排序维度和是否扣费，这些条件共同定义了结果。

练习

某公司半年累计利润为 60，一季累计为 25；上年全年为 100，上年半年为 45。计算第二季度利润与最新 TTM 利润。

查看解答

第二季度利润为 60−25=3560-25=3560−25=35；TTM 利润为 60+100−45=11560+100-45=11560+100−45=115。三项历史数据均应使用研究时点已公开、彼此口径一致的版本。半年利润乘 2 得到 120，是简单年化估计，与真实最近十二个月的 115 不同。
