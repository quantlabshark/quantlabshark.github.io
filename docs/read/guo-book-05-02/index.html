多元订单强度与相互激励

建立多类订单相互激励模型，计算长期强度，并用时间变换检验拟合。

订单类型之间会相互影响

一笔主动买单可能引出更多同向买单，也可能促使卖侧补单或撤单。把所有事件合为一个计数过程，会丢失方向和行为差异。可以分别记录主动买、主动卖、限价新增和撤单，建立多元点过程。

对类型 iii，定义

λi(t)=μi(t)+∑j∫s<thij(t−s) dNj(s).\lambda_i(t)=\mu_i(t)+\sum_j\int_{s<t}h_{ij}(t-s)\,dN_j(s).λi​(t)=μi​(t)+j∑​∫s<t​hij​(t−s)dNj​(s).

这里 hijh_{ij}hij​ 表示“类型 jjj 事件对类型 iii 强度的影响”，矩阵的行列方向必须固定。指数核 hij(u)=αije−βijuh_{ij}(u)=\alpha_{ij}e^{-\beta_{ij}u}hij​(u)=αij​e−βij​u 分别用幅度和衰减率描述冲击。

鲨鱼说

点过程，即用随机发生时刻描述离散事件的模型。

冲击峰值、衰减与累积效应

两种影响的初始幅度相同，但持续时间不同，累计作用就不同。核积分组成矩阵 Gij=αij/βijG_{ij}=\alpha_{ij}/\beta_{ij}Gij​=αij​/βij​。在线性非负 Hawkes 模型中，平稳性要求谱半径 ρ(G)<1\rho(G)<1ρ(G)<1，长期平均强度满足

λˉ=(I−G)−1μ.\bar\lambda=(I-G)^{-1}\mu.λˉ=(I−G)−1μ.

例如 G=(0.30.10.20.25)G=\begin{pmatrix}0.3&0.1\\0.2&0.25\end{pmatrix}G=(0.30.2​0.10.25​)、μ=(0.4,0.3)⊤\mu=(0.4,0.3)^\topμ=(0.4,0.3)⊤，解得平均强度约 (0.6535,0.5743)⊤(0.6535,0.5743)^\top(0.6535,0.5743)⊤。事件既产生直接后代，也通过其他类型继续传播，所以不能仅用 μi/(1−Gii)\mu_i/(1-G_{ii})μi​/(1−Gii​) 分别计算。

平稳条件为什么要检查整个矩阵

给定背景事件平均强度 μ\muμ，第一代后续事件的平均强度为 GμG\muGμ，第二代为 G2μG^2\muG2μ。全部事件平均为 μ+Gμ+G2μ+⋯\mu+G\mu+G^2\mu+\cdotsμ+Gμ+G2μ+⋯；当谱半径小于一时，矩阵级数才收敛为 (I−G)−1μ(I-G)^{-1}\mu(I−G)−1μ。

只检查每种类型自身的激发是否小于一还不够。例如 G=(0.40.70.70.4)G=\begin{pmatrix}0.4&0.7\\0.7&0.4\end{pmatrix}G=(0.40.7​0.70.4​)，两项自身激励都是 0.4，但同方向特征值为 1.1，类型之间来回激发使总体达到超临界状态。把非对角项忽略，就漏掉了这一传播环路。

指数核递推也可按一个事件核算。若类型一事件刚到达，它给类型一和二分别增加 α11,α21\alpha_{11},\alpha_{21}α11​,α21​，即矩阵第一列。到下次事件前，这些历史贡献分别按对应 βi1\beta_{i1}βi1​ 衰减。新事件的对数似然应使用跳升前强度，跳升后的强度用于预测后续事件。

线性非负 Hawkes 核描述激励。若希望表达某类事件抑制另一类，直接允许任意负系数可能产生负强度；应使用有正值约束的非线性强度或其他抑制模型，并重新检查稳定条件。

鲨鱼说

两种订单各自的自激励不强，也可能通过“甲引出乙、乙再引出甲”形成很长的事件链。谱半径衡量的是整个传播系统的累积效应。

数量与订单簿状态作为解释变量

若事件带有成交量标记 vvv，可令激发幅度乘以正函数 g(v)g(v)g(v)，并规范化其均值，避免总体尺度与 α\alphaα 无法区分。大单可能包含更多信息，也可能是同一大额需求拆成的多个子单，因此是否加入数量应通过样本外似然和残差检验判断。

背景强度可以依赖买卖深度、不平衡和时段。为保证正值，可用指数链接或其他正函数。若当前订单簿状态已经受到过去事件影响，再加入自激励项时要检查共线性和可识别性。

递推计算与模拟

指数核的每个历史累积状态在无事件时按 e−βΔte^{-\beta\Delta t}e−βΔt 衰减，某类事件到达后，只向对应的激励列加入跳升。对数似然为各类型事件的对数强度之和，减去所有类型强度积分。

模拟可使用稀疏化：给当前总强度找上界，抽取候选等待时间，按实际总强度与上界的比率接受，再按各类型强度比例抽取事件类型。若背景强度随时间上升，上界也必须覆盖这一变化。

拟合之后检查什么

对每个分量计算积分强度残差，比较单位指数分布的分位数，并检查残差自相关及不同分量之间的剩余依赖。似然提高可能只是参数更多，应结合信息准则和时间外检验。

实际行情校准应明确事件分类：一笔市场化限价单可能立即成交，也可能留下剩余订单。按订单编号和成交消息重建后再归类，避免把同一次事件同时计作两种独立冲击。历史 ITCH 等数据格式的研究例子说明事件解析的重要性，具体字段与交易规则应按使用数据的版本处理。

鲨鱼说

交叉激励表示时间上的条件关联。它可以来自拆单、共同新闻或交易反应，不能仅凭一个正系数就确定是哪一种经济机制。
