停时与Wald等式、区间首达、反射原理和序列等待时间的推导。

随机游走累加逐次随机增量，鞅则要求给定已有信息后的下一步条件均值等于当前值。涉及停止规则时，还需检查取期望与停止操作所需的条件。

醉汉过桥

题目

醉汉站在长 100 米桥的第 17 米处，每步等概率向前或向后走 1 米。求先到达第 100 米而不是第 0 米的概率，以及到达任一端点所需步数的期望。

考点：随机游走；边界方程；鞅。

查看分析与解答

必要知识

每步等概率加一或减一，因此下一步位置的条件均值等于当前位置。这样的过程是鞅。求首次到边界问题，也可以直接按当前位置建立概率和时间的递推，便于初学者理解。

分析思路

先用边界差分方程求成功概率与平均步数，再用鞅核对。这样能看清停止等式背后的状态关系。

解答步骤

记 h_i 为从第 i 米先到 100 的概率，则 h₀=0、h₁₀₀=1，且 h_i=(h_(i−1)+h_(i+1))/2。因此相邻差值相等，h_i=i/100，h₁₇=0.17。

记 e_i 为到任一端点的平均步数。e₀=e₁₀₀=0，内部满足 ei=1+(ei−1+ei+1)/2e_i=1+(e_{i-1}+e_{i+1})/2ei​=1+(ei−1​+ei+1​)/2，即二阶差分 e_(i+1)−2e_i+e_(i−1)=−2。试二次式 e_i=−i²+Ai+B，边界给 B=0、A=100，故 e₁₇=17×83=1411。

若把起点平移到零，停止位移为 83 或 −17。鞅 S_n 与 S_n²−n 给出 E[S_T]=0、E[T]=E[S_T²]=0.17×83²+0.83×17²=1411，与递推一致。有限区间的吸收时间期望有限，可通过每百步有统一正概率到达边界给出几何尾界。

同类问题

均值为零的游走求命中概率常用线性函数，求退出时间常用二次函数。使用停时等式前先确认可积性或通过截断停时证明，不能把所有无限等待问题都当作有限区间情况。

骰子累计支付

题目

每次掷六面骰都获得等于点数的美元金额。若掷出 4、5、6，可继续掷；若掷出 1、2、3，游戏结束。求累计支付的期望。

考点：Wald 等式；停时；指示变量求和。

查看分析与解答

必要知识

停时 N 的含义是：是否在第 k 次以前停止，只由此前观察决定，不需要未来信息。Wald 等式允许停止次数依赖已经看见的点数；关键是第 k 次是否会被掷出，不能预先利用第 k 次结果。

分析思路

先算平均投掷次数，再解释为什么可以把平均单次收益与平均次数相乘。本题也可用一步递推交叉检查。

解答步骤

令 X_k 为第 k 次点数，总收益可写成 Σ_(k≥1)X_k 1_{N≥k}。事件 N≥k 只依赖前 k−1 次，因此与 X_k 独立，于是每项期望为 E[X_k]P(N≥k)。求和后得到 E[X₁]ΣP(N≥k)=E[X₁]E[N]。这说明不需要 N 与整个点数序列独立。

停止次数 NNN 为参数 1/21/21/2 的几何分布，E[N]=2E[N]=2E[N]=2。单次点数 E[X1]=7/2E[X_1]=7/2E[X1​]=7/2。虽然 NNN 取决于点数，Wald 等式仍适用，因为它要求停时条件，而非 NNN 与所有点数独立。因此

E[∑k=1NXk]=2×72=7.E\left[\sum_{k=1}^NX_k\right]=2\times\frac72=7.E[k=1∑N​Xk​]=2×27​=7.

也可设总期望为 vvv，按第一次点数分类得到 v=7/2+v/2v=7/2+v/2v=7/2+v/2，同样得到 7。

具体地，P(N≥k)=(1/2)^(k−1)，求和为 2；单次点数均值 3.5，所以总期望为 7。与直接使用 v=3.5+v/2 的结果一致。

同类问题

想使用“平均次数乘平均收益”时，先确认是否是合法停时以及收益可积。若根据未来结果决定是否把某次收益算入，指示事件与该次收益便可能相关。

购票队列与反射原理

题目

售票处有 2n2n2n 人排队，nnn 人只带 5 美元钞票，另 nnn 人只带 10 美元钞票，每人购买一张 5 美元票。售票员起初没有零钱。若人员顺序等概率随机排列，求所有人均无需调整位置即可购票的概率。

考点：前缀和；反射原理；Catalan 数。

查看分析与解答

必要知识

持五美元者提供一张零钱，持十美元者需要找回一张五美元，故可分别记为上一步与下一步。任一前缀中，十美元人数不能超过五美元人数。所有身份不同的人员排列诱导等概率的正负符号序列。

分析思路

直接数合法路径较难，先数全部路径，再把非法路径一一对应到终点为 −2 的路径。双射必须说明如何反向恢复，才能确保没有重计或漏计。

解答步骤

例如 n=2，六个正负序列中只有 ++−− 和 +−+− 合法，所以概率应为 2/6=1/3。一般推导应能还原这个小例子。

将持 5 美元者记为 +1+1+1，持 10 美元者记为 −1-1−1。累计和表示售票员拥有的 5 美元零钱张数。队列可行当且仅当所有前缀和非负，最终和为零。

所有 nnn 个 +1+1+1、nnn 个 −1-1−1 的符号序列共 (2nn)\binom{2n}{n}(n2n​) 个。对首次到达 −1-1−1 的非法路径，在该点之后关于水平线 −1-1−1 反射，得到一条从 0 到 −2-2−2 的 2n2n2n 步路径。反射是双射。后者包含 n−1n-1n−1 个上步和 n+1n+1n+1 个下步，数量为 (2nn−1)\binom{2n}{n-1}(n−12n​)。

因此合法队列数为 Catalan 数

Cn=(2nn)−(2nn−1)=1n+1(2nn),C_n=\binom{2n}{n}-\binom{2n}{n-1}=\frac1{n+1}\binom{2n}{n},Cn​=(n2n​)−(n−12n​)=n+11​(n2n​),

所求概率为 1/(n+1)1/(n+1)1/(n+1)。反射原理的核心是构造坏路径与另一端点路径之间的一一对应。

反射的逆操作是：任意从零走到 −2 的路径必先到过 −1，找到首次到 −1 的位置，把此后的部分再反射一次，即恢复一条终点为零的非法路径。计数比值可直接算为 C(2n,n−1)/C(2n,n)=n/(n+1)，因此合法比例为 1−n/(n+1)=1/(n+1)。

同类问题

合法括号序列、栈操作顺序、零钱排队都可能转成不低于零且最终回零的路径。先建立前缀约束，再识别 Catalan 结构，比只背公式更容易迁移。

连续正面与一般硬币模式的等待时间

题目

公平硬币首次出现连续 nnn 个正面，期望需要投掷多少次？如何将方法推广到任意有限硬币序列？以 HHTTHH 为例讨论一般序列。

考点：模式等待；更新递推；前后缀重叠。

查看分析与解答

必要知识

目标序列出现后，其尾部可能同时是目标的开头，这种重叠会影响等待时间。连续 H 的所有较短前缀都能与后缀重合；一般串只保留部分重叠长度。

分析思路

先用递推求连续 n 个 H，熟悉重置机制；再把每个可能的重叠前缀解释为一条仍存活的公平下注路径，推导一般模式公式。

解答步骤

从已经等到 n 个 H 的时刻再掷一次：若为 H，目标 n+1 个完成；若为 T，刚积累的连续 H 全部失效，需要从头再等。两种情况共享前面等待 a_n 和当前这一抛，所以递推右侧先写 a_n+1，再加失败概率乘完整重等时间。

递推

记 ana_nan​ 为首次得到连续 nnn 个 H 的期望次数，a0=0a_0=0a0​=0。先等到 nnn 个 H，再投一次：若为 H 则结束，若为 T 则从初始状态重新等待。于是

an+1=an+1+12an+1,an+1=2an+2.a_{n+1}=a_n+1+\frac12a_{n+1},\qquad a_{n+1}=2a_n+2.an+1​=an​+1+21​an+1​,an+1​=2an​+2.

由此

an=2+22+⋯+2n=2n+1−2.a_n=2+2^2+\cdots+2^n=2^{n+1}-2.an​=2+22+⋯+2n=2n+1−2.

n=1,2,3n=1,2,3n=1,2,3 时分别为 2、6、14，与状态方程一致。

公平下注与重叠前缀

每次投掷前加入一位投入 1 美元的新玩家。玩家按目标序列的各位逐次押注，押对则资金翻倍并继续全押，押错则归零。完整押中后停止下注。当目标序列首次出现时，所有仍持有资金的玩家，恰好对应目标串中同时也是其后缀的前缀。

令目标长度为 mmm，其非空前缀与后缀相同的长度集合为 BBB，则停止时总支付为 ∑k∈B2k\sum_{k\in B}2^k∑k∈B​2k。公平下注过程给出

E[T]=∑k∈B2k.E[T]=\sum_{k\in B}2^k.E[T]=k∈B∑​2k.

有限模式的等待时间有几何尾界：分成长度为 mmm 的不重叠区间，每个区间完整命中目标的概率为 2−m2^{-m}2−m，因此上述停止与取期望可成立。

对连续 nnn 个 H，所有 1,…,n1,\ldots,n1,…,n 都是重叠长度，得到 2n+1−22^{n+1}-22n+1−2。对 HHTTHH，重叠长度仅为 1、2、6，因此

对非公平硬币，可将 2k2^k2k 替换成目标长度为 kkk 的前缀出现概率的倒数。

对 HHTTHH，可逐长度检查前后缀：长度 1 都为 H，长度 2 都为 HH，长度 3 分别为 HHT 与 THH，不同；长度 4、5 也不同，长度 6 是整个串。因此只有 1、2、6 三项，期望为 2+4+64=70。公平下注论证中的“总投入期望等于总支付期望”可以通过截断与有限期望成立；状态递推则提供不依赖下注直觉的替代计算。
