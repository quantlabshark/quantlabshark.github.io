5.3 特质性波动率与低波动异象

计算模型残差波动，解释套利不对称，并通过条件排序比较高估与低估股票的历史表现。

波动大的股票，未必承担同一种风险

甲的日收益标准差为3%，其中大部分随市场一起变化；乙的日波动只有2%，却常因公司自身消息突然涨跌。投资者已经持有广泛市场组合时，两者给组合增加的风险可能不同。区分它们需要先扣除共同因子的影响。

给定一个定价模型，股票日超额收益写成

ri,d=αi+βi⊤fd+εi,d.r_{i,d}=\alpha_i+\boldsymbol\beta_i^\top\mathbf f_d+\varepsilon_{i,d}.ri,d​=αi​+βi⊤​fd​+εi,d​.

fd\mathbf f_dfd​ 是当天因子收益，βi\boldsymbol\beta_iβi​ 是敏感程度，残差 ε\varepsilonε 是该模型没有解释的部分。特质性波动率IVOL就是残差的标准差，而非股票原始收益标准差。

图中共同部分会同时影响多只股票，特质部分是模型剩余。增加持股数量可以抵消相互独立的个股冲击，但如果模型漏掉共同因素，残差之间仍会相关，分散效果便会减弱。

用21个交易日计算一个月末信号

历史A股检验使用过去21个交易日的市场、规模、价值三因子日收益回归，在月末计算残差波动，检验随后一月的收益。若采用回归残差标准差，

IVOL^=∑d=1nε^d2n−p,\widehat{IVOL}=\sqrt{\frac{\sum_{d=1}^{n}\hat\varepsilon_d^2}{n-p}},IVOL=n−p∑d=1n​ε^d2​​​,

nnn 为有效交易日数，ppp为估计参数数，三因子加截距时为4。分母扣除参数数，是因为回归已经利用样本估计了这些系数。若改用残差序列普通标准差，则是另一自由度约定，复现时应统一。

下面用模拟数据同时生成共同收益和个股噪声，再用最小二乘取回残差：

Python11 行
import numpy as np
rng = np.random.default_rng(17)
f = rng.normal(0, 0.01, (21, 3))
X = np.column_stack([np.ones(21), f])
y = 0.0002 + f @ np.array([1.1, 0.3, -0.2]) + rng.normal(0, 0.004, 21)
b = np.linalg.lstsq(X, y, rcond=None)[0]
resid = y - X @ b
ivol = np.sqrt(resid @ resid / (len(y) - X.shape[1]))
assert np.allclose(X.T @ resid, 0, atol=1e-10)
assert ivol > 0
print(f'日特质性波动率：{ivol:.4%}')

输出单位是日波动率。只做同日截面排序时无需年化；若展示年化数，应统一交易日约定。短窗口内少数极端收益和缺失交易日会显著影响结果，因此应保留有效样本数与异常点检查。

为什么高IVOL可能对应较低未来收益

在充分分散且残差风险不被定价的理论条件下，单只股票的独立波动不需要额外补偿。然而美国等市场的许多研究观察到高IVOL股票未来平均收益较低。另一些研究报告正相关或不显著。历史窗口、波动估计方法、权重及极端样本都可能影响结论，这构成了特质性波动率之谜。

套利不对称提供一种机制。被低估的股票可以买入等待修正。被高估的股票要通过卖空获利，而借券、费用和保证金会限制这一过程。若股价在修正前继续上涨，空头可能先遭追加保证金并被迫退出。高IVOL使这种等待风险更大，因此高估更难被消除，随后修正时的平均收益也可能更低。

该机制预测：高估组中的IVOL负向关系较强；低估组中可能较弱甚至为正。机构持股低、卖空较困难的股票，以及情绪高涨时期，还可能表现出更强的负向关系。这些条件预测使理论能够接受数据检验。

鲨鱼说

“存在套利机会”不等于可以无风险等待。方向判断正确，也可能在价格继续偏离时先因资金或借券约束退出。IVOL在这里衡量等待修正期间的不稳定程度。

错误定价分组怎样构造

先用一组已研究的异象指标建立潜在错误定价评分，统一方向，使高分表示更可能高估，再平均排名。美国研究使用11项指标。A股历史复现因数据不足，去掉财务困境、股票净发行、复合股权发行三项，保留应计利润、净营业资产、资产增长、投资、O-Score、动量、毛盈利能力、资产回报率八项。

先按评分把股票分成五组，再在每个评分组内部按IVOL分五组，共25组。这是条件排序：第二步的断点由各组自身数据确定。每个评分组计算低IVOL减高IVOL收益，再比较五个评分组的差异。

“潜在高估”只是综合指标名称，不能被当作已经测得真实内在价值。若评分本身在新市场中失去预测能力，对套利不对称的检验也会受到影响。

A股证据支持到哪一步

2000—2019年，把五个评分组的低IVOL减高IVOL收益平均后，三因子月α在等权下约1.27%，t=8.64t=8.64t=8.64；市值加权约0.82%，t=3.64t=3.64t=3.64。市值加权再改用加入盈利的四因子，α降为0.36%，t=1.62t=1.62t=1.62。

最被高估组呈现明显的IVOL负向关系，但最被低估组没有完整重现美国研究中的正向关系，最高IVOL股票仍较差。部分中低IVOL档具有上升趋势，最后一档却改变了整体关系。因此数据支持高估端的机制，同时留下低估端尚未解释的部分。

其他解释提供什么检验方向

IVOL可能同时包含关于基本面的信息不确定性和纯粹残差变化；将两者分开，可以检验负向收益关系主要来自哪一部分。不同股票IVOL还可能共同升降，说明风险的波动本身存在共同驱动。

另一条思路是偏度。投资者可能愿意为小概率大幅上涨的机会支付溢价，使相关股票未来平均回报较低。剩余协偏度研究资产超额收益与市场超额收益平方的协方差，例如 Cov⁡(ri,rM2)\operatorname{Cov}(r_i,r_M^2)Cov(ri​,rM2​)，它描述的不是普通线性同涨同跌，而是资产在市场大幅波动状态中的表现。历史美国研究用期权隐含偏度代理相应风险，加入该因子后低波动异象减弱，并以多个低波动异象的第一主成分检查共同来源。

这些检验将问题从“低波动组合是否赚钱”推进到“收益与哪种风险或定价偏差共同变化”。更换基准后α减少时，应检查新增因子的经济含义与暴露，而不是只更换显著或不显著的标签。

鲨鱼说

协方差，即两个变量偏离各自均值时，共同变化程度的度量。

练习

甲的总日波动3%、IVOL为1%，乙的总日波动2%、IVOL为1.5%。哪只剩余风险更大？若所有股票的残差同时大幅下跌，为什么简单增加持股数量可能无效？

查看解答

在相同模型、窗口和自由度下，乙的IVOL更大。若残差共同下跌，它们之间存在协方差，可能反映遗漏的共同因素。组合方差既包括个股方差，也包括这些协方差，增加股票数量无法自动抵消共同冲击。

资料来源：石川、刘洋溢、连祥斌，《因子投资：方法与实践》，2020年，PDF第214—223页。
