1. 已知两个0.8相关

题目

随机变量 X、Y、Z 的方差均为正，且 Corr⁡(X,Y)=Corr⁡(X,Z)=0.8\operatorname{Corr}(X,Y)=\operatorname{Corr}(X,Z)=0.8Corr(X,Y)=Corr(X,Z)=0.8。求 Corr⁡(Y,Z)\operatorname{Corr}(Y,Z)Corr(Y,Z) 的最大值与最小值，并构造达到边界的变量。

考点：标准化；正交残差；协方差界。

查看分析与解答

必要知识

标准化后 X、Y、Z 均方差一。若 Y 与 X 相关 0.8，可把 Y 写成 0.8X 加一个与 X 不相关的残差，残差方差为 1−0.8²=0.36。因此残差标准差为 0.6。

分析思路

把 Y、Z 分成共同的 X 部分与各自残差。共同部分贡献固定 0.64，剩余相关只由两个残差的配合方式决定。

解答步骤

先把 X、Y、Z 各自标准化为均值零、方差一，以下沿用原字母。令 ε=Y−0.8X、η=Z−0.8X，则 Cov(Y,Z)=0.64+Cov(ε,η)。柯西不等式给 |Cov(ε,η)|≤√(0.36×0.36)=0.36，因此范围是 0.64±0.36。

将三变量标准化，令 c=Corr⁡(Y,Z)c=\operatorname{Corr}(Y,Z)c=Corr(Y,Z)，相关矩阵的行列式非负给出 1+2(0.8)2c−2(0.8)2−c2≥0,1+2(0.8)^2c-2(0.8)^2-c^2\ge0,1+2(0.8)2c−2(0.8)2−c2≥0, 整理为 (c−0.64)2≤0.362(c-0.64)^2\le0.36^2(c−0.64)2≤0.362，故 0.28≤c≤10.28\le c\le10.28≤c≤1。

可直接构造边界。取独立标准变量 X、U，设 Y=0.8X+0.6UY=0.8X+0.6UY=0.8X+0.6U。若 Z=0.8X+0.6U=YZ=0.8X+0.6U=YZ=0.8X+0.6U=Y，则 c=1；若 Z=0.8X−0.6UZ=0.8X-0.6UZ=0.8X−0.6U，则 c=0.82−0.62=0.28c=0.8^2-0.6^2=0.28c=0.82−0.62=0.28。两种情况下，Y、Z 方差都为 1，与 X 的相关均为 0.8。

因此共同的 0.8 相关限制了两者的最小相关，它们不能同时与 X 高度同向、彼此却任意反向。

下界构造里，Y 与 Z 的残差分别为 0.6U、−0.6U，它们已完全反向，但共同的 0.8X 仍留下更大的同向贡献，所以总相关仍为正。上下界的 Y、Z 方差都为 0.64+0.36=1，无需再额外归一化。

同类问题

多个变量同一个参照高度相关时，它们之间并非任意相关。先分解共同信号与残差，可把相关范围转成残差协方差的上下界。

2. 秩一扰动特征值

题目

给定列向量 α∈Rn\alpha\in\mathbb R^nα∈Rn，求矩阵 A=I+αα⊤A=I+\alpha\alpha^\topA=I+αα⊤ 的全部特征值及重数。分别讨论 α≠0\alpha\ne0α=0 和 α=0\alpha=0α=0。

考点：外积；方向分解；特征空间。

查看分析与解答

必要知识

ααᵀ 是向量外积，作用在 v 上得到 α(αᵀv)：先用内积测量 v 沿 α 的分量，再把结果放回 α 方向。I 对任何向量保持不变，因此 A 只额外改变沿 α 的部分。

分析思路

把空间分为平行 α 的一维方向与垂直 α 的子空间，分别计算作用结果，无需展开 n 阶特征多项式。

解答步骤

例如 α=(1,2)ᵀ，则 A=[[2,2],[2,5]]。乘 α 得 (6,12)ᵀ=6α，乘垂直向量 (−2,1)ᵀ 得 (−2,1)ᵀ，因此两个特征值为六和一，与 1+||α||²=6 相符。

若 α≠0\alpha\ne0α=0，先观察沿 α\alphaα 的方向： Aα=α+α(α⊤α)=(1+∥α∥2)α.A\alpha=\alpha+\alpha(\alpha^\top\alpha)=(1+\|\alpha\|^2)\alpha.Aα=α+α(α⊤α)=(1+∥α∥2)α. 所以 1+∥α∥21+\|\alpha\|^21+∥α∥2 是一个特征值。

再取任意满足 α⊤v=0\alpha^\top v=0α⊤v=0 的非零向量，有 Av=v+α⋅0=vAv=v+\alpha\cdot0=vAv=v+α⋅0=v，因此特征值为 1。这些向量构成 n−1 维子空间，故 1 的重数为 n−1。上述两个正交子空间已覆盖全部 n 维空间。

若 α=0\alpha=0α=0，A 就是单位矩阵，全部 n 个特征值都为 1。可用迹核对：特征值和为 n+∥α∥2n+\|\alpha\|^2n+∥α∥2，等于 tr⁡(I+αα⊤)\operatorname{tr}(I+\alpha\alpha^\top)tr(I+αα⊤)；所有特征值为正，所以 A 正定。

任意 v 可唯一拆成 cα+u，其中 αᵀu=0。A 对第一部分乘 1+||α||²，对第二部分乘一，因此这两类方向已穷尽全部作用。n=1 时垂直子空间维数零，只有前一个特征值；α=0 时则要单独处理，不能再谈沿零向量的方向。

同类问题

遇到 I 加低秩矩阵，先找低秩项的像空间与零空间。对 rank-one 更新，方向分解通常比求行列式更直接，也有助于理解协方差的单因子结构。

3. 严格对角占优

题目

实矩阵 A 满足每行 aii>∑j≠i∣aij∣a_{ii}>\sum_{j\ne i}|a_{ij}|aii​>∑j=i​∣aij​∣。仅凭此条件能否推出 x⊤Ax≥0x^\top Ax\ge0x⊤Ax≥0？若再要求 A 对称，请证明其正定。

考点：二次型；对称部分；占优与正定。

查看分析与解答

必要知识

二次型 xᵀAx 实际只取决于对称部分 S=(A+Aᵀ)/2，因为反对称部分 K 满足 xᵀKx=0。非对称 A 的行约束不一定转化为 S 的行约束，因此不能跳过对称性。

分析思路

先在对称条件下把交叉项合并，使用基本平方不等式给出下界；再对缺少对称性的情况构造反例，辨明结论的适用范围。

解答步骤

由 (|x_i|−|x_j|)²≥0，得到 2|x_ix_j|≤x_i²+x_j²。每个交叉项最坏可贡献 −|a_ij|(x_i²+x_j²)。把含 x_i² 的项收集起来，恰好出现题设的对角占优差。

对称时可以直接从二次型证明。由 2∣xixj∣≤xi2+xj22|x_ix_j|\le x_i^2+x_j^22∣xi​xj​∣≤xi2​+xj2​， x⊤Ax=∑iaiixi2+2∑i<jaijxixjx^\top Ax=\sum_i a_{ii}x_i^2+2\sum_{i<j}a_{ij}x_ix_jx⊤Ax=i∑​aii​xi2​+2i<j∑​aij​xi​xj​ ≥∑i(aii−∑j≠i∣aij∣)xi2>0(x≠0).\ge\sum_i\left(a_{ii}-\sum_{j\ne i}|a_{ij}|\right)x_i^2>0\qquad(x\ne0).≥i∑​​aii​−j=i∑​∣aij​∣​xi2​>0(x=0). 因此实对称且满足题设条件的矩阵是正定，结论强于半正定。也可由 Gershgorin 圆盘和对称矩阵的实特征值证明所有特征值为正。

没有对称性时，取 A=(10.9100101),x=(10,−1)⊤.A=\begin{pmatrix}1&0.9\\100&101\end{pmatrix},\qquad x=(10,-1)^\top.A=(1100​0.9101​),x=(10,−1)⊤. 两行分别满足 1>0.91>0.91>0.9、101>100101>100101>100，但 x⊤Ax=100−1009+101=−808<0x^\top Ax=100-1009+101=-808<0x⊤Ax=100−1009+101=−808<0。行占优可限制特征值实部，却不能代替对称二次型的正定条件。

同类问题

矩阵题先识别结论谈的是特征值、可逆性还是二次型。这些性质在对称矩阵中紧密相连，去掉对称性后不能沿用同一推理。

4. 高斯积分

题目

计算高斯积分 I=∫0∞e−t2 dtI=\int_0^\infty e^{-t^2}\,dtI=∫0∞​e−t2dt，要求给出化为二重积分与极坐标的步骤。

考点：积分乘积；极坐标；面积元。

查看分析与解答

必要知识

e^(−t²) 没有常用初等函数形式的原函数，但定积分可通过几何对称性求出。两个相同一维积分相乘，会把指数合成 x²+y²，而它在极坐标中只依赖半径。

分析思路

先确认积分有限，再平方并转入第一象限。利用径向对称将二维积分分成角度长度与半径积分，最后取正根。

解答步骤

收敛性可直接比较：0≤t≤1 时被积函数不超过一；t≥1 时 t²≥t，所以 e^(−t²)≤e^(−t)，尾部可积。极坐标中半径 r 至 r+dr、角度 θ 至 θ+dθ 的小块面积约为 dr×r dθ，解释了面积元里的 r。

被积函数为正，积分收敛。将 I 平方后写成第一象限的二重积分： I2=(∫0∞e−x2 dx)(∫0∞e−y2 dy)=∫0∞∫0∞e−(x2+y2) dx dy.I^2=\left(\int_0^\infty e^{-x^2}\,dx\right)\left(\int_0^\infty e^{-y^2}\,dy\right)=\int_0^\infty\int_0^\infty e^{-(x^2+y^2)}\,dx\,dy.I2=(∫0∞​e−x2dx)(∫0∞​e−y2dy)=∫0∞​∫0∞​e−(x2+y2)dxdy. 令 x=rcos⁡θ,y=rsin⁡θx=r\cos\theta,y=r\sin\thetax=rcosθ,y=rsinθ，第一象限对应 r≥0r\ge0r≥0、0≤θ≤π/20\le\theta\le\pi/20≤θ≤π/2，面积元为 r dr dθr\,dr\,d\thetardrdθ。所以 I2=∫0π/2∫0∞e−r2r dr dθ=π2⋅12=π4.I^2=\int_0^{\pi/2}\int_0^\infty e^{-r^2}r\,dr\,d\theta=\frac\pi2\cdot\frac12=\frac\pi4.I2=∫0π/2​∫0∞​e−r2rdrdθ=2π​⋅21​=4π​. 内层积分用 u=r2u=r^2u=r2、du=2r drdu=2r\,drdu=2rdr 即得 1/2。由于 I 为正，最终 I=π/2I=\sqrt\pi/2I=π​/2。若漏掉 Jacobian 中的 r，就无法得到正确结果。

本题只积分正半轴，平方后覆盖第一象限，角度是 π/2；若先定义整条实轴积分，角度才是 2π。两种写法都可行，但区域与角度必须一致。推广得 ∫₋∞^∞e^(−at²)dt=√(π/a)，其中 a>0，由变量代换 u=√a t 得到。

同类问题

指数中出现平方和时可尝试升维与极坐标。每次换元同时检查积分区域、Jacobian 和最终符号，能防止倍数错误。

5. 概率1/7

题目

只使用各次独立的公平六面骰，设计一个几乎必然结束的程序，使成功事件概率恰为 1/7，并求平均需要掷骰几次。

考点：均匀映射；拒绝采样；几何期望。

查看分析与解答

必要知识

两个独立公平六面骰提供 6×6=36 个等可能结果。要把结果均分为七类，接受的结果数需是七的倍数，否则直接取余会使某些类别多一次。拒绝采样把多余结果丢弃后重新开始。

分析思路

用六进制编码建立零到三十五的均匀整数，留下三十五个结果，再选其中五个作为成功。停止概率和成功概率要分别计算。

解答步骤

题目

考点：链表指针；不变量；原地更新。

查看分析与解答

必要知识

单链表节点只知道下一节点的位置。修改 current.next 会直接改变通向后续链条的唯一入口，因此必须在修改之前保存原后继。原地是指复用原节点，不另建一份反向链表。

分析思路

把链表分为已反转前缀和未处理后缀。每轮从后缀取一个节点，接到前缀头部，维持两部分仍覆盖所有原节点的不变量。

解答步骤

第一轮开始 previous 为空、current 为一；保存 following 为二后，将一的 next 改为空，再把 previous 指向一、current 指向二。保存的是节点引用而非节点值，因此二之后的三仍可以访问。

维护 previous 和 current：前者是已反转前缀的头，后者是尚未处理部分的头。每一步先保存后继，再把当前节点指向已反转前缀，最后向前推进。

维护一个尚未输出的当前区间，把所有与它连接的新区间吸收；遇到严格空隙时才输出。右端点必须取最大值，避免被包含的小区间缩短范围。

例如当前 [1,10]、新来 [2,3]，只需保留 [1,10]，不能把右端更新为三。若新来 [10,12]，闭端点相接，应合为 [1,12]；若新来 [13,14]，则中间有实数空隙，开始新段。

先按左端点排序。维护当前合并区间 [L,R]，读到新区间 [a,b] 时：若 a≤R，两者重叠或相接，更新 R=max⁡(R,b)R=\max(R,b)R=max(R,b)；若 a>R，后续区间左端也不小于 a，不可能再与当前区间连接，可以输出当前区间并开始新区间。

例中先取 [1,3]，看到 [2,6] 时 2≤3，合成 [1,6]；再看到 [8,10]，8>6，于是分别输出 [1,6]、[8,10]。循环结束后别忘记输出最后一个区间；空输入返回空列表。

排序花费 O(nlog⁡n)O(n\log n)O(nlogn)，扫描 O(n)O(n)O(n)，输出最坏包含 n 个区间。闭区间 [1,2] 和 [2,3] 可以合并，但 [1,2] 和 [3,4] 之间存在实数空隙，不能按整数相邻规则合并。

扫描不变量为：已输出区间不再能与任何后续区间连接，当前区间恰好覆盖自上次输出后遇到的连续连通部分。由于后续左端非降，当 a>R 时旧区间可以安全定稿。最后一段没有后继触发输出，所以必须在循环结束后补上。

同类问题

区间问题先确定端点开闭及底层是整数还是实数，再决定合并条件。排序把全局相互关系变成局部相邻检查，是许多扫描算法的核心。

12. 数字根

题目

对非负整数 n，反复把十进制各位相加，直到只剩一位，求最后结果。给出常数次算术公式，并说明 n=0 和超长数字字符串的处理。

考点：十进制展开；模不变量；输入规模。

查看分析与解答

必要知识

把 n 写成 Σd_i10ⁱ，由 10≡1 mod9 得 n≡Σd_i mod9。重复求位和保留这个余数，同时逐步减小大于九的整数，最后落在个位数字。

分析思路

先证明每步保留模九，再区分零与正数的最终取值集合。正数最终只能在一至九中选唯一同余值，因此余数零要映成九。

解答步骤

18→9 与 0→0 的余数都是零，但正数各位和始终正，不可能变成零。这就是公式需要单独处理 n=0 的原因。1+(n−1) mod9 把正整数的余数循环平移到一至九。

因 10≡1(mod9)10\equiv1\pmod910≡1(mod9)，写成十进制展开后有 n≡n\equivn≡ 各位和（模 9）。每次求位和都保留余数，最终正整数落在 1 至 9。

因此 n>0 时数字根为 1+(n−1) mod 9,1+(n-1)\bmod9,1+(n−1)mod9, n=0 时结果单独为 0。例如 9875→29→11→2，公式为 1+9874 mod 9=21+9874\bmod9=21+9874mod9=2。若 n 是正的 9 的倍数，余数为 0，但最后应为 9，而不是 0。

若输入是长度 L 的数字字符串，无需转成大整数，可逐字符累加并取模 9，同时记录是否出现非零字符。全零返回 0，否则余数零返回 9，其余返回该余数。时间 O(L)O(L)O(L)、额外空间 O(1)O(1)O(1)。

字符串如 "00018" 可逐位维护 remainder=(remainder+digit) mod9，另设 nonzero 记录是否至少一位非零；结果 remainder=0 且 nonzero=True，因此返回九。读取 L 位本身需 O(L)，所以常数次算术公式只在机器整数模型下是 O(1)，不能说超长输入也与长度无关。

同类问题

数字运算题可寻找进位制下的模不变量。推导公式后检查零、整除模数的正数、前导零和超长输入，明确算术操作次数与读取成本的区别。
