28 · 线性回归、Ridge与Lasso

手算两种正则化的系数，解释惩罚、尺度和相关特征，并区分财务估值残差与未来收益预测。

线性回归用特征的加权和预测目标。Ridge 和 Lasso 在拟合误差之外加入系数约束，分别通过收缩或筛选减轻估计对样本变化的敏感性。

特征相关性与系数敏感性

假设两列特征几乎相同，模型给出10x1−9x210x_1-9x_210x1​−9x2​。因为x1≈x2x_1\approx x_2x1​≈x2​，预测看起来接近x1x_1x1​；但只要两列稍有偏差，两个大系数的抵消就会改变。训练误差很低，并不保证系数或未来预测稳定。

线性模型写作y^=a+x′β\hat y=a+\mathbf x'\boldsymbol\betay^​=a+x′β。最小二乘最小化残差平方和，正则化再对系数大小施加惩罚，使模型在拟合误差与稳定性之间取舍。截距通常单独处理，特征先统一尺度。

一维岭回归的手算过程

取x=(−1,0,1)x=(-1,0,1)x=(−1,0,1)、y=(−2,0,2)y=(-2,0,2)y=(−2,0,2)，两者均已中心化，截距为0。最小二乘斜率为∑xy/∑x2=4/2=2\sum xy/\sum x^2=4/2=2∑xy/∑x2=4/2=2。

岭回归目标是

L(b)=∑i(yi−bxi)2+λb2.L(b)=\sum_i(y_i-bx_i)^2+\lambda b^2.L(b)=i∑​(yi​−bxi​)2+λb2.

求导并令其为零，得到−2∑xiyi+2b∑xi2+2λb=0-2\sum x_iy_i+2b\sum x_i^2+2\lambda b=0−2∑xi​yi​+2b∑xi2​+2λb=0，所以

bRidge=42+λ.b_{Ridge}=\frac4{2+\lambda}.bRidge​=2+λ4​.

λ=2\lambda=2λ=2时斜率为1，λ=6\lambda=6λ=6时为0.5。系数变小意味着对输入变化的响应减弱，但训练误差会增加。强度过大时，真实信号也被过度压缩。

Lasso的零系数从哪里来

将惩罚改为绝对值，目标写成12∑i(yi−bxi)2+λ∣b∣\frac12\sum_i(y_i-bx_i)^2+\lambda|b|21​∑i​(yi​−bxi​)2+λ∣b∣。绝对值在0处有折点，最优解为软阈值：

bLasso=sign⁡(c)max⁡(∣c∣−λ,0)∑ixi2,c=∑ixiyi.b_{Lasso}=\frac{\operatorname{sign}(c)\max(|c|-\lambda,0)}{\sum_ix_i^2},\qquad c=\sum_ix_iy_i.bLasso​=∑i​xi2​sign(c)max(∣c∣−λ,0)​,c=i∑​xi​yi​.

本例c=4c=4c=4，所以λ=1\lambda=1λ=1时斜率1.5，λ≥4\lambda\ge4λ≥4时为0。岭回归逐渐缩小，Lasso可以在有限惩罚下把变量直接删去。

图中两条曲线使用各自刚才写出的目标函数约定。横轴数值相同不表示两种惩罚具有相同统计强度；Lasso曲线在4处到达零，岭回归继续平滑接近零。

代码参数如何对应公式

Python10 行
import numpy as np
from sklearn.linear_model import LinearRegression, Ridge, Lasso

X = np.array([[-1.0], [0.0], [1.0]])
y = np.array([-2.0, 0.0, 2.0])
ols = LinearRegression(fit_intercept=False).fit(X, y)
ridge = Ridge(alpha=2.0, fit_intercept=False).fit(X, y)
lasso = Lasso(alpha=1/3, fit_intercept=False, tol=1e-12).fit(X, y)
print(ols.coef_, ridge.coef_, lasso.coef_)
assert np.allclose([ols.coef_[0], ridge.coef_[0], lasso.coef_[0]], [2., 1., 1.5])

输出依次为2、1、1.5。这里Ridge的alpha=2对应平方误差和加2b22b^22b2；Lasso实现的目标为平方误差除以2n2n2n，因此手算的λ=1\lambda=1λ=1需要设置alpha=1/3。参数名相同，归一化方式却可能不同。

鲨鱼说

正则化约束的是系数，不会自动识别异常观测。平方误差仍可能被极端残差主导；若需要稳健性，应另外检查数据或使用适当损失函数。

特征单位为什么影响惩罚

同一变量用元和万元表示，系数相差一万倍，但预测可以相同。若直接对系数平方施罚，两种单位会受到不同约束。因此一般先在训练段标准化，再拟合模型，后续数据使用同一均值与标准差。

若标准化系数为3、原特征标准差为2，原变量增加1单位对应预测增加1.5。恢复原始截距时还要减去各均值对应的项，不能只改斜率。

两列完全相同时，最小二乘只确定系数之和。正的岭惩罚在这种情况下倾向对称分配，给出唯一稳定解。Lasso可能在相关变量间选择不同代表。某列系数为零，是给定样本、其他变量和惩罚下的结果，不证明它在所有场景中无用。

用财务信息拟合市值，与预测未来收益不同

可用净资产、利润、负债和研发等财务指标解释同一时点公司市值。预测市值高于实际市值，说明它相对该截面模型偏低，不等于已经观测到真实内在价值。模型可能遗漏行业、增长或风险差异。

例如模型估值120亿元、实际100亿元，差额20亿元，相对实际价格偏离20%。要把这个残差用于选股，应在随后时期检验收益，而不是把拟合时的偏离直接称为盈利。若拟合与筛选使用同一批股票，还需考虑训练内残差的选择问题，可用交叉拟合或历史模型产生信号。

缺失财务数据不能不加区分地全部填零。零研发与未报告研发不同，负债率倒数在接近零时也可能极端；这些数据问题应在回归之前处理。

验证强度与预测范围

惩罚强度通过过去训练、随后验证的方式选择，每个候选都在训练段重新拟合标准化。最终测试不参与选择。训练误差往往偏好更弱惩罚，而验证误差可能先下降再上升，反映偏差与方差的权衡。

线性预测还可能外推到训练范围之外。若训练中利润增长最高30%，新公司为300%，即使代码返回一个数，也需要检查是否由极端基数驱动，而不是假定线性关系保持不变。
