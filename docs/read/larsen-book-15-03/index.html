三因素设计与二水平效应编码

用正负编码计算二水平主效应和交互，区分效应与系数，并扩展到三因素。

三因素设计同时包含 A、B、C 主效应，AB、AC、BC 二阶交互和 ABC 三阶交互。三阶交互表示 A 与 B 的交互程度还会随 C 改变。

从水平数得到自由度

平衡设计中，主效应自由度分别为 a−1、b−1、c−1，交互自由度为相应项的乘积。例如 ABC 为 (a−1)(b−1)(c−1)，每格 n 次重复的误差自由度为 abc(n−1)。这些项加上共同均值，覆盖所有组合均值的变化方向。

二水平的正负编码

将每个因素低水平记 −1，高水平记 +1。k 个因素共有 2k2^k2k 个组合，模型可写为

y=β0+βAxA+βBxB+βABxAxB+⋯ .y=\beta_0+\beta_Ax_A+\beta_Bx_B+\beta_{AB}x_Ax_B+\cdots.y=β0​+βA​xA​+βB​xB​+βAB​xA​xB​+⋯.

交互列由对应因素列相乘得到。完整平衡设计中，不同列的乘积和为零，每列平方和等于运行次数，因此最小二乘系数可直接用带符号求和计算。

接续四格算例

按 (−,−)、(+,−)、(−,+)、(+,+) 排列，均值为 2、6、4、12。A 列为 (−1,+1,−1,+1)，带符号和为 −2+6−4+12=12。高低各两格，A 效应为 12/2=6。

B 效应为 (−2−6+4+12)/2=4，AB 列为 (+1,−1,−1,+1)，效应为 (2−6−4+12)/2=2。回归系数分别为 3、2、1，截距为 6。AB 效应 2 是差中之差 4 的一半，来自这里的高低组平均定义。

对比与平方和

每组合 n 次重复，共 N=n2kN=n2^kN=n2k 个观测。某列带符号总和为 C，由正交性，系数为 C/N，效应为 2C/N，平方和为

SS=C2N=C2n2k.SS=\frac{C^2}{N}=\frac{C^2}{n2^k}.SS=NC2​=n2kC2​.

三因素时同样计算 A、B、C、AB、AC、BC、ABC 七列。完整设计可分开估计各列；若每格无重复，全部效应拟合后没有独立误差自由度，需要额外重复或关于高阶交互的模型假设。
