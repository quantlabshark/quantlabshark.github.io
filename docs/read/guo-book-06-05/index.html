检查数量、单位与边界

实际订单簿是离散且有限的。连续形状近似需要给出拟合范围，大单超出观测范围时不能无限外推。最后一笔必须由 Q−∑i<NqiQ-\sum_{i<N}q_iQ−∑i<N​qi​ 计算，并检查非负，避免递推公式中的索引或符号错误。
