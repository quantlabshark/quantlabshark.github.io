停止鞅：条件、退出概率与平均等待

理解有界停止和一致可积的作用，用停止布朗运动计算双边退出问题。

选一个停止规则会改变平均值吗

若 MtM_tMt​ 是右连续鞅，τ\tauτ 是有界停止时间，则停止定理给出 E[Mτ]=E[M0]\mathbb E[M_\tau]=\mathbb E[M_0]E[Mτ​]=E[M0​]。更一般地，适当有界的 σ≤τ\sigma\le\tauσ≤τ 满足 E[Mτ∣Fσ]=Mσ\mathbb E[M_\tau\mid\mathcal F_\sigma]=M_\sigmaE[Mτ​∣Fσ​]=Mσ​。

离散时间下，可以把停止值写成初值加上若干项 1{τ≥k}ΔMk\mathbf1_{\{\tau\ge k\}}\Delta M_k1{τ≥k}​ΔMk​。是否进行第 kkk 步由此前信息决定，而该步条件均值为零，因此每一项平均为零。有界性保证只需处理有限项；连续时间再用网格近似和可积性控制极限。

有界离散停止的逐项证明

若整数停止时间 τ≤n\tau\le nτ≤n，则

Mτ=M0+∑k=1n1{τ≥k}(Mk−Mk−1).M_\tau=M_0+\sum_{k=1}^n\mathbf1_{\{\tau\ge k\}}(M_k-M_{k-1}).Mτ​=M0​+k=1∑n​1{τ≥k}​(Mk​−Mk−1​).

事件 {τ≥k}\{\tau\ge k\}{τ≥k} 等价于“截至第 k−1k-1k−1 步还没有停止”，所以属于 Fk−1\mathcal F_{k-1}Fk−1​。逐项取条件期望，

E[1{τ≥k}ΔMk]=E[1{τ≥k}E[ΔMk∣Fk−1]]=0.\mathbb E[\mathbf1_{\{\tau\ge k\}}\Delta M_k] =\mathbb E[\mathbf1_{\{\tau\ge k\}}\mathbb E[\Delta M_k\mid\mathcal F_{k-1}]]=0.E[1{τ≥k}​ΔMk​]=E[1{τ≥k}​E[ΔMk​∣Fk−1​]]=0.

有限求和得到均值不变。关键不是停止时间与过程独立，而是是否继续下一步由该步发生前的信息决定。对固定 ttt 的停止过程 Mt∧τM_{t\wedge\tau}Mt∧τ​，同样的条件论证使它保留鞅结构。

鲨鱼说

条件期望，即给定已有信息后，对可能结果按条件概率求平均。

无界停止需要额外的尾部控制

对无界 τ\tauτ，通常先用 τ∧n\tau\wedge nτ∧n，得到 E[Mτ∧n]=E[M0]\mathbb E[M_{\tau\wedge n}]=\mathbb E[M_0]E[Mτ∧n​]=E[M0​]，再考虑 n→∞n\to\inftyn→∞。即使停止值逐条路径收敛，也不能自动把极限放进期望。

常见充分条件是停止变量族 {Mτ∧n}\{M_{\tau\wedge n}\}{Mτ∧n​} 一致可积；若它们被同一个可积变量控制，也足够。某些离散过程还可以用有限平均停止时间和有界增量等条件。使用停止定理时，应说明实际采用哪一个条件。

一致可积的含义是：对变量族 {Yn}\{Y_n\}{Yn​}，有

lim⁡K→∞sup⁡nE[∣Yn∣1{∣Yn∣>K}]=0.\lim_{K\to\infty}\sup_n\mathbb E[|Y_n|\mathbf1_{\{|Y_n|>K\}}]=0.K→∞lim​nsup​E[∣Yn​∣1{∣Yn​∣>K}​]=0.

几乎必然收敛加一致可积允许把极限与一阶期望交换。停止定理从 τ∧n\tau\wedge nτ∧n 走向 τ\tauτ 时，需要的正是这个步骤。
