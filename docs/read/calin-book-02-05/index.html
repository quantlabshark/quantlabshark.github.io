正态分布的参数与标准化

若 X∼N(μ,σ2)X\sim N(\mu,\sigma^2)X∼N(μ,σ2)，其密度为

p(x)=1σ2πexp⁡[−(x−μ)22σ2],σ>0.p(x)=\frac1{\sigma\sqrt{2\pi}}\exp\left[-\frac{(x-\mu)^2}{2\sigma^2}\right],\qquad\sigma>0.p(x)=σ2π​1​exp[−2σ2(x−μ)2​],σ>0.

μ\muμ 决定中心，σ\sigmaσ 决定宽度。标准化 Z=(X−μ)/σZ=(X-\mu)/\sigmaZ=(X−μ)/σ 后，Z∼N(0,1)Z\sim N(0,1)Z∼N(0,1)。线性变换 aX+baX+baX+b 的均值为 aμ+ba\mu+baμ+b，方差为 a2σ2a^2\sigma^2a2σ2，标准差为 ∣a∣σ|a|\sigma∣a∣σ。

矩母函数将各阶矩集中在一个函数中，对参数求导即可取得相应期望。正态分布的矩母函数为 E[etX]=eμt+σ2t2/2\mathbb E[e^{tX}]=e^{\mu t+\sigma^2t^2/2}E[etX]=eμt+σ2t2/2。对 ttt 求导并令 t=0t=0t=0 可以得到各阶矩。标准正态的奇数阶矩为零，二阶矩为 1，四阶矩为 3。这些结果将用于计算布朗增量的平方和。

独立正态变量之和仍为正态，均值与方差分别相加。例如两个独立误差的标准差为 3 和 4，其和的标准差为 32+42=5\sqrt{3^2+4^2}=532+42​=5，不是 7。

正态变量的指数为什么偏斜

若 Y=eXY=e^XY=eX，其中 X∼N(μ,σ2)X\sim N(\mu,\sigma^2)X∼N(μ,σ2)，称 YYY 服从对数正态分布。因为指数始终为正，YYY 适合描述正值的乘性变化。由变量变换，
