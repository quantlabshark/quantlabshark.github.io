资产价格、消费风险与市场有效性

用两种经济状态解释随机折现因子，再连接有效市场、消费模型、行为金融与截面定价。

一元钱在不同状态下的价值

考虑两项资产。资产甲在经济景气时支付 120 元，困难时支付 80 元；资产乙相反，在景气时支付 80 元，困难时支付 120 元。假设两种状态的概率各为一半，两项资产的平均支付都是 100 元。

如果困难时更缺钱，资产乙提供的支付就具有保险作用。购买者可能愿意为它支付更高的价格。这说明，定价除了计算平均能收到多少钱，还要考虑这笔钱在哪种状态下收到。

用 msm_sms​ 表示状态 sss 下，将未来一元支付换算为今天价值的折现权重。它称为随机折现因子。若真实状态概率为 πs\pi_sπs​，资产在该状态支付 XsX_sXs​，则今天的价格为

P=∑sπsmsXs=E[mX].P=\sum_s\pi_s m_sX_s=E[mX].P=s∑​πs​ms​Xs​=E[mX].

∑\sum∑ 表示跨状态求和，EEE 表示按真实概率求期望。单期、有限状态且无交易摩擦的市场中，无套利与正的定价权重相联系；市场不完全时，符合观察价格的折现因子可能不唯一。

取景气状态 m=0.9m=0.9m=0.9，困难状态 m=1.1m=1.1m=1.1。资产甲的价格为 0.5×0.9×120+0.5×1.1×80=980.5\times0.9\times120+0.5\times1.1\times80=980.5×0.9×120+0.5×1.1×80=98 元；资产乙的价格为 102 元。两者平均支付相同，乙在困难状态支付更多，所以价格更高。

鲨鱼说

随机折现因子不是“某种状态发生的概率”。概率回答这种状态多常见，折现因子回答这种状态中的支付值多少钱。困难状态的概率可以很低，但在该状态获得支付的价值仍可能很高。

短期不可预测性与市场有效性

若两个时点相隔很短，忽略利息和期间分红，并近似取 m=1m=1m=1，则定价式变为 Pt≈Et[Pt+1]P_t\approx E_t[P_{t+1}]Pt​≈Et​[Pt+1​]。下标 ttt 表示只使用时点 ttt 已知的信息。它意味着已知信息不能系统性地预测下一步价格涨跌；波动大小仍可能随时间改变。

短期预测可以用收益的序列相关、涨跌游程，以及事先规定的交易规则检验。有效市场假说进一步按信息范围区分：弱式有效性关注历史价格等交易信息，半强式关注全部公开信息，强式关注包括私人信息在内的全部信息。

判定某项收益是否“异常”，必须先规定正常收益。若某策略收益高于模型预期，可能是价格没有及时反映信息，也可能是模型漏掉了应有的风险补偿。因此，市场有效性检验与正常收益模型构成联合假说。

事件研究：把不同公告放到同一时间轴

假设公司甲在周一公告，公司乙在周四公告。直接按日历日期平均，容易把事件反应错开。事件研究把每家公司自己的公告日定义为 t=0t=0t=0，公告前一天为 t=−1t=-1t=−1，后一天为 t=1t=1t=1，再跨公司比较同一事件时刻。

设某股票公告日实际收益为 2%，正常收益模型给出 0.8%，则异常收益为 1.2 个百分点。对同一事件时刻的异常收益跨公司平均，可以降低个别公司特殊波动的影响。再对事件窗口中的平均异常收益求和，得到累计异常收益。

Fama 等人在 1969 年的拆股事件研究中，把市场收益影响、事件时刻对齐和跨公司平均结合起来。其样本中事件后没有持续显著的异常回报，支持信息较快反映在价格中的解释。该结论的对象是所用拆股样本及正常收益模型。

价格为什么比股息更剧烈地波动

股票最终提供的是未来股息等现金流。若 VtV_tVt​ 表示未来股息实现后计算的折现总值，模型认为今天的价格等于对该数值的条件期望，即 Pt=Et[Vt]P_t=E_t[V_t]Pt​=Et​[Vt​]。定义预测误差 et=Vt−Pte_t=V_t-P_tet​=Vt​−Pt​，便有 Vt=Pt+etV_t=P_t+e_tVt​=Pt​+et​。

Var⁡(Vt)=Var⁡(Pt)+Var⁡(et)≥Var⁡(Pt).\operatorname{Var}(V_t)=\operatorname{Var}(P_t)+\operatorname{Var}(e_t)\ge\operatorname{Var}(P_t).Var(Vt​)=Var(Pt​)+Var(et​)≥Var(Pt​).

这个不等式给出了价格波动的上界：预测值不能比它要预测的变量更不稳定。推导用到“不相关”，并不要求两个变量相互独立。

Shiller 对股票和债券的研究发现，按固定折现率等设定计算的基本面现金流波动，难以解释观察到的价格波动。这促使研究者考察随时间变化的要求回报。Campbell 与 Shiller 关于长期盈利和估值的研究，以及 Fama 与 French 关于股息率的研究，都把估值水平与较长持有期的后续收益联系起来。

价格波动大本身不是预测公式。要建立长期预测关系，还须直接检验估值变量与未来收益之间的关系，并处理趋势、终端现金流和重叠持有期等问题。短期涨跌难以预测与长期预期收益随估值变化，可以同时成立。

鲨鱼说

条件期望，即给定已有信息后，对可能结果按条件概率求平均。

GMM：把理论等式转为可估计的平均条件

消费模型同时包含消费、资产收益与未知风险偏好参数，且通常是非线性的。直接线性化会加入额外假设，使模型被拒绝时难以判断问题来自哪里。

广义矩估计，即 GMM，利用模型本来就要求成立的平均条件。例如，对每项资产都有 E[m(θ)G−1]=0E[m(\theta)G-1]=0E[m(θ)G−1]=0，θ\thetaθ 表示待估参数。给出一组参数后，先计算每期 m(θ)G−1m(\theta)G-1m(θ)G−1，再求样本平均；选择使这些平均偏差整体最小的参数。

如果有效矩条件多于参数，模型无法自由地把所有误差调成零，多余条件便可用于检验。估计还需要参数可识别、矩存在和相应的收敛条件；有时间相关性时，权重和标准误要计入长期协方差。

早期美国消费与资产收益数据的检验中，基础消费模型难以同时解释相对平滑的消费和较大的风险溢价。Hansen 与 Singleton 的 GMM 检验延续了这一结果，促使研究引入更丰富的偏好、消费风险和投资者差异。

夏普比率对折现因子的约束

令 Re=R−RfR^e=R-R_fRe=R−Rf​ 为超额收益。由 E[mRe]=0E[mR^e]=0E[mRe]=0，可以写出

σ(m)E[m]≥∣E[Re]∣σ(Re).\frac{\sigma(m)}{E[m]}\ge\frac{|E[R^e]|}{\sigma(R^e)}.E[m]σ(m)​≥σ(Re)∣E[Re]∣​.

右边是绝对夏普比率，左边是折现因子的相对波动。这称为 Hansen–Jagannathan 界。假设某一收益频率下，最大夏普比率为 0.5，则能为这些资产定价的折现因子必须满足 σ(m)/E[m]≥0.5\sigma(m)/E[m]\ge0.5σ(m)/E[m]≥0.5。资产收益、波动和折现因子必须采用相同频率。

鲨鱼说

夏普比率越高，模型需要解释的“单位波动收益”越大。若模型产生的折现因子几乎不变，就难以给出很高的风险补偿。这个下界把抽象的定价模型与可观察的收益数据联系起来。

行为偏差为什么未必立即被纠正

投资者可能因过度自信、注意力有限、损失厌恶或心理账户而错误处理信息。噪声交易者模型允许价格偏离基本面价值；理性投资者虽然可能识别偏差，却受到资金、卖空、借券费用和投资期限等约束。

例如，同一家公司的相关证券出现价差，交易者买入便宜一端、卖出昂贵一端。若价差在回归前继续扩大，持仓可能先产生浮亏，并触发追加保证金或资金赎回。最终方向判断正确，也无法消除这段融资风险。

同质证券在不同市场的价格差异、封闭式基金折价等现象，推动了对投资者情绪与套利限制的研究。行为机制还可进入偏好模型，与消费和风险的解释共同研究价格及成交量。

同一时点，为什么资产的预期收益不同

将 E[mG]=1E[mG]=1E[mG]=1 按期望与协方差展开，并利用 Gf=1/E[m]G_f=1/E[m]Gf​=1/E[m]，得到

E[G]−Gf=−Cov⁡(m,G)E[m].E[G]-G_f=-\frac{\operatorname{Cov}(m,G)}{E[m]}.E[G]−Gf​=−E[m]Cov(m,G)​.

困难状态的 mmm 较高。若某资产恰在这些状态回报较低，它与 mmm 的协方差为负，投资者就要求正的预期风险补偿。保险型资产在困难时支付更多，可以以较低的预期收益吸引购买者。

CAPM 用市场暴露解释这种横截面收益差异。逐期截面回归及 Fama–MacBeth 方法提供了相应检验工具。规模、价值等证据随后推动了三因子、五因子及其他多因子模型。模型中的特征或收益序列能够解释数据，还需进一步研究其所代表的风险状态或行为机制。

回到两种状态的例子，顺周期资产的预期净收益为 100/98−1≈2.04%100/98-1\approx2.04\%100/98−1≈2.04%，保险型资产为 100/102−1≈−1.96%100/102-1\approx-1.96\%100/102−1≈−1.96%。预期支付相同，但今天的价格不同，因而预期收益不同。

Python12 行
import numpy as np

prob = np.array([0.5, 0.5])
m = np.array([0.9, 1.1])
payoffs = np.array([[120., 80.], [80., 120.]])
prices = payoffs @ (prob * m)
gross = payoffs / prices[:, None]
print("价格:", prices)
print("预期净收益:", gross @ prob - 1)
assert np.allclose(prices, [98., 102.])
assert np.allclose(gross @ (prob * m), 1.)
print("消费下降或上升10%时的m:", 0.98 / np.array([0.9, 1.1])**2)

程序依次得到价格 98、102，预期净收益约 0.02041、−0.01961，以及消费模型中的折现因子约 1.20988、0.80992。最后一行是另一组消费参数示例，不与前面指定的 0.9、1.1 混用。

练习：没有风险调整时会怎样

保持两种状态的概率与资产支付不变，把两个状态的折现因子都设为 1。两项资产的价格与预期净收益分别是多少？这项改动去掉了什么？

查看解答

两项资产价格均为平均支付 100，预期净收益均为零。把 mmm 设为常数，去掉了支付随经济状态变化的价值差异。在这一设定中，同样一元支付在景气与困难状态下获得相同权重，因此保险作用不再形成价格差。
