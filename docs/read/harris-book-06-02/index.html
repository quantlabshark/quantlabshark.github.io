6.2 集合竞价的供需曲线与交易剩余

计算统一成交价，并区分成交量最大化与真实交易收益。

用累计数量寻找可成交价格

集合竞价把某一时段收集的订单一起处理。对候选价格 ppp，把所有限价不低于 ppp 的买单数量相加，得到需求 D(p)D(p)D(p)；把所有限价不高于 ppp 的卖单数量相加，得到供给 S(p)S(p)S(p)。该价格能成交的数量为

Q(p)=min⁡{D(p),S(p)}.Q(p)=\min\{D(p),S(p)\}.Q(p)=min{D(p),S(p)}.

价格提高，会让更多卖单符合条件，同时排除部分买单。统一价格通常从能够实现最大成交量的候选价格中确定。若有多个候选，还需要市场规定的不平衡量、参考价等进一步规则。离散数量下，买卖需求不必恰好相等，较多一侧的边界订单需要分配。

以下自拟例子中，价格单位为元，数量单位为件。买单为限价 101 的 3 件、限价 100 的 4 件；卖单为限价 99 的 2 件、限价 100 的 5 件。

Python12 行
buys = [(101, 3), (100, 4)]
sells = [(99, 2), (100, 5)]
rows = []
for price in sorted({p for p, q in buys + sells}):
    demand = sum(q for p, q in buys if p >= price)
    supply = sum(q for p, q in sells if p <= price)
    rows.append((price, demand, supply, min(demand, supply)))
for row in rows:
    print("价格、需求、供给、成交量：", row)
best = max(row[3] for row in rows)
winners = [row[0] for row in rows if row[3] == best]
assert winners == [100] and best == 7

成交价为 100，7 单位同时成交。愿意出 101 的买方没有支付 101，愿意接受 99 的卖方也没有只收到 99。限价主要决定是否能参加，而统一价格决定最终支付。

若某价格上的需求为 10 单位、供给只有 7 单位，成交量仍为 7。随后要决定买方的 3 单位缺口由谁承担：可以依价格和时间排队，也可以在边界价格按比例分配。这一步不会改变已经算出的总成交量，却会改变每个账户的结果。回测集合竞价时，只计算成交价而忽略数量分配，容易把实际买不到的数量也算成成交。

在候选价 100 上，累计买量和卖量均为 7，能够成交 7 单位。把价格提高到 101，愿意支付该价格的买量降为 3，成交量随之减少。

交易剩余与账面盈利不同

若买方愿意为某物支付 105，卖方至少愿意接受 98，而成交价为 100，买方剩余为 5，卖方剩余为 2，合计为 7。换成 102 成交，只会把剩余重新分配为 3 和 4，合计仍是 7。这里的“价值”是参与者对该物的评价，不是已观察到的未来市场价格。

在给定真实估值、可行交易和相应数量条件下，优先让估值更高的买方与估值更低的卖方成交，可以提高总剩余。若参与者用限价准确表达这些估值，统一价格集合能够实现这种分配。但真实估值通常不可见，申报还可能受到策略影响，不能从订单簿直接宣布市场已经达到社会最优。

连续交易为何采用不同价格

连续市场一笔大买单可能依次接受 100、101 和 102 的卖单。固定已有订单不变时，买方获得部分低价成交。若全部按最后的 102 成交，买方支出更高，前面的卖方收入更多。前者称为差别定价，后者是统一定价。

然而，改规则后订单不会保持不变。统一定价下，小交易者提高报价积极性，可能主要改变成交机会而不直接改变成交价。差别定价下，挂单价格更直接决定收到或支付多少。因此不能只把同一订单表换个计算方式，就断定某制度永久有利于某一类人。

连续市场也难以强制一名大交易者的整张隐含订单统一定价，因为他可以拆成多次提交。暂时停止并集中撮合，可以让更多反向需求到场，但同时牺牲即时性。连续市场多出的中间成交和交易商周转，会增加报告成交量。成交量较高不一定代表最终配置带来的剩余更高。

练习

为什么不能只比较连续市场与集合市场的成交量，就判断哪个市场更好？

查看解答

连续市场可能通过交易商多次转手连接不同时间到达的客户，成交量因此增加；集合市场可能让最终买卖方直接相遇。还应比较等待成本、执行价格、总费用、风险和信息作用。单纯的剩余计算也未必计入立即成交的价值。
