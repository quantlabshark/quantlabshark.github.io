42 · 资本增长与风险预算

通过重复投资解释对数增长、Kelly比例和再平衡效应，用Euler分解计算各资产风险贡献。

长期资本增长取决于各期财富倍数的连乘。对数效用将这一过程转为可加的增长指标，风险预算则限制各持仓对组合风险的贡献。

平均赚钱为何仍可能长期缩水

每次有55%概率赚下注金额、45%概率损失下注金额。若把财富的一半下注，单次财富乘数为1.5或0.5，算术期望乘数为1.05；但平均对数增长为

0.55log⁡1.5+0.45log⁡0.5≈−0.08891.0.55\log1.5+0.45\log0.5\approx-0.08891.0.55log1.5+0.45log0.5≈−0.08891.

反复投资的财富是每期乘数相乘，取对数后变成逐期相加。因此长期增长与对数平均相关，而不是简单比较单次算术平均。一次严重损失会压低后续复利基础。

Kelly比例怎样推导

若每次下注财富比例fff，赔率为一比一，获胜概率为ppp，期望对数增长为

g(f)=plog⁡(1+f)+(1−p)log⁡(1−f),0≤f<1.g(f)=p\log(1+f)+(1-p)\log(1-f),\quad0\le f<1.g(f)=plog(1+f)+(1−p)log(1−f),0≤f<1.

求导得g′(f)=p/(1+f)−(1−p)/(1−f)g'(f)=p/(1+f)-(1-p)/(1-f)g′(f)=p/(1+f)−(1−p)/(1−f)。令其为0得到f∗=2p−1f^*=2p-1f∗=2p−1。在p=0.55p=0.55p=0.55时，最优比例为10%，对数增长约0.005008，每轮约0.5008%。g′′(f)<0g''(f)<0g′′(f)<0说明这是唯一最大点。

曲线在10%附近达到峰值，随后下降；增加下注并不会持续增加增长。f=1f=1f=1时只要输一次财富便为0，对数损失为负无穷。胜率从55%估错到50%，最优比例由10%变为0，可见参数误差直接影响仓位。

Python10 行
import math
import numpy as np
for f in [0.1, 0.5]:
    growth = 0.55 * math.log1p(f) + 0.45 * math.log1p(-f)
    print(f, growth)
w = np.array([2 / 3, 1 / 3])
cov = np.diag([0.1 ** 2, 0.2 ** 2])
vol = math.sqrt(float(w @ cov @ w))
contribution = w * (cov @ w) / vol
print('volatility:', vol, 'risk contributions:', contribution)

程序使用标准库与NumPy，计算不同下注比例的增长与风险贡献。下注和资产配置是不同应用场景，这里使用简化赔率只为把复利机制算清楚。

从单次下注到投资组合

若Rt+1R_{t+1}Rt+1​表示各资产的总收益乘数，组合财富满足Zt+1=Ztwt⊤Rt+1Z_{t+1}=Z_tw_t^\top R_{t+1}Zt+1​=Zt​wt⊤​Rt+1​。对数效用目标可逐期最大化E[log⁡(wt⊤Rt+1)∣Ft]E[\log(w_t^\top R_{t+1})\mid\mathcal F_t]E[log(wt⊤​Rt+1​)∣Ft​]，其中Ft\mathcal F_tFt​表示当时已有信息。

在适当的可积性、可行性条件下，对数最优组合有长期相对增长性质，其他可行财富与其财富的比值具有上鞅性质。但它不保证任意有限期限都领先，也不一定满足其他效用、回撤或偿付需求。部分Kelly降低下注比例，减少对参数误差的敏感性，其比例仍需与估计误差和风险目标联系。

小收益时log⁡(1+r)≈r−r2/2\log(1+r)\approx r-r^2/2log(1+r)≈r−r2/2，所以Elog⁡(1+r)≈E(r)−E(r2)/2E\log(1+r)\approx E(r)-E(r^2)/2Elog(1+r)≈E(r)−E(r2)/2。这里是二阶矩E(r2)=Var⁡(r)+[E(r)]2E(r^2)=\operatorname{Var}(r)+[E(r)]^2E(r2)=Var(r)+[E(r)]2；只有均值平方可忽略时，才常写成均值减半方差。

再平衡收益来自什么

设A先涨20%，再跌1/61/61/6，两期后回到原价；B始终不变。最初各投一半并一直持有，终值回到1。若每期末恢复各半，第一期财富为1.1；第二期乘数为0.5×(5/6)+0.5=11/120.5\times(5/6)+0.5=11/120.5×(5/6)+0.5=11/12，终值为1.1×11/12=1.0083331.1\times11/12=1.0083331.1×11/12=1.008333。

第一期卖出部分上涨的A、转入B，第二期A回落时损失较小。这条特定路径产生0.8333%的再平衡收益。若A持续单边上涨，持续卖出A可能落后于持有；费用也会消耗再平衡收益。

对固定非负权重，逐期有log⁡(∑iwiRi)≥∑iwilog⁡Ri\log(\sum_iw_iR_i)\ge\sum_iw_i\log R_ilog(∑i​wi​Ri​)≥∑i​wi​logRi​，这是对数凹性的结果。它比较组合对数收益与各资产对数收益的加权平均，不等于保证超过事后最佳资产。另一个Jensen关系是Elog⁡W≤log⁡EWE\log W\le\log EWElogW≤logEW，方向不能颠倒。

鲨鱼说

风险预算决定风险由谁承担，风险目标决定总共承担多少。把所有仓位同时加倍，贡献占比可以不变，但总波动、融资和回撤都会改变。

组合方法怎样放到同一个检验中

增长最优、均值方差、风险预算解决不同目标，比较时不能只挑其中一种擅长的指标。使用同样的滚动训练窗口和未来样本，报告复合增长、波动、回撤、换手、费用、极端暴露及资金约束。

例如历史研究使用50只股票、120个月估计窗口进行滚动测试，这是一种固定估计再向前评价的设计。不同市场或时期应重新检查相关结构；平稳遍历假设下的长期结论，不能替代有限样本结果。

练习

不相关的两资产波动率为15%和30%，等风险权重是多少？若两个仓位同时乘以1.5，风险贡献比例与总波动各怎样变化？

查看解答

波动率之比仍为1:2，权重为2/32/32/3与1/31/31/3。在协方差与融资条件不变的线性模型下，同时放大1.5倍后，各项风险贡献和总波动均变为1.5倍，风险贡献占比不变。放大后的净风险资产权重和为1.5，需要融资或衍生工具支持。
