用协方差矩阵检查联合结果

任何时刻的二维协方差矩阵都必须半正定，因此协方差平方不超过两个方差之积。这可以作为公式与程序的核验。零时刻两个方差和协方差都应为零；小时间内速度方差先以一次时间增长，角度方差以三次时间增长。

如果数值图中角度每一步出现直接跳变，可能把噪声误加在位置而不是速度方程上。两个模型都能画出波动曲线，但响应核、光滑性和能量变化不同，应回到状态方程核对噪声作用的位置。

固有频率一、噪声幅度 0.2、初值为零。左图为一条角度与角速度轨迹，右图展示跨路径平均能量与线性理论值。

鲨鱼说

半正定，即矩阵对应的二次型对任意向量均不为负的性质。

将位置与速度组成状态向量后，二阶随机方程可写成一阶矩阵方程。均值由矩阵指数传播，协方差由噪声响应核的乘积积分决定，二者可以分开计算。
