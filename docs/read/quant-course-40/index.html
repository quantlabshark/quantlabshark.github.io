40 · 参数不确定性与重抽样组合

区分收益波动和参数误差，重抽样整个估计与配置过程，并用条件方差分解解释预测风险。

配置决策面对两类不确定性：资产未来收益会变化，估计出的均值和协方差也可能不准确。重抽样与贝叶斯方法用于将参数估计的不确定性纳入组合分析。

鲨鱼说

协方差，即两个变量偏离各自均值时，共同变化程度的度量。

风险不仅来自下一期涨跌

假设下一期收益在给定真实均值后，标准差为10%；但当前有两种同样可能的均值判断：5%与−5%。整体平均收益为0，而预测方差为

0.102+0.052=0.0125,0.10^2+0.05^2=0.0125,0.102+0.052=0.0125,

标准差约11.18%。第一项是均值已知时仍存在的收益波动，第二项来自均值尚未确定。将估计值当作真实参数，会遗漏后一部分。

配置还增加了一层变化：不同样本会给出不同均值、协方差与权重。研究对象不只是某一组固定权重，也包括生成这组权重的估计程序。

条件方差如何分解

用DDD表示当前数据，w(D)w(D)w(D)表示由这些数据算出的权重，RRR表示未来收益。给定DDD时，预测均值为μD\mu_DμD​，协方差为ΣD\Sigma_DΣD​。跨样本考察组合收益Y=w(D)⊤RY=w(D)^\top RY=w(D)⊤R，全方差公式给出

Var⁡(Y)=E[w(D)⊤ΣDw(D)]+Var⁡[w(D)⊤μD].\operatorname{Var}(Y)=E[w(D)^\top\Sigma_Dw(D)] +\operatorname{Var}[w(D)^\top\mu_D].Var(Y)=E[w(D)⊤ΣD​w(D)]+Var[w(D)⊤μD​].

外层期望和方差还包括数据集DDD的变化。第二项描述不同样本下预测组合收益的差异。评价估计程序时，权重必须随每个新样本重新计算；固定原权重只重抽收益，回答的是另一个问题。

自助法怎样生成替代样本

自助法又称Bootstrap。从已有nnn期收益中有放回地抽取nnn期，形成一个替代样本；随后重新估计参数、重新求权重。重复多次，观察权重分布及表现分布。

多资产收益矩阵的一行属于同一期，应整行抽样。若分别抽各列，会打乱资产同期共同涨跌，改变协方差。普通逐行抽样保留同期关系，却打破时间依赖。存在持续性时可抽取连续区块，或先拟合条件均值与波动模型，再对联合残差重抽样。

例如条件模型rt+1=μt+Dtzt+1r_{t+1}=\mu_t+D_tz_{t+1}rt+1​=μt​+Dt​zt+1​中，DtD_tDt​是各资产条件波动的对角矩阵，zzz为标准化残差。下一期协方差为DtCov⁡(z)DtD_t\operatorname{Cov}(z)D_tDt​Cov(z)Dt​。重抽样时保留每期的残差向量，才能保留同期相关性。

六期数据估计两资产权重

以下程序依赖NumPy。每次抽取六行收益、估计协方差，再在不卖空的两资产权重网格中寻找最小方差点，重复500次。微小对角修正用于避免退化样本的数值奇异。

Python15 行
import numpy as np
returns = np.array([[0.02, 0.01], [-0.01, 0.03], [0.03, -0.02],
                    [0.01, 0.02], [-0.02, -0.01], [0.02, 0.04]])
rng = np.random.default_rng(2026)
grid = np.linspace(0, 1, 1001)
weights = np.column_stack([grid, 1 - grid])
chosen = []
for _ in range(500):
    sample = returns[rng.integers(0, len(returns), len(returns))]
    cov = np.cov(sample, rowvar=False) + 1e-8 * np.eye(2)
    risk = np.einsum('ij,jk,ik->i', weights, cov, weights)
    chosen.append(weights[np.argmin(risk)])
chosen = np.array(chosen)
print('mean weights:', chosen.mean(axis=0))
print('A weight percentiles:', np.quantile(chosen[:, 0], [0.1, 0.5, 0.9]))

输出包含500组最优权重的均值与分位数。区间越宽，说明六期数据不足以稳定区分配置比例；频繁落在0或1边界，表示目标对样本变化很敏感。分位数描述的是重抽样下估计权重的变化，不是收益的置信区间。

图将500次结果同时展示，避免只报告一个平均权重。平均权重可以缓和极端配置，但不能凭平均这一操作保证未来收益提高。预算、不卖空等凸约束会被平均保留；“最多持有三项资产”这样的非凸约束则可能被平均破坏。

平均权重与经验贝叶斯有何区别

平均重抽样权重是组合层面的汇总。经验贝叶斯则利用数据估计先验参数，再形成后验预测。非参数经验贝叶斯可以借经验分布和重抽样估计预测均值、协方差或二阶矩，不要求指定完整的收益分布。

若μn=E(R∣D)\mu_n=E(R\mid D)μn​=E(R∣D)、Vn=E(RR⊤∣D)V_n=E(RR^\top\mid D)Vn​=E(RR⊤∣D)，则Vn=Σn+μnμn⊤V_n=\Sigma_n+\mu_n\mu_n^\topVn​=Σn​+μn​μn⊤​。均值方差目标可借一个辅助参数η\etaη，转化为一组内层二次优化：

min⁡1⊤w=1 λw⊤Vnw−ηw⊤μn.\min_{\mathbf1^\top w=1}\ \lambda w^\top V_nw-\eta w^\top\mu_n.1⊤w=1min​ λw⊤Vn​w−ηw⊤μn​.

注意这里使用二阶矩VnV_nVn​，并非只使用协方差。固定η\etaη后可以解内层权重，再按原始均值方差目标在外层选择η\etaη。这与“每次求最优权重后直接平均”是不同算法，报告应给出实际使用的步骤。

鲨鱼说

重抽样只能重组样本里已有的信息。六期数据没有包含的危机状态，不会因为抽了500次便自然出现；因此还要另设有经济含义的压力情景。

怎样检验组合估计是否改善

比较方法时保持样本窗口、约束、费用和测试时期一致。每个训练窗口完成参数估计与风险偏好选择，然后向前评价；最终测试期不参与选择重抽样次数、区块长度或风险厌恶系数。

历史研究中的少资产、短样本模拟用于展示参数误差对方法比较的影响。例如四资产、六期估计样本与500次模拟是特定实验设计。真实应用还需报告边界仓位比例、权重分位数、换手、不可行比例和样本外风险，而非只保留最高信息比率。

练习

两资产各有100期收益，研究者分别重抽两列后发现相关性接近0。能否据此认为原先的相关性不稳定？若只保存平均权重，又遗漏了什么？

查看解答

不能。分列抽样破坏了同一期的配对关系，接近0可能是抽样设计造成的。应整行抽取，时间依赖明显时进一步采用区块。只保存平均权重会遗漏离散程度、极端仓位频率及多峰结构，应同时保存每次结果和分位数。
