23 · 交易成本、成交约束与绩效指标

建立逐笔现金账，计算费用后的收益、回撤与风险调整表现，判断信号能否覆盖实际执行成本。

交易成本把价格变化产生的毛盈亏转换为账户净盈亏。手续费、价差、滑点和成交限制作用于不同环节，应与实际订单和成交记录对应。

股价上涨0.5%，账户赚了多少

以10元买入10股，再以10.05元卖出，价格上涨0.5%，毛利润为0.50元。若买卖两边均按成交额的0.1%收费，买入费用0.10元，卖出费用0.1005元，净利润只剩0.2995元。价格优势越小，费用占毛利润的比例越高。

账户有1000元，却只买入100元股票，因此账户净收益为0.2995/1000=0.02995%0.2995/1000=0.02995\%0.2995/1000=0.02995%。它与股票本身上涨0.5%使用不同分母。研究报告应明确是在计算标的收益、持仓收益还是总账户收益。

现金与股票怎样共同形成净值

一笔买入只是把现金转成股票，股票购买金额不是损失；手续费才使总资产立即下降。逐笔记账如下。

时点 现金 股票数量 估值价格 总资产
开始 1000.0000 0 10.00 1000.0000
买入后 899.9000 10 10.00 999.9000
价格上涨后 899.9000 10 10.10 1000.9000
全部卖出后 1000.2995 0 10.05 1000.2995

任意时点净值都满足Vt=Ct+qtPtV_t=C_t+q_tP_tVt​=Ct​+qt​Pt​。本例没有借贷、分红与外部出入金；若存在这些现金流，应分别记账，而不是全部混进交易盈亏。

Python20 行
import numpy as np

cash = 1000.0
shares = 0
fee_rate = 0.001
buy_price, sell_price, quantity = 10.0, 10.05, 10
buy_fee = quantity * buy_price * fee_rate
cash -= quantity * buy_price + buy_fee
shares += quantity
nav_after_buy = cash + shares * buy_price
nav_middle = cash + shares * 10.10
sell_fee = shares * sell_price * fee_rate
cash += shares * sell_price - sell_fee
shares = 0
nav = np.array([1000.0, nav_after_buy, nav_middle, cash])
drawdown = nav / np.maximum.accumulate(nav) - 1
print("net pnl:", cash - 1000)
print("max drawdown:", -drawdown.min())
assert np.isclose(cash, 1000.2995)
assert shares == 0

程序输出净利润0.2995元、最大回撤约0.00059996，即0.0600%。回撤使用曾经达到的最高净值1000.9元作为分母。累计收益则使用最初1000元。买入后瞬间减少0.1元，是检查手续费是否正确入账的一个具体依据。

佣金、价差与市场影响

显式费用包括佣金与按适用规则产生的收费。买卖价差则来自同时存在的买价与卖价：若最优买价9.99元、最优卖价10.01元，立即买入再卖出，即使中间价未变也会损失0.02元。市场影响是订单消耗流动性后，后续成交价格变差的部分。

因此模拟成交可以从参考价加不利滑点，再扣显式费用。若已经使用真实买卖成交价，其中的价差与冲击已进入价格，就不能重复扣除。对未成交订单，还可能存在机会成本，称为执行落差的一部分，需要与已成交部分分开记录。

图中使用同一组买卖价格，只改变双边费率。费率为0、0.1%、0.2%时，净利润分别为0.50、0.2995、0.0990元。零利润的费率满足0.5−200.5c=00.5-200.5c=00.5−200.5c=0，即约0.2494%。若成交价进一步变差，可承受费率还会降低。

鲨鱼说

“每边0.1%”不是整笔交易只扣0.1%。买入与卖出各有成交额，应分别计费；但实际成交价中已经包含的价差，不要再次全额扣除。

不能成交的订单怎样处理

资金不足、最小交易单位、可用持仓、借券数量、单股上限和成交量占比，都可能改变最终交易。若每股价格10元、费率0.1%、现金100元，能买的整数股为⌊100/(10×1.001)⌋=9\lfloor100/(10\times1.001)\rfloor=9⌊100/(10×1.001)⌋=9股。直接买10股会在扣费后出现负现金。

约束应进入撮合过程：订单可以部分成交、被拒绝或延期，账户仍按实际持仓计价。指定最多持有若干股票属于离散数量约束，不能等同于简单的权重上限。实际市场制度随市场和产品不同。教学程序中的整数股、空仓、无借贷都是明确的模拟约定。

绩效指标各自回答一个问题

累计收益为VT/V0−1V_T/V_0-1VT​/V0​−1；回撤为Vt/max⁡s≤tVs−1V_t/\max_{s\le t}V_s-1Vt​/maxs≤t​Vs​−1；波动率衡量周期收益的离散程度。夏普比率使用平均超额收益除以超额收益标准差，信息比率则将无风险基准替换为比较组合，分母也改为主动收益的标准差。

例如月主动收益均值0.3%、标准差1.5%，月信息比率为0.2。它没有直接说明绝对收益是正还是负，因为基准当月也可能亏损。市场β调整后的Treynor比率、回归截距Jensen α、关注目标以下波动的Sortino比率，分别采用不同风险口径。Sortino的分母应是下行波动的平方根，并明确是否按全部期数计算下行二阶矩。

M²可把组合调整到市场波动水平后比较回报：rf+(σM/σp)(μp−rf)r_f+(\sigma_M/\sigma_p)(\mu_p-r_f)rf​+(σM​/σp​)(μp​−rf​)。这些指标都需要统一频率和样本。独立、平稳等近似下，夏普可乘周期数平方根年化；净值复合增长则使用连乘，二者不是同一种年化。

报告同时保留收益幅度与执行条件

收益、回撤、波动、交易次数、持仓暴露和换手应一起展示。较高信息比率可能来自极小但稳定的主动收益，若收益量级无法覆盖成本，就没有相同的交易意义。还可固定策略，分别提高费率、延迟成交和限制成交数量，观察结果是否变化。
