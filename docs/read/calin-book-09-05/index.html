蒙特卡洛与网格方法

概率表示提供一种数值方案：从 (t,x)(t,x)(t,x) 生成多条状态路径，计算每条路径的终端值和时间累计，再取平均。路径数量影响抽样误差，时间步长影响离散误差，两者应分别检查。增加路径数不能消除错误的时间离散。

另一种方案直接在状态和时间网格上解偏微分方程。低维时网格法能得到多个初始状态的函数值；高维时网格数量迅速增长，路径模拟往往更方便。二者计算的是同一对象，已知显式解时可以相互核对。

边界条件的含义

若过程碰到边界后停止，表示式中的终点应改成退出时间与 TTT 的较小者，并使用相应边界收益。反射边界、吸收边界和自由扩散代表不同模型，不能只在数值程序中随意截断状态而不改数学问题。

累计成本与终端支付分开记账

路径模拟中，运行成本应乘时间步长再累加，终端支付只在最后加一次；如果有贴现，每笔成本应使用它实际发生时的贴现因子。把全部成本先求和再按终点统一贴现，会改变支付时点。

当源项可以为负时，概率表示仍可使用，但需要相应可积性来保证期望存在。把成本理解为“累计量”比只理解成正费用更一般，例如累计位移、收益或带符号源项都可由同一结构描述。
