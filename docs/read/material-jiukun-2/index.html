排列、等待时间与状态压缩

表盘上的时刻表示、排列的最长递减前缀、连续掷出指定点数的等待时间、网格摆放的最大权重、组合数量的指数上界

表盘上的时刻表示

题目

一个只标出 12 点方向的表盘上放两根等长木棒作为时针和分针，要求表示 5 时 12 分。求两棒相对 12 点顺时针的角度及较小夹角，并判断互换两棒是否仍是合法时刻。

考点：时针连续移动；角度约束；交换验证。

查看分析与解答

必要知识

分针每小时一圈，时针十二小时一圈；时针在整点之间持续运动。两棒等长会隐藏身份，但合法时刻仍要求二者由同一个时间参数生成。

分析思路

分别用分钟数计算分针和时针角度，再交换角色尝试求同一时刻，检查两个角度约束能否同时满足。

解答步骤

5时12分已过312分钟，时针每分钟0.5度，故156度；分针只看本小时12分钟，给72度。两角差84度小于180度，即较小夹角。

分针每分钟转 6°，12 分钟对应 12×6=72∘12\times6=72^\circ12×6=72∘。时针每小时转 30°，每分钟还前进 0.5°，因此 5 时 12 分对应 5×30+12×0.5=156∘5\times30+12\times0.5=156^\circ5×30+12×0.5=156∘。较小夹角为 156−72=84∘156-72=84^\circ156−72=84∘。

辨认两根等长指针时，可分别尝试把其中一根视为分针，再检查另一根是否对应同一时刻的时针位置。如果互换，156° 的分针表示 26 分，而 72° 的时针表示 2 时 24 分，二者不能同时成立，因此不是另一个合法时刻。

摆放时，从 12 点方向顺时针量取 72° 与 156°。时针在 12 分钟内继续转过 6°，所以其位置超过了 5 点刻度。

交换后，分针156度意味着26分钟；小时针72度对应过12点144分钟，即2时24分。若真为2时26分，时针应在60+13=73度，与72不符，所以交换不是另一个合法时刻。

同类问题

钟表题把两针角度都写成时间的函数，并用同一个时间变量求解。不能把时针锁在整点刻度或独立读取小时和分钟。

排列的最长递减前缀

题目

对 1,…,n1,\ldots,n1,…,n 的所有排列，求最长严格递减前缀恰为 kkk 的排列数。再允许用数字 1,2,3,41,2,3,41,2,3,4 重复组成长度 nnn 的序列，分别求整串严格递减、整串非增，以及最长对应前缀恰为 kkk 的计数。

考点：尾计数差；严格与非严格；边界。

查看分析与解答

必要知识

最长前缀恰为k等于“前k项满足”减去“前k+1项仍满足”。计数至少长度的事件通常更简单，最后再做相邻差。重复数字使严格递减和非增明显不同。

分析思路

先求至少k的计数A_k，再用A_k−A_{k+1}。整串已到末尾时单独处理；允许重复的版本分别用选不同数字和重数分配计算前缀。

解答步骤

排列的前k个数只要选定集合，递减顺序便唯一，剩余(n−k)!种；所以A_k=n!/k!。n=3时恰长1、2、3的数量为3、2、1，总六，检验分组覆盖全部排列。

前 kkk 项递减时，先从 nnn 个数中选出这 kkk 个数，其内部次序唯一，其余数任意排列，故数量为

Ak=(nk)(n−k)!=n!k!.A_k=\binom nk(n-k)!=\frac{n!}{k!}.Ak​=(kn​)(n−k)!=k!n!​.

当 1≤k<n1\le k<n1≤k<n，减去前 k+1k+1k+1 项仍递减的情形：

Nk=Ak−Ak+1=n!k!−n!(k+1)!.N_k=A_k-A_{k+1}=\frac{n!}{k!}-\frac{n!}{(k+1)!}.Nk​=Ak​−Ak+1​=k!n!​−(k+1)!n!​.

当 k=nk=nk=n，只有完全降序排列，Nn=1N_n=1Nn​=1。均匀随机排列下，将上述计数除以 n!n!n! 即得概率。

对于题目第二部分，用 1,2,3,41,2,3,41,2,3,4 可重复组成长度 nnn 的序列时：严格递减要求各项不同，整串计数为 (4n)\binom4n(n4​)（n>4n>4n>4 时为零）；非增序列由四个数的出现次数决定，计数为 (n+33)\binom{n+3}{3}(3n+3​)。

若问最长严格递减前缀恰为 kkk，前缀至少长 kkk 的序列数为 (4k)4n−k\binom4k4^{n-k}(k4​)4n−k，因此 k<nk<nk<n 时答案为

(4k)4n−k−(4k+1)4n−k−1.\binom4k4^{n-k}-\binom4{k+1}4^{n-k-1}.(k4​)4n−k−(k+14​)4n−k−1.

非增前缀则将组合数换为 (k+33)\binom{k+3}{3}(3k+3​) 与 (k+43)\binom{k+4}{3}(3k+4​)。

非增前缀长度k由四种数字的非负出现次数决定，次数和k，隔板法给C(k+3,3)。因此k<n时为C(k+3,3)4^{n−k}−C(k+4,3)4^{n−k−1}；k=n时就是C(n+3,3)。严格版本k=n时为C(4,n)，n>4为零，不应代入含4^{-1}的差式。

同类问题

“最长”“首次”类计数可先求尾事件再相减。另需检查末端边界，以及允许重复是否把排列问题变成重数组合问题。

连续掷出指定点数的等待时间

题目

独立反复投掷公平六面骰，首次连续出现 k≥1k\ge1k≥1 个点数 2 时停止。求投掷总次数的期望，并计算 k=1,2k=1,2k=1,2。

考点：连续成功；状态重置；几何级数。

查看分析与解答

必要知识

状态是末尾连续出现点数2的次数。非2的结果虽有五种，对未来的影响相同，都把状态重置为零，因此可合并为概率5/6的一类。

分析思路

设各末尾长度的剩余期望，写一步递推；从完成状态E_k=0向前展开成有限几何级数，再解E₀。

令A=1+(5/6)E₀，E_i=A+E_{i+1}/6。于是E_{k−1}=A、E_{k−2}=A(1+1/6)，逐步得E₀=A(1−6⁻ᵏ)/(5/6)。整理为E₀6⁻ᵏ=(6/5)(1−6⁻ᵏ)，得到公式。

网格摆放的最大权重

题目

给定 n×nn\times nn×n 权重矩阵 aija_{ij}aij​，每格最多放一个奖杯，任意相邻 2×22\times22×2 子方格最多放两个，允许空格。求可获得的最大总权重，给出程序并分析其适用规模。

考点：局部约束；行掩码；最优子结构。

查看分析与解答

必要知识

每个2×2约束只涉及相邻两行与相邻两列。处理新行时，更早行的具体摆法不再与它直接相邻，因此可把过去压缩为上一行的掩码和累计最优值。

分析思路

枚举所有行掩码，预计算相邻掩码是否满足每个2×2至多两杯，再逐行转移并保留每个当前掩码的最大累计权重。

解答步骤

两位窗口(p>>j)&3提取上一行相邻两列，bit_count给其中杯数；对q同样提取，再相加不超过二。例如2×2权重1、2、3、4，允许最多两个，选3和4得7；各行可有两个杯，但不能让相邻两行同一两列合计超二。

处理到第 iii 行时，较早行对未来的影响只能通过第 iii 行摆法传递，因为任何约束最多跨相邻两行。于是同一个当前行掩码，只需保留到这里的最大累计权重，较小累计值以后不可能反超。

代码先预计算每个掩码的合法前驱列表，再逐行累加。负权格可以不选；全负矩阵的最优值为 0。若还需恢复方案，可同时存下取得最大值的前行掩码。

用位掩码 qqq 表示当前行，wi(q)w_i(q)wi​(q) 为其权重，则 Di(q)=wi(q)+max⁡p: (p,q)合法Di−1(p)D_i(q)=w_i(q)+\max_{p:\,(p,q)\text{合法}}D_{i-1}(p)Di​(q)=wi​(q)+maxp:(p,q)合法​Di−1​(p)。合法条件是相邻两列的四个位之和不超过二。朴素复杂度上界为 O(n24n)O(n^2 4^n)O(n24n)；矩形网格宜让较短边充当掩码宽度。

def maximum_grid_weight(weights):
    if not weights or not weights[0]:
        return 0
    width = len(weights[0])
    if any(len(row) != width for row in weights):
        raise ValueError("各行长度必须一致")
    states = range(1 << width)
    legal = {q: [p for p in states
                 if all(((p >> j) & 3).bit_count()
                        + ((q >> j) & 3).bit_count() <= 2
                        for j in range(width - 1))] for q in states}
    dp = {q: sum(x for j, x in enumerate(weights[0]) if q >> j & 1)
          for q in states}
    for row in weights[1:]:
        dp = {q: sum(x for j, x in enumerate(row) if q >> j & 1)
                 + max(dp[p] for p in legal[q]) for q in states}
    return max(dp.values())

assert maximum_grid_weight([[1, 2], [3, 4]]) == 7
assert maximum_grid_weight([[-1, -2], [-3, -4]]) == 0

宽w、高h时合法表预计算O(w4^w)，各行转移O(h4^w)，行权重另可预计算。方形情形代码的实际上界可写O(n4^n+n²2^n)，粗略O(n²4^n)也是上界；关键是对宽度指数增长，因此宜让较短边作为掩码宽度。空掩码始终合法，使全负矩阵得到零。

网格局部约束可用行状态压缩，但需说明状态数量随宽度指数增长。若要求恢复具体摆法，在每个最优转移中记录前驱。

组合数量的指数上界

题目

设整数 n≥k≥1n\ge k\ge1n≥k≥1。证明 (nk)≤(en/k)k\binom nk\le(en/k)^k(kn​)≤(en/k)k，并据此估计 ∑j=0k(nj)\sum_{j=0}^k\binom nj∑j=0k​(jn​) 的一个上界。

考点：非负展开；辅助参数；组合上界。

查看分析与解答

必要知识

二项式展开的每一项均非负，因此整和不小于某一项，也不小于部分项之和。引入正参数x后，可通过选择x把组合数转成容易控制的指数式。

分析思路

先用单项得到C(n,k)x^k≤(1+x)^n，再取x=k/n并用1+x≤e^x。部分和则利用x≤1时小指数对应更大幂值。

解答步骤

对0<x≤1和j≤k，x^j≥x^k，所以Σ_{j≤k}C(n,j)x^j≥x^kΣ_{j≤k}C(n,j)。这一步允许整段计数同时被同一上界控制，不必把每项分别界定后再多乘k+1。

由二项式定理，对任意 x>0x>0x>0，(1+x)n≥(nk)xk(1+x)^n\ge\binom nkx^k(1+x)n≥(kn​)xk，因为展开各项非负。取 x=k/nx=k/nx=k/n，再用 1+x≤ex1+x\le e^x1+x≤ex，得到 (nk)≤(1+k/n)n(k/n)k≤(enk)k.\binom nk\le\frac{(1+k/n)^n}{(k/n)^k}\le\left(\frac{en}{k}\right)^k.(kn​)≤(k/n)k(1+k/n)n​≤(ken​)k. 这给出了组合数量相对于 n,kn,kn,k 的增长级别，不需展开阶乘。

进一步对 0<x≤10<x\le10<x≤1，j≤kj\le kj≤k 时 xj≥xkx^j\ge x^kxj≥xk，所以 (1+x)n≥∑j=0k(nj)xj≥xk∑j=0k(nj).(1+x)^n\ge\sum_{j=0}^k\binom njx^j\ge x^k\sum_{j=0}^k\binom nj.(1+x)n≥j=0∑k​(jn​)xj≥xkj=0∑k​(jn​). 仍取 x=k/n≤1x=k/n\le1x=k/n≤1，得到 ∑j=0k(nj)≤(en/k)k.\sum_{j=0}^k\binom nj\le(en/k)^k.j=0∑k​(jn​)≤(en/k)k. 例如 n=10,k=2n=10,k=2n=10,k=2 时，左侧为 1+10+45=561+10+45=561+10+45=56，上界为 (5e)2≈184.73(5e)^2\approx184.73(5e)2≈184.73。上界不要求很紧，主要用途是控制“至多选 kkk 个元素”的候选规模。

n=10、k=2时部分和56，上界约184.73，较松但易于代入后续估计。k=n时上界e^n仍大于真实2^n。若k=0，原表达式出现除零，应单独返回部分和一；本题已限定k≥1。
