比例、计数与首达时间分布

理解 Beta、Poisson、逆 Gamma 与逆高斯分布的取值范围、参数和矩。

变量取值范围与分布选择

选择分布时，首先检查变量的取值范围。比例应落在 0 与 1 之间，事件次数只能是非负整数，等待时间应非负。只比较均值和方差，可能选出取值范围不合适的模型。

Beta 分布适合描述 (0,1)(0,1)(0,1) 内的比例。形状参数为 α,β>0\alpha,\beta>0α,β>0 时，密度为

p(x)=xα−1(1−x)β−1B(α,β),B(α,β)=Γ(α)Γ(β)Γ(α+β).p(x)=\frac{x^{\alpha-1}(1-x)^{\beta-1}}{B(\alpha,\beta)},\quad B(\alpha,\beta)=\frac{\Gamma(\alpha)\Gamma(\beta)}{\Gamma(\alpha+\beta)}.p(x)=B(α,β)xα−1(1−x)β−1​,B(α,β)=Γ(α+β)Γ(α)Γ(β)​.

均值与方差分别为

E[X]=αα+β,Var⁡(X)=αβ(α+β)2(α+β+1).\mathbb E[X]=\frac\alpha{\alpha+\beta},\qquad \operatorname{Var}(X)=\frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}.E[X]=α+βα​,Var(X)=(α+β)2(α+β+1)αβ​.

两参数相等时密度左右对称；同时增大参数会使分布更集中。Beta⁡(2,2)\operatorname{Beta}(2,2)Beta(2,2) 和 Beta⁡(20,20)\operatorname{Beta}(20,20)Beta(20,20) 的均值都是 1/21/21/2，但方差分别为 1/201/201/20 和 1/1641/1641/164。当两参数都为 1/21/21/2 时，密度反而在两端较高，这将与布朗运动的反正弦律相联系。

比例分布的均值从哪里来

把 Beta 密度乘以 xqx^qxq 后积分，分子仍是一个 Beta 积分：

E[Xq]=B(α+q,β)B(α,β),q>−α.\mathbb E[X^q]=\frac{B(\alpha+q,\beta)}{B(\alpha,\beta)},\qquad q> -\alpha.E[Xq]=B(α,β)B(α+q,β)​,q>−α.

利用 Gamma 函数递推，E[X]=α/(α+β)\mathbb E[X]=\alpha/(\alpha+\beta)E[X]=α/(α+β)，E[X2]=α(α+1)/[(α+β)(α+β+1)]\mathbb E[X^2]=\alpha(\alpha+1)/[(\alpha+\beta)(\alpha+\beta+1)]E[X2]=α(α+1)/[(α+β)(α+β+1)]。二阶矩减均值平方，才得到方差公式。

取 α=2,β=3\alpha=2,\beta=3α=2,β=3，密度为 12x(1−x)212x(1-x)^212x(1−x)2，均值为 0.4，二阶矩为 0.2，方差为 0.04。若两参数同时乘 10，均值仍为 0.4，但方差降为 0.24/51≈0.0047060.24/51\approx0.0047060.24/51≈0.004706。参数比决定中心，参数总和控制集中程度。

Poisson 分布计算事件次数

若 N∼Poisson⁡(λ)N\sim\operatorname{Poisson}(\lambda)N∼Poisson(λ)，则

P(N=k)=e−λλkk!,k=0,1,2,….\mathbb P(N=k)=e^{-\lambda}\frac{\lambda^k}{k!},\qquad k=0,1,2,\ldots.P(N=k)=e−λk!λk​,k=0,1,2,….

其均值和方差都等于 λ\lambdaλ。利用指数级数，矩母函数为

E[euN]=e−λ∑k=0∞(λeu)kk!=exp⁡[λ(eu−1)].\mathbb E[e^{uN}]=e^{-\lambda}\sum_{k=0}^{\infty}\frac{(\lambda e^u)^k}{k!} =\exp[\lambda(e^u-1)].E[euN]=e−λk=0∑∞​k!(λeu)k​=exp[λ(eu−1)].

若一段时间内平均收到 3 条请求，Poisson 模型给出没有请求的概率 e−3≈0.0498e^{-3}\approx0.0498e−3≈0.0498，至少两条请求的概率 1−e−3(1+3)≈0.80091-e^{-3}(1+3)\approx0.80091−e−3(1+3)≈0.8009。这里的 λ\lambdaλ 是该时间段的平均次数。到了 Poisson 过程，常用 λ\lambdaλ 表示单位时间速率，长度 ttt 的区间对应参数 λt\lambda tλt。

独立 Poisson 变量之和仍为 Poisson，参数相加。这可由矩母函数乘积得到，也可逐项卷积验证。若计数来自共同冲击，独立性失效，方差便不一定等于均值。

计数矩用阶乘形式更容易计算

从概率质量函数直接求和：

E[N]=e−λ∑k=1∞kλkk!=λe−λ∑j=0∞λjj!=λ.\mathbb E[N]=e^{-\lambda}\sum_{k=1}^{\infty}k\frac{\lambda^k}{k!} =\lambda e^{-\lambda}\sum_{j=0}^{\infty}\frac{\lambda^j}{j!}=\lambda.E[N]=e−λk=1∑∞​kk!λk​=λe−λj=0∑∞​j!λj​=λ.

同理，E[N(N−1)]=λ2\mathbb E[N(N-1)]=\lambda^2E[N(N−1)]=λ2。因为 N2=N(N−1)+NN^2=N(N-1)+NN2=N(N−1)+N，故二阶矩为 λ2+λ\lambda^2+\lambdaλ2+λ，减去均值平方后方差为 λ\lambdaλ。这种下降阶乘 N(N−1)⋯(N−r+1)N(N-1)\cdots(N-r+1)N(N−1)⋯(N−r+1) 的期望等于 λr\lambda^rλr，以后计算 Poisson 积分的高阶矩时很有用。

例如 λ=3\lambda=3λ=3，E[N2]=12\mathbb E[N^2]=12E[N2]=12；不能把“均值为 3”直接平方当作二阶矩 9。差额 3 恰好是计数的不确定性。

设 YYY 服从形状 α\alphaα、速率 β\betaβ 的 Gamma 分布，令 X=1/YX=1/YX=1/Y。变量变换的 Jacobian 为 1/x21/x^21/x2，得到逆 Gamma 密度

E[X]=βα−1(α>1),Var⁡(X)=β2(α−1)2(α−2)(α>2).\mathbb E[X]=\frac\beta{\alpha-1}\quad(\alpha>1),\qquad \operatorname{Var}(X)=\frac{\beta^2}{(\alpha-1)^2(\alpha-2)}\quad(\alpha>2).E[X]=α−1β​(α>1),Var(X)=(α−1)2(α−2)β2​(α>2).
