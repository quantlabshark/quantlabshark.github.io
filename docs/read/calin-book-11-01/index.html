鲨鱼说

协方差，即两个变量偏离各自均值时，共同变化程度的度量。

观测位置时看到的平滑

速度直接受到噪声冲击，位置则把速度再积分一次，所以同一条模拟路径上位置通常比速度更平滑。位置可微且导数为连续速度，并不意味着位置没有随机性；它的随机性由此前全部速度冲击积累而来。

如果只用离散位置差估计速度，测量误差会被差分除以时间步长而放大。缩短采样间隔未必让速度估计更准，需同时考虑测量精度。这正是把运动方程和观测方程分开建模、再用滤波估计速度的动机。

回复速度和噪声幅度均为一，初始速度、位置均为零。两幅图中相同颜色代表同一次试验：位置积累速度，曲线因积分而更平滑。

鲨鱼说

白噪声要通过积分或时间平均来使用。仿真中加入状态的是噪声冲量，方差与时间步长成正比；把它当成普通、逐点有限方差的函数，会破坏尺度。
