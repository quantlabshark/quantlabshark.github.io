27 · 标准化、相关性与主成分分析

从二维数据推导PCA的投影方向，理解尺度、相关性和解释方差，并建立不使用未来信息的预处理流程。

标准化统一变量的比较尺度，相关分析检查特征是否包含重复信息。主成分分析把相关变量转换为若干相互正交的方向，用较少维度描述主要变化。

两列数据其实只表达一个变化

三条记录为(1,2)(1,2)(1,2)、(2,4)(2,4)(2,4)、(3,6)(3,6)(3,6)。第二列始终是第一列两倍，因此知道一列就知道另一列。把两列同时交给模型，增加了输入数量，却没有增加独立信息。

先减去均值(2,4)(2,4)(2,4)，得到(−1,−2)(-1,-2)(−1,−2)、(0,0)(0,0)(0,0)、(1,2)(1,2)(1,2)。样本协方差矩阵为

S=13−1Xc′Xc=(1224).S=\frac1{3-1}X_c'X_c=\begin{pmatrix}1&2\\2&4\end{pmatrix}.S=3−11​Xc′​Xc​=(12​24​).

对角元是各列样本方差，非对角元表示共同变化。因为第二列的单位尺度更大，它的方差也更大；不能据此断言它更重要。

鲨鱼说

协方差，即两个变量偏离各自均值时，共同变化程度的度量。

标准化在改变什么

标准化写作z=(x−μ)/σz=(x-\mu)/\sigmaz=(x−μ)/σ。减均值移动坐标原点，除标准差使不同列使用相近尺度。市值以元计、利润率以小数计时，这一步尤其重要，否则距离和方差几乎完全由市值决定。

缩放参数只能用允许的训练数据估计，再用于后续数据。截面标准化则是在某个日期对当时可见股票计算均值和标准差；它与把所有日期混在一起标准化不是一回事。常数列没有变化，标准差为零，需要删除或单独处理。

PCA寻找的是最大变化方向

取单位方向v\mathbf vv，中心化数据投影为XcvX_c\mathbf vXc​v，投影方差为v′Sv\mathbf v'S\mathbf vv′Sv。第一主成分选择使这个值最大的方向：

max⁡v′v=1v′Sv.\max_{\mathbf v'\mathbf v=1}\mathbf v'S\mathbf v.v′v=1max​v′Sv.

解是最大特征值对应的特征向量。本例特征值为5和0，第一方向为(1,2)/5(1,2)/\sqrt5(1,2)/5​，第二方向与它垂直。投影分数为−5,0,5-\sqrt5,0,\sqrt5−5​,0,5​；只保留第一方向即可重建全部中心化数据。

图中三点落在第一主成分方向上，垂直方向没有离散。箭头是坐标方向，旁边的数值是相应方差，不是未来收益。稍有噪声时，第二特征值会变为小的正数，舍弃它就会产生重建误差。

载荷、分数与解释方差

载荷是方向向量中各原始特征的系数；分数是每条观测在该方向上的坐标。解释方差比例为某个特征值除以所有特征值之和。本例为100%和0%，表示输入变化全部落在一条直线上。

“解释100%输入变化”不等于“预测100%未来收益”。PCA不读取目标标签。一个大方差方向可能来自规模，也可能来自数据错误。一个小方差方向反而可能包含对目标有用的信息。选择主成分数量应同时考虑压缩误差和后续预测验证。

鲨鱼说

PCA方向整体乘以−1仍是同一个答案。因此软件给出的主成分分数越高，并不自动意味着股票越值得买入；交易方向需要另外定义和检验。

标准化后的结果为何不同

下面代码先标准化每列，再进行PCA。两列标准化后完全相同，所以方向系数的绝对值均为1/21/\sqrt21/2​，不同于原尺度的(1,2)/5(1,2)/\sqrt5(1,2)/5​。两种结果对应不同度量空间，并不矛盾。

Python15 行
import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.pipeline import make_pipeline

train = np.array([[1., 2.], [2., 4.], [3., 6.]])
pipe = make_pipeline(StandardScaler(), PCA(n_components=1))
score = pipe.fit_transform(train)
new_score = pipe.transform([[4., 8.]])
pca = pipe.named_steps["pca"]
print("loadings:", pca.components_)
print("variance ratio:", pca.explained_variance_ratio_)
print("scores:", score.ravel(), "new:", new_score.ravel())
assert np.isclose(pca.explained_variance_ratio_[0], 1.0)
assert score.shape == (3, 1)

训练分数的绝对端点约为1.732，中心点为0，解释方差比例为1。新输入(4,8)(4,8)(4,8)使用原训练均值和尺度，投影绝对值约3.464。方向符号可能随实现约定改变，但重建信息不变。

缺失、异常值与中性化

处理缺失时，删除记录会改变覆盖股票，填充值则会改变分布。可用训练期中位数填充，并保留缺失标记。不要把“未披露”直接解释为财务值恰好为零。净利润率超过100%可能来自特殊会计项目或分母很小，先检查来源，再决定是否处理。

缩尾把超出边界的数压回边界，截尾则删除相应记录。两种操作不同；边界应来自训练集或当时截面。中性化可用行业内去均值，或对规模等已知暴露回归取残差。它改变了信号含义：剩余值表示相对同行或同规模公司的偏离。

相关特征多时怎样判断稳定性

若样本数不多而特征很多，估计的主方向可能对少量数据变化敏感。两个特征值很接近时，单个方向可能旋转，联合子空间却较稳定。可以比较不同训练窗口的解释方差、载荷和下游模型，而不是只阅读一次漂亮的载荷表。

处理顺序为：在训练段拟合缺失处理、缩放、PCA及预测模型；对后续记录只调用已拟合变换。任何一步用到未来分布，都可能改变历史坐标，从而污染测试。

练习

本例只保留第二主成分，会保留多少方差？如果把第一方向和全部分数同时乘以−1，重建数据是否变化？

查看解答

第二特征值为0，所以保留0%的输入方差。方向与分数同时反号，二者乘积不变，因此重建数据不变。改变符号只改变坐标命名，不改变几何信息。
