随机利率与零息支付

从贴现因子的条件期望出发，计算高斯累计利率下的债券价格。

连续复利与一笔未来支付

若一笔资金按常数年利率 rrr 连续复利增长，价值满足 dV=rVdtdV=rVdtdV=rVdt，所以经过 τ\tauτ 年后为 V0erτV_0e^{r\tau}V0​erτ。反过来，未来100元折算到现在应乘 e−rτe^{-r\tau}e−rτ。当每时刻利率不同，累计增长指数变成 ∫rsds\int r_sds∫rs​ds。

短利率 rtr_trt​ 描述当前一个很短区间内的利率，到期收益率则是根据整张债券的当前价格换算出的单一等效利率。两者只在特殊情况下相等。下面讨论到期固定支付、期间无票息的模型，并明确所有随机参数都在所指定的定价测度 QQQ 下。

支付、短利率与累计利率

零息债在到期时刻 TTT 支付固定金额 BBB，期间没有票息。若利率确定，时刻 ttt 的价格为 Bexp⁡[−∫tTrsds]B\exp[-\int_t^Tr_sds]Bexp[−∫tT​rs​ds]。当利率随机，未来贴现因子也随机。在给定风险中性测度 QQQ 及相应无套利模型后，价格写成

取期望的是整个指数，而不是先平均利率再指数。指数函数凸，累计利率的不确定性会使这两种计算不同。这里的 QQQ 用于定价；现实测度下的平均利率预测不能不经转换就代入同一价格公式。

白噪声利率的形式例子

如果直接规定累计贴现指数为 rτ+σ(WT−Wt)r\tau+\sigma(W_T-W_t)rτ+σ(WT​−Wt​)，则其条件均值为 rτr\taurτ、方差为 σ2τ\sigma^2\tauσ2τ，期望贴现支付为 Be−(r−σ2/2)τBe^{-(r-\sigma^2/2)\tau}Be−(r−σ2/2)τ。这可以作为高斯指数计算的练习，但这里随机的是累计指数，形式导数中的白噪声不是通常的逐点短利率函数。

在标准短利率模型中，短时间累计噪声经过积分，其方差通常为更高阶；上述形式模型则直接令累计量具有布朗尺度，两者不能混作同一个利率过程。

从价格到收益率

连续复利到期收益率定义为 y(t,T)=−log⁡[P(t,T)/B]/τy(t,T)=-\log[P(t,T)/B]/\tauy(t,T)=−log[P(t,T)/B]/τ。高斯公式给 y=mI/τ−vI/(2τ)y=m_I/\tau-v_I/(2\tau)y=mI​/τ−vI​/(2τ)。收益率是由当前价格与到期支付换算得到的量，不等于未来短利率的每条路径，也不等于当前短利率。

对期限的两个核验

很短期限时，当前短利率尚未来得及大幅变化，累计均值首先近似为 rτr\taurτ。OU 利率噪声先进入利率再被时间积分，所以累计方差首项为 σ2τ3/3\sigma^2\tau^3/3σ2τ3/3，而不是与期限一次方成正比。这能检查是否误把瞬时利率噪声直接当成累计利率噪声。

价格除以支付金额后不应再依赖面值，面值翻倍只使价格翻倍。期限曲线的形状则由当前利率、长期均值、回复速度和噪声共同决定；同一个当前利率可以对应不同期限结构。

鲨鱼说

随机贴现先看累计利率的分布。若累计量正态，价格计算只需要它的均值和方差；但这两个参数必须属于同一个定价测度。
