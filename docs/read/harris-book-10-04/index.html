10.4 信息成本、交易冲击与市场效率

理解知情交易的利润边界、竞争进入以及公共信息的作用。

好信息还需要能够成交

知情交易的净收益取决于估值差、可建立数量、价格冲击和研究成本。信息非常准确，但市场很小，买入少量就使价格上升到估值附近，利润也可能有限。相反，较小但可验证的优势，在较深市场中可能支持更多数量。

自拟简化模型设每单位价值优势为 aaa，买入 QQQ 单位使平均成交价格增加 bQbQbQ，其中 b>0b>0b>0 表示冲击程度，研究等固定成本为 ccc。预期净利润为

Π(Q)=aQ−bQ2−c.\Pi(Q)=aQ-bQ^2-c.Π(Q)=aQ−bQ2−c.

若暂不计风险和资金约束，最大值位于 Q∗=a/(2b)Q^*=a/(2b)Q∗=a/(2b)。这个式子说明数量不是越大越好：新增单位既有信息收益，也会抬高整笔执行成本。下面令数量以股计，a=0.20a=0.20a=0.20 元/股、b=0.001b=0.001b=0.001 元/股平方、c=5c=5c=5 元，利润以元计。

Python8 行
a, b, c = 0.20, 0.001, 5.0
def profit(q):
    return a * q - b * q * q - c
q_star = a / (2 * b)
for q in (0, 50, 100, 150, 200):
    print(q, round(profit(q), 2))
print("模型最优数量：", q_star)
assert q_star == 100 and abs(profit(q_star) - 5) < 1e-10

这里的 Q=0Q=0Q=0 仍计入已发生研究成本；若比较是否开展整项研究业务，还需另设完全不进入、成本为零的方案。该模型没有收益波动和融资限制，不能直接作为真实头寸计算器。

图中使用正文的二次冲击模型。规模扩大同时增加信息收益与冲击成本；两者的边际变化相等时，净利润达到最大值。此例最优数量为 100，利润为 5。

准确之外还要看拥挤程度

很多交易者同时用相同信息得出相同结论，会争夺有限流动性，价格更快调整，利润被压缩。独特且准确的信息可能减少这种竞争。独特但错误的判断则只是更便宜地犯错，因此“与众不同”不能单独证明优势。

较高利润吸引研究者进入，增加的信息交易使价格更充分，剩余机会减少。长期能够留在市场的机构，需要覆盖数据、人员、系统、执行及资本成本。短期盈利可能源于运气，短期亏损也可能来自偶然不利事件，进入和退出因而不会立即完成。

为什么价格不会始终包含全部信息

若所有信息已经无成本地进入价格，继续花钱研究就无法获得补偿；若没人研究，一部分信息又不会被发现和使用。这意味着，信息价格与研究激励共同形成均衡，价格可以较有效，却未必每时每刻完全准确。

投资、融资和套保等需求使缺少特殊价值信息的人仍愿意交易。知情者可能从这些订单取得利润，非知情者则获得其他服务。若交易只在一群纯粹为信息利润参与的人之间进行，整体相对交易利润无法让每个人同时获得正收益。

三种信息范围与成本约束

弱式效率关注历史价格信息，半强式效率关注公开信息，强式效率还包括私人信息。它们区别的是被纳入价格的信息集合。实证检验还必须说明正常风险补偿与成本模型，发现可预测收益不自动等于发现可实现的异常利润。

市场微观结构进一步问：信息是否值得获取，获取之后是否能以合理成本成交。很昂贵、影响很小的信息可能不会被充分研究。因此市场效率是信息、竞争、风险和执行条件共同作用的结果。

鲨鱼说

信息集，即截至指定时点已经获得的全部信息。

公共信息可以减少重复支出

及时、可理解的披露和统计数据，使更多人能够形成价值判断，可能同时改善价格信息并减少少数人的独占优势。若信息难以解释，分析能力仍有价值，但共享基础数据可以降低重复收集成本。

制度比较应看边际变化：增加多少信息、改善多少交易条件、花费多少成本。不能因为信息价格整体有重要作用，就认定任何增加速度或研究支出的安排都值得。

练习

一种信号在不计成本时平均每单位有 0.02 元收益，实际往返成本为 0.03 元。它是否已经证明存在可实施的超额收益策略？

查看解答

没有。按给定口径，扣成本后的均值为负，且还需评估风险、估计误差和容量。发现统计关系与形成有经济收益的交易策略，是两个需要分别验证的步骤。
