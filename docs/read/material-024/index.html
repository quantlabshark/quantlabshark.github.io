1. 命中后的射手识别

题目

一次试验中，A、B、C 出手的概率分别为 0.3、0.4、0.2，余下 0.1 的概率无人出手；每次至多一人出手。三人的命中率分别为 0.4、0.3、0.3。已知本次命中，求出手者为 A 的条件概率。

考点：条件概率方向；联合事件；全概率。

查看分析与解答

必要知识

命中率 P(H|A) 是已知 A 出手后命中的概率；后验 P(A|H) 是已经命中后反推 A 出手的概率。两者条件方向不同，需结合各人原先出手概率转换。

分析思路

先算每名射手对全部命中事件贡献多少，再在命中总量中归一化。无人出手是第四种互斥情形，但对命中贡献零。

解答步骤

设重复一千次试验，平均约三百次 A 出手，其中一百二十次命中；B 四百次出手、约一百二十次命中；C 二百次出手、约六十次命中。合计三百次命中，其中一百二十次来自 A。

记命中事件为 HHH。先计算三种“出手且命中”的联合概率：A 为 0.3×0.4=0.120.3\times0.4=0.120.3×0.4=0.12，B 为 0.4×0.3=0.120.4\times0.3=0.120.4×0.3=0.12，C 为 0.2×0.3=0.060.2\times0.3=0.060.2×0.3=0.06。这些事件互斥，无人出手时不能命中，故 P(H)=0.30P(H)=0.30P(H)=0.30。

在所有命中的试验中，A 所占比例为 P(A∣H)=P(A∩H)P(H)=0.120.30=0.4.P(A\mid H)=\frac{P(A\cap H)}{P(H)}=\frac{0.12}{0.30}=0.4.P(A∣H)=P(H)P(A∩H)​=0.300.12​=0.4. 不能直接回答 A 的命中率 0.4：本题恰巧数值相同，但所问是“已命中后来自谁”，条件方向相反。

若只把三名射手的出手概率先归一化到总和一，三者同时除以 0.9，最终后验中公共因子会消去，仍为 0.4。但直接忽略出手概率、只比较命中率，则会给出 0.4/(0.4+0.3+0.3)，本题数值巧合相同却没有正确的概率推理。

同类问题

看到“已观察到结果，求来源”时，先列来源先验乘结果似然，再除以全部来源贡献之和。用频数表能直观看出分子与分母各包含哪些试验。

2. 三人相遇

题目

三人独立地在 9:00 至 10:00 间均匀到达同一地点，每人停留 10 分钟。即使超过 10:00，也停满 10 分钟。求三人至少有一段共同在场时间的概率。

考点：共同在场；极差；边界积分。

查看分析与解答

必要知识

每人的在场区间为到达时刻至十分钟后。所有区间有公共部分，当且仅当最晚到达不晚于最早离开，即最大到达时间减最小到达时间不超过十分钟。

分析思路

将一小时归一化到单位区间，按最早到达者的时间积分。最早者靠近终点时，可到达区间会缩短，所以需要分段，不能始终用固定窗口长度。

解答步骤

指定第一人最早且到达于 [t,t+dt]。若 t≤5/6，另两人各自必须落在长 1/6 的窗口内，联合概率为 (1/6)²；若 t>5/6，另两人仍不能晚于一小时到达，窗口只有 1−t。最早者唯一的概率为一，因此最后乘三不会重复计数。

把到达时间除以 60 分钟，记为独立的 U1,U2,U3∼U(0,1)U_1,U_2,U_3\sim U(0,1)U1​,U2​,U3​∼U(0,1)。设最早到达时刻为 mmm，最晚为 MMM。最早者在 m+1/6m+1/6m+1/6 离开，因此相遇等价于 M−m≤aM-m\le aM−m≤a，其中 a=1/6a=1/6a=1/6。

指定其中一人为最早者。若他在 t≤1−at\le1-at≤1−a 到达，其余两人都要落在 [t,t+a][t,t+a][t,t+a]，概率密度贡献为 a2dta^2dta2dt；若 t>1−at>1-at>1−a，可用区间缩短为 [t,1][t,1][t,1]，贡献为 (1−t)2dt(1-t)^2dt(1−t)2dt。最早者有 3 种选择，故 P=3∫01−aa2dt+3∫1−a1(1−t)2dt=3a2−2a3=227.P=3\int_0^{1-a}a^2dt+3\int_{1-a}^1(1-t)^2dt=3a^2-2a^3=\frac2{27}.P=3∫01−a​a2dt+3∫1−a1​(1−t)2dt=3a2−2a3=272​. 恰在离开时相遇的事件概率为零，不影响结果。

积分后 3a²(1−a)+a³=3a²−2a³；代 a=1/6 得 1/12−1/108=2/27≈7.407%。虽然每人可停留到十点以后，到达时间本身仍限制在十点前，这解释了末端截短来源。

同类问题

若若干相同长度时间窗口要有公共交集，可先转成开始时刻的极差约束。积分时同时检查到达域和停留域，避免把离开时间限制误加到题目中。

3. 推广与模拟

题目

N≥1N\ge1N≥1 人独立均匀在一小时内到达，每人停留 10 分钟。求所有人同时在场的概率，并用模拟检验 N=3N=3N=3 的结果。

考点：人数推广；最早者分解；模拟误差。

查看分析与解答

必要知识

对 N 个连续独立到达时间，最早者几乎必然唯一，因此可以指定一人最早再乘 N。一次模拟输出成功或失败，相当于一个伯努利变量；M 次独立重复的平均有方差 p(1−p)/M。

分析思路

沿用三人问题的最早时刻积分，把另外两人的窗口概率推广为 N−1 次幂。模拟只检查最大最小差，再用标准误判断结果与理论是否相符。

解答步骤

内层尾段积分满足 ∫₁₋ₐ¹(1−t)^(N−1)dt=aᴺ/N，所以乘 N 后恰为 aᴺ。与前段 Na^(N−1)(1−a) 合并得到公式，不能漏掉这一边界修正。

令 a=1/6a=1/6a=1/6，按最早到达者的时刻积分。指定最早者后，另 N−1N-1N−1 人必须落在长为 aaa 的窗口内；窗口靠近一小时末端时需截短。因此 pN=N∫01−aaN−1dt+N∫1−a1(1−t)N−1dt=NaN−1−(N−1)aN.p_N=N\int_0^{1-a}a^{N-1}dt+N\int_{1-a}^1(1-t)^{N-1}dt=Na^{N-1}-(N-1)a^N.pN​=N∫01−a​aN−1dt+N∫1−a1​(1−t)N−1dt=NaN−1−(N−1)aN. N=1N=1N=1 时概率为 1，N=3N=3N=3 时为 2/272/272/27。

模拟一次就是生成 NNN 个均匀数，检查最大值减最小值是否不超过 aaa。重复 MMM 次，命中比例 p^\hat pp^​ 的标准误约为 pN(1−pN)/M\sqrt{p_N(1-p_N)/M}pN​(1−pN​)/M​。代码用固定随机种子，并将偏差限制在 6 个标准误内。每次只求极值，时间为 O(N)O(N)O(N)。共 O(MN)O(MN)O(MN)，不需要排序。

同类问题

模拟应先把数学事件转为最小判定条件，再报告误差规模。只比较几个小数是否一致容易误判；标准误说明增加样本量能改善到什么程度。

4. 顺序与随机内存访问

题目

对一个远大于处理器缓存的数组，每个元素读取一次。比较按地址顺序读取与按随机排列读取的性能，并解释可能的差异。

考点：缓存行；预取；带宽与延迟。

查看分析与解答

必要知识

CPU 通常不能以寄存器速度直接访问全部内存，会按缓存行把相邻字节搬入较小缓存。带宽表示单位时间能搬多少数据，延迟表示一次请求多久返回，两者决定不同访问模式的瓶颈。

分析思路

分别考察一次取回的数据能利用多少、未来地址能否提前知道、同时能发出多少请求。再设计不混入随机数生成和死代码消除的对照计时。

解答步骤

若每行六十四字节、元素八字节，顺序读八个元素通常共用一次缓存行载入。巨大数组随机排列读取时，相邻元素可能相隔很久才使用，缓存行已被逐出，导致同一行反复载入。实际次数取决于缓存容量与随机顺序。

缓存通常按一整行搬运数据。例如一行 64 字节、每个元素 8 字节，一次取回的内容包含 8 个相邻元素。顺序读时，这 8 个元素很快都会使用；随机读时，刚取回的一行可能只使用其中一个元素就转向别处。

顺序地址还容易被硬件预取器预测，并能形成多笔连续内存请求，使运行时间接近“总读取量÷有效带宽”。若随机访问存在指针依赖，后一次地址要等前一次读完才知道，性能更容易受单次访存延迟限制。跨大量内存页还会增加 TLB 未命中。

比较时应固定数组大小、元素类型、访问次数与结果使用方式，并预先生成随机下标，避免把随机数生成开销算入访存。若整个数组已在缓存中，两种方式的差距会缩小。

随机下标数组若预先可知，处理器仍可能并行发出多次读取；链表式随机指针追踪则下一地址依赖当前结果，更难隐藏延迟。因此“随机访问必然串行”不准确，应区分独立随机索引与依赖链。计时可累加读出值并最终使用，确保编译器没有删除整个循环。

同类问题

性能题先画数据移动路径与依赖关系，再判断计算、带宽、延迟还是地址转换限制性能。用相同数据量和可控访问顺序做对照，结论才有可解释性。

5. 等相关范围

题目

n≥2n\ge2n≥2 个随机变量均值为 0、方差为 1，任意两个不同变量的相关系数都是 rrr。求 rrr 的全部可行范围，说明端点的含义。

考点：等相关矩阵；线性组合方差；端点。

查看分析与解答

必要知识

相关矩阵对角线一、非对角线 r。向量全一代表所有变量同方向相加；与它正交的方向代表权重和零的相对差异。不同方向的方差都不能为负。

分析思路

先看总和的方差得到负相关下界，再看两个变量之差得到上界，最后用矩阵分解确认这两类方向覆盖所有可能组合。

解答步骤

Var(ΣX_i)=n+n(n−1)r≥0，故 r≥−1/(n−1)。Var(X_i−X_j)=2−2r≥0，故 r≤1。n 增大时下界靠近零，意味着大量变量不能同时彼此强烈反向。

相关矩阵为 R=(1−r)I+r11TR=(1-r)I+r\mathbf1\mathbf1^TR=(1−r)I+r11T。沿全 1 向量方向，R1=[1+(n−1)r]1R\mathbf1=[1+(n-1)r]\mathbf1R1=[1+(n−1)r]1；对任意与它正交的向量 vvv，有 1Tv=0\mathbf1^Tv=01Tv=0，所以 Rv=(1−r)vRv=(1-r)vRv=(1−r)v。

方差不能为负，即任意 vvv 都应满足 vTRv≥0v^TRv\ge0vTRv≥0。因此两个特征值必须非负： 1−r≥0,1+(n−1)r≥0,1-r\ge0,\qquad1+(n-1)r\ge0,1−r≥0,1+(n−1)r≥0, 从而 −1/(n−1)≤r≤1-1/(n-1)\le r\le1−1/(n−1)≤r≤1。该条件也充分，例如用矩阵平方根作用于独立标准正态向量即可构造。

r=1r=1r=1 时所有标准化变量几乎必然相同；r=−1/(n−1)r=-1/(n-1)r=−1/(n−1) 时它们的和方差为零，故和几乎必然为零。两端都合法，但矩阵不可逆。

n=2 时下界为 −1，两个变量可以互为相反数；n=3 时下界升为 −1/2。下界处总和恒零，但单个变量仍方差一；上界处任意差恒零，全部变量相同。两个端点的奇异性来自这些确切线性关系。

同类问题

相关可行性可以通过组合方差理解。零特征值不表示单个变量没有波动，而是存在某种非零权重组合被严格抵消。

6. 构造等相关变量

题目

已知 n≥2n\ge2n≥2 个独立随机变量 Z1,…,ZnZ_1,\ldots,Z_nZ1​,…,Zn​ 均值 0、方差 1。给定 −1/(n−1)≤r≤1-1/(n-1)\le r\le1−1/(n−1)≤r≤1，构造方差均为 1、两两相关系数为 rrr 的变量 X1,…,XnX_1,\ldots,X_nX1​,…,Xn​。

考点：均值方向；中心化方向；协方差构造。

查看分析与解答

必要知识

令平均值 Z̄=ΣZ_i/n。每个 Z_i 可拆为 Z_i−Z̄ 与共同均值 Z̄。前者所有分量之和零，后者所有分量相同；在原变量协方差为单位阵时，这两部分不相关。

分析思路

分别调整共同方向与相对差异方向的波动。目标相关为负时共同方向应更弱、差异方向更强，因此只用“一个共同因子加独立噪声”的正相关构造不够。

解答步骤

不用矩阵也能直接写 Xi=1−r(Zi−Zˉ)+1+(n−1)rZˉX_i=\sqrt{1-r}(Z_i-\bar Z)+\sqrt{1+(n-1)r}\bar ZXi​=1−r​(Zi​−Zˉ)+1+(n−1)r​Zˉ。这里平方根为标准差倍数；乘方差倍数本身会把协方差放大两次。

先把 ZZZ 分成两个互相正交的部分：公共均值方向 QZQZQZ 和去均值方向 PZPZPZ。其中 Q=11T/nQ=\mathbf1\mathbf1^T/nQ=11T/n，P=I−QP=I-QP=I−Q，满足 P2=PP^2=PP2=P、Q2=QQ^2=QQ2=Q、PQ=0PQ=0PQ=0。目标矩阵在这两个方向上的方差倍数分别是 1+(n−1)r1+(n-1)r1+(n−1)r 和 1−r1-r1−r，因而应分别按它们的平方根缩放。

据此取 X=[1−rP+1+(n−1)rQ]ZX=[\sqrt{1-r}P+\sqrt{1+(n-1)r}Q]ZX=[1−r​P+1+(n−1)r​Q]Z。其协方差为 (1−r)P+[1+(n−1)r]Q=(1−r)I+r11T(1-r)P+[1+(n-1)r]Q=(1-r)I+r\mathbf1\mathbf1^T(1−r)P+[1+(n−1)r]Q=(1−r)I+r11T，对角线为 1、非对角线为 rrr，满足要求，包括允许范围内的负相关。

有 Var(Z̄)=1/n、Var(Z_i−Z̄)=1−1/n、Cov(Z_i−Z̄,Z_j−Z̄)=−1/n。两部分交叉协方差零，故 Var(X_i)=(1−r)(1−1/n)+[1+(n−1)r]/n=1；i≠j 时协方差为 −(1−r)/n+[1+(n−1)r]/n=r。n=3、r=−1/2 时公共项消失，X_i=√(3/2)(Z_i−Z̄)，和恒零。

同类问题

构造指定协方差时可按正交方向分别缩放标准随机向量。正态性不是计算协方差所必需；若额外需要联合正态，再把原始 Z 取为独立标准正态。

7. 等角向量数量

题目

在 Rn\mathbb R^nRn 中选择非零向量，要求任意两向量之间的通常夹角都相同且不为 0。最多能选多少个？请同时给出上界与达到上界的构造。

考点：单位向量；Gram 矩阵；秩下界。

查看分析与解答

必要知识

单位向量的内积等于夹角余弦。m 个向量的 Gram 矩阵记录全部两两内积，其秩不超过这些向量所在空间维数。题目使用有方向向量之间的通常夹角，不能改成把正负方向视作同一直线的锐角。

分析思路

将几何条件变成等相关形状的 Gram 矩阵，利用秩限制求数量上界，再用正则单纯形顶点构造达到上界的向量。

解答步骤

若共同余弦 r<1，Gram 矩阵在 m−1 维的和为零方向上特征值为 1−r>0，所以至少有 m−1 个独立方向。嵌入 n 维空间要求 m−1≤n，这就是 n+1 的来源。

夹角与长度无关，先把所有向量缩成单位向量。将它们作为矩阵 VVV 的列，Gram 矩阵 G=VTVG=V^TVG=VTV 的秩不超过空间维数 nnn。另一方面，共同夹角余弦为 r<1r<1r<1 时，GGG 在与全 1 向量正交的子空间上等于 (1−r)I(1-r)I(1−r)I，这个子空间维数为 m−1m-1m−1。

构造可以从 Rn+1\mathbb R^{n+1}Rn+1 的标准基开始，令 wi=ei−1/(n+1)w_i=e_i-\mathbf1/(n+1)wi​=ei​−1/(n+1)。它们都位于坐标和为零的 nnn 维子空间，且归一化后不同向量内积为 −1/n-1/n−1/n。

由于 1−r>01-r>01−r>0，rank⁡(G)≥m−1\operatorname{rank}(G)\ge m-1rank(G)≥m−1，而 rank⁡(G)≤n\operatorname{rank}(G)\le nrank(G)≤n，故 m≤n+1m\le n+1m≤n+1。上述构造恰有 n+1n+1n+1 个向量，因此最大数量为 n+1n+1n+1。

构造中 ||w_i||²=1−1/(n+1)=n/(n+1)，不同 i、j 的内积为 −1/(n+1)，归一化后等于 −1/n。n=2 时得到平面内相隔一百二十度的三个向量；n=3 时对应四面体中心指向四顶点的四个向量。

同类问题

大量成对几何约束可转成 Gram 矩阵的正定性和秩约束。上界证明与达到界的构造缺一不可；同时注意向量角与无向直线角的定义差别。

8. 超过物理内存

题目

一台物理内存为 16 GB 的计算机上，某程序申请并可能使用 24 GB 内存。分析申请时与实际访问时可能发生的情况，并说明应观测哪些指标。

考点：虚拟内存；工作集；按需调页。

查看分析与解答

必要知识

虚拟地址是程序看到的地址范围，常驻集是当前实际占用的物理页，工作集是某段时间反复需要访问的页。申请二十四 GB 不代表同一时刻已把二十四 GB 数据放进物理内存。

分析思路

分别分析地址申请、首次触碰以及持续访问三个阶段。每阶段资源限制不同，因此需要用提交量、常驻量和缺页活动共同判断。

解答步骤

例如只申请二十四 GB 地址却只写入一 GB，常驻占用可能接近实际触碰部分；若对全部二十四 GB 反复随机更新，而可用内存不足十六 GB，就可能不断调出再调入页面。即使程序未报错，也可能因存储访问而大幅变慢。

申请地址空间与实际占用物理页是两个阶段。操作系统可能先保留一段虚拟地址，直到程序写入某页时才分配后备存储；也可能在分配时就检查提交额度，直接返回失败。

若程序确实反复访问 24 GB，而可用物理内存小于工作集，系统可能把不活跃页写入交换区。随后又访问这些页时要从磁盘读回。频繁来回换页称为抖动，程序仍可能运行，但速度明显下降。若交换区、地址空间或提交额度不足，也可能分配失败或被系统终止。

诊断时分别看虚拟地址量、已提交内存、常驻集、缺页速率和磁盘活动。仅看到申请量超过物理内存，尚不能判断程序一定崩溃。减少同时驻留的数据、分块处理或使用外存算法，通常比反复申请更大的内存有效。

顺序分块处理可把同时使用的数据压在可用内存内：读一块、计算并输出，再处理下一块。若算法需要随机访问全部数据，应重新考虑外存索引、压缩或更大内存；仅把分配接口改成内存映射并不会自动消除工作集过大的问题。

同类问题

诊断内存问题先区分申请量与实际活跃量，再观察是否存在持续换页。解决方法应针对访问模式和驻留需求，而非只看总文件或数组大小。

9. 排序规模估计

题目

对 10510^5105、10810^8108、101010^{10}1010 个 8 字节整数做比较排序。用快速排序的平均工作量与存储量估计“一秒完成”是否合理，并指出还需要哪些机器信息。

考点：运算规模；内存预算；吞吐估算。

查看分析与解答

必要知识

大 O 给增长趋势，不直接给秒数。估算耗时还需把操作数除以机器对应操作的有效吞吐，且一次比较排序还包含分支、交换与访存。存储是否容纳则是独立约束。

分析思路

对每个 n 同时算 nlog₂n 与 8n，再检查一秒内需要的比较吞吐和数据搬运能力。超出内存后，应改用外存排序的成本模型。

解答步骤

10⁸ 的 log₂ 约 26.58，因此工作量尺度约 2.66×10⁹；10¹⁰ 的 log₂ 约 33.22，对应 3.32×10¹¹。这里系数取一仅作数量级估计，具体快速排序实现的平均比较数还带常数。

先分两笔账。运算账用 nlog⁡2nn\log_2nnlog2​n 估计比较数量，内存账用 8n8n8n 估计原数组字节数。即使机器平均每秒能完成 10910^9109 次这样的比较，三种规模仅比较部分也分别约需 0.0017、2.7、332 秒。这个吞吐只是用于演算的假设，未包含交换元素和访存。

数组放不进内存时，问题已变为外存排序，磁盘读写可能成为主要成本。实测应说明 CPU、线程数、可用内存、输入分布及是否包含数据读取；可先对较小规模计时，再检查扩规模时是否出现缓存或内存拐点。

三种规模的比较量约为 1.66×1061.66\times10^61.66×106、2.66×1092.66\times10^92.66×109、3.32×10113.32\times10^{11}3.32×1011，原数组分别占约 0.8 MB、0.8 GB、80 GB。第一种规模一秒完成可能合理，后两种须结合吞吐量和可用内存判断。快速排序的最坏时间还可能退化为 O(n2)O(n^2)O(n2)。

八十 GB 原数组若有效读取带宽假设为每秒二十 GB，仅完整读一遍也需四秒，更不用说排序多次访问。这个带宽是演算参数，应换成实际机器测量值。多线程能提高吞吐，但还受内存带宽、分区负载与同步成本限制。

同类问题

性能估算至少列出运算、内存和输入输出三笔账。先用下界或数量级排除明显不可能的目标，再用小规模实测估计常数和性能拐点。

10. 环境变量

题目

在 SSH 登录的 shell 中执行 export MODE=test 后，分别启动子程序、打开另一独立会话、退出后重新登录。哪些进程通常能读到这个值？怎样使以后登录时自动设置？

考点：进程环境；父子继承；配置加载。

查看分析与解答

必要知识

环境变量属于进程状态。启动子进程时通常复制父进程环境，之后两份环境各自变化；export 标记 shell 变量需要传给将来启动的子进程，并不广播到整台机器。

分析思路

画出当前 shell、它的子程序和另一个 SSH 会话的进程关系，逐个判断是否继承到设置后的环境。持久化则依靠新会话启动时重新读配置。

解答步骤

当前 shell 执行 export 后再启动 Python，Python 可读取 MODE=test；已经启动的旧 Python 不会随之改变。子程序把自己的 MODE 改为 prod，也不会把父 shell 的 test 改掉，继承方向与修改范围要分开。

环境变量是进程附带的一组字符串键值。export MODE=test 将变量加入当前 shell 的环境，随后由它创建的子程序通常继承该值；已经运行的其他进程以及父进程不会被追溯修改。

另一条独立 SSH 会话由登录服务创建，不是刚才 shell 的子进程，因此不会因为该次 export 自动获得变量。退出后重新登录也是新进程，临时设置一般消失。

若希望每次登录自动设置，应在实际使用的 shell 所读取的登录配置中加入赋值，或在服务管理器的环境配置中声明。验证时分别在父 shell、子程序和新会话中读取变量，就能区分“继承”与“重新执行配置”。

以 Bash 为例，交互式非登录 shell 通常读取 .bashrc，登录 shell 读取其登录配置链；具体文件取决于启动方式。应把设置放进实际会执行的位置，再重新登录验证。服务由服务管理器启动时通常不读取个人交互 shell 配置，需要在服务环境中单独设置。

同类问题

环境配置问题可按“谁启动了谁、启动时有哪些变量、读取了哪个配置文件”排查。临时 export、启动脚本和服务配置对应不同生命周期。
