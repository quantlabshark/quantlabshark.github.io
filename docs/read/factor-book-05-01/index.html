基础理论与原理

5.1 估值与财务质量怎样共同影响收益

计算F-Score和G-Score，区分价格便宜、财务健康和成长持续性，并构造预期差组合。

低市盈率为何可能没有便宜可占

两家公司股价都是10元，过去一年每股利润都是1元，市盈率均为10倍。甲的利润主要来自稳定经营，乙有0.8元来自出售资产。若下一年不再出售资产，乙的持续盈利可能只有0.2元。相同的历史PE，包含了不同的未来现金流前景。

PE、PB、PS和PCF分别是价格与盈利、账面权益、销售收入、经营现金流的比值，统称价格乘数。分母为正且可比时，乘数较低表示相对该项基本面更便宜；亏损导致负PE时，数值排序已不能解释为“越低越便宜”。

价值因子按估值排序，研究一组股票的平均表现。基本面分析进一步考察盈利、资产和现金流能否持续。历史美国研究在低估值组合中仍观察到超过一半股票随后超额收益为负，说明组合平均优势不等于每只成分股都具有优势。2014年Amazon与IBM估值悬殊的案例同样说明，脱离成长前景比较PE会遗漏重要信息。

用九项财务条件计算F-Score

F-Score把财务健康拆为九项条件，每项满足得1分，否则得0分，总分0至9。这里采用A股历史实证的会计口径：

维度 条件 需要先理解的量
盈利 ROA为正；ROA同比提高 ROA为不含少数股东损益的滚动净利润除以平均总资产
现金质量 经营现金流率为正；应计利润为负 现金流率为滚动经营现金流净额除以平均资产；此处应计项为营业利润减经营现金流，再除以平均资产
偿债与融资 长期负债率下降；流动比率提高；过去一年无增发或配售 流动比率为流动资产除以流动负债
经营效率 毛利率提高；资产周转率提高 毛利率比较销售毛利与收入；周转率比较收入与资产

“同比”比较上年同期，减少季节性影响；滚动指标把最近四个季度连在一起，避免只看一个淡季或旺季。现金流与会计利润的差异有助于识别利润是否已经转化成现金，不能把两者当成同一张表中的同一数字。

下面用连续两年的自拟财表计算九项条件。金额单位均为百万元，表中平均资产已按统一季度口径计算；利润和现金流均为对应年度滚动值。

ROA由5%升至6.6667%，本年CFOA为8.3333%。应计项为(11−10)/120=0.8333%(11-10)/120=0.8333\%(11−10)/120=0.8333%，并非负数。长期负债率由30%降至25%，流动比率由1.6升至2.2，毛利率由30%升至35%，资产周转率由1.5降至1.4。根据这组数值逐项计分：

Python26 行
previous = dict(assets=100, net=5, operating=8, cashflow=7,
                debt=30, current_assets=40, current_debt=25,
                sales=150, cost=105)
current = dict(assets=120, net=8, operating=11, cashflow=10,
               debt=30, current_assets=55, current_debt=25,
               sales=168, cost=109.2, issued=True)
def ratios(d):
    return dict(roa=d['net']/d['assets'], cfoa=d['cashflow']/d['assets'],
                accrual=(d['operating']-d['cashflow'])/d['assets'],
                leverage=d['debt']/d['assets'],
                liquidity=d['current_assets']/d['current_debt'],
                margin=1-d['cost']/d['sales'], turnover=d['sales']/d['assets'])
p, c = ratios(previous), ratios(current)
signals = {'ROA为正': c['roa']>0, 'ROA提高': c['roa']>p['roa'],
           '经营现金流为正': c['cfoa']>0, '应计利润为负': c['accrual']<0,
           '长期负债率下降': c['leverage']<p['leverage'],
           '流动比率提高': c['liquidity']>p['liquidity'],
           '无增发配售': not current['issued'],
           '毛利率提高': c['margin']>p['margin'],
           '资产周转率提高': c['turnover']>p['turnover']}
score = sum(signals.values())
for name, value in signals.items():
    print(name, int(value))
print('本年比率', {k: round(v, 6) for k, v in c.items()})
assert score == 6
print('F-Score =', score)

常用分组为0—3分、4—6分、7—9分。这样比为每个分数单独建组更容易获得足够的股票数。6分表示六项条件成立，没有包含各项改善幅度；缺失财报也不能直接当作经营状况差而记0分。

鲨鱼说

“现金流好于利润”通常是检查盈利质量的线索，但不同评分表的利润口径可能不同。F-Score此处使用营业利润减经营现金流，G-Score则使用ROA减CFOA。复算时应照着会计科目建立数据字典，不能只凭“应计利润”四个字复用同一列。

高估值公司的成长质量：G-Score

低BM意味着价格相对账面权益较高。这类公司可能有尚未充分体现在账面上的研发、品牌和成长机会，也可能只是价格过高。G-Score从八项条件评价这种成长是否有财务支撑。

维度 得1分的条件
当前盈利 ROA高于行业中位数；经营现金流率CFOA高于行业中位数；ROA−CFOA为负
未来投入 研发费用、销售费用、资本支出分别除以平均资产，高于行业中位数
稳定性 过去三年季度ROA方差低于行业中位数；季度收入同比增速方差低于行业中位数

除应计条件外，各项都与同行业比较。研发密集行业和公用事业的正常投入水平不同，直接跨行业比较会把商业模式差异当成质量差异。费用化的研发和广告会压低当前利润，但可能支持未来经营。A股实证因数据可得性用销售费用代替广告费用。投入指标只记录投入程度，项目产出仍需后续检验。

设公司研发前利润为30、现金研发支出为12。若当期全部费用化，利润为18。若在一个自拟分析口径中将12计入资产、按三年等额摊销，当期摊销4，利润为26，期末新增未摊销资产8。两种处理本期都付出12现金，却报告不同利润与资产。

这个例子解释投入为何可能压低当期盈利，资本化分析如何把影响分摊到未来。能否在正式报表资本化仍取决于适用准则和项目条件，不能统一将研发全部资本化。

G-Score通常按0—1、2—5、6—8分组。历史A股季度资产负债与利润数据、现金流数据起始时间不同，2005年前两个三年方差指标缺失较多，因此该时期把中组调整为2—4分、高组调整为5—8分。

这个调整改变了可用信息集，复现时需要保留。

BM与G-Score做 3×33\times33×3 独立排序后，2000—2019年的等权结果在低BM组中具有一定区分力，市值加权时高G-Score组的夏普比率却未保持优势。这表明评分的实际作用与规模分布和权重有关。

把市场预期与财务状态放在同一张表

高BM、低估值可看作市场预期较低；低BM、高估值可看作市场预期较高。F-Score则提供财务状态的代理。两者交叉后，有两类尤其值得检验：价格便宜但财务较强，价格昂贵但财务较弱。

使用图中独立分组的思路，将BM和F-Score各分三档，得到九组。预期差组合定义为

rgap=r高BM,高F−r低BM,低F.r_{gap}=r_{\text{高BM,高F}}-r_{\text{低BM,低F}}.rgap​=r高BM,高F​−r低BM,低F​.

它比较“便宜且较强”与“昂贵且较弱”。另设非预期差对照：raligned=r高BM,低F−r低BM,高Fr_{aligned}=r_{\text{高BM,低F}}-r_{\text{低BM,高F}}raligned​=r高BM,低F​−r低BM,高F​，再与仅按BM构造的普通价值组合比较。如果优势主要集中在预期差组，基本面与价格的匹配关系就提供了额外解释。

这些分组没有直接观察到真实内在价值。预期差机制还可通过后续业绩公告验证：潜在低估公司的公告收益是否较好，分析师是否上调预测，潜在高估公司是否呈相反变化。价格与盈利预测的共同修正，比单独一条收益曲线提供更多机制证据。

历史A股检验的收益与基准

2000—2019年等权预期差组合月均收益1.43%，普通价值组合0.65%，非预期差组合0.19%。前者的Newey–West调整 ttt 值为5.63。市值加权预期差组合月均收益1.31%，对照组合0.23%。

检验采用CAPM、市场规模价值三因子、加入盈利的LSL四因子，财务因子使用已披露季报并按月更新。等权预期差组合的三个基准α依次约1.44%、1.09%、0.68%，最后一项仍有3.89的 ttt 值。市值加权后，四因子α的 ttt 值降至1.88，说明盈利暴露解释了较多收益。

非预期差组合相对CAPM的α接近0，加入风格因子后的α则显著为负。比较多种基准与两种权重，有助于区分“财务筛选增加的信息”和“重新配置了已有因子”。这些数值是历史组合的毛收益统计，实施净收益还要扣除换手、成交冲击和借券费用。

练习

公司A为高BM、F-Score8分，公司B为低BM、F-Score2分，公司C为高BM、F-Score1分。预期差组合的多头和空头分别更接近哪家公司？为什么不能因为C更便宜就与A作同样处理？

查看解答

多头对应A，空头对应B。C虽然价格相对账面权益较低，但财务评分也低，低价可能反映经营恶化。应进一步查看哪些评分项恶化、资产是否减值以及现金流变化，再判断低估值是否仍有基本面支撑。

资料来源：石川、刘洋溢、连祥斌，《因子投资：方法与实践》，2020年，PDF第192—204页。
