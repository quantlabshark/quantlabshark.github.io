限价与市价的脉冲控制

区分持续挂单与主动成交，解释含固定费用的库存控制区间和准变分不等式。

两种交易动作

限价单控制是持续决定挂在哪个价格、挂多少。市价单控制是在选定时刻主动改变库存。前者等待对手方成交，后者消耗订单簿中的流动性，通常支付价差与费用。

记最优买卖价为 b,ab,ab,a，最小价格变动单位为 Δ\DeltaΔ。买单改善一个档位是 b+Δb+\Deltab+Δ，卖单改善一个档位是 a−Δa-\Deltaa−Δ。改善报价可能提高成交速度，也减少单位成交收益；若跨过对手价，则需要按实际成交规则处理。

价差可用离散状态表示，例如 a−b∈{Δ,2Δ,3Δ}a-b\in\{\Delta,2\Delta,3\Delta\}a−b∈{Δ,2Δ,3Δ}，状态间按马尔可夫强度转换。库存、现金、价格和价差共同构成控制状态。

固定费用为什么形成区间

看一个静态近似：不交易的风险成本为 aq2aq^2aq2；将库存调整到 zzz 的成本为 az2+h∣q−z∣+εaz^2+h|q-z|+\varepsilonaz2+h∣q−z∣+ε，其中 h=d/2h=d/2h=d/2。设 q>0q>0q>0，先考虑 0≤z≤q0\le z\le q0≤z≤q。对 zzz 求导，最优交易目标为 z∗=h/(2a)z^*=h/(2a)z∗=h/(2a)，前提是当前库存超过这一水平。

q>z∗+ε/aq>z^*+\sqrt{\varepsilon/a}q>z∗+ε/a​

才值得支付固定费用。负库存情形对称。触发库存与交易后目标不同，形成了“达到外侧边界后退回内侧”的结构。

取 a=0.02,h=0.1,ε=0.18a=0.02,h=0.1,\varepsilon=0.18a=0.02,h=0.1,ε=0.18，目标库存为 2.5，正侧触发点为 5.5。整数库存 5 股时继续持有；6 股时应减少至约 2 或 3 股。多期随机模型的边界还取决于剩余时间、成交强度和价格信号。

用一个单步成本例说明行动区间。当前库存为整数 q≥0q\ge0q≥0，交易后保留 jjj 股，库存惩罚为 0.01j20.01j^20.01j2；一旦交易，就支付固定费 0.10 元以及每股 0.02 元。全部数值都用同一成本单位。

这只是解释固定费用作用的单步模型。完整脉冲控制还需把交易后的继续价值、未来成交和时间变化纳入比较。

从连续阈值回到整数交易

减去最小交易成本后，不交易成本与它的差额为 a(q−z∗)2−εa(q-z^*)^2-\varepsilona(q−z∗)2−ε。因此固定费用决定是否启动交易，而每股费用与边际持仓风险决定启动后去哪里。若 q≤z∗q\le z^*q≤z∗，上述内点目标不在允许的减仓区间里，不能照搬触发公式。

沿用 a=0.02,h=0.1,ε=0.18a=0.02,h=0.1,\varepsilon=0.18a=0.02,h=0.1,ε=0.18。库存为 6 股时，不交易成本为 0.02×36=0.720.02\times36=0.720.02×36=0.72。交易到 2 股的成本为 0.02×4+0.1×4+0.18=0.660.02\times4+0.1\times4+0.18=0.660.02×4+0.1×4+0.18=0.66，到 3 股的成本也为 0.66。两个整数动作都优于等待。库存为 5 股时，不交易成本为 0.50，交易到 2 或 3 股均需 0.56，此时等待更好。连续目标 2.5 股需要经过整数动作比较，不能直接作为可发送数量。

动态方程中的 V−MV≥0V-\mathcal MV\ge0V−MV≥0 表示最优价值至少与立即交易一样好，因为立即交易始终是可选动作。等待区域中，这个差额为正；触发区域中，它为零。若数值解出现明显负值，说明动作比较、交易后状态或离散误差需要检查。

设当前所有订单事件和价差跳变的总强度为 Λ\LambdaΛ，最简单的一步离散法给“不发生事件”的概率 1−ΛΔt1-\Lambda\Delta t1−ΛΔt。例如 Λ=12\Lambda=12Λ=12 每秒、步长 0.1 秒会得到负概率，必须缩小步长或采用保持概率非负的转移计算。

鲨鱼说

触发点与交易后的目标点分开，能避免频繁支付固定费用。只把库存拉回触发点附近，下一次小波动就可能再次产生一笔费用。

数值求解与边界

可把库存和价差离散化，在每个时间步先计算挂单产生的期望继续价值，再枚举允许的市价交易数量，取两者较优值。需要检查交易强度与时间步的乘积，避免把离散转移概率算成负数。

等待区域和交易区域的交界处，价值函数可能不能逐次求导。黏性解用接触价值函数的光滑测试函数表达局部不等式，使动态规划在这种边界上仍有明确含义。实际计算更关心网格细化后边界是否稳定，以及清仓费用是否与终端条件一致。

查看解答

“暂时不交易”可以是优化结果。只要小幅调整节省的风险成本不足以支付费用，等待就有明确的经济依据。
