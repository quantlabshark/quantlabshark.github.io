1. 正态与独立

题目

X 与 Y 各自服从标准正态分布，且相关系数为零。能否推出独立？请构造反例，并说明附加什么条件后结论成立。

考点：边际与联合分布；零相关；依赖反例。

查看分析与解答

必要知识

边际分布只描述每个变量单独取值的规律，联合分布还描述它们怎样一起出现。相关系数由 E[XY] 等二阶矩构成，只能约束线性共同变化。联合正态是比两个边际都正态更强的条件。

分析思路

保留正态的对称边际，同时人为制造明显依赖，再用随机符号把协方差抵消。分别验证边际、相关和不独立，才能构成完整反例。

解答步骤

令 Y=SX，S 独立于 X 且等概率取 ±1。对任意阈值 y，有 P(Y≤y)=[P(X≤y)+P(−X≤y)]/2=Φ(y)，因此 Y 确为标准正态，而不是仅均值方差相同。

不能只凭这两个条件推出独立。取 X∼N(0,1)X\sim N(0,1)X∼N(0,1)，再取与 X 独立的随机符号 S，正负一概率各半，定义 Y=SXY=SXY=SX。

先看边缘分布：标准正态关于零对称，所以 X 与 -X 同分布，随机选择其中一个得到的 Y 仍是标准正态。再看协方差：两者均值为零，且 E[XY]=E[SX2]=E[S]E[X2]=0,E[XY]=E[SX^2]=E[S]E[X^2]=0,E[XY]=E[SX2]=E[S]E[X2]=0, 因此相关系数确为零。

然而 ∣Y∣=∣X∣|Y|=|X|∣Y∣=∣X∣ 恒成立。令事件 A 为 ∣X∣≤1|X|\le1∣X∣≤1、B 为 ∣Y∣≤1|Y|\le1∣Y∣≤1，它们其实是同一事件。其概率约为 0.6827，交集概率也为 0.6827。若独立，交集应为 0.68272≈0.46610.6827^2\approx0.46610.68272≈0.4661，明显不同。联合分布位于两条直线 y=x 与 y=-x 上，不能由两个独立正态变量产生。

若附加“X、Y 联合服从二元正态”，零协方差才意味着联合密度或特征函数可分解，从而独立。各自正态只描述单个变量，联合正态还约束变量之间的关系；零 Pearson 相关一般只能排除线性关联。

协方差为零来自正负关系平均抵消，但绝对值始终完全相等。若附加联合正态，且相关为零，联合密度指数分解成 −x²/2−y²/2、归一化常数也分解，因而 f_(X,Y)=φ(x)φ(y)，才推出独立。反例的概率集中在两条直线上，不满足这一联合结构。

同类问题

证明两个概念不等价，可构造一个同时满足已知条件却明显违背结论的对象，并逐项验证。涉及正态时始终区分边际正态与联合正态。

2. 灯泡时间

题目

灯泡寿命 TTT 服从速率为 λ>0\lambda>0λ>0 的指数分布，即 P(T>t)=e−λtP(T>t)=e^{-\lambda t}P(T>t)=e−λt。求一个灯泡的平均寿命；再设两只灯泡寿命独立、同时点亮，系统在两只都损坏后才停止，求系统平均持续时间。

考点：寿命分布；最大最小；尾概率积分。

查看分析与解答

必要知识

指数分布的 λ 是单位时间发生失效的速率，平均寿命单位为时间，因此应与 1/λ 同量纲。两灯都坏才停止对应最大寿命；任一灯坏就停止对应最小寿命。

分析思路

先根据系统停止规则选择 max 或 min，再从“所有灯均已坏”或“所有灯仍好”的事件写分布。非负变量均值用生存函数积分最直接。

解答步骤

两灯都在 t 之前损坏的概率为 P(T₁≤t)P(T₂≤t)=(1−e⁻λᵗ)²。因此至少一灯仍亮的概率是其补集，而不是两个生存概率简单相加，后者会重复计算两灯都亮的情况。

非负随机变量的均值可用生存函数积分：E[T]=∫0∞P(T>t) dtE[T]=\int_0^\infty P(T>t)\,dtE[T]=∫0∞​P(T>t)dt。单灯泡因此有 E[T]=∫0∞e−λt dt=1λ.E[T]=\int_0^\infty e^{-\lambda t}\,dt=\frac1\lambda.E[T]=∫0∞​e−λtdt=λ1​. 这里 λ\lambdaλ 是单位时间的速率，其倒数才是平均寿命。

两灯系统的持续时间为 M=max⁡(T1,T2)M=\max(T_1,T_2)M=max(T1​,T2​)。由独立性，P(M≤t)=(1−e−λt)2P(M\le t)=(1-e^{-\lambda t})^2P(M≤t)=(1−e−λt)2，故 P(M>t)=2e−λt−e−2λt.P(M>t)=2e^{-\lambda t}-e^{-2\lambda t}.P(M>t)=2e−λt−e−2λt. 积分得 E[M]=2/λ−1/(2λ)=3/(2λ)E[M]=2/\lambda-1/(2\lambda)=3/(2\lambda)E[M]=2/λ−1/(2λ)=3/(2λ)。例如单灯平均寿命 100 小时，两灯并联系统平均持续 150 小时。

若系统在任意一只损坏时就停止，持续时间变为最小值，其生存函数为 e−2λte^{-2\lambda t}e−2λt，均值为 1/(2λ)1/(2\lambda)1/(2λ)。泊松分布描述次数，指数分布描述相邻事件等待时间，答题时要先区分随机变量。

也可把并联系统分成两个阶段：首次损坏时间是速率 2λ 的指数变量，均值 1/(2λ)；利用无记忆性，剩余灯在该时刻的平均剩余寿命仍为 1/λ。相加得 3/(2λ)，与最大值积分相同。

同类问题

寿命系统先翻译停止条件再求分布。独立性用于事件概率相乘，无记忆性用于阶段重启，两者承担不同作用，不能对任意寿命分布混用。

3. IC 与收益

题目

解释因子 IC 如何与组合收益联系。高换手率股票是否必然具有更高 IC？仅用 IC 评价因子会遗漏什么？

考点：横截面相关；收益尺度；换手口径。

查看分析与解答

必要知识

相关系数把协方差除以两个标准差，因此是无量纲指标。组合收益却有金额或收益率单位，仍取决于未来收益离散幅度、权重大小与成本。股票成交换手描述市场活跃度，策略换手描述自身仓位变化。

分析思路

先在一个明确的线性权重规则下推导 IC 与毛收益的联系，再指出实际约束和成本会改变这个关系。高换手分组的效果应通过同日对照检验。

解答步骤

若有 N 只股票，标准化因子均值零、平方平均一，令权重 w_i=f_i/N，则横截面组合收益为 N⁻¹Σf_i r_i，即因子与收益的总体口径协方差，等于 IC×σ_r。权重若再按总绝对敞口归一化，收益还要除以因子绝对值平均。

横截面 IC 为因子与未来收益的相关系数。设因子已标准化为均值零、方差一，未来收益横截面标准差为 σr\sigma_rσr​，则二者协方差为 IC⋅σrIC\cdot\sigma_rIC⋅σr​。若权重与标准化因子成比例，毛收益与这个协方差有关。实际权重截断、行业约束和持有期会改变对应关系。

IC 不携带全部收益幅度。例如两个市场的 IC 都为 0.05，但收益横截面标准差分别为 1% 和 4%，同样标准化权重所对应的毛收益尺度不同。Rank IC 只使用排序，进一步忽略绝对幅度。

股票自身的换手率高，表示交易活跃，不等同于因子预测准确。若观察到高换手组 IC 高，应在相同日期比较，并控制规模、波动和流动性，检查是否由少数高波动样本推动。

评价还应包含分组单调性、时间外稳定性、尾部损失、行业规模暴露、策略换手、净收益和容量。股票换手率与策略调仓换手是不同量；后者直接影响费用，不能因前者较高便认定策略成本低。

IC=0.05、σ_r=1% 时，上述未再归一化的毛收益尺度为 0.05%；σ_r=4% 时为 0.2%。但高波动也可能带来更大尾部风险和执行成本。将因子乘十不会改变 IC，却会在不做权重归一化时放大头寸，因此 IC 本身不确定投资规模。

同类问题

评价相关指标时同时看收益幅度、权重规范和成本。若比较股票换手分组，应控制规模与波动，避免把市场活跃程度误认成预测准确程度。

4. CAPM 偏离与套利

题目

市场预期收益为 10%，无风险收益为 4%，某组合 PPP 的市场 β=1/3\beta=1/3β=1/3、预期收益为 5%。计算 CAPM 定价偏离，并判断能否仅凭这些条件构造无风险套利。

考点：CAPM；模型残差；套利定义。

查看分析与解答

必要知识

CAPM 的预期收益由无风险收益加市场风险溢价乘 β 得到。β 只衡量对市场共同变化的暴露，不代表组合没有其他随机风险。相同 β 与相同逐状态支付是不同条件。

分析思路

先算模型要求的均值，再构造同 β 的参照组合，最后写出对冲后的随机收益，检查是否仍可能亏损。

解答步骤

市场风险溢价为 10%−4%=6%，β=1/3 对应风险补偿 2%，加无风险 4% 得 6%。给定 P 均值仅 5%，因此模型 α 为 −1%。参照 Q 用三分之一市场与三分之二无风险资产复制同一市场暴露。

按 CAPM，组合应有预期收益 rf+β(E[rm]−rf)=4%+13(10%−4%)=6%.r_f+\beta(E[r_m]-r_f)=4\%+\frac13(10\%-4\%)=6\%.rf​+β(E[rm​]−rf​)=4%+31​(10%−4%)=6%. 实际给定预期为 5%，因此相对模型的 α=−1%\alpha=-1\%α=−1%。

构造参照组合 QQQ：三分之一资金投市场、三分之二投无风险资产，则 βQ=1/3\beta_Q=1/3βQ​=1/3、预期收益为 6%。若卖空一单位 P、买入一单位 Q，初始资金可相抵，市场贝塔也抵消，预期收益差为 1%。

但 P 的收益可能还含残差 ε\varepsilonε。写成 rP=α+rf+β(rm−rf)+εr_P=\alpha+r_f+\beta(r_m-r_f)+\varepsilonrP​=α+rf​+β(rm​−rf​)+ε 后，对冲收益为 −α−ε-\alpha-\varepsilon−α−ε。即使均值是 1%，某些状态下仍可能亏损，因此这只是具有正预期的相对价值交易。

无风险套利要求零或非正初始成本、所有状态不亏且某些状态获利。只有进一步排除残差风险，并满足融资、做空与支付复制条件，才可讨论这种意义的套利。

假设 P 的残差某期为 +3%，则做多 Q、做空 P 的对冲收益为 1%−3%=−2%，即使其期望为 +1% 仍可亏损。若残差恒为零且可按同口径做空融资，才可能把模型偏离转成逐状态确定收益；一般题设没有给出这一条件。

同类问题

看到“定价偏离”先问是相对某个预期收益模型，还是违反可复制现金流的无套利关系。正预期交易与无风险套利需要不同的证据。

5. 相关性与最小风险

题目

两资产波动率 σ1,σ2>0\sigma_1,\sigma_2>0σ1​,σ2​>0，权重固定且 w1,w2>0w_1,w_2>0w1​,w2​>0、和为 1。相关系数取何值时组合方差最小？何时能降为零？若允许一多一空，结论怎样改变？

考点：方差交叉项；权重符号；完全对冲。

查看分析与解答

必要知识

组合方差包含各资产自身方差和协方差交叉项。固定权重下，相关系数 ρ 只出现在交叉项，其系数符号由 w₁w₂ 决定。最低方差为零还要求两边波动幅度恰好匹配。

分析思路

把方差看成 ρ 的一次函数，先判断斜率正负，再取允许区间端点。代入端点后化为一个平方，直接读出零方差条件。

解答步骤

两权重均正时，斜率 2w₁w₂σ₁σ₂>0，故选 ρ=−1。此时平方根波动为 |w₁σ₁−w₂σ₂|。σ₁=20%、σ₂=10%，若各半则 |10%−5%|=5%，并不为零。

代入后 σp2=(w1σ1−w2σ2)2\sigma_p^2=(w_1\sigma_1-w_2\sigma_2)^2σp2​=(w1​σ1​−w2​σ2​)2。要使其为零，还需 w1σ1=w2σ2w_1\sigma_1=w_2\sigma_2w1​σ1​=w2​σ2​，结合权重和为 1，得 w1=σ2/(σ1+σ2)w_1=\sigma_2/(\sigma_1+\sigma_2)w1​=σ2​/(σ1​+σ2​)。例如波动分别为 20%、10%，权重取三分之一与三分之二才能相抵；各半时仍有 5% 波动。

若一多一空，则 w1w2<0w_1w_2<0w1​w2​<0，相关项系数为负，此时越高的相关性越有利于对冲，最小值在 ρ=1\rho=1ρ=1。所以应先说明权重符号，再讨论最优相关。

要抵消，需 w₁×20%=(1−w₁)×10%，解得 w₁=1/3。若一多一空，交叉项系数负，ρ=1 更有利，此时需要有符号波动和 w₁σ₁+w₂σ₂=0。若另外限制权重和或杠杆，是否可实现还需联立这些约束。

同类问题

相关性是否帮助分散取决于持仓方向。固定权重求最优相关，与给定相关求最优权重是不同问题，答题时先明确哪个量可以调整。

6. 外汇利率平价

即期汇率 SSS 以美元/英镑报价，一年期英镑利率 27%、美元利率 9%，均为简单利率。假设两种货币可以按给定利率借贷并签订无信用风险远期，求无套利远期汇率 FFF 及英镑远期升贴水。

7. 因子研究

题目

拟研究一个股票因子，从提出假设到组合评价应经过哪些步骤？若近期效果下降，如何诊断而不只反复修改参数？

考点：假设检验；因子增量；收益归因。

查看分析与解答

必要知识

因子研究包含预测关系与投资实施两层。IC、分组差检查信号，行业风格暴露解释风险来源，组合与成交决定净收益。近期失效可能发生在其中任意一层。

分析思路

按数据、预测、增量、组合顺序建立基准结果。近期下降时沿同一顺序定位最早改变的环节，用针对性对照代替反复搜索参数。

解答步骤

例如近期毛 IC 基本不变但净收益下降，先比较换手、价差、成交率和容量；若 IC 也下降，先检查数据可见时点、样本覆盖和特征分布，再考虑经济关系变化。这样的分支诊断能避免把执行成本问题误交给模型调参。

定义与数据。 先写可检验关系、计算式和收益标签，检查财报公布时点、复权、股票池与缺失。对特征做必要变换、截尾和标准化，再分析行业、规模等暴露；中性化的控制变量也应在当时可知。

预测检验。 计算每日 IC、IC 均值与波动、分层收益及稳定性。ICIR 通常指 IC 均值除以其标准差，若年化需说明频率和序列相关假设。测试日期按时间留出，不能在看到测试结果后不断筛选。

增量与合成。 检查与已有因子的相关性和多重共线性，比较残差化或加入基准模型后的增量。可用线性组合或非线性方法合成，但应保留简单等权基准，避免权重由少量噪声主导。

组合与归因。 估计协方差，设置行业、单票、杠杆和换手约束，加入费用及成交规则。将收益分解为市场、行业、风格与个股部分，判断组合收益是否符合最初假设。

近期下降时，先排查输入质量和标签时序，再比较暴露、信号分布、成交成本和市场状态。如果预测还在而净收益下降，重点检查执行。若增量 IC 消失，检查重复信息或状态变化。每次调整只改变有依据的部分，再用后续日期评价。

若加入行业、规模控制后新因子收益消失，原先收益可能主要来自这些共同暴露；若单因子仍有效但与因子库残差无预测力，则新增价值不足。ICIR=平均 IC/IC 标准差不等于均值 t 值，后者还涉及样本量和序列相关，应明确用途。

同类问题

研究流程应让每个结论能追溯到一个可比较实验。新参数只修正有证据的问题，并保留之后日期检验，才能区分改进与对历史噪声的适配。

8. DataFrame 操作

题目

DataFrame 使用名为 date、ticker 的两层行索引，其余列均为数值特征。写出取得股票 A 全部日期、计算每行中位数、计算每行大于 0.5 的元素的样本标准差的方法。缺失值忽略，不足两个有效元素时标准差为 NaN。

考点：多层索引；按行聚合；样本自由度。

查看分析与解答

必要知识

MultiIndex 的每层有名称，选股票应定位 ticker 层，而不是默认第一层。axis=1 表示在每行的各特征之间计算。样本标准差用分母 n−1，至少需要两个有效值。

分析思路

先按层名选出股票，再做独立的逐行统计。条件标准差先用掩码把不满足 >0.5 的元素置为缺失，保留原行结构，再聚合。

解答步骤

第一行 [0.2,0.6,1.0] 中位数为 0.6；条件后只剩 [0.6,1.0]，均值 0.8、平方偏差 0.04+0.04=0.08，分母一，标准差 √0.08≈0.28284。第二行没有大于 0.5 的数，应为 NaN，而不是零波动。

取股票 A 时，应按索引层级而非默认第一层选择。逐行操作使用 axis=1；条件不满足的值设为缺失后，标准差只使用剩余元素。

表格操作先明确选的是哪一索引层、沿哪个轴聚合、如何处理缺失及自由度。用一两行手算能快速检查这些接口约定。

9. 不用 corr

题目

不用 DataFrame.corr，计算两个可能含缺失值的等长序列的 Pearson 相关。要求按位置配对删除缺失；有效样本不足两个或任一序列为常数时返回 NaN，并解释数值稳定性。

考点：成对缺失；中心化；数值稳定性。

查看分析与解答

必要知识

相关系数需要同一个样本位置上的成对观察。协方差与两个方差若都使用同一 n−1 分母，分母在比值中抵消，因此可直接使用中心化平方和。任一列为常数时标准差为零，相关无定义。

分析思路

先同时筛选有效配对，再用这个共同样本分别求均值，第二遍求偏差积和平方和。避免先独立删除两列缺失，也避免大数平方和相减。

解答步骤

例如 x=[1,缺失,3]、y=[2,9,6]，共同有效配对只有 (1,2)、(3,6)，不能把 y 的 9 留下后错配到 x 的 3。有效样本数的判断应放在共同筛选之后。

相关系数为 r=∑i(xi−xˉ)(yi−yˉ)∑i(xi−xˉ)2∑i(yi−yˉ)2.r=\frac{\sum_i(x_i-\bar x)(y_i-\bar y)}{\sqrt{\sum_i(x_i-\bar x)^2\sum_i(y_i-\bar y)^2}}.r=∑i​(xi​−xˉ)2∑i​(yi​−yˉ​)2​∑i​(xi​−xˉ)(yi​−yˉ​)​. 先确定同时有效的位置，再对这个共同样本计算均值。不能分别删除两列缺失后直接配对，否则位置会错开。

from math import isfinite, sqrt, fsum, isnan

def pearson(x, y):
    if len(x) != len(y):
        raise ValueError('序列长度必须相同')
    pairs = []
    for a, b in zip(x, y):
        if a is None or b is None:
            continue
        a, b = float(a), float(b)
        if isfinite(a) and isfinite(b):
            pairs.append((a, b))
    if len(pairs) < 2:
        return float('nan')
    mx = fsum(a for a, _ in pairs) / len(pairs)
    my = fsum(b for _, b in pairs) / len(pairs)
    xx = fsum((a-mx)**2 for a, _ in pairs)
    yy = fsum((b-my)**2 for _, b in pairs)
    if xx == 0 or yy == 0:
        return float('nan')
    xy = fsum((a-mx)*(b-my) for a, b in pairs)
    return xy / sqrt(xx*yy)

assert abs(pearson([1, 2, float('nan'), 4], [2, 4, 9, 8])-1) < 1e-12
assert isnan(pearson([1, 1], [2, 3]))
assert abs(pearson([1e12, 1e12+1, 1e12+2], [2, 4, 6])-1) < 1e-12

先中心化可避免直接使用“平方和减均值平方”时两个大数相减的精度损失；fsum 减少累加误差。算法时间为 O(n)O(n)O(n)，此实现保存配对样本，空间为 O(n)O(n)O(n)。流式数据可改用在线均值和协方差更新，以减少额外空间。

当 x≈10¹² 而差异只有一两单位时，直接算 Σx²−n均值² 会相减两个约 10²⁴ 的数，丢失小差异；先中心化后累加一两单位的偏差可改善稳定性。fsum 进一步减小累加误差，但不能恢复输入浮点数在读取时已经丢失的信息。代码同时将 None 与 NaN 作为缺失处理，非有限值也排除。

同类问题

实现统计量需同时保证样本对齐和数值算法稳定。验证至少包括完全相关、常数列、缺失位置不同和大基数小波动四类样例。

10. 最多k次股票交易

题目

给定 n 天价格和非负整数 k，每次只能持有一单位，最多完成 k 次先买后卖，不计费用，允许不交易。求最大利润并给出时间、空间复杂度。

考点：交易状态；动态规划；旧状态更新。

查看分析与解答

必要知识

一天结束时必须区分持仓与空仓，因为未来允许的动作不同。买入减少现金，卖出增加现金；持仓现金余额不是含股票市值的账户权益。交易预算 j 还决定能否再开启新交易。

分析思路

对每个 j 保留买入与卖出状态，分别比较保持现状与今天交易。所有转移读取上一日状态，确保时间顺序清楚；最后答案来自空仓状态。

解答步骤

例如 [3,2,6]、一次交易，买入状态随价格从 −3 改为 −2，第三日卖出候选 −2+6=4。两次交易例 [3,2,6,5,0,3] 中，第一次实现四元后，第二次在零价买入仍保有现金四，三价卖出达到七。

设 buy[j] 为使用至多 j 次买入额度、当前持仓的最大现金余额，sell[j] 为最多完成 j 次交易且当前空仓的最大余额。空仓可以从不交易开始，所以 sell 初值为 0；尚未买入的持仓状态初值为负无穷。

价格为 p 时，用上一日状态更新： buyj′=max⁡(buyj,sellj−1−p),sellj′=max⁡(sellj,buyj+p).buy_j'=\max(buy_j,sell_{j-1}-p),\qquad sell_j'=\max(sell_j,buy_j+p).buyj′​=max(buyj​,sellj−1​−p),sellj′​=max(sellj​,buyj​+p). 第一式选择继续持有或从空仓买入，第二式选择继续空仓或卖出。使用旧状态副本，避免一天内重复使用刚更新的结果。

Python18 行
def max_profit(prices, k):
    if k <= 0 or len(prices) < 2:
        return 0
    if k >= len(prices)//2:
        return sum(max(b-a, 0) for a, b in zip(prices, prices[1:]))
    buy = [float('-inf')] * (k+1)
    sell = [0] * (k+1)
    for p in prices:
        old_buy, old_sell = buy[:], sell[:]
        for j in range(1, k+1):
            buy[j] = max(old_buy[j], old_sell[j-1]-p)
            sell[j] = max(old_sell[j], old_buy[j]+p)
    return sell[k]

assert max_profit([3, 2, 6, 5, 0, 3], 2) == 7
assert max_profit([7, 6, 4, 1], 2) == 0
assert max_profit([], 2) == 0
assert max_profit([1, 2, 3, 4], 20) == 3

例中在 2 买 6 卖获利 4，再在 0 买 3 卖获利 3，总利润 7。一般复杂度为 O(nk)O(nk)O(nk) 时间、O(k)O(k)O(k) 空间；当 k≥⌊n/2⌋k\ge\lfloor n/2\rfloork≥⌊n/2⌋，交易预算不再约束，可累加所有正相邻差，时间降为 O(n)O(n)O(n)。

sell[j] 初始零表示允许少于 j 次、甚至不交易，buy[j] 为负无穷表示尚无合法持仓。若 k≥floor(n/2)，预算足以实现所有上涨段，把相邻正涨幅相加即可；连续上涨段拆成多笔与合成一笔利润相同。存在费用、冷却期或交易量限制时，这个快捷分支可能失效。

同类问题

交易动态规划先明确状态代表现金还是总权益、交易次数在买入还是卖出时计数。定义一致后再写转移，初始化与终态才能正确处理不交易和持仓未平等情况。
