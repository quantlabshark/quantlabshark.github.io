严格支配关系下的有效前沿

题目

每个观测点含收益 pnl 与非负回撤幅度 drawdown。只有某点 yyy 同时满足 y.pnl>x.pnly.\mathrm{pnl}>x.\mathrm{pnl}y.pnl>x.pnl 且 y.drawdown<x.drawdowny.\mathrm{drawdown}<x.\mathrm{drawdown}y.drawdown<x.drawdown，才称 yyy 严格支配 xxx。返回所有未被严格支配的点，保留重复点。

考点：严格支配；同收益分组；扫描不变量。

查看分析与解答

必要知识

本题支配要求收益严格更高且回撤严格更低，任一指标相等都不构成支配。这比常见“至少不差且一项更好”的定义更弱，因此会保留更多点。

分析思路

按收益降序处理同值组，使用之前更高收益组的最小回撤判断当前组。整组判断完成后再更新最小值，避免同组互相支配。

解答步骤

若历史最小回撤为3，当前回撤4会被某个更高收益且回撤3的点支配；当前回撤3则不满足严格更小，必须保留。收益相同的两个点也都先对历史比较，而非先用其中低回撤更新。

按收益从大到小排序，维护此前收益严格更高的点中的最小回撤 d∗d_*d∗​。当前点被支配当且仅当自己的回撤大于 d∗d_*d∗​：此前确有收益更高且回撤更小的点。

相同收益须成组判断，整组完成后再更新最小回撤。否则同收益但更低回撤的点会错误地支配本组其他点。回撤相同也不能删除，因为题目要求回撤严格更小。

例如点 (10,3),(10,4),(9,3),(8,5) 中，前三个都保留：前两个收益相同，第三个与最佳高收益点回撤相同；只有 (8,5) 被严格支配。排序 O(nlog⁡n)O(n\log n)O(nlogn)，扫描 O(n)O(n)O(n)，返回结果所需空间为 O(n)O(n)O(n)。下方实现中临时分组用于保持上述不变量。

from itertools import groupby
from math import isfinite

def efficient_frontier(points):
    if any(not (isfinite(p) and isfinite(d) and d >= 0) for p, d in points):
        raise ValueError("收益须有限，回撤须为有限非负幅度")
    ordered = sorted(enumerate(points), key=lambda x: -x[1][0])
    keep, best_drawdown = [], float("inf")
    for _, group in groupby(ordered, key=lambda x: x[1][0]):
        group = list(group)
        keep.extend(i for i, (_, d) in group if d <= best_drawdown)
        best_drawdown = min(best_drawdown, min(x[1][1] for x in group))
    return [points[i] for i in sorted(keep)]

assert efficient_frontier([(3, 2), (3, 4), (2, 3), (1, 2)]) == [(3, 2), (3, 4), (1, 2)]

重复点具有相同状态，且题目要求保留重复，返回时应使用原始下标而非集合去重。代码最后按下标排序恢复输入顺序。空输入返回空表；回撤按幅度给定应为非负，实际输入校验也应包含此条件。

同类问题

连续损益的最小累计和

题目

给定非空每日损益数组，求任意非空连续区间的损益和最小值。再说明它与非负的最大绝对回撤，以及按净值比例计算的最大回撤之间的区别。

考点：最小区间；累计净值；绝对与比例回撤。

查看分析与解答

必要知识

累计损益P_t相邻日期之差是每日损益，一段损益和等于后端累计值减前端累计值。最小区间允许全正时仍返回一个正值，最大回撤却允许完全没有下跌时取零。

分析思路

先求非空最小区间和，再把负方向的峰谷差转换成非负绝对回撤。比例回撤另需除以对应历史峰值，不能只反转符号。

解答步骤

以初始累计值零记P，区间[i,j]和为P_{j+1}−P_i；最小化所有合法i≤j，就是寻找先前峰值到随后低值的最大下降。绝对回撤因此为max(0,−最小和)。若所有每日损益正，最小和正，但绝对回撤为零。

设 mim_imi​ 为以第 iii 天结束的最小区间和。若延续此前区间更小则延续，否则从本日重新开始： mi=min⁡(Li,mi−1+Li).m_i=\min(L_i,m_{i-1}+L_i).mi​=min(Li​,mi−1​+Li​). 每步更新全局最小值，初值取首项。例如 [3,-5,2,-4,6] 的最小区间为 [-5,2,-4]，和为 -7。若数组全为正数，答案是最小的单日损益，而不是零，因为区间必须非空。

净值的绝对回撤幅度取历史峰值到随后谷值的下降，允许没有下降，因此为 max⁡(0,−最小区间和)\max(0,-\text{最小区间和})max(0,−最小区间和)。按百分比的回撤则为 1−Vt/max⁡s≤tVs1-V_t/\max_{s\le t}V_s1−Vt​/maxs≤t​Vs​，还要使用峰值净值作分母，不能只对日损益求和。

该递推每次仅依赖上一状态，时间 O(n)O(n)O(n)、额外空间 O(1)O(1)O(1)。

def minimum_pnl_interval(pnl):
    if not pnl:
        raise ValueError("损益序列不能为空")
    ending = best = pnl[0]
    for i in range(1, len(pnl)):
        x = pnl[i]
        ending = min(x, ending + x)
        best = min(best, ending)
    return best

assert minimum_pnl_interval([3, -4, 2, -5, 6]) == -7
assert minimum_pnl_interval([2, 4]) == 2

初始净值100和1000的两个账户同样亏7元，绝对回撤都7，比例却约7%和0.7%。比例分析需要正净值与明确初始值。与最大和实现相同，按下标扫描可避免列表切片占用额外O(n)空间。

不含相邻 1 的二进制串

题目

长度为 nnn 的 0/1 串中，相邻位置不能同时为 1。求线性排列的计数；再对 n≥2n\ge2n≥2、首尾也视为相邻的圆环求计数，并给出小规模例子。

考点：尾部约束；分类递推；环边界。

查看分析与解答

必要知识

相邻不能同为一是局部约束。线性串的首尾互不约束，圆环多出第一位与最后一位这一对，因此需要单独处理首位状态。

分析思路

线性情况按首位零或一分类，一开头强制下一位零。圆环按首位分类，一开头还强制末位零，再调用较短线性问题的计数。

解答步骤

空串算一个合法方案，故a₀=1而非零；一位串0、1共二。依次得到a₂=3、a₃=5、a₄=8。圆环四位首位零贡献a₃=5，首位一时第二、四位零，中间一位自由贡献a₁=2，合计七。

令线性计数为 ana_nan​。按首位分类：首位为 0 时，后面任取合法 n−1n-1n−1 位串；首位为 1 时，第二位必须为 0，剩余为合法 n−2n-2n−2 位串。因此 an=an−1+an−2a_n=a_{n-1}+a_{n-2}an​=an−1​+an−2​，边界 a0=1,a1=2a_0=1,a_1=2a0​=1,a1​=2，得到 an=Fn+2a_n=F_{n+2}an​=Fn+2​，其中 F0=0,F1=1F_0=0,F_1=1F0​=0,F1​=1。

圆环在 n≥3n\ge3n≥3 时也按首位分类。首位为 0，余下 n−1n-1n−1 位是线性问题，共 an−1a_{n-1}an−1​；首位为 1，第二位和末位必须为 0，中间剩 n−3n-3n−3 位，共 an−3a_{n-3}an−3​。故 bn=an−1+an−3=Fn+1+Fn−1.b_n=a_{n-1}+a_{n-3}=F_{n+1}+F_{n-1}.bn​=an−1​+an−3​=Fn+1​+Fn−1​. 例如线性三位串有 000、001、010、100、101，共 5 个；圆环还要去掉首尾同时为 1 的 101，剩 4 个。n=2n=2n=2 时直接列出 00、01、10，共 3 个。

用两项滚动状态可在 O(n)O(n)O(n) 时间、O(1)O(1)O(1) 额外空间内计数；大整数位数会随 nnn 增长。

n=2时首位的左右邻居是同一个位置，不能按n−3公式留下负长度，应直接枚举00、01、10。计数增长为斐波那契量级，若只需模结果可每步取模；精确大整数的位数与操作成本会随n增长。

同类问题

把线性序列改为环时，新增约束只跨首尾，可先固定首部状态，把剩余部分还原成线性计数。短长度需单独检查邻居是否重合。

HTH 模式竞争

题目

公平硬币独立反复投掷，A 预先选择模式 HTH，B 可以选择另外一个长度为 3 的正反面模式。任一模式第一次在连续三次投掷中出现时，其选择者获胜。B 如何选择以使胜率最大？推导其获胜概率。

考点：模式前缀；吸收概率；候选比较。

查看分析与解答

必要知识

各三次窗口出现某个模式的概率相同，不代表两个模式先出现的概率相同。当前尾串可能已形成某模式的前缀，后续投掷会继承这部分进展。

分析思路

对HHT与HTH建立有效后缀状态，逐一列出下一次H或T的转移并解胜率。再对其他候选用相同状态构造比较，确认最优性。

解答步骤

HH之后若再H，尾部仍是HH而不是空；若T则HHT完成。HT之后H使对方HTH完成，T使尾部没有任一目标的非空前缀，回到空状态。保留最长有效后缀正是状态压缩的依据。

B 选择 HHT。比较两种模式时，只需记住当前投掷串末尾中能够继续构成模式的最长前缀，状态为空、H、HH、HT；出现 HHT 或 HTH 后吸收。

记 B 从这四个状态出发的胜率为 p0,pH,pHH,pHTp_0,p_H,p_{HH},p_{HT}p0​,pH​,pHH​,pHT​。逐个列出下一次投掷： p0=12p0+12pH,p_0=\tfrac12p_0+\tfrac12p_H,p0​=21​p0​+21​pH​, pH=12pHH+12pHT,pHH=12pHH+12,p_H=\tfrac12p_{HH}+\tfrac12p_{HT},\quad p_{HH}=\tfrac12p_{HH}+\tfrac12,pH​=21​pHH​+21​pHT​,pHH​=21​pHH​+21​, pHT=12×0+12p0.p_{HT}=\tfrac12\times0+\tfrac12p_0.pHT​=21​×0+21​p0​. 例如 HH 后再来 H 仍保留 HH 后缀，来 T 则 B 获胜；HT 后来 H 则 A 获胜，来 T 后两种模式的有效前缀均为空。

解得 pHH=1p_{HH}=1pHH​=1，p0=pHp_0=p_Hp0​=pH​，pHT=p0/2p_{HT}=p_0/2pHT​=p0​/2，继而 p0=(1+p0/2)/2=2/3p_0=(1+p_0/2)/2=2/3p0​=(1+p0​/2)/2=2/3。对其他六个候选模式按同样方法枚举前缀状态、解线性方程，可比较最优性。下方验证程序给出全部候选概率。固定三个位置出现各模式的概率虽都是 1/81/81/8，但模式自重叠和相互重叠不同，先出现概率因而不同。

            elif not suffix.endswith(a):
                nxt = max((v for v in states if suffix.endswith(v)), key=len)
                matrix[i,index[nxt]] -= .5
    return float(np.linalg.solve(matrix,rhs)[index['']])

probabilities = {''.join(p):pattern_win('HTH',''.join(p))
                 for p in itertools.product('HT',repeat=3) if ''.join(p)!='HTH'}
assert np.isclose(probabilities['HHT'],2/3)
assert max(probabilities.values()) <= 2/3+1e-12
print(probabilities)

由p_HH=1得从HH出发迟早遇T而获胜；空状态反面自循环，所以p₀=p_H。代入p_HT=p₀/2，得p₀=1/2+p₀/4，解为2/3。程序对七个候选分别建立线性系统，最大值检查给出最优证明的有限枚举部分。

取石子博弈

题目

初始有 N≥1N\ge1N≥1 颗石子。先手第一次可以取任意正整数颗，但不能取完；之后每次取数不能超过对方上次所取数量。无法取石者输，取到最后一颗者赢。判断先手必胜的 NNN 并给出策略证明。

考点：博弈状态；最低有效位；归纳证明。

查看分析与解答

必要知识

当前可取上限由对手上次动作决定，因此只记录剩余石子数不够。最低非零位ℓ(n)是整除n的最大二次幂，如12的二进制1100最低一位权重四。

分析思路

证明(m≥ℓ(n))为必胜判据：一类状态可走到相反类，另一类的所有合法动作都会走到前一类。再把初始上限N−1代入。

解答步骤

若n=2^a u、u奇，ℓ(n)=2^a。取掉2^a后若未清空，u−1为偶，所以余数最低位权重至少2^{a+1}，对手上限却只有2^a，进入必败类。

用 (n,m)(n,m)(n,m) 表示还剩 nnn 颗、当前最多可取 mmm 颗。令 ℓ(n)\ell(n)ℓ(n) 为二进制最低非零位的权值，例如 ℓ(12)=4\ell(12)=4ℓ(12)=4。关键判据是当前必胜当且仅当 m≥ℓ(n)m\ge\ell(n)m≥ℓ(n)。

若满足条件，取 k=ℓ(n)k=\ell(n)k=ℓ(n)。若取完直接获胜；否则 n−kn-kn−k 的最低非零位比 kkk 大，而对手只能取至多 kkk，进入不满足判据的状态。

若 m<ℓ(n)m<\ell(n)m<ℓ(n)，任意合法 k≤mk\le mk≤m 都小于 ℓ(n)\ell(n)ℓ(n)。由于 nnn 是大于 kkk 的某个二次幂的倍数，减去 kkk 后有 ℓ(n−k)=ℓ(k)≤k\ell(n-k)=\ell(k)\le kℓ(n−k)=ℓ(k)≤k，对手上限为 kkk，处在满足判据的状态。这两种转移互相配合，给出归纳证明。

初始上限是 N−1N-1N−1，只有当 ℓ(N)=N\ell(N)=Nℓ(N)=N，即 NNN 为 2 的幂时才无法获胜。因此非 2 的幂由先手取最低非零位即可。例如 6 取 2 留 4，8 则任一首步都会给对手必胜状态。N=1N=1N=1 无合法首步，也属于后手获胜。

当k<2^a时，写k=2^b v、v奇、b<a，则n−k=2^b(2^{a−b}u−v)，括号是偶减奇仍为奇，因此ℓ(n−k)=2^b=ℓ(k)≤k。这证明必败类的任一合法动作都给对手必胜。每次石子减少，可按n归纳。

一万枚公平硬币恰有五千枚正面

题目

独立投掷 10000 枚公平硬币，求恰好 5000 枚正面的概率。给出精确表达式、数值计算方法和适当近似。

考点：二项单点概率；Stirling；对数稳定性。

查看分析与解答

必要知识

均值是最可能结果附近的位置，不是该位置的概率。10000次独立投掷有10001种可能正面数，正好5000只占一个整数点。

分析思路

用二项计数给精确式，再用Stirling约去指数项得到中心近似。数值计算转到对数域避免巨大阶乘和极小概率分别溢出。

解答步骤

Stirling给(2m)!≈√(4πm)(2m/e)^{2m}，(m!)²≈2πm(m/e)^{2m}，比值约4^m/√(πm)。再乘2^{-2m}后4^m完全抵消，只余1/√(πm)。

每一个指定的正反面序列概率为 2−100002^{-10000}2−10000，恰好 5000 枚正面有 (100005000)\binom{10000}{5000}(500010000​) 种位置选择，因此 P=(100005000)2−10000≈0.00797864614.P=\binom{10000}{5000}2^{-10000}\approx0.00797864614.P=(500010000​)2−10000≈0.00797864614. 用 Stirling 公式近似 (2m)!/(m!)2∼4m/πm(2m)!/(m!)^2\sim4^m/\sqrt{\pi m}(2m)!/(m!)2∼4m/πm​，取 m=5000m=5000m=5000，得到 P≈15000π≈0.00797884561.P\approx\frac1{\sqrt{5000\pi}}\approx0.00797884561.P≈5000π​1​≈0.00797884561. 因此约为 0.8%。正面比例最常见的是二分之一，但“恰好等于均值”只占很多可能整数中的一个，概率仍不到百分之一。

这里 Γ\GammaΓ 是 Gamma 函数，满足正整数处 Γ(k+1)=k!\Gamma(k+1)=k!Γ(k+1)=k!；lgamma 直接返回 log⁡Γ\log\GammalogΓ，log 表示自然对数。计算机上先求 log⁡P=log⁡Γ(10001)−2log⁡Γ(5001)−10000log⁡2\log P=\log\Gamma(10001)-2\log\Gamma(5001)-10000\log2logP=logΓ(10001)−2logΓ(5001)−10000log2，再指数还原，可避免分别形成巨大阶乘。下面的代码用对数 Gamma 函数实现。

Python3 行

probability = exp(lgamma(10001) - 2 * lgamma(5001) - 10000 * log(2))
assert abs(probability - 0.00797864614) < 1e-10
