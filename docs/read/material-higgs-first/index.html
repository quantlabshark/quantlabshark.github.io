1. 离散概率的归一化

题目

离散随机变量 X 的概率质量函数为 P(X=x)=cxP(X=x)=cxP(X=x)=cx，x=1,2,…,6x=1,2,\ldots,6x=1,2,…,6，其他取值概率为零。求常数 c、期望和中位数。

考点：概率质量；加权均值；分位定义。

查看分析与解答

必要知识

概率质量函数给每个离散值分配非负权重，全部权重之和必须一。期望使用数值乘对应概率，中位数则看左右两侧各至少覆盖一半概率。

分析思路

先归一化确定c，再计算二阶整数和得到期望。中位数逐点累计，并检查候选点右侧也有至少一半概率。

解答步骤

六个点的概率分别1/21、2/21、3/21、4/21、5/21、6/21。求期望再乘一次x，因此求的是平方和91，而不是再次用普通和21。累计概率依次1、3、6、10、15、21除以21。

概率总和为一，所以 c(1+2+3+4+5+6)=21c=1c(1+2+3+4+5+6)=21c=1c(1+2+3+4+5+6)=21c=1，得 c=1/21c=1/21c=1/21。因此 x 越大，其概率也越大，不能把六个值当成等概率。

在4与5之间，左侧累计仍只有10/21，不足一半；在5与6之间，右侧只剩6/21，也不足一半，故中位数唯一为5。期望13/3约4.333，是加权重心，不要求实际能取到。

2. 以有理数为跳跃点的函数

题目

把全部有理数不重复枚举为 r1,r2,…r_1,r_2,\ldotsr1​,r2​,…，在实数上定义 f(x)=∑n:rn<x2−nf(x)=\sum_{n:r_n<x}2^{-n}f(x)=∑n:rn​<x​2−n。讨论有理点和无理点的连续性；若将定义域限制为有理数，结论是否改变？

考点：原子权重；尾和控制；相对拓扑。

查看分析与解答

必要知识

有理数虽在每个区间都稠密，但各跳跃的大小按2⁻ⁿ衰减，尾部总和可任意小。连续性取决于函数值变化大小，不取决于附近是否有无限多个跳跃点。

分析思路

固定点附近把有限个大权重与无限个小尾项分开。无理点可避开全部有限大项；有理点则单独保留对应项，证明其余部分连续。

解答步骤

无理x不等于前N个r，故它到这有限集合的最小距离正，可选更小δ保证这些项的指示值不变。两点函数差只由尾项构成，绝对值至多2⁻ᴺ。

级数总权重为一，故函数处处有定义且单调不减。固定无理点 x 和任意 ε>0\varepsilon>0ε>0，选 N 使尾和 ∑n>N2−n=2−N<ε\sum_{n>N}2^{-n}=2^{-N}<\varepsilon∑n>N​2−n=2−N<ε。前 N 个有理点与 x 均不相同，可选一个足够小邻域避开它们；在此邻域内，前 N 项的取舍不变，函数变化最多来自尾项，绝对值小于 ε\varepsilonε，故在 x 连续。

若 x=rkx=r_kx=rk​，定义中的严格小于使第 k 项在 x 处尚未加入，而从右侧接近后会加入 2−k2^{-k}2−k。将其余项仍按有限前项加可控尾项处理，可得右极限与左极限相差恰为 2−k2^{-k}2−k，所以有跳跃。

有理数在任意邻域都稠密，从两侧取有理数序列仍能逼近 rkr_krk​ 并看到同一个跳跃。因此把定义域限制为有理数后，在每个定义域点依然不连续。

有理x=r_k时，去掉第k项后的函数在x连续，理由与无理点相同：其余有限前项都不等于x。第k项为2⁻ᵏ·1_{x>r_k}，在点上为零、右侧为2⁻ᵏ，所以原函数左连续但右跳。限制到有理定义域时仍可用两侧有理序列观察同一跳跃。

同类问题

稠密跳跃问题用“有限主要项加小尾项”处理。连续性限制到子集后，要使用子集内可逼近的序列，不是仅观察原定义域的空隙。

3. 环形硬币翻转

题目

100 枚硬币围成圆环，编号 0,…,990,\ldots,990,…,99，初始全为正面。第 iii 人（i=1,…,100i=1,\ldots,100i=1,…,100）从共同位置出发，依次翻动编号 ki mod 100ki\bmod100kimod100 的硬币，k=1,…,100k=1,\ldots,100k=1,…,100，每人翻 100 次。最终多少枚正面朝上？

考点：模轨道；最大公约数；翻转奇偶。

查看分析与解答

必要知识

翻转两次等于没翻，所以只需每枚总翻转次数的奇偶。步长i在模100下会重复访问某个轨道；题目每人固定翻100次，不是在首次回起点就停止。

分析思路

按gcd(i,100)分组，计算轨道长度和每点重复次数。偶数重复可忽略，奇数类再统计共有多少个人访问同一轨道。

解答步骤

模100步长i能到的编号恰为g的倍数，共100/g个。每人走100步，因此每个可达点翻g次。比如i=25，轨道25、50、75、0共四点，每点翻25次。

对固定 i，设 g=gcd⁡(i,100)g=\gcd(i,100)g=gcd(i,100)。沿模 100 的步长 i 行走，轨道长度为 100/g100/g100/g，100 次翻动恰好绕轨道 g 遍，所以轨道上每枚硬币被该人翻 g 次，其他硬币零次。

记 gcd⁡(i,100)\gcd(i,100)gcd(i,100) 为 i 与 100 的最大公约数，φ(m)\varphi(m)φ(m) 为 1 至 m 中与 m 互素的整数个数。g 为偶数时，对正反面无净影响。100 的奇因子只有 1、5、25，因此只需考虑这三类人。g 相同且起点相同的人会访问相同的编号集合；对应人数分别为 φ(100)=40\varphi(100)=40φ(100)=40、φ(20)=8\varphi(20)=8φ(20)=8、φ(4)=4\varphi(4)=4φ(4)=4，都是偶数。

每类中每枚被访问硬币的总翻转次数是“奇数 g × 偶数人数”，仍为偶数。三类再叠加也为偶数，所以所有硬币恢复正面，答案为 100。共同起点使同一 g 类访问同一集合，是分组计算的关键。

g=1、5、25分别对应与100、20、4互素的步长缩放数，人数40、8、4均为偶。即使某枚同时被多个g类访问，每类贡献都为偶，总和仍偶。g=100的第100人只翻零号100次，也无净变化。

同类问题

周期翻转先找轨道与重复数，再在模二意义下累加。改变共同起点或每人操作次数后，分组轨道可能不同，需重新计数。

4. 奇数阶反对称矩阵

题目

实矩阵 AAA 满足 AT=−AA^T=-AAT=−A，阶数 n 为奇数。证明 det⁡A=0\det A=0detA=0，并说明为什么奇数阶条件不可省。

考点：行列式性质；奇数变号；反例。

查看分析与解答

必要知识

反对称矩阵转置后等于整体取负。转置不改行列式，整体取负却相当于每行都乘−1，因此奇数阶时两种操作对行列式给出相反符号。

分析思路

把detA依次改写为detAᵀ、det(−A)，利用奇偶性得到它等于自身相反数。再用二维矩阵检查偶数阶不能推广。

解答步骤

行列式对每一行线性，一行乘−1给一个负号，n行共(−1)ⁿ。实数中d=−d意味着d=0，进而至少有一个非零向量被A映到零。

转置不改变行列式，所以 det⁡A=det⁡AT\det A=\det A^TdetA=detAT。由反对称条件，右侧等于 det⁡(−A)\det(-A)det(−A)；把每一行都乘 -1，共 n 行，得到 det⁡(−A)=(−1)ndet⁡A\det(-A)=(-1)^n\det Adet(−A)=(−1)ndetA。

n 为奇数时，det⁡A=−det⁡A\det A=-\det AdetA=−detA，在实数域上可移项得 2det⁡A=02\det A=02detA=0，所以行列式为零，矩阵不可逆。

偶数阶反例为 (01−10)\begin{pmatrix}0&1\\-1&0\end{pmatrix}(0−1​10​)，它反对称但行列式为 1。因此结论依赖奇数阶，而非所有反对称矩阵都奇异。

二维例子[[0,1],[−1,0]]的行列式为0×0−1×(−1)=1，可逆。三维反对称矩阵无论非对角元素如何选，都必须有零特征值，这与行列式零一致。

同类问题

矩阵对称条件可先作用于行列式、迹或特征值等不变量。证明后用最小维度反例检查哪些假设不可删除。

5. 线性变换幂的秩

题目

线性变换 L 作用在某个有限维实向量空间上，维数可自行选择。下列各序列依次表示 rank⁡(L),…,rank⁡(L6)\operatorname{rank}(L),\ldots,\operatorname{rank}(L^6)rank(L),…,rank(L6)：(5,3,1,0,0,0)(5,3,1,0,0,0)(5,3,1,0,0,0)、(5,3,1,1,1,1)(5,3,1,1,1,1)(5,3,1,1,1,1)、(5,4,3,2,1,0)(5,4,3,2,1,0)(5,4,3,2,1,0)。判断能否实现，并给出构造。

考点：线性链；幂零块；秩损失。

查看分析与解答

必要知识

幂零Jordan块可理解为一条长度m的基向量链：每次应用向前移动一格，越过端点则变零。应用k次后仍保留m−k个独立方向，超过链长则全零。

分析思路

把目标秩序列拆成若干条逐步消失的链，以及始终不消失的可逆部分。块对角拼接后各部分秩相加。

解答步骤

J₄的幂秩为3、2、1、0，J₃为2、1、0、0，相加得到5、3、1、0。两条J₃链加一条恒等方向，则开始5、3，随后只剩恒等方向的一。
