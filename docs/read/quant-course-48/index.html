订单簿与随机模型

48 · 排队模型与扩散近似

由流量平衡推导等待时间，区分总队列、前方数量、首次耗尽和扩散误差。

队列模型记录挂单数量及其变化。流体近似描述大规模平均变化，扩散近似保留随机波动；总队列与某笔订单前方的数量需要分别建模。

队列长度与自己的位置

买一共有100股，自己的订单前面有50股。“总队列100”与“前方50”是两个状态。新限价买单到来会增加总量，通常排在自己之后。主动卖单从队首消耗。撤单可能发生在自己前面，也可能在后面。只看总量无法直接得到等待时间。

先学习一个更简单的服务队列。每秒平均到达8个单位，每秒平均服务10个单位。到达和服务等待均独立且服从指数分布。QQQ 包括正在服务的单位，这就是M/M/1模型：两个M表示无记忆的指数等待，1表示一个服务台。用它理解流量平衡，再修改边界和成交机制以描述订单簿。

平稳分布从流量平衡得到

状态 qqq 以速度 λ\lambdaλ 上升到 q+1q+1q+1，状态 q+1q+1q+1 以速度 μ\muμ 下降到 qqq。平稳时两方向概率流量相等：

πqλ=πq+1μ,πq=(1−ρ)ρq,ρ=λ/μ<1.\pi_q\lambda=\pi_{q+1}\mu,\qquad \pi_q=(1-\rho)\rho^q,\quad\rho=\lambda/\mu<1.πq​λ=πq+1​μ,πq​=(1−ρ)ρq,ρ=λ/μ<1.

ρ\rhoρ 称为利用率。利用几何级数求和，得到 E(Q)=ρ/(1−ρ)E(Q)=\rho/(1-\rho)E(Q)=ρ/(1−ρ)。流量守恒的Little关系 E(Q)=λE(T)E(Q)=\lambda E(T)E(Q)=λE(T) 再给出 E(T)=1/(μ−λ)E(T)=1/(\mu-\lambda)E(T)=1/(μ−λ)，其中 TTT 是从到达到完成服务的总时间。

当 λ=8,μ=10\lambda=8,\mu=10λ=8,μ=10，平均系统人数4，逗留时间0.5秒；平均纯等待还要减去服务时间0.1秒，得到0.4秒。若到达率增到9，逗留时间变成1秒。接近满负荷时，新增少量需求会显著增加等待。

Python9 行
import numpy as np
arrival, service = 8.0, 10.0
rho = arrival/service
q = np.arange(200)
probability = (1-rho)*rho**q
print('概率和', probability.sum())
print('平均系统人数', (q*probability).sum())
print('平均逗留时间', 1/(service-arrival))
assert abs((q*probability).sum()-4.0) < 1e-12

代码把前200个状态的概率相加，结果约1；平均人数约4。几何尾部使后续状态贡献很小。若把到达率改为11，ρ>1\rho>1ρ>1，这套平稳概率公式不再成立，不能把得到的负数当成平均人数。

订单簿耗尽是价格事件

普通服务队列在零处等新顾客，最优报价队列耗尽却可能使价格跳到下一档，并重置观察到的深度。令卖队列、买队列首次耗尽时间为 τa,τb\tau_a,\tau_bτa​,τb​，下一次价格变化在 min⁡(τa,τb)\min(\tau_a,\tau_b)min(τa​,τb​) 发生；简化的一档模型中，卖方先耗尽对应向上变化。

若两侧耗尽时间独立，则 P(min⁡(τa,τb)>t)=P(τa>t)P(τb>t)P(\min(\tau_a,\tau_b)>t)=P(\tau_a>t)P(\tau_b>t)P(min(τa​,τb​)>t)=P(τa​>t)P(τb​>t)。只有数量、到达/消耗机制都对称时，上涨概率才是1/2。两侧相互激发或受共同冲击时，应使用联合过程；同量并不足以保证同概率。

在单位订单的临界对称模型里，新增速度恰好等于成交加撤单速度，价格变化等待可能有 1/t1/t1/t 量级的尾部。此时等待均值可以发散，累积价格极限出现不同于通常有限均值更新过程的时间缩放。一个“平均流入等于流出”的条件，并不意味着等待很短或系统容易交易。

前方数量的流体近似

设总队列 QQQ 近似固定，前方数量为 ZZZ，每秒主动成交量为 mmm、撤单量为 ccc。若撤单在队列内均匀分布，撤在前方的比例约为 Z/QZ/QZ/Q，因此

dZdt=−m−cZ/Q.\frac{dZ}{dt}=-m-cZ/Q.dtdZ​=−m−cZ/Q.

解得 Z(t)=(Z0+mQ/c)e−ct/Q−mQ/cZ(t)=(Z_0+mQ/c)e^{-ct/Q}-mQ/cZ(t)=(Z0​+mQ/c)e−ct/Q−mQ/c。令它等于0，得到到达队首时间

t∗=(Q/c)log⁡(1+cZ0mQ).t_*=(Q/c)\log\left(1+\frac{cZ_0}{mQ}\right).t∗​=(Q/c)log(1+mQcZ0​​).

取 Q=100,Z0=50,m=2,c=3Q=100,Z_0=50,m=2,c=3Q=100,Z0​=50,m=2,c=3，t∗≈18.65t_*\approx18.65t∗​≈18.65 秒。无撤单时要25秒；若错误地把所有撤单都当成发生在前方，会得到 50/(2+3)=1050/(2+3)=1050/(2+3)=10 秒。到队首后，自己的订单还要继续等待足够的主动流量，才能全部成交。

固定 QQQ 隐含新增在补充流失量。若整个队列也在缩短，应同时求解 Q(t)Q(t)Q(t) 与 Z(t)Z(t)Z(t)，并与另一侧耗尽边界比较。价格变化后要按新价位重置状态，不能沿用原位置。

流体路径与扩散误差

流体模型只保留平均净流量。若单位新增与消耗分别是独立泊松过程，短期数量变化的均值为 (λ−μ)dt(\lambda-\mu)dt(λ−μ)dt，方差为 (λ+μ)dt(\lambda+\mu)dt(λ+μ)dt，所以内部状态可近似为

dQt=(λ−μ)dt+λ+μ dWt.dQ_t=(\lambda-\mu)dt+\sqrt{\lambda+\mu}\,dW_t.dQt​=(λ−μ)dt+λ+μ​dWt​.

均值相减、方差相加，是因为两类随机流量独立。随机订单量需要二阶矩，相关事件需要长期协方差。扩散是大量细小事件下的近似，接近零边界或只有一两股时，应返回离散事件机制。

鲨鱼说

协方差，即两个变量偏离各自均值时，共同变化程度的度量。

状态依赖的队列反应模型

用多档深度向量 qqq 表示状态，新增强度 fi(q)f_i(q)fi​(q)、消耗强度 gi(q)g_i(q)gi​(q) 随盘口改变。处于某状态累计10秒、发生新增30次，经验新增强度就是3次/秒；不能用“在全部事件中出现该状态的次数”替代停留时间。

模拟时先加总所有离开强度，按总强度抽等待时间，再按各事件强度占比抽事件类型。生成矩阵对角线取离开强度总和的负值，每行和为零，保证概率守恒。主动订单消耗当前最优非空价位。参考价移动时，档位索引、规模单位与深度状态要一起更新。

用最小状态树计算先耗尽概率

先看只消耗、不新增的自拟队列。买方剩1单位、卖方剩2单位。两侧独立，消耗事件速度均每秒1次。所有下一事件中，两侧各占一半。若下一事件消耗买方，价格向下。若先消耗卖方，状态变成买1卖1，此时双方先耗尽概率各一半。

因此上涨概率为 0.5×0.5=0.250.5\times0.5=0.250.5×0.5=0.25，下跌概率0.75。卖方需要连续两个消耗事件才能抢在买方首次事件之前耗尽。若初始两侧都1单位，则直接得到各0.5。这种状态树把“薄的一侧容易耗尽”变成了明确的概率计算。

加入新增事件后，状态可能反复回访，逐条画树会无限延伸。可以在有限截断状态上联立各状态的命中概率方程：内部概率等于下一状态概率的加权平均，边界给定0或1。截断上限要足够大，并比较提高上限后结果是否稳定。

队列单位与缩放方式

队列用股数计，事件用笔数计，一笔订单可能有100股或1000股。每秒10笔不等于每秒10股。设新增每秒2笔、每笔平均100股，平均新增为200股/秒。方差项还需要订单量平方的平均值，不能只把平均100平方代入，除非每笔恰好固定100股。

流体近似适合大量事件后平均路径，扩散再加入围绕平均路径的波动，离散链保留每一笔的跳变和边界。模型选择可以从目标倒推：研究几分钟平均库存可先用流体，研究一档即将耗尽的概率则需要更细的边界机制。
