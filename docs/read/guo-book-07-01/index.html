库存风险、保留价格与最优报价

由库存损益推导保留价格和最优报价，并用有限库存状态计算报价随风险变化的幅度。

持有库存为什么会改变报价

做市商同时挂出买价与卖价。成交可获得价差，也会改变库存。若已经持有很多股票，继续买入会扩大价格下跌的损失，因此买价应降低，并提高卖出的吸引力。

预测信号与衍生品库存

若价格存在短期漂移，预期升值会提高买入意愿；订单流的自激励会改变两侧成交与逆向选择风险。此时应把信号或订单强度加入状态，不能仅靠固定价差表达。

期权做市还涉及多种风险。若持有股票 qqq 股、期权 mmm 份，短期价格变动的一阶暴露为 q+mΔq+m\Deltaq+mΔ。期权的 Gamma、Vega 和时间价值变化不会因 Delta 对冲而消失。股票对冲本身也有成本，因而需要同时决定期权报价与对冲时机。
