基础理论与原理

相关指标怎样分离出各自的增量信息

用残差、几何投影和完整数值例子理解正交化与多元回归。

两项价值指标给股票的排名几乎一样，把它们同时放进收益回归，为什么系数反而忽高忽低？数据可能足以确定二者合起来的作用，却缺少区分“究竟是哪一个指标起作用”的信息。正交化把后一项中已经被前项解释的部分剔除，使增量关系更容易看清。

从单变量最小二乘开始

把 nnn 个观测排成向量 xxx 与 yyy。先考虑没有截距的回归 y=bx+ey=bx+ey=bx+e。向量内积 xTy=∑ixiyix^{\mathsf T}y=\sum_i x_i y_ixTy=∑i​xi​yi​，于是

b^=xTyxTx.\hat b=\frac{x^{\mathsf T}y}{x^{\mathsf T}x}.b^=xTxxTy​.

分子衡量二者同方向变化，分母按 xxx 的幅度标准化。拟合值 b^x\hat b xb^x 是 yyy 在 xxx 方向的投影；残差与 xxx 垂直，即 xTe=0x^{\mathsf T}e=0xTe=0。

若回归包含截距，先把 xxx 和 yyy 各自减去均值，再使用上述公式；截距为 a^=yˉ−b^xˉ\hat a=\bar y-\hat b\bar xa^=yˉ​−b^xˉ。所以去均值可理解为先剔除“常数方向”。

散点图中的垂直残差对应观测误差；向量空间中的“正交”则表示残差与解释变量的内积为零。它是整个样本的代数关系，不是每个散点都与横轴成直角这种图形判断。

两个变量为什么不能各算各的

多元回归 y=b1x1+b2x2+ey=b_1x_1+b_2x_2+ey=b1​x1​+b2​x2​+e 同时估计两个方向。若 x1Tx2=0x_1^{\mathsf T}x_2=0x1T​x2​=0，它们不重叠，两个系数分别由各自与 yyy 的投影确定。若二者相关，直接分别做两次单变量回归，就会让共同部分被计算两次。

解决方法是先解释 x2x_2x2​ 中与 x1x_1x1​ 有关的部分，保留残差

z2=x2−x1Tx2x1Tx1x1.z_2=x_2-\frac{x_1^{\mathsf T}x_2}{x_1^{\mathsf T}x_1}x_1.z2​=x2​−x1T​x1​x1T​x2​​x1​.

此时 x1Tz2=0x_1^{\mathsf T}z_2=0x1T​z2​=0。完整多元回归中 x2x_2x2​ 的系数可由 b^2=z2Ty/(z2Tz2)\hat b_2=z_2^{\mathsf T}y/(z_2^{\mathsf T}z_2)b^2​=z2T​y/(z2T​z2​) 求出。它衡量的是 x2x_2x2​ 剩余部分对 yyy 的贡献，而不是 x2x_2x2​ 与 yyy 的全部相关性。

一组可以手算的数据

取教学向量 x1=(−1,0,1)x_1=(-1,0,1)x1​=(−1,0,1)、x2=(0,1,2)x_2=(0,1,2)x2​=(0,1,2)，并设 y=(1,2,3)y=(1,2,3)y=(1,2,3)。若暂不加截距，x2x_2x2​ 在 x1x_1x1​ 上的投影系数为 2/2=12/2=12/2=1，残差 z2=(1,1,1)z_2=(1,1,1)z2​=(1,1,1)。于是 b2=(1+2+3)/3=2b_2=(1+2+3)/3=2b2​=(1+2+3)/3=2；再从 yyy 中减去 2x22x_22x2​，得到 (1,0,−1)(1,0,-1)(1,0,−1)，对应 b1=−1b_1=-1b1​=−1。检验可得 y=−x1+2x2y=-x_1+2x_2y=−x1​+2x2​。

这个例子中 z2z_2z2​ 恰好是常数。如果再额外加入截距，三列之间就会完全重复，无法唯一分离三个系数。这说明是否包含截距属于模型的一部分，不能在推导中随意增加。

下面换用四个观测并显式包含截距，比较逐步残差化与一次多元回归。

Python14 行
import numpy as np
x1 = np.array([-1., 0., 1., 2.])
x2 = np.array([0., 2., 1., 4.])
y = 0.5 + 2 * x1 + 3 * x2
controls = np.column_stack([np.ones(4), x1])
z2 = x2 - controls @ np.linalg.lstsq(controls, x2, rcond=None)[0]
b2 = np.dot(z2, y) / np.dot(z2, z2)
X = np.column_stack([controls, x2])
full = np.linalg.lstsq(X, y, rcond=None)[0]
print("完整回归 [截距, x1, x2]：", full)
print("残差化得到的 x2 系数：", b2)
assert np.allclose(full, [0.5, 2, 3])
assert np.isclose(b2, full[-1])
assert np.allclose(controls.T @ z2, 0)

多个变量按顺序正交化

对变量 x0,…,xKx_0,\ldots,x_Kx0​,…,xK​，可令 z0=x0z_0=x_0z0​=x0​，并依次计算

zk=xk−∑j=0k−1zjTxkzjTzjzj.z_k=x_k-\sum_{j=0}^{k-1}\frac{z_j^{\mathsf T}x_k}{z_j^{\mathsf T}z_j}z_j.zk​=xk​−j=0∑k−1​zjT​zj​zjT​xk​​zj​.

这就是 Gram–Schmidt 过程：每一步从新变量中剔除已经保留的方向。最后一项的原模型系数为 bK=zKTy/(zKTzK)b_K=z_K^{\mathsf T}y/(z_K^{\mathsf T}z_K)bK​=zKT​y/(zKT​zK​)。前面的 zjz_jzj​ 系数一般不能直接当成原 xjx_jxj​ 系数。

要一次求出全部原系数，可以倒序回代：

bj=zjT(y−∑k=j+1Kbkxk)zjTzj.b_j=\frac{z_j^{\mathsf T}\left(y-\sum_{k=j+1}^{K}b_kx_k\right)}{z_j^{\mathsf T}z_j}.bj​=zjT​zj​zjT​(y−∑k=j+1K​bk​xk​)​.

先减掉后面已求出的变量贡献，再计算当前变量贡献。数值软件通常使用更稳定的 QR 或相关分解完成这类运算；学习手算有助于理解“控制其他变量后”的含义。

高相关为什么使系数不稳定

若 xkx_kxk​ 几乎可由其他变量解释，残差 zkz_kzk​ 很小。在独立同方差误差模型中，设误差方差为 σ2\sigma^2σ2，则原回归中该系数的方差为

Var⁡(b^k∣X)=σ2zkTzk.\operatorname{Var}(\hat b_k\mid X)=\frac{\sigma^2}{z_k^{\mathsf T}z_k}.Var(b^k​∣X)=zkT​zk​σ2​.

分母越小，用来识别独立作用的信息越少，估计越容易被微小数据变化影响。正交化可以明确重新表达变量，却不会凭空增加原数据的信息。若原变量完全线性相关，zk=0z_k=0zk​=0，应合并、删除重复变量或重新定义问题。

鲨鱼说

把盈利指标对规模和行业回归后取残差，得到的是“同规模、同行业条件下相对更高的盈利”。它与原始盈利指标已经不是同一个特征。保存残差指标时，应同时保存被剔除的变量和回归权重。

截面特征正交化、时间序列因子收益正交化以及双重排序控制变量，处理的对象不同。前两者可在所用样本和内积下实现精确正交；分组控制通常只是近似隔离。更换日期、权重或股票池后，相关关系需要重新计算。

练习

先保留价值指标，再把盈利指标对价值回归取残差；交换顺序后，两个残差指标会完全相同吗？

查看解答

通常不同。先保留的变量获得共同部分，后处理的变量只保留增量部分，因此顺序改变经济解释。在满秩、无额外约束且使用同一变量空间的完整回归中，总拟合空间可以不变，但各个新指标的含义和归因份额会改变。
