36 · 预测模型的训练、验证与回测

用合成价格完成特征、成熟标签、时间验证、模型选择与账户回测，分别评价预测误差和交易净收益。

预测模型的评估需要同时检查特征可用时间、标签实现时间与成交时间。训练、验证和回测分别评价模型拟合、方案选择及交易结果。

预测标签与持有区间

在第ttt天收盘得到信息，下一开盘买入、再下一开盘卖出，对应标签为

yt=Pt+2openPt+1open−1.y_t=\frac{P^{open}_{t+2}}{P^{open}_{t+1}}-1.yt​=Pt+1open​Pt+2open​​−1.

输入使用截至ttt收盘可得的单日收益、三日动量和三日波动。标签直到t+2t+2t+2开盘才完成，所以“特征日期在训练截止之前”还不够，必须确认结果也已经发生。

这一次使用180个时点的人工价格，收益由独立随机波动生成，没有人为注入预测信号。它是负对照：流程即使能够拟合训练数据，也不应因此宣称找到了稳定市场规律。

训练、验证与重估的边界

首次验证从第60天收盘开始，因此训练仅保留标签结束时间不晚于第60天开盘的记录。验证特征日期为60至79，最终测试从90开始。确定惩罚强度后，再用第90天已完成的历史标签重估模型。

候选Ridge强度固定为0.1、1、10；每个候选都在训练段拟合自己的标准化参数。验证比较均方误差，最终测试同时比较常数预测与账户结果。没有用测试收益调整交易阈值。

从原始价格计算特征与标签

单日收益为Pt/Pt−1−1P_t/P_{t-1}-1Pt​/Pt−1​−1，三日动量为Pt/Pt−3−1P_t/P_{t-3}-1Pt​/Pt−3​−1，三日波动是最近三个单日收益的样本标准差。标签使用下一开盘至再下一开盘的价格，不与这些输入混列。

例如第59天特征的标签在61日开盘结束，它不能进入60日训练；第58天特征标签在60日开盘结束，则已可使用。把标签结束时间存成一列，比依靠记忆判断日期更可靠。

import numpy as np
import pandas as pd
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import Ridge
from sklearn.metrics import mean_squared_error

rng = np.random.default_rng(36)
n = 180
close = 100*np.cumprod(1+rng.normal(0, 0.01, n))
opening = np.r_[100.0, close[:-1]]
price = pd.Series(close)
frame = pd.DataFrame({"return1": price.pct_change(fill_method=None),
                      "momentum3": price/price.shift(3)-1,
                      "volatility3": price.pct_change(fill_method=None).rolling(3).std()})
frame["target"] = pd.Series(opening).shift(-2)/pd.Series(opening).shift(-1)-1
frame["label_end"] = np.arange(n)+2
frame = frame.dropna()
columns = ["return1", "momentum3", "volatility3"]
train = frame.loc[frame["label_end"] <= 60]
valid = frame.loc[(frame.index >= 60) & (frame.index < 80)]
test = frame.loc[frame.index >= 90]

def fit_model(alpha, data):
    model = make_pipeline(StandardScaler(), Ridge(alpha=alpha))
    return model.fit(data[columns], data["target"])

scores = {}
for alpha in [0.1, 1.0, 10.0]:
    model = fit_model(alpha, train)
    scores[alpha] = mean_squared_error(valid["target"], model.predict(valid[columns]))
best = min(scores, key=lambda a: (scores[a], a))
ready = frame.loc[frame["label_end"] <= 90]
model = fit_model(best, ready)
prediction = model.predict(test[columns])
baseline = np.full(len(test), ready["target"].mean())
print("validation MSE:", scores, "selected alpha:", best)
print("test MSE model/mean:", mean_squared_error(test["target"], prediction),
      mean_squared_error(test["target"], baseline))

cash, shares, cost = 10000.0, 0, 0.001
nav, trades = [cash], 0
for t, forecast in zip(test.index, prediction):
    price_in = opening[t+1]
    target = int(forecast > 0.002)
    if target and shares == 0:
        shares = int(cash/(price_in*(1+cost)))
        cash -= shares*price_in*(1+cost)
        trades += int(shares > 0)
    elif not target and shares > 0:
        cash += shares*price_in*(1-cost)
        shares = 0
        trades += 1
    nav.append(cash+shares*opening[t+2])
if shares:
    cash += shares*opening[test.index[-1]+2]*(1-cost)
    nav[-1] = cash
    shares = 0
    trades += 1
nav = np.array(nav)
print("synthetic account return:", nav[-1]/nav[0]-1, "trades:", trades)
assert train["label_end"].max() <= 60
assert ready["label_end"].max() <= 90
assert shares == 0 and cash >= 0

代码依赖NumPy、pandas和scikit-learn。数据生成、预处理、候选选择、预测和现金账都包含在内，不需要行情接口。固定随机种子保证同一实验可复现，不表示现实市场规律可重复。

数值结果如何解释

验证选中强度0.1。最终模型均方误差约0.00009322，历史均值预测约0.00008919，模型反而略差，误差约高4.5%。这说明在这条无信号合成路径上，三个特征与Ridge并未超过简单基准。

图中模型预测集中在较小范围，实际收益波动明显更大。单个时期预测方向正确并不足以改善整体误差，需把所有测试时点一起评价。

账户按预测超过0.2%才持有，整数股、每边0.1%费用，最终清仓。程序完成18笔买卖，测试净收益约0.3661%。这个正收益与“预测误差没有超过常数基准”同时成立，因为均方误差与阈值交易评价不同问题。

为什么预测误差不能替代交易评价

均方误差平均惩罚每个时点的平方偏差，交易规则只在超过阈值时改变持仓。模型可能在不交易日期改善误差，却在少数大仓位日期判断错误；也可能误差较大，但恰好选中几个盈利区间。

因此报告应同时列出误差、方向、预测分布、交易次数、净收益、回撤和基准差。若改变阈值，应在训练或验证阶段完成，不能为了让这一次测试盈利而反复调整。成本敏感性也应固定已选模型和规则。

鲨鱼说

模型输出的是预测值，账户执行的是有约束的决策。把两层分别记录，才能判断改善来自预测、仓位规则还是偶然行情。

模型文件之外还要保存什么

研究记录应包含原始数据版本、随机种子、特征定义、标签区间、数据划分、全部候选、选定参数、缩放统计量、执行规则和逐笔账。使用文本或财报时，还需保存公告时间、接收时间、事件去重和资产映射。

把研究迁移到平台时，先检查平台字段、复权、停牌、缺失、费用及订单回调语义。相同策略名称不保证不同平台得到相同结果。模型保存后重新加载，应对固定样本产生相同预测；词表或列顺序改变会使权重失去原含义。

持续更新怎样形成新的检验

可按固定频率滚动训练，每次仅加入已结束的标签，保留各次模型在当时给出的预测，供后续评价。监测输入覆盖、分布、预测误差和执行成本；效果下降时先区分数据变化与关系变化，再决定是否更换模型。

财务模型预测市值、文本模型分类情绪、收益模型预测下一期收益，训练目标不同。把它们接入交易之前，必须各自完成到未来收益的连接。更复杂算法和更多数据是否有价值，应通过同样本、同时间、同成本的比较回答。

练习

第89天的特征对应标签结束日91，能否进入第90天重估？测试均方误差下降10%，能否省略账户回测？

查看解答

不能进入，因为第91天结果尚未发生。误差改善也不能省略回测，仓位阈值、收益幅度、交易约束和费用仍会决定净账户表现；两种结果应分别报告。
