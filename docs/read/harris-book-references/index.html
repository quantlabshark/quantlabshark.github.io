文献阅读方向

交易规则与市场组织可从 General Works 及第 3—6 章的文献入手。研究报价中的信息，可接着查阅第 10、13—14 章。研究执行成本和实证评价，可重点使用第 21—22 章。比较交易场所与制度时，第 23—29 章的文献包括相关理论与历史研究。
