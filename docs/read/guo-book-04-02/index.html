稀疏抽样、子样本与双尺度估计

比较稀疏抽样、子样本平均和双尺度修正，理解噪声偏差与离散误差的权衡。

稀疏抽样减少噪声累计

设共有 n+1n+1n+1 个观测价格，原始间隔为 Δ\DeltaΔ。每隔 KKK 个观测取一个价格，得到约 n/Kn/Kn/K 个收益。噪声方差仍为每个收益约 2a22a^22a2，但参与平方和的收益数量减少，因此噪声偏差约为 2na2/K2na^2/K2na2/K。

代价是有效价格路径被观察得更粗。若一天只用开盘和收盘两个点，同一条首尾价格之间可能有多种波动路径，收益平方不能充分反映日内累计波动。

起点也会影响结果

每隔 KKK 笔抽样，可以从第零笔开始，也可以从第一、第二笔开始。单选一个起点，会让结果受少量边界和局部跳动影响。把 KKK 个错开的子网格分别计算方差，再平均，可利用更多数据。

记第 kkk 个子网格的已实现方差为 RV(k)RV^{(k)}RV(k)，平均为 RV‾=K−1∑kRV(k)\overline{RV}=K^{-1}\sum_kRV^{(k)}RV=K−1∑k​RV(k)。子网格不是独立样本，它们共享同一条有效价格路径，不能把方差简单除以 KKK 当作标准误。

平均法降低对起点的敏感度，却仍有约 2nˉa22\bar n a^22nˉa2 的噪声偏差，nˉ\bar nnˉ 是每个子网格的平均收益数量。平滑并不等于消除了系统偏差。

鲨鱼说

标准误，即用于衡量估计量随抽样变化幅度的标准差估计。

两种时间尺度相互补充

最细尺度的 RVallRV_{\rm all}RVall​ 主要包含大量噪声，所以 RVall/(2n)RV_{\rm all}/(2n)RVall​/(2n) 可用于估计噪声方差。粗尺度更接近有效波动。用前者修正后者，得到

TSRV0=RV‾−nˉnRVall.TSRV_0=\overline{RV}-\frac{\bar n}{n}RV_{\rm all}.TSRV0​=RV−nnˉ​RVall​.

在各子网格近似覆盖整个区间时，有限样本修正常用

TSRV=RV‾−(nˉ/n)RVall1−nˉ/n.TSRV=\frac{\overline{RV}-(\bar n/n)RV_{\rm all}}{1-\bar n/n}.TSRV=1−nˉ/nRV−(nˉ/n)RVall​​.

分母修正减去细尺度方差时一并减掉的有效价格成分。边界缺失仍需处理，特别是在样本很短、KKK 很大时，应核对每个网格实际覆盖的时间。

两项相减后为什么还要除一次

假设各子网格都近似覆盖整段交易时间，E(RV‾)≈IV+2nˉa2E(\overline{RV})\approx IV+2\bar n a^2E(RV)≈IV+2nˉa2，而 E(RVall)≈IV+2na2E(RV_{\rm all})\approx IV+2na^2E(RVall​)≈IV+2na2。乘上比例 r=nˉ/nr=\bar n/nr=nˉ/n 后相减，噪声项恰好抵消，但有效波动也被减去 rIVrIVrIV，留下 (1−r)IV(1-r)IV(1−r)IV。因此需要再除以 1−r1-r1−r。

子网格起点不同，末尾也可能缺少几条记录。例如从第零条每隔三条取样，可能正好到收盘。从第一条开始则未必。此时每个网格对应的有效方差积分区间不同，不能只看收益数量就认为信号部分完全相同。可以采用一致的内部观察窗口，或明确计算边界修正，再比较不同带宽。

鲨鱼说

细尺度数据里既有噪声，也仍有市场变化。拿它来减噪声时，市场信号会一起被减掉一部分；分母就是把这部分尺度恢复回来。

带宽与收敛速度

较小的 KKK 保留更多有效变化，但噪声修正的方差较大。较大的 KKK 减少噪声，却增加离散误差。经典独立噪声条件下，双尺度方法采用 KKK 与 n2/3n^{2/3}n2/3 同阶，误差量级约为 n−1/6n^{-1/6}n−1/6。这与无噪声时常见的 n−1/2n^{-1/2}n−1/2 不同。

更精细的多尺度、核和预平均方法可以在适当条件下达到 n−1/4n^{-1/4}n−1/4。该速度反映固定时间跨度内，越来越小的有效价格增量被观测噪声遮蔽的信息限制；增加交易日数量与加密同一天的采样是两种不同渐近情形。

怎样核查实现

先生成已知波动率的布朗路径，再加入已知噪声，比较原始方差、各子网格方差和双尺度结果。重复模拟后计算偏差与均方误差。单条路径上的估计不必恰好等于真值，不能为使一张图准确而反复选择随机种子或带宽。

有限样本双尺度估计偶尔可能为负，这反映噪声修正超过信号估计。用于后续风险系统时可以设置非负约束，但应同时记录未截断值及截断频率，避免把不稳定性藏起来。

鲨鱼说

粗数据负责看市场变化，细数据负责估计噪声大小。双尺度方法的关键是两者分工，而不是单纯丢掉高频数据。
