基础理论与原理

4.1 市价单、限价单与订单簿

理解报价数量、流动性供求、执行价格不确定性及挂单风险。

把交易意愿写成可执行指令

订单至少说明品种、买卖方向和数量，还可以规定价格、时间、可否部分成交及展示方式。经纪商尚在核验时，订单可能处于待受理状态。受理后未成交、未撤销的订单才进入实际执行过程。研究交易记录时，应区分提交、受理、成交与撤单确认的时间。

报价包含价格与可交易数量。具有约束力的实盘报价与仅供参考的意向报价不同。最新成交价也不是买卖双方都能获得的现成价格。买方挂单让别人有机会卖出，卖方挂单让别人有机会买入，两者都可能提供流动性。接受已有报价的一方则消耗当前可用的流动性。

市价单支付多少成本

市价单要求按当时可得的条件尽快成交。假设买一价为 10.00 元，卖一价为 10.04 元。小额买单可能按 10.04 元成交，小额卖单可能按 10.00 元成交。若以中间价 10.02 元作为比较基准，两边各支付 0.02 元，即半个报价价差。迅速完成一次买卖往返则支付整个价差，另有费用。

大单还会消耗多档报价。自拟卖盘为 10.04 元 100 股、10.05 元 200 股、10.08 元 500 股。买入 400 股时，不能假设全部按卖一价成交。下面只模拟该时点的静态订单簿，不加入新订单和撤单。

Python16 行
asks = [(10.04, 100), (10.05, 200), (10.08, 500)]
remaining = 400
cost = 0.0
fills = []
for price, available in asks:
    filled = min(remaining, available)
    if filled:
        fills.append((price, filled))
        cost += price * filled
        remaining -= filled
    if remaining == 0:
        break
assert remaining == 0
print("成交明细：", fills)
print(f"成交均价：{cost / 400:.4f} 元")
assert abs(cost / 400 - 10.055) < 1e-10

实际订单传到市场时，报价还可能已经变化，这叫执行价格不确定性。有时交易商提供优于公开最优报价的价格，即价格改善；是否发生、改善多少，需要看真实成交记录。

图中灰色表示每档可用数量，绿色表示本次成交数量。400 股买单依次取走 100、200、100 股，最后一档仍有 400 股未成交。

限价决定的是价格边界

买入限价单允许按限价或更低价格成交，卖出限价单允许按限价或更高价格成交。限价为 10.06 元的买单在上述卖盘中可以立即买入前 300 股，剩余 100 股不能主动接受 10.08 元。限价单只规定可接受的价格边界。报价能够匹配现有对手单时，也会立即成交并消耗流动性。

尚不能成交的限价单进入订单簿。提高买价、降低卖价，可以增加成交机会，但让出的价格也更多。报价处于买卖价差之间时，会改善当前最优报价；落在同侧最优价后面，则要等较优订单先成交或离开。

挂单相当于授予可撤销的交易机会

挂出固定卖价后，其他人可以等待消息再决定是否购买。价值上升时，对方愿意买。价值下降时，对方可以放弃。挂单者没有收到期权费，却暂时给了市场选择权。它与期权合约并不相同：挂单通常可撤销、可能先被别人成交，也没有一个排他的权利持有人。

有效时间越长、价格波动越大、报价越有利，这个选择机会通常越有价值。挂单者希望换取较好成交价，却承担两种风险：市场走远而未成交，以及成交后价格继续向不利方向变化。后一种情况若源于对手掌握更多价值信息，就是逆向选择。评价挂单策略时，应将成交价格、成交比例和未成交后的处理成本共同计入。

鲨鱼说

逆向选择，即交易对手掌握的信息差异，使成交样本偏向对自身不利状态的现象。

练习

为什么买单限价低于现价，仍不能说明该订单风险很低？

查看解答

限价控制的是买入价格上界，并未限定买入后资产的最低价值。坏消息可能使价值快速下降，买单恰好在撤销前成交；也可能价格上涨导致一直买不到。两种风险都不能从“低于现价”这一条件中排除。
