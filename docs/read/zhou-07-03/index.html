蒙特卡洛与有限差分

随机变量生成、方差缩减、蒙特卡洛Greeks、圆周率估计及三种有限差分格式。

蒙特卡洛通过随机样本估计期望，有限差分通过离散网格近似微分方程。两种方法分别受到抽样误差和离散误差影响，需要采用相应的收敛检查。

数值定价的两种路径

没有闭式解时，可直接模拟风险中性价格路径并平均折现支付，也可把定价偏微分方程离散为代数方程。前者以大数定律为基础，后者以微分方程及初边值条件为基础。路径依赖期权需记录足够的路径状态。美式行权还需比较立即行权与条件继续价值，不能仅平均到期支付。

蒙特卡洛 A：欧式看涨定价

题目

如何用蒙特卡洛方法估计欧式看涨价格？

考点：风险中性模拟；样本均值；标准误。

查看分析与解答

必要知识

蒙特卡洛用多次独立模拟的平均支付近似期望。定价模拟应使用风险中性漂移 r，而非历史收益均值；价格计算还要折现。标准误衡量估计均值的随机波动，区别于单条支付的标准差。

分析思路

欧式看涨只依赖到期价，因此直接模拟精确终端分布，不必把一年切成许多小步。先得到每条折现支付，再计算均值与标准误，并用解析价格核对。

解答步骤

每条样本步骤为：生成 Z，计算 S_T，计算 max(S_T−K,0)，乘 e⁻ʳᵗ。标准差 s_Y 反映单条支付离散程度；除以 √M 才是平均价格估计的标准误。

import math
import random
from statistics import mean, stdev

def european_call_mc(s, k, r, sigma, tau, paths=100000, seed=2026):
    if s <= 0 or k < 0 or sigma < 0 or tau < 0:
        raise ValueError('invalid pricing inputs')
    if paths < 2:
        raise ValueError('at least two paths are required')
    rng = random.Random(seed)
    discount = math.exp(-r * tau)
    drift = (r - sigma * sigma / 2) * tau
    scale = sigma * math.sqrt(tau)
    payoffs = [discount * max(s * math.exp(drift + scale * rng.gauss(0, 1)) - k, 0)
               for _ in range(paths)]
    return mean(payoffs), stdev(payoffs) / math.sqrt(paths)

蒙特卡洛 B：由均匀分布生成正态分布

题目

若计算机只能生成 U(0,1)U(0,1)U(0,1) 随机数，如何生成 N(μ,σ2)N(\mu,\sigma^2)N(μ,σ2)？

考点：逆变换；拒绝采样；分布归一化。

查看分析与解答

必要知识

若 F 连续且递增，U 均匀时，P(F⁻¹(U)≤x)=P(U≤F(x))=F(x)，这解释逆变换法。拒绝采样则从容易生成的分布出发，按密度比有选择地接受，使接受后的密度变成目标。

分析思路

先说明一般生成方法，再给一个只用均匀数和初等函数的正态实现。半正态只产生非负值，最后必须独立随机加正负号。

解答步骤

指数提议 Y=−ln(1−U) 的尾概率 P(Y>y)=P(U>1−e⁻ʸ)=e⁻ʸ，因此密度为 e⁻ʸ。半正态与指数的密度比配方后，在 y=1 取最大值 M=√(2e/π)，接受概率除以 M 后恰为 exp[−(y−1)²/2]。

先产生标准正态 ZZZ，再令 X=μ+σZX=\mu+\sigma ZX=μ+σZ。

逆变换法利用 Z=Φ−1(U)Z=\Phi^{-1}(U)Z=Φ−1(U)。一般连续分布也可由广义逆函数 F−1(U)F^{-1}(U)F−1(U) 生成。标准正态的逆分布函数没有初等表达式，可用可靠的数值近似或求根算法计算；从 Φ′(z)=ϕ(z)\Phi'(z)=\phi(z)Φ′(z)=ϕ(z) 还可写出逆函数微分方程 dz/du=1/ϕ(z)dz/du=1/\phi(z)dz/du=1/ϕ(z)，但尾部的数值条件较差。

import math
import random

def normal_from_uniform(mu=0.0, sigma=1.0, rng=None):
    if sigma < 0:
        raise ValueError('sigma must be nonnegative')
    if sigma == 0:
        return mu
    rng = random if rng is None else rng
    while True:
        y = -math.log1p(-rng.random())
        if rng.random() <= math.exp(-0.5 * (y - 1) ** 2):
            z = y if rng.random() < 0.5 else -y
            return mu + sigma * z

平均接受率为 1/M≈0.7602，平均约需 1.3155 次提议。随机符号各半使正负两侧密度分别为半正态密度的一半，恢复标准正态。最后 μ+σZ 的均值为 μ、方差为 σ²。sigma=0 时可以直接返回 μ，避免无意义采样。

蒙特卡洛 C：方差缩减

题目

说明提高蒙特卡洛估计效率的常见方差缩减方法。

考点：估计量方差；控制变量；重要性权重。

查看分析与解答

必要知识

同样的计算预算下，目标是降低最终估计量的方差，而不是只增加样本数。设计新估计量时，要同时检查是否仍估计同一个期望、是否引入偏差、样本之间是否独立。

分析思路

按利用的信息分类：对偶利用负相关，控制变量利用已知均值，重要性抽样改变抽样区域，分层或低差异方法改善覆盖。每种方法都需说明误差怎样评估。

解答步骤

对偶均值 A=[Y(Z)+Y(−Z)]/2 的方差为 [Var(Y)+Cov(Y(Z),Y(−Z))]/2，而两个独立样本均值方差是 Var(Y)/2。因此负协方差才产生同预算改善，不能只因为“用了成对样本”就认为有效。

设单路径支付方差为 σY2\sigma_Y^2σY2​，独立 MMM 条路径的均值方差为 σY2/M\sigma_Y^2/MσY2​/M。方差缩减通过改变样本或估计量结构，在给定计算量下降低有效方差。

对偶变量。 对同一标准正态向量 ZZZ，同时计算 Y(Z)Y(Z)Y(Z) 与 Y(−Z)Y(-Z)Y(−Z)，取平均。两者分布一致；若协方差为负，成对平均的方差低于两份独立样本的平均。对股票单调增加的欧式看涨，反号路径通常具有这一性质。

矩匹配。 先抽取一批样本，再将样本均值调整为零、样本方差调整为一，使有限样本更接近目标的一阶、二阶矩。调整后的样本相互依赖，且每个调整后样本一般不再严格服从原目标分布，因此非线性支付可能产生有限样本偏差。误差评估应按独立批次进行，并检查随批内样本数增加的偏差，不能仍把每条路径当作独立观测。

控制变量。 目标为 E[X]E[X]E[X]，若相关变量 YYY 的期望 μY\mu_YμY​ 已知，则

μ^CV=Xˉ−β(Yˉ−μY).\widehat\mu_{CV}=\bar X-\beta(\bar Y-\mu_Y).μ​CV​=Xˉ−β(Yˉ−μY​).

固定 β\betaβ 时保持无偏，方差最小的系数为 β∗=Cov⁡(X,Y)/Var⁡(Y)\beta^*=\operatorname{Cov}(X,Y)/\operatorname{Var}(Y)β∗=Cov(X,Y)/Var(Y)。取系数 1，可得到 Xˉ+μY−Yˉ\bar X+\mu_Y-\bar YXˉ+μY​−Yˉ；计算两个支付时使用共同路径增强相关性。

重要性抽样。 目标积分 Ef[h(X)]E_f[h(X)]Ef​[h(X)] 可改写为

Eg[h(Y)f(Y)g(Y)],E_g\left[h(Y)\frac{f(Y)}{g(Y)}\right],Eg​[h(Y)g(Y)f(Y)​],

import random

def estimate_pi(points=1000000, seed=2026):
    if points <= 0:
        raise ValueError('points must be positive')
    rng = random.Random(seed)
    inside = 0
    for _ in range(points):
        x, y = rng.random(), rng.random()
        inside += x * x + y * y <= 1.0
    return 4 * inside / points

有限差分 A：显式、隐式与 Crank–Nicolson

题目

简述显式差分、隐式差分和 Crank–Nicolson 方法。

考点：有限差分；时间离散；三对角系统。

查看分析与解答

必要知识

网格值 u_jⁿ 表示时间 nΔτ、位置 x_j 的函数近似。中心二阶差分 [u_(j−1)−2u_j+u_(j+1)]/Δx² 近似空间二阶导数。显式、隐式的区别在于用旧时层还是新时层计算这个空间项。

分析思路

先统一写出时间差商，再决定右侧在哪个时层取值。新时层包含相邻未知量时，移到左侧就形成三对角线性系统；Crank–Nicolson 则取新旧两层平均。

解答步骤

显式从 (u_j^(n+1)−u_jⁿ)/Δτ=κ(u_(j−1)ⁿ−2u_jⁿ+u_(j+1)ⁿ)/Δx² 出发，乘 Δτ 并移项得到更新式。隐式将右侧所有上标换成 n+1，再把未知项收集到左边。

有限差分 B：时间与空间步数的稳定性

题目

显式求解抛物型方程时，时间步数过多还是空间步数过多更容易产生数值不稳定？

考点：稳定性；傅里叶模态；网格尺度。

查看分析与解答

必要知识

数值稳定性描述小误差是否随迭代失控增长。显式热方程格式的关键无量纲量是 α=κΔτ/Δx²，空间步长以平方进入，所以加密空间网格对稳定性的影响特别强。

分析思路

从加权平均的系数非负性理解稳定，再用傅里叶放大因子验证完整条件。将条件改写为 Δτ≤Δx²/(2κ)，直接回答哪种网格变化更危险。

解答步骤

若 0≤α≤1/2，三个系数 α、1−2α、α 非负且和为一，新值不超过旧层邻域的最大最小范围。α>1/2 时中心系数为负，高频交替误差可能被放大。

对上述一维热方程显式格式，稳定条件为

0≤α=κΔτ(Δx)2≤12.0\le\alpha=\frac{\kappa\Delta\tau}{(\Delta x)^2}\le\frac12.0≤α=(Δx)2κΔτ​≤21​.

可从系数均非负得到最大值原理，也可代入 Fourier 模式得到放大因子 G=1−4αsin⁡2(θ/2)G=1-4\alpha\sin^2(\theta/2)G=1−4αsin2(θ/2)，要求所有频率均满足 ∣G∣≤1|G|\le1∣G∣≤1，得到同一条件。

固定空间网格时，增加时间步数减小 Δτ\Delta\tauΔτ，有利于稳定；固定时间步长时，增加空间步数减小 Δx\Delta xΔx，会使 α\alphaα 增大，可能触发不稳定。因此空间步长减半时，显式时间步长至少应减至四分之一。

后向欧拉与 Crank–Nicolson 对线性热方程具有无条件线性稳定性，但仍需适当的网格分辨率获得精度。Crank–Nicolson 的高频模态在大步长下还可能出现符号交替振荡。稳定、精度和保持支付非负是不同性质。

import math

def explicit_heat(intervals=50, steps=500, horizon=0.1):
    if intervals < 2 or steps < 1 or horizon < 0:
        raise ValueError('invalid grid')
    dx, dt = 1 / intervals, horizon / steps
    alpha = dt / (dx * dx)
    if alpha > 0.5:
        raise ValueError('explicit scheme is unstable for this grid')
    u = [math.sin(math.pi * j * dx) for j in range(intervals + 1)]
    u[0] = u[-1] = 0.0
    for _ in range(steps):
        v = [0.0] * (intervals + 1)
        for j in range(1, intervals):
            v[j] = alpha * u[j - 1] + (1 - 2 * alpha) * u[j] + alpha * u[j + 1]
        u = v
    exact = [math.exp(-math.pi ** 2 * horizon) * math.sin(math.pi * j * dx)
             for j in range(intervals + 1)]
    return max(abs(a - b) for a, b in zip(u, exact))
