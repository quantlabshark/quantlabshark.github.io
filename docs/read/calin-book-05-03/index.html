伊藤等距、鞅性质与连续版本

证明随机积分的均值、协方差和条件预测性质，区分零条件均值与独立增量。

积分保留线性和区间可加性

若 H,GH,GH,G 可预测且在 [0,T][0,T][0,T] 上满足平方可积条件，则

∫0T(aHt+bGt)dWt=a∫0THtdWt+b∫0TGtdWt.\int_0^T(aH_t+bG_t)dW_t=a\int_0^TH_tdW_t+b\int_0^TG_tdW_t.∫0T​(aHt​+bGt​)dWt​=a∫0T​Ht​dWt​+b∫0T​Gt​dWt​.

积分也可以按时间区间拆分。两条性质先对有限和成立，再由均方极限推广。但随机积分不保留普通正测度积分的单调性：即使 Ht≥0H_t\ge0Ht​≥0，∫HtdWt\int H_tdW_t∫Ht​dWt​ 仍可能为负，因为布朗增量有正有负。

交叉项如何消失

对简单过程，积分平方展开含 HiΔWiHjΔWjH_i\Delta W_iH_j\Delta W_jHi​ΔWi​Hj​ΔWj​。设 i<ji<ji<j，则 HiΔWiHjH_i\Delta W_iH_jHi​ΔWi​Hj​ 在 tjt_jtj​ 已知，而 ΔWj\Delta W_jΔWj​ 对当时信息条件均值为零，所以该乘积的期望为零。

不能把所有因子都声称为相互独立，因为后面的权重 HjH_jHj​ 可以依赖前面的增量。正确的理由是对最后一个尚未发生的增量取条件期望。由此得到伊藤等距：

E[(∫0THtdWt)2]=E∫0THt2dt.\mathbb E\left[\left(\int_0^TH_tdW_t\right)^2\right]=\mathbb E\int_0^TH_t^2dt.E​(∫0T​Ht​dWt​)2​=E∫0T​Ht2​dt.

利用极化或直接展开，还可得协方差公式

E[(∫0THtdWt)(∫0TGtdWt)]=E∫0THtGtdt.\mathbb E\left[\left(\int_0^TH_tdW_t\right)\left(\int_0^TG_tdW_t\right)\right] =\mathbb E\int_0^TH_tG_tdt.E[(∫0T​Ht​dWt​)(∫0T​Gt​dWt​)]=E∫0T​Ht​Gt​dt.

鲨鱼说

条件期望，即给定已有信息后，对可能结果按条件概率求平均。

权重依赖过去时怎样算交叉项

取 T=1T=1T=1，前半段权重为 1，后半段权重为 W1/2W_{1/2}W1/2​。令 A=W1/2A=W_{1/2}A=W1/2​、B=W1−W1/2B=W_1-W_{1/2}B=W1​−W1/2​，则 A,BA,BA,B 独立，均值均为 0，方差均为 1/21/21/2。对应积分为

I=A+AB.I=A+AB.I=A+AB.

后半段权重 AAA 依赖前半段的路径，所以不能把 AAA 与整个积分当成独立变量。直接展开：

E[I2]=E[A2]+2E[A2B]+E[A2B2]=12+0+12×12=34.E[I^2]=E[A^2]+2E[A^2B]+E[A^2B^2] =\frac12+0+\frac12\times\frac12=\frac34.E[I2]=E[A2]+2E[A2B]+E[A2B2]=21​+0+21​×21​=43​.

其中 E[A2B]=E[A2]E[B]=0E[A^2B]=E[A^2]E[B]=0E[A2B]=E[A2]E[B]=0 用到了 A,BA,BA,B 的独立性。按等距公式计算则为

E∫01Ht2dt=12+12E[W1/22]=34.E\int_0^1H_t^2dt =\frac12+\frac12E[W_{1/2}^2]=\frac34.E∫01​Ht2​dt=21​+21​E[W1/22​]=43​.

两条路线给出相同结果。零均值来自每一步增量在权重确定以后才发生；它不要求权重自身是常数。

积分过程是鞅

令 It=∫0tHsdWsI_t=\int_0^tH_sdW_sIt​=∫0t​Hs​dWs​。在每个有限区间满足平方可积条件时，ItI_tIt​ 是平方可积鞅，均值为零。对 s<ts<ts<t，

E[It−Is∣Fs]=0.\mathbb E[I_t-I_s\mid\mathcal F_s]=0.E[It​−Is​∣Fs​]=0.

对应的条件二阶矩为

E[(It−Is)2∣Fs]=E[∫stHu2du∣Fs].\mathbb E[(I_t-I_s)^2\mid\mathcal F_s] =\mathbb E\left[\int_s^tH_u^2du\mid\mathcal F_s\right].E[(It​−Is​)2∣Fs​]=E[∫st​Hu2​du∣Fs​].

如果只研究有限时间 [0,T][0,T][0,T]，不需要额外要求从 0 到无穷的平方积分有限；无限时间收敛才需要进一步的全局控制。

条件等距为什么仍然成立

先把 [s,t][s,t][s,t] 分成网格，并将积分写为 ∑iHiΔWi\sum_iH_i\Delta W_i∑i​Hi​ΔWi​。交叉项在最后一个增量发生前条件化后为零；对角项满足

E[Hi2(ΔWi)2∣Fs]=E[E[Hi2(ΔWi)2∣Fti]∣Fs]=ΔtiE[Hi2∣Fs].\mathbb E[H_i^2(\Delta W_i)^2\mid\mathcal F_s] =\mathbb E[\mathbb E[H_i^2(\Delta W_i)^2\mid\mathcal F_{t_i}]\mid\mathcal F_s] =\Delta t_i\mathbb E[H_i^2\mid\mathcal F_s].E[Hi2​(ΔWi​)2∣Fs​]=E[E[Hi2​(ΔWi​)2∣Fti​​]∣Fs​]=Δti​E[Hi2​∣Fs​].

对各格求和，再由平方范数逼近取极限，就得到条件二阶矩公式。HiH_iHi​ 可以依赖 sss 之后、tit_iti​ 之前的信息，故不能直接把它移到最外层 Fs\mathcal F_sFs​ 条件期望之外。

鞅性质的证明也用同样时间顺序：每个未来增量先对发生前信息取条件均值，得到零，再用塔式法则退回 Fs\mathcal F_sFs​。它只给零条件均值，不保证整个条件分布与过去无关。

零条件均值不等于独立未来

取 Hu=WsH_u=W_sHu​=Ws​，作用在固定区间 (s,t](s,t](s,t]，则未来积分增量为 Ws(Wt−Ws)W_s(W_t-W_s)Ws​(Wt​−Ws​)。给定过去时均值为零，但条件方差为 Ws2(t−s)W_s^2(t-s)Ws2​(t−s)，显然依赖过去。它不是独立增量。

因此一般伊藤积分是鞅，却未必是高斯过程或具有独立增量。确定性被积函数具有更强结构，将在 Wiener 积分中单独讨论。随机波动系数通常会形成状态依赖的条件分布。

为什么积分可以取连续路径版本

简单过程积分在每个区间内都是布朗增量的线性组合，路径连续。取逼近过程 H(n)H^{(n)}H(n)，对应积分 I(n)I^{(n)}I(n)。Doob 不等式和等距关系给出

E[sup⁡t≤T∣It(n)−It(m)∣2]≤4E∫0T∣Ht(n)−Ht(m)∣2dt.\mathbb E\left[\sup_{t\le T}|I_t^{(n)}-I_t^{(m)}|^2\right] \le4\mathbb E\int_0^T|H_t^{(n)}-H_t^{(m)}|^2dt.E[t≤Tsup​∣It(n)​−It(m)​∣2]≤4E∫0T​∣Ht(n)​−Ht(m)​∣2dt.

选取误差可求和的子序列，可以获得几乎必然的一致收敛。连续函数的一致极限仍连续，从而构造出积分的连续版本。单有“每两个相近时刻的均方差很小”，本身不足以完成这一步路径证明。

积分还满足 [I]t=∫0tHs2ds[I]_t=\int_0^tH_s^2ds[I]t​=∫0t​Hs2​ds。随机被积函数会使积分的二次变差随机；当 HHH 变化时，路径的局部波动强度也随之变化。

鲨鱼说 伊藤等距提供了最直接的误差度量：被积函数在“时间乘概率”的平方平均误差是多少，终点积分的均方误差就是多少。它既是理论构造工具，也是数值检验工具。

从终点误差到连续路径

可以选取一列简单逼近，使相邻积分满足 E[sup⁡t≤T∣It(n+1)−It(n)∣2]≤2−4n\mathbb E[\sup_{t\le T}|I_t^{(n+1)}-I_t^{(n)}|^2]\le2^{-4n}E[supt≤T​∣It(n+1)​−It(n)​∣2]≤2−4n。Markov 不等式给出相邻路径最大差超过 2−n2^{-n}2−n 的概率不超过 2−2n2^{-2n}2−2n，概率和有限。

Borel–Cantelli 引理使这些超差最终不再发生。而 ∑n2−n\sum_n2^{-n}∑n​2−n 收敛，所以相邻差在整段时间上一致可求和，得到连续函数的一致极限。这说明为什么需要 Doob 的最大值控制：仅有每个固定时刻的均方收敛，不能直接保证同一条路径连续。

对简单权重，局部平方增量贡献为 Hi2ΔtiH_i^2\Delta t_iHi2​Δti​，加总后得到积分的二次变差 [I]t=∫0tHs2ds[I]_t=\int_0^tH_s^2ds[I]t​=∫0t​Hs2​ds。若 HHH 随状态变化，这个累计波动尺度也随机；即使 E[It]=0\mathbb E[I_t]=0E[It​]=0，不同路径可能积累不同的二次变差。

练习：比较两种权重

令 I=∫01Wt dWtI=\int_0^1W_t\,dW_tI=∫01​Wt​dWt​，J=∫01t dWtJ=\int_0^1t\,dW_tJ=∫01​tdWt​。求两者的协方差，判断能否仅凭该结果断言独立。

查看解答

协方差为 E∫01tWtdt=0\mathbb E\int_0^1tW_tdt=0E∫01​tWt​dt=0，因为每个 WtW_tWt​ 的均值为零。但是零协方差不足以推出独立；这里 I=(W12−1)/2I=(W_1^2-1)/2I=(W12​−1)/2 非正态，不能使用联合正态的结论。

进一步有 Cov⁡(W1,J)=∫01tdt=1/2\operatorname{Cov}(W_1,J)=\int_0^1t dt=1/2Cov(W1​,J)=∫01​tdt=1/2，二者联合高斯。利用高斯四阶矩公式可得 E[IJ2]=(1/2)×2(1/2)2=1/4\mathbb E[I J^2]=(1/2)\times2(1/2)^2=1/4E[IJ2]=(1/2)×2(1/2)2=1/4，而 E[I]E[J2]=0\mathbb E[I]\mathbb E[J^2]=0E[I]E[J2]=0。所以 I,JI,JI,J 实际不独立。

不用直接引用高斯四阶矩，也能计算这个混合矩。令 Z=W1Z=W_1Z=W1​，将 JJJ 正交分解为 J=Z/2+εJ=Z/2+\varepsilonJ=Z/2+ε，其中 ε\varepsilonε 与 ZZZ 独立、均值为零、方差为 1/121/121/12。于是 E[J2∣Z]=Z2/4+1/12\mathbb E[J^2\mid Z]=Z^2/4+1/12E[J2∣Z]=Z2/4+1/12，从而

E[IJ2]=12E[(Z2−1)(Z24+112)]=18(3−1)+124(1−1)=14.\mathbb E[IJ^2]=\frac12\mathbb E\left[(Z^2-1)\left(\frac{Z^2}{4}+\frac1{12}\right)\right] =\frac18(3-1)+\frac1{24}(1-1)=\frac14.E[IJ2]=21​E[(Z2−1)(4Z2​+121​)]=81​(3−1)+241​(1−1)=41​.

这与独立时应有的零值不同，提供了具体反证。零协方差只检查一阶乘积 IJIJIJ，这里用 IJ2IJ^2IJ2 检测到了非线性依赖。
