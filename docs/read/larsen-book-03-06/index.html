联合分布与边际分布

从联合概率表和三角支持区域计算边际分布、事件概率及协方差。

同时记录两个变量时，需要知道它们怎样共同出现。仅有各自的分布，不能确定两者是否独立，也不能确定它们的和如何波动。

联合表与边际概率

设 X、Y 都取 0 或 1，联合概率如下。

X、Y Y=0 Y=1 X 的边际
X=0 0.1 0.2 0.3
X=1 0.3 0.4 0.7
Y 的边际 0.4 0.6 1

每格记录 P(X=x,Y=y)P(X=x,Y=y)P(X=x,Y=y)。沿行求和得到 pX(x)p_X(x)pX​(x)，沿列求和得到 pY(y)p_Y(y)pY​(y)。例如 P(X=1∣Y=0)=0.3/0.4=0.75P(X=1\mid Y=0)=0.3/0.4=0.75P(X=1∣Y=0)=0.3/0.4=0.75，大于无条件概率 0.7，说明 Y 的信息改变了 X 的概率。

连续变量在支持区域上积分

连续情形用联合密度 f(x,y)f(x,y)f(x,y)，边际密度为 fX(x)=∫f(x,y)dyf_X(x)=\int f(x,y)dyfX​(x)=∫f(x,y)dy。积分范围由支持区域决定。设 0<x<y<10<x<y<10<x<y<1 时密度为 2，其他位置为零。区域面积为 1/2，所以总概率为 1。

固定 x 后，y 从 x 到 1；固定 y 后，x 从 0 到 y。因此

fX(x)=∫x12dy=2(1−x),fY(y)=∫0y2dx=2y,f_X(x)=\int_x^12dy=2(1-x),\qquad f_Y(y)=\int_0^y2dx=2y,fX​(x)=∫x1​2dy=2(1−x),fY​(y)=∫0y​2dx=2y,

两者都仅在 (0,1) 内非零。

联合分布函数与多维样本

联合分布函数定义为 FX,Y(x,y)=P(X≤x,Y≤y)F_{X,Y}(x,y)=P(X\le x,Y\le y)FX,Y​(x,y)=P(X≤x,Y≤y)。矩形 a<X≤b,c<Y≤da<X\le b,c<Y\le da<X≤b,c<Y≤d 的概率可用四个角作容斥：

F(b,d)−F(a,d)−F(b,c)+F(a,c).F(b,d)-F(a,d)-F(b,c)+F(a,c).F(b,d)−F(a,d)−F(b,c)+F(a,c).

若联合密度存在，则 F 是对左下区域的二重积分；在可微处，f(x,y)=∂2F/∂x∂yf(x,y)=\partial^2F/\partial x\partial yf(x,y)=∂2F/∂x∂y。离散表中，F(0,0)=0.1F(0,0)=0.1F(0,0)=0.1、F(1,0)=0.4F(1,0)=0.4F(1,0)=0.4、F(0,1)=0.3F(0,1)=0.3F(0,1)=0.3、F(1,1)=1F(1,1)=1F(1,1)=1。

n 个变量的共同独立要求联合分布等于全部边际分布的乘积。仅检查两两独立还不够：让 A、B 为独立公平零一变量，C 表示两者是否不同。三对变量分别独立，但 A、B 一旦给定，C 已确定，因此三者并不共同独立。

若 X1,…,XnX_1,\ldots,X_nX1​,…,Xn​ 共同独立且具有相同分布，便称它们是来自该总体的随机样本，常缩写为 iid。连续情形的联合密度为 ∏i=1nf(xi;θ)\prod_{i=1}^nf(x_i;\theta)∏i=1n​f(xi​;θ)，这正是后续构造似然函数的起点。

鲨鱼说 积分上下限表达了“哪些组合可能出现”。即使区域内密度是常数，也要先保留区域形状，才能正确计算边际分布。
