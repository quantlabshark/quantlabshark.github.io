策略与回测

24 · 样本外回测与研究报告

完成一次按时间划分的均线策略实验，检查交易时序、验证集选参、测试基准与费用敏感性。

样本外回测评价预先确定的规则在后续时期的表现。报告将参数选择、资金核算、基准比较和结果解释连接起来，使读者能够追溯结论的依据。

三个均线窗口，什么时候才能选出一个

想检验“价格高于近期均价后，是否仍会继续上涨”，可以设置2、3、4日三个候选窗口。但如果先看完整行情，再选择赚钱最多的窗口，得到的是经过挑选的历史赢家。它尚未回答新时期会发生什么。

把36个时点分成三段：0—17用于开发程序，18—23用于比较窗口，24—35用于最终评价。验证段选择一次窗口，最终测试只执行这个选择。训练和验证可以反复使用，测试一旦被用来调整规则，就已经成为新的开发数据。

图中上方显示三个区间的时间位置，下方只展示固定窗口在测试段的净值及同口径买入持有。曲线从相同资金开始，终点均计入清仓费用。

从上一日收盘形成今日订单

均线窗口为LLL时，时点ttt的开盘信号使用Pt−1closeP^{close}_{t-1}Pt−1close​及截至t−1t-1t−1的LLL个收盘价。高于均价且当前空仓就买入，否则清仓。当天尚未发生的收盘价不能用于当天开盘交易。

每段开始资金10000元，只买整数股，不借款、不卖空，买卖每边费率0.1%。买入数量按⌊C/[P(1+c)]⌋\lfloor C/[P(1+c)]\rfloor⌊C/[P(1+c)]⌋确定，确保预留手续费。每个区间最后按指定开盘价清仓，现金收益设为零。

例如现金10000元、买价102元，能买⌊10000/(102×1.001)⌋=97\lfloor10000/(102\times1.001)\rfloor=97⌊10000/(102×1.001)⌋=97股，买入及费用为9903.894元，剩余96.106元。若忽略费用计算数量，在现金接近整数股金额时可能产生透支。

训练、验证与样本外回测

下面只使用程序内的模拟价格，依赖NumPy与pandas。backtest负责执行固定规则；窗口选择留在函数之外，因此可以清楚看到哪些数据参与了选择。

Python63 行
import numpy as np
import pandas as pd

close = np.array([100,101,102,101,100,99,100,102,104,103,102,104,
                  105,106,104,103,102,104,105,104,103,101,100,102,
                  103,105,106,104,103,101,102,104,106,105,107,108], dtype=float)
opening = np.array([100,100,101,102,101,100,99,100,102,104,103,102,
                    104,105,106,104,103,102,104,105,104,103,101,100,
                    102,103,105,106,104,103,101,102,104,106,105,107], dtype=float)

def backtest(window, start, end, cost=0.001):
    average = pd.Series(close).rolling(window).mean().to_numpy()
    cash, shares = 10000.0, 0
    nav, orders = [cash], []
    for t in range(start, end):
        target = int(t >= window and close[t-1] > average[t-1])
        price = opening[t]
        if target == 1 and shares == 0:
            quantity = int(cash / (price * (1 + cost)))
            if quantity > 0:
                cash -= quantity * price * (1 + cost)
                shares = quantity
                orders.append((t, "buy", quantity, price))
        elif target == 0 and shares > 0:
            cash += shares * price * (1 - cost)
            orders.append((t, "sell", shares, price))
            shares = 0
        assert cash >= -1e-8 and shares >= 0
        nav.append(cash + shares * opening[t+1])
    if shares:
        cash += shares * opening[end] * (1 - cost)
        orders.append((end, "sell", shares, opening[end]))
        nav[-1] = cash
        shares = 0
    assert shares == 0
    return np.array(nav), orders

def buy_and_hold(start, end, cost=0.001):
    quantity = int(10000 / (opening[start] * (1 + cost)))
    cash = 10000 - quantity * opening[start] * (1 + cost)
    nav = np.r_[10000.0, cash + quantity * opening[start+1:end+1]]
    nav[-1] -= quantity * opening[end] * cost
    return nav

def metrics(nav):
    drawdown = nav / np.maximum.accumulate(nav) - 1
    return {"return": float(nav[-1]/nav[0]-1),
            "max_drawdown": float(-drawdown.min())}

candidates = [2, 3, 4]
validation = {w: backtest(w, 18, 23)[0][-1] for w in candidates}
best = max(candidates, key=lambda w: (validation[w], -w))
nav, orders = backtest(best, 24, 35)
print("validation final wealth:", validation)
print("selected window:", best)
print("strategy:", metrics(nav))
print("buy and hold:", metrics(buy_and_hold(24, 35)))
print("cash:", metrics(np.full(12, 10000.0)))
print("orders:", orders)
for cost in [0.0, 0.001, 0.002]:
    scenario, _ = backtest(best, 24, 35, cost=cost)
    print("cost scenario:", cost, metrics(scenario))
assert len(nav) == 12

开盘时点从24到35形成11个持有区间，连同初始净值共12个值。循环先处理当前订单，再按下一开盘价估值。末项清仓后改为实际现金。滚动均线可以使用测试开始前已知的历史价格，不必把早期价格清空，关键是参数选择不能使用测试收益。

为什么盈利仍不代表超过基准

验证阶段选择2日窗口，并列时按预先设定规则选较小窗口。基准费率下，测试策略累计收益约4.5053%、最大回撤约1.9665%。同区间买入持有约4.6473%，现金为0%。策略赚了钱，但比买入持有少约0.1420个百分点。

比较基准时，两者必须使用相同初始资金、价格、费用、整数股与清仓约定。否则较高收益可能只是少扣了一次费用，或采用了更有利的成交时刻。验证段三个候选均亏损，也应如实保留；“选最优”不等于“找到有效策略”。

鲨鱼说

样本外是一段数据在研究中的角色。文件名叫test，并不会让它自动独立；只要看过结果后据此改规则，这段数据就参与了开发。

费用敏感性为什么固定规则

程序将同一选定窗口分别放在零费率、0.1%和0.2%费率下执行，测量成本变化的影响。它没有在每种测试费率下重新选择赚钱最多的窗口。由于数量必须为整数，费率改变也可能改变可买股数，因此净值差不一定严格等于某个固定费用差。

还可以将信号推迟一个开盘执行，检验预测优势是否很快消失；或限制单笔成交比例，检验容量。每次敏感性分析应说明只改变了什么，并保留各项结果，不只展示最有利场景。

多次尝试会怎样改变证据

若一个无效规则以5%概率偶然显著，独立尝试20个规则，至少一次误报概率为1−0.9520≈64.2%1-0.95^{20}\approx64.2\%1−0.9520≈64.2%。真实策略往往相关，但搜索越广、只保留赢家的偏差仍然存在。White或Hansen等重抽样方法、控制整体错误率的逐步检验，都是处理“从很多候选里挑一个”的研究方向。不能只对最终赢家做一次普通检验。

时间序列中相邻收益可能相关，随机打乱记录的交叉验证容易把未来状态放入训练。较长历史可用滚动窗口：每次用过去训练和选参，评价下一段，再拼接各期样本外结果。若标签跨越多日，还需排除在预测时尚未完成的训练标签。

鲨鱼说

交叉验证，即反复划分拟合与评价样本，用于比较模型或参数的方法。

研究报告应写出哪些数值

报告至少包含研究假设、数据版本、时间划分、候选窗口、最终规则、成交与费用假设、测试净收益、回撤、交易次数和基准差。交易清单应能对应每次现金变化；没有成交的信号也应记录。

对这个实验，结论可以写为：“2日均线在给定模拟测试段净赚4.5053%，略低于同成本买入持有。结论仅来自11个持有区间。下一步需要增加后续时间和不同状态，并检验延迟与成本。”这段结论明确了结果、比较对象和下一项研究问题，没有把程序成功运行当作市场有效性证明。

练习

测试结果公布后，将候选窗口从2、3、4改成2到20，并再次挑选测试收益最高者。这个新结果应如何标注？最后为什么要更新清仓后的末项净值？

查看解答

原测试段已经参与新的参数搜索，应标为开发或验证结果，新的结论需要新的未查看时间段。末项在清仓前只是持仓市值，更新为实际现金才能计入退出手续费，避免高估最终收益。
