几何体积、重掷策略与路径

1. 近砖点体积

题目

一个实心长方体长宽高分别为 1、2、3。把空间中到该长方体的最短距离小于 1 的所有点组成区域，内部点也计入。求该区域体积。

考点：欧氏距离；外平行体；面棱角分解。

查看分析与解答

必要知识

到长方体距离小于一是沿所有方向做圆形膨胀，棱角处是圆柱或球面，不是把长宽高各加二后的更大长方体。最近点落在面、棱、角上的区域可分开计体积。

分析思路

先保留原体积，再依次加面外直棱柱、棱外四分之一圆柱和角外八分之一球。按最近点分类避免重叠计数。

解答步骤

面外厚度一的体积为面积乘一；靠近一条棱且超出两相邻面时，垂直截面必须满足两个方向位移平方和小于一，只占圆盘一个象限；超出三个相邻面时则是球的一个八分体。

按最近点位于砖的内部、面、棱、顶点分类，外侧区域互不重叠（边界除外）。六个面各向外伸出厚度 1 的直棱柱，总体积为表面积 2(1⋅2+1⋅3+2⋅3)=222(1\cdot2+1\cdot3+2\cdot3)=222(1⋅2+1⋅3+2⋅3)=22。

每条棱外形成半径 1 的四分之一圆柱。四条长为 1、四条长为 2、四条长为 3 的棱，总贡献 (π/4)⋅4(1+2+3)=6π(\pi/4)\cdot4(1+2+3)=6\pi(π/4)⋅4(1+2+3)=6π。八个顶点各对应八分之一球，合起来为一个单位球。最后加上砖体积 6。

总量为 6+22+6π+4π/3=28+22π/36+22+6\pi+4\pi/3=28+22\pi/36+22+6π+4π/3=28+22π/3。严格距离与非严格距离只相差零体积的边界。

一般长宽高a、b、c，膨胀半径r的体积为abc+2(ab+ac+bc)r+π(a+b+c)r²+4πr³/3。代入1、2、3及r=1即得本题。每项分别按r的零、一、二、三次增长，对应内体、面、棱、角的维度。

同类问题

几何邻域题先辨别距离定义。欧氏距离产生圆弧与球面，最大坐标距离才对应简单地各边加宽。

2. 重掷两骰的概率

题目

先投 3 颗独立公平六面骰，观察全部点数后，可选任意 0 至 3 颗重新投一次，以最终总和等于 7 为目标。每个初始结果都选择成功概率最大的方案。求最优方案需要重投恰好 2 颗的初始结果所占概率。如有不同重投数并列，应先检查其影响。

考点：观察后决策；卷积概率；最优方案分类。

查看分析与解答

必要知识

看到初始骰点后才选重投子集，因此必须对每个初始状态分别比较条件成功率，再统计哪类状态的最优动作是重投两颗，不能预先固定某两颗。

分析思路

零颗重投若已有和七则必胜；一颗重投只要所需点数合法，成功率1/6。两颗重投按保留点数算卷积，三颗重投固定成功率5/72，用这些值先分类再枚举校验。

解答步骤

把初始点数排成a≤b≤c。若a+b≤6，一颗重投可补成七，成功率1/6，大于任何两颗重投的最高5/36，所以两颗不最优。若a+b≥7，一颗方案均无效；两颗方案应保留最小a，其成功率为(6−a)/36（a≤5）。它超过三颗的5/72当且仅当a≤3。

某个重投子集一经确定，保留的点数和 sss 就固定。若重投 kkk 颗，成功概率为 P(X1+⋯+Xk=7−s)P(X_1+\cdots+X_k=7-s)P(X1​+⋯+Xk​=7−s)。例如保留一颗 3、重投两颗时，需要两骰和为 4，共有 (1,3),(2,2),(3,1)(1,3),(2,2),(3,1)(1,3),(2,2),(3,1) 三种，概率为 3/36。

初始三骰有 63=2166^3=21663=216 个等概率结果，每个结果有 23=82^3=823=8 个子集。用整数计数与有理数比较这些概率，可避免浮点近似误判并列。枚举还应记录所有达到最大值的重投数；本题恰好需要两颗的状态没有与其他数量并列。

枚举得 42 个初始结果应重投两颗，所求概率为 42/216=7/3642/216=7/3642/216=7/36。

题目

考点：切向与法向；摩擦圆；速度空间积分。

查看分析与解答

必要知识

圆周运动即使速率不变也需要向心加速度v²/R。加速时摩擦还要提供切向分量，两者正交，共同受总摩擦上限约束。

选择一条折线路径，每个点最多作为一个选定节点出现一次，允许任意两点直连；线段穿过其他点不自动记为选择该点。求最长路径长度并给出一条达到它的路径。

考点：欧氏路径；全排列；集合动态规划。

查看分析与解答

必要知识

路径长度是相邻选定点之间的直线距离之和，不是移动次数。题目允许任意直连且穿过未选择点不算访问，因此与常见手机解锁规则不同。

分析思路

证明最优使用全部八点，再将路径转成排列求相邻距离总和。给出一条候选并用全排列或子集动态规划证明无更大值。

解答步骤

任一少于八点的路径都可在末端接一个未用点，新增距离严格为正，故不可能最优。单位网格中横跨两格斜一格为√5，横纵各两格为√8，斜一格为√2。

任意未使用节点都可附加到路径末端，并增加一段正长度，所以最长路径会使用全部 8 个点。问题转化为：对 8!8!8! 种排列计算相邻欧氏距离之和，再取最大。

例如 2→7→3→4→6→1→8→52\to7\to3\to4\to6\to1\to8\to52→7→3→4→6→1→8→5 的七段长度依次为 5,8,5,2,5,8,2\sqrt5,\sqrt8,\sqrt5,2,\sqrt5,\sqrt8,\sqrt25​,8​,5​,2,5​,8​,2​，总长 35+28+2+2≈15.779271744.3\sqrt5+2\sqrt8+\sqrt2+2\approx15.779271744.35​+28​+2​+2≈15.779271744. 下面枚举所有排列核验没有更长路径。对本题 8 点，8!=403208!=403208!=40320，可直接计算；一般 nnn 点的这种枚举为 O(n!n)O(n!n)O(n!n)，可改用“已访问集合、最后节点”的动态规划，将时间降为 O(n22n)O(n^22^n)O(n22n)。

from itertools import permutations
from math import hypot,sqrt
xy=[(0,0),(1,0),(2,0),(0,1),(1,1),(2,1),(0,2),(2,2)]
def length(p):
    return sum(hypot(xy[a][0]-xy[b][0],xy[a][1]-xy[b][1]) for a,b in zip(p,p[1:]))
best=max(length(p) for p in permutations(range(8)))
assert abs(best-(3*sqrt(5)+2*sqrt(8)+sqrt(2)+2))<1e-12
