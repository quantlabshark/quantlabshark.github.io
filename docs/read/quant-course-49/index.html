49 · 买卖价反弹与已实现波动率

推导成交价反弹和价格噪声的协方差结构，用频率实验解释已实现方差偏差。

成交价包含有效价格变化，也可能受到买卖方向和价差的影响。已实现波动率累加高频收益平方，因此需要分析报价噪声怎样进入该统计量。

价值没变，成交价也会跳动

设市场对资产的有效价格一直是100元，买一99.99、卖一100.01。主动买方在卖价成交，主动卖方在买价成交。成交方向交替时，记录的价格来回相差0.02元，尽管有效价格没有变化。这称为买卖价反弹。

用 Pi=Pi∗+cIiP_i=P_i^*+cI_iPi​=Pi∗​+cIi​ 表示第 iii 笔成交：Pi∗P_i^*Pi∗​ 为有效价格，ccc 为半价差，Ii=+1I_i=+1Ii​=+1 表示主动买入、Ii=−1I_i=-1Ii​=−1 表示主动卖出。买卖价差为 2c2c2c。本例半价差0.01元，买卖价差0.02元；把两者混用，会使成本相差一倍。

为什么相邻价格变化负相关

令 ΔPi=Pi−Pi−1\Delta P_i=P_i-P_{i-1}ΔPi​=Pi​−Pi−1​，则

ΔPi=ΔPi∗+c(Ii−Ii−1).\Delta P_i=\Delta P_i^*+c(I_i-I_{i-1}).ΔPi​=ΔPi∗​+c(Ii​−Ii−1​).

假设各笔方向独立、正负等概率，且与独立的有效价格增量无关。相邻变化共享 Ii−1I_{i-1}Ii−1​：在本期中符号为负，在上期中为正。展开协方差，独立项消失，只留下 −c2Var⁡(I)=−c2-c^2\operatorname{Var}(I)=-c^2−c2Var(I)=−c2。因此Roll价差估计为

价差^=2−Cov⁡^(ΔPi,ΔPi−1).\widehat{\text{价差}}=2\sqrt{-\widehat{\operatorname{Cov}}(\Delta P_i,\Delta P_{i-1})}.价差=2−Cov(ΔPi​,ΔPi−1​)​.

若协方差为−0.0001元²，则半价差0.01、全价差0.02元。样本协方差为正时，这个反推不再给出实数解，需要检查方向依赖、有效价格动态与样本误差。这里的负相关也不自动带来反向交易利润，因为真实买入仍支付卖价、卖出仍收到买价。

对数价格噪声怎样进入收益

更一般地，设观测对数价格 Yi=Xi+εiY_i=X_i+\varepsilon_iYi​=Xi​+εi​。XXX 是有效对数价格，ε\varepsilonε 是报价离散、交易方向等机制造成的误差。先假设误差均值0、方差 η2\eta^2η2，各时点独立且与 XXX 独立。观测收益为

ri=Yi−Yi−1=ΔXi+εi−εi−1.r_i=Y_i-Y_{i-1}=\Delta X_i+\varepsilon_i-\varepsilon_{i-1}.ri​=Yi​−Yi−1​=ΔXi​+εi​−εi−1​.

两个价格误差相减，所以单个收益额外增加 2η22\eta^22η2 方差；相邻收益额外有 −η2-\eta^2−η2 协方差。价格噪声独立不代表收益噪声独立。这个差分结构也解释了下一课QMLE中的三对角矩阵。

已实现方差估计的是什么

有效价格满足 dXt=μtdt+σtdWtdX_t=\mu_tdt+\sigma_tdW_tdXt​=μt​dt+σt​dWt​ 时，连续路径在窗口 [0,T][0,T][0,T] 内的积分方差为 IV=∫0Tσt2dtIV=\int_0^T\sigma_t^2dtIV=∫0T​σt2​dt。把高频收益平方相加得到已实现方差 RV=∑i=1nri2RV=\sum_{i=1}^nr_i^2RV=∑i=1n​ri2​。无噪声时，网格加密有助于接近 IVIVIV；独立噪声下，其期望近似变成

E(RV)≈E(IV)+2nη2.E(RV)\approx E(IV)+2n\eta^2.E(RV)≈E(IV)+2nη2.

例如有效日波动2%，则日方差0.0004。若对数价格噪声标准差0.1%，即 η=0.001\eta=0.001η=0.001，10000个收益额外带来 2×10000×10−6=0.022\times10000\times10^{-6}=0.022×10000×10−6=0.02，远大于有效方差。平方和不是波动率。最后开平方才得到波动尺度，不能在去偏前把两者混为一谈。

图比较同一交易窗口内不同间隔的理论均值。横轴变粗时，纳入的收益数量减少，噪声项随之减少；细网格上翘并不说明资产的真实风险随着采样软件变快而增长。

同一模型反复模拟

下面每条路径含10000个等长区间，生成有效日波动2%的布朗价格，再独立加入0.1%的价格噪声。重复300次，按间隔1、5、20、100分别计算RV。

Python13 行
import numpy as np
rng = np.random.default_rng(49)
n, repetitions = 10000, 300
sigma, noise_sd = 0.02, 0.001
results = {k: [] for k in [1, 5, 20, 100]}
for _ in range(repetitions):
    x = np.r_[0.0, np.cumsum(rng.normal(0, sigma/np.sqrt(n), n))]
    y = x + rng.normal(0, noise_sd, n+1)
    for k in results:
        results[k].append(np.sum(np.diff(y[::k])**2))
for k, values in results.items():
    theoretical = sigma*sigma + 2*(n//k)*noise_sd**2
    print(k, round(np.mean(values), 6), round(theoretical, 6))

四行模拟均值约为0.020403、0.004397、0.001407、0.000603，与理论0.0204、0.0044、0.0014、0.0006接近。间隔100仍高于0.0004，因为还保留100个含噪收益。

若继续变粗，偏差下降，但每条路径的估计只依靠更少增量，抽样波动会增大。选择频率是在两种误差之间权衡。

采样时钟和价格定义

每隔一秒取样是日历时间；每隔十笔成交取样是事件时间。后一种在活跃时覆盖很短，在安静时覆盖很长。若估计单位时间方差，应保留真实时间间隔。把每个事件间隔都当成一秒，会混淆交易活跃度与价格变化速度。

中间价可减少成交价反弹，但仍有最小价位、过期报价和异步更新。先按协议过滤无效盘口，再比较同一窗口、同一价格定义的频率图。开盘跳跃、午休和隔夜应单独处理。全天风险可按目标组合盘中变差与隔夜收益平方，而不是把隔夜变化平均摊进盘中每秒。

从一个统计量识别噪声大小

若有效增量独立，观测收益一阶协方差约为 −η2-\eta^2−η2。观测值为 −9×10−8-9\times10^{-8}−9×10−8 时，η=0.0003\eta=0.0003η=0.0003，即对数价格约3个基点。一个基点等于0.01%，在小变动下可近似理解为价格比例0.0001。

这个估计利用相邻收益共享误差的结构。若噪声本身有持续性，或订单流与有效价格相关，一阶协方差还包含其他项，需要相应扩展。单一数字应与频率图、方向序列及报价质量一起解释。

四笔价格的手工分解

取成交价99.99、100.01、99.99、100.01元，有效价格始终100。三个价格增量为0.02、−0.02、0.02，平方和为0.0012元²。有效价格增量平方和却为0。成交方向完全交替的这个小例用于展示反弹，不满足前面Roll推导中的独立方向假设，不能再机械套用其总体协方差结果。

若对同一路径只保留第一与第三笔，两价格都99.99，观察增量为0。若保留第一与第四笔，则增量0.02。非常短样本中，起点选择也会明显改变结果。平均多个起点的稀疏网格能减小这种依赖，这正是双尺度方法需要多个子网格的原因。

价格误差与收益误差的对应表

假设三个时点价格误差依次为0.001、−0.001、0.002，对应两个收益噪声为−0.002、0.003。中间的−0.001在第一个差分中使收益下降，在第二个差分中被减掉，反而使收益上升。

这个共享项的相反符号产生负协方差，而不是价格本身必须存在反向趋势。

对数收益0.001约为0.1%，即10个基点；其平方是 10−610^{-6}10−6。若把“0.1%”作为0.1输入，再平方，方差会放大10000倍。高频估计中数值看起来很小，恰恰需要固定小数、百分数与基点的存储约定。

一天用10000条收益估日方差，与用252天日收益估年波动，是两个不同维度的汇总。前者缩小日内采样间隔，后者延长日历观察窗口。微观结构去噪处理前者的问题，跨日风险预测处理后者的问题，不能通过简单乘252同时解决。

1. IV=0.0009,n=5000,η=0.0002IV=0.0009,n=5000,\eta=0.0002IV=0.0009,n=5000,η=0.0002，RV期望近似为多少？

查看解答

噪声项 2×5000×0.00022=0.00042\times5000\times0.0002^2=0.00042×5000×0.00022=0.0004，合计0.0013。其平方根约3.606%，但这不是每次估计开平方后再平均的精确期望。

2. 某成交价序列明显反弹，按上一笔涨跌反向交易回测盈利。首先应补什么成交条件？

查看解答

买入按可成交卖价、卖出按可成交买价，并计入费用、到达延迟和数量。若反弹仅由价差产生，使用上一笔成交价作为双向都可成交的价格会制造虚假利润。
