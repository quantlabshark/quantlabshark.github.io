1. 代数幂整数个位

题目

求 ⌊(3+22)2024⌋\lfloor(3+2\sqrt2)^{2024}\rfloor⌊(3+22​)2024⌋ 的十进制个位，要求避免直接计算巨大实数幂。

考点：代数共轭；整数递推；取整方向。

查看分析与解答

必要知识

共轭数把根号项符号相反，相加后的许多无理项能消去。构造 aⁿ+bⁿ 可通过整数递推保证是整数，再利用小共轭 bⁿ 在零一之间确定 aⁿ 位于哪个整数下方。

分析思路

先求两根的和与积，建立二阶递推；再研究模十的连续两项状态周期。最后处理向下取整的减一，不能把近整数直接四舍五入。

解答步骤

a、b 都满足 x²=6x−1，故 xⁿ=6x^(n−1)−x^(n−2)，相加得 S_n。初值二、六均整数，所以每个 S_n 都整数。b=3−2√2=(√2−1)² 严格在零一之间，任意正 n 都有 S_n−1<aⁿ<S_n。

两共轭数 a=3+22,b=3−22a=3+2\sqrt2,b=3-2\sqrt2a=3+22​,b=3−22​ 满足 a+b=6,ab=1a+b=6,ab=1a+b=6,ab=1，均为方程 x2−6x+1=0x^2-6x+1=0x2−6x+1=0 的根。乘上 xn−2x^{n-2}xn−2 再把两根相加，得到整数递推 Sn=6Sn−1−Sn−2S_n=6S_{n-1}-S_{n-2}Sn​=6Sn−1​−Sn−2​。

由于 0<b2024<10<b^{2024}<10<b2024<1，a2024=S2024−b2024a^{2024}=S_{2024}-b^{2024}a2024=S2024​−b2024 位于整数 S2024S_{2024}S2024​ 的下方，因此向下取整应减 1。模 10 递推必须观察连续两项状态复现，不能只看到某一项重复就认定周期。

初值为 S0=2,S1=6S_0=2,S_1=6S0​=2,S1​=6。模十的连续两项状态以六为周期复现，各 SnS_nSn​ 的个位依次为 2、6、4、8、4、6。2024≡2(mod6)2024\equiv2\pmod62024≡2(mod6)，所以 S2024S_{2024}S2024​ 个位为四，所求整数个位为三。

模十递推得 2、6、4、8、4、6、2、6，最后两项 (2,6) 与初始相同，因此后续重复、周期六。单独数字四在不同相邻状态出现，不能据此认定更短周期。2024除六余二，对应 S 的个位四，向下取整为个位三。

同类问题

无理幂的整数部分可尝试用共轭幂形成整数序列。周期递推需保存足以确定未来的全部状态，二阶递推至少观察连续两项。

2. 乘积大小比较

题目

令 P=∏j=11011(1+2/(2j+1)3)P=\prod_{j=1}^{1011}(1+2/(2j+1)^3)P=∏j=11011​(1+2/(2j+1)3)，即分母为 3、5、7、…、2023。比较 PPP 与 3/2\sqrt{3/2}3/2​，不必逐项相乘。

考点：取对数；级数放缩；目标下界。

查看分析与解答

必要知识

乘积各因子均正，取对数可把许多小幅增量转成和。要证明乘积小于目标，可给其对数一个方便上界，再给目标对数一个更大的下界，无需精确求和。

用 ln(1+x)<x 去掉对数，再扩大求和范围并用递减函数积分界控制尾部。目标一侧用可证明的对数下界，把比较转成两个有理数。

不等式题不必追求最紧界，应寻找足以越过目标的简单界。每次扩大或缩小范围都注明方向，尤其乘积取对数后可借助级数与积分工具。

3. 深度学习与循环网络

题目

说明深度学习与循环神经网络的关系。给出一个基本 RNN 的状态更新公式，区分按层堆叠的深度和按时间展开的深度。

考点：循环状态；参数共享；两类深度。

查看分析与解答

必要知识

RNN 用隐藏状态保存从历史中提取的信息，当前输入与旧状态共同决定新状态。深度学习是更广的表示学习框架，RNN 是可用的一种序列结构，二者不是互斥分类。

分析思路

先解释单个时间步公式中各变量，再沿时间展开看共享参数，最后区分上下堆叠多层与跨许多时点的计算链。

解答步骤

若 x_t 有 d 个特征、h_t 长 h，则 W_x 为 h×d、W_h 为 h×h、b 长 h，维度一致后 φ 逐分量作用。即便只有一个循环层，一百个时间步也形成一百次递归更新，但同一组 W_h、W_x 被重复使用，并非一百组独立参数。

一个基本 RNN 可以写为 ht=ϕ(Whht−1+Wxxt+b)h_t=\phi(W_hh_{t-1}+W_xx_t+b)ht​=ϕ(Wh​ht−1​+Wx​xt​+b)，输出 y^t=g(Woht+c)\hat y_t=g(W_oh_t+c)y^​t​=g(Wo​ht​+c)。隐藏状态 hth_tht​ 把历史信息传向下一时刻，矩阵 Wh,WxW_h,W_xWh​,Wx​ 在各时刻共享。

把同一个更新单元沿时间展开，会得到长度与序列相同的计算链。把多个循环层上下堆叠，则形成另一种层级深度。训练时反向传播沿这些连接计算梯度，长链可能出现梯度消失或爆炸，门控结构、梯度裁剪等方法分别针对这些问题。

深度学习强调多层可训练的非线性表示。RNN 属于序列建模结构，时间展开深度与循环层堆叠深度应分别描述。

反向传播跨时间不断乘状态更新的 Jacobian，乘积过小会使远期影响消失，过大则梯度爆炸。梯度裁剪直接限制过大梯度，门控结构改变状态传递路径；两者针对的问题不同。若再堆两层，上一层同一时点隐藏状态作为下一层输入，增加的是层级深度。

同类问题

描述序列模型时分别说明状态维度、时间长度、堆叠层数与参数共享。仅说“深度很大”无法判断计算、记忆能力或训练困难来自哪里。

4. Transformer 时序预测

题目

希望用截至 ttt 时点的历史价格、成交量及风险特征预测未来收益。说明 Transformer 的输入组织、注意力计算、何时需要因果遮罩，以及如何验证模型有没有信息泄漏与实际增益。

考点：注意力；历史信息集；预测时点。

查看分析与解答

必要知识

每个时间 token 表示一个时点的特征向量。查询 Q 表示当前要找什么信息，键 K 用于计算匹配程度，值 V 是被加权汇总的内容。softmax 将每个查询的匹配分数转换成权重，位置编码补充时间顺序。

分析思路

先确定每个输出对应哪个决策时点，再决定哪些 token 可见。之后检查预处理、标签和数据版本的时间边界，并用相同信息集的基准衡量预测增益。

解答步骤

若一个查询对三个历史键的分数经 softmax 得权重 0.2、0.3、0.5，输出就是三个值向量的相应加权和。因果遮罩对不可见位置加负无穷，使其权重为零；除以 √d 是对键查询维度造成的分数尺度作调整。

可以把每个时间点的价格、成交量、风险暴露等组成一个 token，经线性投影后加入位置或时间编码，再通过注意力层聚合历史信息。标准注意力计算为 Attention⁡(Q,K,V)=softmax⁡(QK⊤/d+M)V,\operatorname{Attention}(Q,K,V)=\operatorname{softmax}(QK^\top/\sqrt d+M)V,Attention(Q,K,V)=softmax(QK⊤/d​+M)V, 其中 Q、K、V 分别是查询、键和值矩阵。对于 L 个时点，Q,K∈RL×dQ,K\in\mathbb R^{L\times d}Q,K∈RL×d，V∈RL×dvV\in\mathbb R^{L\times d_v}V∈RL×dv​，遮罩 M∈RL×LM\in\mathbb R^{L\times L}M∈RL×L；softmax 按行执行，输出为 L×dvL\times d_vL×dv​。M 在允许位置取 0，在不可见位置取负无穷。

若模型只在 t 时点对一个完全已观测的历史窗口 [t−L+1,t] 输出一个未来预测，窗口内部使用双向注意力本身不构成泄漏，因为窗口内所有值在决策时已知。若同时对窗口内每个时点生成当时的预测，或在序列上做自回归训练，则必须阻止较早 token 看到较晚 token，常用上三角因果遮罩。样本末端以后的特征和标签始终不可见。

更常见的泄漏来自全样本标准化、使用后来修订的财务数据、构造了跨越测试期的标签、从未来回填缺失值，以及测试段反复调参。遮罩不能修复这些问题。

说明模型价值时，应提出可检验的假设，例如跨多个滞后的非线性交互是否优于线性或树模型。固定训练预算、滚动验证和成本假设比较。序列长度 L 增大时标准注意力计算和内存近似随 L² 增长，因此需要同时考察计算代价和稳定性，不能因为模型复杂就默认更好。

例如九点半至十点的窗口在十点统一预测十点后收益，窗口内相互注意不含未来；但若同时用窗口中九点四十五的输出预测当时之后收益，则十点 token 对它不可见。即使遮罩正确，用全日均值标准化九点四十五特征仍会泄漏，需分别审查输入构造。

同类问题

注意力结构是否因果由输出语义决定。模型验证应同时覆盖网络连接与数据处理链，并报告未来误差、稳定性、交易成本及计算预算，不能只比较训练损失。

5. 从商店到公司的最短路

题目

每组给定有 N≤100N\le100N≤100 个顶点、M≤10000M\le10000M≤10000 条无向道路的图，道路时间为 1 至 1000 的正整数，允许平行边。求从 1 号到 NNN 号的最短时间。若不可达返回无穷或约定标记。多组输入以 0 0 结束，说明算法与程序。

考点：最短路；松弛不变量；非负边。

查看分析与解答

必要知识

dist[v] 保存目前已发现的到 v 最短路径长度，是一个可实现上界。松弛检查经当前点走向邻居是否更短。非负边保证最小候选出堆时，未处理绕路不能再降低其距离。

分析思路

建双向邻接表，用最小堆按候选距离推进；跳过过期条目后才判断是否到终点。函数处理单组，再用输入循环组织多组和终止标记。

解答步骤

若先发现到三号距离九，随后经二号改成六，堆里可能同时有 (9,3)、(6,3)。六先出堆并确定答案；旧九若以后弹出，因不等当前 dist[3] 被跳过。负边则可能让一个较远未处理点再向已确定点提供更短路径，破坏此依据。

Dijkstra 维护已发现的最短候选距离。每次从最小堆取距离最小的顶点，因为所有边权非负，尚未展开的绕行路径不可能再把它变短，因此这个距离可以确定。

对其邻点做松弛：若经当前点得到的新距离更短，就更新并压入堆。一个顶点可能留下多个旧条目，取出时比较堆中距离与当前距离，不相同就跳过。示例中先发现 1 到 3 的直达 9，再经 2 把它改成 6。旧的 9 条目不能被当作新的最终结果。

无向道路分别加入两个方向，平行边可以保留。使用最小堆，惰性条目的时间上界为 O((N+M)log⁡(N+M))O((N+M)\log(N+M))O((N+M)log(N+M))。

Python24 行
import heapq

def shortest(n, roads):
    graph = [[] for _ in range(n + 1)]
    for a, b, c in roads:
        graph[a].append((b, c))
        graph[b].append((a, c))
    dist = [float('inf')] * (n + 1)
    dist[1] = 0
    heap = [(0, 1)]
    while heap:
        d, u = heapq.heappop(heap)
        if d != dist[u]:
            continue
        if u == n:
            return d
        for v, cost in graph[u]:
            nd = d + cost
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(heap, (nd, v))
    return dist[n]

assert shortest(3, [(1, 2, 4), (2, 3, 2), (1, 3, 9)]) == 6

这份实现允许平行边且用惰性堆，堆中条目可达 O(M)，一般上界写作 O((N+M)log(N+M)) 更准确。若先只保留每对顶点最短边，或使用支持减少键值的堆，可得到常见的 O((N+M)logN) 表述。

def solve(text):
    tokens = iter(map(int, text.split()))
    output = []
    while True:
        n = next(tokens, None)
        if n is None:
            break
        m = next(tokens)
        if n == 0 and m == 0:
            break
        roads = [(next(tokens), next(tokens), next(tokens)) for _ in range(m)]
        distance = shortest(n, roads)
        output.append('-1' if distance == float('inf') else str(distance))
    return '\n'.join(output)

assert solve('3 3 1 2 4 2 3 2 1 3 9 2 0 0 0') == '6\n-1'

if __name__ == '__main__':
    import sys
    print(solve(sys.stdin.buffer.read()))
