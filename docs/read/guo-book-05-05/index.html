队列位置、流体极限与序列反应

计算前方排队量的流体变化，并建立依赖订单簿状态的队列反应模型。

总深度与个人排队位置不同

在价格时间优先队列中，自己的订单前方有 ZZZ 单位，总队列为 QQQ。新限价单通常排到后方，增加 QQQ 而不增加 ZZZ。市场单从前方消耗，使两者同时下降。撤单是否改善自己的位置，取决于被撤订单在前方还是后方。

仅有按价位汇总数据时，无法精确知道撤单位置，需要明确建模假设。假设撤单在现有队列中均匀发生，则一单位撤单发生在自己前方的概率约为 Z/QZ/QZ/Q。

dQdt=ℓ−m−c,dZdt=−m−cZQ.\frac{dQ}{dt}=\ell-m-c,\qquad\frac{dZ}{dt}=-m-c\frac ZQ.dtdQ​=ℓ−m−c,dtdZ​=−m−cQZ​.

这一平均路径使用均匀撤单假设，且只计算到 Z=0Z=0Z=0；到达队首后应切换到自身订单成交的状态，不能继续使用负的前方数量。

从状态占用时间估计强度

假设“买侧深度在 100 至 200 股”这一状态区域累计停留 120 秒，其中发生 300 次新增事件，则新增强度估计为 300/120=2.5300/120=2.5300/120=2.5 次每秒。若 300 次事件的平均订单量为 20 股，数量流入速度估计为每秒 50 股。

这两个量单位不同：生灭模型按单位跳跃时可直接用事件率，真实订单数量不等时还要描述标记分布。

同一状态停留短却事件多，说明强度高；仅按这一状态在全部事件中出现的频次，得到的是事件时抽样分布，会过度代表活跃状态。

鲨鱼说

“每秒来几单”和“每秒增加多少股”差一个订单数量分布。队列方程使用什么单位，标定时就必须用同一种单位。

队列到零时模型需要切换

方程中的 Z/QZ/QZ/Q 只在 Q>0Q>0Q>0 时有意义。自己的前方量先到零时，进入实际成交过程；某一侧队列先耗尽时，最优报价移动，价格网格和排队位置需要重新定义。不能把常系数解继续延伸到负队列。

围绕流体路径作中心极限定理尺度的展开，可以得到排队位置的随机波动近似。撤单项对 ZZZ 的负反馈产生均值回复性质，其强度随撤单率和队列深度变化。均值路径、方差与首达时间不是同一个统计量。

队列反应模型

多价位模型把状态写成 q=(q−K,…,q−1,q1,…,qK)q=(q_{-K},\ldots,q_{-1},q_1,\ldots,q_K)q=(q−K​,…,q−1​,q1​,…,qK​)，每档新增率为 fi(q)f_i(q)fi​(q)，移除率为 gi(q)g_i(q)gi​(q)。生成元为

LF(q)=∑ifi(q)[F(q+ei)−F(q)]+gi(q)[F(q−ei)−F(q)].\mathcal L F(q)=\sum_i f_i(q)[F(q+e_i)-F(q)]+g_i(q)[F(q-e_i)-F(q)].LF(q)=i∑​fi​(q)[F(q+ei​)−F(q)]+gi​(q)[F(q−ei​)−F(q)].

对应生成矩阵对角元必须是所有离开该状态的速率之和的负值。空队列的移除率应为零；市场单只消耗当前最优可用档位，撤单则可发生在更深档位。

估计状态依赖强度时，用某类事件次数除以系统在相应状态区域停留的总时间。直接除以事件数量会得到另一种条件概率，单位也不同。高维状态可分箱、平滑或用正值回归降低稀疏性。

鲨鱼说

生成元，即描述状态函数在极短时间内条件平均变化率的算子。

参考价格与外部冲击

在参考价格固定的一段时间内，可拟合相对价位的队列动态；参考价格移动时，把各档重新编号，必要时按模型重新抽取深度。状态中还需保存参考价格及其变化方向，才能描述均值回复或持续移动。

纯内生订单流未必解释新闻冲击，可以增加外部状态或价格重置机制。稳定分布的存在需要回拉漂移、非爆炸等条件，不能因为有限样本深度没有发散就认定理论平稳。

鲨鱼说

别人撤单可能帮你前进，也可能发生在你后面。模拟限价成交时，把所有撤单都算作前方减少，会系统性高估成交率。

练习

总队列 200，前方 40。均匀撤单假设下，一次撤掉 10 单位的前方减少期望是多少？

查看解答

前方比例为 40/200=0.240/200=0.240/200=0.2，期望减少 10×0.2=210\times0.2=210×0.2=2 单位。若观察到撤单集中在队首或队尾，应改变撤单位置分布，不能继续使用均匀假设。
