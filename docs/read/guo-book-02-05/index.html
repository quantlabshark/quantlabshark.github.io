厚尾、随机时钟与条件分布

从尾部概率和交易活跃度理解非正态收益，区分稳定分布、混合分布与随机时钟。

正态分布解释不了哪些现象

正态分布由均值和方差决定，偏离均值很多倍标准差的事件概率下降很快。金融收益常出现更多极端值。所谓厚尾，是指分布尾部相对基准分布衰减更慢，并不表示每一天都波动很大。

一个直观来源是波动率变化：平静日的收益标准差为 1%1\%1%，活跃日为 4%4\%4%。两类日内收益即使各自服从正态分布，混合后的总体分布也不是同一方差的正态分布。估计尾部之前，需要先分清条件分布与跨时期混合后的分布。

幂律尾部与稳定分布

若大 xxx 下 P(∣X∣>x)≈cx−αP(|X|>x)\approx cx^{-\alpha}P(∣X∣>x)≈cx−α，则 ppp 阶绝对矩通常只有在 p<αp<\alphap<α 时才有限。比如 α=1.5\alpha=1.5α=1.5 时，均值可以存在，方差不存在；此时样本方差能算出一个数，却不会稳定估计某个有限总体方差。

稳定分布的特点是独立同分布变量相加、平移并缩放后仍属于同一分布族。对称情形的特征函数可以写成

ϕ(u)=E(eiuX)=exp⁡{−γα∣u∣α+iδu},0<α≤2.\phi(u)=E(e^{iuX})=\exp\{-\gamma^\alpha|u|^\alpha+i\delta u\},\quad0<\alpha\le2.ϕ(u)=E(eiuX)=exp{−γα∣u∣α+iδu},0<α≤2.

非对称稳定分布还含偏斜参数 β∈[−1,1]\beta\in[-1,1]β∈[−1,1]。在一种常用参数约定下，α≠1\alpha\ne1α=1 时的对数特征函数为 −γα∣u∣α[1−iβsign⁡(u)tan⁡(πα/2)]+iδu-\gamma^\alpha|u|^\alpha[1-i\beta\operatorname{sign}(u)\tan(\pi\alpha/2)]+i\delta u−γα∣u∣α[1−iβsign(u)tan(πα/2)]+iδu；α=1\alpha=1α=1 时改为 −γ∣u∣[1+iβ(2/π)sign⁡(u)log⁡∣u∣]+iδu-\gamma|u|[1+i\beta(2/\pi)\operatorname{sign}(u)\log|u|]+i\delta u−γ∣u∣[1+iβ(2/π)sign(u)log∣u∣]+iδu。不同参数约定的位置参数可能不同，比较估计值时应统一定义。

市场时间走得并不均匀

钟表经过一分钟，市场可能只成交几笔，也可能成交上千笔。可以用随机交易时间 VVV 描述活跃程度，设

R∣V∼N(0,γ2V).R\mid V\sim N(0,\gamma^2V).R∣V∼N(0,γ2V).

条件方差与活跃度成正比。若 E(V)=mE(V)=mE(V)=m、Var⁡(V)=s2\operatorname{Var}(V)=s^2Var(V)=s2，则

E(R2)=γ2m,E(R4)=3γ4(m2+s2).E(R^2)=\gamma^2m,\qquad E(R^4)=3\gamma^4(m^2+s^2).E(R2)=γ2m,E(R4)=3γ4(m2+s2).

因此峰度为 3(1+s2/m2)3(1+s^2/m^2)3(1+s2/m2)。只要活跃度随机变化，即使条件收益是正态的，总体峰度也大于三。这是厚尾的一种机制，且所有这些矩仍然可能有限。

取 VVV 为均值一、方差 1/21/21/2 的 Gamma 随机变量，峰度就是 4.54.54.5。以 Gamma 过程作为布朗运动的随机时钟，可得到方差 Gamma 类模型。它与无限方差的稳定模型表达不同的尾部机制，不能因为两者都“厚尾”就互换使用。

用尾概率判断哪些矩存在

对非负随机变量 Y=∣X∣Y=|X|Y=∣X∣，E(Yp)=p∫0∞xp−1P(Y>x)dxE(Y^p)=p\int_0^\infty x^{p-1}P(Y>x)dxE(Yp)=p∫0∞​xp−1P(Y>x)dx。若尾部为 cx−αcx^{-\alpha}cx−α，大数区域的积分与 ∫xp−1−αdx\int x^{p-1-\alpha}dx∫xp−1−αdx 同阶，只有 p<αp<\alphap<α 才收敛。这个积分给出了“均值存在但方差不存在”的具体含义，不是说每次观察都会得到无穷大的数。

随机时钟模型的四阶矩也可分两步算。给定 VVV 时，正态变量满足 E(R4∣V)=3γ4V2E(R^4\mid V)=3\gamma^4V^2E(R4∣V)=3γ4V2；再对 VVV 平均，利用 E(V2)=Var⁡(V)+[E(V)]2E(V^2)=\operatorname{Var}(V)+[E(V)]^2E(V2)=Var(V)+[E(V)]2，就得到前述峰度。厚尾可以来自有限矩的波动混合，也可以来自无限方差分布，风险处理方式不同。

设收益在平静和活跃状态各出现一半，条件标准差分别为 1%1\%1% 和 4%4\%4%。总体方差为 0.5(0.012+0.042)=0.000850.5(0.01^2+0.04^2)=0.000850.5(0.012+0.042)=0.00085，四阶矩为 1.5(0.014+0.044)1.5(0.01^4+0.04^4)1.5(0.014+0.044)，峰度约为 5.33565.33565.3356。两个状态内部的峰度都是 3，混合后却明显更大。

鲨鱼说

无限方差是总体分布的性质，有限数据中的样本方差仍然是有限数。问题在于再加入一个极端样本时，这个估计可能剧烈改变，难以稳定到某个有限总体值。

条件模型怎样接入数据

若用成交量近似活跃度，可以比较收益平方与成交量的关系。但成交量既有日内季节性，也受信息冲击影响，应先控制时段差异。对 log⁡R2\log R^2logR2 回归 log⁡V\log VlogV 时，误差中含有 log⁡Z2\log Z^2logZ2；截距包括其期望，不能直接当成 log⁡γ2\log\gamma^2logγ2。

实际诊断可先按过去信息估计条件波动率，再观察标准化残差。若厚尾明显减弱，说明波动混合解释了一部分极端值。若残差仍厚尾，可以进一步采用 Student 分布或其他重尾创新。尾部分布的选择会影响风险区间和极端损失估计。

把不同波动水平的日子放在同一个直方图里，好比把步行和跑步的速度混在一起。总体分布很宽，不意味着每种状态本身都那么不稳定。
