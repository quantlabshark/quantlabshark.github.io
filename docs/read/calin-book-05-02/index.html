伊藤积分的构造与两个基本例子

由简单可预测过程的均方极限定义积分，计算常数积分和布朗运动自身的积分。

从分段权重定义积分

取简单可预测过程 Ht=∑iHi1(ti,ti+1](t)H_t=\sum_iH_i\mathbf1_{(t_i,t_{i+1}]}(t)Ht​=∑i​Hi​1(ti​,ti+1​]​(t)，其中 HiH_iHi​ 对 Fti\mathcal F_{t_i}Fti​​ 可测。定义

∫0THt dWt=∑iHi(Wti+1−Wti).\int_0^T H_t\,dW_t=\sum_iH_i(W_{t_{i+1}}-W_{t_i}).∫0T​Ht​dWt​=i∑​Hi​(Wti+1​​−Wti​​).

若 ∑iE[Hi2](ti+1−ti)<∞\sum_i\mathbb E[H_i^2](t_{i+1}-t_i)<\infty∑i​E[Hi2​](ti+1​−ti​)<∞，积分平方可积。不同时间段的乘积项通过条件期望消失，从而有

E[(∫0THt dWt)2]=E∫0THt2dt.\mathbb E\left[\left(\int_0^T H_t\,dW_t\right)^2\right] =\mathbb E\int_0^T H_t^2dt.E​(∫0T​Ht​dWt​)2​=E∫0T​Ht2​dt.

这个等距关系把被积过程的误差，直接转化成积分结果的均方误差。

鲨鱼说

可预测过程，即其用于积分的权重能够由当前增量发生前的信息确定的过程。

扩展到一般权重

若 HHH 可预测且 E∫0THt2dt<∞\mathbb E\int_0^TH_t^2dt<\inftyE∫0T​Ht2​dt<∞，用简单可预测过程 H(n)H^{(n)}H(n) 逼近，使 E∫0T∣H(n)−H∣2dt→0\mathbb E\int_0^T|H^{(n)}-H|^2dt\to0E∫0T​∣H(n)−H∣2dt→0。由等距关系，相应积分构成 L2L^2L2 Cauchy 序列，定义其均方极限为 ∫0THtdWt\int_0^TH_tdW_t∫0T​Ht​dWt​。

这个定义不依赖具体逼近序列。对连续适应且满足相应矩控制的过程，常用左端点和逼近；但对任意可测过程，不能不检查条件就认定直接采样的左端点和必然收敛。一般定义依靠的是过程空间中的均方逼近。

为什么不同逼近会得到同一个积分

若 H(n)H^{(n)}H(n) 在过程平方范数下逼近 HHH，由三角不等式，E∫∣H(n)−H(m)∣2dt→0\mathbb E\int|H^{(n)}-H^{(m)}|^2dt\to0E∫∣H(n)−H(m)∣2dt→0。等距关系把它变成两近似积分的均方差趋于零，因此积分是 L2L^2L2 Cauchy 序列，具有平方可积极限。

若另一列 G(n)G^{(n)}G(n) 也逼近同一个 HHH，则 ∥H(n)−G(n)∥≤∥H(n)−H∥+∥G(n)−H∥→0\|H^{(n)}-G^{(n)}\|\le\|H^{(n)}-H\|+\|G^{(n)}-H\|\to0∥H(n)−G(n)∥≤∥H(n)−H∥+∥G(n)−H∥→0。它们的积分差由等距关系趋零，故两个极限相同。这一步保证定义没有把具体网格或近似方法写进最终对象。

可预测简单过程在相应平方范数空间中稠密，是这一扩展的基础。连续适应过程可以用左阶梯近似说明；一般过程则依赖该稠密性结果，而不是任意逐点采样都自动有效。

常数权重

当 Ht=cH_t=cHt​=c 时，增量相加直接望远镜消去：

∫abc dWt=c(Wb−Wa).\int_a^b c\,dW_t=c(W_b-W_a).∫ab​cdWt​=c(Wb​−Wa​).

结果服从 N(0,c2(b−a))N(0,c^2(b-a))N(0,c2(b−a))。例如 c=2c=2c=2、区间长度为 3，积分均值为零、方差为 12。它是随机变量，不是某条路径上固定的面积。

权重等于当前布朗值

对 Ht=WtH_t=W_tHt​=Wt​，平方恒等式给出

Wti+12−Wti2=2WtiΔWi+(ΔWi)2.W_{t_{i+1}}^2-W_{t_i}^2=2W_{t_i}\Delta W_i+(\Delta W_i)^2.Wti+1​2​−Wti​2​=2Wti​​ΔWi​+(ΔWi​)2.

求和得

∑iWtiΔWi=12(WT2−∑i(ΔWi)2).\sum_iW_{t_i}\Delta W_i=\frac12\left(W_T^2-\sum_i(\Delta W_i)^2\right).i∑​Wti​​ΔWi​=21​(WT2​−i∑​(ΔWi​)2).

∫0TWt dWt=12(WT2−T).\int_0^TW_t\,dW_t=\frac12(W_T^2-T).∫0T​Wt​dWt​=21​(WT2​−T).

左端点近似误差的精确规模

令等距步长为 h=T/nh=T/nh=T/n，在每段用 Ht(n)=WtiH^{(n)}_t=W_{t_i}Ht(n)​=Wti​​ 逼近 Ht=WtH_t=W_tHt​=Wt​。因为 E[(Wt−Wti)2]=t−ti\mathbb E[(W_t-W_{t_i})^2]=t-t_iE[(Wt​−Wti​​)2]=t−ti​，有

E∫0T∣Ht−Ht(n)∣2dt=∑i∫titi+h(t−ti)dt=Th2.\mathbb E\int_0^T|H_t-H_t^{(n)}|^2dt =\sum_i\int_{t_i}^{t_i+h}(t-t_i)dt=\frac{Th}{2}.E∫0T​∣Ht​−Ht(n)​∣2dt=i∑​∫ti​ti​+h​(t−ti​)dt=2Th​.

均方根误差因此按 n−1/2n^{-1/2}n−1/2 缩小，增加四倍网格数才能约减半。这里比较的是同一条布朗路径上的细化近似，不是重新抽样后两组不配对结果的差。

用两种方法检查均值和方差

写 WT=TZW_T=\sqrt TZWT​=T​Z，则自积分 IT=(T/2)(Z2−1)I_T=(T/2)(Z^2-1)IT​=(T/2)(Z2−1)。对 x≥−T/2x\ge-T/2x≥−T/2，其分布函数为

中点积分为什么没有同一修正

若用端点平均 12(Wti+Wti+1)\frac12(W_{t_i}+W_{t_{i+1}})21​(Wti​​+Wti+1​​) 作为权重，代数上每一段恰好给出平方差的一半，总和为 WT2/2W_T^2/2WT2​/2。这对应 Stratonovich 积分。在这个例子中，

∫0TWt∘dWt=∫0TWt dWt+T2.\int_0^T W_t\circ dW_t=\int_0^T W_t\,dW_t+\frac T2.∫0T​Wt​∘dWt​=∫0T​Wt​dWt​+2T​.

鲨鱼说 伊藤积分不是把普通积分符号换成随机变量。它把信息顺序和均方极限一起写进定义，因此平方展开中的二阶项必须保留。
