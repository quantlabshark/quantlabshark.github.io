1. 套信封

题目

给定 nnn 个信封的宽高 (wi,hi)(w_i,h_i)(wi​,hi​)，不允许旋转。只有宽和高都严格小于另一个信封时，才能嵌入其中。求最多能嵌套多少层，并分析复杂度。

考点：二维严格偏序；同值排序；LIS不变量。

查看分析与解答

必要知识

合法嵌套要求两个维度同时严格增加。按宽度排序只能解决其中一维，相同宽度还需特殊处理，否则高度递增可能错误地把同宽信封也算进去。

分析思路

宽升高降排序后求高度严格LIS。说明同宽不会被选两次，再解释tails中每个位置保存什么，以及为什么较小末尾更有利于未来延长。

解答步骤

若同宽按高升序排成(6,4)、(6,7)，高度LIS会错误选中两只；降序变成7、4后，严格递增序列至多选择一个。同样，高度相同不允许增层，所以二分必须找到首个≥h的位置替换。

先按宽度升序排序，同宽时按高度降序。之后对高度序列求严格最长递增子序列（LIS）。宽度已经非递减，同宽高度被逆序排列，LIS 不会选中同宽的两只信封，因此选出的宽、高都严格递增。

用数组 tails 维护“长度为 k+1k+1k+1 的递增子序列所能达到的最小末尾高度”。对当前高度 hhh，二分找到首个大于等于 hhh 的位置并替换；不存在则追加。使用大于等于，而非严格大于，能避免相等高度增加层数。

例如 [(5,4),(6,4),(6,7),(2,3)] 排序后为 [(2,3),(5,4),(6,7),(6,4)]，高度 [3,4,7,4] 的 LIS 长度为 3，对应三层嵌套。排序和二分总时间 O(nlog⁡n)O(n\log n)O(nlogn)，空间 O(n)O(n)O(n)；若需返回具体信封，还应记录前驱下标。

样例高度3、4、7、4依次使tails成为[3]、[3,4]、[3,4,7]、[3,4,7]。tails[k]是长度k+1的最小可能末尾，不一定与其他位置来自同一条实际链；若要返回方案，需保存前驱而不能直接把tails当信封序列。

同类问题

多维严格排序问题在降到一维前，先处理相等键。对于最优长度与最优方案，要分别维护统计值和恢复路径所需的信息。

2. 打印字母 K

题目

输入整数 n≥2n\ge2n≥2，用星号输出高度为 2n−12n-12n−1、宽度为 nnn 的字母 K。行、列从零开始：每行第 0 列为竖线，第 ∣i−(n−1)∣|i-(n-1)|∣i−(n−1)∣ 列为斜线，其余位置为空格；删除每行末尾多余空格。给出算法，并展示 n=3n=3n=3 的输出。

考点：字符网格；坐标对称；边界检查。

查看分析与解答

必要知识

文本图案也可视为二维网格，每个位置由行列条件决定。中间行为n−1，斜线到竖线的距离等于当前行离中间行的距离。

分析思路

逐行算唯一的斜线列号，再给第零列和该列放星号。用中间行、首行、末行检查重合与对称。

解答步骤

n=3时中间行索引2，斜线列按行依次为2、1、0、1、2。第零列始终为星号，故上半和下半镜像对称，中间只有一个星号。

对行号 i=0,…,2n−2i=0,\ldots,2n-2i=0,…,2n−2，先求斜线列号 j=∣i−(n−1)∣j=|i-(n-1)|j=∣i−(n−1)∣。建立长度为 nnn 的空格字符列表，将第 0 列和第 jjj 列赋为星号，再连接并删除右侧空格。中间行 j=0j=0j=0，两次赋值指向同一位置，所以只产生一个星号。

n=3n=3n=3 时输出为：

文本 / 日志5 行
* *
**
*
**
* *

每行可用 ''.join('*' if c in (0,j) else ' ' for c in range(n)).rstrip() 生成。遍历 2n−12n-12n−1 行、每行 nnn 列，时间 O(n2)O(n^2)O(n2)；逐行输出时额外空间 O(n)O(n)O(n)。

rstrip只删每行右侧空格，不能删左侧或内部空格，否则列位置会改变。n=2时列号1、0、1，对应三行“”“*”“”，也满足高度2n−1与最大宽n。

同类问题

打印图案先写坐标判定函数，再写循环，比直接拼凑若干重复字符串更容易处理重合位置和尺寸边界。

3. SQL 筛选

题目

交易表 trades(trade_id, account_id, amount, status) 中，每行是一笔交易，trade_id 唯一，amount 为金额。查询状态为 paid 且金额大于 1000 的记录；再查询已付款总额超过 10000 的账户及其总额。空金额不计入总额。

考点：行条件；组条件；SQL空值逻辑。

查看分析与解答

必要知识

WHERE决定哪些交易进入统计，GROUP BY把剩余交易分成账户组，HAVING再筛选汇总后的组。NULL表示未知或缺失，与数值零不同，比较NULL得到未知而不是真。

分析思路

第一问逐笔判断状态和金额。第二问只在逐笔阶段筛状态，把金额条件放到组总额计算之后。

解答步骤

账户A有两笔已付6000和5000，单笔都没超过10000，但组总额11000应入选；账户B有20笔已付600，总额12000，也应入选。如果先加amount>1000，B的所有交易会被误删。

第一问只检查单行条件，因此用 WHERE：

sql3 行
SELECT trade_id, account_id, amount
FROM trades
WHERE status = 'paid' AND amount > 1000;

amount 为空时，amount > 1000 不是真，该行不会进入结果。

第二问先筛选已付款记录，再按账户求总额，最后对组结果筛选：

sql5 行
SELECT account_id, SUM(amount) AS paid_total
FROM trades
WHERE status = 'paid'
GROUP BY account_id
HAVING SUM(amount) > 10000;

SUM 忽略空值。若一个账户的金额全为空，其总额为 NULL，不满足大于 10000。第二问没有要求每笔金额超过 1000，因此不能沿用第一问的金额筛选条件，否则会漏算小额已付款交易。

SUM忽略NULL，但如果整组没有一个非空金额，结果仍是NULL。若业务希望显示零，可用COALESCE(SUM(amount),0)，不过对“总额超过10000”这一筛选，NULL和零都不会入选。未付款记录无论金额多大都不参与第二问总额。

同类问题

聚合查询先明确每个条件针对行还是针对组，并用“很多小额合计达标”的例子检查是否错误地提前筛掉数据。

4. 字母频次

题目

输入字符串，统计英文字母 a—z 的出现次数，忽略大小写，忽略数字、标点和空格。输出按字母升序排列的字典，例如输入 Aa,b2B! 应得到什么？

考点：字符范围；大小写统一；固定字母表。

查看分析与解答

必要知识

本题只统计26个英文字母，不能把所有语言的字母都计入。大小写统一后，同一字母只有一个计数键；输出排序与扫描计数是两个步骤。

分析思路

逐字符检查是否为ASCII字母，再转小写累计，最后按键排序。数字、标点和空格在统计前排除。

解答步骤

A和a都归到a，b和B归到b，因此Aa,b2B!仅贡献四个字母。Counter需从collections导入；若要求未出现字母也显示零，可另按a至z枚举全部键并取默认零。

先逐字符保留原始 ASCII 大小写英文字母，再转为小写。每遇到一个字符，将其计数加一；最后按键排序构造结果。

可写为 counts = Counter(ch.lower() for ch in text if 'a' <= ch <= 'z' or 'A' <= ch <= 'Z')，随后 dict(sorted(counts.items()))。输入 Aa,b2B! 清洗后是 aabb，结果为 {'a':2,'b':2}。

长度为 nnn 的字符串扫描时间为 O(n)O(n)O(n)，字母种类至多 26，排序开销有固定上界，计数额外空间为 O(1)O(1)O(1)。若要统计所有 Unicode 字母，清洗规则应改为 casefold 与 isalpha。那时“字符”及大小写变换的范围与本题不同。

严格限定原始输入为a—z和A—Z时，应先检查原字符范围再lower，因为个别非ASCII字符的小写变换可能得到ASCII字母。先筛选原字符可避免无意扩大统计范围。

同类问题

文本统计要先固定字母表与归一化规则，再讨论复杂度。大小写折叠可能改变字符数量或映射范围，Unicode统计需要单独定义口径。

5. 岭回归惩罚系数

题目

岭回归最小化 ∥y−α1−Xβ∥2+λ∥β∥2\|y-\alpha\mathbf1-X\beta\|^2+\lambda\|\beta\|^2∥y−α1−Xβ∥2+λ∥β∥2，截距 α\alphaα 不受惩罚，λ≥0\lambda\ge0λ≥0。说明 λ=0\lambda=0λ=0 和 λ→∞\lambda\to\inftyλ→∞ 时系数、截距和预测值的变化，并讨论 XXX 不满列秩的情形。

考点：中心化；奇异值；正则极限。

查看分析与解答

必要知识

不惩罚截距意味着模型可以保留整体均值，只压缩特征引起的变化。中心化将均值部分与斜率部分分开，便于分析λ的两个极限。

分析思路

对截距求导得到它与斜率的关系，随后在中心化矩阵的各奇异方向上观察收缩系数。先处理λ>0，再讨论趋零与趋无穷。

解答步骤

若X某方向奇异值d很小，普通最小二乘沿该方向需乘1/d，容易放大扰动；岭回归改为d/(d²+λ)，限制放大。当d=0时λ>0下该方向系数为零，不存在除零。

先对 X,yX,yX,y 中心化。对给定斜率，截距最优值为 α=yˉ−Xˉβ\alpha=\bar y-\bar X\betaα=yˉ​−Xˉβ，因此只需研究中心化数据的斜率。

λ=0\lambda=0λ=0 时，目标退化为普通最小二乘。若中心化后的 XXX 满列秩，解为 (XTX)−1XTy(X^TX)^{-1}X^Ty(XTX)−1XTy；不满列秩时系数可能不唯一，但投影到 XXX 列空间的拟合值仍唯一。

若 X=UDVTX=UDV^TX=UDVT 为奇异值分解，岭回归沿每个奇异方向的系数乘子为 dj/(dj2+λ)d_j/(d_j^2+\lambda)dj​/(dj2​+λ)。因此 λ→∞\lambda\to\inftyλ→∞ 时所有被惩罚的斜率趋于零，截距趋于 yˉ\bar yyˉ​，每个样本的预测值趋于均值。截距不受惩罚是这一极限结论的条件。若同时惩罚截距，结果会改变。

λ从正数趋零时，岭解趋于最小范数的最小二乘解；这比“λ=0时任意一个OLS解”更具体。λ趋无穷时β趋零，但α=ȳ−X̄β趋ȳ，因此预测趋均值而非零。若y均值本身为零，两者才恰好相同。

同类问题

讨论正则极限应说明哪些参数被惩罚、是否中心化以及解是否唯一。系数不唯一与拟合值唯一可以同时成立，二者不要混淆。

6. filter 与 map

题目

对列表 ["a","ab","abc","python"]，先用 filter 保留长度大于 2 的字符串，再用 map 转大写，最后转为列表。给出表达式及输出，并说明 Python 3 中两类对象的求值方式。

考点：映射与过滤；惰性求值；迭代器消费。

查看分析与解答

必要知识

filter决定一个元素是否保留，map把保留的元素变成另一个值。它们在Python 3中返回可逐项消费的迭代器，不会在创建对象时立即处理完整输入。

分析思路

从外层list拉取数据的过程追踪：请求一个结果，内层filter不断检查直到找到合格元素，map将它转大写，再交给list。

解答步骤

请求第一个结果时，a和ab被filter跳过，abc通过后转为ABC；第二个结果来自python，转为PYTHON。两级迭代器之间不必保存完整中间列表。

表达式为 list(map(str.upper, filter(lambda s: len(s)>2, words)))。

过滤阶段先检查长度 1、2、3、6，只留下 abc 与 python。映射阶段分别调用 str.upper，所以输出 ['ABC','PYTHON']。

Python 3 的 filter 与 map 返回迭代器，外层 list 消费迭代器时才逐项执行筛选和转换，不会先建立两份中间列表。迭代器消费完毕后再遍历不会重做计算；若要重复使用结果，需要保存列表。

若it=map(...)，第一次list(it)消耗全部结果，第二次list(it)得到空列表，而不是重新计算。同样任务也可写[s.upper() for s in words if len(s)>2]；需要完整列表时这种写法通常更直观。

同类问题

选择惰性管道适合逐项处理或只取前几个结果；需要重复遍历时，要么保存结果，要么重新建立迭代器。

7. 按行取最小值

题目

NumPy 数组 a=[[4,12,6,9],[10,8,12,7],[6,8,5,2]] 的形状为 (3,4)。求 np.amin(a, axis=1) 的结果与形状，并比较 axis=0 和 keepdims=True。

考点：轴归约；形状推导；广播。

查看分析与解答

必要知识

数组形状(3,4)表示行索引三个取值、列索引四个取值。沿某轴归约是让该轴取值合并成一个统计量，而保留其他轴索引。

分析思路

固定行号遍历列得到axis=1结果，固定列号遍历行得到axis=0结果，再用输出维度检查方向是否正确。

解答步骤

第一行min(4,12,6,9)=4，第二行min(10,8,12,7)=7，第三行min(6,8,5,2)=2。axis=1消去原第二维，剩第一维长度三，因此结果形状(3,)。

axis=1 表示沿第二个维度消去列索引，每一行留下一个最小值：第一行为 4，第二行为 7，第三行为 2，所以结果是 [4,7,2]，形状为 (3,)。

axis=0 沿行方向归约，每一列留下一个最小值，结果为 [4,8,5,2]，形状为 (4,)。这里轴表示被消去的维度，不能把 axis=1 误读为“取第一列”。

np.amin(a, axis=1, keepdims=True) 的数值相同，但形状为 (3,1)。保留长度为一的维度后，可直接与原数组广播，例如每行减去自己的最小值。

每行减自己的最小值时，(3,1)可广播成(3,4)，分别减4、7、2；(3,)会先与末尾长度4匹配，长度3与4不符而报错。keepdims保留归约轴为长度一，正是为这种后续广播提供结构。

同类问题

多维数组题先写输入形状、删去哪一轴、输出形状，再看数值。形状推导常能提前发现按错方向的问题。

8. 每周胜利总数

题目

DataFrame 每行表示一名英雄，含字符串列 Hero，以及星期一至星期日七个只含 0 或 1 的列，1 表示当天获胜。新增列 V_counts，表示该行一周的获胜总次数；解释不能使用累计求和的原因。

考点：显式字段；按行求和；累计统计。

查看分析与解答

必要知识

每行是一个统计对象，七列是该对象的七次0/1结果。总和给一个周统计量，累计和则给七个随日期推进的统计量。

分析思路

明确选择七个日列，再沿列方向求和。用一行手算检查结果，并确保新增列不会在重复执行时又被计入。

解答步骤

[1,0,1,1,0,0,1]的总和为4；累计和却为[1,1,2,3,3,3,4]。最后一个累计值虽也为4，整个操作返回七列而非所需单列。

先固定七个日列的名称 day_columns，再执行 df['V_counts'] = df[day_columns].sum(axis=1)。选择这七列后，axis=1 消去列维度，使每行得到一个标量；例如 [1,0,1,1,0,0,1] 得到 4。

sum(axis=0) 得到各天所有英雄的胜利总数，方向不符；cumsum(axis=1) 得到从周一累计到每一天的七个值，也不是本题所需的一列总数。

显式day_columns还防止把Hero、其他数值属性或已有V_counts一起加总。若数据从外部读取，先确认是数值0/1而非字符串“0”“1”；缺失值应按业务规定处理，不能默认缺失等于失败。

同类问题

表格聚合先确定每行代表谁、哪些字段参与、输出应有几行几列。重复执行仍得到同样结果，是检查字段选择是否稳健的好方法。

11. 右乘矩阵后的秩

题目

矩阵 A∈R8×4A\in\mathbb R^{8\times4}A∈R8×4 的秩为 2，U=(20000500001640005)U=\begin{pmatrix}2&0&0&0\\0&5&0&0\\0&0&16&4\\0&0&0&5\end{pmatrix}U=​2000​0500​00160​0045​​。求 AUAUAU 的秩，并证明右乘可逆矩阵不改变秩。

考点：列空间；上三角可逆性；双向包含。

查看分析与解答

必要知识

矩阵秩是列空间中独立方向的数量。右乘U把A的列重新线性组合；若这种组合可逆，就能恢复原列，不会丢失独立方向。

分析思路

先由上三角对角积确认U可逆，再分别证明新列可由旧列表示、旧列也可由新列表示，从两个方向得到秩相等。

解答步骤

U的非对角元素4会把部分列混合，但不改变其上三角行列式等于对角积的性质。800不为零，所以逆矩阵存在，不需要实际算出它。

UUU 是上三角矩阵，行列式等于对角线乘积 2×5×16×5=800≠02\times5\times16\times5=800\ne02×5×16×5=800=0，因此可逆。

AUAUAU 的每一列都是 AAA 各列的线性组合，所以 rank⁡(AU)≤rank⁡(A)\operatorname{rank}(AU)\le\operatorname{rank}(A)rank(AU)≤rank(A)。反过来，由 A=(AU)U−1A=(AU)U^{-1}A=(AU)U−1，AAA 的每列又是 AUAUAU 各列的线性组合，故 rank⁡(A)≤rank⁡(AU)\operatorname{rank}(A)\le\operatorname{rank}(AU)rank(A)≤rank(AU)。

两个不等式合并得到 rank⁡(AU)=2\operatorname{rank}(AU)=2rank(AU)=2。可逆右乘改变列的表示方式，但既不增加也不丢失列空间中的方向；若右乘矩阵不可逆，秩则可能下降。

A是8×4，AU仍为8×4，维度保持一致。若把U换为零矩阵，AU秩立即降到零，说明“任意右乘不改变秩”错误；始终成立的只是乘积秩不超过原秩。

同类问题

证明变换保持某性质时，寻找可逆操作并证明两个方向都可恢复。仅有“新对象由旧对象组合”通常只能得到一个不等式。

12. 数组视图与复制

题目

比较 NumPy 的 flatten()、ravel()、flat 和 reshape()：返回什么对象，是否一定复制内存，修改结果是否会影响原数组？以连续二维数组为例说明。

考点：内存共享；数组布局；迭代访问。

查看分析与解答

必要知识

数组对象包含数据缓冲、形状和步长。不同数组对象可共享同一缓冲，所以对象身份不同不代表内容独立。视图通过新形状或步长解释原数据，复制则分配新缓冲。

分析思路

先区分返回数组还是迭代器，再判断操作能否仅靠调整布局完成。用修改一个元素与shares_memory检查共享关系。

解答步骤

a=np.arange(6).reshape(2,3)，b=a.ravel()后若b[0]=99，a[0,0]也变99；若b=a.flatten()，相同赋值不改变a。a.flat提供按扁平序访问原数组的接口，不是把数据复制到一个新一维容器。

flatten() 返回一维副本，对返回数组赋值不改变原数组。ravel() 返回一维数组，在布局允许时共享内存，无法满足要求时才复制。flat 是按扁平顺序访问元素的迭代器，本身不是一份新数组，a.flat[0]=... 会修改原数组。

reshape() 返回指定形状的数组，可能为视图，也可能因内存布局需要复制。对 C 连续数组 a=np.arange(6).reshape(2,3)，a.reshape(3,2) 和默认 a.ravel() 通常都可共享原数据；对某些转置或非连续切片则不能直接按同样方式重排。

判断共享关系可用 np.shares_memory(a,b)，不能仅凭形状判断。若业务要求修改互不影响，应显式调用 .copy()；若只做只读计算，则可接受视图以减少分配。

转置会改变步长而不一定搬动数据，此时按C顺序重新展平可能需要复制。即使某次reshape恰好返回视图，也不能把它当所有布局下的保证。需要隔离修改时显式copy，要求节省内存时则检查共享和连续性。

同类问题

数组调试同时观察shape、strides及共享内存关系。形状说明逻辑索引，不能单独说明物理排列或修改传播。

13. 订报方式

题目

有四种不同报纸，每种最多订一份，一个人至少订一种、最多订四种。共多少种订阅组合？不区分订阅顺序。

每项独立选择是否入选时，优先使用子集模型。至少一项常可通过总数减空集简化。

14. 不同形状数组合并

题目

两个二维 NumPy 数组的形状分别为 (2,2) 和 (3,2)。分别调用 np.column_stack、np.stack、np.dstack 与默认 axis=0 的 np.concatenate，判断是否成功；成功时写出输出形状。

考点：已有轴拼接；新轴堆叠；维度匹配。

查看分析与解答

必要知识

沿已有轴拼接会把该轴长度相加；新增轴堆叠则让每个完整输入成为新轴上的一片，要求原形状完全一致。两种操作不能混为一谈。

分析思路

写出每种操作实际拼接轴，再逐一比较所有非拼接轴长度。先检查可行性，成功后才计算新形状。

解答步骤

axis=0拼接时，行数2与3可以不同并相加为5，列数都为2必须匹配。若axis=1，则列数相加，但行数2和3不相等，所以失败。

先区分操作：concatenate 沿已有轴连接，stack 新增一个轴。

操作 形状要求 本题结果
column_stack 二维输入按列拼接，行数须相同 2 行与 3 行不同，报错
stack 所有输入形状须相同 (2,2) 与 (3,2) 不同，报错
dstack 二维输入先扩为三维，再沿第三轴拼接，前两维须匹配 行数不同，报错
concatenate(...,axis=0) 除第 0 轴外其余维度相同 都有 2 列，得到 (5,2)

拼接维度可以不同，其他维度必须一致。新增轴并不会自动补齐原有的不同行数。

dstack把二维形状变为(2,2,1)与(3,2,1)，随后沿轴2连接；轴0仍为2与3，不兼容。stack会想产生一个新增长度2的轴，但每片原数组形状不同，同样无法形成规则矩形数组。

同类问题

数组拼接不要靠函数名猜结果。明确“新增轴还是已有轴”“哪一轴允许不同”，即可处理高维版本。

15. 三骰最可能点数和

题目

独立投掷三颗标准公平六面骰。点数和哪些值的概率最大？求最大概率，并给出计数依据。

考点：卷积计数；滑动和；对称但非均匀。

查看分析与解答

必要知识

三颗骰的有序结果等可能，但同一总和对应的结果数不同。两骰和计数呈三角形，加入第三颗骰相当于对六个相邻计数求和。

先列两骰计数c(t)，再用三骰计数g(s)=Σ_{j=1}^6c(s−j)。通过相邻滑动和差证明最大位置，而不只凭对称性猜中心。

同类问题

多个独立离散变量相加时，用卷积保留计数。判断众数需结合单峰性或相邻差，不能把“分布对称”直接等同于“中心最大”。

16. 不平衡分类

题目

训练数据有正类 100000 个、负类 10000 个。比较类别加权、正类下采样、负类上采样和按原分布直接训练，说明各自改变什么、如何选评价指标，以及预测概率是否需要调整。

考点：样本权重；抽样先验；概率校准。

查看分析与解答

必要知识

此题正类是多数类，负类才是少数类。类不平衡是否需要处理，取决于错误成本、目标指标和模型能力。重加权改变优化目标，抽样改变训练分布，二者都会影响概率的解释。

分析思路

先计算不加权时两类在损失中的总贡献，再比较保留的信息量与优化目标。评估保持真实分布，最后检查输出是原概率还是重加权概率。

解答步骤

正类权重1、负类权重10时，两类总权重都是100000。若原正类条件概率为p=0.8，加权交叉熵的理想输出为q=0.8/(0.8+10×0.2)=2/7，而不是0.8。按q>0.5分类因此已经改变了决策阈值。

未经加权的平均损失中，正类样本数是负类的十倍。若希望两类总体贡献接近，可将负类权重设为 10、正类为 1。正类随机下采样至 10000 个也能平衡数量。将负类重复十次则在常见逐样本损失下近似等价于增加负类权重。

三种操作的代价不同：下采样减少训练量但丢失多数类信息；重复采样保留多数类，却没有创造新的独立负类样本；加权保留数据，但使优化目标偏向负类错误。采样和权重都只作用于训练部分。

评价时保留真实类别比例，先规定误判成本，再看精确率、召回率、PR 曲线及对应阈值的损失。全部预测正类就有约 90.9% 准确率，可作为识别“高准确率但无判别能力”的检查。

若模型在加权分布下输出概率 q(x)q(x)q(x)，负类权重为 w0w_0w0​、正类为 w1w_1w1​，则理想交叉熵解满足 q=w1p/[w1p+w0(1−p)]q=w_1p/[w_1p+w_0(1-p)]q=w1​p/[w1​p+w0​(1−p)]。恢复原概率需校正权重或在原分布验证集上校准。直接训练也可以通过调整决策阈值满足不同错判成本，不能仅因比例不平衡就排除它。

由q=w₁p/[w₁p+w₀(1−p)]解得p=w₀q/[w₁(1−q)+w₀q]。这个校正针对理想权重变换；有限样本模型仍需在真实分布验证集检验校准。精确率和召回率还要明确哪个类别是关注对象，若重点识别稀少负类，应按该类报告相应指标。

同类问题

先确定错误代价和目标工作点，再选择加权、抽样或阈值调整。训练集上的平衡不应延续到用于估计真实业务效果的测试分布。

17. 事件概率上界

题目

对任意两个事件 A,BA,BA,B，记 a=P(A)a=P(A)a=P(A)、b=P(B)b=P(B)b=P(B)。证明 P(A∩B)P(A\cap B)P(A∩B) 的通用上下界，并判断它是否总不小于 ababab、是否总不大于 (a+b)/2(a+b)/2(a+b)/2。

考点：集合包含；概率界；依赖关系。

查看分析与解答

必要知识

只知道两个边缘概率，尚不知道事件如何重叠。交集最大在小事件完全包含于大事件时取得，最小则尽可能把两事件错开，但总样本空间容量只有一。

分析思路

上界从集合包含得到，下界从并集不超过一得到。涉及乘积ab时，寻找互斥或相同事件作反例，区分独立假设与通用性质。

解答步骤

若a=0.7、b=0.6，两事件总概率1.3，至少有0.3必须重叠；交集又不可能超过0.6，因此范围[0.3,0.6]。独立时交集0.42位于其中，但不是由边缘概率唯一决定。

交集包含于两个事件，故 P(A∩B)≤min⁡(a,b)P(A\cap B)\le\min(a,b)P(A∩B)≤min(a,b)。又由 P(A∪B)=a+b−P(A∩B)≤1P(A\cup B)=a+b-P(A\cap B)\le1P(A∪B)=a+b−P(A∩B)≤1，得到 P(A∩B)≥a+b−1P(A\cap B)\ge a+b-1P(A∩B)≥a+b−1；概率非负，所以 max⁡(0,a+b−1)≤P(A∩B)≤min⁡(a,b).\max(0,a+b-1)\le P(A\cap B)\le\min(a,b).max(0,a+b−1)≤P(A∩B)≤min(a,b). 较小的两个数不超过其均值，因此 P(A∩B)≤(a+b)/2P(A\cap B)\le(a+b)/2P(A∩B)≤(a+b)/2 恒成立。

乘积 ababab 不是通用下界。例如掷公平骰，A={1}A=\{1\}A={1}、B={2}B=\{2\}B={2}，则交集概率为零，而 ab=1/36>0ab=1/36>0ab=1/36>0。只有额外给出独立性时才有 P(A∩B)=abP(A\cap B)=abP(A∩B)=ab；正关联或负关联会分别使交集位于乘积两侧。

若A=B且概率为1/2，交集1/2大于ab=1/4；若A与B互斥且各1/2，交集零小于1/4，说明两侧都可能。min(a,b)≤(a+b)/2，因此均值上界恒成立，但通常比最小值上界更松。

同类问题

概率不等式先寻找集合关系，再判断是否隐含独立性。用完全重合、互斥和独立三种极端结构检查命题，往往能快速定位缺少的条件。
