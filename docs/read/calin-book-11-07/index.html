光子散射与扩散逃逸时间

从随机步长推导扩散系数，再计算球形区域的平均退出时间。

路程很长，净位移却可能很小

设一次飞行沿单位向量 UUU 前进长度 LLL，位移为 LULULU。下一次散射后方向改变，前后两段路程都为正，但位移向量可能部分抵消。因此总路程与离起点的直线距离是两个不同量。逃逸问题关心位置第一次到达边界的时刻，不能简单用总路程除以初始到边界的距离。

扩散近似将大量短飞行的累积位置表示为连续随机路径。它舍弃了每次飞行的细节，却保留大尺度的平均平方位移。适用的尺度关系是平均自由路径远小于介质尺寸，并且观察期限包含许多次散射。

许多次散射如何形成扩散

一个粒子以速度 ccc 运动，每次散射后方向重新随机化。若单次自由路径长度为 LLL，方向各向同性且各步独立，则每步平均位移为零、平方位移均值为 EL2EL^2EL2。经过许多步，累计时间约为步数乘 EL/cEL/cEL/c，所以单位时间的平方位移增长率约为 cEL2/ELcEL^2/ELcEL2/EL。

光子模型的参数来源

对光子散射，平均自由路径由介质的吸收、散射性质及密度决定，不能用胶体颗粒的黏性阻力半径公式直接替代。若自由路径随半径改变，扩散系数也随位置改变，需要从具体输运近似推导对应算子和边界条件。

例如辐射输运中常见的散度形式算子 ∇⋅(D∇u)\nabla\cdot(D\nabla u)∇⋅(D∇u)，与直接写 SDE dX=2D(X)dWdX=\sqrt{2D(X)}dWdX=2D(X)​dW 所对应的 DΔD\DeltaDΔ 并不相同；前者还含 ∇D⋅∇\nabla D\cdot\nabla∇D⋅∇ 项。空间系数变化时应明确采用哪一个模型，而不能只把常数公式里的 DDD 替换为 D(r)D(r)D(r)。

数值模拟中的边界误差

离散步长模拟可能一步从球内跳到球外。记录第一次网格越界会把真实连续退出时刻近似为该步结束，通常带来向上的时间误差。减小步长可检查收敛，也可对边界穿越进行更精细处理。

若直接模拟自由飞行和散射，最后一段飞行应在球面截断，不能把整段穿出后的距离也算作球内时间。扩散近似适用于自由路径远小于球体尺度；当两者相近时，事件模拟更能反映直线运动细节。

逃逸时间的分布与均值

平均退出时间不是所有粒子都需要的固定时间。靠近边界并朝外运动的路径很快退出，反复向内部散射的路径则等待较久。用大量路径画出直方图，能看到平均值之外的离散程度和尾部。

检查模拟时，可在多个初始半径重复计算。理论均值随 r2r^2r2 线性下降，所以把横轴改为初始半径平方后应接近直线。这个结构比只对一个中心起点核对一个数字更能发现边界处理或扩散系数中的常数错误。

单位球、扩散系数 0.5、中心出发。虚线为连续模型均值三分之一；模拟在离散网格首次越界时停止，因此平均值存在边界离散误差。

鲨鱼说

扩散系数由单步位移与等待时间确定，再通过生成元进入退出时间方程。这样每个常数都有来源，也能看清哪些结论依赖步长分布、空间均匀性和边界规则。
