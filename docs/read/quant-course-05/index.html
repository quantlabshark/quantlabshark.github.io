05 · 波动、回撤与分散投资各衡量什么

计算净值峰值和回撤，用两资产协方差解释分散投资，并区分常见风险调整指标。

风险指标从不同角度描述资金变化。波动率衡量收益的分散程度，回撤衡量从历史高点下降的幅度，分散投资则利用资产之间的共同变化调整组合风险。

标准差衡量单期收益偏离均值的幅度

两条策略最终都从 100 元涨到 110 元，一条缓慢上升，另一条先涨到 150、跌到 75、再回到 110。最终收益一样，持有体验、资金要求和中途被迫退出的可能性却不同。风险指标需要说明波动的大小和资金路径。

收益序列为 r1,…,rnr_1,\ldots,r_nr1​,…,rn​，平均数为 rˉ\bar rrˉ。样本标准差是

s=∑t=1n(rt−rˉ)2n−1.s=\sqrt{\frac{\sum_{t=1}^{n}(r_t-\bar r)^2}{n-1}}.s=n−1∑t=1n​(rt​−rˉ)2​​.

先计算每期偏离平均数多少，再平方、平均并开根号。平方使正负偏离都贡献风险，开根号让单位回到收益率。下跌和上涨都会增加标准差，因此它没有直接区分“好波动”和“坏波动”。分母 n−1n-1n−1 用于估计总体方差时的样本修正。

若各期收益不相关且波动尺度稳定，AAA 期收益和的方差为单期方差的 AAA 倍，标准差按 A\sqrt AA​ 放大。相关性明显时还存在跨期协方差，简单平方根年化就会遗漏这一部分。

鲨鱼说

协方差，即两个变量偏离各自均值时，共同变化程度的度量。

回撤以过去最高净值为参照

定义截至第 ttt 期的最高净值 Ht=max⁡(V0,…,Vt)H_t=\max(V_0,\ldots,V_t)Ht​=max(V0​,…,Vt​)，回撤为 Dt=Vt/Ht−1D_t=V_t/H_t-1Dt​=Vt​/Ht​−1。回撤是零或负数，最大回撤的幅度等于最负回撤的绝对值。

自拟净值为 100、110、105、120、90、108。到 120 时创造新高。跌到 90 时回撤为 90/120−1=−25%90/120-1=-25\%90/120−1=−25%。随后回升到 108，回撤仍为 −10%。从谷底上涨 20% 并没有恢复到峰值，因为恢复所需涨幅为 120/90−1=33.33%120/90-1=33.33\%120/90−1=33.33%。

上图的虚线只在出现新高时上移，下图比较当前净值与这条历史峰值线。回撤持续时间衡量离开前高后多久没有恢复，与最大回撤幅度是不同的指标。

Python11 行
from statistics import stdev
nav = [100, 110, 105, 120, 90, 108]
returns = [b/a-1 for a,b in zip(nav,nav[1:])]
peak, drawdowns = nav[0], []
for value in nav:
    peak = max(peak,value)
    drawdowns.append(value/peak-1)
print("回撤:", [round(x*100,2) for x in drawdowns])
print(f"最大回撤 {min(drawdowns):.2%}")
print(f"单期样本标准差 {stdev(returns):.2%}")
assert min(drawdowns) == -0.25

回撤输出为 0、0、−4.55%、0、−25%、−10%。标准差由五个相邻收益计算，不应把六个净值本身的标准差当作收益波动。

分散投资取决于资产是否一起变化

两资产权重为 www 和 1−w1-w1−w，标准差分别为 σA,σB\sigma_A,\sigma_BσA​,σB​，相关系数为 ρ\rhoρ，组合方差为

σp2=w2σA2+(1−w)2σB2+2w(1−w)ρσAσB.\sigma_p^2=w^2\sigma_A^2+(1-w)^2\sigma_B^2 +2w(1-w)\rho\sigma_A\sigma_B.σp2​=w2σA2​+(1−w)2σB2​+2w(1−w)ρσA​σB​.

假设两资产标准差都是 20%，各持有一半。相关系数为 1 时组合波动仍为 20%。相关为 0 时降为约 14.14%。相关为 −1 时在这个理想设定下完全抵消波动。最后一种结果要求收益始终精确反向且规模匹配，不能只凭短样本负相关就假定未来无风险。

共同市场影响使许多资产同时下跌，增加持仓数量主要分散个别企业风险，不能自动消除市场风险。资产的相关关系也会随环境变化，因此组合评价要保留极端行情中的共同损失。

收益与风险的比值需要匹配对象

夏普比率把平均超额收益除以超额收益标准差。例如年平均收益 8%、同期限无风险收益 2%、年波动 12%，夏普比率为 (8%−2%)/12%=0.5(8\%-2\%)/12\%=0.5(8%−2%)/12%=0.5。它表示每单位波动对应多少超额收益，不是获利概率。

信息比率使用相对基准的主动收益及其波动。Treynor 比率使用市场 beta 作分母。回归 alpha 则衡量模型没有解释的平均收益。Sortino 类型指标只计算相对目标收益的下行偏离，使用时需给出目标和下行偏差的具体定义。指标名称相似，却不能把不同分母直接互换。

同样波动可能对应不同尾部损失

标准差只概括二阶波动，不能完整描述收益分布。一个规则多数时候小赚、少数时候大亏，可能与另一个较对称的规则具有接近的标准差，但两者的资金承受方式不同。检查分位数、最差几期及损失集中发生的情景，可以补充这部分信息。

VaR 通常给出一定概率水平下的损失分位数。预期短缺进一步描述超过该分位点后的平均损失。它们需要明确持有期、概率水平及估计方法。历史样本没有出现某种冲击，并不意味着这种冲击的损失为零。压力情景可以直接设定共同价格变化、流动性减少和交易费用上升，再计算账户结果。

例如账户持有 A、B 各 50 万元，平时相关较低。某压力情景下 A 跌 20%、B 跌 15%，组合损失仍为 50×20%+50×15%=17.550\times20\%+50\times15\%=17.550×20%+50×15%=17.5 万元。此前较低的平均相关性不能删除这个共同下跌情景。分散投资应同时检查平均环境和关键压力状态。

鲨鱼说

比较策略时至少同时看累计净值、回撤和单期收益分布。一个比率把多种信息压成一个数，图形能显示它隐藏的集中亏损与恢复过程。

查看解答
