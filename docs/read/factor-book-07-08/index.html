7.8 另类数据与跨资产风险配置

研究新数据的信息增量和采集偏差，构建宏观因子模拟组合，并用风险偏好与分散化指标观察组合脆弱性。

客流增加为何不一定意味着利润增加

某连锁企业的门店客流同比增加20%。这可能来自销量改善，也可能来自新店增多、促销、统计覆盖扩大。即使收入增加，促销成本也可能使利润下降。另类数据的第一步是还原观测过程，再把观测量连接到企业经营和证券价格。

所谓另类数据，是相对于当时普遍使用的数据而言的。网页招聘、员工评价、专利、新闻和会议文本、遥感图像、经授权的消费统计等，都可能更及时地反映经营活动。2018年特斯拉的历史案例中，供应商利用工厂区域夜间活动的聚合变化推断产能增长，体现了从活动代理量推断生产的思路。类似推断还需要处理样本覆盖和非生产活动，不能把代理量直接等同于产量。

数据类型决定分析方法

价格、成交量和财务报表通常有明确的表格结构；文本需要分词、语境和实体识别，卫星图像需要对象检测与时间空间校准，消费数据需要商户匹配、样本加权和账户覆盖分析。复杂算法不能补救错误的公司映射或时间戳。

至少要保存事件发生时间、数据首次公开时间、实际获取时间和后续修订。回测应使用决策时已经公开且可取得的数据版本。招聘信息在6月采集、描述5月岗位，不能在5月初就当作已知信号。

变量越来越多而独立历史时期没有增加，会使样本在高维空间中稀疏，增加估计方差与过拟合机会。应先通过业务机制筛选变量，再在训练期拟合处理规则，保留之后的验证与测试时间。数据维度增加不意味着偏差与方差必然同时增加。具体方向取决于模型、正则化与真实关系。

鲨鱼说

正则化，即在拟合目标中加入约束或惩罚，以控制模型复杂度的方法。

专业知识决定能否找到增量

专利数量可能只是公司规模的另一种表示。专利内容之间的技术关联，才可能揭示企业间的信息传导。类似地，员工评价总分、分项评分与评分变化回答不同问题。把供应商已经加工的统一信号直接用于所有客户，还可能导致同质化交易。

新数据需要与已有特征比较。若加入文本情绪后，只是重复了股票最近涨跌，就未必增加独立预测信息。时序上更能解释某只股票的收益波动，也不等于能够预测不同股票的预期收益差，两种检验目标应分别设置。

采样偏差怎样产生虚假变化

员工评价数据来自愿意评价的人，不一定代表全体员工。极端感受者可能更积极留言，星级的含义也可能因人而异。平台认证、雇主鼓励评价、行业覆盖和地区结构，都可能改变分布。关于Glassdoor的历史研究报告评价改善与后续收益存在关系，同时讨论了这些数据生成问题。平台机制应按研究时点的版本理解。

例如去年只有科技公司进入样本，今年增加大量制造企业，平均评分下降可能来自样本构成，而不是所有企业的员工感受恶化。可在固定公司样本中比较变化，并控制行业和覆盖变化；如果评分者构成也在变，仍需继续分析。

历史较短还会放大多次尝试的影响。相关研究的模拟比较显示，两年数据下少量试验就可能偶然得到很高夏普，延长到五年需要更多尝试才产生类似极值。其含义是历史长度与搜索次数应同时报告，而不是存在一个通用的最小安全年限。

鲨鱼说

另类数据的覆盖对象与缺失对象共同决定样本范围，应在收益预测前明确记录。覆盖范围变化往往比模型选择更早决定结论是否可信。

用同一测试集比较信息增量

设四个月真实销售增长为2%、4%、1%、3%，财报模型预测为1%、3%、2%、2%，加入新数据后预测为2%、3%、1%、3%。

Python8 行
# 自拟测试集；所有预测均假定在对应月份之前产生。
y = [.02,.04,.01,.03]
base = [.01,.03,.02,.02]
extra = [.02,.03,.01,.03]
def mse(prediction):
    return sum((a-b)**2 for a,b in zip(y,prediction))/len(y)
print(mse(base), mse(extra), mse(extra)/mse(base))
assert abs(mse(extra)/mse(base)-.25)<1e-12

均方误差由0.0001降到0.000025，变为四分之一。销售预测在这组模拟中改善了。要形成股票策略，还需检验市场是否已通过其他信息预期了销售变化，并比较控制已有风格后的净收益。训练误差下降不构成同样证据，因为添加变量通常就能改善样本内拟合。

多种资产可能承担同一种风险

股票、高收益债券和房地产看起来属于三类资产，却可能都受经济增长、融资和流动性共同影响。跨资产因子配置把证券映射到增长、实际利率、通胀、信用和流动性等驱动，再决定风险分配。

有些风险可直接用可交易指数近似，有些需要组合对冲。以下是历史研究中的构造思路。

风险来源 可用于研究的模拟组合
发达市场股票 股票指数相对现金的收益
新兴市场股票 新兴市场股票相对发达市场股票的收益
商品 商品指数相对现金的收益
实际利率 一篮子通胀挂钩国债相对现金
通胀相关成分 期限或久期匹配的名义国债与通胀挂钩国债之差
信用 投资级企业债减去匹配的政府债
房地产 房地产信托基金相对现金
非流动性 低流动性股票减去高流动性股票

模拟组合的正负方向必须写明。例如做多名义国债、做空通胀挂钩债，通常具有与反向组合相反的通胀敏感性，不能只写“通胀因子”而省略方向。久期、流动性、融资与基差也会残留，因此模拟组合是经济风险的近似。

分散化为何会在压力时期减弱

两项资产各有20%年波动、权重各半。若相关系数为0，组合波动为20%/2=14.14%20\%/\sqrt2=14.14\%20%/2​=14.14%；若相关系数升至1，组合波动回到20%。证券数量没有减少，分散效果却消失了。

分散化比率用

DR=∑iwiσiw′ΣwDR=\frac{\sum_iw_i\sigma_i}{\sqrt{\mathbf w'\Sigma\mathbf w}}DR=w′Σw​∑i​wi​σi​​

比较单项加权波动与实际组合波动。在非负权重、口径一致的条件下，较大DR表示较强分散效果。前述两个情景的DR分别为2\sqrt22​与1。危机中多类资产同时下跌，还涉及尾部依赖，平均相关系数未必充分描述这种共同极端变化。

图中相关结构决定组合能否有效分散。评估多资产组合时，应同时检验平常时期和压力时期的协方差，而不是仅统计持有了多少种证券。

风险容忍指标与分散化比率互补

风险容忍指标RTI比较同一时期各因子收益与波动的排名：

RTI=Corr⁡(q(R),q(σ)).RTI=\operatorname{Corr}(q(\mathbf R),q(\boldsymbol\sigma)).RTI=Corr(q(R),q(σ)).

qqq表示排名，RTI范围为−1到1。若高风险因子表现更强，排名倾向一致。若高风险因子跌得更多，排名倾向相反。例如三个因子波动排名为1、2、3，收益排名也为1、2、3，则RTI为1。收益排名反过来则为−1。它描述风险偏好状态，不是直接的预期收益模型。

防御性因子择时关注风险容忍下降、相关性上升及极端估值，目的在于降低组合暴露。两个历史案例说明指标的互补：2012年欧洲债务压力期间，RTI从约0.2降至−0.6，相关研究在5月降低20%仓位，8月指标恢复后再提高。2013年减码恐慌中RTI变化不明显，DR下降却显示分散化减弱，研究方案在6月至9月降低仓位。

这两例分别由风险偏好和共同波动触发，展示了不同风险途径。实际规则仍需预先确定估计窗口、阈值、交易时点与恢复条件，再用后续数据检验，而不能在危机结束后挑选最灵敏的指标。

练习

同时持有一家银行的股票、信用债和可转债，是否已经获得三种独立的风险来源？

查看解答

没有。三种证券的现金流和优先顺序不同，但都可能受同一家银行的信用、资本、盈利和融资条件影响。应将它们映射到共同风险，并计算组合暴露及压力情景；证券名称不同不等于经济风险独立。
