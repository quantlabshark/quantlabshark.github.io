总变差与二次变差

比较直线、折线和布朗路径，解释随机微积分为什么保留增量的平方。

把一条路径切成小段

在区间 [0,T][0,T][0,T] 上取分割 $\pi:0=t_0<t_1<\cdots<t_n=T$。记 Δif=f(ti+1)−f(ti)\Delta_i f=f(t_{i+1})-f(t_i)Δi​f=f(ti+1​)−f(ti​)。观察一条曲线，可以累加它的净变化、绝对变化或平方变化：

∑iΔif=f(T)−f(0),Vπ(f)=∑i∣Δif∣,Qπ(f)=∑i(Δif)2.\sum_i\Delta_i f=f(T)-f(0),\quad V_\pi(f)=\sum_i|\Delta_i f|,\quad Q_\pi(f)=\sum_i(\Delta_i f)^2.i∑​Δi​f=f(T)−f(0),Vπ​(f)=i∑​∣Δi​f∣,Qπ​(f)=i∑​(Δi​f)2.

第一项会相互抵消，只看终点和起点；第二项记录来回走过的纵向距离；第三项强调较大的局部波动。三者回答的是不同问题。即使一条路径最终回到起点，总变差和二次变差仍可能很大。

四点划分下的路径变差

设路径在时刻 0,1,2,30,1,2,30,1,2,3 的值依次为 0,2,−1,00,2,-1,00,2,−1,0。三个增量是 2,−3,12,-3,12,−3,1，所以净变化为 0，绝对变化和为 6，平方变化和为 14。如果只观察起点与终点，三种和都会变成零；粗观测遗漏了中间的往返。

现在把三个区间分别按直线连接，并将每段均匀分成 mmm 份。绝对变化和仍为 2+3+1=62+3+1=62+3+1=6，平方变化和却变成

m(2/m)2+m(−3/m)2+m(1/m)2=14/m→0.m(2/m)^2+m(-3/m)^2+m(1/m)^2=14/m\to0.m(2/m)2+m(−3/m)2+m(1/m)2=14/m→0.

因此某次粗分割算出非零平方和，并不能说明连续路径有非零二次变差。二次变差取决于不断加密后的极限，而总变差会保留路径已经发生的所有往返。

有界变差的含义

总变差定义为所有有限分割下 Vπ(f)V_\pi(f)Vπ​(f) 的上确界。若这个上确界有限，称 fff 为有界变差函数。对单调增加函数，任意分割都给出 f(T)−f(0)f(T)-f(0)f(T)−f(0)。对连续可微函数，

TV⁡[0,T](f)=∫0T∣f′(t)∣dt.\operatorname{TV}_{[0,T]}(f)=\int_0^T|f'(t)|dt.TV[0,T]​(f)=∫0T​∣f′(t)∣dt.

例如 f(t)=sin⁡tf(t)=\sin tf(t)=sint 在 [0,2π][0,2\pi][0,2π] 上先由 0 升到 1，再降到 -1，最后升回 0，总变差是 1+2+1=41+2+1=41+2+1=4。终点与起点之差却是零。图形的弧长还包括横向移动；利用 1+x2≤1+∣x∣\sqrt{1+x^2}\le1+|x|1+x2​≤1+∣x∣，可得弧长不超过 T+TV⁡(f)T+\operatorname{TV}(f)T+TV(f)。

二次变差看的是细分后的极限

二次变差不是对 QπQ_\piQπ​ 取最大值，而是让分割网格 ∣π∣=max⁡i(ti+1−ti)|\pi|=\max_i(t_{i+1}-t_i)∣π∣=maxi​(ti+1​−ti​) 趋于零后，研究平方增量和的极限。若 fff 连续且有界变差，则

Qπ(f)≤max⁡i∣Δif∣∑i∣Δif∣≤max⁡i∣Δif∣TV⁡(f).Q_\pi(f)\le\max_i|\Delta_i f|\sum_i|\Delta_i f| \le\max_i|\Delta_i f|\operatorname{TV}(f).Qπ​(f)≤imax​∣Δi​f∣i∑​∣Δi​f∣≤imax​∣Δi​f∣TV(f).

连续函数在紧区间上一致连续，所以第一因子趋于零，第二因子有固定有限上界，故二次变差为零。对直线 f(t)=ctf(t)=ctf(t)=ct、等距分割 h=T/nh=T/nh=T/n，也可以直接算出

Qn=n(ch)2=c2T2n⟶0.Q_n=n(ch)^2=\frac{c^2T^2}{n}\longrightarrow0.Qn​=n(ch)2=nc2T2​⟶0.

连续性不能删除。例如只有一次跳跃、跳幅为 aaa 的阶梯函数，总变差为 ∣a∣|a|∣a∣，细分后平方增量和仍趋于 a2a^2a2。有限变差路径的连续部分不贡献二次变差，跳跃则贡献跳幅平方。

鲨鱼说

有限变差，即在给定有限区间内，路径总变差有限的性质。

分割变细需要什么条件

网格 ∣π∣|\pi|∣π∣ 是最长的小区间长度，而不是区间个数的倒数。若不断在左半区间加点，却始终不细分右半区间，虽然点数越来越多，网格仍不趋于零，无法保证捕捉整条路径的局部变化。

连续有限变差路径的证明用了两个独立条件。有限总变差控制 ∑∣Δf∣\sum|\Delta f|∑∣Δf∣ 不会随着细分爆炸。一致连续性使最长区间内的最大增量趋于零。两者相乘才把平方和压到零。对于跳跃路径，一致连续性失效：无论网格多细，总有某个小区间跨过跳点，留下近似等于跳幅的增量。

例如 f(t)=t+21{t≥1/2}f(t)=t+2\mathbf1_{\{t\ge1/2\}}f(t)=t+21{t≥1/2}​ 在 [0,1][0,1][0,1] 上总变差为 3，二次变差为 4。线性部分贡献总变差 1，但不贡献二次变差；跳跃贡献总变差 2 和平方变差 4。不能用“有界变差”直接推出“二次变差为零”，还要检查连续性。

布朗路径为什么不同

布朗运动的每个长度为 hhh 的增量方差为 hhh。等距分割上有

E[Qn(W)]=nh=T.\mathbb E[Q_n(W)]=nh=T.E[Qn​(W)]=nh=T.

正态变量满足 E[(ΔW)4]=3h2\mathbb E[(\Delta W)^4]=3h^2E[(ΔW)4]=3h2，所以平方增量的方差为 3h2−h2=2h23h^2-h^2=2h^23h2−h2=2h2。不同区间相互独立，因此

Var⁡(Qn(W))=2nh2=2T2n⟶0.\operatorname{Var}(Q_n(W))=2nh^2=\frac{2T^2}{n}\longrightarrow0.Var(Qn​(W))=2nh2=n2T2​⟶0.

这表明 Qn(W)Q_n(W)Qn​(W) 在均方意义下趋于 TTT。写成过程记号就是 [W]t=t[W]_t=t[W]t​=t。单个小增量的平方仍然随机；变得稳定的是大量平方增量的总和。

由于布朗路径连续而二次变差非零，它不可能具有有限总变差。这是路径粗糙性的一个精确表达：不断加密观察，并不会得到有限的累计绝对运动距离。
