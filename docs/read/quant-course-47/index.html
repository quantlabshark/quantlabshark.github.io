47 · 订单不平衡与价格预测

计算盘口不平衡与微价格，将方向标签、概率校准和实际执行成本联系起来。

订单不平衡比较买卖两侧的可见数量。它可以描述短期供需状态，预测作用则需要结合队列变化、标签区间和实际成交条件检验。

相同价格可以对应不同供需结构

买一99.99元、卖一100.01元时，中间价为100元。若买量300股、卖量100股，卖方最优队列较薄。若买量100、卖量300，则买方较薄。价格相同并不代表短期状态相同。下一步方向还取决于订单到达、撤销和补充，不能只用快照判断必涨或必跌。

先用最优两档构造不平衡：

I=Qb−QaQb+Qa.I=\frac{Q_b-Q_a}{Q_b+Q_a}.I=Qb​+Qa​Qb​−Qa​​.

QbQ_bQb​ 为买一数量，QaQ_aQa​ 为卖一数量。第一种状态 I=0.5I=0.5I=0.5，第二种为 −0.5-0.5−0.5。两边相等时为0。分母把原始数量差缩放到 [−1,1][-1,1][−1,1]，使300对100与3000对1000具有同一个相对不平衡，但它们的绝对可交易容量仍不同。

微价格为何向较薄的一侧移动

一种常用特征用对侧数量给报价加权：

mmicro=aQb+bQaQb+Qa=m+a−b2I,m=a+b2.m_{\mathrm{micro}}=\frac{aQ_b+bQ_a}{Q_b+Q_a}=m+\frac{a-b}{2}I,\qquad m=\frac{a+b}{2}.mmicro​=Qb​+Qa​aQb​+bQa​​=m+2a−b​I,m=2a+b​.

买量较多时，较大的权重落在卖价上。因此300对100的微价格为100.005元。100对300时为99.995元。这里“微价格”是由当前盘口生成的预测特征，只有在特定价格变化机制或经过数据检验后，才能把它解释为未来价格的条件期望。

图中微价格始终位于当前买卖报价之间；不平衡从−1变到1，微价格从买价移到卖价。若计算结果超出区间，应先检查权重、方向和缺失盘口。单边无有效报价或报价交叉时，应将其识别为特殊市场/数据状态。

更深盘口可构造 Db=∑kwkQb,kD_b=\sum_kw_kQ_{b,k}Db​=∑k​wk​Qb,k​ 和 Da=∑kwkQa,kD_a=\sum_kw_kQ_{a,k}Da​=∑k​wk​Qa,k​，再代入不平衡公式。权重需说明依据：离最优档越远，短期内通常越难被消耗。固定数量的清算价格则直接计算买入或卖出给定股数的逐档均价，再比较双方成本。大订单涉及深档，其含义不同于最优档微价格。

鲨鱼说

条件期望，即给定已有信息后，对可能结果按条件概率求平均。

定义可以训练的预测目标

“价格上涨”至少有三种具体含义：下一次中间价变化向上、未来1秒中间价收益为正、订单成交后1秒收益为正。它们的标签和样本集合不同。设本课 Y=1Y=1Y=1 表示当前状态之后首次中间价变化向上，Y=0Y=0Y=0 表示向下。

若观察窗口结束前没有变化，应保留未完成标签，不能随意记为下跌。

从第一个状态起，使用当时可得的特征；向未来寻找标签终点。按时间划分训练与测试；若一个训练标签直到测试区间才结束，应移除该跨界样本或留出相应隔离区间。特征标准化、缺失处理和参数选择都在训练侧完成。

逻辑回归把特征变成概率

用 p(I)=1/[1+e−(β0+β1I)]p(I)=1/[1+e^{-(\beta_0+\beta_1I)}]p(I)=1/[1+e−(β0​+β1​I)] 预测上涨概率。β0\beta_0β0​ 控制中性盘口的方向偏置，β1\beta_1β1​ 控制不平衡的影响。对数损失对正确结果赋予较高概率的模型更有利；对斜率加二次惩罚可避免小样本系数过大。

下面八个观测均为自拟教学数据。程序从零系数开始，每次沿平均损失下降方向更新。X 第一列全为1，用来估计截距；第二列才是不平衡。

Python12 行
import numpy as np
imbalance = np.array([-0.9, -0.7, -0.4, -0.1, 0.1, 0.4, 0.7, 0.9])
y = np.array([0, 0, 1, 0, 1, 0, 1, 1], dtype=float)
X = np.column_stack([np.ones(len(y)), imbalance])
beta = np.zeros(2)
for _ in range(2000):
    probability = 1/(1+np.exp(-X@beta))
    gradient = X.T@(probability-y)/len(y)
    gradient[1] += 0.05*beta[1]
    beta -= 0.1*gradient
print('系数', beta.round(4))
print('I=-0.5 与 0.5 的上涨概率', (1/(1+np.exp(-np.array([[1,-0.5],[1,0.5]])@beta))).round(4))

输出斜率约1.1983、截距接近0。I=−0.5I=-0.5I=−0.5 与0.5时概率分别约0.3545、0.6455。此处样本关于正负方向对称，因此概率也近似对称。正斜率说明模型从这组标签中学到买方相对更厚时上涨更常见，不等于建立了普遍市场规律。

概率质量与交易盈亏

预测概率为0.6的一组样本，若其中约60%上涨，说明这一组校准较好。若只有40%上涨，即使总体准确率尚可，这组仓位仍可能被系统性高估。Brier分数 1n∑(pi−yi)2\frac1n\sum(p_i-y_i)^2n1​∑(pi​−yi​)2 和对数损失都可用于样本外概率评价。标签高度重叠时，应按时间区块评价误差。

设未来中间价要么上升1分、要么下降1分。上涨概率0.6给出的预期变化为 0.6×1−0.4×1=0.20.6\times1-0.4\times1=0.20.6×1−0.4×1=0.2 分。立即买入支付1分半价差，暂不计费用，预期净变化为−0.8分。预测方向与交易成本必须放在同一价格单位下比较。

被动挂买单又是另一个条件问题。若买单更容易在价格即将下跌时成交，所有时刻的平均预测收益不能代表已成交样本的收益。执行评价需要成交概率、成交条件下的后续价格变化、撤单延迟及未成交补单成本。

从快照扩展到事件流

同样的 I=0.5I=0.5I=0.5，可以由新增买单造成，也可以由撤销卖单造成。加入最近一段新增、撤单、主动买卖流量，便能区分变化来源。多变量点过程描述事件相互激发，分类树或回归模型描述状态与标签关系。它们最终都要输出与实际持有时间一致的预测。

手算一组概率的校准误差

设四个独立教学观测的预测为0.2、0.4、0.6、0.8，标签依次0、1、0、1。以0.5为分类阈值，预测对了第一和第四项，准确率50%。Brier分数为 (0.22+(−0.6)2+0.62+(−0.2)2)/4=0.20(0.2^2+(-0.6)^2+0.6^2+(-0.2)^2)/4=0.20(0.22+(−0.6)2+0.62+(−0.2)2)/4=0.20。始终预测0.5的分数为0.25。准确率相同也可以有不同概率质量，因为0.8与0.51表达的把握不同。

对概率0.8却出现下跌的观测，对数损失为 −log⁡(1−0.8)≈1.609-\log(1-0.8)\approx1.609−log(1−0.8)≈1.609。预测0.6却下跌时为0.916。错误且过度自信受到更大惩罚。样本外评估可以按概率分箱，同时报告每箱数量，避免一个只有两条记录的“100%命中箱”造成错觉。

多档深度改变特征时要保留规模

自拟买一300、买二100，卖一100、卖二500，权重分别1与0.5。加权买深度350、卖深度350，多档不平衡为0。只看最优档则为0.5。二者不同，是因为较深卖盘提供了大量潜在流动性。预测下一次一档变化时最优档可能更直接，执行较大数量时深档更有作用，目标时间和数量决定特征取舍。

还可以同时保留总深度 Db+DaD_b+D_aDb​+Da​ 和相对不平衡。两边各10股与各10000股都给出不平衡0，但小额主动单对前者的影响大得多。仅用比率会丢掉这一规模信息。把近期净新增与撤销量再加入，就能区分一个静态比率是稳定形成还是正在快速恶化。
