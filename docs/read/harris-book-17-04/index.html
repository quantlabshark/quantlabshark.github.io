17.4 套利如何连接市场与转移流动性

从价格修正和风险转移两种角度，理解套利机会的来源、服务作用和竞争边界。

同样的价差可能来自不同原因

第一种原因是信息反应不同步。某个共同因素已经变化，一个市场先调整，另一个市场尚未调整。相对价格差异反映了价格发现速度的不同。第二种原因是交易需求不同：基本信息未明显改变，但买方集中在一个市场、卖方集中在另一个市场，局部供需把价格拉开。

二者在图上都可能表现为基差扩大，经济过程却不同。前者需要核对哪些价格尚未反映新价值，后者需要核对各市场风险承接能力。若误把个别资产的真实价值变化当成上述两种情形，所谓套利机会可能根本不存在。

鲨鱼说

基差，即按约定顺序计算的现货与期货价格之差，具体符号取决于所用定义。

价格观点与数量观点

从价格看，套利促使相关风险的定价关系趋于一致。这常被称为一价定律的市场力量，但“同价”必须在质量、期限、地点、汇率和成本都调整后才有意义。

从数量看，套利把一个市场愿意出售的风险交给另一个市场愿意购买的人。若投资者只想持有期货，而另一些投资者主要持有现货，套利组合可以连接这两种需求。它并没有凭空创造最终买方，而是把原本分开的交易意愿组织到一起。

期权和其他衍生品还体现风险转换。例如投资者需要特定形状的收益，交易者可以用相关资产和合约形成对冲组合。新增的衍生品多空头寸相互对应，其未平仓数量取决于交易双方是在建立新头寸还是了结旧头寸。成交量增加不必然意味着净持仓风险增加。

做市商跨越时间，套利者连接市场

做市商先从今天到来的卖方买入，再卖给稍后到来的买方，用库存衔接不同时间的需求。套利者则可能同时在两个市场成交，用对冲组合衔接不同地点或不同工具的需求。两者既竞争，也合作。

套利者会占用过时的做市报价，使更新缓慢的做市商遭受逆向选择。但做市商库存过大、主动调整报价吸引接手时，套利者也能把风险转到相关市场。一个交易者兼具两种能力，可以根据库存与相关资产价格选择更合适的风险转移方式。

经纪人与套利者也有相似的匹配作用。前者代表客户组织交易并收取佣金，后者以自身账户分别完成交易，承担中间风险并取得价差。比较服务成本时，需要把资本占用和承担风险的差别算进去。

一个汇率单位检查

设自拟报价为每欧元 1.10 美元、每美元 150 日元。隐含的欧元日元汇率应为

1.10  美元欧元×150  日元美元=165  日元欧元.1.10\;\frac{\text{美元}}{\text{欧元}}\times150\;\frac{\text{日元}}{\text{美元}}=165\;\frac{\text{日元}}{\text{欧元}}.1.10欧元美元​×150美元日元​=165欧元日元​.

中间的美元单位消去，剩下日元/欧元。这种单位检查能及时发现相乘与相除弄反的问题。真正可执行的跨汇率比较，还必须对每一步选择正确的买价或卖价，而不能把三个中点相乘后就宣称存在利润。

Python5 行
eur_usd = 1.10   # 每欧元对应美元
usd_jpy = 150.0  # 每美元对应日元
implied_eur_jpy = eur_usd * usd_jpy
print(round(implied_eur_jpy, 2))
assert abs(implied_eur_jpy - 165.0) < 1e-9

为什么套利价差不会永远消失

交易费、融资、借券、库存、执行延迟和模型研究都有成本。竞争迫使套利者在更小偏离时行动，但不会让所有成本归零。较低成本的交易者能够在较窄价差中生存，较高成本者则需要更大空间。

具有天然经营需求的参与者，可能在某一条腿上有成本优势。例如本就储存某商品的经营商，处理交割和库存的边际成本可能更低。相反，屏幕上看到同一价差的普通交易者，未必拥有相同的资金、借券或交付条件。

当套利把一个市场的价格变化传递给另一个市场时，观察者可能认为它“制造波动”。但还需要问，原始变化来自基本信息还是局部流动性需求，以及风险跨市场分摊后总价格偏离是否减少。只看被传导市场的波动增加，不能衡量整个系统的效果。

练习

市场甲有很多急于买入的人，市场乙有很多急于卖出的人，但两地交易的是同一种可转移资产。套利者的主要数量作用是什么？

查看解答

它在乙吸收出售需求，在甲满足购买需求，把两地流动性连接起来。相对价格差额需要补偿执行、转移与融资成本。若资产不能自由转移，或两边合约并不等价，这种连接能力就会受限。
