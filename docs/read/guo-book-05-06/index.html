多主体市场与平均场近似

比较随机订单流、异质主体与平均场博弈，用固定点理解市场相互作用。

市场模型如何描述参与者

随机订单流模型直接规定新增、撤销和成交的概率规律，适合检验撮合机制如何产生价差和深度。理性主体模型从收益与风险目标出发推导行动，适合分析激励与均衡。多主体模拟允许参与者具有不同信息、期限、预算和学习规则。

模型选择取决于解释目标。随机订单流可用于分析撮合规则怎样产生价差和深度，主体优化可用于分析策略互动。价格是否稳定、成交率如何变化，则需要根据模型整体运行结果检验。

多主体模拟的最小组成

每个主体保存现金、库存、可观察信息和策略状态。撮合引擎按统一规则处理订单，成交同时改变买卖双方现金和库存。模拟应检查资产守恒、自成交规则、订单生命周期和未成交订单占用。

若一批主体都根据同一个信号做相同交易，会产生拥挤和共同冲击。改变主体数量时，要同时说明单个主体规模是否缩小，否则总体交易需求也在改变，无法把结果归因于“人数更多”。

纳什均衡与最优反应

给定其他人的策略，某个主体不能通过单独改变策略提高自己的目标，这样的策略组合称为纳什均衡。它不表示所有人收益相等，也不表示总收益最大。协调改变可能让所有人受益，而单独改变却不划算。

平均场近似保留分布

当主体很多、单个影响很小，可用状态经验分布 mtN=N−1∑iδXtim_t^N=N^{-1}\sum_i\delta_{X_t^i}mtN​=N−1∑i​δXti​​ 代替每一对主体的相互作用。注意前面的 1/N1/N1/N，否则不是概率分布。

分布而不只是均值也很重要。全部主体库存为零，与一半库存为 1、另一半为 -1，平均库存都为零，但平均平方库存分别为 0 和 1。如果成本含库存平方，两种市场状态的总风险不同，不能仅用平均库存代替状态分布。

在 HJB 与前向方程的迭代中，可检查两次分布的差、最优反应的变化和质量守恒。密度积分应保持一，非负性也应保留；仅看平均库存收敛，会漏掉分布尾部仍在变化的情况。

鲨鱼说

平均场用大量参与者的状态分布描述共同环境。例如一半人持有大额多头、一半人持有同等空头，平均库存为零，但每个人仍承担持仓风险。因此模型需要保留分布的离散程度及尾部。

HJB 与前向方程相互耦合

价值从终值往回计算，分布从初始状态往前推进。可以猜测一条分布路径，解控制，再更新分布并适当阻尼，直到两者一致。另一种路线使用随机最大值原理建立前向后向随机微分方程，但同样需要分布固定点。

非平稳与识别

订单流的长记忆可能来自拆单，也可能来自参数在不同时段切换。把多个状态混在一起会产生缓慢衰减的相关，不能直接认定为某个固定长记忆机制。模拟校准应同时比较状态内特征、状态切换与跨日稳定性。

鲨鱼说

平均场计算需要回答两遍同一个问题：在这种市场环境下，大家会怎样行动；大家这样行动后，市场环境是否还是刚才假设的那一种。
