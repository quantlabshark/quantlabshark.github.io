59 · 智能订单路由与随机逼近

用队列流量、返利和欠超成交成本构造路由目标，以投影随机逼近调整订单。

订单路由将交易分配到不同市场。报价、排队位置、费用和截止时间共同影响成交结果，随机逼近则利用逐次观察更新分配参数。

鲨鱼说

随机逼近，即利用逐次含噪观测更新未知参数或最优决策的方法。

返利、排队与补单成本共同决定路由

两个市场同报买价10元，A前方20股、B前方60股。B返利更高，但一段时间内先要消耗60股才轮到自己。路由需要比较实际成交机会和截止时补单成本，不能只比较费率。

设固定窗口内目标买入 NNN，开头主动买入 MMM，各市场被动挂单 LiL_iLi​。到截止时，未完成部分补单，超额部分需要处理。市价与限价总提交量可以大于目标，前提是明确保留超成交风险。若系统禁止这种做法，则必须改可行集合。

从流量计算自己的成交量

QiQ_iQi​ 为排在前方的数量，ηi\eta_iηi​ 为窗口内有效消耗前方的流出，自己的成交为

Fi=min⁡{(ηi−Qi)+,Li},A=M+∑iFi.F_i=\min\{(\eta_i-Q_i)^+,L_i\},\qquad A=M+\sum_iF_i.Fi​=min{(ηi​−Qi​)+,Li​},A=M+i∑​Fi​.

曲线前段为0，中段斜率1，最后封顶在自己的订单量。增加挂单量只有在流量已足以穿过前方及现有挂单时，才增加本次成交。

主动买入支付价差和费；被动成交相对中间价取得价差及返利，故为负项。欠成交惩罚须按定义计入末端补单代价，避免在末端重复计入相同费用。超成交与欠成交不同方向，不能相互抵消后只惩罚净平均误差。

在非折点处，令 Di=1{ηi>Qi+Li}D_i=1\{\eta_i>Q_i+L_i\}Di​=1{ηi​>Qi​+Li​}，$U=1{A<N},O=1{A>N}$。样本梯度为

投影随机逼近

无需为所有市场流量积分，每次抽一个联合流量样本，计算梯度，再作 zt+1=ΠC(zt−atgt)z_{t+1}=\Pi_{\mathcal C}(z_t-a_tg_t)zt+1​=ΠC​(zt​−at​gt​)。z=(M,L1,…)z=(M,L_1,\ldots)z=(M,L1​,…)，Π\PiΠ 把更新结果拉回合法数量集合。若集合是每项0到 NNN，逐项截断就是投影；若还限制总和，逐项截断就不够。

Python28 行
import numpy as np
rng = np.random.default_rng(59)
N, h, fee, theta = 1.0, 0.01, 0.001, 0.0001
rebate = np.array([0.0002,0.0001])
Q = np.array([0.2,0.1])
under_penalty, over_penalty = 0.06, 0.03
order = np.array([0.4,0.3,0.3])
average = np.zeros(3)
for t in range(1,30001):
    flow = rng.exponential([0.7,0.5])
    fill = np.minimum(np.maximum(flow-Q,0),order[1:])
    total = order[0]+fill.sum()
    common = -(under_penalty+theta)*(total<N)+over_penalty*(total>N)
    active = (flow>Q+order[1:]).astype(float)
    gradient = np.r_[h+fee+theta+common,
                      theta+active*(-h-rebate+common)]
    step = 0.3/(1+t/100)**0.6
    order = np.clip(order-step*gradient,0,N)
    if t>15000:
        average += order/15000
flow = rng.exponential([0.7,0.5],(100000,2))
fill = np.minimum(np.maximum(flow-Q,0),average[1:])
total = average[0]+fill.sum(axis=1)
cost = ((h+fee)*average[0] - fill@(h+rebate)
        + under_penalty*np.maximum(N-total,0) + over_penalty*np.maximum(total-N,0)
        + theta*(average.sum()+np.maximum(N-total,0)))
print('市价与两处限价',average)
print('独立评估成本、全市价成本',cost.mean(),(h+fee+theta)*N)

本例归一化目标为1，后期迭代平均约为主动0.68179、A挂单0.29203、B挂单0.31368，总提交约1.2875。独立抽样评估平均成本约0.009953，低于全主动0.0111。比较的是自拟流量分布下的模型成本。总提交超过1并非计算错误，而是可行集合允许超挂，目标函数用惩罚处理超成交。

学习速度与样本依赖

经典递减步长满足 ∑at=∞,∑at2<∞\sum a_t=\infty,\sum a_t^2<\infty∑at​=∞,∑at2​<∞：前者保留长期调整能力，后者控制噪声积累。还需要目标、梯度矩及样本依赖等条件。后半段平均可减小迭代噪声，但市场状态不断变化时，原平稳收敛解释要重新评估。

训练应保留同一窗口内各市场流量的联合样本。把两市场各自随机打乱后重新配对，会改变“同时流动性不足”的概率，可能低估尾部补单成本。评估至少分列平均成本、欠成交、超成交与延迟敏感性。

路由结果进入订单管理

两处可能几乎同时成交，撤单请求不是撤单确认。风险暴露必须包含未确认的在途订单。用成交编号去重、回报更新剩余量，再重新计算需要路由的数量，才能使模型中的超成交惩罚与实际账户一致。

将更新后的订单量投影到可行域

若允许每个分量0到1、总和可以超过1，逐项截断足够。若要求主动与两处被动总和恰好1，候选向量 (0.7,0.5,0.4)(0.7,0.5,0.4)(0.7,0.5,0.4) 各项都合法，但总和1.6。对这个例子投影到单纯形会从每项减去共同阈值0.2，得到 (0.5,0.3,0.2)(0.5,0.3,0.2)(0.5,0.3,0.2)。简单截断则根本没有改变它。

若减去阈值后出现负数，应将该项归零，再对剩余项重新确定阈值。这来自欧氏距离最小化与和约束的拉格朗日条件。可行集合表达真实系统能提交什么，选择不同集合就是不同路由任务，不能只换一个数值优化器名字。

联合流动性的数值影响

设每场所有一半概率能完成自己的50股、另一半完全不能成交。若两处独立，目标100股时双方都失败概率0.25。若它们总同时充足或同时短缺，则双方都失败概率0.5。每处的平均成交率完全相同，总任务的尾部风险却不同。

两个场所各自样本随机打乱会把第二种结构变得近似第一种，使路由低估同时补单的风险。保留同步联合样本不只为了计算平均相关系数，也为了保留共同极端状态。

样本梯度还可以用有限差分核对。选不在折点的状态，将某个订单量增加很小的 ϵ\epsilonϵ，计算 [c(z+ϵei)−c(z)]/ϵ[c(z+\epsilon e_i)-c(z)]/\epsilon[c(z+ϵei​)−c(z)]/ϵ，应接近公式梯度。若恰好总成交等于目标或队列流量等于订单边界，应比较左右方向或使用合法次梯度，而不是要求处处同一导数。
