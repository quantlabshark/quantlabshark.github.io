回归怎样区分因子暴露与风险溢价

从散点和小数据计算理解时序回归、截面回归与 Fama–MacBeth 检验。

一只股票总在市场上涨时涨得更多，能否推断它长期一定赚得更多？第一个问题比较同一只股票在不同月份的变化；第二个问题比较不同股票的平均收益。回归把两种比较连接起来，但它们使用的数据排列和估计目标不同。

截距、斜率与回归残差

设 ftf_tft​ 为市场第 ttt 个月的超额收益，rtr_trt​ 为某股票同期超额收益。用 rt=α+βft+εtr_t=\alpha+\beta f_t+\varepsilon_trt​=α+βft​+εt​ 描述它们：β\betaβ 是直线斜率，α\alphaα 是纵轴截距，εt\varepsilon_tεt​ 是某个点与拟合值之间的差。普通最小二乘 OLS 选择使残差平方和最小的直线。

每个点是一段相同的持有期。沿横轴移动反映因子收益变化；拟合线的倾斜程度反映暴露；点到线的垂直距离是该期残差。不能把某个月较大的残差直接称为长期 α\alphaα。

另一组教学数据中，市场超额收益为 −2%、0%、2%，股票超额收益为 −2%、1%、4%。直线恰为 r=1%+1.5fr=1\%+1.5fr=1%+1.5f。市场变动 1 个百分点，股票拟合收益变动 1.5 个百分点。市场收益为零时，拟合收益为 1%。三期完全落在线上只为演示计算，真实数据通常有散点。

时序回归：每只资产各自估计暴露

设有 NNN 项资产、KKK 个因子和 TTT 期数据。对资产 iii，估计

rit=αi+βiTft+εit.r_{it}=\alpha_i+\beta_i^{\mathsf T}f_t+\varepsilon_{it}.rit​=αi​+βiT​ft​+εit​.

ftf_tft​ 是含 KKK 个因子收益的列向量；βi\beta_iβi​ 是对应的 KKK 个暴露。转置后相乘，等价于逐项相乘再相加。对每项资产单独回归，可得到 α^i\hat\alpha_iα^i​、β^i\hat\beta_iβ^​i​ 和残差。帽号表示估计值。

带截距的 OLS 残差均值为零，因此对时间取平均得到

rˉi=α^i+β^iTfˉ.\bar r_i=\hat\alpha_i+\hat\beta_i^{\mathsf T}\bar f.rˉi​=α^i​+β^​iT​fˉ​.

若因子本身是可交易组合收益，它的均值 fˉ\bar ffˉ​ 就是因子溢价的样本估计，截距表示该组因子无法解释的平均收益。GDP 增速等宏观量也能作为时序回归变量估计敏感度，但其平均值不是投资收益，因而不能沿用同样的溢价解释。

下面用有噪声的教学数据估计一条直线。所有收益以小数输入，0.01 表示 1%。

Python10 行
import numpy as np
factor = np.array([-0.02, 0.00, 0.02, -0.01, 0.01, 0.03])
noise = np.array([0.001, -0.002, 0.001, -0.001, 0.002, -0.001])
asset = 0.003 + 1.2 * factor + noise
X = np.column_stack([np.ones(len(factor)), factor])
alpha, beta = np.linalg.lstsq(X, asset, rcond=None)[0]
residual = asset - X @ np.array([alpha, beta])
print(f"月截距 {alpha:.4%}，市场暴露 {beta:.4f}")
assert abs(residual.mean()) < 1e-12
assert abs(np.dot(factor, residual)) < 1e-12

检查残差均值和残差与解释变量的内积，是核对 OLS 计算的办法；它们为零来自拟合条件，不证明模型已经解释了所有经济机制。

各资产的截距也有估计误差。令 μf\mu_fμf​、Σf\Sigma_fΣf​ 分别为因子收益总体均值与协方差，Σe\Sigma_eΣe​ 为同一期各资产残差的协方差，TTT 为样本期数。在残差随时间独立、条件协方差不变且与因子正交的回归条件下，时序截距向量的渐近协方差为

Var⁡(α^TS)≈1+μfTΣf−1μfTΣe.\operatorname{Var}(\hat\alpha_{\mathrm{TS}})\approx \frac{1+\mu_f^{\mathsf T}\Sigma_f^{-1}\mu_f}{T}\Sigma_e.Var(α^TS​)≈T1+μfT​Σf−1​μf​​Σe​.

分母 TTT 说明样本越长，平均截距一般估计得越精确。Σe\Sigma_eΣe​ 则保留不同资产截距误差之间的相关性。括号中的因子反映同时估计斜率对截距精度的影响：因子均值离零越远、相对于自身波动越大，截距越依赖对斜率的估计。该式用于时序回归的截距联合检验。下面的截面定价误差还经过截面拟合投影，协方差公式会有所不同。

鲨鱼说

协方差，即两个变量偏离各自均值时，共同变化程度的度量。

截面回归：共同暴露对应怎样的平均收益

第一步仍估计每项资产的暴露；第二步把资产平均收益排成一列，把暴露排成一张表。令 BBB 为 N×KN\times KN×K 的暴露矩阵，每行对应一项资产，rˉ\bar rrˉ 为 NNN 维平均收益向量。模型为

rˉ=Bλ+α,λ^=(BTB)−1BTrˉ.\bar r=B\lambda+\alpha,\qquad \hat\lambda=(B^{\mathsf T}B)^{-1}B^{\mathsf T}\bar r.rˉ=Bλ+α,λ^=(BTB)−1BTrˉ.

这里由截面数据重新估计 λ\lambdaλ，目标是减小各资产平均收益与模型解释值之间的平方差。矩阵求逆要求各因子暴露不能完全重复。若加入一列全为 1 的变量，就额外估计零暴露资产的截面截距。是否加入，取决于待检验的定价限制。

自拟例子：两项资产暴露为 0.5、1.5，平均超额收益为 2%、8%。已有因子均值为 4%，时序定价关系解释为 2%、6%，留下 0、2% 的误差。截面 OLS 则估计

λ^=0.5×2%+1.5×8%0.52+1.52=5.2%.\hat\lambda=\frac{0.5\times2\%+1.5\times8\%}{0.5^2+1.5^2}=5.2\%.λ^=0.52+1.520.5×2%+1.5×8%​=5.2%.

此时解释收益为 2.6%、7.8%，误差为 −0.6%、0.2%。误差更小是因为第二步专门优化了这两项资产的拟合，不意味着它发现了无误差的真实溢价。

时序方法沿每项资产的月份估计暴露，截面方法在资产之间估计风险价格。横向和纵向都用到收益数据，但因变量、解释变量和系数含义不能互换。

回归还隐含了一组因子组合

定义 Ω=(BTB)−1BT\Omega=(B^{\mathsf T}B)^{-1}B^{\mathsf T}Ω=(BTB)−1BT。它是 K×NK\times NK×N 的矩阵，第 kkk 行可以看作构造第 kkk 个因子组合的资产权重。因为 ΩB=I\Omega B=IΩB=I，该行权重对目标因子的估计暴露为 1，对其余因子为 0。

这组权重通常不同于排序组合，也可能需要较大空头头寸。它解释了为什么截面估计的因子收益不一定等于排序组合收益。等式描述的是样本估计暴露下的隔离，实际暴露估错或随时间改变时，隔离效果也会改变。

标准误需要承认股票共同涨跌

两只同行业股票的残差可能同时受行业消息影响。若把它们当作完全独立观测，可能高估证据数量。广义最小二乘 GLS 用残差协方差 Σe\Sigma_eΣe​ 调整这种关系：

λ^GLS=(BTΣe−1B)−1BTΣe−1rˉ.\hat\lambda_{GLS}=(B^{\mathsf T}\Sigma_e^{-1}B)^{-1} B^{\mathsf T}\Sigma_e^{-1}\bar r.λ^GLS​=(BTΣe−1​B)−1BTΣe−1​rˉ.

此外，BBB 是第一步估计出来的，含有误差。第二步若把它视作精确常数，会遗漏一层不确定性。Shanken 修正在特定模型假设下计入这种生成解释变量误差。

进阶推导：溢价、定价误差的协方差与联合检验

为统一 OLS 与 GLS，令 WWW 为截面权重：OLS 用 III，GLS 用 Σe−1\Sigma_e^{-1}Σe−1​。定义 A=(BTWB)−1BTWA=(B^{\mathsf T}WB)^{-1}B^{\mathsf T}WA=(BTWB)−1BTW、M=I−BAM=I-BAM=I−BA。AAA 把平均收益转成溢价，MMM 留下模型没有解释的部分，因此 λ^=Arˉ\hat\lambda=A\bar rλ^=Arˉ、α^=Mrˉ\hat\alpha=M\bar rα^=Mrˉ。

设因子与残差相互独立，各自跨期独立同分布；因子协方差为 Σf\Sigma_fΣf​。不考虑暴露估计误差时，经典公式为

Vλ=1T(AΣeAT+Σf),Vα=1TMΣeMT.V_\lambda=\frac1T(A\Sigma_eA^{\mathsf T}+\Sigma_f),\qquad V_\alpha=\frac1T M\Sigma_eM^{\mathsf T}.Vλ​=T1​(AΣe​AT+Σf​),Vα​=T1​MΣe​MT.

第一式包含残差均值传播过来的误差和因子样本均值的波动。设 c=λTΣf−1λc=\lambda^{\mathsf T}\Sigma_f^{-1}\lambdac=λTΣf−1​λ，Shanken 修正将残差部分乘以 1+c1+c1+c：

Vλ=1T[(1+c)AΣeAT+Σf],Vα=1+cTMΣeMT.V_\lambda=\frac1T[(1+c)A\Sigma_eA^{\mathsf T}+\Sigma_f],\qquad V_\alpha=\frac{1+c}{T}M\Sigma_eM^{\mathsf T}.Vλ​=T1​[(1+c)AΣe​AT+Σf​],Vα​=T1+c​MΣe​MT.

实践中代入相应估计值。协方差矩阵对角元素开方，得到各参数标准误。联合检验使用 α^TV^α+α^\hat\alpha^{\mathsf T}\hat V_\alpha^{+}\hat\alphaα^TV^α+​α^，在相应大样本条件下参照 χN−K2\chi^2_{N-K}χN−K2​。加号表示广义逆，因为拟合 KKK 个参数后，残差只有 N−KN-KN−K 个独立方向。若加入截面截距，自由度还要相应减少。

这些公式的独立同分布条件决定了它们如何处理相关性。存在跨期依赖时，需要用长期协方差或 GMM 重新构造推断，不能只沿用独立样本公式。

Fama–MacBeth：每个月回归，再平均系数

Fama–MacBeth 方法在每个月分别用股票当月收益对上期已知暴露回归：

rit=γt+βi,t−1Tλt+uit.r_{it}=\gamma_t+\beta_{i,t-1}^{\mathsf T}\lambda_t+u_{it}.rit​=γt​+βi,t−1T​λt​+uit​.

先得到 TTT 组 λ^t\hat\lambda_tλ^t​，再计算 λˉ=T−1∑tλ^t\bar\lambda=T^{-1}\sum_t\hat\lambda_tλˉ=T−1∑t​λ^t​。例如三个月某个标准化特征的系数为 0.2%、−0.1%、0.5%，平均为 0.2%。跨月系数的波动用来估计均值标准误，而不是把所有股票月份简单堆在一起当作独立观测。

这样可以容纳同一个月股票之间的共同冲击。系数存在跨月自相关时，仍需 Newey–West 等修正。暴露由历史估计时，也仍有生成变量误差。滚动估计暴露应只使用截至 t−1t-1t−1 的数据，使当月收益不提前进入解释变量。

若暴露、股票样本和回归权重完全固定，先平均收益再截面回归，与逐月回归后平均系数相等；变化的样本和暴露会打破这种交换关系。

鲨鱼说

读回归表先写清楚“每一行是什么”。若一行是一个月，斜率通常表示资产对因子的敏感度；若一行是一只股票，斜率通常表示当期特征或暴露对应的收益差。两张表都叫回归，系数回答的问题却不同。

练习

某宏观变量的平均值为 2 个指数点，一只股票对它的时序斜率为每指数点 0.3%。能否把两者相乘得到该股票的风险溢价？

查看解答

乘积 0.6% 是该时序方程的一部分拟合值，尚不是该宏观风险的价格。宏观变量均值不等于可交易因子的平均收益。需要利用不同资产的暴露和平均收益，估计该暴露在截面上对应的风险价格，并考虑第一步暴露估计误差。
