30 · 决策树与随机森林

手算一次树切分，理解分段预测、交互关系和森林平均，并正确使用时间验证与特征重要性。

决策树按特征阈值逐步划分样本，在末端给出类别或数值预测。随机森林汇总多棵树的结果，以降低单棵树对训练样本变化的敏感性。

一个阈值怎样分开四条记录

输入1、2、3、4对应类别0、0、1、1。问题“输入是否不超过2.5”把前两条分到左边、后两条分到右边，两边都只剩一种类别。决策树用一连串特征阈值划分样本，到叶节点后给出类别比例或数值均值。

树适合表达条件关系。例如盈利质量较好时，低估值可能提供不同信号；盈利质量较差时，同样低估值可能对应困境。这样的交互不能仅靠两个独立线性项表达。

Gini不纯度如何选择切分

一个节点中两类比例为p0,p1p_0,p_1p0​,p1​，Gini不纯度是G=1−p02−p12G=1-p_0^2-p_1^2G=1−p02​−p12​。根节点各占一半，G=0.5G=0.5G=0.5。按2.5切分后，两边不纯度均为0，改善为0.5。

如果按1.5切分，左边只有类别0，右边为0、1、1，右边不纯度为1−(1/3)2−(2/3)2=4/91-(1/3)^2-(2/3)^2=4/91−(1/3)2−(2/3)2=4/9。按样本数加权后的不纯度为1/4×0+3/4×4/9=1/31/4\times0+3/4\times4/9=1/31/4×0+3/4×4/9=1/3，改善仅为1/61/61/6，因此2.5更优。

回归树使用类似思想比较平方误差。某叶目标为1、2、6，预测均值3，平方误差为4+1+9=144+1+9=144+1+9=14；继续切分只有在误差下降足够且样本数量允许时才值得进行。

为什么一棵深树容易记住噪声

不断切分直到每片叶只有一个训练样本，可把训练误差压得很低，但阈值可能只是偶然波动。限制深度、提高叶节点最少样本数和剪枝，都能减少这种细碎划分。最合适的复杂度要在后续验证数据上选择。

噪声增加并不意味着真实关系自动变为非线性。若数据本来由直线加噪声生成，树可能比线性模型更容易追随噪声。比较算法时应保留相同划分、指标与简单基准。

随机森林怎样平均多个不稳定估计

随机森林通常对样本有放回抽取，并在每个节点随机挑选部分候选特征，形成不同的树。回归平均各树数值，分类汇总概率或投票。假设每棵树预测误差方差为σ2\sigma^2σ2、两树误差相关约为ρ\rhoρ，平均MMM棵树的误差方差可近似写为

ρσ2+1−ρMσ2.\rho\sigma^2+\frac{1-\rho}{M}\sigma^2.ρσ2+M1−ρ​σ2.

增加树数降低第二项，但共同误差第一项仍然存在。让树有所不同有助于平均；数据泄漏、错误标签或共同偏差不会因树多而消失。

import numpy as np
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.inspection import permutation_importance

X = np.array([[1.0], [2.0], [3.0], [4.0]])
y = np.array([0, 0, 1, 1])
stump = DecisionTreeClassifier(max_depth=1, random_state=1).fit(X, y)
print("threshold:", stump.tree_.threshold[0])
assert np.isclose(stump.tree_.threshold[0], 2.5)

rng = np.random.default_rng(11)
features = rng.normal(size=(120, 3))
labels = ((features[:, 0] > 0) != (features[:, 1] > 0)).astype(int)
forest = RandomForestClassifier(n_estimators=100, max_depth=4,
                                min_samples_leaf=3, random_state=11)
forest.fit(features[:80], labels[:80])
print("later-sample accuracy:", forest.score(features[80:], labels[80:]))
importance = permutation_importance(forest, features[80:], labels[80:],
                                   n_repeats=10, random_state=11)
print("permutation importance:", importance.importances_mean)

第一部分恢复阈值2.5。第二部分生成120条三特征记录，标签只取决于前两列是否异号，第三列是无用噪声。前80条训练，后40条评价。它展示森林如何学习交互以及如何计算置换重要性，输出对应这组固定模拟任务。

图中异号的两个象限属于同一类，同号象限属于另一类。单条直线不能将这两类完全分开，而连续阈值切分可以形成四个区域。背景把第三个特征固定为0，样本点显示前两项特征与真实标签，因此它展示的是二维切片。

实际三维输入的测试准确率由程序单独计算。

鲨鱼说

森林能平均单棵树的随机波动，但所有树若读到了未来标签，平均结果仍然泄漏。模型复杂度与数据时序是两项独立检查。

重要性不是因果证明

按分裂带来的纯度改善累计重要性，可能偏向可选阈值更多的连续变量。置换重要性在固定评价数据上打乱某列，观察评分下降多少，回答“模型对这一列有多依赖”。相关特征能互相替代，单列打乱时下降可能很小。

如果使用重要性选择因子，选择过程必须在训练或内部验证完成，再到新的测试段评价。不能先根据最终测试重要性删列，又把同一测试段当作独立证据。

还要核对标签方向。用昨天的技术指标去解释过去50日累计收益，可能主要测量同一历史行情，而不是预测随后50日。特征区间、标签区间和可用时点应画在同一时间轴上。

回归树外推和袋外误差

回归树的叶节点输出训练目标均值，因此通常是分段常数。新输入超过训练最大值，会落入边界叶，而不会自动沿上涨趋势外推。用森林预测市值后得到的估值差，也只是模型残差，需要后续收益检验。

每棵树抽样时没被选中的记录可用于袋外误差，但这些记录不一定晚于该树全部训练样本。对未来预测，袋外分数不能替代按时间留出的后段。树对尺度变换通常不敏感，仍然需要处理缺失、类别编码和数据更新时点。
