7.4 因子指数的构建与评价

从质量指数的具体权重出发，说明Smart Beta的规则、可投资性、基金评价以及多因子混合和整合。

同样两只股票，权重为什么不同

两只股票的市值分别为100亿元和200亿元，传统市值加权会分配三分之一与三分之二。如果第一家公司盈利稳定、负债较低，第二家质量较弱，一个质量指数可能改为60%与40%。股票池没有变化，承担的风格风险却变了。

Smart Beta通常指在某类资产内部，以公开、可复制的规则偏离传统市值加权，形成价值、质量、低波动、动量、红利或规模等倾向，以改善收益或风险。选择何种风格属于主动决定，按规则执行则具有指数投资的特征。它仍然可能长期落后于宽基指数。

学术多空因子经常同时买入高分组、卖空低分组，净资金可能为零。可投资的因子指数通常是纯多头组合。后者包含市场风险，不能直接用前者的历史收益代替。融资、融券、保证金及交易成本，也使理论组合与产品净值存在差异。

因子暴露与可投资性怎样取舍

因子暴露表示组合在目标特征上的倾向；可投资性则涉及持仓是否合理、股票能否成交、换手成本和资金容量。五类构造可以放在同一个比较框架中。

构造 主要用途 需要关注的限制
纯因子组合 在模型中分离目标因子的收益 可能需要负权重和集中持仓，主要用于风险估计
多空排序组合 比较高低特征股票的收益 融券、杠杆、其他因子暴露
高暴露指数 筛选或优化，强化目标风格 集中度、换手与容量之间的平衡
高容量指数 保留较广股票池，按市值和得分倾斜 风格强度较温和
市值加权基准 提供广泛市场暴露 仍承担市场风险，风格为相对自身的零点

因子暴露并非越高越好。把所有资金集中到一只最高分股票，可能提高目标得分，却同时增加个股风险和冲击成本。指数通常设置入选数量、流动性筛选、权重上限、缓冲区和调仓频率。

构造方式有两类：等权、最小方差或基本面加权通过权重规则间接产生风格倾向；按指标排序选股则直接控制目标特征。等权常增加小股票相对权重，最小方差偏向低风险股票，但具体暴露仍需用持仓计算，不能仅凭名称判断。

质量指数的计算步骤

历史质量指数示例采用ROE、负债权益比和盈利波动三个指标。先确定可投资股票池，再处理异常值，分别标准化。ROE越高得分越高。负债权益比和盈利波动越高则得分越低，因此后两项需要反向计分。若指标名称是“盈利稳定性”，应先检查实际数值究竟代表稳定程度还是波动程度。

# 自拟两股票质量指数：假定两只股票均已入选。
size = [100.0, 200.0]
z = [1.0, -0.5]
quality = [1+x if x >= 0 else 1/(1-x) for x in z]
raw = [s*q for s,q in zip(size,quality)]
weight = [x/sum(raw) for x in raw]
print(quality, weight)
assert all(abs(a-b)<1e-12 for a,b in zip(weight,[.6,.4]))

鲨鱼说

两个产品都叫“质量指数”，也可能采用不同盈利指标、行业处理和权重上限。比较时先检查规则和实际持仓，再比较费率与历史收益。

收益、风险、费用与透明度

因子指数的收益来源比单纯市场暴露更具体。多个低相关风格组合也可能降低集中风险。公开规则便于识别持仓和风格漂移，通常比频繁主观交易更容易控制执行成本。但费用水平取决于产品和交易方式，透明规则本身不会保证较高收益。

2000—2019年的BetaPlus历史研究以A股总市值最大的1000只股票构建基准，再构建价值、质量、红利、动量、低波动和规模六类纯多头指数。指数权重采用流通市值口径，与学术排序实验中的总市值加权不同。基准年化收益7.24%、波动27.63%。该样本六类因子指数的收益和夏普均较高，其中质量、价值较强，动量改善较小。

相关股债配置实验将60%的股票部分替换为六个因子指数，40%仍为国债，年化收益由6.68%变为9.11%，夏普由0.48变为0.60，最大回撤减少2.13个百分点。另一个防御版本将30%配置质量、30%配置低波动。它们展示了改变股票部分如何改变整体风险收益，数字属于当时样本和指数方法。

历史换手同样值得比较：基准月均换手6.83%，价值18.8%，动量32.9%。交易费用会不断从收益中扣除。持有期“胜率”则是历史窗口累计收益大于零的比例。较长窗口彼此重叠，不能把这些窗口当成独立的重复实验。

评价因子基金要同时看净值与持仓

净值分析包括年化收益、波动、最大回撤、夏普、相对基准收益及跟踪误差。持仓分析进一步检查目标风格暴露、意外行业倾向、单股集中、换手、容量和收益风险归因。只有目标风险相近时，成本高低才容易直接比较。

配置流程应从现有组合的需要出发：缺少哪类风险来源；哪种因子可能补充它；加入以后组合的暴露、风险和费用怎样变化。单只基金历史表现较好，仍可能与已有持仓高度重叠。

产品数量和规模反映市场发展背景。按2019年末统计，美国Smart Beta ETF超过900只、规模约9826.9亿美元。按2020年一季度统计，中国相应ETF为30只、规模169.62亿元。

这些是历史截面，不代表今天的产品清单、价格或费率。

拥挤度可从估值、波动、相关性、动量、持仓重叠及因子内部离散程度观察。大量资金采用相似规则时，平时成交可能顺畅，集中赎回时却会同时卖出相近股票。高拥挤意味着压力情景更值得检验，不是一个精确的反转日期。

鲨鱼说

跟踪误差，即策略收益与基准收益之差的波动率。

多因子混合与整合怎样不同

混合先独立构建价值、质量等单因子组合，再配置这些组合；整合先计算每只股票的多因子综合分，再统一选股。若A非常便宜但质量差，B质量好但昂贵，混合可能同时持有A与B；整合更可能选择价格和质量都适中的C。

混合方便调整单个风格的权重，持仓通常较分散；整合能在同一股票上协调多个特征，但可能提高集中和换手。比较时需要匹配因子暴露和主动风险，否则收益差也可能只是风险强度差。

BetaPlus历史实验中，混合方案等权配置六个指数，整合方案在1000只股票中选综合分前200只，再按自由流通市值加权。整合年化收益高1.49个百分点、夏普高0.06，但最大回撤也略高。不同市场研究对两者优劣并无一致结论。

组合之间的权重还可以采用等权、反波动率、风险平价、最大分散度或因子动量。后四类引入波动、相关性或收益预测，增加信息的同时也增加估计误差。该历史案例中复杂权重未明显超过等权。另一个按1个月与6个月均线在价值和质量间切换的实验报告年化13.98%。它需要进一步扣除换仓成本，并确保信号形成先于交易。

同一风格在不同资产中的定义

价值、动量、持有收益与防御思想也可以用于股票以外的资产，但计算变量必须随资产的现金流结构改变。

资产 价值的参照 动量 持有收益或利差的例子
股票 账面净资产相对市值 过去12个月收益，跳过最近1个月 预期股息率
利率债 名义收益率减预期通胀得到实际利率 对应债券组合的历史收益 期限利差
货币 实际汇率相对其历史或经济参照 汇率相关投资收益 短期存款利率差
商品 当前价格相对5年前价格的变化 商品合约投资收益 展期收益

商品不产生股票式账面净资产，价值指标只能借助其他价格参照。期货持有收益还与合约期限结构相关。股票的防御可由低市场β和质量刻画，国债则需考虑利率敏感性及相对基准风险。跨资产比较应统一投资方向、融资成本和波动尺度。

练习

某质量基金与已有股票组合高度重合，另一质量基金行业更分散，但费率略高。仅按费率能否选出更合适的一个？

查看解答

不能。先计算加入后是否改善目标质量暴露、行业集中与组合风险，再比较总费用及跟踪质量。若两种实现的风险暴露接近，低成本具有明确优势；若实现的目标不同，应比较对整体组合的贡献。
