3.1 极限与导数

复习极限与求导规则，计算复合幂导数并比较指数幂的大小。

极限描述变量接近某处时函数的变化，导数描述局部变化率。计算前需要确认定义域、趋近方向与可导条件，再选择代数化简或微分规则。

微积分与线性代数是后续概率、优化和定价问题的基础。本章按定义、公式和例题组织，计算时同时说明定义域与方法条件。

(uv)′=u′v+uv′,(u/v)′=(u′v−uv′)/v2,(f∘u)′=f′(u)u′.(uv)'=u'v+uv',\quad (u/v)'=(u'v-uv')/v^2,\quad(f\circ u)'=f'(u)u'.(uv)′=u′v+uv′,(u/v)′=(u′v−uv′)/v2,(f∘u)′=f′(u)u′.

复合幂函数求导

**题目。**在 x>1x>1x>1 上，求 y=(ln⁡x)ln⁡xy=(\ln x)^{\ln x}y=(lnx)lnx 对 xxx 的导数。

考点：对数求导；乘积法则；复合函数。

查看分析与解答

必要知识

当底数和指数都含变量时，普通的幂函数公式不能直接使用。对正函数 y 取对数，有 (ln⁡y)′=y′/y(\ln y)'=y'/y(lny)′=y′/y；乘积求导为 (uv)′=u′v+uv′(uv)'=u'v+uv'(uv)′=u′v+uv′，复合函数求导需要再乘内层导数。本题在 x>1 时，底数 ln x 为正，可以作实数幂并取对数。

分析思路

先用对数把指数移到乘号前，把复合幂转成两个函数的乘积。对等式两侧求导后，先得到 y'/y，再乘回 y。

解答步骤

由 y=(ln⁡x)ln⁡xy=(\ln x)^{\ln x}y=(lnx)lnx，得到

ln⁡y=ln⁡x ln⁡(ln⁡x).\ln y=\ln x\,\ln(\ln x).lny=lnxln(lnx).

右侧两个因子的导数分别为 1/x1/x1/x 和 1/(xln⁡x)1/(x\ln x)1/(xlnx)。因此

y′y=1xln⁡(ln⁡x)+ln⁡x1xln⁡x=ln⁡(ln⁡x)+1x.\frac{y'}y=\frac1x\ln(\ln x)+\ln x\frac1{x\ln x} =\frac{\ln(\ln x)+1}{x}.yy′​=x1​ln(lnx)+lnxxlnx1​=xln(lnx)+1​.

乘回原函数可得

y′=(ln⁡x)ln⁡xx[ln⁡(ln⁡x)+1].y'=\frac{(\ln x)^{\ln x}}x[\ln(\ln x)+1].y′=x(lnx)lnx​[ln(lnx)+1].

例如 x=e 时，y=1、y'=1/e。计算中第二项的 ln x 被约去，不能漏掉这一项。

比较 eπe^\pieπ 与 πe\pi^eπe

**题目。**不计算二者的数值，判断哪个更大。

考点：单调变换；辅助函数；导数判号。

查看分析与解答

必要知识

对数函数严格递增，所以两个正数的大小与其对数的大小一致。要证明两个幂谁大，可以先比较指数乘对数。导数为正、负，分别意味着函数在相应区间递增、递减。

分析思路

取对数得到 π 与 e ln π。两边除以正数 eπ 后，比较对象变成同一函数 ln x/x 在 e 和 π 两点的值，因此可以用导数确定顺序。

解答步骤

有 ln⁡(eπ)=π\ln(e^\pi)=\piln(eπ)=π，ln⁡(πe)=eln⁡π\ln(\pi^e)=e\ln\piln(πe)=elnπ。比较这两个数，等价于比较 1/e1/e1/e 与 ln⁡π/π\ln\pi/\pilnπ/π。

令 f(x)=ln⁡x/xf(x)=\ln x/xf(x)=lnx/x，则

f′(x)=1−ln⁡xx2.f'(x)=\frac{1-\ln x}{x^2}.f′(x)=x21−lnx​.

在 x>e 时分子为负，函数递减。由于 π>e，故 $f(\pi)<f(e)=1/e$。乘回 eπ 得 eln⁡π<πe\ln\pi<\pielnπ<π，再用对数的严格单调性得到 πe<eπ\pi^e<e^\piπe<eπ。

同类问题

比较 a^b 与 b^a 时，可比较 ln a/a 与 ln b/b。辅助函数在 (0,e) 上递增、在 (e,∞) 上递减；若两个底数分处 e 两侧，仅知道底数大小不足以直接下结论。

洛必达法则与两个极限

对 0/00/00/0 或无穷比无穷型，在邻域内可微、分母导数非零、导数比极限存在等条件下，可用 lim⁡f/g=lim⁡f′/g′\lim f/g=\lim f'/g'limf/g=limf′/g′。

**题目。**求 lim⁡x→∞ex/x2\lim_{x\to\infty}e^x/x^2limx→∞​ex/x2 和 lim⁡x↓0x2ln⁡x\lim_{x\downarrow0}x^2\ln xlimx↓0​x2lnx。

考点：未定式；洛必达法则；增长速度。

查看分析与解答

必要知识

洛必达法则用于满足可导等条件的 0/0 或 ∞/∞ 型商式，计算的是分子、分母各自求导后的商，不是对整个商求导。乘积 0×∞ 必须先改写成适用的商式。

分析思路

第一式是指数与多项式的比，连续求导两次可消去分母的幂。第二式的困难是零乘无穷，把 x² 移到分母，转成 ln x 与 x⁻² 的比再求导。

解答步骤

当 x→∞ 时，e^x 与 x² 都趋于无穷，第一次应用法则得到 e^x/(2x)，仍是 ∞/∞；再次应用后为 e^x/2。因此

lim⁡x→∞exx2=+∞.\lim_{x\to\infty}\frac{e^x}{x^2}=+\infty.x→∞lim​x2ex​=+∞.

当 x→0⁺ 时，写成

x2ln⁡x=ln⁡xx−2.x^2\ln x=\frac{\ln x}{x^{-2}}.x2lnx=x−2lnx​.

分子趋于负无穷、分母趋于正无穷。分别求导得到

1/x−2x−3=−x22⟶0.\frac{1/x}{-2x^{-3}}=-\frac{x^2}{2}\longrightarrow0.−2x−31/x​=−2x2​⟶0.

故第二个极限为 0。因为小于 1 的正数取对数为负，原表达式从负侧趋近零。

同类问题

先识别未定式再选方法。指数通常比固定次幂增长快，固定正次幂又比对数增长快；用这些结论前应明确趋近方向和指数范围。不能把非未定式直接交给洛必达法则。
