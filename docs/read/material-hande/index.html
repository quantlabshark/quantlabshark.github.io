1. 递归程序与静态变量

题目

函数 rr 共享静态计数 ctrl=0,odds=0。每次调用先令 odds+=1；若 x<9，令 ctrl+=1，取 q=trunc(x/2)（ctrl<3）或 q=trunc(x/3)（其他情况），当 ctrl>1 再加 ctrl；若 x>=9，令 q=rr(x-2)+rr(trunc(x/3))。返回前按最终 odds+q 的奇偶打印 I like q（偶）或 I hate q（奇），再返回 q。计算 rr(rr(rr(13)-3)-5)：分别说明未规定两个加数求值顺序时的问题，并在先左后右的约定下给出输出和返回值。

考点：共享状态；递归轨迹；求值先后。

查看分析与解答

必要知识

静态计数在所有调用之间共享，子调用修改后不会在返回时恢复。函数返回值因此依赖当前计数，不仅依赖参数x；父调用打印时还使用子调用完成后的odds。

分析思路

先固定两个子调用的求值顺序，再建立参数、进入计数、返回q和打印计数的轨迹。嵌套外层调用必须等内层结果计算完才能开始。

解答步骤

最内rr(13)产生结果15后，下一层实际调用rr(12)，因为先减三；这一层结束后再减五作为最外参数。每一层进入都增加odds，即使走递归分支也不能漏记；ctrl只在x<9的分支增加。

ctrl 与 odds 只初始化一次，不是每层递归各有一份。进入子调用后计数会改变，父调用打印时也会读取更新后的全局计数，所以不能只按输入 x 给函数预先列一张无状态返回表。

按先左后右约定，最内层 rr(13) 先调用 rr(11)，再向下调用 rr(9)。rr(9) 先进入 rr(7)。此时 odds=4,ctrl=1,q=3，奇偶和为 7，打印 I hate 3。随后 rr(3) 增加共享计数，得到 ctrl=2,q=1+2=3，打印 I like 3。父调用依次恢复，但不会恢复静态计数。

因此要逐条记录“进入时参数、共享计数、子调用返回值、打印时计数”。下面的显式临时变量固定求值顺序，模拟程序输出相应轨迹，最终返回 70。没有固定加数求值顺序时，不能假定所有实现都会给出这条轨迹。

两个加数的求值先后若没有明确规定，而递归会修改共享状态。要获得可复现输出，应把该行改成：

C++3 行
int left = rr(x - 2);
int right = rr(x / 3);
q = left + right;

按先左后右的顺序，打印轨迹如下；这份轨迹对应先左后右的约定。

可用下面的状态模拟逐行检查。Python 的 // 对负数向下取整，C++ 的整数除法向零截断，故这里采用 int(x / d)。

Python20 行
def trace():
    ctrl = odds = 0
    lines = []
    def rr(x):
        nonlocal ctrl, odds
        odds += 1
        if x < 9:
            ctrl += 1
            q = int(x / (2 if ctrl < 3 else 3))
            if ctrl > 1:
                q += ctrl
        else:
            left = rr(x - 2)
            right = rr(int(x / 3))
            q = left + right
        lines.append(('I like ' if (odds + q) % 2 == 0 else 'I hate ') + str(q))
        return q
    result = rr(rr(rr(13) - 3) - 5)
    return lines, result
assert trace()[1] == 70

整数除法也会影响负参数分支：向零截断的−5/2为−2，而Python的−5//2为−3。本题模拟数值较小，int(x/d)可对应截断；一般大整数宜用绝对值整除再恢复符号，避免转浮点损失精度。把子调用拆成两个语句可令共享状态变化顺序明确。

同类问题

追踪有副作用的递归时，不能把函数当作纯数学映射。分别记录局部栈帧和共享存储，并先确认语言的求值顺序约定。

2. 一维存储数据的协方差矩阵

题目

长度为 nmnmnm 的一维数组按行保存一个 n×mn\times mn×m 实数观测矩阵，n≥2n\ge2n≥2，各行独立同分布且二阶矩有限，每行为一次观测、每列为一个变量。计算无偏样本协方差矩阵。说明分母为什么为 n−1n-1n−1，给出 [1,2,3,4,5,6]、n=3,m=2n=3,m=2n=3,m=2 的结果。

考点：观测方向；中心矩；无偏性推导。

查看分析与解答

必要知识

每行一个观测、每列一个变量，故协方差矩阵为m×m。中心化需要减每列均值，而不是每行均值；一维恢复顺序也必须与存储规则一致。

分析思路

先reshape并中心化，计算列之间的交叉乘积。用中心化恒等式推导分母n−1，再对小矩阵逐项核算。

解答步骤

记总体均值μ、样本均值X̄，有Σ_i(X_i−X̄)(X_i−X̄)ᵀ=Σ_i(X_i−μ)(X_i−μ)ᵀ−n(X̄−μ)(X̄−μ)ᵀ。独立同分布时两项期望为nΣ和n(Σ/n)，相减得到(n−1)Σ，所以除n−1无偏。

先将数组恢复为 nnn 行 mmm 列，再计算每列均值 Xˉj\bar X_jXˉj​，令中心化矩阵 Zij=Xij−XˉjZ_{ij}=X_{ij}-\bar X_jZij​=Xij​−Xˉj​。协方差矩阵为 S=ZTZn−1,Sjk=1n−1∑iZijZik.S=\frac{Z^TZ}{n-1},\qquad S_{jk}=\frac1{n-1}\sum_i Z_{ij}Z_{ik}.S=n−1ZTZ​,Sjk​=n−11​i∑​Zij​Zik​. 样本均值由同一批数据估计，中心化后的每列元素和为零，消耗一个自由度；在独立同分布且二阶矩存在时，中心化乘积和的期望为 (n−1)Σ(n-1)\Sigma(n−1)Σ，所以除以 n−1n-1n−1 无偏。

示例恢复为三行 [1,2]、[3,4]、[5,6]，均值为 [3,4]，中心化行为 [-2,-2]、[0,0]、[2,2]。ZTZZ^TZZTZ 的四项都是 8，除以 2 得到 [[4,4],[4,4]]。

矩阵乘法的朴素计算量为 O(nm2)O(nm^2)O(nm2)。先中心化再相乘，可减少“大平方和减大均值平方”导致的消减误差。若求正态总体的极大似然协方差，分母为 nnn，它与无偏估计是不同目标。

Python8 行
import numpy as np
def covariance(flat, n, m):
    if n < 2 or len(flat) != n*m:
        raise ValueError('至少两次观测，且数据长度等于 n*m')
    x = np.asarray(flat, dtype=float).reshape(n, m)
    z = x - x.mean(axis=0)
    return z.T @ z / (n-1)
assert np.allclose(covariance([1,2,3,4,5,6], 3, 2), [[4,4],[4,4]])

样例两个变量始终差一，中心化后完全相同，故协方差4等于各自方差4，相关为一，矩阵秩一。这既核验计算，也说明协方差矩阵可以半正定而非正定。若观测存在时间相关，样本均值协方差不再简单等于Σ/n，上述无偏推导条件便改变。

同类问题

矩阵统计先固定行列含义，再推导估计量针对的目标。分母选择来自无偏或极大似然目标，不能仅凭软件默认值决定。

3. 25 匹马的排名

题目

25 匹马速度固定且互异，每场最多 5 匹，不使用计时器，每场只知道参赛马的先后顺序。给出找出最快 3 匹的最少场次和安排；再给出找出最快 5 匹的一个有限场次方案，并解释哪些候选可以排除。

考点：偏序淘汰；对抗下界；排序链合并。

查看分析与解答

必要知识

每场只得到相对顺序，没比赛过的马之间仅能靠传递关系比较。某马已知有三匹更快便可排除前三。证明最少场次既要给安排，也要说明更少场次无法保证成功。

分析思路

五组内部排序后比冠军，按已知前驱数量删候选；第七场决出剩余两名。下界用“尚无败绩”的候选冠军构造不利结果，前五则用多条排序链逐名合并。

解答步骤

六场下界可用对抗论证。每场至多让四匹首次失去冠军可能。对手安排任何尚无败绩的参赛马都快于已有败绩者；这样要在六场淘汰24个冠军候选，每场必须恰有五匹无败绩者，且淘汰四匹。否则六场后连第一名都未必确定。

先分五组比赛，得到各组内部顺序，再让五组冠军比赛。按冠军由快到慢将组记为 A,B,C,D,EA,B,C,D,EA,B,C,D,E，组内记作 A1>A2>⋯A_1>A_2>\cdotsA1​>A2​>⋯。这六场之后，A1A_1A1​ 已确定最快。

进入前三的其余马只可能是 A2,A3,B1,B2,C1A_2,A_3,B_1,B_2,C_1A2​,A3​,B1​,B2​,C1​。例如 B3B_3B3​ 已知至少慢于 A1,B1,B2A_1,B_1,B_2A1​,B1​,B2​，不能进入前三。D1D_1D1​ 至少慢于三个组冠军。第七场比较五名候选，其前两名连同 A1A_1A1​ 就是前三。第七场完成前三排序；对任意安排的六场下界见后面的对抗论证。

找前五时，先沿上述七场方案确定前三，将这三匹从各自组内排序链删除。每组尚未选出的最快马至多五匹，让它们参加第八场，冠军就是全局第四。从冠军所在组换入下一匹，再让五组当前候选参加第九场，冠军就是全局第五。

这给出 9 场方案，每场最多五匹。

每个未入选的马都不快于本组当前候选，故全局下一名必在这五个候选中。第八、九场依次确定第四和第五，方案共需 9 场。

在这一必要结构下，最后一场含至少一匹此前比赛冠军。可安排它赢下最后一场；它此前直接击败的次名与最后一场次名，都是可能的全局第二。这两匹已败后不能在前述六场结构中再次参赛，因此彼此次序未定，六场无法保证前三。第七场构造达到下界。前五的九场方案只是一个上界，此处不据此声称九场最少。

同类问题

无计时排名用已知比较构成偏序，并以可能排名保留候选。场次最少的证明需涵盖自适应安排，不能只说明某一种六场方案失败。

4. 共同市场因素下的组合收益

题目

NNN 只股票收益为 ri=rm+εir_i=r_m+\varepsilon_iri​=rm​+εi​。市场项均值、方差为 μm,σm2\mu_m,\sigma_m^2μm​,σm2​。特异项相互独立，均值、方差为 με,σε2\mu_\varepsilon,\sigma_\varepsilon^2με​,σε2​，并与市场项独立。对 R=∑hiriR=\sum h_ir_iR=∑hi​ri​，分别求三种权重下的均值和方差：全部 hi=1/Nh_i=1/Nhi​=1/N。NNN 为偶数，一半 1/N1/N1/N、一半 −1/N-1/N−1/N。权重相互独立服从 N(0,σh2)N(0,\sigma_h^2)N(0,σh2​)，且与整个收益向量独立。

考点：共同风险；权重平方和；全方差。

7. 分类、聚类与算法

题目

比较有监督分类与无监督聚类，分别列举模型和评价指标。详细说明 KNN 分类、K-means 聚类步骤，以及轮廓系数怎样结合组内、组间距离；给出一个轮廓系数的数值例子。

考点：监督信号；邻居与簇；距离评价。

查看分析与解答

必要知识

分类使用已经知道的类别作为学习目标，聚类则依据特征相似性划分组。KNN的K是每次预测参考多少邻居，K-means的K是整个数据形成多少簇，两个参数没有相同含义。

分析思路

先确定任务有无标签，再分别讲数据预处理、算法步骤、预测或分配方式与评价。最后把轮廓系数的两种平均距离代入数值解释。

解答步骤

KNN对新点计算与训练点的距离，取最近K个并投票；K-means对全部点分配最近中心后，把各簇中心更新为均值。均值最小化簇内平方距离，因此固定分组时更新不会增大目标；固定中心时分配最近中心也不会增大目标。

先确认要预测已有标签还是探索没有标签的结构。分类给每条训练样本已知类别，学习从特征到标签的规则；聚类则由样本之间的相似性形成分组，组号本身没有先验经济含义。

KNN 的 k 是预测时参考的邻居数；K-means 的 k 是要形成的簇数。距离对尺度敏感，例如成交额以元计、收益以小数计时，应先依据训练数据缩放，否则距离可能几乎由成交额决定。

K-means 每轮分配和更新均不增加平方距离目标，直到达到局部稳定，但不同初始中心可能给出不同结果。一次分配需约 O(nkd)O(nkd)O(nkd) 次运算，d 为特征维数；可多初值运行并比较目标。

例如某点到同簇其他点平均距离为 a=2a=2a=2，到最近其他簇的平均距离为 b=5b=5b=5，轮廓系数为 (5−2)/5=0.6(5-2)/5=0.6(5−2)/5=0.6；若 a=5,b=2a=5,b=2a=5,b=2，则为 -0.6，提示其更接近其他簇。下面分别列出算法与评价口径。

分类有已知标签，例如用历史特征预测下一期涨跌。聚类在没有类别标签时按相似性分组，例如划分股票的收益特征。分类评估用混淆矩阵、精确率、召回率及相应阈值下的指标。聚类可用轮廓系数、Calinski–Harabasz 指数、Davies–Bouldin 指数，有外部标签时再用 ARI、NMI。

KNN 分类先使用训练样本拟合尺度变换，计算待预测点与各训练点的距离，选取最近 kkk 个，按多数标签或距离加权投票。K-means 先选 kkk 个中心，再交替进行“分配到最近中心”和“更新各组均值”，到目标函数变化很小或达到迭代上限为止。前者保留训练样本用于预测，后者学习一组中心。两者的 kkk 含义不同。

常见分类器包括 Logistic 回归、支持向量机、决策树、随机森林、梯度提升树、KNN 和朴素贝叶斯。应先固定时间划分，再在训练集内选择超参数。比较准确率时，还需要考虑类别不平衡和错判成本。常见聚类方法有 K-means、层次聚类、高斯混合模型和 DBSCAN，分别依赖中心距离、层次合并、概率分布或局部密度。

轮廓系数同时比较组内紧密程度与组间分离程度。对样本 iii，令 a(i)a(i)a(i) 为它到同簇其他样本的平均距离，b(i)b(i)b(i) 为它到其他各簇平均距离中的最小值，则

s(i)=b(i)−a(i)max⁡{a(i),b(i)}.s(i)=\frac{b(i)-a(i)}{\max\{a(i),b(i)\}}.s(i)=max{a(i),b(i)}b(i)−a(i)​.
