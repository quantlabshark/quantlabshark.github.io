收益、风险与因子：阅读所需的基础知识

通过收益率、回归和两资产组合的计算，理解因子研究中的常用概念。

一笔投资怎样计算收益

花 100 元买入一股股票，一期后以 103 元卖出，期间收到 1 元分红。这笔投资赚了 4 元，相对于最初投入的 100 元，收益率为 4%。价格上涨和现金分红共同构成持有收益：

Rt=Pt+Dt−Pt−1Pt−1.R_t=\frac{P_t+D_t-P_{t-1}}{P_{t-1}}.Rt​=Pt−1​Pt​+Dt​−Pt−1​​.

Pt−1P_{t-1}Pt−1​ 是期初买入价格，PtP_tPt​ 是期末价格，DtD_tDt​ 是期间每股分红，下标 ttt 表示期末。分母必须是为取得这一期收益投入的资金。使用复权行情时，先查明分红的处理方式，已计入分红的收益序列无需再次加上现金分红。

收益率便于比较不同金额的投资。投入 100 元赚 4 元，与投入 1000 元赚 40 元，收益率相同，都是 4%。但两者承担的资金损失金额不同。因此，研究收益率之后，还要根据风险和资金规模决定持仓。

多期收益需要连乘。100 元先上涨 10%，再下跌 10%，金额依次变为 110 元和 99 元，累计收益为 −1%。一般地，TTT 期的累计收益为

R1:T=∏t=1T(1+Rt)−1.R_{1:T}=\prod_{t=1}^{T}(1+R_t)-1.R1:T​=t=1∏T​(1+Rt​)−1.

符号 ∏\prod∏ 表示把每一期的括号依次相乘。平均每期涨多少与最终资金增加多少，是两个不同的量。

鲨鱼说

上涨 10% 后，下一次下跌的基数已变成 110 元；下跌 10% 会损失 11 元。复利计算中的基数随时间变化，这就是“先涨后跌”不能简单相抵的原因。

收益比较与基准选择

假设股票收益为 4%，同期无风险收益为 1%，二者之差 3 个百分点称为相对无风险资产的超额收益。若市场指数上涨 2%，股票相对该指数的收益差则为 2 个百分点。两个比较基准回答的问题不同。

资产定价公式常用超额收益 rt=Rt−Rf,tr_t=R_t-R_{f,t}rt​=Rt​−Rf,t​，其中 Rf,tR_{f,t}Rf,t​ 是同一持有期的无风险收益。年利率不能直接从月收益中扣除。若年有效利率为 3%，对应月有效利率为 (1.03)1/12−1(1.03)^{1/12}-1(1.03)1/12−1，约为 0.2466%。

收益高于指数，也不必然表示存在选股贡献。某组合可能只是持有了更多随市场涨跌的资产。因子模型正是用来进一步分解这种差异。

因子研究的四个基本对象

同一天，不同股票可能因规模、估值、盈利能力或行业不同而表现各异。研究者先把差异表示为指标，再检验指标与未来收益的关系。例如，账面市值比等于账面权益除以股票市值，用于描述价格相对账面权益的高低。

图中的四个对象有不同的数据形态。特征是每只股票在某时点的属性。因子收益通常是某种组合逐期产生的收益序列。暴露描述资产对因子的敏感度。溢价是在定价模型中，每单位暴露对应的预期收益补偿。

例如，按账面市值比把股票分为高、低两组，高组收益减去低组收益，可以形成一个价值因子收益序列。某只股票与这一序列共同变化的程度，可通过回归估计。高账面市值比本身只是特征值，不能直接当作下一期收益率使用。

历史平均因子收益是长期预期收益的一项估计。它随样本变化，因此还需要衡量估计误差，并研究这种收益差异为何可能持续。

鲨鱼说

特征值，即矩阵沿对应特征向量方向的伸缩倍数。

平均收益、波动率与标准误

某策略三个月的收益分别为 1%、−1%、3%，平均值为 1%。三个收益相对均值的偏差为 0、−2、2 个百分点。样本标准差为

s=(0−0)2+(−0.02)2+0.0223−1=0.02.s=\sqrt{\frac{(0-0)^2+(-0.02)^2+0.02^2}{3-1}}=0.02.s=3−1(0−0)2+(−0.02)2+0.022​​=0.02.

更一般地，s=∑t(Rt−Rˉ)2/(T−1)s=\sqrt{\sum_t(R_t-\bar R)^2/(T-1)}s=∑t​(Rt​−Rˉ)2/(T−1)​。TTT 是期数，Rˉ\bar RRˉ 是样本均值。这里的 2% 衡量单月收益的波动，不是平均收益的误差。

如果各期收益相互独立、具有相同均值和有限方差，样本均值的标准误为 s/Ts/\sqrt Ts/T​。上例约为 1.155 个百分点。波动率描述每一期收益有多不稳定。标准误描述用这些样本估计长期均值有多不准确。增加样本期数可以降低均值估计的误差，却不会使策略自身的月度波动自动下降。

如果相邻月份收益相关，均值的误差还包含跨期协方差。这时需要根据相关结构估计标准误，第 2 章将介绍相应的方法。

用回归分解共同变化

设 ri,tr_{i,t}ri,t​ 是股票 iii 在第 ttt 期的超额收益，ftf_tft​ 是同一期的因子收益。单因子回归写成

ri,t=αi+βift+εi,t.r_{i,t}=\alpha_i+\beta_i f_t+\varepsilon_{i,t}.ri,t​=αi​+βi​ft​+εi,t​.

等号右侧分为三部分：截距 αi\alpha_iαi​、随因子变化的部分 βift\beta_i f_tβi​ft​、模型未解释的残差 εi,t\varepsilon_{i,t}εi,t​。普通最小二乘法从历史数据中选择截距和斜率，使残差平方和最小。

假设估计得到 α=0.2%\alpha=0.2\%α=0.2%、β=1.2\beta=1.2β=1.2。当因子收益为 2% 时，拟合的股票超额收益为 0.2%+1.2×2%=2.6%0.2\%+1.2\times2\%=2.6\%0.2%+1.2×2%=2.6%。若实际收益为 3%，残差就是 0.4 个百分点。斜率 1.2 描述对因子变化的敏感程度，并非买入了 120% 的股票。

这项回归沿时间比较同一只股票的收益。若要研究不同股票的平均收益为何不同，则需要比较股票之间的暴露或特征，属于横截面问题。辨别回归中的一行是一个月份还是一只股票，有助于理解不同方法的用途。

统计检验怎样判断证据

假设研究目标是判断某策略的长期平均收益是否为零。先提出原假设 H0:μ=0H_0:\mu=0H0​:μ=0，再比较样本均值与其估计误差。常用的 ttt 统计量为“估计值除以标准误”。在上面的三个月示例中，t≈0.01/0.01155=0.866t\approx0.01/0.01155=0.866t≈0.01/0.01155=0.866。

检验时的 ppp 值，是在原假设和检验模型成立的条件下，出现至少同样极端统计量的概率。它不能直接读成“策略无效的概率”。样本只有三个月，均值估计的误差很大。这也是需要积累更多观察、而不能只看平均收益正负的原因。

如果反复尝试不同股票池、窗口和参数，再只报告最好的结果，偶然波动便可能被选成所谓规律。比较方案时需要保留尝试记录，并将后续数据用于评估已经固定的方法。第 6 章将进一步讨论多重检验。

两只股票的组合，为什么需要矩阵

假设两只股票的权重为 60% 和 40%，预期收益分别为 5% 和 8%，组合预期收益是

0.6×0.05+0.4×0.08=6.2%.0.6\times0.05+0.4\times0.08=6.2\%.0.6×0.05+0.4×0.08=6.2%.

把权重写为向量 w=(0.6,0.4)⊤w=(0.6,0.4)^\topw=(0.6,0.4)⊤，预期收益写为 μ=(0.05,0.08)⊤\mu=(0.05,0.08)^\topμ=(0.05,0.08)⊤，上述计算可简写为 w⊤μw^\top\muw⊤μ。向量是一组有顺序的数，⊤\top⊤ 表示转置，即把行与列互换。

风险还取决于两只股票是否一起涨跌。协方差矩阵 Σ\SigmaΣ 的对角线记录各自的方差，非对角线记录共同波动的协方差。组合方差写作

w⊤Σw=w12σ12+w22σ22+2w1w2Cov⁡(R1,R2).w^\top\Sigma w=w_1^2\sigma_1^2+w_2^2\sigma_2^2+2w_1w_2\operatorname{Cov}(R_1,R_2).w⊤Σw=w12​σ12​+w22​σ22​+2w1​w2​Cov(R1​,R2​).

图中两项资产的波动率都为 20%，权重各为一半。完全同向时，组合波动率仍为 20%。不相关时降为约 14.1%。完全反向且波动率相同时，组合波动相互抵消。分散化效果取决于资产的共同波动结构，持仓数量需与相关性和集中度一并分析。

用 Python 复算

Python18 行
import numpy as np

returns = np.array([0.01, -0.01, 0.03])
mean = returns.mean()
vol = returns.std(ddof=1)
print("均值、波动率、均值标准误:", mean, vol, vol / np.sqrt(3))
print("先涨后跌累计收益:", np.prod(1 + np.array([0.1, -0.1])) - 1)

factor = np.array([-0.02, -0.01, 0.0, 0.01, 0.02])
asset = 0.002 + 1.2 * factor
x = np.column_stack([np.ones(factor.size), factor])
alpha, beta = np.linalg.lstsq(x, asset, rcond=None)[0]
assert np.allclose([alpha, beta], [0.002, 1.2])
print("截距、斜率:", alpha, beta)

w = np.array([0.5, 0.5])
cov = np.diag([0.2**2, 0.2**2])
print("不相关时的组合波动率:", np.sqrt(w @ cov @ w))

第一行依次约为 0.01、0.02、0.01155。累计收益为 −0.01。回归结果为 0.002、1.2。最后得到约 0.14142。回归例子采用精确线性关系，便于检查斜率的计算。散点图展示的残差含义，则对应实际收益偏离拟合值的情况。

练习

某资产收益为 5%，同期无风险收益为 1%。若模型给出的超额收益拟合值为 3%，实际超额收益和残差各是多少？

查看解答

实际超额收益为 5%−1%=4%5\%-1\%=4\%5%−1%=4%，残差为 4%−3%=1%4\%-3\%=1\%4%−3%=1%，即 1 个百分点。比较实际值与拟合值时，两者必须采用同一种收益口径。
