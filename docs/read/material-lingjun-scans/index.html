1. 放回规则不同的抽球

题目

盒中有 3 个红球、2 个黄球。每次在盒内球中均匀抽一个，红球放回、黄球取走不放回，共抽 3 次。求取出黄球数量的期望。

考点：变化样本空间；状态期望；条件递推。

查看分析与解答

必要知识

红球放回使红球数始终三，黄球取走使后续抽中黄球的概率降低。因此三次抽取不是相同成功率的独立伯努利试验。剩余黄球数与剩余次数足以描述未来。

分析思路

设E(y,t)，按下一次颜色拆分即时收获与未来收获。先填一抽和一黄球的边界，再逐步算到两黄球、三抽。

解答步骤

抽到黄球分支的1代表当前取走的一球，后续只有y−1黄球；抽到红球当前收获零，后续仍y黄球。若y=0或t=0，未来黄球数均为零，这给出递推停止条件。

令 E(y,t)E(y,t)E(y,t) 表示还剩 yyy 个黄球、还抽 ttt 次时的未来黄球数期望。若下一次抽到黄球，得到 1 个并进入 (y−1,t−1)(y-1,t-1)(y−1,t−1)；抽到红球则进入 (y,t−1)(y,t-1)(y,t−1)，红球总数始终是 3。

计算基值 E(1,1)=1/4E(1,1)=1/4E(1,1)=1/4、E(2,1)=2/5E(2,1)=2/5E(2,1)=2/5。进一步 E(1,2)=1/4+(3/4)(1/4)=7/16E(1,2)=1/4+(3/4)(1/4)=7/16E(1,2)=1/4+(3/4)(1/4)=7/16；E(2,2)=(2/5)(1+1/4)+(3/5)(2/5)=37/50E(2,2)=(2/5)(1+1/4)+(3/5)(2/5)=37/50E(2,2)=(2/5)(1+1/4)+(3/5)(2/5)=37/50。最后 E(2,3)=(2/5)(1+7/16)+(3/5)(37/50)=1019/1000E(2,3)=(2/5)(1+7/16)+(3/5)(37/50)=1019/1000E(2,3)=(2/5)(1+7/16)+(3/5)(37/50)=1019/1000。

2. 阳性检测的条件概率

题目

人群中某状态的发生率为 1%。检测对真实阳性的识别率为 95%，对真实阴性的识别率也为 95%。随机抽取一人检测为阳性，求其真实为阳性的概率。若只知道总体“准确率 95%”，能否得到同一结果？

考点：基础率；条件方向；混淆矩阵。

查看分析与解答

必要知识

灵敏度是实际阳性中检出阳性的比例，特异度是实际阴性中检出阴性的比例。题目问的是阳性报告中实际阳性的比例，条件方向相反，需要结合发生率重新归一化。

分析思路

用一个便于整除的假想人群建立四格计数表，再在阳性报告列内求比例。第二问把总体准确率写成两未知性能的一个方程，检查是否足以唯一求解。

解答步骤

10000人中四格平均计数为真阳95、漏报5、误报495、真阴9405。报告阳性列包含95和495，所以后验不是95%，而是95/(95+495)。这里人数是概率比例的演示，并非另一次实际调查。

用 10000 人作比例计算：真实阳性约 100 人，其中检出阳性 95 人；真实阴性约 9900 人，其中误报阳性 9900×0.05=4959900\times0.05=4959900×0.05=495 人。阳性报告共 590 份，所以所求比例为 95/590=19/118≈16.10%95/590=19/118\approx16.10\%95/590=19/118≈16.10%。

用事件 DDD 表示真实阳性、+++ 表示检测阳性，同一计算写成 P(D∣+)=P(+∣D)P(D)P(+∣D)P(D)+P(+∣Dc)P(Dc).P(D\mid+)=\frac{P(+\mid D)P(D)}{P(+\mid D)P(D)+P(+\mid D^c)P(D^c)}.P(D∣+)=P(+∣D)P(D)+P(+∣Dc)P(Dc)P(+∣D)P(D)​. 基础率低时，阴性人群很大，即使误报率不高，也可能产生较多误报。

总体准确率只给出 P(+)P(D∣+)+P(−)P(Dc∣−)P(+)P(D\mid+)+P(-)P(D^c\mid-)P(+)P(D∣+)+P(−)P(Dc∣−)，或等价的 0.01s+0.99t=0.950.01s+0.99t=0.950.01s+0.99t=0.95，不能分别确定灵敏度 sss 和特异度 ttt。不同的 (s,t)(s,t)(s,t) 会给出不同后验，因此必须分别给出两项性能。

只知准确率0.95时，s=0、t=0.95/0.99与s=1、t=0.94/0.99都满足0.01s+0.99t=0.95。前者阳性报告全是误报、后验零；后者真阳性概率0.01、误报0.05，后验1/6。因此相同总体准确率不能确定阳性报告可信度。

同类问题

识别、筛查和报警题先标出每个概率的条件方向。基础率较低时，必须同时报告误报机制，单一准确率不足以解释阳性结果。

3. 连续三次正面的等待时间

题目

独立投掷公平硬币，求首次连续出现 3 个正面所需投掷次数的期望，并推广到连续 m≥1m\ge1m≥1 个正面。

考点：连续模式；末尾状态；等待时间递推。

查看分析与解答

必要知识

判断是否快要达到连续三正面，只需末尾已有几次连续正面，而无需保存全部历史。一次反面会清空已累计的连续前缀，重叠窗口使等待不等于八次。

鲨鱼说

三个正面的概率是八分之一，指的是预先固定的三个位置。等待过程中，相邻窗口共享投掷结果；前面已连续出现的正面会影响下一步距离成功还有多远，所以要记录末尾状态。

分析思路

为末尾长度0、1、2分别设剩余期望，每次付出一次投掷后转到新状态。将递推从成功边界向前代入，最后求初始E₀。

解答步骤

一般m次连续正面时，E_i=1+E_{i+1}/2+E₀/2，E_m=0。设A=1+E₀/2，从末端逐层代入得E₀=AΣ_{j=0}^{m−1}2⁻ʲ=2A(1−2⁻ᵐ)。移项E₀2⁻ᵐ=2(1−2⁻ᵐ)，故E₀=2^{m+1}−2。

只需记录当前末尾连续正面数 k=0,1,2,3k=0,1,2,3k=0,1,2,3。令 EkE_kEk​ 为从该状态继续到成功还需的平均次数，E3=0E_3=0E3​=0。出现反面后状态归零，出现正面则状态增加一，故 E0=1+E0+E12,E1=1+E0+E22,E2=1+E02.E_0=1+\frac{E_0+E_1}{2},\quad E_1=1+\frac{E_0+E_2}{2},\quad E_2=1+\frac{E_0}{2}.E0​=1+2E0​+E1​​,E1​=1+2E0​+E2​​,E2​=1+2E0​​. 先由第一式得 E1=E0−2E_1=E_0-2E1​=E0​−2，再代入第二式得 E2=E0−6E_2=E_0-6E2​=E0​−6，与第三式联立得到 E0=14E_0=14E0​=14。

等待某串模式时，状态应是当前末尾与目标前缀匹配的最长长度。目标不全相同时，失败后未必回零，应保留仍匹配的后缀。

def lottery(n):
    # 以0.5元为单位，避免浮点比较
    cost=[0]*(n+1); choice=[0]*(n+1)
    for size in range(1,n+1):
        options=[]
        for m in range(1,size+1):
            branches=[4]
            if m>1: branches.append(2+cost[m-1])
            if m<size: branches.append(3+cost[size-m])
            options.append((max(branches),m))
        cost[size],choice[size]=min(options)
    return cost[n]/2,choice[n]

def max_profit_trade(prices):
    if len(prices) < 2:
        return 0, None
    low, buy = prices[0], 0
    best, dates = 0, None
    for sell in range(1, len(prices)):
        profit = prices[sell] - low
        if profit > best:
            best, dates = profit, (buy, sell)
        if prices[sell] < low:
            low, buy = prices[sell], sell

def knight_probability(n,k,r,c):
    moves=[(1,2),(1,-2),(-1,2),(-1,-2),(2,1),(2,-1),(-2,1),(-2,-1)]
    p=[[0.0]*n for _ in range(n)];p[r][c]=1.0
    for _ in range(k):
        q=[[0.0]*n for _ in range(n)]
        for i in range(n):
            for j in range(n):
                for di,dj in moves:
                    a,b=i+di,j+dj
                    if 0<=a<n and 0<=b<n:q[a][b]+=p[i][j]/8
        p=q
    return sum(map(sum,p))
assert knight_probability(3,2,0,0)==0.0625
assert knight_probability(1,0,0,0)==1

K=0时尚未移动，合法起点存活概率一；N=1、K>0时第一步必越界，结果零。实现每轮新建q而不原地更新p，避免同一轮传播多步。每轮质量应在[0,1]内且不增加，可作为检查。
