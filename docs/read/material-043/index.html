设 (X,Y)(X,Y)(X,Y) 服从二元联合正态分布，E(X)=E(Y)=0E(X)=E(Y)=0E(X)=E(Y)=0，Var⁡(X)=Var⁡(Y)=1\operatorname{Var}(X)=\operatorname{Var}(Y)=1Var(X)=Var(Y)=1，相关系数为 ρ=1/3\rho=1/\sqrt3ρ=1/3​。求 P(X<0∣Y<0)P(X<0\mid Y<0)P(X<0∣Y<0) 和 E[min⁡(X,Y)]E[\min(X,Y)]E[min(X,Y)]。

2. 岭回归梯度

题目

已知 A∈Rm×dA\in\mathbb R^{m\times d}A∈Rm×d、b∈Rmb\in\mathbb R^mb∈Rm，待求参数为列向量 x∈Rdx\in\mathbb R^dx∈Rd。对 L(x)=∥Ax−b∥22+∥x∥22L(x)=\|Ax-b\|_2^2+\|x\|_2^2L(x)=∥Ax−b∥22​+∥x∥22​ 求梯度和 Hessian，并求最优解满足的方程。

考点：矩阵梯度；维度；严格凸性。

查看分析与解答

必要知识

x 是 d 维列向量，残差 Ax−b 是 m 维，梯度必须回到 d 维，因此残差前需乘 Aᵀ。Hessian 描述各方向曲率，正定意味着唯一全局极小值。

分析思路

展开二次项求导，再通过任意方向 v 的二次型证明 Hessian 正定。最后给一个标量例子检查系数与转置。

解答步骤

一般 xᵀMx 对 x 求导为 (M+Mᵀ)x；这里 M=AᵀA 对称，所以变成2AᵀAx。−2bᵀAx 的梯度为−2Aᵀb，xᵀx 的梯度2x，常数bᵀb不贡献。

先展开平方项： L=xTATAx−2bTAx+bTb+xTx.L=x^TA^TAx-2b^TAx+b^Tb+x^Tx.L=xTATAx−2bTAx+bTb+xTx. 对任意非零向量 vvv，vT(ATA+I)v=∥Av∥2+∥v∥2>0v^T(A^TA+I)v=\|Av\|^2+\|v\|^2>0vT(ATA+I)v=∥Av∥2+∥v∥2>0，故目标严格凸，驻点就是唯一最小值点。令梯度为零，得到 (ATA+Id)x∗=ATb. (A^TA+I_d)x_*=A^Tb.(ATA+Id​)x∗​=ATb. 例如 A=[2]A=[2]A=[2]、b=[3]b=[3]b=[3] 时，5x∗=65x_*=65x∗​=6，所以 x∗=1.2x_*=1.2x∗​=1.2。实际计算可解此线性方程，或将 AAA 与 IdI_dId​ 纵向拼接、将 bbb 与零向量拼接后解最小二乘。

3. 异形骰子的和

题目

两颗骰子均有六个等概率的面，各面标正整数，允许不同面标相同整数，且两颗骰子独立。能否重新标号，使点数和与两颗标准六面骰的分布相同，而至少一颗不是 1,…,61,\ldots,61,…,6？给出构造并验证。

考点：生成函数；卷积；系数计数。

查看分析与解答

必要知识

骰子多项式的 zᵏ 系数是标 k 的物理面数。两骰独立时，多项式相乘的 zˢ 系数统计和为 s 的有序面组合，因此相同乘积就意味着相同和分布。

分析思路

分解标准骰子多项式，把可重新分配的因子在两骰之间转移，再检查新多项式系数非负整数且系数和六。最后用几个点数和直接核验。

解答步骤

A(z)=z+2z²+2z³+z⁴ 表示一点一面、二点两面、三点两面、四点一面。B 的六项系数各一，表示 1、3、4、5、6、8。重复标签仍是不同等可能物理面，组合计数不能去重。

标准骰子的未归一化生成多项式为 D(z)=z+z2+⋯+z6=z(1+z)(1+z+z2)(1−z+z2).D(z)=z+z^2+\cdots+z^6=z(1+z)(1+z+z^2)(1-z+z^2).D(z)=z+z2+⋯+z6=z(1+z)(1+z+z2)(1−z+z2). 两骰之和的计数多项式为 D(z)2D(z)^2D(z)2。将最后一个因子的两份重新分配，取 A(z)=z(1+z)(1+z+z2)=z+2z2+2z3+z4,A(z)=z(1+z)(1+z+z^2)=z+2z^2+2z^3+z^4,A(z)=z(1+z)(1+z+z2)=z+2z2+2z3+z4, B(z)=z(1+z)(1+z+z2)(1−z+z2)2=z+z3+z4+z5+z6+z8.B(z)=z(1+z)(1+z+z^2)(1-z+z^2)^2=z+z^3+z^4+z^5+z^6+z^8.B(z)=z(1+z)(1+z+z2)(1−z+z2)2=z+z3+z4+z5+z6+z8. 对应骰面分别为 1、2、2、3、3、4 和 1、3、4、5、6、8。两个多项式的系数均为非负整数，系数之和均为六，能对应六个等概率面。

因为 A(z)B(z)=D(z)2A(z)B(z)=D(z)^2A(z)B(z)=D(z)2，任一点数和对应的有序面组合数均一致。比如和为 2 只有一组，和为 7 有六组；所有组合共有 36 组，除以 36 就是概率。

和为七时：A一点配B六点有一组，A二点配B五点有两组，A三点配B四点有两组，A四点配B三点有一组，共六。多项式乘积恒等则同时验证所有和二至十二的计数1、2、3、4、5、6、5、4、3、2、1，不只是几个样例。

同类问题

独立离散和可用生成函数将概率卷积转为乘法。重新分解乘积能构造不同边缘而相同总和，但必须检查系数是否仍可对应合法概率或面数。

4. 幂等矩阵

题目

查看分析与解答

必要知识

5. 两地上市股票收益

题目

同一家公司的 A 股和 H 股在不同市场交易。请设计一项研究，检验一侧已经发生的价格变动能否预测另一侧随后发生的收益。说明时间、币种、复权、样本划分和预测评价的处理方法。

考点：异步报价；同币收益；滚动增量。

查看分析与解答

必要知识

同一公司两地股票包含共同经营信息，但市场流动性、交易时间及投资者结构不同。观察到一侧先动，可能是真正信息传递，也可能是另一侧报价未更新，需要用可见时间区分。

分析思路

先对齐报价实际时间与计价币种，再在明确不重叠的预测窗口检验滞后信息。基准控制本地自身与市场变化，样本外比较新增一侧信息的贡献。

解答步骤

若 H 股某分钟已有新成交，而 A 股记录仍是几分钟前的旧价，把两条记录当同时新报价会制造机械领先。可设置最大报价陈旧阈值，或在共同交易段内用可执行买卖价构造等长窗口，单边休市另处理。

  1. **确定观测单位。**上海与香港使用相同民用时区。研究对象是交易时段、假期安排和成交更新时间的差异。先统一时间戳精度，选择双方都能观测到的固定间隔；单边休市时另设状态，不把陈旧报价当作新成交。

  2. **建立可比较收益。**选择统一计价币种，按当时汇率换算；股票拆分、分红等按同一复权规则处理。对共同交易段计算对齐收益，对单边交易段计算“另一市场收盘后至本市场开盘前”等明确窗口的收益。

  3. **写出预测模型。**例如用时点 ttt 前已经产生的 H 股收益预测下一段 A 股收益：

  1. **评价新增预测信息。**按日期滚动训练，以不含 H 股信息的模型作基准，比较留出期的误差和方向判断。计算收益时，信号只能在相关报价公布后形成，成交使用随后可得到的买卖价。这样可区分统计领先、异步报价效应与可执行的预测收益。

将港币股价换成人民币时，人民币价值等于港币价乘人民币每港币汇率；对数收益是股票港币收益加汇率对数变化，方向必须按报价定义。若只研究各自本币预测也可保留本币收益，但需单独控制汇率，不能混用两种口径。

同类问题

跨市场领先研究先排除异步与计价造成的伪关系，再检验时间外增量。统计领先只有在信号可见后仍能按实际价格成交，才可能转化为可执行收益。

6. 递增子序列枚举

题目

输入整数序列 values、非负整数长度上限 limit 和阈值 threshold。枚举所有非空子序列：所选下标严格递增、所选数值严格递增、长度不超过上限，且元素和严格小于阈值。相同数值序列只输出一次，输入允许负数和重复值。

考点：回溯树；同层去重；负数剪枝。

查看分析与解答

必要知识

子序列保留原下标顺序，严格递增还额外限制数值；两者不是同一条件。元素允许负数时，增加新元素可能使总和下降，因此当前和不合格并不代表所有扩展不合格。

分析思路

以起始下标、当前路径和总和为状态逐个扩展；每层去掉相同值的后续重复选择。先输出符合的当前路径，再继续探索允许长度内更长路径。

解答步骤

对同一前缀，若值二在下标一与二都出现，先选下标一后拥有的后续位置包含先选下标二的后续位置，故后者不会产生新的数值序列。同层 used 可排除它，但不同前缀的二不能全局删除。

递归状态包含下一次可选择的起始下标、已经选出的数值序列 path 以及当前和 total。从起始下标向右枚举候选；若其数值不大于末值，就不能加入严格递增序列。每次加入后从下一下标继续搜索，因此不会改变原有顺序。

每个递归层单独建立 used 集合。对同一个前缀，相同值只选最早出现的那个位置：较早位置允许使用的后续元素包含较晚位置的选择，故不会漏掉数值序列。集合不能在所有层共享，否则会错删位于不同位置的合法选择。

只要当前非空序列的和小于阈值，就先输出；长度达到上限才停止扩展。不能一见 total >= threshold 就剪枝，例如前缀 [-5]、阈值 −6-6−6 尚不符合要求，但加入 −4-4−4 后的和 −9-9−9 符合要求。

最坏情况下所有元素严格递增且都满足约束，合法结果数量可达指数级；复杂度至少与输出总长度成正比。当前路径与调用栈深度为 O(min⁡(n,limit))O(\min(n,\mathrm{limit}))O(min(n,limit))，去重集合额外占用空间；返回列表按结果总长度另计。下面的断言同时检查重复值和严格小于边界。

Python23 行
def increasing_subsequences(values, limit, threshold):
    answer = []
    def visit(start, path, total):
        if path and total < threshold:
            answer.append(tuple(path))
        if len(path) == limit:
            return
        used = set()
        for i in range(start, len(values)):
            x = values[i]
            if x in used or (path and x <= path[-1]):
                continue
            used.add(x)
            path.append(x)
            visit(i+1, path, total+x)
            path.pop()
    if limit < 0:
        raise ValueError('长度上限非负')
    visit(0, [], 0)
    return answer

assert set(increasing_subsequences([1,2,2,3],2,5)) == {(1,),(2,),(3,),(1,2),(1,3)}
assert increasing_subsequences([-5, -4], 2, -6) == [(-5, -4)]

实现用 append、递归、pop 复用当前路径，输出时转 tuple 保存快照，避免每层 path+[x] 复制整个前缀。路径与栈深度 O(min(n,limit))；当前活跃各层 used 对应所选下标之间已扫描的不相交区段，总空间可界为 O(n)，结果存储另计。负数反例可核对：[-5] 不满足和小于−6，但扩展[-5,−4]满足，不能提前剪掉。

同类问题

枚举题先保证输出完整与去重正确，再做有证明的剪枝。最坏结果本身指数多，不能承诺多项式总时间；应分别说明搜索开销、辅助空间和输出大小。

7. 斜杠字典

题目

实现 SlashDict：键 a/b/c 表示三级字典路径。支持 obj[key] 读写、删除、get、pop，以及枚举所有叶子路径的 deep_keys()。写入时自动创建缺失的中间字典。空路径段非法，中间节点若为普通值则报错。普通字典值转为嵌套 SlashDict，空子字典不产生叶子路径。

考点：嵌套映射；路径解析；协议复用。

查看分析与解答

必要知识

SlashDict 的底层是树：中间键指向子映射，叶键指向普通值。斜杠字符串是一条访问路径，不是底层单个键。读、写、删除必须共享同一解析规则，才能让 get、pop 等接口保持一致。

分析思路

先把路径校验与找父节点抽成内部方法，再实现 MutableMapping 所需最小接口。写操作可建中间映射，读删不创建；深层枚举只输出普通值叶子。

解答步骤

写 e/f/g=5 时先建立 e、再建立其 f，最后在父 f 中写 g。读不存在的 x/y 时 _parent(create=False) 抛 KeyError，get 才能按映射协议返回默认值，且不会留下空 x。若 e 已是整数，再写 e/f 必须报类型错误，保护原数据语义。

  1. 分开处理路径与映射接口。_parts 校验字符串并按斜杠分割；_parent 找到最后一个键的父节点。读与删除只遍历已有节点，写入则允许创建缺失节点。这样读操作不会意外改变字典。

  2. **实现最小映射协议。**继承 MutableMapping 后实现 __getitem__、__setitem__、__delitem__、__iter__ 和 __len__，标准 get、pop 即可复用同一套查找逻辑。obj['a']=3 后再写 obj['a/b']=4 应报类型错误，不能静默覆盖已有的 3。

  3. **递归枚举叶子。**遇到子字典时给其深层键补上当前前缀；遇到普通对象则产出当前路径。例如 {'a':{'b':1},'c':2} 输出 a/b、c。插入顺序由内部字典保留。

含 ddd 层的单次路径操作通常需 O(d)O(d)O(d) 次哈希查找，另有解析键字符串的开销。枚举深层键需访问全部树节点，并为输出路径分配空间。下方用删除、默认值和深层写入检查这些约定。

Python50 行
from collections.abc import MutableMapping, Mapping

class SlashDict(MutableMapping):
    def __init__(self, data=None):
        self._data = {}
        for k, v in (data or {}).items():
            self[k] = v
    @staticmethod
    def _parts(key):
        if not isinstance(key, str) or any(not p for p in key.split('/')):
            raise KeyError(key)
        return key.split('/')
    def _parent(self, key, create=False):
        parts = self._parts(key)
        node = self
        for p in parts[:-1]:
            if p not in node._data:
                if not create:
                    raise KeyError(key)
                node._data[p] = SlashDict()
            node = node._data[p]
            if not isinstance(node, SlashDict):
                raise TypeError('路径中间节点不是字典')
        return node, parts[-1]
    def __getitem__(self, key):
        node, leaf = self._parent(key)
        return node._data[leaf]
    def __setitem__(self, key, value):
        node, leaf = self._parent(key, True)
        node._data[leaf] = SlashDict(value) if isinstance(value, Mapping) and not isinstance(value, SlashDict) else value
    def __delitem__(self, key):
        node, leaf = self._parent(key)
        del node._data[leaf]
    def __iter__(self):
        return iter(self._data)
    def __len__(self):
        return len(self._data)
    def deep_keys(self):
        for k, v in self._data.items():
            if isinstance(v, SlashDict):
                for child in v.deep_keys():
                    yield k+'/'+child
            else:
                yield k

sd = SlashDict({'a': {'b': {'x': 1, 'y': 2}}})
assert sd.pop('a/b/y') == 2
sd['e/f/g'] = 5
assert sd.get('missing', 9) == 9
assert list(sd.deep_keys()) == ['a/b/x', 'e/f/g']

删除 a/b/y 只删叶 y，不自动清空祖先，因此空子字典仍可存在，但 deep_keys 遍历它不会产出路径。继承的 pop 先读取再删除，若路径缺失可按默认参数处理；中间类型错误应继续暴露，不能伪装成普通缺失。枚举顶层 iter 与深层 deep_keys 是两个不同接口。

同类问题

实现复合键容器时，先约定非法路径、类型冲突、空节点与删除后清理行为。通过标准映射协议复用通用方法，可以减少读写删语义分叉。
