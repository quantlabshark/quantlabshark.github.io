布朗桥与 Bessel 过程

认识固定终点的高斯路径和多维布朗运动的距离，推导协方差与径向分布。

把终点固定下来

标准布朗运动在 TTT 时刻的终点随机。如果关心一条从 0 出发、在 TTT 时刻又回到 0 的随机路径，可以构造布朗桥

Bt=Wt−tTWT,0≤t≤T.B_t=W_t-\frac tT W_T,\qquad0\le t\le T.Bt​=Wt​−Tt​WT​,0≤t≤T.

显然 B0=BT=0B_0=B_T=0B0​=BT​=0。减去的直线把原路径终点恰好拉回零。由于布朗桥是高斯变量的线性组合，它仍为高斯过程。其均值为零，协方差为

Cov⁡(Bs,Bt)=min⁡(s,t)−stT.\operatorname{Cov}(B_s,B_t)=\min(s,t)-\frac{st}{T}.Cov(Bs​,Bt​)=min(s,t)−Tst​.

推导时展开两个括号，并使用 E[WsWT]=s\mathbb E[W_sW_T]=sE[Ws​WT​]=s。特别地，Var⁡(Bt)=t(1−t/T)\operatorname{Var}(B_t)=t(1-t/T)Var(Bt​)=t(1−t/T)，在两端为零，在中点最大。若 T=2T=2T=2，中点方差为 1/21/21/2。

这个过程具有“布朗运动给定终点为零”的条件分布。虽然 P(WT=0)=0\mathbb P(W_T=0)=0P(WT​=0)=0，高斯条件分布仍然可以定义。更一般地，从 aaa 到 bbb 的桥为 a+(b−a)t/T+Bta+(b-a)t/T+B_ta+(b−a)t/T+Bt​。

鲨鱼说

协方差，即两个变量偏离各自均值时，共同变化程度的度量。

条件于终点的分布怎样定义

对任意 t≤Tt\le Tt≤T，Cov⁡(Wt−(t/T)WT,WT)=t−(t/T)T=0\operatorname{Cov}(W_t-(t/T)W_T,W_T)=t-(t/T)T=0Cov(Wt​−(t/T)WT​,WT​)=t−(t/T)T=0。桥残差与终点属于联合高斯向量，因此独立。于是可以分解

Wt=tTWT+Bt,W_t=\frac tTW_T+B_t,Wt​=Tt​WT​+Bt​,

其中 BtB_tBt​ 的整组有限维值与 WTW_TWT​ 独立。给定终点 WT=bW_T=bWT​=b 后，未来的条件路径分布就是 (t/T)b+Bt(t/T)b+B_t(t/T)b+Bt​。这通过正态条件密度定义，不需要把普通条件概率除以零概率事件 {WT=b}\{W_T=b\}{WT​=b}。

例如 T=2T=2T=2、起点 0、终点 1，时刻 t=1t=1t=1 的条件均值为 1/21/21/2，条件方差为 1/21/21/2。固定终点后，均值走沿起终点连线，随机偏离在两端收缩为零。

固定终点改变了预测

对 0≤s<t<T0\le s<t<T0≤s<t<T，布朗桥的条件均值为

E[Bt∣Bs]=T−tT−sBs.\mathbb E[B_t\mid B_s]=\frac{T-t}{T-s}B_s.E[Bt​∣Bs​]=T−sT−t​Bs​.

路径若在 sss 时刻偏离零，后续平均会向终点回拉。这个系数来自高斯条件均值公式：Cov⁡(Bt,Bs)/Var⁡(Bs)\operatorname{Cov}(B_t,B_s)/\operatorname{Var}(B_s)Cov(Bt​,Bs​)/Var(Bs​)。条件方差为 (t−s)(T−t)/(T−s)(t-s)(T-t)/(T-s)(t−s)(T−t)/(T−s)。

构造式使用了未来的 WTW_TWT​，因此 BtB_tBt​ 通常不适应原布朗运动到 ttt 为止的信息流。它可以在自己的信息流中研究，也可以通过另一条随机微分方程逐步模拟，但不能把上述构造当成实时可用的交易信号。

桥的条件方差也可以逐项算出。联合高斯回归给出

Var⁡(Bt∣Bs)=Var⁡(Bt)−Cov⁡(Bs,Bt)2Var⁡(Bs)=(t−s)(T−t)T−s.\operatorname{Var}(B_t\mid B_s) =\operatorname{Var}(B_t)-\frac{\operatorname{Cov}(B_s,B_t)^2}{\operatorname{Var}(B_s)} =\frac{(t-s)(T-t)}{T-s}.Var(Bt​∣Bs​)=Var(Bt​)−Var(Bs​)Cov(Bs​,Bt​)2​=T−s(t−s)(T−t)​.

取 T=2,s=1,t=1.5T=2,s=1,t=1.5T=2,s=1,t=1.5，若观察到 B1=0.8B_1=0.8B1​=0.8，则 B1.5B_{1.5}B1.5​ 的条件均值为 0.40.40.4，方差为 0.250.250.25。越靠近固定终点，剩余可自由波动的时间越少。这个条件分布也给出无需提前读取 WTW_TWT​ 的逐步桥模拟方法。

多维布朗运动的距离

取 nnn 个独立标准布朗运动，组成向量 Wt\mathbf W_tWt​。它到原点的距离

Rt=(Wt(1))2+⋯+(Wt(n))2R_t=\sqrt{(W_t^{(1)})^2+\cdots+(W_t^{(n)})^2}Rt​=(Wt(1)​)2+⋯+(Wt(n)​)2​

称为 nnn 维 Bessel 过程。每个时刻的 Rt2/tR_t^2/tRt2​/t 是 nnn 个独立标准正态的平方和，服从 χn2\chi_n^2χn2​。由变量变换得到径向密度

pR(r)=2rn−1(2t)n/2Γ(n/2)e−r2/(2t),r>0.p_R(r)=\frac{2r^{n-1}}{(2t)^{n/2}\Gamma(n/2)}e^{-r^2/(2t)},\qquad r>0.pR​(r)=(2t)n/2Γ(n/2)2rn−1​e−r2/(2t),r>0.

其中 rn−1r^{n-1}rn−1 来自球壳体积。离原点稍远的球壳拥有更多方向，这会与高斯密度向外衰减的趋势共同决定距离分布。

从平方距离到距离的变量变换

令 Q=Rt2/t∼χn2Q=R_t^2/t\sim\chi_n^2Q=Rt2​/t∼χn2​，其密度为 qn/2−1e−q/2/[2n/2Γ(n/2)]q^{n/2-1}e^{-q/2}/[2^{n/2}\Gamma(n/2)]qn/2−1e−q/2/[2n/2Γ(n/2)]。取 q=r2/tq=r^2/tq=r2/t，导数为 dq/dr=2r/tdq/dr=2r/tdq/dr=2r/t，所以

pR(r)=pQ(r2/t)2rt=2rn−1(2t)n/2Γ(n/2)e−r2/(2t).p_R(r)=p_Q(r^2/t)\frac{2r}{t} =\frac{2r^{n-1}}{(2t)^{n/2}\Gamma(n/2)}e^{-r^2/(2t)}.pR​(r)=pQ​(r2/t)t2r​=(2t)n/2Γ(n/2)2rn−1​e−r2/(2t).

这个推导不需要先掌握高维球面积公式；它把维度信息集中到卡方自由度 nnn。密度中的 rn−1r^{n-1}rn−1 同时与几何球壳体积相符。

一般矩也可利用 Rtq=tq/2Qq/2R_t^q=t^{q/2}Q^{q/2}Rtq​=tq/2Qq/2 和 Gamma 矩公式计算，得到前面的 Gamma 函数比。取 q=2q=2q=2 时，递推关系 Γ(n/2+1)=(n/2)Γ(n/2)\Gamma(n/2+1)=(n/2)\Gamma(n/2)Γ(n/2+1)=(n/2)Γ(n/2) 将它简化为 ntntnt。

不同维度对应的熟悉分布

当 n=1n=1n=1，Rt=∣Wt∣R_t=|W_t|Rt​=∣Wt​∣，是半正态分布；当 n=2n=2n=2，密度为 rt−1e−r2/(2t)r t^{-1}e^{-r^2/(2t)}rt−1e−r2/(2t)，是 Rayleigh 分布；当 n=3n=3n=3，密度为 2/π r2t−3/2e−r2/(2t)\sqrt{2/\pi}\,r^2t^{-3/2}e^{-r^2/(2t)}2/π​r2t−3/2e−r2/(2t)。

利用 Gamma 积分，可以统一计算矩：

E[Rtq]=(2t)q/2Γ((n+q)/2)Γ(n/2),q>−n.\mathbb E[R_t^q]=(2t)^{q/2}\frac{\Gamma((n+q)/2)}{\Gamma(n/2)},\qquad q>-n.E[Rtq​]=(2t)q/2Γ(n/2)Γ((n+q)/2)​,q>−n.

特别地，E[Rt2]=nt\mathbb E[R_t^2]=ntE[Rt2​]=nt，E[Rt]=2t Γ((n+1)/2)/Γ(n/2)\mathbb E[R_t]=\sqrt{2t}\,\Gamma((n+1)/2)/\Gamma(n/2)E[Rt​]=2t​Γ((n+1)/2)/Γ(n/2)。二维情形的均值为 πt/2\sqrt{\pi t/2}πt/2​，方差为 (2−π/2)t(2-\pi/2)t(2−π/2)t。

鲨鱼说 向量平均位置为零，不意味着到原点的平均距离为零。方向可以互相抵消，距离始终非负。∣E[Wt]∣|\mathbb E[\mathbf W_t]|∣E[Wt​]∣ 与 E[∣Wt∣]\mathbb E[|\mathbf W_t|]E[∣Wt​∣] 不能互换。

在二维情形，E[Wt(1)]=E[Wt(2)]=0\mathbb E[W_t^{(1)}]=\mathbb E[W_t^{(2)}]=0E[Wt(1)​]=E[Wt(2)​]=0，但距离均值为正。三维时 E[Rt]=22t/π\mathbb E[R_t]=2\sqrt{2t/\pi}E[Rt​]=22t/π​，二阶矩为 3t3t3t，方差为 (3−8/π)t(3-8/\pi)t(3−8/π)t。维度越高，距离增大的原因来自多个独立坐标的平方相加，不是每个坐标出现向外的固定漂移。

对半径过程写随机微分方程时会出现与维度相关的径向项，并在原点附近需要特殊处理。因此直接对平方根函数套普通链式法则，既会漏掉伊藤修正，也会遇到零点导数问题。利用卡方变量变换，可以先准确获得固定时刻分布，再研究路径方程。

练习：二维位置落在圆内的概率

二维标准布朗运动从原点出发。求时刻 t=2t=2t=2 时距离不超过 3 的概率，并比较均方根距离与平均距离。

查看解答

二维径向分布函数为 P(Rt≤r)=1−e−r2/(2t)\mathbb P(R_t\le r)=1-e^{-r^2/(2t)}P(Rt​≤r)=1−e−r2/(2t)，所以所求概率为 1−e−9/4≈0.89461-e^{-9/4}\approx0.89461−e−9/4≈0.8946。均方根距离为 E[R22]=2\sqrt{\mathbb E[R_2^2]}=2E[R22​]​=2，平均距离为 π≈1.7725\sqrt\pi\approx1.7725π​≈1.7725。两者不同，且后者不超过前者，与 Cauchy–Schwarz 不等式一致。
