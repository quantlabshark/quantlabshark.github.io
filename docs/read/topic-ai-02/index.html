02 · 线性模型、正则化与预测基线

推导最小二乘与岭回归，解释标准化、收缩和样本外误差，并复现历史基线。

特征如何变成一个预测值

将特征按权重相加，是一种便于检查的预测方式：

y^i=β0+∑j=1pxijβj.\widehat y_i=\beta_0+\sum_{j=1}^p x_{ij}\beta_j.y​i​=β0​+j=1∑p​xij​βj​.

β0\beta_0β0​ 是截距。βj\beta_jβj​ 表示在其他输入保持不变时，第 jjj 个输入增加一单位对应的预测变化。例如标准化后的成交额特征系数为 0.001，则该特征增加一个训练期标准差，模型预测收益增加 0.1 个百分点。

这个系数描述拟合关系，不直接证明成交额变化导致收益变化。

模型需要一个可优化的误差标准。令残差 ei=yi−y^ie_i=y_i-\widehat y_iei​=yi​−y​i​，最小二乘选择使残差平方和最小的参数。平方避免正负误差相互抵消，也使较大误差得到更高权重。

高度相似的特征为何使系数不稳定

过去 19 日收益与过去 20 日收益往往高度相关。若两个特征恰好相同，预测只取决于 β1+β2\beta_1+\beta_2β1​+β2​，无法唯一识别两者各自的系数。若只是近似相同，小量噪声就可能让一正一负的两个大系数发生明显变化，训练误差却几乎不变。

岭回归在误差后增加平方惩罚：

Lλ(β)=∥y−Xβ∥22+λ∥β∥22,λ≥0.L_\lambda(\beta)=\|y-X\beta\|_2^2+\lambda\|\beta\|_2^2,\qquad\lambda\ge0.Lλ​(β)=∥y−Xβ∥22​+λ∥β∥22​,λ≥0.

求导得到

β^λ=(X⊤X+λI)−1X⊤y.\widehat\beta_\lambda=(X^\top X+\lambda I)^{-1}X^\top y.β​λ​=(X⊤X+λI)−1X⊤y.

当 λ>0\lambda>0λ>0，即使特征存在完全线性相关，矩阵也可逆。若 X⊤XX^\top XX⊤X 在某个方向的特征值为 ddd，该方向相对于最小二乘的收缩比例为 d/(d+λ)d/(d+\lambda)d/(d+λ)。数据支持较弱、ddd 很小的方向会受到更强收缩。

上述三点例子取 λ=2\lambda=2λ=2，斜率变成 1.8/(2+2)=0.451.8/(2+2)=0.451.8/(2+2)=0.45。训练平方误差增大，但参数对扰动不那么敏感。正则化是否有利，应由后续时间段的误差判断。

鲨鱼说 正则化主动放弃一部分训练拟合程度，以减少参数随样本噪声大幅变化。它不会自动知道哪些关系在未来有效，惩罚强度仍需要用较晚的验证期选择。

标准化与惩罚必须配套

某特征用“元”表示，换成“万元”后数值缩小一万倍，相同预测所需系数会放大一万倍。若直接惩罚系数，单位变化就会改变模型偏好。常见处理为

zij=xij−μjsj,z_{ij}=\frac{x_{ij}-\mu_j}{s_j},zij​=sj​xij​−μj​​,

其中 μj,sj\mu_j,s_jμj​,sj​ 仅在训练集估计，并固定用于验证和预测。截距通常不施加惩罚。一个常数特征无法按正常标准差缩放，可删除或由实现按约定处理。

标准化不是去除经济单位的全部信息；原始单位、变换方法和拟合期均应保存。测试期不能重新利用测试标签选尺度，也不能把全样本均值、标准差提前放进历史模型。
