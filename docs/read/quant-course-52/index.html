52 · 傅里叶估计、跳跃与幂变差

从正弦余弦权重理解频域方差估计，用幂变差区分连续波动和跳跃。

高频收益同时包含连续波动和偶发跳跃。傅里叶方法利用频率加权描述变化，幂变差则通过不同幂次的累积分析连续部分与跳跃部分。

平方和相同，价格路径也可能不同

连续小幅波动与偶发大跳跃都能增加收益平方和，但它们对持仓风险、对冲误差和成交价格的影响不同。本课一部分用频域系数估计波动，另一部分用不同幂次区分连续变化与跳跃。频域只是加权计算工具，不预设价格存在可重复的赚钱周期。

先把窗口写为 [0,T][0,T][0,T]，使用对数价格增量 ΔXi\Delta X_iΔXi​。积分方差累加整个窗口的连续随机变化；瞬时方差 σt2\sigma_t^2σt2​ 描述单位时间的局部变化速度。总量与局部曲线的单位不同。

一个频率对应一组正弦余弦权重

定义 ω=2π/T\omega=2\pi/Tω=2π/T，以及未除以窗口长度的复系数

Ck=∑ie−ikωti−1ΔXi.C_k=\sum_i e^{-\mathrm{i}k\omega t_{i-1}}\Delta X_i.Ck​=i∑​e−ikωti−1​ΔXi​.

这里 i2=−1\mathrm{i}^2=-1i2=−1，由 e−iu=cos⁡u−isin⁡ue^{-\mathrm{i}u}=\cos u-\mathrm{i}\sin ue−iu=cosu−isinu 可知，实部和虚部只是两组带符号的加权收益。k=0k=0k=0 时权重全1，C0C_0C0​ 就是总对数收益；kkk 越大，权重随时间切换越快。使用真实事件时间即可计算，不要求每个间隔相等。

在一个自拟两增量例中，T=1T=1T=1，起点0与0.5，收益0.01与−0.02。零频为−0.01；频率1的权重为1和−1，故 C1=0.03C_1=0.03C1​=0.03。不同频率是在用不同方式组合同一批数据。

频域中的积分方差

截断在频率 −N,…,N-N,\ldots,N−N,…,N，一个积分方差估计为

IV^N=12N+1∑k=−NN∣Ck∣2.\widehat{IV}_N=\frac1{2N+1}\sum_{k=-N}^{N}|C_k|^2.IVN​=2N+11​k=−N∑N​∣Ck​∣2.

对实值收益，C−kC_{-k}C−k​ 与 CkC_kCk​ 共轭，模平方相等。展开模平方，会得到收益自身平方与不同时点收益乘积。后者由Dirichlet核加权，因此它与上一课的核方法有关。NNN 小时更平滑，NNN 大时纳入更快变化，也可能带入更多高频噪声。

两增量例取 N=1N=1N=1，得到 (0.032+0.012+0.032)/3≈0.0006333(0.03^2+0.01^2+0.03^2)/3\approx0.0006333(0.032+0.012+0.032)/3≈0.0006333，而RV为0.0005。频域估计在有限小样本中不必等于RV。等间距数据还存在频率混叠，不能靠不断增大 NNN 创造未观测到的信息。

恢复随时间变化的方差

在上述归一化下，方差率的傅里叶系数可用卷积估计：

c^k=1T(2N+1)∑s=−NNCsCk−s.\hat c_k=\frac1{T(2N+1)}\sum_{s=-N}^{N}C_sC_{k-s}.c^k​=T(2N+1)1​s=−N∑N​Cs​Ck−s​.

然后对 ∣k∣≤M|k|\le M∣k∣≤M 加上Fejér权重 1−∣k∣/(M+1)1-|k|/(M+1)1−∣k∣/(M+1) 做反演，得到平滑曲线。NNN 控制估计系数时保留多少价格频率，MMM 控制最后曲线的分辨率。零阶系数乘 TTT 对应积分方差，因此这里比上一式多除一个 TTT。

多资产可将乘积换成两资产系数的交叉乘积，各自使用自己的时间戳，减少显式同步。截断、噪声和窗口两端仍要处理：傅里叶展开把窗口周期延拓，开盘与收盘不自然连接时，边界附近可能产生波纹。

跳跃怎样进入二次变差

对 dXt=μtdt+σtdWt+dJtdX_t=\mu_tdt+\sigma_tdW_t+dJ_tdXt​=μt​dt+σt​dWt​+dJt​，若 JJJ 为有限活动跳跃，则

[X]T=∫0Tσt2dt+∑s≤T(ΔJs)2.[X]_T=\int_0^T\sigma_t^2dt+\sum_{s\le T}(\Delta J_s)^2.[X]T​=∫0T​σt2​dt+s≤T∑​(ΔJs​)2.

例如连续积分方差0.01，两次跳幅0.03和−0.04，总二次变差为0.0125。平方使两次跳跃都增加风险，不会因方向相反抵消。作为尺度比较，一次5%的对数跳幅贡献0.0025，明显高于年波动20%对应的约0.0001587日连续方差。

幂变差 ∑∣ΔX∣p\sum|\Delta X|^p∑∣ΔX∣p 用 ppp 调整大小增量的相对权重。在存在布朗部分、有限活动跳跃时，p=2p=2p=2 保留两者；p>2p>2p>2 的未标准化和中连续部分趋零，留下跳幅的 ppp 次幂；0<p<20<p<20<p<2 需随网格作尺度标准化。比较不同幂次时，应先确认有没有标准化。

鲨鱼说

二次变差，即将各小区间增量的平方相加，再考察网格加密后的极限。

用双幂变差比较连续与跳跃

双幂变差 BV=(π/2)∑i=2n∣ri∣∣ri−1∣BV=(\pi/2)\sum_{i=2}^n|r_i||r_{i-1}|BV=(π/2)∑i=2n​∣ri​∣∣ri−1​∣ 在无噪声和相应条件下估计连续积分方差。孤立大跳跃只影响附近少数乘积，其邻近连续增量随网格缩小，因而影响在极限中消失。

Python16 行
import numpy as np
rng = np.random.default_rng(52)
n, sigma = 8192, 0.20
r = rng.normal(0, sigma/np.sqrt(n), n)
t = np.arange(n)/n
N = 40
freq = np.arange(-N, N+1)
C = np.exp(-2j*np.pi*np.outer(freq,t))@r
fourier_iv = np.mean(np.abs(C)**2)
r_jump = r.copy()
r_jump[n//2] += 0.08
for label, increments in [('连续', r), ('含跳跃', r_jump)]:
    rv = increments@increments
    bv = np.pi/2*np.sum(np.abs(increments[1:])*np.abs(increments[:-1]))
    print(label, 'RV', round(rv,5), 'BV', round(bv,5))
print('频域 IV', round(float(fourier_iv),5), '真实连续 IV', sigma*sigma)

模拟的真实连续IV为0.04。无跳时RV约0.04026、BV约0.04082。加入0.08跳幅后，RV约0.04640、BV约0.04182。频域估计约0.04069。图中RV明显上升，而BV变化较小。有限样本里RV增加不严格等于 0.0820.08^20.082，因为跳跃所在格原本也有连续增量，平方展开存在交叉项。

把RV−BV当成跳跃证据时，还要估计它的抽样误差并设置检验阈值。价格噪声、连续多个大变动和无限活动跳跃会改变结论；截断法按阈值排除大增量时，阈值也须随采样频率调整。

从增量尺度理解幂变差

把固定长度窗口分成 nnn 段，布朗增量通常有 n−1/2n^{-1/2}n−1/2 的尺度。每项绝对值的 ppp 次幂约为 n−p/2n^{-p/2}n−p/2，共 nnn 项，和的尺度约为 n1−p/2n^{1-p/2}n1−p/2。因此 p=2p=2p=2 恰好保持有限量。p=4p=4p=4 时连续部分约按 1/n1/n1/n 缩小。p=1p=1p=1 时未标准化和约按 n\sqrt nn​ 增大。

一次固定大小的跳跃不会随切分而缩小。它落在哪个小格可能变化，但该格仍包含近似相同跳幅，所以在 p>2p>2p>2 的和中留下有限贡献。这一尺度推理解释了为什么改变幂次能够区分连续与跳跃，也说明把一阶绝对收益和当作不依赖采样频率的固定风险量会出错。

频率截断与时间分辨率

若窗口为一小时，频率 k=1k=1k=1 的权重在一小时内完成一次正弦余弦循环，k=60k=60k=60 则每分钟一次。系数本身是加权收益，不等于存在一个一分钟价格周期。它记录的是收益与该组基函数的投影。

恢复瞬时方差时，保留很少的 MMM 只能表达平滑变化。增加 MMM 可以表达较窄的波动峰，但估计误差也更容易表现为快速起伏。可以先用已知“前半低波动、后半高波动”的模拟检验曲线是否定位变化，再考察端点和噪声，而不是用最曲折的曲线作为细致程度的标准。

对一小时窗口和一天窗口使用相同数字 kkk，对应的真实时间频率不同。比较两图之前应先换算 k/Tk/Tk/T，同时核对方差率与积分方差。少了窗口长度 TTT 的归一化，曲线面积就不能回到同一段总方差。

练习

1. 跳幅0.03与−0.04，对四次幂变差极限贡献多少？

查看解答

0.034+0.044=0.000003370.03^4+0.04^4=0.000003370.034+0.044=0.00000337。在本课有限活动设定下，布朗连续部分未标准化的四次幂和趋零。

2. C0C_0C0​ 等于累计收益，为什么不能只用 ∣C0∣2|C_0|^2∣C0​∣2 估计一日方差？

查看解答

一天内先上涨后下跌会使总收益相互抵消，但盘中已经经历明显变化。多个频率保留不同时间排列的信息；只有零频会把这些变化压缩成一个终点差。
