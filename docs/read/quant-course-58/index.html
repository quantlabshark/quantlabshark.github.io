58 · 做市报价、库存与脉冲控制

从现金和库存推导保留价格、报价强度及HJB，理解主动减仓的控制边界。

做市通过双边报价提供成交机会，同时承担未平库存的价格风险。报价决策需要结合库存估值、订单到达与成交后的价格变化。

做市账户同时记录现金与库存

在99.99挂买、100.01挂卖，先买一股再卖一股，现金增加0.02元、库存回到0。如果只成交买单，中间价随后跌至99.90，按市价计算已亏0.09元。价差收入必须和未平库存损益一起看。

令现金 xxx、库存 qqq、中间价 sss，财富为 x+qsx+qsx+qs。卖一股时 x→x+s+δa,q→q−1x\to x+s+\delta_a,q\to q-1x→x+s+δa​,q→q−1；买一股时 x→x−s+δb,q→q+1x\to x-s+\delta_b,q\to q+1x→x−s+δb​,q→q+1。δa,δb\delta_a,\delta_bδa​,δb​ 是相对中间价的报价距离。成交通知必须同时更新现金和库存，之后价格变化再更新库存市值。

报价越远，成交越少

假设成交强度 λ(δ)=Ae−kδ\lambda(\delta)=Ae^{-k\delta}λ(δ)=Ae−kδ，AAA 表示基础活动量，kkk 表示距离每增加一单位时成交机会衰减多快。报价远一些，每笔价差更大，但成交更少。风险与成交强度共同决定宽度。

一类无库存边界近似给出总宽度

d=γσ2τ+2γlog⁡(1+γ/k),d=\gamma\sigma^2\tau+\frac2\gamma\log(1+\gamma/k),d=γσ2τ+γ2​log(1+γ/k),

买价 r−d/2r-d/2r−d/2、卖价 r+d/2r+d/2r+d/2。宽度第一项由持仓价格风险产生，第二项来自利润与成交概率的权衡。它是特定指数效用、指数强度模型的近似报价，不是由观察一个价差直接得到的通用公式。

Python9 行
import math
s, gamma, sigma, tau, k = 100.0, 0.1, 2.0, 1.0, 1.5
spread = gamma*sigma*sigma*tau + 2/gamma*math.log1p(gamma/k)
for inventory in [-1,0,1]:
    reservation = s-inventory*gamma*sigma*sigma*tau
    bid, ask = reservation-spread/2, reservation+spread/2
    print('库存',inventory,'保留价',round(reservation,4),
          '买价',round(bid,4),'卖价',round(ask,4))
assert spread > 0

本例总宽度约1.69077元。库存−1、0、1时中心分别100.4、100、99.6。买价分别99.5546、99.1546、98.7546，卖价分别101.2454、100.8454、100.4454。库存增加1，两边都向下0.4，使卖单更激进、买单更保守。

图中每条横线是一个库存状态下的买卖报价区间，中点为保留价格。区间整体移动与区间变宽是两种不同控制动作。实际报价还应落在可行最小价位、价格区间和库存边界内。

若一次成交的效用价值改善可写作 1−e−γa1-e^{-\gamma a}1−e−γa，其中 a=δ+a=\delta+a=δ+库存价值变化，则优化项与 e−kδ(1−e−γa)e^{-k\delta}(1-e^{-\gamma a})e−kδ(1−e−γa) 成正比。求导令零，得 e−γa=k/(k+γ)e^{-\gamma a}=k/(k+\gamma)e−γa=k/(k+γ)，所以 a=log⁡(1+γ/k)/γa=\log(1+\gamma/k)/\gammaa=log(1+γ/k)/γ。

求最优报价距离 δ\deltaδ 时，还需计入成交前后的库存价值差。队列位置、逆向选择和预测信息改变库存价值或强度，两边报价也随之变化。

鲨鱼说

逆向选择，即交易对手掌握的信息差异，使成交样本偏向对自身不利状态的现象。

立即减仓形成脉冲控制

允许一次市价调整 ζ\zetaζ 股：q→q+ζq\to q+\zetaq→q+ζ，现金变化为 −ζs−∣ζ∣dmarket/2−费用-\zeta s-|\zeta|d_{market}/2-\text{费用}−ζs−∣ζ∣dmarket​/2−费用。ζ>0\zeta>0ζ>0 为买入，ζ<0\zeta<0ζ<0 为卖出。定义 MV\mathcal MVMV 为立即调整后能达到的最佳价值，就在继续等待与 MV\mathcal MVMV 之间比较，形成拟变分不等式。

固定费用使频繁小额调整不划算，因而常出现一个允许等待的库存区间，越界后一次减到较合理位置。例：现金0、库存3，以100元参考价卖2股，半价差0.01、固定费0.1，现金变199.88、库存1，标记财富299.88，比原300少0.12元。

两条成交路径的现金与损益

初始现金0、库存0，先在99.99买1股，现金−99.99、库存1。若随后在100.01卖出，现金0.02、库存0，完成一个价差循环。若随后中间价跌到99.90且没有卖出，财富为 −99.99+99.90=−0.09-99.99+99.90=-0.09−99.99+99.90=−0.09，与已经赚到0.01半价差的说法不一致。

如果被迫以99.89平仓，最终现金−0.10，还未计费用。这里0.01来自初次被动成交的价格优势，−0.10来自之后价格下跌，−0.01来自最终主动卖出半价差。三项合计−0.10。按这种分解逐笔记录，才能把报价收益、逆向选择和清仓成本分开。

到达强度与成交后的信息不能分开假定

假设某买报价每秒成交概率近似10%，成交后平均中间价下降0.03元，而被动买价只比当前中间价低0.01元。按下一观察时点标记，每次成交的平均优势反而为−0.02元。提高这类成交的次数会放大损失。

可以将“报价距当前中间价”之外的队列、最近主动流量与预测状态纳入条件强度，并同时估计成交后价格变化。较远报价不一定只降低成交次数，也可能改变成交样本的组成。独立泊松强度模型提供了可解结构，但实际数据应核对这些条件关系。

离散最小价位还使连续最优报价需要比较邻近格点。连续买价99.995不能直接无条件四舍五入；99.99与100.00的成交强度、库存变化和费用可能不同，应在合法报价集合上比较价值。

2. 为什么仅提高被动成交率可能让做市表现变差？

查看解答

更靠近市场的报价会缩小每笔价差，并可能更容易在价格即将不利变化时成交。应联合看成交后价格变化、库存积累和终端清仓成本，不能把每次成交都视为同样有利。
