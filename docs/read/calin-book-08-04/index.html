回复强度与不确定性的时间尺度

均值偏离按 e−κte^{-\kappa t}e−κt 衰减，初值引起的方差按 e−2κte^{-2\kappa t}e−2κt 衰减。两个指数相差一倍，原因是方差对状态倍数取平方。判断一段观察是否接近稳态时，不能只看均值已经靠近回复水平，还应检查方差是否接近极限。

若只观察一条较短路径，估计回复速度可能很不稳定。路径在一段时间持续偏离均值并不反驳模型，因为邻近观测高度相关。把每个高频采样点当成独立样本，会夸大有效样本数量；指数协方差结构正是描述这类依赖的工具。
