26 · 分组收益、信息系数与换手

用六只股票手算分组收益和Rank IC，明确多空资金口径，比较信号持续性、组合换手与交易成本。

分组收益描述高低因子股票的后续表现，信息系数描述因子排序与收益排序的关系。换手进一步说明维持这组持仓需要多少交易。

高分股票后来是否表现更好

六只股票今天的因子值依次为1、2、3、4、5、6，随后同一持有区间收益为−2%、0%、1%、−1%、2%、3%。按因子从低到高、每两只一组，低组平均−1%，中组0%，高组2.5%。这构成一次截面的预测检验。

分组曲线关心收益是否随分数变化，而不只比较两个端点。如果中间组起伏很大，高低收益差可能由少数股票造成。组数应根据股票池规模事先规定，同时报告各组数量、因子范围和权重方式。

左侧三组均值来自右侧六个观测。第四只股票得分高于第三只，却随后跌1%，说明正的总体排序关系并不要求每一对股票都排序正确。

高低组收益差不是自动实现的账户收益

高组减低组为2.5%−(−1%)=3.52.5\%-(-1\%)=3.52.5%−(−1%)=3.5个百分点。若账户以净值50%做多高组、50%名义金额做空低组，忽略费用和融资，账户收益贡献为1.75%。若多空两端各为净值100%，才得到3.5%，此时总敞口为200%。

净敞口是多头减空头，总敞口是两边绝对名义金额之和。零净敞口不表示没有风险。无法借券或存在较高借券费时，理论高低组差不能直接作为可实现回报；也可以单独研究纯多头高组相对基准的收益。

Pearson IC与Rank IC

IC是当前因子xix_ixi​与随后收益rir_iri​的截面相关：

IC=∑i(xi−xˉ)(ri−rˉ)∑i(xi−xˉ)2∑i(ri−rˉ)2.IC=\frac{\sum_i(x_i-\bar x)(r_i-\bar r)}{\sqrt{\sum_i(x_i-\bar x)^2\sum_i(r_i-\bar r)^2}}.IC=∑i​(xi​−xˉ)2∑i​(ri​−rˉ)2​∑i​(xi​−xˉ)(ri​−rˉ)​.

Pearson IC保留数值间距，容易受到极端值影响。Rank IC先把输入和收益转成名次，重点衡量单调排序。这里因子名次为1至6，收益名次为1、3、4、2、5、6，名次差平方和为6。

无并列时，Spearman相关简式为

ρ=1−6∑idi2n(n2−1)=1−36210=2935≈0.8286.\rho=1-\frac{6\sum_id_i^2}{n(n^2-1)}=1-\frac{36}{210}=\frac{29}{35}\approx0.8286.ρ=1−n(n2−1)6∑i​di2​​=1−21036​=3529​≈0.8286.

有并列时应采用平均名次再计算相关，而不是直接套这个无并列简式。全体股票因子值相同，相关没有定义，应记录缺失。

Python14 行
import pandas as pd
import numpy as np

factor = pd.Series([1., 2., 3., 4., 5., 6.])
future = pd.Series([-0.02, 0.00, 0.01, -0.01, 0.02, 0.03])
rank_ic = factor.rank().corr(future.rank())
groups = pd.Series([1, 1, 2, 2, 3, 3])
means = future.groupby(groups).mean()
old = np.array([0.5, 0.5, 0.0])
new = np.array([0.0, 0.5, 0.5])
print("rank IC:", rank_ic, "group means:", means.to_dict())
print("one-way turnover:", 0.5*np.abs(new-old).sum())
assert np.isclose(rank_ic, 29/35)
assert np.isclose(means.loc[3]-means.loc[1], 0.035)

程序同时输出Rank IC约0.8286、三组收益−1%、0%、2.5%，以及单边换手50%。数值一致表明分组、排名和权重差使用了同一组数据。

一天的高IC如何变成长期证据

每个日期先在共同有特征和未来标签的股票上计算IC，再形成时间序列。均值反映平均方向，波动反映稳定性，正值比例反映符号频率。ICIR通常是IC均值除以IC标准差，不等于持仓组合的信息比率。

例如两个月IC为0.8和−0.8，平均为0。只展示第一个月会掩盖关系反转。按月观察历史IC可定位状态变化，但不能在月末看到结果后声称月初已经知道哪个因子最好。分行业、规模和覆盖率还能检验结果是否集中在少数子样本。

鲨鱼说

IC没有收益率单位。很高的IC可能对应很小的收益差；能否交易还要看价差幅度、换手、融资与成交费用。

成交金额、单侧换手与权重变化

昨日持有A、B各50%，今日改为B、C各50%。组合单边换手为12∑i∣winew−wiold∣=50%\frac12\sum_i|w_i^{new}-w_i^{old}|=50\%21​∑i​∣winew​−wiold​∣=50%；买卖金额合计占净值100%。若每边费用按成交额收取0.1%，这次调仓的费用约占净值0.1%。

分组成员替换率统计有多少股票进入或退出，与权重换手不同；市场换手率则是成交股数相对参考股本，也不是组合的调仓比例。实际组合应比较调仓前已经价格漂移的权重和新目标，而非仅比较两次目标。

因子自相关比较相邻日期同一股票集合的排名或数值。它高说明信号持续，但可能只是一个长期不变却无预测力的特征。预测能力衰减应另看当前信号与未来不同期限收益的关系。

鲨鱼说

自相关，即同一序列与其滞后值之间的相关关系。

持有期与事件收益曲线

若每天计算未来五日收益，相邻标签共享四天，不能当成独立观测，也不能把每天的五日收益直接连乘成账户净值。可以每五日形成一次非重叠组合，或明确每天开一批、每批分配固定资本并持有五日。

因子形成日前后的平均收益曲线还可检查：高分股票此前是否已上涨，随后差异持续多久。形成日前的曲线是股票过去的实际表现，不是策略“没有赚到所以产生的亏损”。未来曲线也必须与可成交时间、持仓批次和费用一致。

练习

把全部因子值乘以−1，Rank IC和高低收益差怎样变化？若以50%做多、50%做空，并为两端合计支付净值0.2%的费用，当前例子的净账户收益是多少？

查看解答

排名方向翻转，Rank IC变为−0.8286，高低组交换，收益差变为−3.5个百分点。保持原来做多高收益组、做空低收益组的交易方向，毛账户收益1.75%，扣0.2%后为1.55%。若连交易方向也随翻转后的因子一起改变，则毛收益会反号。
