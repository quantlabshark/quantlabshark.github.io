Wiener 积分：确定性权重下的高斯变量

计算核函数积分的正态分布、协方差和奇异性，识别仅方差相同的非布朗过程。

确定性权重带来的简化

若 fff 是确定性平方可积函数，If=∫0Tf(t)dWtI_f=\int_0^Tf(t)dW_tIf​=∫0T​f(t)dWt​ 称为 Wiener 积分。分段近似中，每个积分都是独立正态增量的确定性线性组合，所以是正态变量。均方极限保持相应高斯分布，得到

If∼N(0,∫0Tf(t)2dt).I_f\sim N\left(0,\int_0^Tf(t)^2dt\right).If​∼N(0,∫0T​f(t)2dt).

确定性权重使每段布朗增量按固定系数组合，因而保留高斯结构。若权重随已观察路径变化，这种固定线性组合的论证不再适用，一般伊藤积分也就可能具有其他分布。

鲨鱼说 确定性核提供了一张清楚的计算表：平方积分给方差，两个核的乘积积分给协方差。判断过程性质时，把核在两个不同时间点相乘，往往比只看单时刻方差更有效。

在 [0,1][0,1][0,1] 上，可取正交归一函数 f0(t)=1f_0(t)=1f0​(t)=1、f1(t)=12(t−1/2)f_1(t)=\sqrt{12}(t-1/2)f1​(t)=12​(t−1/2)。它们各自平方积分为 1，乘积积分为零，所以对应积分是两个独立标准正态变量。这把函数空间中的正交方向变成随机空间中的独立高斯坐标。

两个核即使在几乎所有时间点都不同时为零，也可以因正负面积抵消而正交。正交并不意味着时间支持不重叠；后者只是保证正交的一种更强条件。
