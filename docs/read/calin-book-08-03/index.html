系数匹配的实际顺序

计算时可依次检查：扩散项是否为某函数的状态导数；漂移是否等于其时间导数加一半状态二阶导数；初值是否满足；函数在所需区域是否光滑。按这个顺序，每一步都对应一个明确的等式。

检查兼容条件的顺序

先检查 ax=bt+bxx/2a_x=b_t+b_{xx}/2ax​=bt​+bxx​/2，可以避免在不可能存在端点表达式时反复猜函数。但即使条件成立，初值和定义域仍需单独检查。积分常数可能依赖初始信息，却不能依赖尚未发生的未来噪声。

在有奇点或不连通的区域，局部构造不一定能直接拼成一个全局函数。实践中可先在路径停止前所在的光滑区域推导，之后再研究是否触及边界。这样能把代数问题与边界问题分开，也能看清解失效究竟来自公式计算还是函数定义域。

鲨鱼说

先匹配扩散项，相当于先找状态原函数；再匹配漂移，相当于决定剩下的时间函数；最后用初值定常数。每一步各解决一个未知部分，能避免同时猜整个解。
