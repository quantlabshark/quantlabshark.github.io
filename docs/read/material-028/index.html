停止时间与几何覆盖

骰子累计余数、多一枚硬币、多两枚硬币、51点覆盖、三次骰子最优停止

1. 骰子累计余数

题目

独立反复投掷公平六面骰，累计点数从 0 开始。至少投掷一次后，第一次累计和为 5 的倍数时停止，求期望次数；把 5 改为 6 又如何？

考点：模状态；双随机矩阵；正返回。

查看分析与解答

必要知识

停止条件只看总和除以 m 的余数，具体总和无需保存。状态零既是起点也是目标，但题目要求至少走一步，因此求首次正返回，而不是从零到零的零步时间。

分析思路

先证明余数链的均匀平稳分布，再用返回时间公式。对模五还要特别说明每步增量并不均匀，防止错误套几何分布。

解答步骤

从任意起点到指定终点 j，所需增量余数唯一；把所有起点的转移概率相加，恰好把每种增量余数概率加一次，总和一。因此均匀分布经过一步仍均匀，且骰子可掷出一使全部状态互相可达。

是否停止只取决于累计和的余数，因此用除以 mmm 后的余数作为状态，可将无限多种累计点数压缩为 mmm 个状态。无论当前余数是什么，下一步都是加一个独立骰子点数再取模，因此转移矩阵每行是同一组概率的循环移位，每列之和也为 1。均匀分布于是保持不变。

对 m=5m=5m=5，增量余数 1 的概率为 2/6，其他余数各为 1/6，不能把每步成功概率直接当成 1/5；应使用余数链的返回时间结论。余数 0 的平稳概率是 1/m1/m1/m，平均首次正返回时间为 mmm。

由平均返回时间等于平稳概率的倒数，答案分别为 5 次和 6 次。模 6 时每次新增点数恰在六个余数上均匀，也可直接用成功概率 1/61/61/6 的几何等待验证。

模五时从零一步返回只有掷五，概率 1/6，不是 1/5；从余数四返回可掷一或六，概率 1/3。虽然单步成功率随状态变，长期零状态占比仍为 1/5，平均返回间隔为五。模六各增量余数均为 1/6，才可直接看作固定成功率的几何等待。

同类问题

随机累积量碰到周期条件时，可先对模数压缩状态。平稳占比求返回期望与每步独立成功求几何期望是不同依据，即使数值恰好一致也要区分。

2. 多一枚硬币

题目

A、B 分别独立投掷 n+1n+1n+1 枚和 nnn 枚公平硬币，n≥0n\ge0n≥0。求 A 的正面数严格多于 B 的概率。

考点：对称差；额外一次；平局概率。

查看分析与解答

必要知识

两人各投 n 枚时结果分布相同，互换两组会使正面差 D 变为 −D，因此领先和落后概率相等。唯一需要单独处理的是平局，额外一枚硬币正好给平局一半的转胜机会。

分析思路

先暂时拿走 A 多的一枚，按 D 正、零、负分类，再放回这枚硬币。可直接观察严格领先不能被额外非负正面数破坏。

解答步骤

若 D>0，无论额外一枚如何 A 都赢；若 D=0，仅额外为正面时赢；若 D<0，一枚最多把差补到零，不能严格赢。因此胜率为 P(D>0)+(1/2)P(D=0)=(1−p₀)/2+p₀/2。

先比较 A 的前 nnn 枚与 B 的 nnn 枚。令它们的正面数差为 DDD，交换两人的这两组硬币可把 D=dD=dD=d 与 D=−dD=-dD=−d 一一对应。记并列概率为 p0p_0p0​，则 P(D>0)=(1−p0)/2P(D>0)=(1-p_0)/2P(D>0)=(1−p0​)/2、P(D≥0)=(1+p0)/2P(D\ge0)=(1+p_0)/2P(D≥0)=(1+p0​)/2。

A 最后一枚为反面时需要 D>0D>0D>0，为正面时只需 D≥0D\ge0D≥0。把两种条件各乘 1/2 后相加，并列概率恰好抵消。

结果为 12(1−p0)/2+12(1+p0)/2=1/2\tfrac12(1-p_0)/2+\tfrac12(1+p_0)/2=1/221​(1−p0​)/2+21​(1+p0​)/2=1/2。

n=0 时 B 不抛，A 只有一枚，严格多于零的概率就是一半，公式仍成立。若改问“不少于”，平局也算赢，答案会改变；严格不等号是本题关键。

同类问题

两组同分布独立样本的比较可先用交换对称，避免展开长组合求和。额外样本的作用集中在接近并列的状态上。

3. 多两枚硬币

题目

A、B 分别独立投掷 n+2n+2n+2 枚和 nnn 枚公平硬币。求 A 的正面数严格多于 B 的概率，并与只多一枚硬币的情况比较。

考点：二项差；边缘优势；组合合并。

查看分析与解答

必要知识

额外两枚的正面数 K 以四分之一、二分之一、四分之一概率取零、一、二。A 原本落后一分时，两枚都正面也能反超，这比只多一枚新增了获胜机会。

分析思路

先按 K 分类，将不等式转成 D 的阈值，再用 D 的对称性只留下并列和相差一的概率。最后用二项分布表达这两个局部概率。

解答步骤

K=0 要 D>0；K=1 要 D≥0；K=2 要 D≥−1。设 p₀=P(D=0)、p₁=P(D=−1)，则三项分别为 (1−p₀)/2、(1+p₀)/2、(1+p₀)/2+p₁，按 K 权重相加得 1/2+(p₀+p₁)/4。

仍记前 nnn 枚正面数之差为 DDD，额外两枚的正面数 KKK 服从 Bin⁡(2,1/2)\operatorname{Bin}(2,1/2)Bin(2,1/2)。所求为 14P(D>0)+12P(D≥0)+14P(D≥−1).\tfrac14P(D>0)+\tfrac12P(D\ge0)+\tfrac14P(D\ge-1).41​P(D>0)+21​P(D≥0)+41​P(D≥−1). 令 p0=P(D=0)p_0=P(D=0)p0​=P(D=0)、p1=P(D=1)=P(D=−1)p_1=P(D=1)=P(D=-1)p1​=P(D=1)=P(D=−1)，用分布对称性化简，得到 1/2+(p0+p1)/41/2+(p_0+p_1)/41/2+(p0​+p1​)/4。

把 B 的反面数加到 A 的正面数中，得到一个 Bin⁡(2n,1/2)\operatorname{Bin}(2n,1/2)Bin(2n,1/2) 变量，而 DDD 是它减去 nnn，因此可直接写出 p0,p1p_0,p_1p0​,p1​ 的组合数形式。结果比 1/2 大；n=0n=0n=0 时是两枚至少一正面的 3/4。

具体地，p0=(2nn)/4np_0=\binom{2n}n/4^np0​=(n2n​)/4n、p1=(2nn−1)/4np_1=\binom{2n}{n-1}/4^np1​=(n−12n​)/4n，从而 P=1/2+(2n+1n)/4n+1P=1/2+\binom{2n+1}n/4^{n+1}P=1/2+(n2n+1​)/4n+1。

D=A_H−B_H=A_H+B_T−n，其中 A_H 与 B_T 独立、都为 n 枚公平币正面式计数，所以 D+n∼Bin(2n,1/2)。n=1 时 p₀=1/2、p₁=1/4，胜率为 11/16。n 增大时并列附近概率降低，额外两枚带来的优势趋小。

同类问题

多几个额外试验的比较题，可先对额外成功数条件化。真正影响胜负的是原差距靠近零的部分，无需求全部差分布的复杂累积和。

4. 51点覆盖

题目

单位正方形内任意放置 51 个点，点可位于边界。证明存在一个半径 1/71/71/7 的圆，至少覆盖其中 3 个点。

考点：抽屉原理；网格尺度；覆盖构造。

查看分析与解答

必要知识

抽屉原理说：若五十一个对象放入二十五类，至少一类含三个。几何题还需把分类单元控制得足够小，才能将同类点装进题目要求的圆。

分析思路

由点数倒推网格数量，再由圆半径检查格子边长。两个限制同时满足，便得到一个与具体点位置无关的构造。

解答步骤

5×5 网格共有二十五格，若每格最多两个点，总数最多五十，与五十一矛盾。小格边长 1/5，中心到最远角的距离为 √[(1/10)²+(1/10)²]=√2/10≈0.14142，小于 1/7≈0.14286。

要用抽屉原理保证一格至少 3 点，格子数应不超过 25，因为每格至多 2 点时最多容纳 50 点。另一方面，小格还必须能装进半径 1/71/71/7 的圆。把正方形均分为 5×55\times55×5 正好同时满足这两个要求。

边长 1/51/51/5 的小方格，其中心到顶点距离为半条对角线 2/10\sqrt2/102​/10。比较平方可知 2/100<1/492/100<1/492/100<1/49，因此覆盖整个小格所需半径小于 1/71/71/7。

将落在边界上的点按固定规则分配给某一格，至少一个小格含三个点；以它的中心作半径 1/71/71/7 的圆即可覆盖。

边界点可约定优先分给右侧、上侧格，外边界归最外一格，每点只计一次；实际几何位置仍在被分配格的闭包内，所以外接圆仍覆盖。无需假设点互不相同，共点只会使覆盖更容易。

同类问题

覆盖存在性可用“数量迫使聚集、单元尺寸控制距离”两步完成。网格数与外接半径应一起选择，不能只满足抽屉数量就结束。

5. 三次骰子最优停止

题目

公平六面骰最多掷 3 次，每次看见点数后可停止；继续则放弃当前点数，最后一次必须接受。奖励等于停止时的点数，求最优策略与期望奖励。

考点：机会价值；逆向递推；停止阈值。

查看分析与解答

必要知识

看到当前点数时，它已经确定；继续的收益仍随机，风险中性比较其期望即可。剩余机会越多，放弃当前结果的代价越低，所以初期可以要求更高点数。

分析思路

从强制接受的最后一次开始倒推。先求还剩一次的平均价值，再求还剩两次、三次时各点数应保留还是继续。

解答步骤

第二次若见一、二、三，继续的 3.5 优于当前；见四、五、六则接受。因此两次机会价值为 (3.5+3.5+3.5+4+5+6)/6=4.25。第一次的继续价值应使用这个 4.25，而不是再使用 3.5。

设 VkV_kVk​ 是尚有 kkk 次投掷机会、但还未投当前一次时的最优期望。观察到 xxx 后，立即停止得 xxx，继续的价值为 Vk−1V_{k-1}Vk−1​，所以选择两者较大值，Vk=E[max⁡(X,Vk−1)]V_k=E[\max(X,V_{k-1})]Vk​=E[max(X,Vk−1​)]。

最后一次没有选择，平均点数 V1=(1+2+3+4+5+6)/6=3.5V_1=(1+2+3+4+5+6)/6=3.5V1​=(1+2+3+4+5+6)/6=3.5。往前推时，阈值是“剩余机会的价值”，不是固定的 3.5；这就是第一次与第二次停止阈值不同的原因。

因此 V2=(3×3.5+4+5+6)/6=17/4V_2=(3\times3.5+4+5+6)/6=17/4V2​=(3×3.5+4+5+6)/6=17/4，第二次见到 4、5、6 就接受；V3=(4×17/4+5+6)/6=14/3V_3=(4\times17/4+5+6)/6=14/3V3​=(4×17/4+5+6)/6=14/3，第一次见到 5、6 就接受。公平入场价为 14/314/314/3。
