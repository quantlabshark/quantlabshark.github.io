新增因子是否改善了定价与组合机会

解释 GRS、均值—方差张成、alpha 摘要和贝叶斯比较，连接统计量与投资含义。

市场、规模和价值已经组成一个模型，再加入盈利因子，拟合误差通常会下降。需要进一步判断的是：下降有多大，是否只是增加参数后的样本内改善，以及新增收益能否由原来的因子组合复制。

检验对象与基准模型

测试资产是拿来评价模型的股票或组合。可以让两个模型解释同一组行业或特征组合，也可以让模型甲解释模型乙的因子，再反过来检验。前者比较对共同问题的解释能力，后者检查各模型是否包含对方没有的信息。

样本期间、收益频率、无风险基准与测试资产应保持可比。若一个模型用大盘股检验、另一个用全市场检验，误差差异同时包含资产选择的影响。

张成检验关心整条最小方差前沿

对给定目标收益，选择风险最低的组合。把不同目标收益的最优组合连接起来，得到最小方差前沿。横轴用标准差、纵轴用平均收益时，经典无约束前沿通常是双曲线的一部分。张成意味着现有资产已经提供新增资产能够带来的全部均值—方差机会。

使用普通收益而非先扣无风险的超额收益，令 R1tR_{1t}R1t​ 为 KKK 个原资产收益，R2tR_{2t}R2t​ 为 NNN 个新增资产收益，回归

在协方差可逆、允许卖空且只要求权重和为 1 的均值—方差问题中，任意前沿组合都能写成两个不同前沿组合的仿射组合：权重形如 awA+(1−a)wBa w_A+(1-a)w_BawA​+(1−a)wB​，其中 aaa 可以超出 0 到 1。这是两基金分离的含义。完整前沿具有两个独立方向，因此仅检查给定无风险利率下的一个切线组合，不能同时确定最小方差位置是否改变。

例如新资产可表示为 0.4RA+0.6RB+e0.4R_A+0.6R_B+e0.4RA​+0.6RB​+e，且残差平均为零、与旧资产不相关，那么直接持有 40% A 和 60% B 就能得到相同平均收益，并去掉残差风险。若复制权重只有 0.4+0.2=0.60.4+0.2=0.60.4+0.2=0.6，剩余 40% 资金放在哪里就成了额外问题。只检验截距为零无法解决它。

GRS 的投资解释允许按给定无风险利率借贷，因此比较从该利率出发的最大斜率。没有这项借贷条件时，整条风险资产前沿都重要，特别是最低波动点。某个新增资产不提高一条切线斜率，仍可能改善低风险区域。

单项误差有助于定位问题

联合检验给整体结论，单项结果帮助找到具体误差。常用摘要为

MAα=1N∑i∣α^i∣,MAt=1N∑i∣tαi∣.MA\alpha=\frac1N\sum_i|\hat\alpha_i|,\qquad MAt=\frac1N\sum_i|t_{\alpha_i}|.MAα=N1​i∑​∣α^i​∣,MAt=N1​i∑​∣tαi​​∣.

自拟例子中，三个资产的月截距为 0.2%、−0.4%、0.3%，平均绝对截距为 0.3%。不能先平均再取绝对值，否则正负误差会相互抵消。平均绝对 ttt 值反映标准化偏离，但它本身不是自动具有联合 ppp 值的新检验。

贝叶斯比较把参数不确定性纳入评价

设 DDD 为数据、MMM 为模型、θ\thetaθ 为模型参数，边际似然为 p(D∣M)=∫p(D∣θ,M)p(θ∣M)dθp(D\mid M)=\int p(D\mid\theta,M)p(\theta\mid M)d\thetap(D∣M)=∫p(D∣θ,M)p(θ∣M)dθ。它对不同参数的拟合按先验加权，而不只挑最佳参数。

两个模型的后验概率比等于先验概率比乘边际似然比。若先验相同、边际似然比为 3，且只比较这两个候选，后验概率为 75% 与 25%。这个结论取决于候选集合和先验。

Barillas–Shanken 的相关方法在备择假说下为 α\alphaα 设置与残差协方差有关的正态先验，如 α∣Σe∼N(0,τΣe)\alpha\mid\Sigma_e\sim N(0,\tau\Sigma_e)α∣Σe​∼N(0,τΣe​)。2020 年 Chib 等人的讨论指出，跨模型使用不可归一化先验时，任意比例常数未必能够抵消。参数空间、共同参数和先验尺度应一致处理，才能使边际似然比较有明确含义。

鲨鱼说

模型比较可以先问两个具体问题：新增因子能否解释旧模型留下的收益？旧模型能否复制新增因子？前者看测试资产，后者把因子本身当作测试资产。两个方向一起看，比只展示一个更高的拟合优度更有信息。

练习

新资产没有提高给定无风险利率下的最大夏普比率，却降低了全局最小方差组合的波动。GRS 与张成检验会关注相同变化吗？

查看解答

GRS 的几何比较主要关注给定无风险利率出发的切线斜率；张成还检验完整投资约束下的整条前沿，包括最低波动点。因此“某条切线没有改善”不足以推出“所有组合机会都没有改善”。
