整数交换

题目

不使用额外存储位置，如何交换整数 i,ji,ji,j？

考点：变量状态；异或；溢出与别名。

查看分析与解答

必要知识

赋值会立即覆盖变量旧值，因此每一步都要用更新后的状态理解。异或在每一位上相同为零、不同为一，满足交换律、结合律和 x⊕x=0。它可以把两个整数的信息暂时编码到一个整数中。

分析思路

用初值 a、b 追踪三步状态，比只记三行操作更能说明正确性。随后区分数学整数与固定宽度整数，以及两个参数是否实际指向同一存储位置。

解答步骤

以 a=3、b=5 为例，加减交换的状态是 (8,5)→(8,3)→(5,3)。异或交换则为 (3⊕5,5)=(6,5)，下一步 j=6⊕5=3，最后 i=6⊕3=5。

在算术运算不溢出的条件下，依次执行 i←i+ji\leftarrow i+ji←i+j、j←i−jj\leftarrow i-jj←i−j、i←i−ji\leftarrow i-ji←i−j。设初值为 a,ba,ba,b，三个步骤后的状态分别为 (a+b,b)(a+b,b)(a+b,b)、(a+b,a)(a+b,a)(a+b,a)、(b,a)(b,a)(b,a)。

按位异或的对应步骤为 i←i⊕ji\leftarrow i\oplus ji←i⊕j、j←i⊕jj\leftarrow i\oplus jj←i⊕j、i←i⊕ji\leftarrow i\oplus ji←i⊕j。利用 x⊕x=0x\oplus x=0x⊕x=0、x⊕0=xx\oplus0=xx⊕0=x 可验证交换结果。在引用参数可能指向同一变量时，应先检测地址是否相同，否则异或方法会把该变量清零。固定宽度有符号整数的加法溢出也会使加减方法失效。

实际程序通常使用语言提供的交换操作以表达意图。

若 i、j 是同一内存位置，第一步 i^=j 实际变成 x^=x，信息立即清零，后续无法恢复。加减交换则可能在 a+b 超出固定宽度范围时失败。Python 的 i,j=j,i 更清楚，但它是语言级解包赋值，不能用它来证明严格机器层面的“没有任何临时存储”。

同类问题

原地技巧先证明状态不丢失，再检查表示范围与别名。工程代码优先表达意图；题目限制存储时，应说明采用的计算模型。

有序数组的唯一元素

题目

给定有序数组，提取不同的元素。例如 [1,1,3,3,3,5,5,5,9,9,9,9][1,1,3,3,3,5,5,5,9,9,9,9][1,1,3,3,3,5,5,5,9,9,9,9] 应输出 [1,3,5,9][1,3,5,9][1,3,5,9]。

考点：有序性；扫描不变量；输出空间。

查看分析与解答

必要知识

有序数组中，同值元素必然相邻成组。每组只需保留首次出现者，不必用额外集合记住全部已见值。O(n) 表示访问元素次数随长度线性增长；输出本身占用的空间与辅助空间应分开。

分析思路

从左到右扫描，首元素保留，其后只在当前值与前一个值不同的时候输出。扫描到位置 i 时，输出已经恰好包含前缀中的每个不同值一次。

解答步骤

对 [1,1,3,3,3,5]，依次保留第一个 1，跳过第二个 1；遇到 3 时与前项不同而保留，后两个 3 跳过；最后保留 5。这个过程依赖输入有序。

相同元素在有序数组中连续出现，因此只需保留首元素，以及其后每个与前项不同的元素。时间复杂度为 Θ(n)\Theta(n)Θ(n)，除输出外只需常数额外空间。

Python8 行
def unique_sorted(a):
    if not a:
        return []
    out = [a[0]]
    for i in range(1, len(a)):
        if a[i] != a[i - 1]:
            out.append(a[i])
    return out

若要求原数组内压缩，可用读指针扫描、写指针记录不同值的下一个存放位置，发现新值就写入 a[write] 并加一。返回写指针作为有效长度；数组尾部的旧值不属于结果。空数组直接返回长度零。

同类问题

先利用输入已提供的结构，再决定是否需要哈希表。相邻去重适用于已分组的数据；无序输入若要保持首次出现顺序，则需要记录已见值或采用其他结构。

Horner 多项式求值

题目

设计高效算法计算 y=A0+A1x+⋯+Anxny=A_0+A_1x+\cdots+A_nx^ny=A0​+A1​x+⋯+An​xn。

考点：嵌套乘法；循环不变量；运算次数。

查看分析与解答

必要知识

多项式各项共享同一个 x。Horner 写法逐层提取公因子 x，把许多幂运算改成一次乘加的重复。系数列表按常数项到最高次排列时，计算必须反向遍历。

分析思路

先从最高次两项提取 x，再不断向低次扩展。每一步维护“当前已处理高次系数所构成的嵌套多项式”，直到把常数项加入。

解答步骤

例如 2+3x+4x² 在 x=5 时，先取 4，乘 5 加 3 得 23，再乘 5 加 2 得 117，与 2+15+100 一致。

分别从头计算每个 xix^ixi 需要二次量级乘法；逐项维护幂可降至线性。Horner 方法进一步将多项式写成

y=A0+x(A1+x(A2+⋯+xAn)⋯ )).y=A_0+x(A_1+x(A_2+\cdots+xA_n)\cdots)).y=A0​+x(A1​+x(A2​+⋯+xAn​)⋯)).

从最高次系数开始，递推 bn=Anb_n=A_nbn​=An​、bi=Ai+xbi+1b_i=A_i+xb_{i+1}bi​=Ai​+xbi+1​，最终 y=b0y=b_0y=b0​。总共需要 nnn 次乘法和 nnn 次加法，额外空间为常数。

Python5 行
def horner(coefficients, x):
    value = 0
    for coefficient in reversed(coefficients):
        value = value * x + coefficient
    return value

循环中处理到 A_i 后，value=A_i+x(A_(i+1)+…+xA_n)。反向加入下一个系数就维持这个关系，最后 i=0 得到原多项式。理论上从 A_n 初始化需 n 次乘加；示例从零初始化会多做一次 0*x+A_n，但仍为线性复杂度。浮点计算还受舍入影响，运算少并不自动等于任意输入下误差最小。

同类问题

重复幂次计算可通过代数重写共享中间结果。证明循环正确性时，明确每一步 value 代表哪一个子表达式，而不只是列出代码。

移动平均

题目

长度为 mmm 的数组 A，计算所有连续 nnn 个元素的平均值，1≤n≤m1\le n\le m1≤n≤m。

考点：滑动窗口；增量更新；边界索引。

查看分析与解答

必要知识

长度 n 的相邻窗口共享 n−1 项，窗口和只需减去离开的元素、加上新进入元素。长度 m 的输入共有 m−n+1 个完整窗口。

分析思路

先完整计算第一个窗口，再维护固定长度窗口和的不变量。每次新下标 i 进入时，离开的下标是 i−n，二者都必须包含在更新解释中。

解答步骤

例如数组 [2,4,6,8]、n=2，首和为 6、均值 3；下一步加 6 减 2，和为 10、均值 5；再加 8 减 4，和为 14、均值 7。

先求首窗口之和，随后每次删除离开窗口的元素、加入新元素。第 iii 个窗口与前一窗口共享 n−1n-1n−1 项，因此无需重新累加。总时间为 Θ(m)\Theta(m)Θ(m)，除输出外使用常数额外空间。

Python9 行
def moving_average(a, n):
    if not 1 <= n <= len(a):
        raise ValueError('window must be between 1 and array length')
    total = sum(a[i] for i in range(n))
    result = [total / n]
    for i in range(n, len(a)):
        total += a[i] - a[i - n]
        result.append(total / n)
    return result

代码检查 n 至少为一且不超过数组长度，因此除数有效且首窗口存在。初始化也逐项求和，避免切片复制 n 个元素造成额外空间。结果存储为 O(m−n+1)，除结果外维护 total 和索引只需常数空间。大量浮点更新可能积累舍入误差，可按精度需求周期性重新求和。

同类问题

固定窗口的和、计数等可加统计量适合“出一项、进一项”的更新。最大值、分位数并不满足同样的减加关系，需要单调队列或有序结构。

三种排序算法

题目

说明三种对 nnn 个不同数排序的方法，并分析复杂度。

考点：分治；排序稳定性；最好平均最坏复杂度。

查看分析与解答

必要知识

稳定排序会保持相等键元素的原相对顺序；原地通常指仅需常数或很少辅助空间。时间复杂度要说明输入情形：已排序、随机输入和最坏输入可能不同。

分析思路

用每种算法如何减少未排序工作来解释复杂度：插入逐个移动，归并逐层合并，快排按枢轴划分。再比较稳定性、空间和最坏情形，而不是只列 O 符号。

解答步骤

对四个数 [4,1,3,2]，插入法逐步整理前缀；归并先得到 [1,4]、[2,3]，再双指针合成 [1,2,3,4]；快排若选 4 为枢轴，会把其余三个全放一侧，这说明枢轴影响平衡。

插入排序维护一个已排序前缀，将新元素逐项向前比较并插入。第 iii 步最坏移动 i−1i-1i−1 个元素，最坏及均匀随机输入的平均时间均为 Θ(n2)\Theta(n^2)Θ(n2)；已排好序且实现带提前停止时为 Θ(n)\Theta(n)Θ(n)。它可原地、稳定地执行。

归并排序将输入对半分为子问题，再把两个有序子数组线性合并。递推 T(n)=2T(n/2)+Θ(n)T(n)=2T(n/2)+\Theta(n)T(n)=2T(n/2)+Θ(n) 给出平均和最坏均为 Θ(nlog⁡n)\Theta(n\log n)Θ(nlogn)。常见数组实现需要 Θ(n)\Theta(n)Θ(n) 辅助空间，并可保持稳定性。

快速排序选取枢轴，将较小与较大元素分到两边后递归。若每次枢轴都位于极端位置，递推为 T(n)=T(n−1)+Θ(n)T(n)=T(n-1)+\Theta(n)T(n)=T(n−1)+Θ(n)，最坏为 Θ(n2)\Theta(n^2)Θ(n2)。均匀随机枢轴下，设排序后第 ppp、qqq 个元素满足 p<qp<qp<q，两者发生直接比较当且仅当区间 p,…,qp,\ldots,qp,…,q 首先被选作枢轴的是其端点，概率为 2/(q−p+1)2/(q-p+1)2/(q−p+1)。所以期望比较次数为

E[Cn]=∑p<q2q−p+1=2(n+1)Hn−4n=Θ(nlog⁡n).E[C_n]=\sum_{p<q}\frac2{q-p+1}=2(n+1)H_n-4n=\Theta(n\log n).E[Cn​]=p<q∑​q−p+12​=2(n+1)Hn​−4n=Θ(nlogn).

随机化保证的是期望界，不会消除理论上的最坏输入路径。以下归并实现给出可直接运行的示例。

def merge_sort(a):
    if len(a) <= 1:
        return list(a)
    middle = len(a) // 2

随机排列 A：均匀洗牌

题目

已知可生成离散或连续均匀随机数，如何洗一副 52 张牌，使每种排列等概率？

考点：均匀排列；条件选择；Fisher–Yates。

查看分析与解答

必要知识

均匀洗牌要求 n! 个排列概率都为 1/n!，不仅要求每张牌在每个位置的边际概率相同。逐步固定位置时，必须只从尚未固定的牌中均匀选择。

分析思路

从位置零向后，把剩余牌中的随机一张交换进当前位置。固定后的位置不再参与选择，因而能直接把各步条件概率相乘证明每个排列等概率。

解答步骤

三张牌时，第一位有三选一，第二位在剩余两张中二选一，最后一位确定，所以每个指定排列概率为 1/3×1/2=1/6。若每一步都从全部三个位置选择再交换，固定位置会被反复打乱，不能使用这个证明，通常产生偏差。

一种方法是给每张牌赋独立连续随机键，再按键排序；键无相等的理想条件下，各排列由对称性等概率，时间为 Θ(nlog⁡n)\Theta(n\log n)Θ(nlogn)。有限精度实现还需处理随机键冲突。

Fisher–Yates（Knuth）洗牌可在线性时间内完成：第 iii 步从尚未固定的位置 i,…,n−1i,\ldots,n-1i,…,n−1 均匀抽取一个位置并交换到 iii。每个指定排列的概率为 1/n×1/(n−1)×⋯×1=1/n!1/n\times1/(n-1)\times\cdots\times1=1/n!1/n×1/(n−1)×⋯×1=1/n!。

def minmax(a):

        raise ValueError('empty array')

def first_nonzero(get):

        try:
            return get(i) != 0
        except IndexError:
            return True

    if boundary(0):
        try:
            return 0 if get(0) != 0 else None
        except IndexError:

    low = high // 2 + 1

查找 C：行列递增矩阵

题目

考点：二维单调性；排除区域；阶梯搜索。

查看分析与解答

必要知识

行递增保证右边不小于左边，列递增保证下边不小于上边。右上角兼具“向左变小、向下变大”的方向性；左上角则两个方向都变大，无法仅凭一次比较选择方向。

分析思路

从右上角出发，当前值大则排除整列并左移，当前值小则排除整行并下移。每步都说明被排除的区域为何不可能含目标。

解答步骤

例如矩阵 [[1,4,7],[2,5,8],[3,6,9]] 查找 6：从 7 开始过大，删最右列到 4；4 过小，删首行到 5；5 过小，下移到 6，成功。

从右上角开始。若当前值大于目标，则该列当前行及下方均过大，删除该列并左移。若当前值小于目标，则该行当前列及左侧均过小，删除该行并下移。每次至少排除一整行或一整列，至多访问 2n−12n-12n−1 个位置，时间为 O(n)O(n)O(n)、空间为 O(1)O(1)O(1)。

def search_matrix(a, target):
    if not a or not a[0]:
        return None
    row, col = 0, len(a[0]) - 1
    while row < len(a) and col >= 0:
        if a[row][col] == target:
            return row, col
        if a[row][col] > target:
            col -= 1
        else:
            row += 1
    return None

剩余搜索区域是从当前行向下、从当前列向左的矩形，即 a[row:, :col+1]。当前右上值大于目标时，同列下方更大；当前值小于目标时，同行左方更小。行下标最多增加 n 次、列下标最多减少 n 次，方阵至多访问 2n−1 个位置；m×n 矩阵则为 O(m+n)。

示例扫描的 current 依次为 1、3、−2、4、1、3、9、4、3。到 4 时前段累计为负，因此重新从下标 3 开始；到下标 6 的 6 时累计达到 9，得到 [4,−3,2,6]。

定义前缀和 P0=0P_0=0P0​=0、Pj=∑k=1jAkP_j=\sum_{k=1}^jA_kPj​=∑k=1j​Ak​。子数组 iii 至 jjj 的和为 Pj−Pi−1P_j-P_{i-1}Pj​−Pi−1​。固定右端点 jjj 时，应减去此前最小的前缀和，因此一边扫描、一边维护最小前缀和及其位置即可在线性时间求解。

等价的 Kadane 递推是：以当前位置结尾的最优和，等于“当前元素”与“前一位置的最优和加当前元素”中的较大者。以下实现同时保留端点，并正确处理全负数组。

Python13 行
def maximum_subarray(a):
    if not a:
        raise ValueError('empty array')
    current = best = a[0]
    start = left = right = 0
    for i in range(1, len(a)):
        if current + a[i] < a[i]:
            current, start = a[i], i
        else:
            current += a[i]
        if current > best:
            best, left, right = current, start, i
    return best, left, right

示例返回 (9, 3, 6)，采用从 0 开始、两端包含的索引，对应 [4,−3,2,6][4,-3,2,6][4,−3,2,6]。时间为 Θ(n)\Theta(n)Θ(n)，额外空间为常数。若输入是累计收益的一阶差分，该计算与最大连续上涨相关；最大回撤需要相应的最大历史峰值与后续低点比较。

非空要求使初始化必须用首元素，而不能把 best 默认设为零。例如 [−5,−2,−7] 正确答案是 −2，而非空子数组的零。代码采用从零开始、左右端点都包含的索引；相同最大值时因使用严格大于更新，会保留先遇到的答案。
