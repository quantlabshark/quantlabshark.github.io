05 · 实测结果、覆盖率与复现步骤

比较不同公式的真实样本结果，识别短窗退化、费用敏感性和筛选偏差。

怎样阅读结果表

逐项课程报告一日、五日和十日 Rank IC，年度一日 IC，以及高低分组的费用敏感性。每项都使用同一股票池、复权和时间规则，便于分辨差异来自公式还是实现变化。

一个平均 IC 由许多股票和日期组成。平均值接近零时，可能是整个时期都弱，也可能是前后方向相反。年度图与有效覆盖一起看，才能区分这些情况。

三类值得检查的结果

第一类是方向稳定但费用较高。信号每日变化快，分组差为正，也可能不足以覆盖换仓。第 9 项一日平均 Rank IC 约 0.0210，但在本次目标变化测算中，加入 5 个基点的单位费用后，平均分组差变为负值。

第二类是原方向与数据不一致。第 101 项一日平均 IC 约 −0.0218，表示本样本中高分组随后排序偏低。可以提出“是否存在短期反转”的新假设，但若看完结果就反转方向，再用相同数据汇报绩效，只是在重新利用同一份证据。

第三类是输入口径使信号退化。第 7 项的成交股数与平均成交金额比较，在本样本中常落入固定分支，有效 IC 日数不足。第 96 项长链条包含短窗相关，任何一层零方差都可能使后续窗口缺失。空结果应追踪计算链，而非填零凑出曲线。

费用为何影响结论

第 42 项在本次延迟评价下，一日平均 IC 约 0.0256，高低分组平均差约 11.21 个基点。按目标权重变化施加 5 个基点费用后约为 1.54，施加 10 个基点后约为 −8.13。一个看似较强的排序关系，对费用假设仍可能敏感。

以上是分组诊断，未模拟真实借券和成交，也没有使用收益结果反向调整参数。多空分组中的负权重不代表实际市场随时提供相应借券，

鲨鱼说

预测有一点用，并不等于交易值得做。若每次调整赚到的差价还不够付费用，改进方向可能是降低换仓、合并信号或改变执行方式；每次改变都要重新检验。

多个公式同时检验的问题

即使所有公式都无效，测试足够多次也会出现较大的偶然 t 值。101 项之间又存在相关，不能把每项当作完全独立的发现。可以使用预留检验期、错误发现率控制、按经济含义合并相近假设等方式处理。

例如有 101 个预先固定的检验，最简单的 Bonferroni 方法将单项显著性水平降为 0.05/101≈0.0004950.05/101\approx0.0004950.05/101≈0.000495。它较保守，但说明“每个都用 5%”与“整体保持 5%”不是同一个要求。逐项报告的 HAC t 值没有自动执行这一步。

代码怎样运行

附件包含 alpha_engine.py、101 项表达式、alpha_runner.py、教学数据生成与验证程序，以及本次汇总统计。安装 requirements.txt 中的库后，运行：

文本 / 日志2 行
python alpha_runner.py --alpha 101 --demo
python alpha_runner.py --alpha 9 --input panel.csv --output alpha09.csv

用户输入 CSV 每行是一个日期与股票组合，包含 date,asset,open,high,low,close,volume,amount,vwap。价格、成交股数和金额应预先统一单位及复权。需要行业的公式再提供对应分类，需要市值的公式提供 cap；缺少字段会明确报错，不以当前分类或常数代替。

--demo 生成教学面板，不访问网络。输出为日期乘股票的分数矩阵。真实行情评价还需独立构造下一开盘开始的标签；原始行情未放入压缩包。

检查一项复现差异

若两份程序结果不同，依次比较：输入日期和股票范围、价格与量的单位、adv 定义、窗口取整、rank 并列规则、argmax 方向、常量相关和缺失处理。最后才比较组合与费用。

对复杂表达式，逐层保存 z1、z2 等中间量。找到第一个不同的中间量，比只比较最后净值更容易定位错误。还可以把某个日期之后的输入整体改变，确认之前的输出不受影响，这直接检查计算是否误读未来行。

练习

看到某公式在 101 项中排名第一，下一步是否应立即提高仓位？

查看解答

先检查样本量、年度分布、输入定义和费用，再固定候选规则进入未参与筛选的数据。排名第一只说明它在本次比较中较好，并未消除多次筛选带来的乐观偏差。仓位还需结合风险、流动性与成交条件。
