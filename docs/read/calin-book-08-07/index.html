解的存在、唯一性与边界

理解 Lipschitz 条件的作用，并区分局部解、爆炸和平方根扩散。

为什么要问解是否存在

写出 dX=a(t,X)dt+b(t,X)dWdX=a(t,X)dt+b(t,X)dWdX=a(t,X)dt+b(t,X)dW 并不能自动保证它在所有时间都有唯一状态。存在性回答能否构造满足方程的过程。路径唯一性回答在同一概率空间、同一布朗运动和同一初值下，两个候选解是否几乎必然重合。若噪声路径不同，得到不同状态本来就是模型所允许的。

一个常用充分条件是：在有限时间范围内，存在常数 L,KL,KL,K，使

∣a(t,x)−a(t,y)∣+∣b(t,x)−b(t,y)∣≤L∣x−y∣,|a(t,x)-a(t,y)|+|b(t,x)-b(t,y)|\le L|x-y|,∣a(t,x)−a(t,y)∣+∣b(t,x)−b(t,y)∣≤L∣x−y∣, ∣a(t,x)∣2+∣b(t,x)∣2≤K(1+∣x∣2).|a(t,x)|^2+|b(t,x)|^2\le K(1+|x|^2).∣a(t,x)∣2+∣b(t,x)∣2≤K(1+∣x∣2).

第一条控制状态变化引起的系数变化，第二条限制远处增长，防止有限时间跑到无穷。再配合可测性和平方可积初值，可得到唯一、非爆炸的强解。它们是便于检验的充分条件，并不是所有可解方程都必须满足的必要条件。

平方根扩散需要专门条件

考虑 CIR 型方程 dX=κ(θ−X)dt+σXdWdX=\kappa(\theta-X)dt+\sigma\sqrt XdWdX=κ(θ−X)dt+σX​dW，状态限制在非负半轴。平方根在零附近不是 Lipschitz，因此不能把它直接列为全局 Lipschitz 定理的例子。然而在 κ,θ,σ>0\kappa,\theta,\sigma>0κ,θ,σ>0 下，它具有唯一的非负强解。

若 X0>0X_0>0X0​>0 且 2κθ≥σ22\kappa\theta\ge\sigma^22κθ≥σ2，零边界不可达；若不等式不满足，过程可能到达零，但仍有非负解。这里的结论来自针对平方根系数和边界的专门分析。欧拉离散却可能生成负值，再对负数开平方就失效，数值方案必须尊重状态边界。

数值发散与真实爆炸

模拟值突然变大可能来自方程本身的爆炸，也可能来自离散步长不稳定。区分时应缩小步长、检查解析表达式或增长条件，并比较不同停止阈值。只有看到一个很大的数，不能立即判断连续模型已经在那个时刻爆炸。

同样，数值状态越过零可能是模型允许，也可能是方案没有保持边界。对平方根扩散，把负值直接截为零会改变数值分布；若采用这种方案，应明确其近似含义，并检查均值、方差和边界命中频率是否随步长改善。
