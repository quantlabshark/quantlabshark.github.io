跳表与随机层级索引

追踪跳表的逐层查找与前驱更新，推导期望层数、空间和有序映射操作。

有序链表能顺序扫描区间，却仍需逐个比较才能找到起点。跳表在完整底层之上增加稀疏索引层，用较长的跳跃接近目标，再逐层缩小搜索范围。

查找路径

底层为 1→3→5→7→9，上层只保留 1→5→9。查找 7 时，从最高层向右到 5；下一项 9 已超过目标，下降到底层，再检查 7。

一般规则是：下一节点键小于目标就右移，否则下降。下降后仍从当前节点继续，因为此前已经排除它左边的键。底层最终停在目标之前，检查下一节点是否相等。

节点为什么有不同高度

每个节点必在第 0 层，再以概率 p 独立提升一层，连续成功则继续。到第 k 层的概率为 pᵏ，n 个节点中该层期望数量为 npᵏ。

取 p=1/2，各层期望数量为 n、n/2、n/4、…，总引用数量的期望为 n/(1−p)=2nn/(1-p)=2nn/(1−p)=2n，所以期望空间 O(n)。令 npᵏ约为 1，得到最高层数量级 log⁡1/pn\log_{1/p}nlog1/p​n。

每层典型横向移动数受几何分布控制，期望为常数级，结合对数层数得到期望 O(log n) 查找。随机提升不提供每一次构造的确定性高度保证；固定最大层数也需随预期规模合理设置。

插入保存各层前驱

搜索时将每层最后一个小于目标的节点存入 update[k]。若底层下一键已相等，只更新 value。否则生成高度 h，在第 0 至 h−1 层依次执行：

new.next[k] = update[k].next[k]，然后 update[k].next[k] = new。

先保存原后继再接入新节点，与单链表插入相同。若新节点超过当前最高层，新层的前驱为头哨兵，同时提高当前层数。

删除和范围访问

删除也先取得 update。每层若前驱的下一节点就是目标，将它改为目标同层的下一节点。移除后，若最高层为空，逐层降低当前层数；底层仍完整保存剩余记录。

范围 [a,b] 查询先找到第一个不小于 a 的节点，再沿第 0 层前进至键大于 b。若输出 k 条记录，期望时间 O(log n+k)。映射接口还可提供 get、put、delete、size 和按键顺序的 items。

与平衡树的关系

AVL 用旋转确定性地限制高度，跳表用随机层级获得期望性能。二者都保留有序关系。跳表的随机种子只控制本次演示结构，检查时应验证底层顺序、上层为下层子序列及键值操作，而非要求每次图形完全相同。

鲨鱼说 上层通过快捷链接连接底层的部分节点。修改一个键对应的值时，所有层仍指向同一记录，不需要分别更新多份值。

import random
class Node:
    def __init__(self,key,value,height):
        self.key,self.value=key,value;self.next=[None]*height
class SkipMap:
    def __init__(self,max_level=16,seed=20261018):
        self.max_level=max_level;self.head=Node(None,None,max_level)
        self.level=1;self.rng=random.Random(seed)
    def predecessors(self,key):
        update=[self.head]*self.max_level;node=self.head
        for level in range(self.level-1,-1,-1):
            while node.next[level] and node.next[level].key<key:node=node.next[level]
            update[level]=node
        return update
    def put(self,key,value):
        update=self.predecessors(key);node=update[0].next[0]
        if node and node.key==key:node.value=value;return
        height=1
        while height<self.max_level and self.rng.random()<.5:height+=1
        if height>self.level:
            for i in range(self.level,height):update[i]=self.head
            self.level=height
        node=Node(key,value,height)
        for i in range(height):
            node.next[i]=update[i].next[i];update[i].next[i]=node
    def get(self,key):
        node=self.predecessors(key)[0].next[0]
        if node is None or node.key!=key:raise KeyError(key)
        return node.value
    def items(self):
        node=self.head.next[0]
        while node:
            yield node.key,node.value;node=node.next[0]
m=SkipMap()
for key in [7,2,9,1,5]:m.put(key,str(key))
m.put(5,'five')
assert m.get(5)=='five' and [k for k,v in m.items()]==[1,2,5,7,9]
print(list(m.items()))
