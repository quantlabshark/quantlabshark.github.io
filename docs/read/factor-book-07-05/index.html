7.5 因子择时的信号与验证

区分估值、动量、波动、情绪和宏观信号，推导权重规则，并用数据发布时间与成本检验动态配置的价值。

调整因子权重需要预测什么

假设价值和质量因子各配置50%。如果预计价值下个月更强，动态策略会提高价值权重。择时目标是随后持有期的相对表现，解释当期行情属于另一项分析任务。固定等权组合提供一个明确对照：动态调整增加的净收益，是否足以补偿预测误差与换手成本。

五类常见择时信息分别是因子估值、因子动量、因子波动、市场情绪和宏观状态。它们回答的问题不同，有的预测收益，有的管理风险，不宜把所有权重变化都解释成“知道哪个因子会涨”。

估值价差为何需要增长预期

稳定增长股利模型给出

P0=D1k−g,k=D1P0+g,P_0=\frac{D_1}{k-g},\qquad k=\frac{D_1}{P_0}+g,P0​=k−gD1​​,k=P0​D1​​+g,

其中D1D_1D1​是下一期股利，ggg是长期增长率，kkk是要求回报率，且k>gk>gk>g。若股利支付率为ppp、下一期盈利为E1E_1E1​，则k=pE1/P0+gk=pE_1/P_0+gk=pE1​/P0​+g。因此直接把股利收益率写成盈利收益率，隐含了支付率等额外条件。

价值多头与成长空头的预期回报差，可分成现金分配收益差与增长预期差。高盈利收益率可能提供较高当前收益，也可能对应较低增长。仅看到“便宜”，还不足以判断完整回报。

实践中可以把多头与空头的盈利收益率差或BM差作为价值价差VSVSVS，也可使用比值。它衡量一个因子当前多空两端的相对便宜程度。需要比较同一因子自己的历史：价值因子本来就会持有便宜股票，通常的价差并不是额外择时信号。

一种历史规则使用过去36个月的均值和极差：

qk,t=1+VSk,t−VS‾k,tVSk,tmax⁡−VSk,tmin⁡,wk,t=qk,t∑jqj,t.q_{k,t}=1+\frac{VS_{k,t}-\overline{VS}_{k,t}}{VS^{\max}_{k,t}-VS^{\min}_{k,t}},\qquad w_{k,t}=\frac{q_{k,t}}{\sum_jq_{j,t}}.qk,t​=1+VSk,tmax​−VSk,tmin​VSk,t​−VSk,t​​,wk,t​=∑j​qj,t​qk,t​​.

当前价差高于自身历史平均，原始权重qqq提高。若历史极差为零，应跳过该信号或保留基准权重；新观测超出历史范围时，也应预先规定上下限，避免异常权重。

例如因子A当前价差6%、历史均值4%、最高7%、最低3%，则qA=1.5q_A=1.5qA​=1.5。因子B当前恰好等于均值，qB=1q_B=1qB​=1。归一化后A、B各60%、40%。这只是权重映射，没有证明A随后回报更高。估值择时还可能增加长期价值风格暴露，因此应检验其增量是否只是价值因子本身的表现。

因子动量与股票动量的区别

股票动量在股票之间比较过去涨跌；因子动量比较价值、质量等因子组合的过去收益。截面因子动量买入近期较强因子、卖出较弱因子；时序因子动量则判断某个因子自身的近期收益方向。两者的基准与持仓不同。

一项历史研究使用1963—2016年美国股票构造的51个因子，每月做多近期最强8个、做空最弱8个。在1个月形成期、1个月持有期的设置下，报告年化收益10.49%。另一些研究扩展到22或65个因子及多个市场。相关结果说明因子收益可能存在延续，但不能把某一组样本参数直接当作稳定规则。

持有期超过形成频率时，多个批次会重叠，必须规定每批资本权重。用近期IC调整选股信号权重，也具有按信号近期效果调整配置的特点，但IC与因子组合收益不是完全相同的对象。

波动率调整主要改变风险

反波动率权重为

wk=1/σ^k∑j1/σ^j.w_k=\frac{1/\hat\sigma_k}{\sum_j1/\hat\sigma_j}.wk​=∑j​1/σ^j​1/σ^k​​.

波动较低的因子获得更多资金；当所有相关系数相同时，这一规则也能实现风险平价。最小方差和一般风险平价还需要相关结构，不能仅用单项波动代替。

Python8 行
# 自拟：波动预测在上月末产生，用于下一月配置。
vol = [.10,.20]
raw = [1/x for x in vol]
w = [x/sum(raw) for x in raw]
next_return = [.02,-.01]
result = sum(a*b for a,b in zip(w,next_return))
print(w, 'next month return:', result)
assert abs(result-.01)<1e-12

权重为三分之二和三分之一，下一月收益为1%；等权为0.5%。若下一月收益交换，反波动配置反而不如等权。波动预测即使准确，也不等于收益预测准确。

同期情绪与随后收益不能混为一谈

乐观情绪可能推动高风险、难估值股票当期上涨；价格推得过高又可能降低其随后回报。这两种关系可以同时存在。研究必须明确是比较情绪状态下的同期表现，还是用今天的情绪预测未来。

历史研究曾按VIX划分乐观、中性和悲观状态。所引用的表格中，乐观状态下价值、动量、低波动相对标普500的年收益分别为4.85%、−1.20%、−2.60%。悲观状态下三者分别为1.42%、13.40%、15.20%。

这些同期分组数字不能直接生成下一期的配置方向。判断状态所用信息是否事前可得，还需要单独检查。

鲨鱼说

“危机期间某因子表现好”与“提前知道危机将发生”是两件需要分别检验的事。先写出信号可用日期和持有期，再解释分组收益。

宏观变量怎样进入预测

宏观信号包括增长、通胀、利率、信用、货币与流动性，也包括政策或外部冲击。期限利差反映不同期限收益率的差，TED利差在相关历史研究中用于表示银行融资压力。变量与因子的关联可能随预测期限改变。

历史研究报告：期限利差与盈利因子表现存在负向关联。持有期超过6个月时，TED及期限利差与价值、盈利、投资因子的关系较明显。超过一年时，单位产出增长、个人储蓄率、CPI和PPI等与价值及投资因子的关系更突出。

这些关联依赖样本、变量定义与持有期，不能由单个相关系数直接推导因果。

商业周期分组也揭示不同风险：历史样本中价值和动量较顺周期，低波动较偏防御，质量在收缩阶段可能具有较强相对表现。衰退日期通常由事后确认，宏观统计又可能修订。回测应保存首次发布日期、当时可见值和修订版本。今天看到的最终数据不等于当时可以使用的数据。

扩张阶段需求改善、产能利用率提高，固定成本占比较高的企业利润可能恢复更快，部分低估值或困境公司因盈利修复而受益。持续的盈利上修也可能延续价格趋势。收缩阶段相反，收入下滑与融资收紧会放大这些公司的利润和偿付压力。质量较高公司的现金生成和资产负债表通常更稳定，低Beta组合对市场下跌的敏感度较小，因此可能表现出相对防御性。

这个传导链说明为何应同时观察行业、经营杠杆和融资条件。“价值”“动量”这样的标签本身不能确定每次周期转换中的收益方向。

怎样判断择时增加了价值

先固定因子定义、基准权重和少量有经济机制的信号，在训练期估计关系，在后续期间形成权重并执行。每次交易记录形成信号、发出指令和实际成交的时间。比较同一风险口径下的净收益、回撤与换手，并检查结果是否主要来自少数危机月份。

预测关系会变化，历史样本中的指标选择可能受到数据窥探，事后修订也会引入未来信息。反复尝试许多窗口之后，只展示最好的一条曲线，不能证明规则可靠。已有历史比较中，估值、动量或复杂风险权重在扣费后未必明显超过等权。复杂模型需要证明其新增参数确实带来样本外改善。
