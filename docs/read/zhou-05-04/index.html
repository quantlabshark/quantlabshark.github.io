布朗运动与随机微积分

布朗运动性质、单侧与双侧首达、指数鞅、Itô公式及全部原题。

布朗运动用于描述连续时间的随机波动。随机积分沿时间累加随机增量，伊藤公式中的二阶项来自这些增量平方在细分后的累积。

布朗运动 A：定义与基本性质

题目

定义标准布朗运动，并列出其主要性质。

考点：独立增量；正态尺度；鞅。

查看分析与解答

必要知识

随机过程 B_t 是每个时刻对应一个随机变量的一组对象。路径描述一次实现随时间的变化；增量 B_t−B_s 描述一段时间内的变化。信息集 ℱ_t 汇总截至 t 时刻已知的路径，条件期望表示在这些信息下预测未来。

分析思路

先列定义中的四个条件，再用“当前值加独立未来增量”推导均值、协方差与鞅性质。不要把固定时刻的正态分布当成完整过程定义。

解答步骤

增量方差等于时长 Δt，因此标准差为 √Δt。时间缩小到百分之一，典型波动只缩小到十分之一，这与普通可导曲线的线性缩放不同。

标准布朗运动 BtB_tBt​ 满足：B0=0B_0=0B0​=0；样本路径连续；不相交时间区间上的增量相互独立；对 0≤s<t0\le s<t0≤s<t，Bt−Bs∼N(0,t−s)B_t-B_s\sim N(0,t-s)Bt​−Bs​∼N(0,t−s)。因此

E[Bt]=0,Var⁡(Bt)=t,Cov⁡(Bs,Bt)=min⁡(s,t).E[B_t]=0,\quad\operatorname{Var}(B_t)=t,\quad\operatorname{Cov}(B_s,B_t)=\min(s,t).E[Bt​]=0,Var(Bt​)=t,Cov(Bs​,Bt​)=min(s,t).

布朗运动 B：与平方的相关性

题目

对 t>0t>0t>0，标准布朗运动 BtB_tBt​ 与 Bt2B_t^2Bt2​ 的相关系数是多少？二者是否独立？

考点：正态矩；不相关与独立；非线性关系。

查看分析与解答

必要知识

相关系数只刻画线性共同变化，定义为协方差除以标准差乘积。B_t∼N(0,t)，奇数阶矩为零，二阶矩为 t、四阶矩为 3t²。平方关系属于非线性依赖。

分析思路

先计算 Cov(B_t,B_t²)，再检查两个方差是否非零。得出相关为零之后，还应单独判断独立性，而不是把两者混为一谈。

解答步骤

t>0 时，协方差为 E[B_t³]−E[B_t]E[B_t²]=0−0×t=0。Var(B_t)=t，Var(B_t²)=E[B_t⁴]−E[B_t²]²=3t²−t²=2t²。因此相关系数为零。

但知道 B_t 的数值后，B_t² 完全确定；例如 B_t²≤1 等价于 |B_t|≤1，显然不是独立事件。只有联合正态变量才有“不相关推出独立”的性质，这一对变量并不联合正态。t=0 时两个方差均为零，相关系数无定义。

布朗运动 C：两个时刻异号

题目

求 Pr⁡(B1>0,B2<0)\Pr(B_1>0,B_2<0)Pr(B1​>0,B2​<0)。

考点：独立增量；旋转对称；扇区概率。

查看分析与解答

必要知识

B₁ 与 B₂ 不是独立变量，因为 B₂ 含有 B₁ 的累计变化。但 X=B₁ 与 Y=B₂−B₁ 是两个不重叠单位时间增量，独立且均为 N(0,1)。它们的联合密度只依赖 x²+y²，具有旋转对称性。

分析思路

先把相关的 B₁、B₂ 改写成独立增量，再将符号条件转为平面直线两侧的区域。旋转对称使扇区概率等于角度占比。

解答步骤

条件变为 X>0、X+Y<0，即 X>0、Y<−X。这是第四象限中从负 y 轴到直线 y=−x 的扇区，夹角 π/4。整个平面角度 2π，故概率 (π/4)/(2π)=1/8。

也可先要求 X>0、Y<0，概率 1/4；在此条件下，|X|、|Y| 是独立同分布的正值，|Y|>|X| 的概率为 1/2。相乘得 1/8。后半程必须向负方向且幅度超过前半程，才能由正转负。

同类问题

布朗运动多时刻问题，优先拆成独立增量。若两个增量时长不同，应先按各自标准差缩放，几何边界斜率也随之变化，不能继续直接使用 π/4。

考点：首次退出；平方鞅；截断停时。

查看分析与解答

必要知识

考点：首次到达；反射原理；重尾等待。

查看分析与解答

必要知识

符号 inf⁡\infinf 表示集合的下确界；这里 τx\tau_xτx​ 表示第一次碰到水平 xxx 的时间。以下先取 x>0x>0x>0。记 ϕ(z)=e−z2/2/2π\phi(z)=e^{-z^2/2}/\sqrt{2\pi}ϕ(z)=e−z2/2/2π​ 为标准正态密度，Φ(z)=∫−∞zϕ(u) du\Phi(z)=\int_{-\infty}^z\phi(u)\,duΦ(z)=∫−∞z​ϕ(u)du 为其分布函数。事件 τ_x≤t 表示截至 t 曾到过 x，与终点 B_t≥x 不同：路径到过 x 后可能又落回其下。反射原理把这部分路径与终点在 x 上方的路径配成等概率的一对。

分析思路

先求到达时间分布函数，再求导得到密度，最后检查均值积分尾部。最终必能到达，不代表平均等待时间有限。

解答步骤

在首次到达 x 的时刻之后，将路径关于水平线 x 镜像。布朗增量正负对称，使反射后的路径概率不变；终点低于 x 的已命中路径映为终点高于 x 的路径。因此命中概率是终点越界概率的两倍。

反射原理把到达 xxx 后最终落在 xxx 以下的路径，与最终在 xxx 以上的路径对应。因此
